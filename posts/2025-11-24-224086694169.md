# Havard-QuEra팀의 임계오류율 아래로 오류율을 낮추는 데 성공

[A potential quantum leap — Harvard Gazette](https://news.harvard.edu/gazette/story/2025/11/a-potential-quantum-leap/)

**📌 핵심 요약**

- - Harvard 연구팀(루킨 그룹)이 중첩형(멀티-레이어) **양자 오류 정정(Quantum Error Correction, QEC)** 기법을 실제 실험에서 구현하여, **임계 오류율(threshold) 아래로 오류율을 낮추는 데 성공**했다고 Harvard Gazette가 보도함.

> **임계 오류율**
>
> 실측 오류율 ~0.6% → threshold ~1% 근처로 추정 가능

**주요 포인트**

- - **여러 단계의 오류 정정 레이어를 결합하여** 회로 심도를 깊게 유지하면서도 안정적인 계산 가능
  - **오류율이 threshold보다 낮아지면**, qubit 수를 늘릴수록 오히려 정확도가 증가
  - **중립 원자(Neutral Atom) 플랫폼**, 루비듐(Rb) 원자를 레이저로 제어
  - Google Quantum AI의 Hartmut Neven도 “대규모 유용한 양자컴퓨터” 방향으로 큰 진전이라고 언급
  - Harvard-MIT-QuEra 팀의 **3,000-qubit Rydberg 시스템**(2시간 연속 작동) 성과와 연결

**🧠 기술적 의미**

|  |  |
| --- | --- |
| **항목** | **내용** |
| 실험적 성과 | 다층 QEC가 실제 원자 기반 시스템에서 실증됨 |
| 스케일링 중요 포인트 | 버틸 수 있는 오류율 이하로 만들어야 논리 큐비트 증가가 의미 있음 |
| 플랫폼 | 루비듐 중립원자 + Rydberg 상호작용 |
| 경쟁 기술 대비 | Superconducting(IBM, Google), Ion-trap(IonQ, Quantinuum)과 다른 강점: 확장성 및 2D lattice 자연 구조 |
| 시장 영향 | QuEra / Harvard / MIT 연합의 전략적 가속화 가능성 |

****

**✨ 왜 의미가 큰가?**

- - 기존 이론 중심 오류정정 논의 ➜ **실험적으로 실제 논리 회로 깊이를 늘리고 성능이 좋아지는 영역을 보여줌**
  - 즉, **전통적 “오류정정 비용이 너무 높다”는 주장을 실험으로 반박할 수 있는 수준**에 가까워짐.
  - **기존 문제점**

    - 오류정정 코드는 구현 오버헤드가 매우 큼
    - 다층 구조는 복잡하고 실제 실험에서 잘 동작하지 않음
  - **이번 성과의 개선점**

    - 불필요한 구성 요소 제거하여 **오버헤드 축소**
    - 실험 데이터 기반 최적화

**🔗 Quantum Ecosystem 연관성**

|  |  |
| --- | --- |
| **기관 / 기업** | **방향 / 관련성** |
| **QuEra, Harvard, MIT** | 중립원자 기반 대규모 클러스터 |
| **IonQ / Oxford Ionics** | 고신뢰도 control 기반 QEC, ion-trap 경쟁 |
| **Google / IBM** | surface code 기반 QEC |
| **US National Quantum Strategy** | 대규모 fault-tolerant QPU 개발 요구 |

- - Harvard-QuEra 방향성은 **대규모 NISQ → 실용 QEC → Fault-tolerance** 로 이어지며, IonQ/Oxford의 **고신뢰 게이트** 전략과는 **스케일링 접근 방식이 상호 보완적**.

**✨ 한줄 결론**

- - Harvard 연구는 **실제 장비에서 다층 QEC가 오류율 임계점 아래로 진입할 수 있음을 실증한 핵심적 진전**이며, **대규모 fault-tolerant quantum computing으로 가는 전환점**이 될 가능성이 높다.

**🧠 핵심 내용**

- - **3,000개 이상의 중립 원자(87Rb) 큐비트를 2시간 이상 연속 유지**하는 실험 성공.
  - **연속 로딩(continuous reloading) 아키텍처** 발표:

    - optical lattice conveyor belt 2단 구조로 원자 저장소(reservoir) 이동
    - optical tweezer array로 원자를 끊임없이 추출 & 보충
    - 초당 **30,000 qubits/sec 생성**, **15,000 qubits/sec rearranged**
  - 저장 영역의 qubit는 **초퍼레이션(operations) 중에도 coherence 유지**

    - T2 ≈ 1.09 s, T1 ≈ 12.6 s 수준 유지
  - **큐비트 손실(lost atoms)을 실시간 보충**하여 기존 tweezer lifetime(60s)을 획기적으로 초과
  - 결과적으로 **deep circuit 실행의 필수 조건(손실 보충 + coherence 유지) 충족**

****

**🚀 의의**

- - 기존 neutral-atom platform의 가장 큰 약점이었던 **atom loss 문제를 해결**
  - **Fault-tolerant deep-circuit quantum computing pre-condition 실험적 달성**
  - 단순 NISQ scaling이 아니라 **유용한 logical QEC를 수행할 수 있는 인프라 완성 단계로 진입**
  - 📍 **즉: 대규모 FTQC 운영에 필요한 “qubit sustainability” 문제를 해결한 landmark 실험**

**🧠 핵심 내용**

- - **완전한 fault-tolerant quantum computing 아키텍처의 핵심 요소를 실제 실험으로 구현**
  - **448-qubit 시스템에서** **반복 QEC(surface code) + logical gates + teleportation + magic state + constant-entropy computing****을 통합 시연**
  - **성과 요약:**

    - **d=5 surface code****에서** **below-threshold behavior** **실험적 입증**
    - **➜ error per round** **2.14× reduction vs d=3**
    - **atom loss detection + machine learning decoding** **활용하여 performance 향상**
    - **transversal gate vs lattice surgery** **성능 비교 → transversal이 더 robust**
    - **3D Reed-Muller 코드로 T-gate / arbitrary-angle synthesis** **실험 성공**
    - **logical teleportation으로 deep circuit 27 layer 수행**
    - **constant-entropy logical cluster state 구성**

****

**🚀 의의**

- - **단순 QEC demonstration 수준이 아니라** **완전한 FTQC 아키텍처의 구성 요소를 통합 구현**
  - **threshold crossing + resource overhead 최적화에 실제 실험적 근거 제공**
  - **논리 연산 & 오류 정정 & atom replenishment를 동시에 수행 가능**
  - **📍 즉: 실험실에서 실제 FTQC의 작동 원리와 구성 전략을 보여준 첫 사례**

**🔍 IonQ와 QuEra의 차이점**

**1️⃣ IonQ는 “물리적 fidelity 최적화가 우선”, QEC는 이후 단계**

|  |  |
| --- | --- |
| **IonQ 전략** | **설명** |
| **고충실도 물리게이트 확보(99.99% 2Q)** | 오류 자체를 최소화하고 누적되기 전에 억제 |
| **Cyclic HGP 등으로 chain loss 감지/회복** | 논리코드가 아니라 detection 중심 |
| **오버헤드가 거의 없는 QEC-lite 접근** | 현재는 full surface-code style QEC 아님 |
| **목표: logical qubit ~2026**, Helios/Tempo 경쟁 |  |

- - **👉 IonQ는 “충실도 기반 bottom-up” 접근**

****

**2️⃣ Harvard-QuEra는 “다층 오류정정 구조 그 자체의 실험 구현”이 핵심**

|  |  |
| --- | --- |
| **Harvard-QuEra 전략** | **설명** |
| **layered error correction을 실제 실험에서 구현** | 이론 수준이 아닌 실험 증명 |
| **오류 임계점(threshold)을 실제 장비에서 넘음** | QEC 레이어가 늘어날수록 성능이 상승 |
| **scale-first (3,000+ qubit) + QEC-stack-first** | fidelity보다 구조적 scaling 우선 접근 |
| **Fault-tolerant 회로 깊이를 증가시키는 실증** |  |

- - 👉 Harvard-QuEra는 **“QEC-architecture 기반 top-down”** 접근

> **IonQ는 오류정정 전에 물리 fidelity를 극한까지 높여야 실제 logical QEC가 의미가 있다는 철학**
>
> **QuEra는 물리 fidelity가 완벽하지 않아도 QEC layer stack로 임계점을 돌파하여 scaling을 증명.******

> **이건 진짜 흥미로운 관전 포인트다.**
