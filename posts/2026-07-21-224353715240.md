- - 이 발표는 2026년 7월 16일, 미 우주군 산하 Space Development Agency(SDA)가 **PWSA(Proliferated Warfighter Space Architecture)** **Tranche 1의 세 번째 발사**를 성공적으로 완료했다는 내용이다. 핵심은 단순히 위성 21기를 더 올렸다는 것이 아니라, 미국이 구축 중인 **저궤도 군사 데이터·미사일 추적 메쉬 네트워크가 본격적인 작전 체계에 가까워지고 있다**는 점이다.

**📌** **핵심 내용**

- - 이번 발사에서는 **SpaceX Falcon 9**을 이용해 **York Space Systems가 제작한 Transport Layer 위성 21기**를 반덴버그 우주군기지에서 발사했다. 이로써 현재 궤도에 올라간 **Tranche 1 위성은 총 63기**가 됐다. 위성들은 우선 초기 궤도에서 시험·점검을 거친 뒤 약 **1,000km 고도**의 목표 궤도로 상승해 실제 운용에 투입된다.
  - 이 Transport Layer는 쉽게 말하면 **우주에 구축하는 군사용 초고속 인터넷 백본**이다.
  - 센서/추적 위성 → 광학 위성간 링크(OISL) → Transport Layer 메쉬망 → 지상·공중·해상 전투부대
  - 이 구조를 통해 미사일 탐지·추적 데이터를 기존처럼 지상국을 여러 번 거쳐 전달하는 것이 아니라, **저궤도 위성끼리 레이저 통신으로 빠르게 전달**해 전투원에게 거의 실시간으로 제공하려는 것이다.
  - 주요 임무는 **보안·저지연 통신**, **BLOS(Beyond-Line-of-Sight) 전술 통신**, **첨단 미사일 경보·추적**, **시간 민감/이동 표적에 대한 BLOS targeting**이다. SDA는 이를 “optically-connected network”, 즉 **광학적으로 서로 연결된 위성 네트워크**로 설명한다.

- - 또한 **앨라배마와 노스다코타에 2개의 첨단 Space Operations Center**가 구축되고, 전 세계의 Ground Entry Point가 이를 지원한다. SDA는 2027년부터 Tranche 1의 초기 실전 능력(initial warfighting capability)을 제공할 계획이다.

**📌** **왜 중요한가**

- - 가장 중요한 표현은 SDA 국장이 말한 “continuous overwatch”다.
  - 기존 군사위성은 소수의 크고 비싼 위성에 의존하는 경우가 많아 특정 지역을 계속 관측하거나 데이터를 즉각 전달하는 데 한계가 있었다. PWSA는 수백 기의 LEO 위성을 분산 배치해 **항상 여러 위성이 전장 위를 지나가도록 하고, 탐지된 정보를 위성간 광통신으로 즉시 전달하는 구조**다.
  - 즉, **탐지 → 추적 → 데이터 전송 → 표적 정보 전달 → 대응**이라는 전체 kill chain의 시간을 크게 줄이는 것이 핵심이다.
  - SDA는 이것이 적의 **first-mover advantage**, 즉 먼저 미사일을 발사하거나 이동식 표적을 움직여 선제적으로 얻는 시간적 우위를 약화시킬 수 있다고 설명한다.

**📌** **앞으로 더 중요한 부분**

- - Tranche 1은 사실 **첫 실전 단계**에 가깝다. 이후 Tranche 2는 약 **270기의 Transport/Tracking 위성**으로 확대돼 Tranche 1의 기능을 전 지구적으로 더 지속적으로 제공하고, 추가적인 tactical data link 기능까지 확장할 계획이다.
  - 특히 이번 발표에서 주목할 부분은 SDA가 “multi-vendor ecosystem”을 명시적으로 강조했다는 것이다. 한 업체가 전체 시스템을 독점하는 것이 아니라 위성, 광통신 단말, 네트워크, 지상국, 센서 등을 여러 업체가 공급하도록 만들어 **상호운용성과 공급망 복원력**을 확보하는 구조다.
  - 이는 최근 우리가 살펴본 **SDA HALO와 Capella/IonQ** 관점에서도 의미가 있다. 현재 Tranche 1은 이미 계약·제작된 기존 PWSA 아키텍처를 배치하는 단계이고, HALO는 그보다 미래의 **차세대 전술 위성통신·상업 위성 기술을 빠르게 실증하여 향후 PWSA capability에 연결할 가능성을 시험하는 경로**에 가깝다. 따라서 이번 발사를 “IonQ/Capella가 직접 참여한 발사”로 보면 안 되지만, **Capella가 진입하려는 SDA 생태계가 실제 대규모 운용 네트워크로 빠르게 확장되고 있다는 점**에서는 중요한 배경이다.
  - 한 문장으로 요약하면, **미국은 이제 PWSA를 ‘실험용 위성 몇 기’ 단계에서 벗어나 수백 기의 레이저 연결 저궤도 위성으로 구성된 실전형 군사 인터넷으로 전환하고 있으며, 이번 3차 발사로 Tranche 1 위성 63기가 궤도에 올라 그 전환이 본격화됐다는 발표**다.

**✅ Tranche 0 → 1 → 2 → 3 로드맵**

|  |  |  |  |
| --- | --- | --- | --- |
| **Tranche** | **단계의 의미** | **주요 규모** | **핵심 기능** |
| **T0** | 기술 실증 / Warfighter Immersion | 28기 | 광통신 mesh, Link 16, 미사일 추적 가능성 검증 |
| **T1** | Initial Warfighting Capability | 154기 | 실제 군사용 regional persistence, sensor-to-shooter |

| **T3** | Sustained / Advanced Capability | Transport 약 140 계획 + Tracking 대폭 확대 | 글로벌 지속 미사일방어, 고급 TDL, PNT, autonomy |

- - SDA의 철학을 아주 단순화하면:

    - T0: “이 구조가 실제로 되는가?”
    - T1: “실제 전투원이 쓸 수 있는가?”
    - T2: “전 세계에서 지속적으로 쓸 수 있는가?”
    - T3: “미사일 방어와 kill chain까지 거의 실시간으로 완성할 수 있는가?”
  - 이다.

**📌 Tranche 0 — Proof of Concept**

- - T0는 **20 Transport + 8 Tracking = 28기**로 구성됐다.
  - Transport는:

    - **York Space Systems: 10기**
    - **Lockheed Martin: 10기**
  - Tracking은:

    - **L3Harris: 4기**
    - **SpaceX: 4기**
  - 였다. T0 위성들은 실제 광통신 OCT를 이용해 위성끼리 연결하고, Link 16 우주 연결, 저지연 데이터 전송, 미사일 추적 등을 실증하는 “Warfighter Immersion” 단계였다. Transport와 Tracking 위성에는 각각 기본적으로 2개의 OCT가 사용된 구성도 있었다.
  - 여기서 중요한 것은 **York가 당시 거의 신생 업체였는데 SDA가 과감하게 prime으로 넣었다**는 점이다.
  - 이것은 나중에 Capella를 볼 때 매우 중요하다.
  - SDA는 처음부터 Lockheed, Northrop 같은 전통 방산업체만 쓰지 않고

    - → 신생 commercial space 기업을 prototype에서 검증
    - → 검증되면 다음 Tranche에서 대규모 prime으로 키운다.
  - 는 전략을 사용했다.
  - 실제로 York가 그 대표적인 성공 사례다.

**📌 Tranche 3 — 이제 “미사일 방어망”에 가까워진다**

- - - 여기서는 2025년 초 계획과 **2026년 현재 실제 계약이 상당히 달라졌다는 점**이 중요하다.
  - **T3 Transport**

    - SDA가 공개한 기본 계획은 **약 140기**이며 세 종류로 나뉜다.
  - **Lambda**

    - Advanced Global Link 16
  - **Upsilon**

    - 약 **40기**
    - 기존·legacy global tactical SATCOM 지원.
  - **Sigma**

    - 약 **20기**
    - S-band tactical SATCOM.
  - SDA는 Upsilon 40기를 10기씩 4개 orbital plane으로 계획했고, 서로 다른 2개 업체에 배정하는 구조를 검토했다. 특히 Upsilon은 OCT를 통해 자기 plane, 다른 plane뿐 아니라 **“Transport Layer 외부의 compatible satellites”와도 optical crosslink**할 수 있도록 요구했다.
  - 이 문장이 나중에 **Capella + Skyloom**과 매우 중요하게 연결된다.
  - 현재 확인한 공개 SDA 자료 기준으로는 **T3 Transport의 Lambda/Upsilon/Sigma 전체 production prime 최종 수주 결과는 아직 명확하게 공개된 상태로 확인되지 않는다.**

**✅ Capella가 이미 첫 번째 중요한 문을 통과했다**

    - mission-specific tactical waveform
    - adaptive beamforming
    - secure ground-to-space integration
  - 을 시험하며, 시연은 **2027년 11월까지** 완료할 계획이다.

**📌** **이것은 SAR 임무가 아니다.**

  - 즉 지금 당장 **“Capella가 HALO에서 SAR + QKD를 PWSA에 넣는다”**라고 말하면 틀린다.
  - 현재 확정 계약은 **RF tactical communication demonstration**이다.

**✅ 그런데 이것이 왜 Capella에게 훨씬 큰 의미가 있나?**

- - SDA 계약 책임자가 HALO를 설명하면서 매우 중요한 말을 했다.
  - HALO를 통해 신규 업체의 **satellite bus를 향후 PWSA Tranche에 활용하고 싶다**는 것이다.
  - SDA는 궁극적으로 commoditized satellite bus 하는 방식으로 가고 싶다고 밝혔다.
  - 즉 Capella의 첫 번째 진입경로는 사실 SAR보다도:

    - **경로 A — PWSA 위성 Bus / Tactical Communications 업체**
  - 이다.

|  |
| --- |
| **Capella HALO**  **2 satellites**  **RF/TACSATCOM demo**  **↓**  **SDA interoperability 검증**  **↓**  **SDA flight heritage 확보**  **↓**  **Future Tranche 경쟁 자격/신뢰**  **↓**  **Transport Layer bus / variant** |

- - York가 걸었던 길과 구조적으로 매우 유사하다.
  - 물론 Capella가 York처럼 40~60기를 받는다는 보장은 전혀 없다.
  - 하지만 **HALO 프로그램 자체가 바로 그런 신규 prime 확대를 목적으로 만들어진 것**은 SDA가 직접 밝힌 사실이다.

**✅ IonQ는 다른 HALO 업체와 조금 다르다**

- - Capella 단독이었다면 **satellite bus + SAR + RF communications**업체다.
  - 그런데 IonQ 체계에서 보면 잠재적으로:

    - Capella = Spacecraft + SAR sensing
    - Skyloom = SDA-compatible optical network interface
    - IonQ/IDQ = quantum-secure networking
  - 이 된다.
  - 다만 이 전체 그림은 **아직 SDA가 IonQ에 통합 시스템으로 발주한 계약이 아니다.**
  - 현재 확정된 것은 각각 따로다.

    - Capella → **HALO Europa RF tactical comm prototype**
    - Skyloom → **기존 SDA OCT 대량 납품 실적**
    - IonQ → **Capella를 이용한 space-based QKD 계획**
  - 이 세 점을 연결한 것이 **전략적 가능성에 대한 분석**이다.

**📌** **투자 관점에서 가장 주목할 다음 신호**

  - 특히 앞으로

    - **① T3 Transport 최종 업체 선정**
    - **② Capella Europa 위성의 bus/OCT 구성 공개**
    - **③ Skyloom의 추가 SDA OCT 계약**
    - **④ Capella SAR를 Custody/PWSA mesh에 연결하는 실증**
    - **⑤ HALO 이후 production transition award**
    - **⑥ SDA가 QKD/quantum networking**
  - **을 Futures·STEC에서 실제 실증하기 시작하는지**를 보면 된다.
  - 결국 **이번 Skyloom OCT 88대와 Capella HALO를 따로 볼 것이 아니라**, 하나는 이미 PWSA의 **광통신 공급망에 들어가 있고**, 다른 하나는 지금 PWSA의 **차세대 위성 공급망으로 진입 시험을 받고 있다**고 보는 것이 가장 흥미로운 해석이다.
