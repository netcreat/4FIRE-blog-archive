**✅****용어 정리**

**💡캐비티(cavity)**

- **광자-스핀 상호작용을 강화**하기 위해 쓰는 공진기
- SiV 같은 광원/검출기와 결합해 광자의 방출 방향·효율·수집률을 높임
- **나노포토닉 캐비티**: 반도체 칩 위에 만든 아주 작은 광 공진 구조
- 이 안에서 광자가 여러 번 왕복 → 스핀과 광자의 결합 세기 증가 → 변환 효율↑

**💡시간-빈 인코딩(time-bin encoding)**

- 광자의 양자 상태를 **도착 시간**으로 표현하는 방법
- 예: **|early⟩**, **|late⟩** 두 개의 시간 슬롯을 이용해 0/1 또는 그 중첩 상태 저장
- 장점: 광섬유 전송에서 편광보다 안정적 → 장거리 전송에 유리
- 바륨 이온·SiV 실험에서도 많이 사용

**💡UHV (Ultra High Vacuum)**

- **초고진공**, 10⁻⁹ mbar 이하의 압력 상태
- 바륨 이온 같은 자유 이온을 트랩하려면, 주변 기체와 충돌하지 않도록 UHV 환경 필요

**💡파이버 또는 집적 포토닉스(웨이브가이드, 그레이팅 커플러)**

- **파이버**: 일반 광섬유(SMF, PMF 등), QPU ↔ 다른 장치 간 광자 전송
- **집적 포토닉스**: 반도체 칩 위에 만든 광 경로(웨이브가이드)
- **그레이팅 커플러**: 파이버에서 온 빛을 웨이브가이드로, 또는 그 반대로 넣어주는 격자형 구조

**💡헤럴드 얽힘(heralded entanglement)**

- **두 광자 검출 이벤트가 “이온 간 얽힘 성공”을 알려주는 방식**
- 예: QPU A와 QPU B가 각각 광자 방출 → 중간 빔스플리터에서 간섭 → 두 검출기에서 특정 패턴의 클릭이 나면 → 두 QPU 이온이 얽힘 상태임을 “헤럴드”(알려줌)

**💡편광**

- **빛의 전기장 진동 방향**을 의미

  - 빛은 전자기파이므로, 전기장이 어떤 방향으로 진동하는지로 상태를 표현할 수 있다.
  - 흔히 쓰는 편광 상태:

    - **수평(H), 수직(V)**
    - **+45°, -45°**
    - **원편광(L, R)**: 전기장이 시계·반시계 방향으로 회전
  - 양자통신에서는 편광을 **큐비트 상태**로 사용하기도 한다.
  - 예: |H⟩를 0, |V⟩를 1로, 또는 이 둘의 중첩으로 표현.

**✅****양자 텔레포테이션 개요**

- 바륨 이온 스핀 상태를 SiV 스핀(또는 다른 QPU)으로 “직접” 옮기기는 물리적으로 어렵다.
- 서로 다른 물리적 시스템(바륨 이온 ↔ SiV)은 같은 트랩 안에 있지 않음 → 직접 게이트 불가능
- 광자를 **중간 매개체**로 써야 함
- 이때 쓰는 표준 절차가 양자 텔레포테이션(quantum teleportation)이다.

****

**💡****텔레포테이션이란?**

- **정의**: 두 시스템이 **이미 얽힘 상태**를 공유하고 있다면, 한쪽의 상태를 고전 정보(비트 2개)와 얽힘을 이용해 다른 쪽으로 **완전히 복사 없이 전송**하는 프로토콜.
- **과정**:

  - A(바륨 이온)와 B(SiV 또는 다른 QPU)가 얽힘을 공유한다.
  - A에서 데이터 이온과 얽힘 이온에 Bell 측정을 수행한다.
  - 측정 결과(2bit)를 B로 전송한다.
  - B가 Pauli 보정(X/Z 연산)을 적용하여, A의 데이터 상태를 그대로 재현한다.

> **⚠️ “복사”가 아니라 “이전”이다. A의 원래 상태는 사라지고, B에만 남는다.**

**💡****텔레포테이션이 어려운 이유**

- **얽힘 채널 준비**

  - 두 커뮤니케이션 이온 사이에 **heralded entanglement**를 만들어야 함
  - 이미 성공해도 확률적이고 재시도가 필요 (효율·속도 문제)
- **데이터 이온 → 광자 매핑**

  - 데이터 이온의 양자 상태를 커뮤니케이션 이온(광자와 얽힌 상태)으로 이전
  - 즉, **이온 내부의 스핀 상태를 광자에 “옮기는” 연산**이 필요
  - 이때 광자 모드(편광·시간빈 등)가 스핀 상태를 정확히 반영해야 함

**💡****구체적으로 문제되는 부분**

- **광자-스핀 결합 세기** → 광자를 충분히 높은 확률로 수집해야 함 (고NA 렌즈, 캐비티 필요)
- **위상·편광 안정성** → 광자 모드가 얽힘 품질에 직결됨
- **광자 손실** → 손실이 커지면 얽힘 성공률 급락 → 재시도 횟수 급증
- **코히런스 시간** → 얽힘 성공 대기 시간 동안 데이터 이온이 상태를 유지해야 함
- **파장 변환** → 이온에서 나온 광자를 통신 파장으로 바꿀 때 양자 상태가 훼손되지 않아야 함

> **메타안정 상태 → 레이저 여기 → 광자 방출)은 광자 자체를 만드는 과정은 맞지만, 텔레포테이션이나 포토닉 인터커넥트에서는 “광자를 만든다” 이상의 절차가 필요하다.******

**💡****단순 방출 vs 텔레포테이션에서 필요한 방출**

- **단순 방출**

  - 메타안정 상태의 이온에 레이저를 쏘면 여기 상태로 올라갔다가 기저 상태로 떨어지면서 광자 방출
  - 광자 자체만 생성 → 여기엔 양자 정보가 없음
  - 말 그대로 “빛을 켠” 것뿐
- **텔레포테이션용 방출**

  - 광자에 **이온 스핀 상태의 양자 정보**(0/1 또는 그 중첩)를 정확히 실어야 함
  - 이 과정에서 **이온 상태와 광자가 얽힘** 상태가 되어야 함
  - 그냥 빛만 나오면 안 되고, 그 빛의 **편광·위상·시간빈**이 이온 상태에 따라 달라야 함

**💡****왜 하이퍼파인 제어가 중요하나?**

- 바륨 이온 같은 경우 하이퍼파인 준위를 이용하면,

  - **|↑⟩** 상태일 땐 레이저에 반응해서 광자 방출,
  - **|↓⟩** 상태일 땐 반응하지 않도록 만들 수 있음.
- 이렇게 해서 **광자 유무** 또는 **방출 시간**을 큐비트 상태와 결부시켜 얽힘 생성 가능.

**💡****텔레포테이션에 필요한 추가 절차**

1. **이온-광자 얽힘 생성**

   - 바륨 이온의 하이퍼파인 상태를 광자의 시간빈 또는 편광 상태에 매핑한다.
   - 493 nm, 650/614 nm 전이를 사용하며, 고NA 렌즈 또는 캐비티로 광자를 수집한다.
2. **양쪽 QPU에서 생성한 광자를 간섭**

   - 두 QPU에서 생성된 광자를 50:50 빔스플리터에서 간섭시킨다.
   - 단일광자 검출기(APD 또는 SNSPD)에서 특정 클릭 패턴이 감지되면 얽힘이 성공한다.
3. 상태 전송

   - 검출 이벤트(헤럴드)로 송신 QPU에서 데이터 이온과 커뮤니케이션 이온에 Bell 측정을 수행한다.
   - 측정 결과를 수신 QPU로 보내고, Pauli 보정을 적용하여 데이터 상태를 재현한다.
   - 필요 시 SWAP 게이트로 데이터 이온과 커뮤니케이션 이온의 위치를 교환한다.

**✅****바륨 이온 QPU 간 포토닉 인터커넥트를 통한 상태 이전 절차 및 구현 방식**

**개요**

- 포토닉 인터커넥트는 서로 다른 타일(QPU 모듈) 간에 양자 상태를 전송하는 핵심 기술이다.
- 각 타일에는 **데이터 이온**(계산 전용)과 **커뮤니케이션 이온**(광자 인터페이스 전담)이 배치된다.
- 커뮤니케이션 이온끼리 원격 얽힘을 생성하고, 이를 이용해 데이터 이온의 상태를 텔레포테이션으로 전달한다

**💡****표준 절차 (양자 텔레포테이션)**

1. **이온–광자 얽힘 생성**

   - 바륨 이온의 하이퍼파인(전자·핵 스핀) 상태를 **라만(또는 공진) 여기**로 광자에 매핑
   - 흔한 인코딩: **시간빈(early/late)** 또는 **편광**
   - 방출 파장: Ba⁺의 고유 전이(예: 493 nm, 650/614 nm).
   - 광 수집: **고NA 렌즈** 또는 **마이크로캐비티**→ **파이버/웨이브가이드**로 추출
2. **두 광자 간섭(HOM) + 검출로 이온–이온 얽힘 ‘헤럴드’**

   - 두 타일에서 온 광자를 **50:50 빔스플리터**에서 간섭**(HOM-Hong–Ou–Mandel 간섭**)

     - 두 광자가 완전히 동일하면(파장, 편광, 시간, 위상 모두 일치), 50:50 빔스플리터에 동시에 들어갔을 때 나타나는 **양자 간섭 현상**
     - **두 QPU(또는 타일)에서 각각 생성한 광자를** **서로 구별 불가능하게** **만들어서 빔스플리터에 보낸다.**
     - **HOM 간섭이 제대로 일어나면, 단일광자 검출기(APD/SNSPD) 2개에서 특정 단일광자 검출 패턴이 이온–이온 얽힘 성공을 알려주는 “****헤럴드 신호****”가 된다.**
     - **HOM 간섭은 광자 기반 원격 얽힘 생성의 핵심 조건****이다.**
3. **상태 이전(텔레포테이션)**

   - 타일 A의 **데이터 이온**과 **커뮤니케이션 이온**에 **Bell 측정**(내부 게이트: MW/Raman)
   - 측정 결과(2bit)와 3)의 헤럴드 정보에 따라
   - 타일 B의 커뮤니케이션 이온에 **파울리 보정**(X/Z)만 적용 → **데이터 상태가 B로 전송 완료**
   - 필요하면 B의 커뮤니케이션 이온 ↔ 데이터 이온 사이에 **SWAP**으로 위치 바꿈

**✅****포토닉 인터커텍팅 구현 방식**

**💡****바륨 이온 직결 방식 (SiV 없음)**

- **구조**: 바륨 이온이 직접 광자 방출
- **옵션**: 장거리 전송 시 QFC로 통신 파장(1550 nm) 변환
- **장점**: 구조 단순, 변환기 불필요(내부 링크)
- **한계**:

  - 광자 수집 효율 낮음(수~수십 %)
  - 493/650 nm는 통신 파장이 아니므로 장거리 시 손실 큼
  - 대형 광학계 필요, 집적성 낮음
  - 얽힘 시도 속도가 수집 효율 × 검출 효율에 비례 → 효율 낮으면 속도 저하

**💡****바륨 이온 – SiV 하이브리드 방식**

- **목적**: 고효율 수집·통신파장 직접 방출·칩 집적성 확보
- **구조**: 바륨 이온 ↔ 광자 ↔ SiV ↔ (광자, 통신 파장) ↔ QPU B
- **장점**:

  - SiV 나노포토닉 캐비티로 광자 수집 효율 80% 이상
  - Er³⁺ 등 특정 컬러센터 사용 시 1550 nm 직접 방출 가능(QFC 불필요)
  - 반도체 공정으로 대규모 집적 가능
  - SiV 핵 스핀(²⁹Si) 장기 메모리 활용 가능
  - 1.5~4.3 K에서 동작 가능 → 냉각 부담 완화
- **한계**: 구조 복잡, 연구 단계

**💡****구간별 장비 구성**

|  |  |  |
| --- | --- | --- |
| **구간** | **장비** | **역할** |
| 이온–광자 얽힘 | 493/650 nm 레이저, AOM/EOM, 고NA 렌즈, 필터 | 스핀↔광자 매핑 |
| (옵션) SiV 매핑 | SiV 나노캐비티, 737 nm 레이저, MW/RF 제어 | 광자–스핀 인터페이스 |
| 파장 변환 | PPLN/PPKTP 모듈, 펌프 레이저, 필터 | 493→1550 nm 변환 |
| 전송 | 단일 모드 광섬유, 편광 보정, GPSDO | 신호 손실 최소화 |
| 간섭·검출 | 50:50 빔스플리터, SNSPD | 얽힘 생성 판정 |
| 상태 전달 | QPU 게이트, Bell 회로, 고전 채널 | 텔레포테이션 |

**💡****핵심 포인트**

- **QFC**는 장거리 네트워킹 필수 요소 (손실률 대폭 감소)
- 광자 수집·검출 효율이 얽힘 성공률을 결정
- **SNSPD**는 1550 nm 검출의 사실상 표준
- SiV 하이브리드는 미래형 확장 옵션 (고효율·고집적 가능)

**✅****광자–스핀 인터페이스**

**💡****변환에 사용되는 물질과 구조**

- **물질**: 다이아몬드 내의 **29SiV(실리콘-공공 결함)**

  - 전자 스핀(communication qubit)
  - 29Si 핵 스핀(memory qubit)
  - 강한 잔류 strain이 걸려 있어 전자 스핀-광자 결합 강도가 큼.
- **광학 구조**: 나노포토닉 캐비티에 SiV 삽입

  - 파장: 737 nm 부근의 광학 전이
  - 캐비티 결합도(cooperativity) C ≈ 1.6 → 광자 방출/흡수 효율 향상
- **자기장**: 외부 자기장으로 스핀 준위 분리 (비축퇴 주파수 생성)
- **전자/핵 제어 장비**:

  - 마이크로파(MW) 전송 라인 → 전자 스핀 제어
  - RF 전송 라인 → 핵 스핀 제어
- **광학 장비**:

  - 공진 레이저 → 특정 전이 여기
  - 전기광학 변조기(EOM) → 시간빈(time-bin) 및 위상 변조
  - 단일광자 검출기(APD/SNSPD) → 방출 광자 검출
  - 위상 기반 판독을 위한 위상 측정(optical homodyne/beat measurement)

**💡****광자 ↔ 스핀(이온) 변환 과정**

- **광자 → 스핀**

  - **광학 여기(Optical excitation)**

    - 737 nm 레이저를 SiV의 특정 전이(스핀 상태와 결합된 준위)에 공진시키거나 라만(Raman) 방식으로 여기.
  - **광자의 양자정보 매핑**

    - 입사 광자의 편광·시간빈(time-bin) 정보가 전자 스핀의 초위상(superposition) 상태로 전이됨.
    - 필요한 경우 전자 → 핵 스핀으로 상태를 SWAP하여 장기 저장.
- **스핀 → 광자**

  - **스핀 상태 선택적 여기**

    - 전자 스핀 상태 |↓ₑ⟩ 또는 |↑ₑ⟩ 중 하나만 공진하는 광학 전이를 선택.
  - **광자 방출**

    - 여기된 상태에서 자발 방출 → 방출 광자의 편광·위상·시간빈이 스핀 상태와 얽힘.
  - **검출 및 전송**

    - 방출 광자를 단일광자 검출기로 측정하거나, 광섬유를 통해 원격 노드로 전송.

**💡****변환을 가능하게 하는 핵심 메커니즘**

- **강한 광학-스핀 결합**: SiV의 전자 스핀은 특정 광학 전이와 1:1로 대응 → 스핀 상태에 따라 광자의 반사율·위상이 달라짐.
- **캐비티 보강(Cavity enhancement)**: 광자–스핀 상호작용 효율을 높이고 단일광자 수집 확률을 극대화.
- **전자 스핀 ↔ 광자 (시간빈(time-bin) 인코딩**)

  - 이 실험에서는 광자의 정보가 “early”와 “late” 방출 시점에 인코딩되어, 스핀과 안정적으로 얽힘 생성.
  - Early 펄스와 Late 펄스 시점에 따라 방출 여부가 달라짐.
  - 이렇게 해서 전자 스핀 상태와 광자의 도착 시각(early/late)이 얽힘.

- **핵 스핀**  ↔ **광자 (PHONE 게이트)**:

  - 전자 스핀을 매개로 핵 스핀과 광자를 직접 얽히게 하는 새로운 게이트.
  - 핵 스핀 ↔ 전자 스핀 CNOT 시퀀스
  - 전자 스핀 ↔ 광자 얽힘 → 결과적으로 핵 스핀과 광자가 얽힘.

- **매핑의 의미**

  - 여기서 매핑(mapping)은 **스핀의 양자 상태 정보를 광자의 양자 상태(시간빈, 편광, 위상 등)에 대응****시켜 전송 가능하게 만드는 것**.
  - 전자 스핀의 상태를 광자에 옮긴 뒤, 필요하면 전자 스핀을 핵 스핀으로 SWAP해 보관.
  - 이 매핑이 “얽힘”을 통해 이루어진다. → 얽힘 상태를 만들고, 그 광자를 멀리 보내면 원격 노드와 스핀이 얽혀 있음.

**✅****광자 검출기**

|  |  |  |
| --- | --- | --- |
| **항목** | **APD (Avalanche Photodiode)** | **SNSPD (Superconducting Nanowire Single-Photon Detector)** |
| **원리** | 반도체 PN 접합에 강한 전기장을 걸어, 광자가 전자-정공 쌍을 만들면 전자들이 연쇄적으로 증폭(Avalanche) | 극저온에서 초전도 나노와이어에 전류를 흐르게 하다가, 광자가 와이어를 가열 → 초전도 파괴 → 전기 펄스 발생 |
| **작동 온도** | 실온 ~ 약간의 냉각 (수십 ℃ 이하) | 극저온 필요 (수 K ~ mK, 보통 2.5~4 K) |
| **검출 효율** | ~50–70% (파장에 따라 다름) | 90% 이상 가능 |
| **다크 카운트(잡음)** | 비교적 높음 (kHz 수준) | 매우 낮음 (Hz 이하 가능) |
| **응답 속도** | 빠름 (ns) | 매우 빠름 (ps~ns) |
| **파장 대응** | 가시광–근적외 일부 대역 최적 | 광범위 (UV ~ 통신 대역 1550 nm 이상) |
| **장점** | 실온 동작 가능, 소형, 비용 저렴 | 고효율, 초저잡음, 고속 |
| **단점** | 잡음 높음, 효율 낮음, 일부 파장 제한 | 극저온 장비 필요, 설치·운영 복잡, 비용 높음 |

- SNSPD는 초전도 재료(예: NbN, NbTiN, WSi, MoSi)로 만든 나노와이어를 사용한다.
- 동작 온도는 재료의 임계온도(Tc)보다 낮아야 하며, 일반적으로 **0.8–4.2 K** 범위에서 사용된다.
- **많은 상용 SNSPD**들은 액체 헬륨 온도(4.2 K)에서 설계·제작되어, 딜루션 냉동기 없이도 구동 가능.
- **검출 효율**: 최저온(≈0.8 K)에서의 최고 성능 대비 조금 떨어질 수 있음. → 4 K에서도 80–90% 효율 달성 가능 (파장·재료 최적화 시).
- **다크 카운트(잡음)**: 4 K에서 열잡음이 약간 증가하지만 여전히 APD보다 훨씬 낮음(Hz 이하~수십 Hz).
- **QPU 내부에 집적 가능**

  - **SNSPD는 초전도 나노와이어**를 만들기 때문에, 반도체/포토닉 칩 위에 **나노패터닝**으로 직접 형성 가능.

    - 나노패터닝 - 나노미터 크기의 구조를 표면에 새겨 그레이팅 커플러나 다이아몬드 나노포토닉 캐비티 구현
  - 이미 집적 포토닉 회로(실리콘 포토닉스, Si₃N₄ 웨이브가이드)에 SNSPD를 얹어, **웨이브가이드에서 오는 광자를 바로 검출**하는 구조가 구현됨.

    - PsiQuantum 발표 <https://blog.naver.com/4-fire/223949172652>
    - MIT, NIST, JPL, KIST 등에서 **웨이브가이드 통합형 SNSPD**를 발표.
  - 장점

    - **광 손실 최소화 :** 외부로 빼서 검출하는 대신, QPU 내부 포토닉 라인에서 바로 검출 가능.
    - **패키징 단순화 :** 광섬유 정렬·연결부 없이 바로 온칩에서 수신.
    - **대규모 다채널 :** 다수의 SNSPD를 병렬로 만들어, 여러 출력 채널을 동시에 모니터링.
  - **제약 사항**

    - **극저온 환경 필수**: SNSPD는 보통 0.8–4 K 동작 → QPU가 같은 온도 범위여야 함.

      - → SiV(1.5–4.3 K)나 초전도 QPU에는 적합, 실온 QPU에는 불가. 옥스포드 가능
    - **재질 호환성**: SNSPD 제작에 필요한 초전도 재료가 QPU 제작 공정과 맞아야 함.
    - **열·EMI 관리**: 검출 이벤트에서 생기는 전기 신호 처리와 발열이 QPU 동작에 영향을 주지 않도록 설계 필요.
    - **광학 정렬**: 웨이브가이드나 캐비티에서 나오는 광을 정확히 나노와이어로 유도해야 함.

**✅****광자 방출기**

**💡****방출 과정**

- **방출 주체**: 다이아몬드 나노포토닉 캐비티 안의 **SiV 전자 스핀**
- **방법**:

  - 기저 상태(ground state) : 전자스핀 상태(|↑⟩, |↓⟩)가 포함
  - 여기 상태(excited state) : 737 nm 레이저로 SiV 전자 스핀을 특정 여기 상태로 올림.
  - 여기 상태가 바닥 상태로 내려오면서 **단일 광자 방출**.
  - 이 광자가 스핀 상태와 얽혀 있음(편광·시간빈 정보 포함).
- **수집 장치**:

  - 나노포토닉 캐비티 → 파이버 결합 → 광학 경로(필터·빔스플리터 등)
  - 마지막에 SNSPD로 전달해 검출.
- **여기 과정 (광자 방출 전 단계)**

  - **공진 레이저 주입**

    - 737 nm 레이저를 SiV의 광학 전이 주파수와 정확히 맞춤(공진 조건).
    - 이때 레이저가 전자 스핀의 특정 상태와 결합된 전이만 여기할 수 있게 조절.
  - **전자 여기**

    - 스핀이 바닥 상태(|↓⟩)에 있다면 레이저에 의해 여기 상태로 올라감.
    - |↑⟩ 상태라면 공진하지 않아 여기가 안 됨 → 상태 선택적 여기 가능
- **방출 과정**

  - 여기 상태의 전자는 자연스럽게 바닥 상태로 내려오면서 **단일 광자(737 nm)를 방출**.
  - 이 광자의 시간, 위상, 편광은 여기 직전의 스핀 상태와 얽힘(entanglement).
- **왜 이렇게 하는가**

  - SiV는 737 nm에서 **스핀-광자 변환**이 직접 가능.
  - 나노포토닉 캐비티가 있어서, 방출된 광자가 **거의 전부 파이버/광학 경로로 수집**.
  - 이 방식 덕분에, 스핀 ↔ 광자 양방향 변환이 가능하고, 멀리 떨어진 노드와 얽힘 공유 가능

**💡****동작 환경**

**극저온(1.5–4.3 K)에서만 동작 가능**하고, 실온에서는 현재 기술로 동일한 성능을 낼 수 없다.

|  |  |  |
| --- | --- | --- |
| **항목** | **실온(300 K)** | **저온(1.5–4.3 K)** |
| 전자 스핀 코히런스 | μs 이하 (매우 짧음) | μs~ms 유지 가능 |
| 광자-스핀 얽힘 | 불가능/매우 낮은 충실도 | 가능 (F≈0.9 수준) |
| 핵 스핀 메모리 | 억 단위 짧아짐 | 최대 2초 이상 |
| 사용 가능성 | 연구용 일부 실험만 가능 | 양자 네트워크 노드로 실용 가능 |

**💡****정리**

- **방출**: SiV 컬러센터 + 737 nm 여기 레이저
- **검출**: SNSPD (4 K에서 가능)
- **중간 경로**: 캐비티 → 파이버 → 필터 → 검출기

**💡****“방출”과 “검출” 사이의 진짜 난이도**

- **방출기**: QPU 내 커뮤니케이션 큐비트가 광자 방출 → 비교적 확립된 기술
- **검출기**: SNSPD/APD는 범용 → 설치만 하면 됨
- **문제는 광자가 두 타일 사이에서 성공적으로 간섭하게 만드는 것**

  - 경로 길이(위상) 안정화
  - 편광 정합
  - 스펙트럼 필터링
  - 잡음 억제 및 손실 최소화

이 영역이 바로 LightSynQ가 파고드는 부분

**✅****맺음말**

양자 텔레포테이션이 어려운 이유는 단순히 이온에서 빛을 방출하는 것이 아니라, **이온 내부의 스핀 상태를 광자에 정확히 매핑하는 연산**이 필요하기 때문이다.

이 과정에서 광자의 편광·위상·시간빈 정보가 손실 없이 옮겨져야 하며, 이를 위해 **HOM 간섭을 통한 헤럴드 얽힘 생성**이 필수적이다.

이를 구현하려면 다음 여섯 가지 기술 과제가 병행돼야 한다.

1. 1. **HOM 간섭 품질** 확보
   2. **광원 스펙트럼 정합**
   3. **Bell 상태 측정(BSM) 충실도**
   4. **위상·타이밍 안정화**
   5. **파장 변환(QFC)** 성능 향상 - 장거리 전송시 해당(QPU내부에서 해당사항 없음)
   6. **광자 수집 효율 및 전송 손실 최소화**- 장거리 전송시 해당(QPU내부에서 해당사항 없음)

이 과제들을 해결하려면 **고성능 광자 방출기와 단일광자 검출기**가 필요한데, 둘 모두 약 4K 저온 환경에서 최적 성능을 발휘한다. 이는 **옥스포드 아이오닉스가 사용하는 Cryo 조건**과도 일치하므로, QPU 내부에의 집적 가능성이 높다고 판단된다.

특히 IonQ의 수석 고문인 **크리스토퍼 먼로**는 이들 과제 중 **HOM 간섭, 스펙트럼 정합, BSM 충실도, 위상·타이밍 안정화**에서 실험 프로토콜, 시스템 설계 최적화, 통합 전략 면에서 강력한 기여가 가능하다.

**파장 변환**과 **광자 수집 효율** 역시 사양 선정과 시스템 통합 측면에서 조언할 수 있지만, 소자 제작은 Lightsynq·IDQ·Qubitekk 등 파트너사의 영역이다.

포토닉 인터커넥트를 위한 기술적 과제를 검토한 결과, **아이온큐 내부에서도 상당 부분 자체 해결이 가능**해 보인다.

남은 것은 **기술 성숙과 통합 과정**—그리고 **시간을 기다리는 일**뿐이다.
