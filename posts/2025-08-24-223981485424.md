**💡****산디아 국립 연구소(Sandia National Laboratories)의 역할: 이온 트랩 "파운드리" + 자체 칩**

- - 산디아 국립 연구소는 미국 DOE 산하 연구소로, 특히 **MESA(Microsystems Engineering, Science and Applications)** 라인에서
  - **MEMS 기반 이온 트랩 칩**을 제작하는 세계적인 시설을 운영하고 있다.
  - 주로 실험 및 연구용 칩 생산 및 납품을 하고 있다.

|  |  |
| --- | --- |
| **항목** | **설명** |
| **설계 모델** | MOOSE, HOA2, HOA3 등 QCCD형 이온 트랩 표준 설계 |
| **제조 공정** | 8" 웨이퍼급 CMOS 호환 MEMS 가공 |
| **대표 고객** | Quantinuum, Honeywell, 일부 DARPA QSCOUT 프로그램 |
| **특징** | 수율 높음 + 표준화 강점 |

- - **산디아 국립 연구소는 이온 트랩 칩의 대표적인 파운드리 역할**을 하고, DARPA, Quantinuum, IonQ 초기 연구실 등에도 칩을 공급함.
  - 실제로 옥스포드 대학교에서 실험에 사용되었던 HOA2와 Phoenix 모두 산디아 국립 연구소에서 제작된 이온트랩이다.

**💡****옥스포드 아이오닉스(Oxford Ionics)의 접근**

- - 옥스포드는 산디아와는 다르게, **직접 칩을 설계하고 독자 제조 파트너를 활용**했다.
  - 옥스포드 QPU는 **마이크로파 전극 통합(WISE)**이라는 특수 설계와 마이크로파 기반 제어가 핵심 → 산디아 시리즈와 다름
  - **바륨(Ba****+****) 이온**을 사용하고, 포토닉 인터커넥트를 위해 전극 패턴과 레이아웃을 별도로 최적화
  - 제조는 주로 유럽계 파운드리(Infineon, Fraunhofer 등)와 협력할 가능성이 높음

    - 실제 Chris Ballance 인터뷰에서 Infineon과 협력 경험을 언급함
    - Infineon은 Quantinuum과 칩 생산 관련 협약을 맺고 있다.

**💡****IonQ의 접근**

- - IonQ도 초창기(2016~2018년)에는 산디아 칩을 일부 썼지만,
  - **현재는 거의 완전한 자체 칩 설계 및 생산을 한다.**

    - 바륨 이온(Ba+) 트랩 설계 → 옥스포드와 비슷하지만 마이크로파 대신 레이저 기반 제어
    - 2024년 imec과 협력하여 포토닉 집적 회로 (PIC)의 기술을 개발을 시작하였으나, 옥스포드 아이오닉스 인수 완료 후에 계획이 바뀔 수도 있다.
    - [IonQ - IonQ to Increase Performance and Scale of Quantum Computers with Photonic Integrated Circuits in Collaboration with imec](https://investors.ionq.com/news/news-details/2024/IonQ-to-Increase-Performance-and-Scale-of-Quantum-Computers-with-Photonic-Integrated-Circuits-in-Collaboration-with-imec/default.aspx#:~:text=IonQ%20%28NYSE%3A%20IONQ%29%2C%20a%20leader%20in%20the%20quantum,world-renowned%20RD%20center%20in%20nanoelectronics%20and%20digital%20technologies.)

**💡****Quantinuum(Honeywell)의 접근**

- - Quantinuum은 **산디아와 매우 밀접한 관계**를 갖고 있지만, 작년부터 Infineon과 협력을 시작하였다.

    - 초기 QCCD 칩은 대부분 **산디아 HOA 시리즈**에서 공급
    - 현재 H1/H2 Racetrack 칩은 산디아 공정 기반에서 Honeywell 사내 MEMS 팹으로 일부 이전
    - DARPA QSCOUT, US2QC 등에도 산디아 칩이 공급된 사례 많음

**✅이온 트랩** **냉각 조건**

**💡****옥스포드 아이오닉스의 이온트랩 칩은 아이온큐나 퀀티넘의 그것과 달리 훨씬 낮은 온도가 필요한가?**

- - 이 질문에 대한 대답은 지난 포스팅의 Oxford Ionics의 QCCD에서 언급했듯이, 단일종의 이온을 사용하면서 QCCD를 이용하여 all-to-all을 구현하기 위해서 낮은 온도가 필요하다.

    - QPU 칩 → ST-400 Cold Head 또는 이에 상응하는 진공 냉각 챔버에 실장
    - 마이크로파 제어 회로 → 상단 플랜지를 통해 연결
    - 레이저 포트 → Optical Window 옵션 사용
    - Helium Compressor → QPU 옆 또는 아래에 위치
  - **QPU 칩 자체는 1×1 cm 수준**으로 매우 작지만,
  - ST-400 Cryostat + Helium Compressor까지 포함한 설치 전체를 보면 **책상 한쪽 면을 거의 차지하는 크기** 수준.

**💡****Cryostat의 기본 구조**

- - **본체(Chamber)**

    - Janis ST-400 같은 장치
    - 안쪽에 QPU 칩, 이온 트랩, 전극 구조가 들어감
    - 상단에 광학 윈도우, RF/DC 피드스루, 마이크로파 라인 등 설치 가능
  - **Cold Head (냉각부)**

    - Cryomech PT405 같은 Gifford-McMahon 방식 또는 Pulse Tube 방식 사용
    - 헬륨(He) 압축-팽창 과정을 이용해 **4K 근처**까지 냉각
    - Janis Cryostat과 직접 연결됨
  - **Compressor Unit (압축기)**

    - QPU 옆 바닥에 설치
    - 무게 110~170kg, 크기 50×50×60cm 이상
    - 헬륨 가스를 압축해 Cold Head로 보내고, 재순환시킴 → **헬륨을 계속 보충할 필요 없음**

| **항목** | **크기** | **비고** |

| **번호** | **구성요소** | **역할 및 특징** |
| **(i)** | **LHe flow cryostat head** | - 액체 헬륨(LHe)을 사용한 극저온 냉각 장치의 헤드 부분- 필박스(pillbox)를 약 **20K**까지 냉각- 열 스트랩(ii)과 연결되어 열을 전달 |
| **(ii)** | **Thermal strap** | - **S자형 구리 포일(25µm × 205장 적층)**- Cryostat head와 필박스를 연결하는 **유연한 열전달 경로**- 열전도율: ~0.8 W/K(상온 기준)- 진동과 열수축을 흡수해 **기계적 디커플링** 역할 수행 |
| **(iii)** | **Microwave semi-rigid coaxial cable** | - 마이크로파 신호를 표면트랩 내부 전극까지 전달- **UHV(초고진공) 호환 재질** 사용: 스테인리스/은/PTFE 복합- 입력 전력 최대 1W까지 안정적으로 전달 가능 |
| **(iv)** | **Microwave PCB** | - 마이크로파 신호를 표면전극의 λ/4 공진기(U-shaped resonator)로 공급- 50Ω 임피던스 매칭 설계- cryogenic 동작 시 Q-factor 안정성 확보 |
| **(v)** | **DC electrode connections** | - 이온 트랩 전극에 DC 바이어스를 공급하는 커넥터- 전위 제어를 통해 이온 포텐셜 웰 형성 및 위치 제어 수행 |
| **(vi)** | **CF100 base flange** | - 진공 챔버 하단 플랜지- 전체 시스템을 UHV 환경(~10⁻¹² mbar)으로 유지하는 밀폐 구조 |
| **(vii)** | **51-pin Micro-D feedthrough** | - 진공 내부 전극으로 전력 및 신호를 공급하는 **다핀 피드스루**- RF, DC, 온도센서, 마이크로파 전선을 모두 통합 |
| **(viii)** | **Temperature sensor PCB** | - Kelvin-connected RTD(저항온도센서) 탑재- 필박스 온도를 실시간 모니터링- RF/µW 신호 간섭을 최소화하는 설계 |
| **(ix)** | **Pillbox lid (cut-away)** | - 필박스를 밀폐하는 상단 뚜껑- 그림에서는 내부 구조를 보이기 위해 절반 잘라낸 상태 |
| **(x)** | **Surface trap chip** | - **43Ca⁺ 이온 트랩 칩**(표면전극 구조)- λ/4 공진기와 통합되어 마이크로파 기반 2큐빗 게이트 구동- 전극 간격 **40µm**로 설계되어 고필드 그래디언트 달성 |
| **(xi)** | **Atomic ovens** | - **칼슘 이온 원자원**(Ca atomic oven)- 저항 가열 방식으로 칼슘 원자를 방출 후 레이저로 이온화- 이온 로딩 시만 활성화되어 열부하 최소화 |

**💡****전체 동작 개요**

1. 1. **냉각 경로**

      - (i) Cryostat head → (ii) Thermal strap → (pillbox 내부 전극 및 칩)
   2. **신호 경로**

      - 마이크로파: (iii) Coaxial cable → (iv) PCB → (x) Surface trap chip
      - DC 제어: (v) DC connector → 칩 전극
      - 온도 측정: (viii) 센서 PCB → RTD 피드백
   3. **진공 및 안정성**

      - (vi) CF100 플랜지 + (vii) 피드스루 → 초고진공(UHV) 유지
      - 열수축 보상 + 진동 억제 → 이온 포지션 안정성 확보

**💡****핵심 설계 포인트**

- - **S자형 열 스트랩** → 열전도와 진동 억제 동시 달성
  - **λ/4 공진기 구조** → 효율적인 마이크로파 제어
  - **Cryopumping 효과** → 10-12 mbar 수준 초고진공 확보
  - **온도 안정성** → RTD 기반 피드백 제어
  - **모듈형 설계** → PCB, 표면트랩, 원자원, 센서가 모두 교체 가능
