**✅ 다체 얽힘은 무엇인가**

**📌 두 큐비트 얽힘에서 여러 큐비트 얽힘으로**

- - 가장 익숙한 얽힘은 두 큐비트 사이의 Bell state다.

    - Q1 ↔ Q2
  - 두 큐비트는 각각 독립된 상태로 설명할 수 없고 둘의 관계를 하나의 양자상태로 봐야 한다.
  - 그런데 세 개 이상의 큐비트도 동시에 하나의 상태로 얽힐 수 있다.
  - 예를 들어 3-qubit GHZ state는 개념적으로 다음과 같다.

    - |000> + |111>
  - 측정하면 세 큐비트가 모두 0이거나 모두 1인 강한 상관관계를 보인다.
  - 중요한 것은 단순한 pair들의 집합이 아니라는 점이다.

    - Q1 ↔ Q2
    - Q2 ↔ Q3
  - 가 아니라 세 큐비트 전체가 하나의 상태로 묶여 있다.

    - Q1 ↔ Q2 ↔ Q3
  - 이것을 multipartite entanglement 또는 many-body entanglement라고 부른다.
  - 다만 100개의 큐비트가 있다고 해서 반드시 100개 전체가 하나의 강한 다체 얽힘 상태라는 의미는 아니다.
  - 일부만 얽혀 있을 수도 있고, 계산 과정에 따라 얽힘의 범위와 구조도 계속 달라진다.

**📌 Many-body interaction과 다르다.**

- - Many-body interaction

    - 3개 이상의 자유도가 하나의 Hamiltonian 항으로 동시에 상호작용
    - 여러 큐비트를 동시에 직접 상호작용시킬 수 있는가

**✅ 현재의 양자컴퓨터도 이미 Many-Body System이다**

**📌 Many-body state 자체가 새로운 것은 아니다**

- - 여기서 한 가지 오해하기 쉬운 부분이 있다.
  - IonQ, Quantinuum, IBM, Google 등의 현재 양자컴퓨터도 물리적으로는 이미 many-body quantum system이다.
  - 예를 들어 64개의 큐비트를 가진 QPU는 64개의 양자 자유도를 가진 시스템이다.

    - Q1, Q2, Q3 ... Q64
  - 초기 상태가 다음과 같다면 서로 얽혀 있지 않을 수 있다.

    - |0000...000>
  - 이후 gate를 실행하면서 일부 또는 많은 큐비트가 서로 얽힌다.

|  |
| --- |
| **Q1 ↔ Q2**  **↓**  **Q2 ↔ Q3**  **↓**  **Q3 ↔ Q17**  **↓**  **복잡한 many-body state** |

- - 따라서 DARPA가 MeasQuIT을 통해 처음으로 many-body state를 만들겠다는 의미는 아니다.
  - 현재도 many-body state는 만들어진다.
  - 문제는 이를 더 큰 규모에서 정확하게 만들고, 유지하고, 검증하고, 제어하는 것이 매우 어렵다는 데 있다.

**✅ 다체 얽힘은 왜 중요한가**

**📌 큐비트 숫자보다 큐비트 사이의 관계가 중요하다**

- - N개의 큐비트가 가지는 상태공간은 2N으로 증가한다.

|  |  |
| --- | --- |
| **큐비트** | **Basis state 수** |
| 10 | 1,024 |
| 20 | 1,048,576 |
| 50 | 약 1.1 × 10^15 |
| 100 | 약 1.27 × 10^30 |

- - 하지만 큐비트들이 서로 완전히 독립적으로 움직인다면 이 거대한 상태공간의 복잡성을 제대로 활용하기 어렵다.
  - 얽힘이 생기면 정보가 각각의 큐비트에만 존재하는 것이 아니라 큐비트 사이의 관계에도 존재하게 된다.

    - Q1의 정보 + Q2의 정보 + Q3의 정보가 아니라 **Q1, Q2, Q3 사이의 관계자체**가 계산 자원이 된다.
  - 양자컴퓨터를 매우 단순화하면 다음과 같이 볼 수 있다.

    - Superposition → 거대한 상태공간 생성
    - Entanglement → 상태공간 안에 복잡한 상관관계 생성
    - Interference → 원하는 결과를 강화하고 원하지 않는 결과를 상쇄
    - Measurement → 필요한 답만 밖으로 꺼냄
  - 따라서 many-body entanglement가 중요한 이유는 많은 데이터를 저장하기 때문이 아니라, 고전적으로 표현하기 어려운 복잡한 correlation을 물리적으로 직접 다룰 수 있기 때문이다.

**✅ 양자컴퓨터는 Many-Body State의 모든 데이터를 고전컴퓨터에 저장하지 않는다**

**📌 이 부분이 Many-Body State을 이해하는 핵심이다**

- - 100개의 큐비트가 복잡하게 얽혀 있다고 하자.
  - 이 pure quantum state를 완전히 고전적으로 표현하려면 2100개의 complex amplitude가 필요하다.
  - 하지만 실제 양자컴퓨터가 동작할 때 이 모든 숫자를 고전컴퓨터의 RAM에 저장하는 것은 아니다.
  - 고전 simulation은 다음과 같다.

    - 2N개의 amplitude를 메모리에 저장 → 고전 CPU/GPU로 evolution 계산
  - 실제 QPU는 다르다.

    - N개의 실제 qubit → 물리계 자체가 quantum evolution
  - 즉 거대한 상태는 고전적인 숫자 배열이 아니라 QPU의 물리적인 상태 자체로 존재한다.

**📌 고전컴퓨터에 저장되는 것은 주로 측정 결과다**

- - 예를 들어 100-qubit circuit을 한 번 실행하고 모두 측정하면 다음과 같은 결과 하나를 얻을 수 있다.

    - 010110101001...
  - 같은 회로를 다시 실행하면 다른 결과가 나온다.

    - 110010001101...
  - 수천 번 또는 수백만 번 반복한 뒤 이 결과들의 통계를 이용한다.
  - 이후 다음과 같은 값을 계산할 수 있다.

    - Energy = -15.32
    - Correlation = 0.82
    - Magnetization = 0.41
  - 즉 양자컴퓨터 내부에는 매우 복잡한 state가 존재하지만, 밖으로 꺼내는 정보는 몇 개의 observable이나 통계값일 수 있다.

**✅ 그렇다면 Full Quantum State Tomography는 왜 문제가 되는가**

**📌 모든 정보를 꺼내려고 하면 다시 지수폭발이 발생한다**

- - Full quantum state tomography는 quantum state 전체를 고전적으로 복원하려는 작업이다.
  - 시스템이 작을 때는 가능하다.
  - 예를 들어 2, 3, 5개의 큐비트 상태를 연구실에서 검증할 때 많이 사용된다.
  - 그러나 큐비트 수가 증가하면 필요한 측정량과 설정 수가 급격하게 증가한다.
  - 따라서 다음과 같은 방식은 대형 양자컴퓨터에서 실용적이지 않다.

|  |
| --- |
| **100-qubit many-body state 생성**  **↓**  **Full tomography**  **↓**  **모든 amplitude를 classical computer에 복원** |

- - 그렇게 해야만 양자컴퓨터를 사용할 수 있다면 오히려 quantum advantage를 스스로 없애는 셈이 된다.

> *용어 정리*
>
> *Tomography는 여러 방향으로 촬영한 후 데이터를 결합하여 보이지 않던 내부 상태를 재구성하는 의미로 CT(Computed Tomography)에서 사용되는 단어다.*
>
> ***Quantum Tomography는 여러 종류의 측정 결과를 이용해서 원래 quantum state를 역으로 복원하는 작업****을 의미한다.*

**✅ 1. 양자 시뮬레이션 — 자연의 다체 문제를 다른 양자계로 옮긴다**

**📌 최근 살펴봤던 Many-Body Problem과 가장 직접적으로 연결된다**

- - 실제 분자나 물질에서는 수많은 전자와 입자가 서로 영향을 주고받는다.
  - 이러한 correlation을 고전컴퓨터에서 모두 추적하면 계산량이 급격히 증가한다.
  - 양자컴퓨터에서는 실제 물리계의 many-body correlation을 qubit들의 many-body correlation에 mapping할 수 있다.

|  |
| --- |
| **실제 Many-body system**  **↓**  **Hamiltonian mapping**  **↓**  **Qubit many-body state**  **↓**  **Quantum evolution**  **↓**  **필요한 observable 측정** |

- - 최근 IonQ의 핵반응 simulation 연구도 quantum many-body phenomena의 동역학을 실제 QPU 위에서 모사하려는 흐름에 해당한다.

**✅ 2. QEC — 전체 상태를 모르면서도 상태를 보호한다**

**📌 Logical qubit은 여러 physical qubit 사이의 관계에 저장된다**

- - 하나의 logical qubit을 많은 physical qubit에 encoding하면 매우 복잡한 entangled state가 만들어진다.
  - 하지만 QEC를 할 때 이 state 전체를 tomography하지 않는다.
  - 대신 stabilizer나 syndrome만 측정한다.

|  |
| --- |
| **+1**  **+1**  **-1**  **+1** |

- - 이를 통해 logical information 자체는 직접 읽지 않으면서도 어느 곳에서 오류가 발생했는지를 추정할 수 있다.

|  |
| --- |
| **Huge many-body state**  **↓**  **Full tomography X**  **↓**  **Syndrome만 측정**  **↓**  **Error correction** |

- - 이 구조는 전체 state를 알지 않고도 quantum system을 제어할 수 있다는 것을 잘 보여준다.

---

**✅ Many-Body Interaction과 Many-Body State는 같은 것이 아니다**

**📌 Interaction은 규칙이고 State는 결과다**

- - 둘은 서로 연결되지만 같은 것은 아니다.

    - Many-body interaction → 여러 큐비트가 어떤 규칙으로 동시에 상호작용할지를 정함
    - Many-body state → 그 interaction과 시간 evolution의 결과로 만들어지는 상태
  - 따라서 다음과 같이 연결된다.

|  |
| --- |
| **Many-body Hamiltonian**  **↓**  **Native many-body interaction**  **↓**  **Quantum evolution**  **↓**  **Many-body entangled state** |

|  |
| --- |

**📌 Engineered Dissipation과 Reservoir Engineering**

|  |

|  |
| --- |
| **잘못된 quantum state**  **↓**  **Engineered dissipation**  **↓**  **불필요한 energy / entropy 배출**  **↓**  **원하는 stable state로 복귀** |

- - 즉 자동차가 계속 운전자의 작은 조작만으로 균형을 유지하는 것이 아니라, 자체적으로 자세를 잡는 안정화 장치를 가진 것과 비슷하다.
  - DARPA는 measurement-backaction, engineered dissipation, reservoir engineering을 state preparation과 stabilization의 자원으로 사용할 가능성을 직접 제시하고 있다.

**✅ DARPA는 Many-Body State를 만드는 연구보다 그 다음 문제를 보고 있다**

- - 현재 양자컴퓨터도 이미 many-body quantum system이며 계산 과정에서 복잡한 many-body entangled state를 만든다.
  - 그리고 그 상태의 모든 정보를 고전컴퓨터에 저장하지도 않는다.
  - 원래부터 필요한 measurement 결과만 밖으로 가져온다.
  - 문제는 큐비트 수와 얽힘이 증가할수록 다음 문제가 급격히 어려워진다는 것이다.

    - 우리가 원하는 state를 정말 만들었는가
    - 계산 도중 state가 망가지고 있지는 않은가
    - 오류가 어디에서 발생했는가
    - 전체 tomography 없이 어떻게 이를 알아낼 것인가
    - 어떻게 실시간으로 다시 정상 상태로 돌릴 것인가
  - DARPA MeasQuIT은 바로 이 부분을 연구한다.
  - Measurement를 단순히 마지막에 결과를 읽는 과정에서 벗어나 quantum control 자체의 일부로 사용하고, feedback과 environment까지 state stabilization에 이용하려 한다.
  - 더 나아가 시스템 자체가 오류를 억제하고 복구할 수 있는 autonomous quantum system도 연구한다.
  - Chris Monroe 교수의 native many-body interaction 연구가 복잡한 Hamiltonian과 state를 더 직접적으로 만들어내는 방향이라면, DARPA MeasQuIT은 그렇게 복잡해진 quantum state를 실제로 어떻게 통제 가능한 계산 자원으로 만들 것인가에 더 가깝다.

    - 결국 이 모든 흐름은 하나의 질문으로 모인다.

      - **많은 큐비트가 함께 만들어내는 거대한 양자상태를 어떻게 만들고, 이용하고, 보호하고, 전체를 읽지 않으면서도 믿을 수 있게 제어할 것인가**
  - 대규모 양자컴퓨터에서 진짜 어려운 문제는 단순히 큐비트 숫자를 늘리는 것만이 아니라, 바로 이 거대한 many-body quantum state를 다루는 능력일 수 있다.

**✅ 결론**

- - 앞으로 양자컴퓨터의 경쟁은 단순히 physical qubit 수를 늘리는 것보다, 큰 many-body entangled state를 얼마나 효율적으로 만들고 유지하고 활용할 수 있느냐로 이동할 가능성이 크다.
  - 이를 크게 네 묶음으로 보면 다음과 같다.

    - **1. Many-body state를 얼마나 잘 만들 수 있는가**

      - 높은 connectivity와 native multi-body interaction을 이용해 더 적은 gate와 더 얕은 circuit으로 복잡한 entanglement를 만드는 능력이 중요해진다.
    - **2. 만들어진 state를 어떻게 읽고 제어할 것인가**

      - MCM, fast reset, real-time feed-forward를 이용해 계산 도중 필요한 정보만 읽고 다음 operation을 즉시 바꾸는 능력이 중요해진다.
    - **3. Many-body logical state를 얼마나 안정적으로 유지할 것인가**

      - QEC와 decoder를 이용해 전체 quantum state를 tomography하지 않고 syndrome만 반복적으로 측정하면서 logical error를 낮춰야 한다.
    - **4. 하나의 QPU를 넘어 어떻게 확장할 것인가**

      - photonic interconnect와 distributed entanglement를 이용해 여러 QPU를 연결하고, 장기적으로는 distributed QEC까지 구현해야 한다.
  - 결국 향후 양자컴퓨터의 성능은 단순한 큐비트 숫자보다 **복잡한 many-body state를 얼마나 적은 overhead로 생성하고, 측정하고, 보호하고, 여러 QPU로 확장할 수 있는가**에 의해 좌우될 가능성이 높다.

> *그래서 지금까지 우리가 본* ***Monroe교수의 native many-body interaction, DARPA MeasQuIT의 state control, Mid-Circuit Measurement, qLDPC, photonic interconnect가 사실 서로 따로 떨어진 연구가 아니라 하나의 대형 FTQC architecture에서 서로 맞물리는 기술들****이라고 볼 수 있다.*
