**✅ XIII. Logical Measurements**

- - **Logical measurement = cat state를 이용해서 여러 qubit을 “한 번에” 측정하는 방식**

****

**📌 기본 아이디어**

- - 기존 방식

    - → ancilla 하나로 측정
    - → error 퍼지기 쉬움
  - 새로운 방식

    - → **cat state (여러 qubit entangled 상태)** 사용
    - → 여러 qubit을 동시에 연결
    - → **high-weight Pauli 측정 가능**
  - 결과:

    - 큰 연산을 한 번에 처리
    - error propagation 감소
  - 아래 표를 보면 logical 정확도 10-10 만들려면 대략 3 ~ 6 번 반복이 필요하다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjZfMjIy/MDAxNzc3MTk0NTI2NzY0.215QZcG8f0_DTilXyEpLiM9PQFhw95f1UabE2KiTaaog.kHYZYQbnYsTOO1T7QrAzFhOJAVTlfgEW23Bxaw66478g.PNG/image.png?type=w800)](#)

**📌 Measurement 방식**

- - cat state를 data qubit들과 연결하고 측정하면
  - 결과:

    - b = c1 ⊕ c2 ⊕ c3 ⊕ ...
  - 즉, **cat state의 각 qubit 측정값 parity = logical 결과**

****

****

**📌 왜 반복 측정이 필요하냐**

- - 한 번 측정하면 오류 확률 O(p)

    - p에 비례하는 작은 확률
  - 그래서 **두 가지 방식 등장**

****

**📌 EDM vs ECM (핵심 차이)**

- - **(1) EDM (Error Detection Mode)**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjZfMTc3/MDAxNzc3MTk0Njc2MzQ1.zwAVo5r0I3pS47uQo_869v1OMA4jkHY8i3wg3qRWEOkg.OOMSkA7IkHC4yKtPYQWA-drXUM8xQAQayKsStpQI4mEg.PNG/image.png?type=w800)](#)

- - - r번 측정
    - **모든 결과가 동일해야 성공**
    - 하나라도 다르면 → 실패 → 버림
    - 특징:

      - 빠름
      - 대신 실패하면 전체 폐기후 다시 시작
      - 신뢰도 ↑ 대신 restart 발생
  - **(2) ECM (Error Correction Mode)**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjZfMjEz/MDAxNzc3MTk0NzA4MzQ4.jLVlqKQAAF5hQv49BU_NIHYMkqDT9RgD2XpLCbu0Rywg.mvpvEeU0MPijKhHlJajqnzRtXRCnaw-O2L66N6t4AvMg.PNG/image.png?type=w800)](#)

- - - r번 측정
    - **다수결 (majority vote)**
    - 특징:

      - 안정적
      - discard 없음
      - 대신 더 많은 연산(error correction) 필요
      - 속도 ↓ / 안정성 ↑

|  |  |  |
| --- | --- | --- |
| **항목** | **EDM** | **ECM** |
| 방식 | reject | correct |
| 실패 | 있음 | 없음 |
| 속도 | 빠름 | 느림 |
| 안정성 | 높음 | 더 높음 |

**📌 성능 scaling (중요 포인트)**

- - 각 measurement error ~ O(p)
  - 반복하면:

    - EDM → O(p^r)
    - ECM → O(p^(r/2))
  - 즉, r 증가 → 오류 급격히 감소
  - 아래 그림에서 ECM-5, 7, 9 비교하자.

    - **p 줄이면 → logical error 급격히 줄어듦**
    - **r 늘리면 → 훨씬 더 빠르게 줄어듦**
    - **이 구조는 fault-tolerant scaling이 된다**
    - **이론 예측 (Heuristic)과 실험결과(simulation)가 잘 맞음.**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjZfMTIx/MDAxNzc3MTk1MDIzNTM0.1q6hTeDtaYnS_Wi7B4B0pFQ9slqttOL5Q3oDN05d5R8g.Sgv0khUtfpsD1B_cNezuN2-12fTw1Dm1xDTya63HlvYg.PNG/image.png?type=w800)](#)

**📌 중요한 발견 (논문 핵심 주장)**

- - LDPC 구조 + decoder 덕분에 **r 크게 안 해도 됨**
  - 결론:

    - **r = 1도 충분할 수 있음**

      - "Here we conjec ture that a single SEC round per cat-based measurement is sufficient, and we provide numerical evidence to that effect for specific instances of quantum LDPC codes se lected for the walking cat architectures."
    - 기존 surface code보다 훨씬 효율적

**📌 Measurement 독립성 문제**

- - 문제:

    - 연속 measurement 결과가 서로 영향 줄 수 있음
  - 해결:

    - measurement 사이에 **SEC (syndrome cycle)** 삽입
  - 효과:

    - 결과 independence 확보

**📌 실제 error 모델**

- - 논문 단순화:
  - bit-flip error:
  - p\_flip ≈ C₁ · w · p
  - 의미:

    - cat state 크기 w 클수록 error 증가
    - 물리 error p 비례

**📌 중요한 trade-off**

|  |  |
| --- | --- |
| **요소** | **효과** |
| w (cat 크기) ↑ | 더 큰 연산 가능, error ↑ |
| r (반복 횟수) ↑ | 정확도 ↑, 시간 ↑ |
| p ↓ | 전체 성능 개선 |

**📌 Viterbi measurement (고급 개념)**

- - 기존:

    - r 고정
  - Viterbi:

    - **중간에 충분하면 멈춤**
  - 조건:

    - 통계적으로 충분히 확신되면 종료
  - 결과:

    - 평균적으로 **~2배 빠름**

****

**📌 시스템 레벨 의미**

- - logical operation = gate가 아니라 → **measurement 기반 계산**
  - cat state = → **연산 리소스 (like GPU tensor)**
  - 반복 measurement + decoding = → **fault tolerance 핵심**

****

**📌 최종 정리**

- - Logical measurement는 단순 측정이 아니라:

    - → cat state를 이용한 병렬 측정
    - → 반복 측정으로 error 억제
    - → decoder로 결과 안정화
  - 즉, **“연산 = measurement + repetition + decoding” 구조**

****

**✅ XIV. Weight-Reduced Logical Pauli Operators**

**📌 출발점**

- - 이 논문의 제약:

    - **우리는 모든 logical Pauli를 측정할 수 있는 게 아니다**
    - → 오직 **accessible logical Pauli만 가능**
  - 그 조건:

    - physical representative의 weight ≤ w
    - 즉, **weight가 작아야 측정 가능**

****

**📌 문제 정의**

- - 같은 logical operator P라도 대응되는 physical operator는 여러 개 있음
  - 그 중 일부는:

    - weight 큼 → 측정 불가
    - weight 작음 → 측정 가능

**📌 핵심 목표**

- - **같은 logical operator를 “더 가벼운(weight 작은)” 형태로 바꾸자**

****

**📌 방법 (2-step 구조)**

- - **Step 1. Stabilizer 최적화**

    - logical operator P̄에 stabilizer S를 곱함:

      - P̄\_opt = P̄ · S
    - 목표:

      - weight 최소화
  - **Step 2. Symplectic basis 최적화**

    - 단일 operator가 아니라:

      - **전체 logical operator 집합 (basis)을 최적화**
    - 목표:

      - **가장 무거운 operator의 weight를 최소화**

****

**📌 직관 (핵심 이해)**

- - 기존:

    - logical operator가 멀리 퍼져 있음
    - 많은 qubit에 걸림 → weight 큼
  - 최적화 후:

    - 더 local하게 표현
    - 필요한 qubit 수 줄임
  - 👉 **“같은 연산을 더 싸게 표현”**

****

- - **Q102**

    - 원래 max weight ≈ 20
    - 최적화 후 ≈ 12
  - **Q70**

    - 최적화 후 ≈ 9
  - **Q54**

    - 최적화 후 ≈ 11

**📌 왜 중요한가 (핵심 연결)**

- - cat factory 제한:

    - cat state 크기 = w
  - 즉:

    - weight > w → 측정 불가
    - weight ≤ w → 측정 가능
  - 그래서:
  - weight 줄이면 = **더 많은 logical operator를 측정 가능**

****

**📌 실제 영향**

- - 아래 표에서 보면, Q102의 경우, 크기가 3 이하인 logical operator만 안정적으로 처리 가능

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjZfMjIw/MDAxNzc3MTk2NjkxNDY2.OmAfUokf39zklw9yBcN4ibQn-qMv_aiCv4wlyhIg1xkg.Utm85nmlYB-NY2N4yS283vUiYEtr4HuqJOKCyfnqtdYg.PNG/image.png?type=w800)](#)

- - **Q54, Q70**

    - 거의 모든 Pauli 측정 가능
    - 모든 Clifford 가능
  - **Q102**

    - weight ≤ 3 Pauli만 직접 측정 가능
    - 대신:

      - single-qubit Clifford
      - SWAP → 가능

**📌 중요한 트레이드오프**

|  |  |
| --- | --- |
| **요소** | **의미** |
| weight ↓ | 측정 쉬움 |
| weight ↑ | 표현 자유도 ↑ |
| block width ↑ | 더 많은 operator 접근 가능 |

> ***Weight reduction = logical operator를 cat factory가 측정 가능한 형태로 변환하는 과정***
