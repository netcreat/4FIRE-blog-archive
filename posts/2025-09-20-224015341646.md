**💡** **System Overview**

- - 진공 챔버 내부에 **원자원(Atomic Source)**, **이온 트랩**, **형광 측정(optical readout)** 이 들어 있음.
  - 외부에서는 **가변형 레이저 소스**, **게이트 필드 소스**, **RF/DC 전극 제어**, **광학 제어** 등이 연결되어 이온들을 제어.
  - 즉, 진공 속의 원자/이온과 외부 전자·광학 장치가 상호작용하는 구조.

**💡****중성 원자 공급**

- - **Thermal Oven** (열로 증발시켜 중성 원자 플룸 생성) → IonQ에서 기존 Yb 기반에서 사용하는 방식

    - Yb 금속 조각을 **텅스텐 튜브(oven)** 안에 넣고 전류를 흘려 가열 → 원자 증기 발생.
    - 칩 하부에 슬롯을 뚫어 플룸(plume-증기 기둥)이 **트랩 영역**을 통과하도록 유도.
    - 이렇게 하면 칩 표면 오염을 피하면서 이온화 영역에 원자를 공급 가능.
  - **MOT (Magneto-Optical Trap)** 로 중성 원자를 모아 옮김 → 주로 중성원자 기반에서 많이 사용됨

    - 소스 챔버에서 **2D(또는 2D+) MOT**로 원자들을 레이저 냉각·속도 선택하여 **차가운 원자빔**을 생성.
    - 푸싱 빔으로 메인(3D) MOT나 트랩 영역으로 전달

      - 이온트랩 응용에선 Sr/Yb 같은 알칼리토류 원자빔을 차갑게 공급한 뒤 PI로 로딩.
      - 제만 슬로어/디퍼런셜 펌핑과 조합한 콤팩트 모듈도 상용화되어 있
  - **Ablation** (레이저로 재료 표면을 때려 원자 방출) → Oxford Ionic와 IonQ 사용할 것으로 추정

    - 트랩 근처의 **금속/염 타깃**(Ca, Sr, Yb, BaCl₂ 등)에 펄스 Nd:YAG(예: 355 nm, ns, mJ급)를 쏘아 플룸(plume)을 생성하면 중성 원자/이온이 순간적으로 방출
    - 중성 위주 운용 시엔 기존처럼 **PI**로 원하는 동위원소만 이온화·포획하고, 조건에 따라 직접 이온도 포획 가능.
    - 반응성 높은 원소(Ba 등)은 염 타깃(BaCl₂ 등)로 안정하게 다룸

**💡****이온화**

- - 중성 Yb 원자가 트랩 영역을 지나가면, **2단계 광이온화**(photo-ionization)로 전자 1개 제거 → 양이온 생성.
  - 이온트랩은 전하가 없는 중성 원자는 못 잡기 때문에, 반드시 전자를 빼야 전기장에 반응.
  - 문제: 이렇게 갓 만들어진 이온은 여전히 빠른 속도로 움직임 → **냉각(Doppler, Sideband)** 필요.

**💡****동위원소 선택 (Loading Ions – Isotope Selection)**

- - 모든 동위원소가 같은 것은 아니다. Yb(이테르륨)에서는 **Yb-171만** 선택하여 트랩에 넣는다.
  - 두 가지 방법이 있다:
  1. 100% Yb-171로만 이루어진 금속 덩어리를 구하거나 제작한다 (실제 연구에서는 매우 비현실적이라 배제됨)
  2. **트랩에서 Yb-171만 선택적으로 잡는 방법**

     - 특정 동위원소의 Yb만 이온화시킨다.
     - (즉, 다른 질량을 가진 중성 원자들은 트랩에 영향을 주지 않음 → 트랩 안에 들어오지 않음)
     - 원리적으로는, 충분한 에너지를 가진 광자라면 어떤 원자든 전자를 떼어낼 수 있다.
     - 그러나 2단계 이온화 과정(2-stage ionization process)을 사용하면, 특정 동위원소만 선택적으로 이온화할 수 있다.

       - 바닥 상태 1S0에서 시작
       - 첫 번째 레이저(399 nm) → 원자를 여기 상태 1P1로 들뜸
       - 두 번째 레이저(369.5 nm 또는 394.1nm) → 전자를 떼어내 연속체(continuum, 즉 이온화 상태)로 보냄
       - 이 2단계 과정을 통해 **Yb-171만 특정 파장에 공명**하고, 다른 동위원소들은 약간의 에너지 차이 때문에 공명하지 않아 선택적으로 걸러짐.
  3. **Ba-137인 경우**

     - - 바닥 상태 6s2 1S0에서 시작
       - 첫 번째 레이저(553.7 nm) → 원자를 여기 상태 6s6p 1P1로 들뜸
       - 두 번째 레이저(413 nm 또는 405 nm) → 전자를 떼어내 연속체(continuum, 즉 이온화 상태)로 보냄
       - 이 2단계 과정을 통해 **Yb-171만 특정 파장에 공명**하고, 다른 동위원소들은 약간의 에너지 차이 때문에 공명하지 않아 선택적으로 걸러짐.

**💡참고 -** **Term symbol (원자 상태 기호)**

- - **기본형**

- - - **S (총 스핀)** → 위첨자에서 2S+1로 표시. (스핀 다중도)
    - **L (총 궤도각운동량)** → 알파벳으로 표시: 아래 그림 참조.

      - S (L=0), P (L=1), D (L=2), F (L=3) …
    - **J (전체 각운동량)** → 아래 첨자. J=L+S

- - **바륨예시**

    - **중성 바륨 (Ba, [Xe]6s****2****)**

      - 두 전자가 모두 6s 껍질에 있으므로, 궤도각운동량 ι=0씩 → 총합 L=0
      - 두 전자가 스핀을 짝지어 S=0
      - 따라서:

- - - - - → 단일항, 총 스핀 0, L=0, J=0
      - **의미:** 완전히 짝지어진 폐각형 → **바닥상태**.
  - **바륨 이온 (Ba****+****, [Xe]6s****1****)**

    - - 최외곽 전자가 하나만 존재 (6s**1**)
      - 스핀 S=1/2 → 다중도는 2S+1=2
      - 궤도각운동량 ι=0 → L=0 → “S”
      - 따라서:

- - - - **의미:** 알칼리 원자와 같은 구조. 한 개 전자만 있어서 S=1/2, J=1/2 상태.

**💡****바닥 상태와 여기상태시 전자배치와 텀 심볼**

- - **중성 바륨**

    - **바닥상태**

      - [Xe]6s2 (1S0)

        - 6s 전자 2개가 짝을 이뤄 총 스핀 0 (singlet), L=0 (S), J=0
    - **대표 여기상태**

      - [Xe]6s6p(1P1)

        - 하나는 6s, 하나는 6p
        - 스핀은 짝지어 S=0 → singlet
        - L=1 (P), J=1
  - **바륨 일가 양이온**

    - **바닥상태**

      - [Xe]6s1 (2S1/2)

        - 홀전자 1개, L=0 (s), S=1/2 → J=1/2
        - **알칼리 금속과 유사한 구조 (Na, K 등과 비슷)**
    - **대표 여기상태**

      - J=∣L−S∣또는L+S → J=1/2 또는 3/2

        - s에서 p로 여기되면 궤도 각운동량 ι=1 → L=1
        - 스핀은 여전히 S=1/2 → 다중도는 2
      - [Xe]6p(2P1/2) 또는 (2P3/2)

        - 쿨링 전이에 쓰이는 493.4 nm: 6s 2S1/2 ↔ 6p 2P1/2
        - 보조 전이에 쓰이는 455.4 nm : 6s 2S1/2 ↔ 6p 2P3/2

          - 처음 오븐에서 이온을 만든 뒤, 제대로 Ba⁺가 잡혔는지 확인할 때 455 nm 레이저를 쏘면 강한 발광을 내므로 trap 확인에 사용
          - 455 nm 전이를 통해 5d 준위(특히 2D5/2)로도 간접적으로 decay 경로가 열리므로, **metastable D** **상태에 원자를 펌핑**하는 실험에 쓰이기도 함.
          - 나중에 1762 nm clock 전이 같은 정밀 분광 실험과 연결
        - 리펌프에 쓰이는 650 nm: 6d 2D3/2 ↔ 6p 2P1/2
      - 홀전자가 여기될 때 6p로 가지만, 5d로 여기될 수 있음

        - 이때는 5d(2D3/2) 또는 (2D3/2)

          - s에서 d로 여기되면 궤도 각운동량 ι=2 → L=2
          - 스핀은 여전히 S=1/2 → 다중도는 2

            - → J=3/2 또는 5/2
