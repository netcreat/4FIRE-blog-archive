**✅WISeKey / SEALSQ → WISeSat 신형 위성 발사 요약**

**1. 무엇을 했나?**

- - WISeKey, SEALSQ, WISeSat.Space가 **SpaceX Falcon 9 Transporter-16**으로
  - **신형 WISeSat 위성 발사 성공**.

**2. 왜 중요한가?**

- - WISeSat의 목표:

    - **양자안전(Quantum-safe) 보안 + IoT 연결을 위한 “소버린(자주적) 위성군” 구축**
  - 2026년부터 **위성 기반 PQC(양자내성) 키 배포 서비스** 제공 예정.

**3. 기술적 특징 (신형 위성 업그레이드)**

- - **SDR(Software-Defined Radio)**

    - → 궤도에서 통신 규격·파장 등을 **유연하게 재구성 가능**
  - **고속 데이터 전송**

    - → 산업용 IoT, 사이버보안, 중요 인프라 모니터링에 적합
  - **보안 강화**

    - → SEALSQ의 **Post-Quantum Chip**과 통합

**4. 제공하려는 서비스**

- - IoT 기기의 **양자안전 디지털 ID 발급 및 온보딩** (우주에서 직접)
  - **암호화된 텔레메트리·명령 인증**

    - (EO(지구 관측)/국방 미션 대상)
  - **스마트시티, 에너지, 교통 인프라**를 위한 보안 데이터 링크

**5. 생태계 확장**

- - 스페인 La Línea에 새 지상국 설치, 스위스 추가 예정

    - → 더 빠른 실시간 운영 및 보안 강화
  - Hedera·SEALCOIN 연동

    - → **위성 서비스 토큰화 및 보안 거래 플랫폼 구축**

**✅****WISeKey의 구조**

- - WISeKey는 지주사 구조라 시가총액이 작지만 핵심 자회사들의 지분을 상당 보유하고 있음.

**1. WISeKey 그룹을 구성하는 3개 핵심 축**

- - WISeKey는 직접 사업을 하지 않고, 실제 매출·기술은 아래 3곳에서 나옴.
  1. **SEALSQ (NASDAQ: LAES)**

     - PQC(양자내성) 보안칩
     - PKI 보안 모듈
     - MCU, Trust anchor
     - 매출 약 **$30–40M 수준**
     - 시총 **$150M~$250M** 밴드에서 움직였음 (2025년 기준 변동 가능)
     - 👉 *WISeKey 그룹 내에서* ***가장 큰 자산****.*
  2. **WISeSat.Space**

     - 초소형 LEO 위성(큐브샛 기반)
     - IoT 보안·키 배포용 Constellation
     - SpaceX Transporter 시리즈로 여러 번 발사
     - 매출은 거의 없지만 **자산가치·기술 가치 중심**
     - 위성 1기 제작비는 일반 큐브샛 기준

       - 제조비 20만~100만 달러
       - 발사비(Transporter rideshare) 30만 달러 전후
     - WISeSat은 **20기 이상 배치 목표**이므로
     - 👉 현재 가치 추정 **약 $20–40M 규모**.
  3. **WISeKey Switzerland (Core PKI/IoT 사업)**

     - 루트 인증서, 디지털 신원
     - eID / IoT 보안 SaaS
     - 매출은 적지만 기술자산·브랜드는 존재
     - 추정 기업가치 **$20–40M**

  2. **WISeSat 가치**

  3. **WISeKey 자체 사업 / IP 자산**

**🚀 WISeSat란 무엇인가 — 현재 상태**

- - WISeSat는 WISeKey의 자회사로, “우주(위성) + IoT 연결 + 보안(PQC 포함)”을 결합한 위성 통신회사임
  - “picosatellite / nanosatellite / LEO(저궤도)” 위성들을 사용해서, 글로벌 커버리지에서 IoT 디바이스를 위성으로 연결하려는 계획.
  - 현재까지 “프로토타입/초기 위성들(나노/피코위성)”을 발사했고, 추가 발사 및 위성군(constellation) 확장을 계획 중.

**📊 WISeSat이 노리는 기회**

- - WISeSat은 다음과 같은 시장기회를 노리고 있다:

    - 지상 인프라가 열악한 **농촌 / 해양 / 광산 / 오지 / 개발국가 지역**에 IoT 연결 제공
    - 기존 통신 인프라가 닿지 않는 **글로벌 커버리지 & 저전력 IoT 디바이스** 시장
    - 양자컴퓨터 시대에 대비한 **보안 IoT 통신 + 인프라 보호**가 필요한 산업/국가 인프라
    - 스마트시티, 에너지, 환경, 물류, 농업 등 다양한 산업 분야에서의 디지털 전환 수요
    - 장기적으로는 **Web3 / DePIN / 블록체인 기반 IoT 서비스** — 위성 + 보안 + 탈중앙화
  - 즉, “단순한 위성 사업”이 아니라, **우주 + 보안 + IoT + 블록체인**을 융합한 “차세대 인프라 + 서비스 플랫폼”을 구축하려는 시도임

    - 아직 위성 수는 많지 않고, “글로벌 전체 커버”가 완성되려면 다수 발사 필요

**✅****초저전력 IoT 디바이스를 위한 위성 네트워크**

**🌱 초저전력 IoT 디바이스의 대표적인 종류**

- - 환경·기후 센서 (Environmental Sensors)
  - 스마트 농업(Agritech) 센서
  - 에너지·유틸리티 산업의 원격계량기(AMI)
  - 물류·운송·해운 분야(Tracking)
  - 산업 인프라 모니터링 센서
  - 가축·야생동물 추적 센서
  - 스마트시티 초저전력 센서

**🔋 초저전력이 필요한 이유**

- - ULP IoT 디바이스는 대부분 이런 조건 아래에서 사용됨:

    - 외딴 곳 (전력 공급 없음)
    - 배터리 교체 비용이 장비 가격보다 비쌈
    - 작은 데이터만 보내기 때문에 고대역폭이 불필요
    - 5~10년 이상 유지해야 경제성이 맞음
  - Starlink, 5G, LTE-M 같은 고전력 통신 방식은 **전혀 적합하지 않음.**
  - 그래서 WISeSat이 노리는 시장은 매우 큼.

**🌍 WISeSat이 노리는 IoT 시장 규모**

- - 2025년 기준 전 세계 IoT 센서 수 약 **140억**
  - 초저전력 IoT 비율 약 **65%**
  - 지상 통신 불가 지역 IoT 수요 지속 증가
  - 2030년에는 IoT 센서 수 **300억~500억** 전망
  - WISeSat이 IoT 센서 일부라도 흡수하면
  - 매우 큰 시장이 됨.

**⭐ 초저전력 IoT 센서가 ‘작은 안테나 + 몇 mW 전력’만으로 위성과 통신 가능한 이유**

- - LEO(저궤도)라서 통신 거리 자체가 매우 짧다
  - IoT 위성은 작은 안테나를 가진 디바이스에 맞게 “거대한 지향성 안테나”로 신호를 증폭

    - **위성이 고출력·고감도의 안테나와 SDR을 탑재**함

      - 센서는 약한 신호 하나 보내고, 위성이 그 신호를 잡아주는 구조
  - 센서는 위성이 ‘지나는 순간 1~2초만 깨어나서 통신’하는 방식 → 전력 문제 해결
  - 안테나가 생각보다 크지 않아도 된다 (수 cm 금속 패턴 수준)

**✅WISeSat과 SEALSQ의 협력**

**📌수십억 ~ 수백억 개의 IOT 센서**

- - WISeSat/SEALSQ의 전략은 “수많은 IoT 디바이스에 PQC(양자내성) 보안 칩을 장착시키는 것”이다.

**📌WISeSat의 비전 = “우주에서 PQC 디지털 ID를 발급하는 IoT 보안망”**

- - WISeSat이 제공하려는 핵심 서비스는:

    - **IoT 디바이스가 위성과 직접 통신하여,**
    - **PQC 기반 디지털 신원(Identity)을 부여받고,**
    - **암호 키를 안전하게 프로비저닝받으며,**
    - **이후 모든 데이터 통신은 PQC 기반으로 암호화되는 구조**

> ***IoT 보안 Identity + PQC 키 + OTA 인증 정보를***
>
> ***위성에서 직접 내려주는 글로벌 보안 인프라***

**📌 그럼 실제로 IoT 디바이스에 무엇이 들어가야 하나?**

- - **다음 두 가지 중 하나가 필요함:**
  1. **SEALSQ의 PQC Secure Element 칩 (WSE/Secure Element)**

     - SEALSQ는 다음과 같은 보안칩을 제작함:

       - PQC 지원(ML-KEM, ML-DSA 등 NIST 선정 알고리즘)
       - 온보드 키 생성
       - 물리적 변조 방지(PUF, secure memory)
       - 초저전력 동작
       - IoT 센서용 소형 패키지
     - 이 칩은 가격이 높지 않고, IoT 센서에 넣기 쉬움.
     - WISeSat 위성이 이 칩들과 통신하여 다음의 역할을 수행할 수 있음

       - ✔ 디지털 ID 발급
       - ✔ 키 교환
       - ✔ 인증 토큰 제공
     - PQC 칩 필수인 경우

       - 국가 인프라(전력망, 물류, 항만, 철도)
       - 국방/보안 시설
       - 정유·가스·플랜트 센서
       - 스마트시티 주요 인프라
       - 원격지 파이프라인 센서
  2. **기존 MCU + 소프트웨어 기반 PQC 스택**

     - 칩이 없어도 일부 PQC 알고리즘은 **펌웨어 업데이트만으로도 구현 가능**

       - (단, 성능/보안/전력 면에서 SE 칩보다 떨어짐)
     - 이 경우에도 WISeSat 위성과 교신하여 키를 받을 수 있음.
     - 칩 없이도 가능한 경우

       - 기상/토양/환경 센서 등 보안 수준이 낮아도 되는 분야
       - 데이터가 오픈이거나 변조 위험이 낮은 경우
       - 비용 압박이 매우 큰 초저가 IoT

**⭐ 핵심 포인트: “위성 기반 PQC = 칩을 팔기 위한 글로벌 분배 시스템”**

- - WISeSat의 비즈니스 구조를 보면 다음과 같다.

    - **SEALSQ – PQC 칩 제공**
    - **WISeSat – PQC 키와 ID를 우주에서 배포**
    - **WISeKey – 전체 생태계(블록체인, 인증, ID)를 묶음**

> ***WISeSat은 단순한 통신 사업자가 아니라,***
>
> ***SEALSQ PQC 칩을 전 세계 IoT로 확산시키는 분배 플랫폼 역할을 한다.***
