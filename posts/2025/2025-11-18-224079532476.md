# Tranche? 그게 뭔대? 새로 나온 코트야?

Published: 2025-11-18T08:13:48.318000+09:00

Original Naver post: https://blog.naver.com/4-fire/224079532476

---

> "Tranche"는 주로 금융, 투자, 프로젝트 관리 등에서 사용하는 프랑스어 기반 용어로, "분할" 또는 "할부", 금융 상품이나 투자 자금의 "일부분"을 뜻한다. 예를 들어, 큰 투자나 자금 지원을 여러 번에 나누어 공급할 때 각각을 "tranche(트랑슈)"라고 부른다.
>
> 우리가 알고 있는 트렌치 코트는 1차 세계대전 참호(Trench)에서 군인들이 입었던 방수 코트에서 유래하며, 여기서 "trench"는 "참호, 도랑"이라는 뜻으로, Tranche와는 관련이 없다.
>
> 

---

**🚀 SDA Tranche-2 (Space Development Agency – Tranche 2)**

**📌 개요**

- - 미국 국방부(DOD) 산하 Space Development Agency(SDA)가 추진하는 **Proliferated Warfighter Space Architecture (PWSA)** 구축 계획의 한 단계.
  - 목표는 **저궤도(LEO) 다중위성 네트워크**를 구축하여

    - **미사일 탐지**
    - **미사일 추적**
    - **전장의 실시간 데이터링크(Tactical Data Transport)**
    - **지상/해상/공중 자산 연결**
    - 을 제공하는 군사 우주 인프라 형성.

**📍 Tranche 시리즈 구조**

|  |  |
| --- | --- |
| **Tranche** | **내용** |
| Tranche-0 | 2023~24: 기술 데모·초기 전력 배치 |
| Tranche-1 | 2025~26: 작전 수준 데이터 전송·미사일 경보 |
| **Tranche-2** | **2027~**: 대규모 전력화, 글로벌 커버리지 완성 |
| Tranche-3 | 향후 확장 및 정비 |

**💡****Tranche-2 세부내용**

- - **Tracking Layer** + **Transport Layer** 대규모 위성 네트워크 확장
  - Lockheed Martin / Northrop Grumman / SpaceX / York Space Systems / Rocket Lab 등 참여 가능
  - Golden Dome / Hypersonic defense와 강하게 연결되는 프로젝트
  - 즉,
  - SDA Tranche-2 = 미국 국방 LEAPS(LEO Defense Internet)의 본격 전력화 단계

---

**✅PWSA란?**

**📡Proliferated Warfighter Space Architecture (PWSA) 뜻**

- - 미국 Space Development Agency(SDA)가 구축 중인 저궤도(LEO) 수백~수천 개 위성으로 이루어진 군사 우주 네트워크로, 전장(warfighter)에게 실시간 정보·통신·추적·미사일 경보 능력을 제공하는 분산형(proliferated) 우주 인프라.

**🚀 왜 만들어지는가?**

- - 기존 군사 우주 시스템의 한계:

    - 고가의 대형 정지궤도 위성(GEO)은 **파괴되면 대체 불가**
    - 중국·러시아 ASAT(위성 파괴 미사일) 위협 증가
    - 극초음속 미사일 탐지·추적에 기존 레이더/위성은 느림
  - 따라서,
  - **수량으로 방어하는 분산 네트워크 구축**

    - 위성 수가 많아 파괴가 어려움 (resilience)
    - 빠른 데이터 전송
    - AI 기반 자동 결합·추적

**🔧 구성 Layer**

|  |  |
| --- | --- |
| **Layer** | **기능** |
| **Tracking Layer** | 극초음속 미사일 / 탄도미사일 / 항공 표적 추적 |
| **Transport Layer** | 위성 간 레이저 링크 → 저지연 global data mesh |
| **Navigation Layer** | GPS 독립 항법, PNT 보강 |
| **Custody Layer** | 시간 민감 목표 persistent tracking (24/7) |
| **Battle Management C3** | 의사결정·지휘통제 |

**🛡 Golden Dome / Hypersonic Defense와의 관계**

|  |  |
| --- | --- |
| **항목** | **의미** |
| Golden Dome | 미국 본토 방어 미사일 방어망 구축 |
| PWSA | 그 방어망의 **우주 기반 신경망(두뇌+눈+신경)** |

> **Golden Dome의 핵심 기반 인프라가 PWSA이다.**

**💡Tranche라는 명칭이 사용된 이유**

- - PWSA 구축은 수백~수천 위성, 통신·추적·항법·C2 등 매우 많은 요소가 필요하므로
  - 한번에 전부 개발·배치할 수 없고, **리스크 관리 / 비용 통제 / 기술 검증 / 조기 전력화**가 필요하다.
  - 그래서 SDA는 아래와 같은 **단계적 Spiral Deployment 방식**을 채택.

[**PWSA-Tranche-0**](https://www.sda.mil/wp-content/uploads/2024/09/Tranche-0-Fact-Sheet_FINAL_UPDATED_2024.pdf)

- - **📊 주요 성과**

    - 2023년 4월 3일: 우주군 발표 – SDA가 T0 위성 10기를 발사했다고 발표.

      - 8기 Transport Layer
      - 2기 Tracking Layer
    - 이후 2023년 9월 2일: 13개 위성이 추가 발사됨.
    - T0 목표 기능:

      - 저지연( Low latency ) 데이터 연결.
      - 시선 밖 표적( Beyond Line of Sight targeting ) 대응.
      - 미사일 경보·추적 기능 실증.
      - 지상 센서와 위성 데이터 융합(On-orbit fusion / multi-phenomenology).
    - 계약 규모 및 단가 예시: T0 Transport 위성 1대당 약 **$15 million** 수준.
  - **👷 참여 업체**

    - Transport Layer: York Space Systems, Lockheed Martin.
    - Tracking Layer: SpaceX, L3Harris Technologies.
    - 위성 버스 공급: Terran Orbital Corporation이 Lockheed Martin에 버스 공급 형태로 참여했음.
  - **📌 의미**

    - T0는 “warfighter immersion tranche(전투요원 체험 트랜치)”로 불림.
    - 상업발사체·소형위성 비즈니스 모델을 활용하여 짧은 기간 내에 운용가능한 위성망 실증
    - 향후 T1·T2로의 확장을 위한 기술적 기반 마련

**💡 Tranche 1 (T1) — 실전 전환 단계**

- - **📊 주요 성과**

    - 2025년 9월 10일: 첫 T1 Transport Layer 위성 21기 발사 완료.
    - T1 계획: 총 154기 (126기 Transport + 28기 Tracking + 4기 미사일방어 실증) 위성 망 구축.
    - T1 기능 목표: 전술 데이터 링크(Low latency), Link 16 통신, 미사일 경보·추적, UHF/S-band 위성통신 실증.
    - 산업 측면: T1 계약 약 **$1.8 billion** 수준(Transport Layer) 및 **$1.3 billion** 수준(Tracking Layer) 계약 존재.
  - **👷 참여 업체**

    - Transport Layer: York Space Systems, Lockheed Martin, Northrop Grumman.

      - **Skyloom, York Space Systems에 OCT 88기 인도 예정(42기, 추가 44기 납품 완료)**
    - Tracking Layer: L3Harris Technologies, Northrop Grumman.
    - 발사체: SpaceX Falcon 9 이용.
  - **📌 의미**

    - T1에서 **실전급(Initial Warfighting Capability; IWC)** 위성망으로 전환 예정 → 2027년부터 운용 개시 목표.
    - 위성량 및 기능이 대폭 증가하여 **운용 지속성(Persistence)·광역 커버리지·고속 데이터망**의 실현 단계

[**PWSA-Tranche-1**](https://www.sda.mil/wp-content/uploads/2025/09/PWSA-Tranche-1-Factsheet-UPDATE_09.05.2025.pdf)

**💡Tranche-1 그림 설명**

- - **PWSA**: 저궤도(LEO) 1,000km 고도에 수백 기의 소형 위성을 뿌려서(optically linked small satellites) 전장에 필요한 능력을 계속 추가해 나가는 구조.
  - **Tranche**: 2년에 한 번씩 새 세대를 쏘아 올려 능력을 계속 업그레이드 하는 “세대(배치)” 개념
  - 전체 위성망의 기본 궤도 설정

    - **ALTITUDE (km): 1000**
    - → 위성들은 약 1,000km 저궤도에 배치.
    - **INCLINATION (deg): 81.3**
    - → 궤도 경사각 81.3°, 거의 극궤도에 가까워서 지구 대부분 위도를 커버.
  - 4 MD Demonstration Tracking SVs - **새로운 미사일 추적 기술 시범용** 위성들
  - 2 OCTs - 위성 한 기당 OCT 2개 장착

    - **K****A****, S****TTC**

      - KA-band RF 통신,
      - STTC = S-band Telemetry, Tracking & Command (위성 상태 전송·명령 수신용).
  - 28 MT/MW Tracking SVs - 정식 운용형 미사일 경보·추적 위성 28기, 4개 궤도면에 배치

    - IR MW/MT Payload

      - 미사일 경보/추적용 적외선 센서 탑재
    - **3 OCTs**

      - 위성당 OCT 3개 → 다른 위성과 **다중 레이저 크로스링크** 구성.
      - KA**, S**STTC 동일.
  - 126 Transport SVs (6 Planes, BLOS) - **Transport Layer** 위성 126기, 6개 궤도면. BLOS(Beyond Line Of Sight - 지평선 너무 전술 데이터 링크 제공을 의히함)

    - **4 OCTs**

      - 위성당 OCT 4개 → 위성-위성 레이저망의 **백본**.
    - **BMC****3**

      - Battle Management, Command, Control → 전장 지휘·통제 기능용 페이로드 일부 포함.
    - **LINK-16**

      - 지상·공중 플랫폼에서 사용하는 NATO 전술 데이터링크(Link-16)를 직접 위성에서 중계한다는 의미.
    - **S****TTC**

      - 마찬가지로 S-band Telemetry/Command.
  - **위성망 기능 설명**

    - IR Missile Warning and Tracking with Global Access

      - Tracking 위성이 쏘는 초록색 빔 + 텍스트.
      - 전 세계 어디에서 발사되든 IR로 미사일을 감지·추적한다는 의미.
    - Direct Downlinks to Theater Targeting Cells

      - 위성에서 바로 전장 근처(극장, theater)의 타겟팅 셀(사격통제/표적팀) 에 데이터 내려보내는 링크.
      - 즉, 중앙 본토 거치지 않고 현장 지휘소로 바로 미사일 정보 전송.
    - Beyond Line of Sight Tactical Data Link Connectivity

      - Transport Layer 위성에서 전술플랫폼(지상부대, 함정, 항공기)으로 가는 연결.
      - BLOS → 지평선 뒤, 산 뒤에 숨어있어도 위성 통해 서로 통신할 수 있다는 것.
    - Low-Latency High-Volume Data Transport with Optical Cross-Links

      - 위·아래 파란 곡선들과 함께 쓰인 문구.
      - 레이저 크로스링크(OCT) 로 위성들끼리 엄청난 데이터량을 낮은 지연으로 전달하는 백본
    - Secure Multi-Domain Optical Communications

      - → 이 레이저 링크가 단순 “위성-위성”이 아니라 공중, 해상, 지상, 우주(멀티 도메인) 모두를 연결하는 암호화된 네트워크로 확장될 것이라는 메시지.

- - 미국에서 방산 산업계 및 국방정책을 전문으로 다루는 산업 협회 산하의 매체인 National Defense에서 밝힌 PWSA의 현재 진행상황.

**📌 핵심 요약**

|  |  |
| --- | --- |
| **내용** | **의미** |
| SDA & 산업 파트너들이 **상호운용되는(Interoperable) 레이저 통신 네트워크** 개발 속도를 크게 끌어올림 | 여러 업체의 위성이 **서로 레이저 데이터 링크로 연결**될 수 있게 됨 |
| GAO는 조기 투자 위험을 경고했으나, **기술 개발 속도가 예상보다 빠르게 진행 중** | 실전 배치 시점이 앞당겨질 가능성 |
| Tranche 1 첫 21기 발사 / 총 154기 예정 / 초기 전투능력 2027년 목표 | **Golden Dome 기반 우주 백본 실체화** |
| **우주–지상–항공기 간 레이저 통신 실험 성공** | 전장 실시간 저지연 C2 가능 |
| 표준화된 광통신 단말기(Enterprise Space Terminal) 개발 | 여러 기업 참여 → 독점 방지·속도 향상 |
| “10년간 말만 하던 것이 현실화” | **게임체인저 기술의 실전 도입 선언** |

**🚀** **Golden Dome 성공의 핵심은 “초저지연 초고속 데이터 이동”**

- - 극초음속 요격 성공 여부 = **탐지 → 추적 → 의사결정 → 요격** 사이 시간 싸움
  - 전통 RF 통신은 **지연·혼선·재밍 취약**
  - 레이저 통신은 **광속, 암호화, 방향성, 재밍불가 특성**

> **레이저 크로스링크 네트워크가 완성되면, Golden Dome은 실전 가능성이 생긴다.**

---

> Golden Dome 프로젝트에는 다양한 항목들이 존재하지만, SDA에서 진행하는 PWSA는 Golden Dome의 핵심이 되는 **두뇌와 눈을 포함하는 신경망을 제공**하기 때문에 그 의미가 남다르다.
>
> 다음편에서는 PWSA의 핵심을 담당하게 되는 기술을 살펴보도록 하겠다.
