**✅****EO/IR 센서**

- - **미군·SDA·MDA 문서에서 대부분 “EO/IR 센서”라고 쓰면서 실제 스펙은 IR 중심으로 공개**하는데, 그 이유는 두 가지다:

    1. **실전 미사일 경보·AMTI 핵심 성능은 IR(특히 MWIR/LWIR)에서 나온다**
    2. **EO(visible/near-IR) 채널은 보조 채널**로 활용되며, 자세한 광학/분해능 스펙은 군사기밀로 묶이기 때문
  - 즉, “EO/IR”이라고 부르는 이유는 **둘이 항상 함께 운용**되기 때문이고, 공개되는 숫자(해상도·NEI·냉각·파장)는 대부분 **IR 중심**이다.

**◆ EO(Optical / Visible) 채널은 실제로 어떻게 동작하나?**

|  |  |  |
| --- | --- | --- |
| **기능** | **IR 센서** | **EO 센서(Visible/SWIR)** |
| 탐지(Detection) | 고열 플룸, 공력 가열, 미사일/항공기 열신호 | **형상·윤곽·배경 대비**, 다중 스펙트럼 색 채널 |
| 추적(Tracking) | 열시그니처 기반 추적 | **형분석, AI 기반 분류** |
| 환경 영향 | 구름·연기·폭풍 영향 큼 | 낮/밤, 기상 제한 일부 있으나 SWIR로 보완 가능 |
| 역할 | **primary** | **refinement / classification** |
| 주요 장점 | long-range, high-sensitivity | **확실한 식별(positive ID)** |

- - **IR로 탐지·트랙을 만들고 EO로 식별한다.**
  - = **SAR(탐지) → IR(추적) → EO(식별)**

****

**◆ EO 채널 구성 방식 (위성 AMTI 기준)**

- - **Wide-FOV EO 카메라 (상황인식)**

    - 넓은 지역 스캔
    - 목표 후보 탐색 및 배경 변화 제거
  - **Narrow-FOV High-Resolution EO 센서 (Positive ID)**

    - 목표를 확대하여 기체 윤곽/날개/플룸/기동 분석
    - 인공지능 기반 **classification model** 수행
  - **Multi-spectral 필터 또는 SWIR (1–2.5 µm) 채널**

    - 연기·구름·먼지 관통 능력 향상
    - IR과 EO 사이 gap bridging
  - 그래서 AMTI 위성의 카메라는 이런 구조를 가진다:
  - [Wide FOV EO] → 탐색 / 배경 분석 [IR MWIR/LWIR] → 첫 탐지 / 추적 / 기동성 [EO Narrow FOV] → ID / 정밀 분석

> **FOV(Field of View)란?**
>
> **센서(카메라, IR, 레이더)가 한 번에 볼 수 있는 공간적 영역의 각도 범위**
>
> **즉, 얼마나 넓게 볼 수 있는가를 의미하는 각(Angle) 단위 값.**
>
> **FOV는 “얼마나 넓게 보느냐 vs 얼마나 선명하게 보느냐”의 균형 문제이며,**
>
> **우주 AMTI/HBTSS는 Wide-FOV 탐지 + Narrow-FOV 정밀추적 구조로 작동한다.**

**✅****AMTI 우주 센서의 기본 요구사항 (개념 정리)**

- - AMTI 위성은 결국 **공중 표적 GMTI + 미사일 경보를 합친 느낌**이라 EO/IR 쪽은 대략 이런 방향의 스펙이 필요하다고 보면 된다.

    - **파장대**

      - 기본: **MWIR(3–5 µm)**, **LWIR(8–12 µm)**
      - → 로켓/제트 플룸·극초음속 공력가열 시그니처에 민감하고, 대기 투과창에 맞음.
      - 일부는 **SWIR/Vis** 채널을 추가해서 구름/지상 클러터 구분, 다중색 분광(MCIR)로 오경보 줄임.
    - **센서 구성**

      - **Wide FOV 스캐닝 센서** + **좁은 FOV 스테어링(스타링) 센서** 조합이 전형적
      - 예: SBIRS GEO 페이로드는 “지구반구 스캐너 + step-stare 센서” 이중 구조.
      - AMTI는 여기서 한 단계 더 가서, 고프레임률 + 고정밀 포인팅으로 **항공기/극초음속 표적 “연속 추적(birth-to-death)”** 수행이 요구됨.
    - **FPA(초점면 어레이)**

      - 해상도: 최소 **1k×1k 이상**, 차세대는 **2k×2k 이상** 대형 포맷이 일반화
      - Teledyne H1RG: 1024×1024, 18 µm 픽셀
      - Teledyne H2RG: 2048×2048, 18 µm 픽셀, 0.6–5 µm NIR/MWIR용으로 우주·천문에 널리 사용.
      - 소재: **HgCdTe(MCT)** / **T2SL(superlattice)** 계열이 주력 – 고양자 효율, 저 암전류.
    - **냉각 & 내우주환경**

      - 온도: 대개 **70 K 전후** 극저온, **Stirling cryocooler** 사용.
      - 방사선 내성: LEO 장기 운용 기준으로 TID·SEU 대응 설계 (MIT LL “Affordable MWIR sensors for LEO missile tracking” RFP에도 명시).
    - **처리**

      - 위성 탑재 **온보드 처리**로 트랙 추출 후 링크 전송 (AMTI·HBTSS 모두 “weapons-quality track” 언급).

**✅****FPA·디텍터의 기본 개념**

- - FPA(Focal Plane Array)란 형태학적으로, 광학계가 맺히는 **초점면(focal plane)** 위에 배열된 다수의 디텍터 픽셀들(2차원 격자 형태)이며, 적외선(IR) 또는 가시/근적외선(EO) 신호를 전기신호로 변환하는 장치다.
  - 디텍터 요소(material) → 어레이화 → 냉각/패키징 → ROIC(Read-Out Integrated Circuit)과의 결합(bonding) → 어셈블리 형태로 우주선 탑재가 가능하도록 설계된다.
  - 우주·미사일추적용 IR 센서에서는 다음 요소가 성능에 직결된다:

    - 픽셀 수(해상도)
    - 픽셀 피치(pixel pitch)
    - 암전류(dark current) 및 노이즈(noise)
    - 양자효율(quantum efficiency)
    - 냉각온도(cooler temperature)
    - 방사선 내성(radiation hardness)
    - 리드아웃 속도(read-out rate) 및 지연(latency)
    - 센서 패키징 크기, 전력 소비, SWaP-C(소형/전력/냉각/비용)

**💡****왜 이러한 사양이 필요한가?**

- - 극초음속 미사일의 경우 **열 신호가 작고 빠르게 이동**하므로, 높은 감도 + 큰 해상도 + 빠른 읽출이 필수.
  - 위성 궤도에서는 냉각·전력·중량 제약이 크므로, SWaP-C( Size, Weight, Power, Cost)가 매우 중요한 설계 요소.
  - 요격용 트랙 데이터(weapons-quality track)를 제공해야 함 → 단순 탐지가 아니라 **정밀 추적**이 가능해야 한다.

**✅****FPA·디텍터 레벨 주요 업체 (AMTI 센서의 “심장부”)**

**(1) Teledyne Imaging Sensors (TIS)**

- - 제품

    - **H1RG**: 1024×1024, 18 µm 픽셀, 0.4–10 µm 지원.

    - **CHROMA-D** 계열: 400 nm 아래 UV부터 14.5 µm LWIR까지 커버 가능한 HgCdTe 디텍터.
  - 특성

    - QE 80–90%, 저 암전류, 고방사선 내성 – 우주·미사일경보용에 적합.

**(2) Lynred (프랑스) / Lynred-USA**

- - 제품

    - SWIR~VLWIR 전체 커버 IR 디텍터, **MWIR/LWIR 대형 FPA** 제공.
    - Sentinel-2 NG용 대형 MCT 라인 센서 (2000픽셀 × 5~6라인, 15 µm pitch) – 우주급 패키징.
  - 용도

    - 지구관측·환경모니터링·미사일경보 위성까지 포함한 우주 프로그램에 다수 채택

**(3) AIM Infrarot-Module (독일)**

- - 역할

    - 고급 IR 디텍터·열영상기·Stirling 냉각기 제조, **미사일 시커·항공기·지상·우주 플랫폼**용으로 공급.

**(4) Raytheon Vision Systems (RVS)**

- - NASA Webb MIRI용 **Si:As 5–28 µm 디텍터** 제작, 우주 LWIR·OPIR 계열에 강점.

**✅****SAR (****Synthetic Aperture Radar) - 합성개구레이다**

- - **SAR 자체는 AMTI 센서의 한 종류로 분류될 수 있지만**, **EO/IR AMTI와는 역할과 접근 방식이 완전히 다르다.**
  - 즉, AMTI (공중 이동 표적 지시/추적)이라는 임무 범주이고, 그 임무를 수행하기 위한 센서 중 하나가 **SAR GMTI/AMTI 모드**이며, 다른 하나가 **EO/IR AMTI(열추적·광학추적)** 이다.

**■ SAR와 EO/IR 비교**

|  |  |  |
| --- | --- | --- |
| **구분** | **EO/IR AMTI** | **SAR AMTI (SAR-GMTI)** |
| 기반 기술 | 열/광학 | 레이더 (Synthetic Aperture Radar) |
| 파장 | MWIR / LWIR / SWIR | X-band, Ka-band, Ku-band 등 |
| 주요 목표 | **제트 플룸·극초음속 열신호 / 항공기 시그니처** | **운동하는 물체의 도플러 변화 감지** |
| 환경 | 날씨·구름 영향 큼 | **모든 날씨·주야·연기·구름 관측 가능** |
| 장점 | 정확한 표적 식별·해상도 우수 | **wide-area moving target detection** |
| 단점 | 구름/날씨 제한 | 표적 분류 능력은 EO/IR 대비 약함 |
| 적용 위치 | SDA Tracking Layer, HBTSS | **Custody Layer SAR 위성, Capella/ICEYE/Synspective** |

> SAR GMTI/AMTI는 도플러 변화를 통해 움직이는 표적을 분리하고
>
> **EO/IR AMTI는 열 신호 기반으로 표적을 추적한다.**

**■ 왜 EO/IR AMTI + SAR AMTI가 모두 필요한가**

- - **공역(air domain) 표적 추적 복잡성 해결**

    - 공중 표적은 지상이나 바다처럼 고정 배경이 없다.
    - EO/IR은 **표적 특성(열신호) 분류**가 좋지만, 구름·연기·기상 취약.
    - SAR GMTI는 **날씨 상관없이 넓은 영역에서 움직이는 표적 탐지**가 가능.
  - **최종 요격/사격 결심을 위해선**

|  |  |  |
| --- | --- | --- |
| **단계** | **센서** | **이유** |
| 탐지 | **SAR GMTI** | 넓은 지역, 날씨 무관 탐지 |
| 추적 / 식별 | **EO/IR AMTI** | 플룸/형상 기반 구분 |
| 요격용 fire-control | **EO/IR + RF 융합** | 정확한 기동 정보 제공 |

> 그래서 **SDA Tracking Layer + Custody Layer + Golden Dome AMTI** 설계는
>
> SAR + EO/IR + RF + OISL 데이터 융합을 기본철학으로 한다.

**■ Capella / ICEYE 같은 SAR 위성이 Golden Dome AMTI에 중요한 이유**

|  |  |
| --- | --- |
| **회사** | **기술 역할** |
| **Capella Space** | X-band **spotlight SAR**, 25cm급 해상도, future **Air-resilient GMTI** 계획 |
| **ICEYE** | 전술 ISR + moving target detection 연구, 신속 tasking |
| **Umbra** | Ka-band SAR – 고해상도 |
| **MDA / Maxar** | 군용 GMTI/SAR 전통 강자 |

> EO/IR AMTI는 현재 **L3Harris / NG / Raytheon / Lockheed / Leonardo DRS**가 중심이고
>
> SAR 쪽은 **Capella / ICEYE / Umbra / MDA**가 연결될 가능성이 큼.

**✅****참고 1. SWIR**

- - **SWIR = Short-Wave Infrared (단파 적외선)** 의 약자다.
  - 센서나 카메라 분야에서 **약 0.9 µm ~ 2.5 µm** 파장 영역을 의미한다.

**📌 SWIR(Short-Wave Infrared) 정의**

|  |  |  |
| --- | --- | --- |
| **파장 밴드** | **대역** | **설명** |
| **NIR** | 0.7–1.0 µm | 가시광 근처, 일반 근적외선 |
| **SWIR** | **0.9–2.5 µm** | **단파 적외선**, 관측·영상·군용 ISR 핵심 밴드 |
| **MWIR** | 3–5 µm | 중파 적외선, 열(thermal) 영상의 주요 영역 |
| **LWIR** | 8–12 µm | 장파 적외선, 열 탐지 및 미사일 경보 핵심 |

- - 즉, SWIR은 **가시광보다 약간 긴 적외선 영역**으로, **열영상(thermal)** 을 직접 잡지는 않지만, 빛의 **반사(reflectance)** 를 이용해 영상화하는 영역이다.

**🌟 왜 SWIR이 중요한가?**

- - **구름·안개·연기 관통 능력**

    - 가시광은 구름·연기에 산란됨
    - SWIR은 산란이 적어서 **투시 영상** 확보 가능
  - **야간에 별빛·달빛만으로도 영상 획득 가능**

    - SWIR 센서는 **천연 광원(밤하늘 배경광)** 을 활용
    - 완전한 열센서(MWIR/LWIR)보다 비용·전력 저감
  - **물/습기 반사 특성 식별**

    - SWIR은 물과 건조함의 반사율 차이가 극명
    - **위장·위폐·습도 패턴·도색 위장 탐지**
  - **다중 스펙트럼 영상(분광정보 분석)**

    - 식별/분류 기능 강화 → AI 모델과 결합하면 전투기 유형 식별에 활용

**⚔ 국방·우주 분야에서 SWIR 용도**

|  |  |
| --- | --- |
| **임무** | **역할** |
| **AMTI / EO 보조 채널** | IR만으로 분류 어려운 표적 확인 |
| **극초음속 표적 shock cone 분석** | 플라즈마 경계 시각화 보조 |
| **SAR GMTI 연동** | SAR에서 탐지한 후보 표적 EO-SWIR로 확인 |
| **위장 탐지 / 오경보 제거** | 열원 오탐(폭염지대/반사) 제거 |
| **야간 ISR** | passive imaging 가능 |

- - 그래서 실제 **AMTI EO/IR 센서 스택 구성**은 이렇게 된다:

    - Wide EO (Visible)
    - Wide SWIR (투시/날씨 관통)
    - MWIR (기본 탐지/추적)
    - LWIR (열 시그니처 분석)
    - Narrow EO/SWIR (ID, classification)

**✅****참고 2. HBTSS (Hypersonic and Ballistic Tracking Space Sensor)**

**💡** **프로그램 개요**

- - HBTSS는 “Hypersonic and Ballistic Tracking Space Sensor”의 약자이며, 고체·극초음속 글라이드체(HGV) 및 전통 탄도미사일을 포함한 미사일 위협을 **발사부터 요격까지(“birth-to-death”) 추적**하기 위한 위성 기반 센서 체계다.
  - 이 프로그램은 미국 MDA가 주도하며, SDA의 Tracking Layer 구조와 연계되어 있다.
  - 주요 기능:

    - 고감도, 저지연 미사일 트랙을 제공 → 요격 통제(fire-control)용 데이터 지원.
    - 전지구 커버리지(near-global) 및 위협 발사 직후부터 감시 가능.
  - 주요 일정:

    - 2024년 2월 14일, MDA/SDA가 HBTSS 위성 2기 + SDA 트래킹 레이어 위성 4기를 발사.
    - 2025년 이후부터 본격 운용 및 조기 생산 얘기가 등장.

**💡** **임무·운용 구조 및 역할**

- - HBTSS는 기존의 경보(Warning) 위성 + 지상 레이더 + 미사일 궤적 추적 수단을 보완하는 **추적(Tracking) 레이어**다.
  - 역할 상세:

    - 발사 감지 → 궤도 및 기동 변화 추적 → 요격 준비를 위한 정밀 트랙 확보.
    - 지상·해상·공중 발사 모두 대상 (land/sea/air) 사용.
    - 다계층 우주 감시 구조 내에서 중추적 센서 역할: GEO/MEO 경보 위성 → HBTSS(LEO/MEO) → 지상/해상 요격체계.

**💡** **기술·센서 사양 및 특징**

|  |  |
| --- | --- |
| **항목** | **내용** |
| 센서 유형 | 다채널 적외선(IR) 센서 + 광학/센서 융합형으로 “dim target detection” 가능 설계. |
| 추적 품질 | “weapons-quality track for fire control”이 명시됨. |
| 감도 및 지연 | 고감도 + 저지연(low latency)가 핵심 설계 요건. |
| 궤도 및 커버리지 | 처음에는 저지구궤도(LEO) 기반, 여러 단계(Tranche)로 확장하면서 중지구궤도(MEO) 포함 가능성 있음. |
| 개발/생산 타임라인 | 프로토타입 위성 2023–24년 런칭, 2025년 이후 양산·운용 확대 언급됨. |

**💡** **AMTI(공중이동표적지시)와의 연계**

- - AMTI 미션이 항공기·극초음속 비행체·미사일 등의 이동 표적을 탐지·추적하는 데 있다면,
  - HBTSS는 이 중 **미사일/극초음속체**에 초점을 맞춘 우주 기반 센서 시스템이다.
  - 특히 AMTI용 위성 체계 설계 시 HBTSS의 기술 요소(고감도 IR, 저지연 트랙, 우주 기반 연속 추적) 등이 핵심 참조점이 된다.
  - 즉, AMTI 위성 설계 시 “HBTSS급 IR 센서 + EO/EO-IR 보조 채널 + SAR/EO 융합”이 하나의 **모델 아키텍처**가 된다.

**💡** **왜 중요하고 무엇이 도전인가**

- - **중요성**

    - 기존 지상 레이더·해상 센서로는 극초음속 미사일의 **기동 궤적 변경 + 낮은 고도 비행**을 완전히 잡기 어렵다.
    - HBTSS 같은 우주센서는 이러한 위협을 더 초기에 탐지·추적 가능하다.
    - 미사일 요격(특히 극초음속 글라이드체)을 위한 최종 트랙 데이터 확보는 승패를 좌우함.
  - **도전 과제**

    - 매우 짧은 탐지 대기 시간, 궤도 내 빠른 기동 표적 대응, 고감도/고해상도 센서 설계.
    - 위성군(proliferated constellation) 구축 및 비용·중량·전력(SWaP-C) 제약.
    - 기밀성 및 적응 위협(전쟁 상태에서 위성 파괴·교란) 대비한 탄력성 설계 필요.

**💡** **향후 전망**

- - 2025년 이후부터 HBTSS 센서의 **상용화 및 대량 양산** 단계로 진입 중. L3Harris가 “Full-rate production 준비됨”이라 발표함.
  - SDA의 Tracking Layer Tranche 1·2 설계에 HBTSS 기술이 **기준(reference)** 으로 포함됨.
  - AMTI/미사일 추적 시장에서 위성센서의 역할이 크게 확대될 전망.
