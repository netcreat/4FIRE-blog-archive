**💡****연구 배경**

- - **목표:** 양자 인터넷(Quantum Internet)을 위한 **다중 노드 양자 네트워크** 구축 가능성을 검증한다.
  - **문제점:**

    - 기존 연구 대부분은 2광자 얽힘(Bell 상태)만 분배.
    - **4광자 이상 다중 얽힘**을 실제 도시 상용 광통신망에서 분배한 사례가 전무.
    - 환경 잡음, 광손실, 동기화 오차 등으로 실험 난도가 높음.

**💡****실험 환경**

- - **실험 장소:** EPB–IonQ **Bohr-IV 양자 네트워크** (미국 테네시주 채터누가)
  - **네트워크 구성:**

    - EPB, IonQ, UTC(University of Tennessee Chattanooga) 공동 운영.
    - 5개 노드(A1~A3, B1, B2) → 향후 10개 노드로 확장 예정.
    - **C-band(1530~1570nm)** 상용 광섬유 인프라 활용.
    - 네트워크 재구성이 가능한 QNIC(Quantum Network Interface Console) 사용.

- - - **빨간 노드 (Equipment Hub A, B, C, D)** **→ 네트워크 “허브”**

      - **EPB 광섬유를 통해 상용 백본 역할**
      - **경로 라우팅, 신호 안정화, 손실 최소화**
      - **QNIC(Quantum Network Interface Console) 장착 → 원격 제어 가능**
    - **녹색 노드 (User Lab IonQ, User Lab UTC)** **→ 양자 실험 “엔드포인트”**

      - **UTC → 얽힘 생성 및 분배 주도**

        - 광자 얽힘 생성 장치(BPS, Fusion 빔스플리터)와 **SNSPD 검출기**를 보유
      - **IonQ → 얽힘 수신 테스트 및 향후 QPU 연동 준비**

        - **향후 IonQ QPU ↔ QPU 포토닉 인터커넥트 실험을 위한 노드**로 준비 중
  - **광원:**

    - Qubitekk사의 **Type-II SPDC 양자광원**, 1570nm 대역.
    - 단점: 낮은 얽힘 비율(~17%), 비수정 가능(상용 패키지형).
  - **검출기:** SNSPD (Superconducting Nanowire Single-Photon Detector).
  - **실험 구조:** 완전 광섬유 기반(beam splitter, PBS, VDL 등 전부 광섬유 결합).

****

**💡****핵심 기술**

- - **4-광자 Fusion 연산**

    - **원리:** 두 쌍의 Bell 상태를 생성 → 50/50 빔스플리터에서 결합 → 4광자 얽힘 상태 형성.
    - **성공 확률:** 약 **1/32** (낮음).
    - **Hong–Ou–Mandel(HOM) 효과** 활용 → 동일 편광 광자는 동위상 간섭으로 얽힘 상태 형성.
    - **결과:**

      - 국소 보유 광자 두 개(b,d)의 편광을 조절하면,

        - **같은 편광** → **N00N 상태** 생성
        - **서로 다른 편광** → **Bell 상태** 생성
  - **Bell 상태 vs N00N 상태**

|  |  |  |
| --- | --- | --- |
| **구분** | **Bell 상태** | **N00N 상태** |
| **특징** | 입자-입자 얽힘 | 경로-경로(Mode-Mode) 얽힘 |
| **표현식** | |HV⟩ - |VH⟩ | |2H⟩ - |2V⟩ |
| **활용** | 양자 통신, QKD | 위상 민감 양자센싱, 초해상 간섭계 |
| **생성 방식** | b,d 편광 **교차** 설정 | b,d 편광 **동일** 설정 |

**💡****주요 실험 결과**

- - **Bell 상태 분배**

    - UTC에서 b,d 편광을 교차 설정 → e,f 광자가 Bell 상태로 얽힘.
    - e,f 광자를 **TQN(Tenth Street Quantum Node)**과 **BQN(Broad Street Quantum Node)** 노드로 각각 전송.
    - **얽힘 검증:** LCVR 기반 위상 제어 + 편광 분석.
    - **얻은 충실도(Fidelity):** 0.62 ~ 0.66
    - → 환경 잡음 및 네트워크 손실 때문에 다소 낮음.
  - **N00N 상태 분배**

    - b,d 편광을 동일 설정 → e,f 광자가 N00N 상태로 얽힘.
    - HOM 간섭 패턴으로 얽힘 상태 확인.
    - **위상 민감도 측정(Heisenberg Limit):** 실험 조건상 측정 불가, 추후 연구 예정.
  - **네트워크 성능**

    - **광손실:**

      - UTC ↔ TQN: 약 **5 dB**
      - UTC ↔ BQN: 약 **10 dB**
      - 전체 네트워크 손실: **15 dB** 수준.
    - **4광자 분배 속도:**

      - **국소(UTC):** ~94 상태/초
      - **원격(TQN+BQN):** 약 **1상태 / 15초** (0.07Hz)
      - 실험 1회당 수 시간 데이터 적산 필요.

**💡****한계점 및 향후 계획**

- - **문제점**

    - 낮은 광원 품질(17% Bell 쌍 비율)
    - 광손실 및 네트워크 재구성 스위치 삽입 손실(5~10dB)
    - 실험 데이터 적산 시간 과다
    - 다중 노드 동기화 미구현
  - **개선 계획**

    - **광원 업그레이드:**

      - NuCrypt EPS 시리즈 또는 Sagnac 기반 SPDC → 공간 비축퇴(spatial non-degeneracy) 확보.
    - **광스위치 개선:**

      - EPB 상용 광스위치 교체 → 손실 최소화(2026년 예정).
    - **동기화 강화:**

      - White Rabbit 프로토콜 기반 **서브나노초 시각 동기화** 적용.
    - **실시간 편광 제어:**

      - 자동 편광 안정화(Auto Polarization Control) 도입.

**💡****의의**

- - 세계 최초로 **실제 상용 메트로급 네트워크**에서 **Bell/N00N 상태를 선택적으로 분배**.
  - **양자 인터넷(Quantum Internet)** 구축을 위한 핵심 실험.
  - 다중 노드 얽힘 네트워크로 확장 가능성을 입증.

**✅****로컬 얽힘 원격 분배**

- 이번 논문에서 다룬 실험은 실제 IonQ QPU(Quantum Processing Unit)를 사용한 **양자 비트(qubit) 얽힘 실험**은 아니다.
- 즉, **IonQ 노드**에서 **이온트랩 기반 큐비트 얽힘**을 수행한 게 아니라, **광자 얽힘 실험**을 상용 네트워크 인프라에서 진행한 것이다.
- IonQ는 이번 실험에서 **네트워크 노드**와 **상용 광섬유 인프라**를 제공하는 역할에 가깝다.
- 이번 실험의 의미는

  - 상용 네트워크에서 **Bell/N00N 상태를 동시에 제어 가능**
  - 4광자 얽힘을 사용해 **다중 상태 분배 실험**을 시연
  - IonQ QPU 네트워크화를 위한 **사전 테스트베드 실험**이라는 전략적 의미 보유

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA5MDhfNTEg/MDAxNzU3MzEyNzA1NDYw.7FGqoNckSvI8rM34YEvgSk1FeW-cIx3N-P9zTZQLloUg.-3lOxjATXDABhhNHh-2Ck1v_rpjG0XOT1k8kv-II0iMg.PNG/image.png?type=w800)](#)

단일 Bi-Photon Source(BPS)에서 생성된 두 개의 Bell 상태 쌍을 **Fiber-coupled Beam Splitter(BS)** 네트워크를 통해 **4광자 얽힘 상태**로 Fusion(결합)한 뒤, 이 얽힘 상태를 세 개의 노드(UTC, TQN, BQN)로 분배하는 과정을 보여준다.

****

**💡****그림 설명**

- - **SPDC 광원(BPS)은 두 쌍의 Bell 상태를 생성한다.**

    - **광자 a, b** → 첫 번째 광자 쌍
    - **광자 c, d** → 두 번째 광자 쌍
  - 생성된 네 개의 광자는 이후 세 개의 50/50 광섬유 빔스플리터(BS)를 통과한다.
  - 네 개의 광자가 동시에 최종 빔스플리터에 도달하여 얽힘 상태를 형성할 확률은 **1/32**이다.
  - 여기서 **모드 a, b, c, d** 중 **a**와 **c**는 최종 Fusion 빔스플리터로 입력되고, **b**와 **d**는 영향을 받지 않은 채 남는다.
  - 50/50 빔스플리터는 입력 모드 a,c의 생성 연산자를 출력 모드 e,f로 변환한다.
  - **HOM 효과**에 따르면, 동일한 편광을 가진 두 광자가 빔스플리터에 동시에 도달하면, 두 광자가 **항상 같은 출력 포트**로 함께 나가게 된다(**Photon bunching**).
  - **Bell 상태와 N00N 상태 제어**

    - 편광 상태에 따라 결과적으로 두 가지 상태를 선택적으로 생성할 수 있다:
    - **같은 편광(HH 또는 VV)** → 출력 모드 e,f는 **N00N 상태**를 형성
    - **서로 다른 편광(HV 또는 VH)** → 출력 모드 e,f는 **Bell 상태**를 형성
    - **국소적으로 유지한 b, d 광자의 편광 설정만으로** 네트워크 상에서 원격 노드(TQN, BQN)에 **Bell 상태** 또는 **N00N 상태**를 자유롭게 분배할 수 있다.

**💡****광자 라벨링**

|  |  |  |
| --- | --- | --- |
| **광자** | **위치** | **역할** |
| **a** | UTC 내부 | Fusion 입력 1 |
| **b** | UTC 내부 | **국소 유지, 편광 설정** |
| **c** | UTC 내부 | Fusion 입력 2 |
| **d** | UTC 내부 | **국소 유지, 편광 설정** |
| **e** | **TQN 원격 노드** | 얽힘 상태 전송 대상 |
| **f** | **BQN 원격 노드** | 얽힘 상태 전송 대상 |

- - **f** 광자는 **BQN 노드**로, **e** 광자는 **TQN 노드**로 전송되고, 이 두 광자(e, f)는 **국소적으로 유지된 b, d 광자와 얽혀 있는 상태**
  - 즉, b·d의 편광을 어떻게 설정하느냐에 따라 원격 노드(TQN, BQN)로 분배되는 e·f의 얽힘 상태가 **Bell 상태**인지 **N00N 상태**인지가 결정
  - b와 d는 UTC에 남아 있지만, **b·d의 편광 설정이 원격 e·f 상태를 제어**다.
  - 즉:

    - b, d = HV/VH → TQN·BQN은 **Bell 얽힘** 수신
    - b, d = HH/VV → TQN·BQN은 **N00N 얽힘** 수신

**✅SPDC (Spontaneous Parametric Down-Conversion, 자발적 매개변수 하향 변환)**

**💡** **BPS (Bi-Photon Source)**

- - **Qubitekk SPDC 기반 광원**으로, 단일 장치지만 **동시에 두 개의 Bell 상태 쌍을 생성**.
  - SPDC에는 **Type-0, Type-I, Type-II** 세 가지 주요 타입이 있고, Bohr-IV 논문에서 사용된 **Type-II SPDC**는 서로 직교하는 편광(H/V)을 가진 광자 쌍을 생성하기 때문에 선택된 것
  - PDC는 결정에서 위상정합 조건(phase-matching condition)에 따라 세 가지로 나뉜다.

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **편광 관계** | **생성되는 광자 특징** | **응용 분야** |
| **Type-0** | 펌프, 신호, 아이들러 **모두 같은 편광** | 동일 편광 광자 쌍 생성 | 고효율 단일광자 원천, 양자광원 집적회로 |
| **Type-I** | 펌프광자 ↔ 쌍광자 **서로 직교**, 쌍광자 **서로 동일 편광** | 같은 편광(HH 또는 VV) | 높은 생성 효율, QKD |
| **Type-II** | 펌프광자 ↔ 쌍광자 직교, **쌍광자끼리도 직교(HV)** | **서로 다른 편광(H, V)** 얽힘 생성 | **Bell 상태, 편광 얽힘 실험**에 최적 |

**✅****Bohr-IV 네트워크의 기능**

**💡Bohr-IV 네트워크가 제공하는 핵심 역할**

- - Bohr-IV 네트워크는 이번 논문에서 **광자 얽힘 분배 인프라**로 사용됨.
  - IonQ는 이번 실험에서 QPU 대신 **네트워크 노드(B2)** 역할만 수행.
  - 하지만 Bohr-IV는 단순한 테스트베드가 아니라, 향후 **IonQ QPU 간 포토닉 인터커넥트** 실험을 위한 **양자 인터넷 플랫폼**으로 발전할 예정.

    - White Rabbit (WR) 프로토콜 도입 예정
    - **White Rabbit**:

      - CERN에서 개발한 **서브-나노초(sub-ns)** 레벨의 고정밀 시각 동기화 기술.
      - IEEE 1588 Precision Time Protocol(PTP) 기반.
  - 이번 논문은 Bohr-IV가 **다중 노드 얽힘 분배를 지원할 수 있는지**를 검증하는 **1단계 실험**이라고 보면 된다.

**💡****Bohr-IV에서 향후 Lightsynq 통합 시 변화**

- - 현재 Bohr-IV는 **Qubitekk Type-II SPDC**를 사용하는데, IonQ가 **Lightsynq 단일광자 원천**을 통합하면 상황이 바뀐다.

|  |  |  |
| --- | --- | --- |
| **항목** | **현재 Bohr-IV(Qubitekk)** | **Lightsynq 통합 후** |
| 광원 | Type-II SPDC (확률적) | NV·SiV 기반 단일광자 원천 (결정적) |
| 편광 제어 | 필요 | 불필요 (직접 Bell/N00N 상태 생성 가능) |
| 성공 확률 | ≈1/32 | 이론적으로 **>80%** 가능 |
| 응용 | Bell/N00N 상태 분배 검증 | 고속 다중 QPU 네트워크 가능 |
