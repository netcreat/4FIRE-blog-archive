# 노이즈 최소화 기술이 양자 에러율을 바꾼다

양자컴퓨터의 세계에서 '노이즈'는 최대의 적이다. 아무리 혁신적인 양자 시스템을 설계해도 노이즈를 통제하지 못하면 모든 계산이 물거품이 된다. 이 글에서는 노이즈가 양자 에러율에 어떤 영향을 미치고, 이를 극복하기 위한 최신 기술들을 살펴본다.

****

**🌪️양자 컴퓨팅에서 자주 등장하는 '노이즈'가 뭘까?**

[![](https://gazetai.s3.ap-northeast-2.amazonaws.com/info_v2/eab35315-0852-4b7d-c526-90076cf8fccd/1751032265152_1751032650_2.jpeg)](#)

양자 컴퓨팅에서 노이즈란 원치 않는 외부 간섭을 말한다. 일상에서 라디오 주파수가 방해받으면 '지지직' 소리가 나는 것처럼, 양자 시스템도 외부 환경(온도 변화, 전자기파, 물리적 진동 등)에 민감하게 반응한다.

양자 상태는 매우 연약해서 주변 환경과의 상호작용으로 쉽게 '디코히런스(decoherence)'라는 현상이 발생한다. 이는 큐비트가 양자 중첩 상태를 유지하지 못하고 고전적인 상태로 붕괴하는 현상이다.

> 코히런스(Coherence)는 양자 상태가 일정한 위상 관계를 유지하여 결맞음 상태가 된 것이라면 디코히런스(Decoherence)는 큐비트가 외부 환경과 상호작용하여 결맞음을 잃는 현상을 가리킨다.

양자컴퓨터의 성능은 이런 노이즈를 얼마나 잘 제어하느냐에 달려있다. 충실도(fidelity)가 높은 시스템일수록 의도한 양자 연산을 정확히 수행할 수 있다. 노이즈는 결국 양자컴퓨터의 에러율을 직접적으로 높이는 주범이다.

****

**📉노이즈가 양자 컴퓨팅에 미치는 영향**

[![](https://gazetai.s3.ap-northeast-2.amazonaws.com/info_v2/eab35315-0852-4b7d-c526-90076cf8fccd/1751032265152_1751032650_3.jpeg)](#)

양자 시스템에서 큐비트 수가 늘어날수록 노이즈 문제는 기하급수적으로 심각해진다. 현재 기술로는 1,000개 큐비트를 가진 양자컴퓨터가 가장 크지만, 이 정도로는 실용적인 문제를 풀기 어렵다.

왜 그럴까? 큐비트 수가 증가할수록 오류율도 함께 증가하기 때문이다. 예를 들어 40개 큐비트로 구성된 시스템에서 노이즈 제어에 실패하면, 계산 결과는 완전히 쓸모없게 된다. 마치 천 개의 전구로 이루어진 크리스마스 트리에서, 몇 개의 전구만 깜빡여도 전체 패턴이 엉망이 되는 것과 비슷하다.

|  |  |  |
| --- | --- | --- |
| **큐비트 수** | **노이즈 영향** | **실용적 활용 가능성** |
| 10개 미만 | 제한적 | 기초 연구용 |
| 40개 | 상당한 노이즈 제어 필요 | 특정 알고리즘 테스트 가능 |
| 100개 | 매우 높은 오류율 | 오류 수정 필수 |
| 1,000개 | 기하급수적 오류 증가 | 현재 기술로 실용화 어려움 |

실제로, 양자컴퓨터에서 오류를 정량적으로 표현할 때에는 1Q오류율과 2Q오류율로 구분한다.

**1Q 오류율 (1Q Gate Error Rate)**

- 정의: 단일 큐비트에 수행되는 기본적인 게이트 연산(예: X, Y, Z, Hadamard 등)이 잘못될 확률을 의미한다.
- 예시: "1Q 오류율이 0.01%"라는 것은 1만 번 중 한 번 정도 연산이 실패한다는 의미이다.
- 오류 발생 원인:

🎯 제어 신호(레이저나 마이크로파)의 불안정성

🌪️ 외부 환경 노이즈

🧊 큐비트의 탈동조화 (decoherence)

🔧 시스템 내부의 열적 잡음, 진동 등

- 활용: 주로 개별 큐비트의 성능을 정량화하는 데 사용된다. 좋은 양자 프로세서(QPU)는 이 값이 매우 낮다. 이상적으로는 10⁻⁴ 이하 수준을 목표로 한다.

**2Q 오류율 (2Q Gate Error Rate)**

- 정의: 두 큐비트 사이에서 수행되는 얽힘 게이트(CNOT, CZ 등)의 실패 확률을 의미한다.
- 예시: "2Q 오류율이 0.5%"는 200번 연산 중 한 번 꼴로 실패한다는 뜻이다.
- 오류 발생 원인:

🎯 큐비트 간 상호작용의 정밀도 부족

⚙️ 얽힘 생성 중 시스템 불안정

⏱️ 1Q 연산보다 복잡하고 긴 연산 시간 → 노이즈 노출 증가

- 활용: 얽힘 연산은 대부분의 양자 알고리즘의 핵심이므로, 2Q 오류율이 낮을수록 전체 알고리즘의 성능이 높아진다. 또한 QEC(양자 오류 수정)에서 가장 큰 제약 조건이 되는 수치이기도 하다.

**그러면 왜 1Q와 2Q 오류율을 구분할까?**

- ✅1Q 게이트는 기술적으로 비교적 잘 제어 가능하므로 오류율이 낮다.
- ⚠️반면 2Q 게이트는 시스템 구조와 상호작용 방식에 따라 오류율이 크게 달라지며, 구현 난이도가 높다.
- 🧠 대부분의 양자 알고리즘은 수많은 CNOT 게이트를 사용하기 때문에, 전체 오류율에 가장 큰 영향을 미치는 요소는 2Q 게이트다.

양자 우위를 달성하려면 에러율을 획기적으로 낮춰야 한다. 이것이 양자컴퓨터 연구에서 노이즈 제어가 가장 중요한 과제로 꼽히는 이유다.

****

**🛠️노이즈를 줄이는 핵심 기술들**

[![](https://gazetai.s3.ap-northeast-2.amazonaws.com/info_v2/eab35315-0852-4b7d-c526-90076cf8fccd/1751032265152_1751032650_4.jpeg)](#)

노이즈 문제를 해결하기 위한 여러 기술 중 가장 주목받는 것은 '잡음-회복 양자 회로'다. 이 기술은 양자 게이트마다 발생하는 오류를 일정 수준까지 허용하면서도 전체 계산의 정확도를 유지한다.

회로 설계 단계에서 깊이(depth)를 최적화하는 방법도 중요하다. 회로 깊이란 양자 게이트가 연속적으로 적용되는 횟수를 말하는데, 깊이가 깊을수록 노이즈에 취약해진다. 마치 길게 이어진 도미노가 중간에 한 개만 쓰러져도 전체가 무너지는 것과 같다.

실제 구현 방식은 다양하다:

- 동일한 연산을 여러 큐비트에 중복 수행
- 측정 결과를 통계적으로 분석해 오류 패턴 파악
- 특정 오류에 강한 양자 게이트 조합 활용

이런 기술들은 양자컴퓨터의 에러율을 낮추고 충실도를 높이는 데 중요한 역할을 한다.

****

**🔍충실도와는 뭐가 다른데?**

양자 컴퓨팅에서 에러율과 충실도(fidelity)는 동전의 양면 같은 개념이다. 충실도는 양자 시스템이 의도한 상태나 연산을 얼마나 정확하게 구현하는지를 나타내는 지표다. 0에서 1 사이의 값을 가지며, 1에 가까울수록 완벽한 구현을 의미한다.

반면 에러율은 오류가 발생할 확률을 의미한다. 예를 들어 99% 충실도는 1%의 에러율과 같다고 볼 수 있다. 그러나 두 개념이 항상 정확히 반비례하는 것은 아니다.

충실도는 주로 개별 양자 게이트나 연산의 정확도를 측정할 때 사용하고, 에러율은 전체 시스템의 오류 발생 가능성을 평가할 때 쓴다. QEC(양자 오류 정정) 기술은 낮은 충실도에도 불구하고 전체 시스템의 에러율을 낮추는 것이 목표다.

양자 시스템을 설계할 때는 두 개념 모두를 고려해야 높은 정확도의 계산이 가능하다.

|  |  |  |
| --- | --- | --- |
| **항목** | **오류율 (Error Rate)** | **충실도 (Fidelity)** |
| 정의 | 연산이 실패할 확률 | 이상적인 상태와 실제 상태의 유사도 |
| 범위 | 0 ~ 1 (낮을수록 좋음) | 0 ~ 1 (높을수록 좋음) |
| 수학적 관계 | 오류율 ≈ 1 - 피델리티 | 피델리티 ≈ 1 - 오류율 |
| 측정 방법 | 🔹 랜덤화 벤치마킹 (Randomized Benchmarking)  🔹 Gate Set Tomography (GST) | 🔹 상태 토모그래피 (State Tomography)  🔹 벨 상태 충실도 측정  🔹 크로스 엔트로피 벤치마킹 (XEB) |
| 사용 대상 | 시스템 성능, 공학적 분석 | 상태 정밀도, 물리 이론 평가 |
| 플랫폼 | IBM, IonQ, Quantinuum | IonQ, Google |

****

**🧪에러율와 충실도를 측정하는 방법**

[![](https://gazetai.s3.ap-northeast-2.amazonaws.com/info_v2/eab35315-0852-4b7d-c526-90076cf8fccd/1751032265152_1751032650_6.jpeg)](#)

양자 시스템의 에러율과 충실도를 측정하는 것은 양자 컴퓨팅 발전의 핵심이다. 가장 널리 사용되는 에러율 측정 방법은 '게이트 세트 토모그래피(Gate Set Tomography)'다. 이 측정 방법은 상태 준비, 게이트 동작, 측정까지 전체적인 시스템을 진단할 수 있다. 높은 정밀도를 자랑하지만, 실험 시간과 리소스 소모가 크다.

또 다른 방법은 '랜덤화된 벤치마킹(Randomized Benchmarking)'으로, 무작위 양자 게이트 시퀀스를 실행한 후 결과를 분석해 평균 오류율을 계산한다. 이는 개별 게이트보다 전체 시스템의 성능을 평가하는 데 유용하다.

|  |  |  |
| --- | --- | --- |
| 항목 | Standard RB (랜덤화 벤치마킹) | Gate Set Tomography (GST) |
| 목적 | 전체 게이트 세트의 평균 오류율 측정 | 모든 게이트·측정·상태준비 오류를 완전 분석 |
| 랜덤화된 벤치마킹 | 실제 사용 환경에서의 성능 측정 | 특정 오류 패턴 식별 어려움 |
| 측정 대상 | 전체 Clifford 게이트 집합의 평균 성능 | 시스템 전체: 상태 준비, 게이트, 측정 모두 |
| 작동 방식 | 무작위 Clifford 시퀀스 실행 → 성공률 측정 | 다양한 회로를 실행하고 밀도 행렬 추정 |
| 출력 | 평균 오류율 (e.g., 0.1%) | 게이트별 오류율, 시스템 바이어스, 전체 추정 오류 등 |
| SPAM 오류 영향 | 거의 없음 (설계 상 제거됨) | 포함됨 (SPAM 자체도 분석 대상) |
| 측정 정확도 | 평균적이고 간결함 | 가장 정밀 (모든 요소 추정 가능) |
| 복잡도 및 비용 | 낮음~중간 (실용적) | 매우 높음 (큐비트 수 ↑ 시 지수적 증가) |
| 스케일링 | 비교적 우수 (수십 큐비트도 가능) | 제한적 (실험 가능 큐비트 수 제한) |
| 실험 시간 | 수 분 ~ 수 시간 | 매우 김 (수일 이상 가능) |
| 활용 예시 | IBM, Google, IonQ, Quantinuum 등에서 표준 성능 평가 | 연구소, 고정밀 실험 (NIST, Quantinuum 일부 실험 등) |

> **Standard RB**:
>
> → *“전체적으로 얼마나 잘 돌아가는가?”* 평균적인 오류율을 쉽게 측정
>
> **GST**:
>
> → *“이 장비는 정확히 어디서 얼마나 왜 틀리는가?”* 전체 시스템 오류 프로파일링

****

충실도를 측정하는 방법은 양자 상태 토모그래피, 벨상태 충실도, 크로스 엔트로피 벤치마킹 등이 있다.

|  |  |  |  |
| --- | --- | --- | --- |
| **항목** | **상태 토모그래피** **(State Tomography)** | **벨 상태 충실도** **(Bell/GHZ Fidelity Test)** | **크로스 엔트로피 벤치마킹 (XEB)** |
| **목적** | **전체 상태의 밀도 행렬**을 재구성하여 정확도 평가 | 얽힘 상태(Bell, GHZ 등)가 잘 생성되었는지 정밀 확인 | **복잡한 회로 출력분포의 유사도** 측정 |
| **측정 대상** | 1큐비트~다큐비트 상태 (전체 양자 상태) | 특정 얽힘 상태 (예: Bell, GHZ, W 등) | 복잡한 랜덤 양자 회로 실행 결과 |
| **출력 값** | 밀도 행렬 ρ → [F = ⟨ψ | ρ | ψ⟩ 또는 트레이스 거리 등] |
| **실험 방식** | 다양한 기준에서 측정 → 역산하여 상태 재구성 | 대상 상태만 측정 → 몇 가지 고정된 기저에서 결과만 통계 분석 | 동일 회로를 수천~수만 번 실행하고 결과 확률분포 비교 |
| **정확도** | 매우 높음 (이론적 정확도 최고) | 높음 (얽힘 품질 중심) | 통계적 정확도 (랜덤성에 의존) |
| **복잡도 / 큐비트 수 제한** | 매우 높음 (큐비트 수 늘면 지수적으로 증가) | 낮음 (주로 2~3큐비트 얽힘 상태에 사용) | 매우 큰 큐비트 수 가능 (Google Sycamore에서 53Q 이상 사용) |
| **SPAM 영향 (측정 오류 등)** | 매우 민감함 (보정 필수) | 보통 수준 | 상대적으로 낮음 (통계 보정 가능) |
| **사용 예시** | 정확한 상태 벡터/밀도행렬 분석, 실험 검증 | 얽힘 품질 평가, Bell test, GHZ 상태 검증 | 양자 우월성 테스트, Google XEB (2019), IQM 등 |
| **장비 요구** | 모든 측정 축에서의 측정 가능성 필요 | 몇 개의 측정 축만으로 충분 | 많은 샘플링 수 + 고속 시뮬레이터 필요 |

**🧪****SPAM이란?**

위에서 중복되어 등장하는 SPAM에 대해 간단히 짚고 넘어가보자. SPAM(State Preparation and Measurement)은 양자컴퓨팅에서 **상태 준비 및 측정 과정에서 발생하는 오류**를 통칭하는 개념으로서, 양자 오류율과 충실도 평가에서 핵심 지표로 작용하며, 주요 내용은 다음과 같다.

****

**🧪SPAM의 정의 및 구성 요소**

**State Preparation(상태 준비)**

큐비트를 초기 상태(보통 |0〉)로 설정하는 과정.

**❌오류 유형**: |0〉대신 |1〉로 잘못 준비되거나 중첩 상태가 불완전하게 형성되는 경우.

****

**Measurement(측정)**

큐비트의 최종 상태를 읽는 과정.

**❌오류 유형**: |0〉을 |1〉로 잘못 판독하거나 그 반대의 경우.

**⚠️SPAM 오류의 특징**

**🔄복합적 오류**: 상태 준비와 측정 오류를 실험적으로 분리하기 어려워 통합하여 평가

**🎯 시스템적 편향(Systematic Bias)**: 게이트 오류와 달리 회로 깊이에 무관하게 일정한 오류율 유지

**📉지수적 영향**: N개 큐비트 시스템의 전체 SPAM 충실도 = (개별 큐비트 충실도)*N*

- 예를 들어 개별 큐비트 충실도가 99%이고, 큐비트수(N)가 100이라면, 전체 충실도는 0.99100 =36.6%임. 이는 100개 큐비트가 모두 정확하게 상태준비 및 측정될 확률은 36.6%인 것이고, 63.4% 확률로 하나 이상의 큐비트에서 SPAM 오류가 발생할 수 있다는 것을 의미한다.
- 여기서 중요한 것은 큐비트 수(N)이다. 큐비트 수가 증가할수록 전체 충실도는 **지수적으로 감소**함을 의미한다. 다음은 큐비트 수가 각각 10, 50, 100일 경우 충실도는 다음과 같이 **급격히 낮아진다**.

  - ***N*****=10: 0.99****10****≈90.4%**
  - ***N*****=50: 0.99****50****≈60.5%**
  - ***N*****=100: 0.99****100****≈36.6%**
- 이번에는 큐비트 수를 동일(100)하다면, 개별 큐비트 충실도에 따라 전체 충실도는 다음과 같이 **급격히 올라감**을 확인할 수 있다.

|  |  |  |  |
| --- | --- | --- | --- |
| **개별 큐비트 충실도** | **큐비트 수(N)** | **전체 충실도** | **오류 발생 확률** |
| 99% (0.99) | 100 | 36.6% | 63.4% |
| 99.9% (0.999) | 100 | 90.5% | 9.5% |
| 99.99% (0.9999) | 100 | 99.0% | 1.0% |

**QEC 임계값**은 양자 게이트, 측정, 큐비트 유지 등에서 발생하는 **물리적 오류율이 일정 수준 이하일 때**, 오류 수정 코드를 계층적으로 적용함으로써 전체 논리적 오류율을 **지수적으로 낮출 수 있는지**를 결정짓는 경계선(error threshold)이다.

임계값보다 오류율이 낮다면, 큐비트를 더 많이 사용할수록 논리적 오류율이 낮아지지만, 임계값보다 오류율이 높다면 QEC를 적용해도 효과가 없고, 오히려 큐비트 수를 늘려도 논리적 오류가 계속 쌓여서 계산 신뢰도 확보가 어려워 실질적으로 양자컴퓨터로서의 기능을 못하게 된다.

|  |  |
| --- | --- |
| QEC 코드 | 임계값 |
| Surface Code | ~1% |
| LDPC/Color Code | ~0.5–2% |

- 이 임계값보다 낮으면 큐비트를 더 많이 사용함으로써 오류를 지수적으로 감소시킬 수 있다.
- 반대로, 이 값을 초과하면 논리 큐비트를 만들더라도 오류가 누적되어 실용성이 떨어진다.
