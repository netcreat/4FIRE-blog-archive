지난 글에서도 살펴봤듯이 이미 IBM, Quantinuum은 이미 qLDPC를 이용한 QEC 개발을 진행해 오고 있다.

**✅ 옥스포드 아이오닉스가 파트너십을 맺은 이유?**

그럼 본격적으로 옥스포드 아이오닉스가 Iceberg Quantum과 파트너십을 맺은 이유에 대해 짚고 넘어가보자.

- **일단 옥스포드 아이오닉스는 2Q 게이트 기준 99.97%라는 세계 최고 수준의 충실도를 자랑한다.**

  - 칼슘이라는 보다 안정적인 이온을 활용해서 실험을 했지만, 그것을 과감히 포기하고, 생산 효율성이 우수한 바륨을 선택하면서, 충실도를 유지시킬 수 있는 기술에 집중해왔다.

    - 레이저 대신 마이크로파로 제어를 하면서 보다 간단하면서 정밀제어가 가능하게 됨.
    - QCCD 기반 구조의 칩 아키텍쳐를 사용하면서 FPGA 설계이므로 오류 정정 코드를 실시간으로 교체 가능
    - Cryo-CMOS를 이용하면서 잡음을 최소화 함.
  - 위의 여러 기술로 인해 오류율 최소화와 큐비트 극대화를 동시에 이루어냄으로써, 앞서 언급했듯이 논리 큐비트 없이도 경쟁력을 갖추게 되었음
  - 하지만, 완전한 FTQC로 가기 위해서는 **효율적인 오류정정의 설계가 필요하게 됨**

****

- **DARPA QBI StageA에 참여중이다.**

  - 옥스포드 아이오닉스는 Stage A에 참여한 15개 기업에 포함되어 있으며, **1백만 USD** 지원을 받아 2025년 10월까지 결과 제출과 평가를 받아, 조건에 해당되는 경우 Stage B로 진입하여 최대 **1천 5백만 USD** 지원을 받게 되고, Stage C는 **3억 USD** 지원을 받게 된다.

****

- - **Stage C의 평가 항목**

    - FTQC가 실현된 실물에서 얼마나 안정적으로 연산을 수행하여 실제 문제를 풀 수 있는지 평가하는 단계

|  |  |  |
| --- | --- | --- |
| **평가 항목** | **설명** | **기준 예시** |
| **① 논리 큐비트 성능** | QEC 기반 논리 큐비트가 실제로 **오류 정정을 수행하고 안정적으로 작동하는가?** | 논리 오류율 ≤ 10⁻⁴, 안정된 logical lifetime |
| **② 논리 게이트 정밀도** | 논리 H, S, CNOT, **T 게이트**가 모두 고충실도로 수행 가능한가? | 논리 T gate fidelity ≥ 99.9% |
| **③ 논리 연산 throughput** | 논리 게이트를 **얼마나 빠르게, 얼마나 많이** 실행 가능한가? | Logical gate depth, T-state/sec |
| **④ 오류 정정 지속성** | 시스템이 **수십 분~수 시간 동안** **안정적으로 오류 정정된 상태로 계산을 유지** 가능한가? | logical uptime ≥ 1 hour |
| **⑤ 유틸리티 알고리즘 실행** | 실제 유틸리티 레벨의 알고리즘(예: VQE, QAOA, chemistry 등)을 수행할 수 있는가? | 정해진 분자/함수 문제를 특정 정확도로 푸는 조건 |
| **⑥ 리소스 오버헤드** | 해당 문제를 풀기 위해 사용된 **논리/물리 큐비트, 시간, 에너지** **등**의 총량 | 예: H₂O 분자 풀 때 10⁶ 큐비트 이하, 1시간 이내 |
| **⑦ 시스템 신뢰성** | 외부 환경 변동, 게이트 오류, 메모리 누수 등 발생 시 시스템이 **자체 복구 또는 내성**을 유지하는가 | 실패 없는 operation rate ≥ 95% over N trials |
| **⑧ 확장성 모델** | 시스템이 더 큰 문제로 확장될 때 **성능이 유지 또는 선형 증가** 가능한 구조인가? | logical overhead vs. scale 곡선 제시 |
| **⑨ 알고리즘과 아키텍처 적합성** | 주어진 시스템에서 특정 알고리즘을 **이론적 모델과 일치하게 구현**했는가? | 시뮬레이터 모델 vs 실측 결과 오차 ≤ ε |

- - 이 모든 단계의 핵심은 FTQC이다. 지금 현시점에서 옥스포드 아이오닉스가 충실도가 최고일지라도, 일명 "도토리 키재기"이고, 각 업체들이 기술 개발에 총력을 다해 일정수 이상의 논리 큐비트를 확보하고, 이를 토대로 T게이트를 구현한다면, 더이상 세계최고의 충실도는 유명무실해 질 수밖에 없다.
  - 옥스포드 아이오닉스 입장에서는 **FTQC를 무조건 만족시켜야 하는 시점**이 온 것이다.

- **어떤 알고리즘을 선택할 것인가?**

  - 지금까지 논리 큐비트를 구현할때 사용했던 오류 정정 알고리즘은 Surface Code나 Color Code임
  - Color Code가 Surface Code보다 오류 임계값이 더 낮기 때문에, 오류가 많이 생기면 논리 큐비트가 바로 깨지는 단점이 있지만, 게이트 구현이 단순하고, 모든 Clifford연산을 **Transversal**하게 구현 가능하여, Clifford 게이트위주의 회로에만 적합함 → **QuEra가 선택한 이유도 여기에 있음.**

> **Transversal 연산** : 논리 큐비트 내부의 물리 큐비트에 같은 연산을 병렬 적용하여, **에러**가 발생되더라도 **확산을 방지**시켜 FTQC의 안정성을 확보하는 기법인데, QEC 코드별로 트랜스버설이 지원되는 게이트가 다름. 특히 **qLDPC 코드에서는 극히 제한적인 게이트만 지원 가능**해서, 이를 지원하는 연구가 진행중임.

- - qLDPC는 위의 코드에 비해 훨씬 고차원적

    - 이미 IBM과 Quantinuum은 Surface Code에서 전환하여 현재 실용 전 단계
    - 논리 큐비트 하나당 필요한 물리 큐비트 수가 훨씩 적음 (오버헤드 감소)
    - 오류 임계값이 이론적으로 매우 높고, Non-Clifford 게트 설계도 가능함.
    - 초대형 양자 컴퓨터 설계에 매우 유리
    - 하지만 실제 구현이 어려움.
    - **Magic state fountain에 잘 어울림**
    - **Fusion based 모델과 잘 어울림 - PsiQuantum과 협업**
    - **Iceberg Quantum이 위 조건을 충족시킴**

**🧩현재 진행중인 Fault Tolerance 관련 연구**

**🧮 Zero-Level MSD**

- **논리 큐비트 없이**, 즉 오류 정정 계층을 완전히 만들지 않고도 **고품질 T 상태를 직접 생성(distill)하는 기법**
- 즉, "오류 정정된 논리 큐비트 위에서의 MSD"가 아니라, **물리 큐비트 수준에서 오류를 줄이는** 방식
- 매우 작은 자원으로 매직 상태를 생성 가능
- 오류율은 제한적이지만, **NISQ+ 경량 FT 실험에는 유용함**
- 다음은 2025년 6월, 오사카 대학의 연구진들이 아카이브에 발표한 관련 논문이다.

  - [Efficient Magic State Distillation by Zero-Level Distillation](https://arxiv.org/html/2403.03991v2)
- 장점

  - 하드웨어 부담 적음
  - 초기 T 게이트 테스트 가능
  - NISQ 수준 장비에서 사용 가능
- 단점

  - **충실도가 높지 않음**
  - **대형 회로에 적합하지 않음**
- 옥스포드 아이오닉스는 물리 큐비트에서의 오류율이 낮기 때문에, 이 것을 사용하기엔 충분히 적합하여, “논리 회로가 아직 없는 상황에서 실험용 부트스트랩 도구”로는 유효하지만,**FT 로드맵에는 직접 기여하지 못함.**

****

**🧮Fusion based**

- 양자 얽힘 상태를 미리 만들어 놓고, 이를 측정(fusion)해서 논리 큐비트 연산을 구성하는 방식으로 PsiQuantum 같은 포토닉 양자컴퓨터에서 사용하는 방식이다.
- qLDPC와 호환이 좋음

|  |  |  |  |
| --- | --- | --- | --- |
| **특성** | **qLDPC 코드** | **Fusion-based 모델** | **궁합 이유** |
| **연산 구조** | 게이트 중심이 아님, 분산적 | 측정 중심, 클러스터 구조 | 둘 다 **고정된 구조** 없이 유연하게 작동 가능 |
| **상호작용 밀도** | sparse (LDPC → low-density) | sparse 연결로도 충분히 동작 | 다중 상호작용이 필요 없는 구조에서 유리 |
| **측정 기반 오류 정정** | 가능 | 필수 | **결합이 자연스럽고 구현이 쉬움** |
| **물리 구현 대상** | 포토닉, trapped-ion 등 | 주로 포토닉 | 하드웨어 플랫폼이 겹침 |

- 주로 포토닉 양자컴퓨터에서 사용하는 방식이긴 하나, 이온트랩에서도 가능함

  - 이온트랩은 고정밀도 얽힘 제어가 가능해서, 수동적으로 얽힘을 만들어 놓고, 측정만으로 연산을 조절하는 방식(MBQC)이 기술적으로 가능
- 단점

  - 얽힘을 미리 배치해 놓는데 **시간과 자원이 많이** 들고,
  - 측정 후 재구성 속도가 느리다는 물리적 한계 때문에 **대규모 병렬성은 어려움**
  - 마이크로파 트랩과 매칭이 어려울 가능성
- **qLDPC와 호환이 좋으나, 마이크로파 기반의 이온트랩에서 구현하기에는 현실적인 제한이 많음.**

**🧮Magic state fountain**

- 말 그대로 "샘물처럼 마법 상태가 계속 나오는 구조"를 의미
- 전통적인 MSD에서는 매번 다수의 입력과 많은 리소스를 투입해야 하나,
- Fountain 구조에서는 FT 논리 계층 안에서 마법 상태가 **주기적으로, 자동 생성**되도록 설계됨
- **qLDPC 구조 내 통합되거나 별도 Fountain Layer를 둘 수 있음**
- 실시간 T 게이트 주입 가능하여 **T 게이트 병목 현상을 없앨 수 있음** (**Stage A 4번 항목 참조**)
- 장점

  - **T 게이트 병목 최소화**
  - **MSD 반복 비용 절감**
  - **대형 알고리즘에 이상적**
- 단점

  - 초기 구조 설계가 복잡
  - qLDPC 기반 논리 계층이 필요
- 다음은 2025년 1월, **IBM의 왓슨 연구소의 연구원인 Guanyu Zhu**가 아카이브에 발표한 관련 논문이다.

  - [A topological theory for qLDPC: non-Clifford gates and magic state fountain on homological product codes with constant rate and beyond the 𝑁^{1/3} distance barrier](https://arxiv.org/html/2501.19375)
- 리스크

  - 아직 아이스버그 퀀텀이 이것을 성공한 사례가 아직 없음.
- 리스크 헷지

  - 이번 협력은 QBI Stage A를 통과하기 위한 필수 조건이므로, 협력자체의 리스크는 적음

    - 아이스버그가 성과를 내면 옥스포드의 FTQC 경쟁력이 완성됨.
    - 실패하면 교체하거나 내부 개발로 방향 선회 가능

**🧮기타**

- 이외에도, 트랜스버설 T 게이트나 Constant-depth Logical Circuit등이 연구되고 있지만, 현실성이 낮은편.

**🧩Magic State Fountain in qLDPC**

**1️⃣동작 메커니즘**

- **논리 MSD 회로 병렬 실행**

  - Bravyi-Kitaev, Meier-Eastin-Knill 등 기존 MSD 알고리즘을 **논리 큐비트 기반에서 병렬 배치**
  - 예: 5-to-1, 10-to-2 같은 구조를 수십 세트 동시 운영
  - 이 회로는 **qLDPC 논리 큐비트**로 구성되며,
  - **decoding threshold가 높은** LDPC 특성상 더 적은 물리 큐비트로도 가능

****

- **논리 |T⟩ 상태 자동 주입 준비**

  - 정제된 고충실도 |T⟩ 상태는 **논리 큐비트 공간에 저장**되거나,
  - 필요할 때 **quantum teleportation** 방식으로 논리 회로에 주입
  - 이때 **Clifford-only 게이트 + Bell 측정 + 고전 제어** 조합으로 구현

****

- **큐(queue) 기반 공급**

  - 위 과정을 주기적으로 반복하여,

    - |T⟩ 상태를 **큐에 쌓아두고**,
    - 논리 회로는 필요할 때마다 꺼내 씀
  - → 이것이 Fountain 구조의 핵심입니다.

**2️⃣ 왜 qLDPC에서 Fountain이 유리한가?**

|  |  |
| --- | --- |
| **이유** | **설명** |
| **논리 큐비트 밀도 ↑** | qLDPC는 surface보다 논리 큐비트당 물리 큐비트가 적음 → **병렬 회로 구성에 유리** |
| **높은 threshold** | qLDPC 코드는 **에러 허용 한계가 높아**서 fault-tolerant한 상태 증류 회로 유지가 쉬움 |
| **복잡 회로 통합** | qLDPC는 네트워크가 sparse하기 때문에, 논리 증류 **회로를 분리/연결하기 쉬움** |
| **게이트 깊이 최적화** | 병렬 구조 덕분에 T-state throughput이 높아져 전체 연산이 가속됨 |

**3️⃣실제 구현 계획 예 (예측 기반)**

|  |  |
| --- | --- |
| **구조 요소** | **설명** |
| **Fountain Layer** | qLDPC 기반 논리 증류 회로 다중 병렬 배치 ->**T-state 생산 공장** |
| **논리 memory bank** | 정제된 T 게이트를 임시 저장 |

| **논리 레이어 통합** | qLDPC 회로 네트워크 안에서 상시 순환 구조 구현 |

**4️⃣ 결론 요약**

|  |  |
| --- | --- |
| **항목** | **Magic State Fountain** |
| **정의** | 논리 상태를 **지속적·병렬적으로 생성하고 공급하기 위한 논리 인프라 구조** |

**옥스포드 아이오닉스는 세계 최고 수준의 물리 큐비트 충실도를 바탕으로, 이미 경쟁사들과는 출발선 자체가 다르다.** 다른 기업들이 높은 에러율의 한계를 극복하기 위해 다양한 오류 정정 코드 연구에 매진하고 있는 지금, 옥스포드는 이미 **두 번째 도약을 위한 준비를 마쳤다.**

2025년 현재, 옥스포드의 물리 큐비트 오류율은 10-4 수준이지만, **머지않아 10****-8** **수준의 획기적 성능을 지닌 큐비트를 시장에 선보일 예정이다.**

이는 FTQC(Fault-Tolerant Quantum Computing)의 본격적인 가동과 함께 양자 우위(Quantum Supremacy)를 향한 결정적 **퀀텀 점프가 될 것**이다.
