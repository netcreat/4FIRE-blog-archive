- - Missile Defense Agency(MDA)는 2025년 12월 2일 발표한 **1,014개 업체**에 대한 1차 수상에 이어, **Scalable Homeland Innovative Enterprise Layered Defense(SHIELD)** 다중수상 **IDIQ 계약** 하에서 **추가 1,086개 업체**를 선정하였다. 본 계약의 총 한도는 1,510억 달러($151B)이다.
  - 정부는 공고 조건에 따라 **스태거드 어워드**를 지속하며, 남은 제안업체들과도 절차를 진행한다. 또한 본 계약 vehicle을 효율적·신속하게 활용하기 위해 주문 단계(ordering phase)로 전환하여 **시장조사**를 수행하고 공정기회 제안요청(Fair Opportunity Proposal Requests)을 준비 중이다.
  - SHIELD는 MDA 및 기타 국방부 기관이 **단일하고 유연한 엔터프라이즈 계약 vehicle**을 통해 **Task Order 및 Delivery Order를 신속히 경쟁·발주**할 수 있도록 설계되었다. 수행 지역은 **미국 전역**이다.
  - 본 계약은 **광범위한 업무 영역**을 포괄하며, 전장에 **혁신적 역량을 보다 빠르고 민첩하게 제공**하는 것을 목표로 한다. 이를 위해 **인공지능(AI)·머신러닝(ML) 응용**, **디지털 엔지니어링**, **오픈 시스템 아키텍처**, **모델 기반 시스템 엔지니어링(MBSE)**, **애자일 획득·개발·유지 프로세스**의 활용을 극대화한다.
  - 모든 옵션이 행사될 경우 계약 수행은 **2035년 12월까지** 지속된다. **기본 IDIQ 어워드 단계에서는 예산이 집행되지 않으며**, 실제 자금은 **개별 주문(TO/DO) 수준에서만** 집행된다. 본 계약은 **SAM.gov**를 통해 **경쟁 방식**으로 조달되었고, **총 2,463건의 제안**이 접수되었다. 계약 담당 기관은 **앨라배마주 헌츠빌 레드스톤 아스널의 MDA**이며, 공고 번호는 **HQ085925RE001**이다.

**✅****요약**

- - 본 공고는 미 국방부 산하 미사일방어국(Missile Defense Agency, MDA)이 주관하는 **SHIELD(Scalable Homeland Innovative Enterprise Layered Defense) Multiple Award IDIQ 계약**에 관한 것이다.
  - 본 계약은 **10년 기간의 다중수여 IDIQ 계약 차량**으로, 최대 계약 한도는 1,510억 달러($151B)로 설정되어 있다.
  - 본 계약 자체는 개별 사업의 수주를 의미하지 않으며, 향후 MDA 및 기타 국방부 기관이 **Task Order 및 Delivery Order를 신속히 발주하기 위한 조달 프레임워크**이다.

**1. 계약 진행 경과**

- - **질문 기간 종료**: 2025년 9월 15일
  - **제안서 제출 마감**: 2025년 10월 16일
  - **Competitive Range 설정 완료**: FAR 15.306(c)에 따라 수행됨
  - Responsive offeror만 경쟁 범위에 포함됨
  - 개별 업체는 PIEE에 등록된 이메일로 통보받음

**2. Award 현황 (누적)**

- - **2025년 12월 2일**
  - 1차로 **1,014개 업체**에 IDIQ 계약 수여
  - **2025년 12월 18일**
  - 추가로 **1,086개 업체**에 계약 수여
  - 현재까지 **총 약 2,100개 이상의 업체**가 SHIELD IDIQ 계약 보유자(contract holder)가 됨
  - 본 수여는 **staggered awards 방식**으로 진행되며, 책임성 검증(responsibility assessment) 및 논의(discussions) 결과에 따라 추가 수여가 가능함을 명시하고 있다.

**3. 현재 단계**

- - 정부는 본 계약을 활용하기 위해 이미 주문 단계(ordering phase)로 전환하였다.
  - 현재 정부가 수행 중인 사항은 다음과 같다.

    - 시장조사(Market Research) 수행
    - **공정경쟁 제안요청서(Fair Opportunity Proposal Request, FOPR)** 초안 작성
  - 다만,
  - 모든 경쟁 범위 내 업체가 의미 있는 논의에 참여하기 전까지는 **Task Order 경쟁은 개시되지 않음**을 명확히 하고 있다.

**4. 향후 절차**

- - SHIELD IDIQ 계약 보유 업체는 향후 Task Order 및 Delivery Order 경쟁에 대해 **개별적으로 연락을 받을 수 있음**
  - 향후 **SHIELD On-Ramp 기회**가 있을 경우 SAM.gov를 통해 별도 공지될 예정임

**5. 계약 성격 정리**

- - 본 공고는 **Golden Dome 단일 사업 계약이 아님**
  - SHIELD는:

    - 미사일 방어
    - 센서·C2·데이터 융합
    - 우주·지상·해상 통합 방어
    - 등 **다수의 미래 사업을 포괄할 수 있는 조달 수단**
  - 개별 사업의 실제 예산 집행과 수주는 **향후 Task Order를 통해 이루어짐**

****

**6. 핵심 요약 문장**

> ***본 SHIELD IDIQ 계약은 수주가 아니라 ‘수주 경쟁 자격’을 부여하는 계약 Vehicle이며,***
>
> ***실제 사업 성과는 향후 발주될 Task Order에서 결정된다.***

**1️⃣CAGE란 무엇인가?**

**CAGE**는 **Commercial and Government Entity code**의 약자다.

미 국방부(DoD)와 연방정부 조달 시스템에서 **법인 단위의 고유 식별자**로 사용된다.

- 5자리 영문·숫자 코드 (예: 02769, 7GVZ9)
- 회사 이름이 같아도 **법적으로 다른 법인**이면 CAGE는 다를 수 있음

**2️⃣실제 계약은 어떤 순서로 나오나?**

- - **Step 0 (지금, 2025년 말)**

    - Awardee Pool 확정 : 총 2,100개
    - 업체들은 내부적으로:

      - Prime 접촉
      - capability brief 업데이트
      - teaming / sub 포지션 정리
    - 👉 **돈은 아직 0**
  - **Step 1 (2026 상반기)**

    - **Draft Task Order (RTO / Draft RFP)** 일부 공개
    - SDA / Space Force 내부 요구사항 정제
    - Prime 중심의 **teaming 구조 고정**
    - 👉 이 시점에 **누가 실제로 먹을지가 사실상 결정**됨
  - **Step 2 (2026 하반기) ⭐**

    - **첫 실제 Task Order 발행**
    - 규모:

      - 수천만 달러 단위 TO 여러 개
      - Prime 위주, Sub는 제한적
    - 👉 **여기서 처음으로 매출 발생**
  - **Step 3 (2027~2029)**

    - Tranche 4 / 5 연계
    - Kill Web, Tracking Layer, C2 확장
    - **반복 TO 구조 정착**
    - 👉 상위 5~10% 업체만 살아남음

**✅****IDIQ vs OTA — 핵심 비교**

**1️⃣ 한 줄 정의**

- - **Federal Acquisition Regulation (FAR) - 연방 조달 규정**
  - **IDIQ (Indefinite-Delivery, Indefinite-Quantity)**

    - → *“검증된 걸* ***오래·반복****해서 쓰기 위한 조달 프레임(차량)”*
  - **OTA (Other Transaction Authority)**

    - → *“새 기술을* ***빨리 만들어·써보는*** *실험/시범 계약”*

**

**2️⃣ 법·규정부터 다르다**

|  |  |  |
| --- | --- | --- |
| **구분** | **IDIQ** | **OTA** |
| 법적 성격 | **정식 조달(FAR 적용)** | **비조달(OTA 법령)** |
| GAO 항의 | 가능 | 거의 불가 |
| 계약 안정성 | 매우 높음 | 상대적으로 낮음 |
| 감사/준법 | 엄격 | 유연 |

**3️⃣ 목적이 다르다**

|  |  |  |
| --- | --- | --- |
| **질문** | **IDIQ** | **OTA** |
| 왜 쓰나? | **운영·확산** | **검증·실험** |
| 무엇을 사나? | 이미 쓸 수 있는 것 | 아직 검증 중인 것 |
| 실패 허용? | 낮음 | 높음 |
| 교체 전제? | 아님 | **전제** |

**4️⃣ 구조가 다르다**

- - **IDIQ**

    - [IDIQ 계약(자격)] → Task Order (일) → Delivery Order (반복·확대)
    - “입장권”을 먼저 주고, **TO/DO로 돈**이 나온다.
    - **Fair Opportunity**가 핵심.
  - **OTA**

    - [OTA 프로그램 계약] → 바로 개발/제작/운용
    - **계약 자체가 돈**이다.
    - Prime 중심, **Sub 변경 자유**.

**5️⃣ 속도·유연성**

|  |  |  |
| --- | --- | --- |
| **항목** | **IDIQ** | **OTA** |
| 속도 | 느림 | **빠름** |
| Sub 변경 | 제한 | **자유** |
| 기술 교체 | 어려움 | **쉬움** |

**6️⃣ 돈의 성격**

|  |  |  |
| --- | --- | --- |
| **항목** | **IDIQ** | **OTA** |
| 매출 시점 | TO/DO 이후 | **즉시** |
| 반복성 | **높음(특히 DO)** | 낮음 |
| 장기 캐시플로우 | **강함** | 약함 |

**7️⃣ 누가 주로 쓰나**

- - **OTA** → **Space Development Agency**

    - Tranche 3 위성 72기, $3.5B
    - “2년 주기 spiral, 기술 교체 전제”
    - 빠른 발사
    - 2년 주기 spiral development
    - 기술 교체 전제
    - 실패 허용
    - 👉 OTA가 아니면 **SDA의 속도가 안 나온다**
  - **IDIQ** → **Missile Defense Agency**

    - SHIELD, 10년 $151B ceiling
    - “운영·통합·확산”
    - 장기 운영
    - Homeland Defense
    - 법적 안정성
    - 반복 예산 집행
    - 👉 OTA로는 **전국 방어 체계를 운용할 수 없다**

**8️⃣ 언제 어느 걸 쓰나 (현실 기준)**

- - **새 기술 / 빠른 검증** → **OTA**
  - **전력화 / 전국·전구 운영** → **IDIQ**
  - 그래서 흐름은 보통 이렇게 간다:
  - OTA로 검증 → IDIQ(TO)로 채택 → IDIQ(DO)로 확산

**9️⃣ 투자·사업 관점의 진짜 차이**

- - **OTA 수주** = 기술 뉴스 (크지만 일회성일 수 있음)
  - **IDIQ DO** = 사업 뉴스 (작아 보여도 반복·안정)

> SHIELD는 **10년간 최대 $151B까지 집행 가능한 IDIQ 계약 vehicle**이며, 이는 **연간 예산을 의미하는 것이 아니라 법적 상한선**임을 먼저 기억할 필요가 있다. 이에 비해 **MDA의 FY26 전체 예산은 약 $13.2B**로, SHIELD는 이 예산을 실제로 집행하기 위한 **조달·집행 수단**에 해당한다.
>
> 또한 MDA의 핵심 임무는 **날아오는 탄도미사일 및 극초음속 비행체를 탐지·추적·식별하고 최종적으로 요격하기 위한 체계의 연구·개발**이다. 이 과정에서 **센서 관련 기술과 요격체 개발이 최우선 과제**로 설정될 수밖에 없으며, 이러한 맥락에서 **Capella Space와 Vector Atomic이 SHIELD Award 리스트에 포함된 것은 충분히 합리적**이다.
