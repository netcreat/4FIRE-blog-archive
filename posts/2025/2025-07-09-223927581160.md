**1️⃣ Grover's Search Algorithm: 정답을 더 빠르게 찾는 마법**

**🔯문제:**

고전 컴퓨터는 N개의 데이터 중 원하는 걸 찾기 위해 고전적인 선형 탐색 방법을 사용하게 되면 입력 N개를 전부 확인 해야하기 때문에, 평균 ***O(N)***번 검색해야 한다.

Grover 알고리즘은 이를 약 ***O(√N)***만큼 단축시킨다.

**🔯알고리즘의 핵심 부분:**

- **중첩 생성:** 모든 가능한 입력 상태를 동등하게 중첩시킨다.

- **오라클 연산**:

  - 입력된 값이 정답인지 아닌지 알려주는 함수로서, 값은 바꾸지 않고, **정답인 상태의 위상을 반전**시킨다.
  - 이때, 양자 간섭(Interference)를 이용하는데, 양자 상태는 지난 번에 언급했듯이 복소수 α,β로 구성되고, 각 복소수는 진폭이 있고, 그 진폭의 위상이 간섭 현상을 일으키게 된다.

    - 여기서 *r*이 진폭, φ이 위상이다.

    - 상태 ∣x⟩|가 오답이면 상쇄 간섭으로 인해 확률 ↓ → 그대로 유지됨

    - Z 게이트는 무조건 반전

**2️⃣ Shor's Algorithm: 소인수분해를 양자 방식으로**

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/e/ed/Peter_Shor_2017_Dirac_Medal_Award_Ceremony.png/250px-Peter_Shor_2017_Dirac_Medal_Award_Ceremony.png)](#)

출처 : 위키피디아 Peter Shor

**🔯문제:**

RSA 암호의 기반인 큰 수 소인수분해는 고전적으로는 매우 느리다.

Shor 알고리즘은 이를 지수 시간에서 다항 시간으로 단축시킨다.

****

**🔯알고리즘의 핵심 부분:**

- 양자 푸리에 변환 (**QFT,** **Quantum Fourier Transform**): 주기성을 측정하여 수학적 해를 도출하는 **도구 (Tool)** 개념
- 양자 위상 추정 (**QPE, Quantum Phase Estimation**) : QFT를 적용하여 소인수를 구하는 **알고리즘** 개념.
- 중첩 + 얽힘:
- 입력 큐비트를 모두 중첩시켜 아래의 함수를 병렬로 계산

  - 이 수식은 지수 모듈러 연산으로, x를 a번 곱해서 N으로 나눈 나머지를 취한다는 의미인데, 쇼어 알고리즘에서 핵심인 "주기성 찾기"함수임.
  - 이 함수에서 주기 r을 찾는 것이 소인수 분해의 핵심 열쇠가 되기 때문이다.

- 결과와 입력을 얽히게 하여 주기 정보가 확률 진폭에 인코딩

👉 얽힘이 없다면 QFT의 간섭(interference) 효과가 사라지고, 해답 추출이 불가능하다.

**🔯소인수분해의 간단 이해**

소수 p,q의 곱인 수 N이 주어졌을 때, p와 q를 찾는 과정이다.

1. N보다 작은 임의의 수 x를 선택한다.
2. 위의 지수 모듈러 연산을 반복하여, **되풀이 되는 값 r을 찾는다**.

   - x를 임의수 y와 곱한 값을 N으로 나눈 나머지를 구하고, 그 값을 y'라고 정한 후 이 과정을 동일한 나머지 값일 나올때 까지 반복(r)한다.
   - 이때 r이 홀수면 소인수 분해가 되지 않기 때문에 반드시 짝수여야 한다.
3. 이때 짝수 r을 반으로 나눈 값(r/2)번째 계산에서의 나머지 값(z)을 찾은 후 아래와 같은 최대공약수(gcd - Greatest Common Divisor) 연산을 이용해 N의 인수 p와 q를 찾는다.

   - gcd(z+1, *N*),
   - gcd(z-1, *N*)
4. 예시 : 유튜브 언더스탠딩 - "맙소사! 양자컴퓨터를 이해하게 되다니(카이스트 김갑진 교수) 참조.

   - N=15이고, 임의 수 x=7로 시작해서 p, q를 찾는다.
   - 여기서는 y=1부터 시작하여 과정을 반복하겠다.

     - 1 \* 7 / 15 = 7 / 15 => 7
     - 7 \* 7 / 15 = 49 / 15 => 4
     - 4 \* 7 / 15 = 28 / 15 => 13
     - 13\*7 / 15 = 91 / 15 => 1
   - 위 예에서 1이 반복되는 주기 4가 곧 r이 된다.
   - r/2번째 계산에서의 나머지 값(z)은 4
   - (z+1)과 N, (z-1)과 N의 최대 공약수를 구한다.

     - (4+1)과 15의 최대공약수 : 5
     - (4-1)과 15의 최대공약수 : 3

**🔯양자 푸리에 변환(QFT, Quantum Fourier Transform)이란?**

- 고전 푸리에 변환처럼, 복잡하게 뒤섞여 있는 파동 및 주파수 신호에서 특정 패턴을 추출하고 분석하는 양자 연산 (푸리에 변환의 개념 아래 그림을 보면 이해하기 쉬운데, 나중에 시간 날때 한번 정리할 생각이다)

[![](https://upload.wikimedia.org/wikipedia/commons/7/72/Fourier_transform_time_and_frequency_domains_%28small%29.gif)](#)

출처 : 위키피디아 이산 푸리에 변환

- 쇼어 알고리즘, 위상 추정 알고리즘 등에 핵심

  - ∣χ⟩라는 "시간 영역" 상태를 **위상이 변조**(주파수 영역)된 모든 상태의 중첩 과정으로 바꾸는 과정으로서, 앞서 잠깐 언급했던 중첩과 간섭으로 그 주파수를 쉽게 추출이 가능하다. 이것 주파수를 추출하는 과정을 이용해서 위의 **소인수분해의 주기를 알기 위함**이다.
  - 위상 추정 알고리즘에서 **에너지, 위상 측정**이 가능
  - **양자 센서나 양자 시뮬레이션** 등에서 핵심 역할
  - QFT는 고전적 이산 푸리에 변환(DFT, Discret Fourier Transfrom)이나 고속 푸리에 변환(FFT, Fast Fourier Transform)에 비해 매우 빠름.

    - 입력 데이터 크기 ***N=2******n***(즉, 입력 비트수 ***n=log******2******N***)일때***,***
    - DFT : ***O(N******2******)***
    - FFT : ***O(N log******2*** ***N)=O(2******n*** ***n)***
    - QFT : ***O(n²)***
  - 예 : 입력비트가 10개 일때(*N*=210=1024) 연산량을 비교하면 아래와 같이 큰 차이가 나는 것을 확인 할 수 있다.

    - DFT : *O*(10242) = 1,000,000
    - FFT : *O*(1024 \* 10) = 10,000
    - QFT : *O*(102) = 100

**🔯양자 위상 추정 (QPE, Quantum Phase Estimation)이란?**

- QFT를 이용하여 위상을 근거로 소인수분해에서 핵심이 되는 주기 r을 찾는데 사용되는 알고리즘이다.

  - **아래 공식에서의 θ는 블로흐 구면에서 큐비트의 극각을 나타내는 그것과 다른 것임**
  - ***θ=s/r*** 추정
  - ***θ=s/r***에서 연분수 전개법(continued fraction expansion)을 사용하여 ***r*** 추출

    - 여기서 s는 r과 서로소, 즉 최대공약수가 1인 수. 여러개일 수 있음
    - 예를 들어 θ ≈ 0.4285714285... 일때, 연분수 전개하여 나올 수 있는 값들은 1/2, 2/5, 3/7,... 이 있는데, 그중에 가장 근사치에 가까운 값이 3/7이고, 이때 *a**r* *mod N*=1테스트를 통과한 값이면 최종 r이 된다.

**3️⃣ GHZ 상태 생성: 다큐비트 얽힘의 대표 사례**

GHZ (Greenberger–Horne–Zeilinger) 상태는 다음과 같은 **세 큐비트 이상 얽힘 상태**. 이전 글에서 살펴봤던 MS게이트나 CNOT 게이트는 보통 2중 큐비트 얽힘에 사용된다는 차이점이 있다.

이 상태는 **양자 통신, 양자 네트워크, 다중 큐비트 검증 실험**에서 매우 중요하다.

**🔯생성 방법 (예: 이온트랩 기준):**

- 모든 큐비트를 ∣0⟩으로 초기화
- 첫 번째 큐비트에 Hadamard 게이트 → 중첩 생성
- 나머지 큐비트에 CNOT → 얽힘 생성

👉 GHZ는 얽힘이 없으면 단순한 중첩에 불과하며, 분산 시스템 간 동기화나 오류 검출이 불가능하다.

**4️⃣ VQE (Variational Quantum Eigensolver) – ⚗️ 양자화학용 하이브리드 알고리즘**

**🔯문제 :**

분자나 물리 시스템의 바닥 상태 에너지(ground state energy)를 찾고 싶다.

고전 시뮬레이터로는 분자가 조금만 커져도 계산 불가

**🔯아이디어**

**양자컴퓨터**는 양자 상태 생성과 측정에 강함

**고전컴퓨터**는 측정값을 기반으로 파라미터 최적화에 강함

둘을 결합해서 에너지 최소화 과정을 반복하는 고전/양자 하이브리드 방

**🔯효과**

현재의 노이즈 많은 장비(NISQ)에서도 사용 가능

수소(H₂), 리튬수소(LiH), 질소(N₂) 등 실험적 성공 사례 있음

향후 약물 설계, 촉매 개발 등에 응용 기대

**5️⃣ QAOA (Quantum Approximate Optimization Algorithm) – 📦 조합 최적화용 하이브리드 알고리즘**

**🔯문제 :**

"도시들을 여행하며 전체 이동 거리가 최소가 되게 하라"

"그래프에서 최대한 많은 간선을 잘라라 (Max-Cut)"

이런 문제들은 NP(Nondeterministic Polynomial)-난해 문제(문제를 풀기는 어렵지만, 이미 주어진 답으로 정답인지 검증은 쉬운 문제)라 고전적인 접근으로 한계

고전 시뮬레이터로는 분자가 조금만 커져도 계산 불가

**🔯아이디어**

양자 회로 파라미터를 조절하면서 근사 최적해를 찾는다

- VQE와 구조 유사 (변분 방식 + 고전/양자 하이브리드)

  - 양자컴퓨터는 cost + Mixer 해밀토니안 기반 회로 실행 및 측정
  - 고전컴퓨터는 목적 함수 최적화, 파라미터 조정

**🔯효과**

- 최적화 문제에 적합
- 현실 문제에 점점 더 많이 시도 중

**🦠변분 방식 알고리즘이란?**

어떤 목적 함수(보통 에너지나 비용 함수)가 최소값을 가질 때, 그 최소값을 갖는 파라미터를 찾아내는 원리로서, 주로 **하이브리드 기법**으로 사용한다. 양자컴퓨터가 파라미터를 생성하면, 고전 컴퓨터로 측정값을 기반으로 그 파라미터를 갱신하면서 최적의 파라미터를 찾는 하이브리드 알고리즘이다. 위에서 살펴본 QAOA와 VQE가 여기에 속한다. 한편, Kipu Quantum이 독자적으로 개발한 **BF-DCQO**는 변분(**變分)**방식이 아닌 순순 양자 알고리즘으로서 동작하는 최적화 알고리즘으로써, 이름에 Counterdiabatic이 있듯이 비분변(**非分變)**이다. 즉 어닐링이 천천히 변화하는 **분변(分變,**Adiabatic)인데 반해 BF-DCQO는 빠르게 변하는 **비분변(非分變, Non-Adiabatic)적**이다.

최근에 IonQ와 Kipu가 협렵하여 단백질 구조를 예측할 때 사용한 알고리즘이다. 이에 대한 자세한 내용은 아래 글을 참고.

**🧠 요약: 얽힘과 중첩, 그냥 현상이 아니라 실전 무기**

|  |  |  |  |
| --- | --- | --- | --- |
| **알고리즘 / 상태** | **주제** | **대표 응용** | **핵심 기술** |
| **Grover** | 정답 탐색 | 비밀번호 크래킹, 퍼즐 | 오라클 + 간섭 증폭 |
| **Shor** | 소인수분해 | RSA 해독 | 위상추정 (QPE) + QFT |
| **QPE** | 고유값 추정 | 양자 시뮬레이션, 선형대수 | 역QFT |
| **VQE** | 분자 에너지 최소화 | 양자화학, 약물 설계 | 변분 원리 + 하이브리드 최적화 |
| **QAOA** | 조합 최적화 | 물류, 스케줄링, 포트폴리오 | 변분 원리 + 하이브리드 최적화 |
| **GHZ 상태** | 다큐비트 얽힘 | 양자 통신, 에러검출, 벨 테스트 | Hadamard + 다중 CNOT로 생성 |
