**💡****양자 알고리즘 (Quantum Part)**

- - 논문에서는 **Projected Quantum Feature Map (PQFM)** 이라는 방법을 사용했다.
  - 구체적으로는:

    - **Heisenberg ansatz 회로(Heisenberg-inspired parameterized circuit)** 를 이용해 **클래식 데이터(feature vectors)** 를 고차원 양자 상태로 임베딩.
    - 이 상태에서 **Pauli 관측자(X, Y, Z 등)** 의 기댓값을 측정해서 **새로운 양자 기반 특성(quantum features)** 을 추출.
    - 즉, 고전 데이터 → 양자 회로 임베딩 → 양자 측정 → 다시 고전 feature 로 변환하는 **양자 특성 생성(quantum feature generation)** 접근법.
  - 중요한 점은, 이 변환 과정에서 **IBM Heron 양자 프로세서(트랜스몬 기반)** 의 실제 노이즈가 반영된다는 것인데, 연구팀은 오히려 이 **하드웨어 노이즈가 feature smoothing 효과**를 주어 성능 개선으로 이어진다고 관찰했다.

**💡****고전적 학습 모델 (Classical Part)**

- - 양자 회로로 변환된 데이터를 그대로 입력해, 기존의 **머신러닝 모델**을 사용했다:

    - **로지스틱 회귀 (Logistic Regression, LR)**
    - **Gradient Boosting (XGB)**
    - **랜덤 포레스트 (Random Forest, RF)**
    - **피드포워드 신경망 (Neural Network, NN)**
  - 즉, **양자 알고리즘 자체가 직접 거래 예측을 수행한 게 아니라, 데이터 전처리 단계에서 양자 회로를 활용**한 것이고, 최종 학습·예측은 전통적인 ML 모델들이 담당했다.

**💡****백테스팅 결과**

- - **클래식 feature → ML 모델** 대비
  - **양자 변환 feature (PQFM) → ML 모델**이
  - **최대 ~34% 성능 개선(AUC 기준)** 을 보였다고 보고했다.
  - 특히 “longer” Heisenberg 회로(깊은 회로, 더 많은 노이즈 포함)에서 가장 큰 개선 효과가 나타났다.

**💡****그림에서 보여주려는 것**

1. 1. **문제 상황 (좌측)**

      - 회사채 시장에서는 고객이 **RFQ(Request for Quote, 가격 문의)** 를 던지면 여러 딜러(은행, 금융기관)들이 가격을 제시함.
      - 각 딜러는 “내가 제시한 가격으로 거래가 성사될 확률(= **fill probability**)”을 추정해서 자기 전략을 짜게됨.
      - 이 과정이 시뮬레이션으로 구현되어 **백테스팅**(과거 데이터로 성능 검증)에 사용됨.
   2. **양자컴퓨터 적용 (우측)**

      - 보통은 모든 딜러가 **고전적 특징(feature)** 만 가지고 확률을 예측하지만,
      - 여기서 **특정 딜러 1명**은 RFQ 특성과 시장 데이터를 **양자컴퓨터**에 통과시킴.
      - 양자컴퓨터는 기존 데이터에서 뽑아내기 어려운 **보완적인 특징(quantum features)** 을 만들어 줌.
      - 이렇게 해서 나온 “양자 보강된 특성”을 사용해, 그 딜러는 더 정교한 fill probability 추정(**P₁**)을 얻게 됨.
   3. **핵심 아이디어**

      - 모든 딜러가 비슷한 데이터를 쓰면 경쟁력이 없는데,
      - **양자컴퓨터를 활용한 딜러는 한 발 앞선 예측력**을 가지게 되는 그림을 보여주려는 것.

---

**💡****그래서 뭘 어떻게 했다는 건데?**

1. 1. **데이터 준비**

      - 유럽 회사채 거래 데이터(고객이 어떤 가격에 사고팔겠다고 문의하는 데이터)를 가져옴.
   2. **양자컴퓨터로 데이터 가공 (Quantum Feature Map)**

      - 데이터를 그냥 쓰지 않고, IBM 양자컴퓨터 위에서 특별한 **양자 회로(Heisenberg ansatz)** 에 넣음.
      - 이 회로는 데이터를 “양자 버전”으로 바꾼 뒤 다시 수치로 뽑아내 주는데,
      - 마치 데이터를 **새로운 각도에서 바라본 특징(feature)** 을 만들어 주는 과정임.
      - 여기서 실제 양자 하드웨어의 노이즈가 섞였는데, 의외로 이게 도움이 됐음 → 데이터를 더 “부드럽게” 만들어준 효과.
   3. **기존 AI 알고리즘에 넣음**

      - 양자 회로에서 나온 데이터를 **로지스틱 회귀, 랜덤포레스트, XGBoost, 신경망** 같은 전통적인 머신러닝 모델에 입력.
      - 이 모델들이 “이 거래 가격으로 체결될 확률”을 예측.
   4. **결과**

      - 그냥 고전 데이터만 썼을 때보다, **양자 회로를 거친 데이터를 썼을 때 예측 성능이 최대 34% 좋아짐.**

**✅ 최최최종 정리:**

- - **원래 방법**: 안경 없이 눈으로만 글자 읽기. (고전 ML)
  - **새 방법**: 양자컴퓨터가 만든 특수한 안경을 쓰고 글자를 읽음 → 글자가 더 선명하게 보임. (양자 feature + ML)
