# Diamond Defects, Now in Pairs, Reveal Hidden Fluctuations in the Quantum World

[Diamond Defects, Now in Pairs, Reveal Hidden Fluctuations in the Quantum World](https://thequantuminsider.com/2025/11/28/diamond-quantum-sensor-princeton/)

**📌 요약**

- - 프린스턴 대학의 **나탈리 드 레온(Nathalie de Leon)** 교수가 이끄는 연구팀은 **다이아몬드 내 질소-공석 결함(NV center) 2개를 매우 가깝게 배치하여 양자 얽힘을 형성한 새로운 양자 센서**를 개발하였음.
  - 이 센서는 기존 방식 대비 **약 40배 높은 민감도**로 **초미세 자기장 변동(magnetic fluctuations)을 측정**할 수 있음.
  - 이 기술은 그래핀, 고온 초전도체 등 실제 양자 재료에서 **나노미터 스케일의 물리 현상을 직접 관측**할 수 있는 새로운 길을 제시함.

**🧠 핵심 기술 포인트**

- **NV 센터 쌍 기반 양자 얽힘 센싱**

  - 질소 분자를 초고속(초당 30,000ft)으로 다이아몬드에 충돌시켜 **20nm 깊이에, 서로 10nm 간격으로 결함 2개를 생성**
  - 두 NV 센터의 전자 스핀을 **양자 얽힘 상태로 결합**
  - 얽힘된 두 센서를 **쌍안경처럼 사용하여 노이즈 속에서 신호를 추출(triangulation)**
- **기존 기술 대비 혁신**

|  |  |
| --- | --- |
| **기존 단일 NV 센서** | **새 얽힘 기반 NV 센서** |
| 독립된 점 센서 | 상호작용하며 공동 측정 수행 |
| 잔류 노이즈 제거 어려움 | 노이즈의 상관성 자체를 활용 |
| 민감도 제한 | **약 40배 향상** |
| 실제 재료 추적 어려움 | 그래핀·초전도체 등 **현실 재료 직접 측정** 가능 |

**🔍 무엇을 측정할 수 있는가**

|  |  |
| --- | --- |
| **측정 대상** | **설명** |
| 전자 mean free path | 전자가 충돌하기 전 이동 가능한 거리 |
| 초전도체 내부 magnetic vortex 진동 | 초전도 특성 및 임계온도 연구 핵심 요소 |
| 나노 스케일 자기장 변동 | 기존 기술로 관측 불가 영역 |

하버드의 **필립 킴(Philip Kim)** 교수는 이를 “현실 재료를 직접 연구할 수 있게 해주는 획기적 기술”이라고 평가.

**🧨 “약점이 강점이 되다” — 연구의 전개**

- - COVID 기간 동안 실험실 접근 제한 → 이론 연구 중심으로 출발
  - **자레드 로브니(Jared Rovny)** 박사가 **상관성(correlation) 기반 센싱**을 탐구
  - 처음에는 **얽힘 없는 2 NV 센서 방식**으로 Science(2022) 논문 발표
  - 그 후 얽힘 도입하여 **단일 측정(single-shot measurement)으로 고감도 센싱 성공**
  - 현재 로브니는 양자 컴퓨팅 스타트업 **Logiqal** 재직
