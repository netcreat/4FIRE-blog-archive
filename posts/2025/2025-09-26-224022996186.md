양자컴퓨터에서는 단순히 비트 값만 바뀌는 것이 아니라 **두 가지 오류 유형**이 존재한다.

- - **Quantum bit-flip (X 게이트)**

- - - → 고전적 비트 플립과 유사.
  - **Quantum phase-flip (Z 게이트)**

- - - → 상태의 위상(phase)이 반전됨.
  - **Y 게이트**

    - Y=*iXZ*
    - 비트 플립과 위상 플립을 동시에 일으키는 오류.
  - 게이트에 대한 자세한 내용은 지난 포스팅 참조.

**💡****신드롬**

- - 각 큐비트의 오류 여부를 체크하기 위해 할당된 비트 또는 큐비트
  - X 신드롬

    - 첫번째 - 1 : 체크하는 큐비트(1,3,5,7)중 3번 큐비트 한곳에서만 비트 에러가 발생했음
    - 두번째 - 1 : 체크하는 큐비트 (2,3,6,7)중 3번 큐비트 한곳에서만 비트 에러가 발생했음
    - 세번째 - 0 : 체크하는 모든 큐비트에서 비트 에러가 없음
  - Z 신드롬

    - 첫번째 - 1 : 체크하는 큐비트(1,3,5,7)중 5번 큐비트 한곳에서만 위상 에러가 발생했음
    - 두번째 - 0 : 체크하는 모든 큐비트에서 위상 에러가 없음
    - 세번째 - 1 : 체크하는 큐비트(4,5,6,7)중 5번 큐비트 한곳에서만 위상 에러가 발생했음

- - 그림에서 보이는 에러:

    - 첫 번째 비트: X (bit-flip)
    - 두 번째 비트: Y (bit+phase flip 동시에)
    - 세 번째 비트: Z (phase flip)
  - 신드롬 계산 결과는 위쪽 파란색(= X 오류 감지)과 아래쪽 빨간색(= Z 오류 감지) 노드의 패리티 값으로 표현된다.
  - 따라서 답은 **110 100**이 맞다.

    - 110 (위쪽) → X 관련 오류 감지
    - 100 (아래쪽) → Z 관련 오류 감지
    - X 신드롬

      - 첫번째 - 1 : 체크하는 큐비트중 1번 큐비트 한곳에서만 비트 에러가 발생했음
      - 두번째 - 1 : 체크하는 큐비트중 2번 큐비트 한곳에서만 비트 에러가 발생했음
      - 세번째 - 0 : 체크하는 모든 큐비트에서 비트 에러가 없음
    - Z 신드롬

      - 첫번째 - 1 : 체크하는 큐비트중 3번 큐비트 한곳에서만 위상 에러가 발생했음
      - 두번째 - 0 : 체크하는 큐비트중 2번, 3번 두 큐비트에서 위상 에러가 발생했기 때문에 패리티 0
      - 세번째 - 0 : 체크하는 모든 큐비트에서 위상 에러가 없음

    - 파란색 노드: 010 → 특정 X 오류 감지

      - 첫번째 신드롬 - 0 : 1,3,5,7 중 0개 또는 2개 오류

        - 1번 큐비트는 오류 없음
      - 세번째 신드롬 - 0 : 4,5,6,7 중 0개 또는 2개 오류

        - 4,5,6,7 큐비트는 오류 없음
      - 두번째 신드롬 - 1 : 2,3,6,7 중 1개 오류

        - 2번과 3번에서 오류가 있는데, 3번에 오류가 있게 되면 첫번째 신드롬도 1이 되어야 하므로
        - **2번 큐비트 오류**
    - 빨간색 노드: 111 → 특정 Z 오류 감지

      - 모든 신드롬이 1이므로, 세 신드롬이 공통적으로 체크하는 큐비트는 7번 큐비트

        - **7번 큐비트 Z 오류**

**💡****Shor code 개요**

- - 피터 쇼어(Peter Shor)가 1995년에 제안한 최초의 **양자 오류 정정 코드**이다.
  - 목적: **비트 플립(X 오류)과 위상 플립(Z 오류)를 동시에 정정할 수 있는 코드**.
  - 구조: **9개의 물리적 큐빗**으로 1개의 논리 큐빗을 인코딩한다.

**💡****동작 원리**

- - **비트 플립 오류 정정**

    - 먼저 1개의 논리 큐빗을 3중 반복 코드로 확장한다.
    - 예:

- - - 이렇게 하면 단일 비트 플립 오류를 다수결로 잡아낼 수 있다.
  - **위상 플립 오류 정정**

    - 각 블록(3개의 큐빗)을 다시 **위상 오류 정정을 위한 코드**로 인코딩한다.
    - 즉, 총 3개의 블록(각각 3큐빗)을 만들고, 위상 플립 오류는 이 블록 구조를 통해 잡아낸다.

**💡****그림 해석**

- - 원형 노드: 데이터(물리 큐빗).
  - 파란색 사각형: **X 오류 감지용 검사 노드** (비트 플립 체크).
  - 빨간색 사각형: **Z 오류 감지용 검사 노드** (위상 플립 체크).
  - 따라서 Shor code는 그래프 구조로 표현했을 때, **비트 플립과 위상 플립을 동시에 검사**할 수 있는 것을 보여준다.

**💡****핵심 요약**

- - **Shor code = 9-qubit code**
  - **비트 플립 + 위상 플립 오류 정정 가능**
  - 이후 더 발전된 Steane code, Surface code 등이 등장했지만, Shor code는 **양자 오류 정정(QEC)의 시작점**이라는 역사적 의미가 크다.
