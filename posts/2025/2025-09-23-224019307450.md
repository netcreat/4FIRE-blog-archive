**💡Yb-171 큐비트**

- - **Hyperfine Qubit (초미세 분리 기반 큐비트)**

    - Yb-171(이트륨바륨-171)은 핵스핀 I=1/2을 가지고 있어, 전자와 핵의 상호작용으로 인해 **기저 상태(****2****S****1/2****)가** ***F*****=0,** ***F*****=1** **두 개의 hyperfine 준위로 갈라짐**.
    - 이 두 준위가 서로 약 **12.64 GHz** 떨어져 있음.
    - 참고로, 슬라이드에는 없지만, **2****P****1/2**에서의 *F'*=0, *F'*=1의 두 준위차는 **2.105GHz 차이**.

      - Selection rule 에 의해 F=0 에서 F'=0 상태로 전이할 수 없음.

        - ΔF = 0, ±1
        - F값이 같거나, ±1 차이가 나는 상태끼리만 전이가 가능함 (단, F=0 ↔ F′=0 전이는 금지)
        - F=0→F′=1 : 허용
        - F=1→F′=0 : 허용
        - F=1→F′=1 : 허용
      - 즉, F=0→F′=1 **전이를 일으키려면 811 THz 기준보다 약 12.6 GHz + 2.1 GHz ≈ 14.7 GHz 더 높은 주파수의 레이저**가 필요한데, 시스템 구성을 그만큼의 에너지를 인가하지 않기 때문에 해당안됨.
      - 결국, 이테르븀을 사용하는 이온트랩에서는 F=0일 때는 전이가 일어나지 않게 되어, dark state가 됨.

**💡Ba-137 큐비트**

- - Ba⁺의 기본 광학 전이는:

    - **6S****1/2** **→ 6P****1/2** **: 493.4 nm ≈ 607.426 THz**
  - 거기에 하이퍼파인 보정을 더해야 함:

    - 바닥 F=1 ↔ F=2 분리: **8.037 GHz**
    - 여기 F′=1 ↔ F′=2 분리: **1.488 GHz**
  - 따라서:

    - **F=2 → F′=1** 전이 = 607.426 THz (기준치)
    - **F=2 → F′=2** = 기준 + 1.488 GHz
    - **F=1 → F′=1** = 기준 – 8.037 GHz
    - **F=1 → F′=2** = 기준 – 8.037 GHz + 1.488 GHz ≈ 기준 – 6.55 GHz

- - **큐비트 정의**

    - ∣0⟩: 기저 상태의 한 hyperfine 준위
    - ∣1⟩: 다른 hyperfine 준위
    - 따라서 큐비트는 Yb-171의 전자 껍질 안에서 만들어진 **두 개의 안정한 hyperfine 상태**로 표현됨.
  - **레이저 전이 (369.5 nm, 811 THz)**

    - 도플러 냉각, 상태 초기화(state preparation), 상태 판독(state detection)에 사용됨.
    - 기저 상태 ↔ 여기 상태(**2****P****1/2**) 전이를 다룰 수 있어, 이온 제어에 필수적.

**💡State Preparation (상태 준비)**

- - **왜 필요한가?**

    - 양자 연산을 하기 전에 모든 큐비트를 **일정한 초기 상태**로 맞춰놓아야 한다.
    - 보통은 ∣0⟩ 상태에 모든 이온을 준비함.
    - 초기 상태가 불균일하면 연산의 신뢰도가 떨어짐.
  - **방법 (레이저 선택적 여기)**

    - ∣1⟩ 상태에 있는 이온만을 **레이저(369.5 nm, 811 THz)** 로 여기 상태(2P1/2)로 올린다.
    - 여기된 이온은 곧 자발 방출(spontaneous emission)로 다시 바닥 상태로 떨어지는데, 이때 확률적으로 ∣0⟩ 상태로 간다.
    - 이런 과정을 여러 번 반복하면, 결국 **모든 이온이 ∣0⟩ 상태로 “펌핑(optical pumping)”** 된다.
    - 이제 양자 알고리즘 시작이 가능해짐.

**💡Ba-137 큐비트**

- - - ∣1⟩ 상태에 있는 이온만을 **레이저(493.4 nm, 607.426 THz)** 로 여기 상태(2P1/2)로 올린다.
    - 나머지 내용은 위와 동일

**💡1 and 2 Qubit Gates (단일 및 이중 큐비트 게이트)**

- - **단일 큐비트 게이트 (1-qubit gates)**

    - **방법**: 레이저를 이용한 **Stimulated Raman Transition(자극 라만 전이)** 사용
    - 특정 이온 하나에 게이트 레이저를 쏘아 단일 큐비트 회전(rotation)을 수행.
    - 즉, Bloch 구면에서 큐비트 상태를 원하는 각도로 회전시킴.
    - 예: ∣0⟩↔∣1⟩ 변환, X, Y, Z 게이트 등

- - **이중 큐비트 게이트 (2-qubit gates)**

    - **방법**: 두 개의 이온을 동시에 게이트 레이저로 조준.
    - 얽힘(Entanglement)은 두 이온만의 직접 상호작용으로 생기는 게 아니라,

      - 이온 사슬 전체의 집단 운동(mode of motion)을 매개체로 사용.
      - 즉, 레이저가 이온의 내부 상태(스핀)와 외부 운동(진동 모드)을 결합시켜 얽힘을 만듦.
    - 대표적인 방식: **Mølmer–Sørensen 게이트, Cirac–Zoller 게이트**.

- - **게이트 구동 방식 비교 (레이저 vs 자기장)**

    - **레이저 - IonQ, Quantinuum 방식**

      - 장점: 빛을 집속(focusing)해서 특정 이온에 정확히 에너지를 전달 가능 → 국소화 쉬움.
      - 단점: 레이저 시스템이 복잡하고 정렬이 어려움.
    - **자기장 (Microwave / Magnetic fields) - Oxford Ionics 방식**

      - 장점: 하드웨어적으로 안정적, 레이저보다 제어 장치가 단순할 수 있음.
      - 단점: 국소화가 어렵지만, 최근에는 기술적으로 많이 성숙해서 레이저 기반 방법을 보완하거나 대체하는 연구 활발.

**💡State Detection (상태 검출)**

1. 1. **목표**

      - 연산이 끝난 뒤, 큐비트가 ∣0⟩인지 ∣1⟩인지 측정해야 한다.
      - 단순히 "레이저를 쏘고 빛이 나오면 ∣1⟩, 빛이 안 나오면 ∣0⟩" 방식으로 구분.
   2. **방법 (레이저 여기)**

      - 레이저(369.5 nm, 811 THz)를 **∣1⟩ 상태와 공명**하도록 맞춘다.
      - **Ba-137인 경우 493.4 nm, 607.426 THz**
      - ∣1⟩에 있는 이온만 2P1/2 준위로 여기됨.
   3. **광자 방출 (Fluorescence)**

      - ∣1⟩ 상태의 이온은 여기와 방출을 반복 → **형광(fluorescence) 빛을 방출**.
      - ∣0⟩ 상태의 이온은 레이저에 반응하지 않음 → **암흑 상태(dark state)**.
      - ∣1⟩에 있는 이온은 레이저로 살짝 펌핑하면 경계선을 넘을 수 있어서 다시 내려오면서 빛을 방출하지만, ∣0⟩에서 출발한 이온은 경계선을 넘을 수 있을만큼의 충분한 에너지가 없는 관계로 횟수를 못채우고 내려오는 상황과 비슷함
   4. **측정 방식**

      - CCD 카메라나 광검출기(PMT 등)가 빛을 감지.
      - 빛이 있으면 → 이온은 ∣1⟩.
      - 빛이 없으면 → 이온은 ∣0⟩.

**💡State Detection (상태 검출)**

1. 1. **광자 수를 세는 방식**

      - ∣1⟩ 상태는 레이저에 의해 반복적으로 여기-방출 사이클을 돌기 때문에 **형광을 많이 방출**.
      - ∣0⟩ 상태는 레이저에 반응하지 않아서 **형광이 거의 없음**.
      - 따라서, 측정은 "얼마나 많은 광자가 검출되었는가?"로 구분.
   2. **임계값(Threshold) 설정**

      - 검출한 광자 수에 따라 ∣0⟩과 ∣1⟩를 구분하기 위해 기준선(검은 선)을 둔다.
      - 슬라이드 예시에서는:

        - **< 2 photons → ∣0⟩**
        - **≥ 2 photons → ∣1⟩**
   3. **그래프 설명**

      - X축: 500 µs 동안 수집된 광자 수
      - Y축: 특정 광자 수가 나올 확률
      - 파란색 분포 (∣0⟩) → 거의 0 근처에 몰려 있음
      - 빨간색 분포 (∣1⟩) → 평균 10개 근처에서 Gaussian 분포
      - 두 분포가 거의 겹치지 않기 때문에, threshold를 정해 잘 구분 가능.

**💡Yb(이테르븀) vs Ba(바륨) 큐비트에서의 상태 검출(State Detection) 성능 비교**

- - 가로축: 읽기 시도당 검출된 광자 수 (Photons Collected Per Readout Attempt)
  - 세로축: Readout Attempts (로그 스케일, 몇 번 그런 값이 나왔는가)
  - **왼쪽 (Ytterbium SPAM Measurement)**

    - 주황색: 실제로 ∣0⟩ 상태를 준비했을 때의 분포
    - 파란색: 실제로 ∣1⟩ 상태를 준비했을 때의 분포
    - 세로 점선(Threshold): 이 선을 기준으로 "광자가 적게 나오면 ∣0⟩, 많이 나오면 ∣1⟩" 라고 판정
    - → Yb에서는 두 분포가 꽤 겹쳐 있어서, 완전히 분리되진 않음 → **검출 정확도 99.66%**
  - **오른쪽 (Barium SPAM Measurement)**

    - 주황색 ∣0⟩ 분포는 광자 수 거의 **0 근처**
    - 파란색 ∣1⟩ 분포는 훨씬 오른쪽으로 **광자가 많이** 나오며 깔끔하게 분리됨
    - 두 분포가 거의 안 겹치기 때문에, 판정이 더 명확
    - → Ba에서는 **검출 정확도 99.96%**

> Ba-137이온은 8.037GHz의 하이퍼파인 주파수를 지니는데, Yb-171대비 주파수가 낮아서 **RF 회로 설계가 조금 더 쉽다는 장점이 있다.**
>
> Ba-137이온은 **상태 검출 성능이 Yb-171에 비해 훨씬 뛰어나서 오류율이 낮다**.

**💡광 경로**

- - **레이저 소스**

    - 라만 전이에 쓰는 안정화된 레이저(주파수 드리프트·선폭 관리).
    - 전·후단에 AOM/EOM로 **펄스 모양/세기/주파수 오프셋**을 만들 수 있음.
  - **멀티채널 모듈레이터(Multi-Channel Modulator)**

    - “IonQ가 처음 창업할 때 썼던 기술”
    - 내부에 **다중 AOM/EOM 어레이**가 있어 **각 채널을 독립 제어**(ON/OFF, 진폭, 주파수, 위상).
    - 채널별로 서로 다른 **게이트 톤**(단일/2큐비트용 비트노트)을 동시에 띄울 수 있음
  - **회절/분기 광학(DOE, 마이크로렌즈 배열 등)**

    - 한 줄로 배열된 **여러 개의 평행 빔**으로 “팬아웃”.
    - 이후 **릴레이 렌즈 + 고NA 집광 렌즈**로 이온 사슬 평면에 **스폿 배열**을 형성.
  - **이미징/정렬**

    - 이온-칩 위를 **수 µm 스폿**으로 찍고, 이온 간 간격(보통 수 µm)을 넘지 않도록 **크로스토크**를 억제.
    - 채널-좌표 **캘리브레이션 맵**을 만들어 “채널 i → 체인의 j번째 이온”으로 대응시킴.
    - 온도·진동으로 인한 빔 포인팅 변화를 **피드백**으로 보정.
  - **수집 광학**

    - 상태검출 때 형광을 **대구경 렌즈/현미경**으로 모아 PMT(또는 카메라)로 보냄(영상에서 큰 원형 렌즈로 표시).

**💡게이트 동작**

- - **그림 설명**

    - **주황색 점들 (가로 줄, 중앙 아래)**

      - → 선형 이온 트랩 안에 배열된 **이온 체인**이다. 각 점 하나가 큐비트 역할을 하는 단일 이온.
    - **세로로 굵은 주황색 빔들**

      - → 나눠진 **게이트 레이저 빔**이 특정 이온 위치에 맞춰 초점이 맺힌 모습.
      - → 여러 갈래로 분리된 빔 중 선택된 일부가 켜져서 특정 이온을 겨냥한다.
    - **오른쪽 상단의 회로도(박스가 그려진 도표)**

      - → 양자 회로 다이어그램. 가로줄은 각각 큐비트, 직사각형 박스는 게이트 연산.
      - → 실제 광학 게이트 작동(빔이 특정 이온을 때리는 것)을 추상화해, 회로 기호와 1:1로 연결된 걸 보여주고 있다.
  - **동작 원리**

    - **레이저 소스** → 하나 혹은 소수의 안정화된 레이저를 사용.
    - **멀티채널 모듈레이터 + 회절 광학** → 레이저 빔을 수십 갈래로 나눠, 각 갈래를 독립적으로 켜고 끌 수 있음.
    - **집광 렌즈**로 초점 → 각각의 갈래가 이온 체인 위 특정 이온에만 도달.
    - **게이트 실행**:

      - **단일 큐비트 회전**: 한 이온 위에만 빔을 맞춰서 상태를 바꿈.
      - **이온 두 개 동시에 겨냥**: 두 이온에 빔을 동시 조사 → 모서-소렌슨(Mølmer–Sørensen) 같은 2큐비트 게이트 실행.
      - **병렬 연산**: 여러 빔을 동시에 켜서 **다른 쌍의 이온들**에도 연산을 병렬적으로 수행 가능.
