**⚛️원자의 이해**

일단, 이 글을 읽고 있다는 건 그 전에 양자컴퓨터의 원리, 양자 역학 그리고 양자 역학의 간단한 역사에 관련된 글이나 동영상을 한번쯤은 접했다는 뜻으로 해석될 수 있다.

**🧬양자역학의 간략한 역사**

1897년 톰슨(영국의 물리학자이자 노벨상 수상자 - 러더퍼드, 막스 보른, 오펜하이머등의 스승. 그의 아들 역시 노벨상 수상)을 시작으로, 러더포드, 보어 등 많은 물리학자가 원자의 모형을 정의하고, 오류를 찾아내고 다시 그리고를 반복하면서, 점차 양자역학의 토대를 갖췄는데, 아인슈타인이 광전효과를 발견하면서 양자역학은 여러 물리학자들로 하여금 흥미를 갖게했고, 급기야는 양자역학의 발전에 기폭제 역할을 한 아인슈타인은 양자역학을 지지하는 여러 물리학자들을 상대로 힘든 싸움을 했어야 했다.

그 후 드브로이, 슈뢰딩거(고양이 주인), 하이젠베르크 등의 물리학자들에 의해 불확정성의 원리가 정의되고, 더 나아가 원자모형을 이해하는데 파동역학 또는 양자역학이 더욱 기반을 다졌다. 그후 오스트리아 출신의 물리학자인 파울리가 "**파울리의 배타 원리**"를 발표하고, 그는 그 공헌으로 노벨 물리학상을 받게 된다. 우리가 학교에서 배웠던 주기율표도 이 원리에 의해 만들어지게 된다.

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/8/8c/Evolution_of_atomic_models_infographic.svg/1920px-Evolution_of_atomic_models_infographic.svg.png)](#)

**⚛️원자와 양자**

원자는 원자핵(양성자 + 중성자)과 전자로 이루어져 있고, 전자가 위치하는 곳을 원자 궤도라고 하는데, 이 때 이 궤도는 전자의 **에너지(n), 궤도각운동량(L) 및 벡터성분(방위 양자수-m)**의 고유 한 값의 집합으로 결정된다.

닐스 보어는 원자 모델을 제안할 때 전자껍질을 제시했는데, 전자가 원자핵 주변에 있을 수 있는 특정 궤도가 있고, 그 궤도와 궤도 사이에는 절대 전자가 존재할 수 없다고 설명한다. 1번째 혹은 2번째 궤도에는 존재할 수 있어도 1.5번째에는 존재하지 않는 다는 사실에 기반해 이를 **양자(****量子, quantum)**라고 일컫는다. 이는 전자가 파동의 성질을 갖고 있어서, 특정 궤도에서 벗어나면 파동, 즉 주파수와 궤도의 이동 거리가 일치하지 않아, 스스로 감쇠현상이 일어나서 소멸될 수 밖에 없기 때문이다.

**🧲전자 껍질 (원자 궤도)과 주기율표**

전자는 기본적으로 가장 안정적인 궤도를 따라 원자핵 주변을 도는데, 이 상태를 바닥 상태라고 말하고, 이 상태에서 에너지를 받으면 다음 궤도로 올라가게 된다. 이를 들뜬 상태라고 한다. 위 그림은 보어의 원자 모형인데, 각 궤도별 궤도의 이름이 존재한다. 순서대로 K, L, M, N, ...(당시 X선 표기법에 따라 K부터 사용했음). 각 원자별로 K에만 전자가 있는가 하면, K,L,M에도 전자가 있는 원자들이 있다. 아래 주기율표에서 보면 각 주기가 전자가 위치한 최대 궤도를 나타낸다.

즉, 수소와 헬륨은 각각 전자가 한개, 두개 있는 원자로서 하나의 원자궤도(K)만 있는 원자이고, 리튬부터 네온까지는 두개의 원자궤도(K, L)가 있는 원자들이다.

출처 : 위키피디아

각 전자 껍질은 정해진 수의 전자만 담을 수 있는데, 1923년에 에드문드 스토너에 의해 도입된 2(n2)개의 공식으로 사용된다. 1925년 파울리의 배타 원리에 따르면 **서로 다른 전자는 항상 다른 상태에 있어야 한다.** 여기서 말하는 상태는, 4가지 숫자에 의해 달라질 수 있다.(위에서는 세가지라고 했지만, 파울리가 네번째 양자수인 스핀양자수를 추가했다)

- 주양자수 n
- 방위양자수 ℓ
- 자기양자수 mℓ
- 스핀양자수 ms

|  |  |  |  |
| --- | --- | --- | --- |
| **양자수** | **기호** | **의미** | **가능한 값** |
| 주양자수 | n | 에너지 준위, 거리 | 1, 2, 3, ... |
| 방위양자수 | ℓ | 부껍질 형태 (s, p, d, f) | 0 ~ n−1 |
| 자기양자수 | mℓ | 부껍질 방향 | −ℓ ~ +ℓ |
| 스핀양자수 | ms | 전자의 회전 방향 | **+½, -½** |

**🧲부껍질 (혹은 오비탈, 세부구조, 세부궤도)**

전자는 껍질이라고 알려진 각 에너지 준위에서 보다 다양한 상태로 분류되고, 이를 부껍질, 오비탈, 세부궤도라고 한다. 앞으로 **오비탈**로 통일하겠다. 각 오비탈은 "위" 또는 "아래"라는 스핀으로 구분되어 **최대 두개의 전자**를 가질 수 있다. 다시 말해, 파울리의 배타 원리에 따라 스핀이 같은 두 전자는 같은 궤도에 존재할 수 없다.

오비탈도 분류하는 방법이 아래와 같은데, 자세히 살펴보자.

|  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| **오비탈**  **기호** | **ℓ** | **가능한 mℓ 개수** | **최대 전자수** | **포함하는**  **껍질** | **역사적 이름** | **모양** |
| **s** | 0 | 1  (0) | 2 | 모든 껍질 | **s**harp | 구형 |
| **p** | 1 | 3  (−1, 0, 1) | 6 | 2번째 껍질 이상 | **p**rincipal | 덤벨 |
| **d** | 2 | 5  (−2, −1, 0, 1, 2) | 10 | 3번째 껍질 이상 | **d**iffuse | 클로버 |
| **f** | 3 | 7  (−3, −2, −1, 0, 1, 2, 3) | 14 | 4번째 껍질 이상 | **f**undamental | 복잡한 형태 |

각 오비탈의 부호를 지칭할때에는 껍질+오비탈 형식으로 사용된다. 즉 2번째 궤도의 p라면 2p이다.

각 오비은 최대 가질 수 있는 전자의 수는 각각 4+2L의 공식으로, 2,6,10,14,18 으로 정해진다.따라서 각 껍질별로 가질 수 있는 최대 전자의 개수는 오비탈의 최대 전자수를 더한것과 같다.

아래 표를 보면 세부구조의 체계를 알 수 있다.

첫번째 궤도 K(n=1)에는 s라는 하나의 오비탈이 있는데, 첫번째 궤도에 있는 s라서 1s라고 하고, s가 가지는 궤도양자수는 1이고, 최대로 전자 두개를 가질 수 있기 때문에, 총 전자수가 2가 된다.

두번째 궤도L에는 각각 s와 p 두개의 오비탈이 존재하고, 각 오비탈은 궤오양자수가 각각 1과 3이기 때문에 최대 2와 6의 전자 가질 수 있으므로, 최대 8개의 전자를 가질 수 있다.

**🧲주기율표에서 족과 주기**

주기율표에서 족은 세로줄, 주기는 가로줄을 의미한다.

|  |  |  |
| --- | --- | --- |
| **용어** | **의미** | **방향** |
| **족 (Group)** | 같은 열(세로줄) | **세로** |
| **주기 (Period)** | 같은 행(가로줄) | **가로** |

- 같은 족에 속한 원소들은 전자배치의 최외각 전자 수가 같아서, 화학적 성질이 비슷함.

  - 1족: H, Li, Na, K (→ 전부 s¹ 구조, 반응성이 강한 금속/비금속)
  - 17족: F, Cl, Br (→ 전부 p⁵ 구조, 강한 산화력 가진 할로겐)

족(Group)은 최외각 전자의 배치(= 원자가 전자)를 기준으로 나눈다.

|  |  |  |  |
| --- | --- | --- | --- |
| **족 번호** | **최외각** | **예시** | **특징** |
| **1족** | s¹ | H, Li, Na | 알칼리 금속 |
| **2족** | s² | Be, Mg | 알칼리 토금속 |
| **13~18족** | p¹ ~ p⁶ | B~Ne 등 | 대표원소군 (p-block) |
| **3~12족** | d¹ ~ d¹⁰ | Sc ~ Zn 등 | 전이금속군 (d-block) |
| **f-block** | f¹ ~ f¹⁴ | 란타넘계, 악티늄계 | 족 번호는 X (별도로 분리) |

- s-block: 2족 ( 헬륨은 2족이지만 1s가 완전히 채워져 있는 안정한 구조라서, 화학적 성질 기준으로 18족-비활성 기체로 배치)
- p-block: 6족
- d-block: 10족
- → 2 + 6 + 10 = 18족

**🧮란타넘족, 악티늄족**

- - f-block은 주기율표의 란타넘족(La–Lu), 악티늄족(Ac–Lr) 원소들에서 나타남
  - 우리가 잘 알고 있는(그냥 많이 들어본) **이테르븀이** 란타넘족에 속하는 원소이다.
  - 이들은 4f (n=4)와 5f (n=5) 에 전자가 차는 시기이며,
  - 주기율표의 아래쪽 두 줄로 따로 빼서 그리는 이유가 바로 여기에 있음

**🔬 2. f-block은 족을 따로 만들지 않는 이유**

|  |  |
| --- | --- |
| **항목** | **설명** |
| **족(Group)** | **세로 줄**이며, **원자가 전자의 수와 화학적 성질**이 비슷한 원소들이 모임 |
| **f-block 원소들** | 전자가 **f-block**에 들어가지만, 최외곽 s 전자가 대부분 같고, **화학적 성질이 서로 비슷하지 않음** |
| **결론** | 족으로 묶기 어려워서, **그룹 번호는 부여되지 않음** (공식적으로는 “족 외 원소”) |

f-block은 주기율표에 "행"으로 반영되지만 "족"으로는 반영되지 않아서 족은 18에서 멈춤

|  |  |  |
| --- | --- | --- |
| **오비탈** | **유형** | **포함되는 족** |
| s-block | s | 1, 2족 |
| p-block | p | 13 ~ 18족 |
| d-block | d | 3 ~ 12족 |

**오비탈 에너지 및 채움 순서**

위의 표에서 오비은 s, p, d, f순서라던데, 실제 포함되는 족에서는 d 가 p보다 먼저 인 이유는 아래와 같이 채워지는 순서가 정해져 있기 때문이다.

이는 "전자는 에너지가 낮은 순서부터 채워진다"라는 오프바우 원리(Aufbau Principle)에서 나온다. "총에너지=n + ℓ"

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **오비탈** | **n** | **ℓ** | **n+ℓ** | **에너지 순위** |
| 3d | 3 | 2 | **5** | ↑ 높은 에너지 |
| 4s | 4 | 0 | **4** | ↓ 낮은 에너지 |

**⚛️****동위원소**

각 원소의 원자를 사용할때 기본 원자 대신 동위원소를 사용하는데, 핵심 이유는 큐비트로 쓰이는 이온은 양자의 상태가 매우 정밀해야 하고, 이를 위해서는 스핀 구조, 하이퍼파인 구조, 제어의 안정성 등을 고려해서 동위원소를 사용하게 된다.

**🧬이온상태에서의 큐비트**

**🕐****파인 구조 (Fine Structure)**

- 원래는 하나로 생각되던 에너지 준위가 **상대론적 효과**와 **스핀-궤도 상호작용** 때문에 분리되는 현상.
- 전자 속도가 빛의 속도에 비례할 만큼 빠를 때 생기는 상대론적 질량 증가 효과.
- **스핀-궤도 결합 :**

  - 전자의 궤도 운동에 의한 자기장 ↔ 전자의 고유 스핀 자기 모멘트가 상호작용.
- 핵스핀이 존재하지 않는 이온에서 큐비트 제어용으로 사용
- 대표적 예시:

  - 바륨

    - 중성 바륨 : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p6 5s2 4d10 5p6 6s2
    - 바륨 이온 : 1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p6 5s2 4d10 5p6 6s1
    - 파인 구조 : 6s1가 6S1/2 ↔ 5D3/2 또는 6S1/2 ↔ 6P1/2 로 분리됨

**🕐****하이퍼파인 구조 (Hyperfine Structure)**

- **전자 스핀**과 **핵스핀** 사이의 자기적 상호작용.
- 파인 구조보다 훨씬 더 작은 규모의 에너지 분할.

**🕐****핵스핀 (Nuclear Spin,** ***I*****)**

- 원자핵을 구성하는 **양성자와 중성자**들의 스핀 합성값.
- 양성자, 중성자는 모두 스핀 1/2 페르미온 → 이들의 결합 방식에 따라 전체 핵스핀이 결정됨.
- 대표적 예시:

  - 138Ba+: 핵스핀 *I* = 0 (핵스핀이 없으므로, 하이퍼파인 구조를 만들 수 없음)
  - 171Yb+: 핵스핀 *I* = 1/2
  - 137Ba+: 핵스핀 *I* = 3/2
  - 43Ca+ : 핵스핀 *I* = 7/2

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **핵종 기호** | **핵스핀**  ***I*** | **전자스핀**  **S=1/2** | **가능한 총각운동량**  ***F*** **값** | **총 하이퍼파인 상태수**  **(*****mF*** **상태)** |
| **138Ba** | **0** | **1/2** | **** | **(하이퍼 파인구조 없음)** |
| **171Yb** | 1/2 | 1/2 | 0, 1 | 1 + 3 = 4 |
| **137Ba** | **3/2** | **1/2** | **1, 2** | **3 + 5 = 8** |
| **43Ca** | 7/2 | 1/2 | 3, 4 | 7 + 9 = 16 |

전체 각운동량 F= I + S 또는 F=I-S

137Ba를 예를 들면

F=3/2 +1/2=**2**와 3/2-1/2=**1** 이렇게 두개의 값이 나온다.

여기에서 각 F상태는 2F+1개의 mF(자기양자수) 상태를 가지게 된다.

다시 137Ba를 예를 들면, F가 1일 경우, mF는 3, F가 2일 경우 mf=5, 총 8개의 하이퍼 파인 상태를 가질 수 있다. 하지만 실제 큐비트를 사용할 때에는 F=1, mF=0인 경우(|0⟩)와 F=2,mF=0인 경우(|1⟩)만 사용한다.

|  |  |  |
| --- | --- | --- |
| **구분** | **138Ba⁺ (파인구조, 핵스핀 없음)** | **137Ba⁺ (하이퍼파인구조, 핵스핀 3/2)** |
| **큐비트 구현 방식** | 전자 파인구조(예: 6S₁/₂ ↔ 5D₅/₂ 등 두 에너지 준위) | 바닥상태 하이퍼파인 준위 |
| **에너지 분할** | 파인구조: **주로 광학(레이저) 영역**, MHz~THz | 하이퍼파인: **마이크로파/라디오파**, GHz |
| **코히런스 타임** | **짧은 편** (자기장 잡음에 취약) | **매우 김** (수십 초~수분, 환경 잡음에 강함) |
| **제어/측정** | 광학적 레이저로 직접 제어, 빠른 연산 가능 | 마이크로파 또는 Raman 레이저로 제어, 측정 안정적 |
| **큐비트 판독** | 파인구조 상태 간 형광 신호로 판독 | 하이퍼파인 상태 간 형광 신호로 판독 |
| **응용** | 광학적 인터페이스, **포토닉 통신에 유리** | **장기 기억, 신뢰성 높은 양자정보처리** |
| **장점** | - 레이저 제어 간단  - **빠른 연산 가능**  - 포토닉 통신에 적합 | - **긴 코히런스 타임**  - **자기장 잡음에 강함**  - "clock state" 선택 가능 |
| **단점** | - 자기장 잡음에 매우 민감  - 코히런스 타임 짧음 | - **레벨 구조 복잡**  - 제어 레이저 세팅 복잡 |

**⏰Clock Transition**

- clock transition은 하이퍼파인 상태가 있는 경우에서만 정의된다.
- 특정한 두 하이퍼파인 상태 사이의 전이(clock transition)는 외부 자기장 변화에 대해 1차 미분값이 0이 되는 지점에서 일어나므로, 주파수 변화가 매우 작고, 외부 환경에 덜 민감하다.
- 양자컴퓨터, 원자시계, 정밀 분광 등에서 사용된다.
- 즉 138Ba 은 하이퍼파인 상태가 없기 때문에 Zeeman효과에 노출될 가능성이 크고, 코히런스가 짧은 특성이 있다.
- 예시

  - 137Ba는 핵스핀 I=3/2를 갖고 있어서 하이퍼 파인 구조가 존재한다.
  - **6S****1/2****바닥상태**는 하이퍼파인 분할로 F=1, 2 두 상태로 나뉘고, 이들 사이의 특정 전이(F=1, mF=0인 경우(|0⟩)와 F=2,mF=0인 경우(|1⟩)가 clock tansition이 된다.
- 이 전이는 외부 자기장 변화에 대해 1차적으로 무감각하여 긴 코히런스 타임과 정밀한 주파수 기준을 제공한다.

> 137Ba이 다른 원자나 동위원소에 비해서 보다 안정적인 큐비트를 구현할 수 있고 광자 검출이 용이하기 때문에 사용하게 된 것인데, 왜 이온상태여야 하냐면, 전기적으로 가두려면(트랩) 중성이 아닌 전하 상태여야 가능하기 때문이다.

지금까지 이온트랩에서의 큐비트 구현을 이해하는 데 필요한 여러 기초지식을 살펴보았다. 글이 너무 길어져서 두편으로 나누게 되었으니 다음 글에서는 보다 흥미 있는 내용을 다뤄보도록 하겠다.
