# IonQ, 슬로바키아 최초의 국가 양자 통신 네트워크 구축으로 EU 내 입지 확대

**IonQ, 슬로바키아 최초의 국가 양자 통신 네트워크 구축으로 EU 내 입지 확대**

**2025년 12월 8일**

**슬로바키아 과학 아카데미와 협력… 국가 안보 및 유럽 양자 통신 인프라 강화**

- - 미국 메릴랜드주 칼리지 파크 — (Business Wire) — 세계를 선도하는 양자 컴퓨팅 기업 IonQ(뉴욕증권거래소: IONQ)는 자회사인 ID Quantique(IDQ)를 통해, **슬로바키아 최초의 국가 양자 통신 네트워크 구축을 공식 발표했다.** 본 시스템은 슬로바키아 과학 아카데미 산하 물리연구소(IPSAS)와의 협력을 통해 개발되었으며, 국가 사이버 보안 인프라를 강화하고 유럽의 양자 디지털 프로그램을 지원하기 위한 ‘복원력 있는 하이브리드 네트워크 아키텍처’를 특징으로 한다.
  - 이번 **슬로바키아 양자 통신 인프라(skQCI) 프로젝트**는 유럽연합(EU) 전역에 **양자 내성 보안 통신망을 구축하는 ‘유럽 양자 통신 인프라(EuroQCI)’ 이니셔티브**에 대한 슬로바키아의 기여에서 중요한 이정표를 의미한다. 국가 단위에서 양자 보안 기술이 통합됨으로써, 슬로바키아의 주요 핵심 기관들의 보안 역량이 직접적으로 강화될 전망이다.
  - IonQ의 회장 겸 CEO 니콜로 데 마시(Niccolo de Masi)는 다음과 같이 말했다.

> “skQCI 프로젝트는 EU의 디지털 주권을 강화하는 데 있어 전략적으로 매우 중요한 이정표입니다. IonQ의 양자 안전 네트워킹 기술과 슬로바키아 과학 아카데미의 과학적 리더십을 결합함으로써, 우리는 유럽의 모델이 될 수 있는 안전하고 복원력 있으며 최첨단의 양자 통신 네트워크를 구축하고 있습니다.”

- - 본 시스템은 **네 개의 전략적 거점을 대상으로 한 최첨단 QKD(양자 키 분배) 아키텍처를 통해**, 수도권 및 원격 지역의 여러 사이트를 연결하여 **안전한 데이터 전송을 보장**한다. 또한 **국가 간 연결 구간에는 QKD와 PQC(양자내성암호)를 결합한 하이브리드 보안 시스템**이 적용된다.
  - 슬로바키아 과학 아카데미 물리연구소의 디렉터 마리오 지만(Mario Ziman)은 다음과 같이 밝혔다.

> “이번 프로젝트를 통해 슬로바키아는 유럽 내 양자 통신 분야의 최전선에 서게 되었으며, 동시에 핵심 국가 기관 전반에 혁신적인 양자 기술을 실제로 통합한 대표적인 실증 사례가 되었습니다.”

- - 이번 프로젝트는 슬로바키아 최고 권위의 과학 연구 기관인 슬로바키아 과학 아카데미(IPSAS)가 주도하고, 슬로바키아 국가 양자기술센터(QUTE.sk)의 지원 아래 진행되었다. 이는 슬로바키아가 전략적 연구 역량과 사이버 보안 인프라 강화를 국가 차원의 핵심 과제로 삼고 있음을 보여준다.
  - 특히 **브라티슬라바 대도시권에서는**,

    - **대통령궁(Office of the President)**
    - **국가보안청(National Security Authority)**
    - **슬로바키아 과학 아카데미 양자 파빌리온(Quantum Pavilion)**
  - 등의 핵심 기관들이 **skQCI 네트워크를 통해 안전하게 상호 연결**된다.
  - 이번 구축은 IonQ가 최근 스위스 제네바에서 학계·정부·산업계를 연결하는 ‘제네바 양자 네트워크’를 출범한 데 이은 행보이며, 다음과 같은 **유럽 및 글로벌 전략 확대와도 맞물린다.**

    - **이탈리아 정부와 Q-Alliance를 통해 이탈리아를 양자 허브로 육성**
    - **영국 옥스퍼드를 IonQ의 EMEA 본부로 지정**
    - **한국 국가 양자센터 오브 엑설런스의 주력 양자 파트너로 선정**

---

**✅이번 기사의 의미**

**1️⃣ IonQ는 이제 “양자컴퓨터 회사”가 아니라**

- - **👉 유럽 국가 안보 인프라 공급사 레벨로 진입**
  - 이 사업의 본질은 **QC(양자컴퓨터)가 아니라 QKD + PQC 보안망 구축 사업**이다.
  - 즉, IonQ는 이제:

|  |  |
| --- | --- |
| **기존** | **지금** |
| 양자컴퓨터 하드웨어 기업 | ✅ 유럽 국가 안보 통신 인프라 기업 |
| 클라우드용 QPU 제공 | ✅ 국가 핵심기관 직접 연결 |
| 연구·산업 위주 | ✅ 대통령궁·국가보안청 연결 |

- - 이건 "실험용 양자 보안"이 아니라 "운영용 국가망"이다.

**2️⃣ 이건 슬로바키아 하나가 아니라**

- - **👉 EuroQCI 전체로 확장되는 실질 레퍼런스 1호**
  - EuroQCI는:

    - ✅ EU 27개 전 회원국
    - ✅ 위성 + 지상 광망
    - ✅ 국가 안보, 국방, 금융, 정부망
    - ✅ “EU 버전 양자 인터넷”
  - **이번 skQCI는:**

    - IonQ(IDQ)가 유럽 국가 양자 보안망의 “공인 시공사”로 인정받았다는 최초 사례
  - 이제 다음 국가들은 이렇게 된다:

    - “슬로바키아에서도 IonQ로 했네? 그럼 우리도 IonQ로 가자.”
  - 이게 **플랫폼 락인 효과**다.

**3️⃣ IonQ의 진짜 무기는 이제 QPU보다**

- - **👉 “Hybrid QKD + PQC 국가 인프라 패키지”**
  - 기사에서 가장 중요한 문장:

> ***“Hybrid QKD–PQC system for cross-country connection”***

- - 이건 의미가 크다.

|  |  |
| --- | --- |
| **QKD만** | **QKD + PQC** |
| 광섬유 필수 | ✅ 인터넷 위에서도 적용 가능 |
| 구축비용 높음 | ✅ 비용 대폭 절감 |
| 도시 내부 중심 | ✅ 국가 간 연결 가능 |
| 실험적 성격 | ✅ 상용 국가망 가능 |

즉:

> ***IonQ는 이제 ‘비싼 실험망’이 아니라***
>
> ***‘실제 국가망으로 바로 구축 가능한 양자 보안 패키지’를 완성한 상태***

**4️⃣ IonQ의 “유럽 지배 전략”이 완전히 드러남**

이번 기사에 나온 지역들을 정리하면:

|  |  |
| --- | --- |
| **지역** | **의미** |
| 🇨🇭 스위스 제네바 | 국제기구·중립국 보안 허브 |
| 🇮🇹 이탈리아 | 국가 양자 허브(Q-Alliance) |
| 🇬🇧 옥스퍼드 | EMEA 본부 |
| 🇸🇰 슬로바키아 | EuroQCI 실전 국가망 |
| 🇰🇷 한국 | 국가 양자센터 주력 파트너 |

이걸 한 줄로 요약하면:

> ***IonQ = “미국 양자컴” → “유럽·아시아 국가망 플랫폼 기업”으로 변신 중***

**5️⃣ 투자 관점에서의 진짜 의미 (가장 중요)**

- - 이 뉴스는 **“단발성 수주”가 아니라 “구조적 반복 수익 모델”의 시작**이다.
  - 앞으로 반복될 구조:

    - EU 국가 1곳 구축
    - 유지보수
    - 업그레이드
    - PQC 칩 교체
    - 위성 QKD 연동
    - 국방·C2·전력망 확장
  - 즉:
  - IonQ는 이제 “국가당 수천억짜리 장기 인프라 사업”을 27번 반복할 수 있는 위치에 올라섰다
  - 이게 시장이 아직 제대로 반영 못 하는 "숨은 가치"이다.

**6️⃣ 주목해야 할 가장 핵심 포인트**

- - 이 뉴스의 본질은:

> ***IonQ는 이제 “양자컴 실험기업”이 아니라 “EU 국가 안보 통신망 공급자”가 되었다***

- - 그리고 이건:

    - 나스닥 퀀텀 테마주 → ❌
    - **국방·정부·EU 예산이 직결된 전략 인프라주** → ✅
