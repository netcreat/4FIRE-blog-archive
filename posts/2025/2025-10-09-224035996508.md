**✅****PQC / 양자보안 기업의 역할**

|  |  |
| --- | --- |
| **역할 / 기능군** | **설명 / 활동 예시** |
| **하드웨어 설계 및 칩 개발** | PQC 알고리즘을 빠르고 에너지 효율 있게 구현하기 위한 전용 암호칩, 보안 하드웨어 보조기기 설계 및 제작 |
| **암호 라이브러리 & 프로토콜 구현** | NIST 표준 PQC 알고리즘(예: Kyber, Dilithium, SPHINCS+)의 효율적, 안전한 구현 (소프트웨어/펌웨어) |
| **보안 모듈 / HSM / 보안 엔클레이브 / TPM 통합** | PQC를 적용한 하드웨어 보안 모듈(HSM, Secure Element) 또는 보안 칩셋 통합 |
| **공개키 기반구조(PKI), 인증서 서비스** | PQC 기반 인증서 발행, 키 관리, 증명서 교환 시스템 설계 및 제공 |
| **네트워크 / 통신 보안 / 암호화 솔루션** | TLS, VPN, IPsec, QUIC 등 통신 프로토콜에 PQC를 통합한 제품 또는 솔루션 |
| **컨설팅 / 적응 마이그레이션 / 보안 감사** | 기업/기관의 기존 암호 시스템을 PQC 체계로 전환하기 위한 로드맵, 보안 검토, 시험 및 검증 |
| **시스템 통합 / PoC / 파일럿 배포** | 실제 운영 환경에서의 PQC 테스트, 파일럿 프로젝트, 상호 운용성 검증 |
| **연구 & 표준화 활동** | 알고리즘 최적화, 새로운 PQC 후보 연구, 표준 제출 또는 참여 |
| **운영 키 인프라 제공 / 서비스형 보안 (Security as a Service)** | 클라우드 기반 PQC 키 관리 서비스, 인증서 관리 서비스 등 |

지난 달에 포스팅한 맥킨지 보고서에 따르면, PQC를 포함한 양자통신 시장이 2024년 대비 각각 **1400%**(2035년)과 **3500%**(2040년) 성장할 것으로 예상하고 있다. 자세한 내용은 아래 포스팅에서 참고바람.

**💡****시장 맥락 & 특징**

- - PQC 시장은 아직 초기 단계지만, **2024년 기준 약 USD 1.15 B** 규모로 평가되며, 2025–2030년 기간 동안 **연평균 약 37.6 % 성장**이 예측됨.
  - 기존 보안 업체(Thales, Entrust, Utimaco 등)와 클라우드/IT 인프라 업체들도 PQC 전환 전략을 채택 중이며, 스타트업 + 연구 중심 기업과 경쟁 및 협업 구조가 복합적으로 얽혀 있음.
  - PQC 기업들은 대개 다음 종류의 역량 조합을 갖추려 함:

    1. 수학/암호학 연구 역량
    2. 효율적인 구현 (소프트웨어 & 하드웨어)
    3. 표준/인증 준수 (예: NIST PQC 표준)
    4. 보안 모듈, 키 관리, 보안 하드웨어 통합 역량

**✅****BTQ Technologies (NASDAQ: BTQ)**

- - **비지니스 모델**

    - 포스트-양자(PQC) 소프트웨어/도구 +(초기 단계) 중성원자 기반 풀스택 QC R&D.
    - 대표 포트폴리오(변동 가능): PQScale(격자기반 서명 압축/검증 가속), Keelung(ZK-DSL), Kenting(ZK/암호 연산 가속 HW 연구), QPoW(블록체인 합의 연구) 등.
    - 2025-09-26 나스닥 업리스트(심볼 BTQ) 완료.
  - **시장/포지셔닝 & 경쟁**

    - 카테고리상 “PQC 소프트웨어/서비스”의 극초기, 군소 플레이어.
    - 대형 벤더(IBM, MS, Thales, Quantinuum, PQShield 등)가 표준 채택 주도. PQC 시장은 2025년 수억~10억 달러대로 급성장 전망.
    - 간접 경쟁: Cloudflare 같은 대형 인프라 사업자의 전면적 PQC 도입(Zero-Trust/네트워킹에 PQC 기본 탑재).
  - **재무(최근)**

    - ’24 매출 수십만 CAD, ’25 LTM 매출 약 0.89M CAD 수준(아주 초기 매출).
    - 업리스트 직후로 규모의 경제/수익성은 아직 미확립 단계.
  - **시장 점유율(해석)**

    - 공신력 있는 ‘점유율’ 데이터 부재. PQC 소프트웨어 시장은 태동기이며, BTQ는 니치(블록체인·ZK 툴체인)에 포지셔닝된 소형 업체.
  - **SWOT**

    - **S(강점)**: PQC+ZK 결합 역량(서명 압축/검증 가속 등 특화), 상장으로 자본시장 접근성↑.
    - **W(약점)**: 매우 작은 매출 기반·고객 레퍼런스 제한, 대형 클라우드/보안 플랫폼 대비 생태계 파워 약함.
    - **O(기회)**: 미국·EU 규제기관의 PQC 전환 권고 가속, 블록체인·지갑/서명 최적화 수요.
    - **T(위협)**: 대형 벤더 번들화(“기본으로 PQC”), 표준·이행 가이드의 빠른 진화 속도.

      - 디지털 신뢰 구축을 위해, **Root‑of‑Trust**, IoT 기기 인증, 공장 출하 시 인증서 발급, Zero‑Touch Field Provisioning 등 다양한 PKI 기반 서비스를 제공하고 있다.
      - **개인 디지털 ID 서비스** 및 생애주기 동안 인증서를 관리할 수 있는 SaaS 기반 인증서 관리 시스템도 갖추고 있으며, 제조 현장 및 현장 운영 환경 전반에서 보안을 유지한다.

      - 양자 컴퓨터 등장 이후 기존 암호기술(RSA, ECC 등)의 공격 가능성에 대응하기 위해, **NIST 승인 기반 PQC 알고리즘**을 하드웨어 차원에서 구현하고 있다 (예: CRYSTALS‑Kyber, CRYSTALS‑Dilithium 등).
      - QS7001과 같은 PQC 최적화 하드웨어 플랫폼을 개발해 1.75억 대 이상의 장치를 보안 처리하는 등, PQC 기술 적용을 가속화하고 있다.
    - RISC-V 기반 PQ-SE 플랫폼 개발, 자율기계/IoT 보안 적용.
    - 모회사인 WiseKey는 위성 보안 네트워크(Wisesat.Space)→ LEO 위성 컨스텔레이션 운영
  - **시장/포지셔닝 & 경쟁**

    - **O(기회)**: IoT/자동차 보안, **양자내성 전환 수요**(칩 내 PQC/루트오브트러스트), 정부·산업 규격화 추세.
    - **T(위협)**: NXP/Infineon/ST·Thales/Entrust/Utimaco 등 **대형사의 번들 전략과 가격경쟁**, 인증 주기 지연 리스크.

      - 위성 의존을 버리고 **경량 Agent+클라우드 PaaS**로 단순·확장성 있는 라인업.
      - **대칭키 합의** 특화(그룹·1회성·제로트러스트 키 정책)로 **네트워크·엣지·국방** 등 ‘대량 키/저지연’ 수요 적합.
    - **W(약점)**

      - **매출 베이스가 매우 작음**(’24 $0.29M; H1’25 예비 $18–67k). 상업화 전환의 가시적 대형 ARR 증명은 진행 중.
      - 대형 플랫폼(Cloudflare/IBM/MS 등)의 **기본 기능화** 압력—차별성/채택 이유를 분명히 해야 함.
    - **O(기회)**

      - **NIST PQC 표준 발표(2024~2025)**, 정부/국방의 **양자내성 전환 의무화** 가속(2030년대 완성 목표) → 마이그레이션·레거시 통합 수요.
      - **통신사·국방·주권 클라우드** 등에서 ‘국가/산업별 주권형 PQ-safe’ 요구 상승(예: AUCloud 사례).
    - **T(위협)**

      - **현금 소진/희석 리스크**(소형 상장사의 숙명). 매출 전환 타임라인 지연 시 재무 압박. H1’25 기준 현금 $24.7M 공시.
      - **표준/배포 스택의 빠른 내재화**(브라우저·CDN·OS·클라우드)로 단품 소프트웨어의 **독립 가치 희석** 가능.

**✅****PQC 표준화 작업에 참여한 기업**

**💡****Cloudflare (NYSE: NET)**

- - **표준화 참여**

    - Cloudflare 연구원(Bas Westerbaan 등)이 **SPHINCS+ (슬롯 해시 기반 서명)** 알고리즘 제안팀 공동저자로 참여 → NIST PQC 최종 표준군 중 하나.
    - 실제로 NIST 웹/논문 기록에 Cloudflare 연구원 이름이 들어가 있음. 즉, **알고리즘 설계 단계에서 직접 기여**.
  - **현재 비즈니스**

    - Cloudflare는 자사 **CDN·Zero Trust 네트워크** 전반에 하이브리드 키 교환(ECDHE+Kyber)을 이미 시험·배포.
    - 2023~2024년부터 Chrome·Firefox와 함께 실험을 진행했고, 지금은 일부 TLS 연결에 적용.
    - 고객 입장에서는 별도 설정 없이 **“양자 안전(Quantum-Safe)” TLS**를 사용하게 되는 구조.
    - 즉, Cloudflare는 PQC를 **기본 네트워크 보안 기능**으로 통합 중이고, 이게 향후 모든 고객 트래픽에 확대될 예정.

**💡****IBM (NYSE: IBM)**

- - **표준화 참여**

    - IBM Research Zurich/Cambridge 팀이 **CRYSTALS-Kyber, CRYSTALS-Dilithium**의 핵심 개발 그룹.
    - Kyber(ML-KEM)과 Dilithium(ML-DSA)은 2022년 NIST 최종 선정 → 2024~2025년에 FIPS 표준으로 발표됨.
    - 즉, IBM은 PQC 표준화의 **주도적 기업** 중 하나.
  - **현재 비즈니스**

    - IBM Cloud 및 IBM Security 서비스에 PQC 알고리즘을 통합 중.
    - 예: **IBM z16 메인프레임**(2022 출시)에는 **Crypto Express HSM**에서 PQC 알고리즘 실행 기능 내장.
    - IBM Cloud TLS 채널에도 점진적으로 PQC 적용.
    - 기업 고객에게 **PQC 전환 컨설팅·마이그레이션** 제공.

**💡****Microsoft (NASDAQ: MSFT)**

- - **표준화 참여**

    - Microsoft Research와 Azure 팀 연구원들이 여러 PQC 알고리즘 검증과 최적화 구현에 기여.
    - 특히, NIST에서 지정한 **“implementer 기업(2022)”** 중 하나로 공식 참여.
    - 알고리즘 설계 직접 참여는 IBM·Google·Cloudflare보다 적지만, **구현 및 대규모 배포 테스트** 역할.
  - **현재 비즈니스**

    - **Windows** 및 **Azure** 보안 스택에서 PQC 전환 로드맵 공개.
    - 2024년 기준으로 **Windows 11 Insider Preview** 빌드에서 Kyber 기반 하이브리드 모드(TLS, VPN)를 테스트.
    - **Azure Key Vault, Azure Confidential Computing** 서비스에 PQC 지원을 점진적으로 추가.
    - 고객사용 가이드라인(암호 전환 가이드) 배포 → “기업이 PQC-ready 되도록” 지원.

**✅****결론**

- - 현재 PQC(Post-Quantum Cryptography)를 주력으로 하는 기업들 대부분은 **비상장 상태**여서 일반 투자자가 직접 투자하기는 쉽지 않다. 이미 상장된 **BTQ, SEALSQ, Arqit Quantum** 등은 존재하지만, 이들 역시 아직 **매출 기반이 미약**하고, **보유 현금 부족이나 재정적 불안정성**에 크게 노출되어 있다. 특히 **소프트웨어 중심의 PQC 업체들**은 Cloudflare, IBM, Microsoft 같은 **대형 플랫폼 기업**이 보안 스택에 PQC를 기본 탑재하는 흐름 속에서 차별성을 확보하기가 쉽지 않다.
  - 반면, IBM과 Microsoft는 PQC 표준화 연구에서부터 클라우드 서비스, 하드웨어 보안 모듈, 운영체제 및 애플리케이션 전환 지원까지 사실상 모든 관련 분야에 깊이 관여하고 있어, 양자 생태계 전체에 걸쳐 광범위한 참여와 영향력을 보여주고 있다.
  - 앞으로 PQC는 별도의 스타트업 솔루션을 구매하는 형태보다는 우리가 이미 사용하고 있는 **보안 장비나 클라우드 서비스에 자연스럽게 내장되는 기능**으로 자리잡을 가능성이 크다. 따라서 투자 관점에서는 **“PQC 순수플레이”보다는 PQC 내재화가 가능한 보안·클라우드 상장사**가 더 실질적이고 유망한 후보군이 될 수 있다.
