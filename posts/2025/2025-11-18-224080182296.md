**✅****DART AE**

- - **DART AE**는 호주 기업 Hypersonix Launch Systems이 Kratos와 전략적 제휴를 맺고 개발 중인 **초음속/극초음속** 스크램제트(scramjet) 기술 데모체로,
  - 미국의 Rocket Lab의 아랫단 서브오비탈 발사체인 HASTE를 이용해 발사될 예정이다.

**💡주요 개요**

- - DART AE = “**Directed Airframe Rapid Technology – Additive Engineering**” (혹은 비슷한 이름)로 불리는 스크램제트 엔진 기반의 초고속 체험기/비행체.
  - 미국 국방부의 OSD R&E 산하의 **DIU(Defense Innovation Unit)**가 주관하는 **HyCAT(Hypersonic and High-Cadence Airborne Testing)** 프로그램에서 선택된 시험 플랫폼
  - 개발사: Hypersonix Launch Systems (호주)
  - 발사체: Rocket Lab의 HASTE 서브오비탈 버전. 즉, 궤도 위성이 아니라 지구 상공 대기권 혹은 대기권 상층에서의 시험비행용
  - 속도 목표: 마하 7 (약 음속의 7배) 급속도로 비행 가능하다는 언급 있음
  - 재사용 가능

    - 엔진 종료 후 활공 모드 전환
    - 저속/저고도 진입
    - 착륙 회수 / 복구

**💡****기술적 특징**

- - 스크램제트(scramjet) 엔진: Supersonic Combustion Ramjet의 약자로, 비행체가 이미 초음속으로 날아가면서 공기를 흡입해 연소시키는 형태의 엔진입니다. DART AE는 이 방식 적용된 기술 데모임
  - 소재 및 제조 방식: 고온합금(high-temperature alloy)과 함께, 적층제조(Additive Engineering, 즉 3D프린팅) 기술이 다수 사용되었다고 보고됨.
  - 길이/중량: 길이는 약 3 미터(≈9.8 피트) 내외, 중량은 약 300 kg급으로 언급됨.
  - 비행 궤적: 서브오비탈(궤도에 진입하지 않고, 대기권 상층 또는 대기권 경로를 따라 비행) 형태이며, 궤도 진입보다는 대기권 내/상층에서의 극초음속 시험비행용이다.

**💡****목적 및 의미**

- - 기술 검증: 초음속/극초음속 비행 기술, 특히 스크램제트 엔진의 실제 비행 환경에서의 성능과 연료·구조 시스템 검증을 목적으로 한다.
  - 전략적 가치: 군사 및 민간 양쪽에서 중요해지는 극초음속 비행 기술(예컨대 대응속도, 탐색·감시 플랫폼, 차세대 발사·비행체 설계 등)에서 핵심이 되는 기술 데모임.
  - 상업·국제 협력: 호주 기업 + 미국 발사체 협력 형태로, 글로벌 항공우주/방산 생태계에서 기술 협력이 진행 중임을 보여줌

**💡****발사체: HASTE**

- - HASTE (Hypersonic Accelerator Suborbital Test Electron)은 Rocket Lab의 서브오비탈 시험용 발사체 버전이며, 다음과 같은 특징이 있다:

    - 원래 궤도발사용 Electron 로켓을 변형해 서브오비탈/고속시험용 플랫폼으로 활용.
    - 발사 장소: 미국 버지니아 주의 Wallops Flight Facility의 Launch Complex 2 (LC-2, Pad 0C) 등에서 계획됨.
    - 목적: 극초음속 시험체 탑재, 대기권 상비행, 다양한 엔진·공기역학 시험 등.

**💡Hypersonix + Kratos의 관계**

- - 2022년 1월, Hypersonix와 Kratos는 “DART AE Hypersonic Drone System을 개발하고 비행시키겠다”는 계약을 체결했다.
  - 2023년 8월에는 두 회사가 **Exclusive Teaming Agreement**를 발표했는데, 미국 시장(특히 Defense Innovation Unit (DIU) 프로그램 등)을 위해 Hypersonix의 DART AE 시스템과 Kratos의 “Zeus” 고체 로켓 모터(Booster) 시스템을 통합하겠다는 내용이다.
  - Kratos는 “최대 20 개의 DART AE 시스템을 Hypersonix로부터 구매할 수 있다”는 옵션도 포함된 것으로 알려졌다

**💡왜 이런 제휴를 하는가**

- - Hypersonix는 스크램제트 엔진, 고속 비행체 설계에 전문성이 있지만, 미국 방산시장 접근성, 발사부스터 통합 경험, 미국 국방 계약 네트워크 등에서는 Kratos가 더 강점이 있다.
  - Kratos는 과거 고체로켓 모터, 초음속/극초음속 시험발사체, 방산체계 통합 경험이 많다. Hypersonix 측 발표에서도 “Kratos는 이미 오스트레일리아에서 여러 초음속 실험을 지원한 경험이 있다”라고 나와 있다.
  - 미국 DIU 등은 시험발사 및 고속 비행체 검증을 위한 고정·반복 가능한 플랫폼을 원하고 있고, 글로벌 협력이 가능한 기업 조합을 선호하는 경향이 있다. Hypersonix+Kratos 조합이 그런 요구사항에 부합했다고 볼 수 있다.

**🚀비행 속도 영역 구분**

- - 비행체 속도는 **마하(Mach)** 기준으로 구분한다.
  - (마하 1 = 음속 ≈ 340 m/s ≈ 1,225 km/h, 대기 조건에 따라 변화)

|  |  |  |  |
| --- | --- | --- | --- |
| **영역** | **속도 범위** | **특징** | **문제** |
| **아음속 (Subsonic)** | Mach 0 ~ 0.8 | 공기 흐름이 비교적 부드럽고 압축성 효과 거의 없음 | 난류(turbulence)  양력/항력 최적화 |
| **천음속 (Transonic)** | Mach 0.8 ~ 1.2 | Shock wave(충격파) 발생 시작 | 충격파(shockwave) 발생  버핏(Buffeting)  항력 급증(Drag rise) |
| **초음속 (Supersonic)** | Mach 1.2 ~ 5 | 독립 shock wave 형성, 압축성 매우 중요 | 충격파 강함  음파 폭발(Sonic boom)  열 증가  제어 민감도 상승 |
| **극초음속 (Hypersonic)** | **Mach 5 이상** | 공기 이온화·플라즈마·열화학 반응, 재료·통신 문제 발생 | 아래 별도 표기 |

**💡극초음속 (Hypersonic) 비행시 발생하는 문제점**

|  |  |
| --- | --- |
| **문제** | **상세 설명** |
| **공기 이온화 → 플라즈마 형성** | 통신·센서 블랙아웃 |
| **열화학 반응 (Thermochemical effects)** | N2, O2 분리 → 재료 공격 |
| **수천 °C 열 플럭스 (Aerothermal heating)** | 일반 합금은 즉시 용융 → 세라믹·탄소 복합재 필요 |
| **Shock–boundary layer interaction (SBLi)** | 충격파 + 경계층 간 상호작용 → 불안정·진동·파손 |
| **구조·제어 문제** | 고속에서 작은 기동도 초대형 g-force 발생 |
| **레이더·IR 탐지 불확실성** | 스텔스 효과·신호 왜곡 |
| **C2 통신 장애** | 데이터링크·GPS·위성통신 중단 가능 |

> 속도가 높아질수록 열·압축성·충격파·플라즈마·제어 문제들이 폭발적으로 증가하며, 특히 극초음속에서는 통신/탐지/제어가 기술의 핵심 난제이다.

**💡실제 극초음속 비행체(DART-AE)**

- - DART-AE는 ‘비행기처럼 생긴 비행체’이다. 날개가 있고 스크램제트 엔진이 달린 공기흡입형 비행체다.
  - 그런데 **왜 스스로 날아서 시험하지 않고, 로켓(HASTE)에 페이로드처럼 실어서 대기 상층으로 올린 뒤 시험하느냐?**
  - 핵심 이유는 **스크램제트 엔진의 작동 조건 때문**이다.

**💡****스크램제트는 정지 상태·저속 상태에서는 작동하지 않음**

- - 스크램제트(supersonic combustion ramjet)는 **엔진 내부로 supersonic airflow가 들어와야 연소가 가능**하다.
  - 즉, **초음속(보통 마하 4–5 이상)에 도달해야 엔진이 켜진다**.

|  |  |  |
| --- | --- | --- |
| **엔진 종류** | **작동 속도 조건** | **비고** |
| 터보팬, 터보제트 | 정지~마하 2까지 가능 | 일반 항공기 |
| 램제트 | 마하 2~4 | 초음속 미사일 |
| **스크램제트** | **마하 4~10 필요** | 마하 0에서는 절대 작동안함 |

- - 👉 따라서 **지상 활주로에서 이륙해서 가속하는 방식으로는 스크램제트가 작동할 수 없다.**
  - 비행기처럼 날아서 시험비행을 시작할 수가 없다.

**💡****초기에 마하 4–5까지 가속하는 것이 가장 어렵다**

- - 스크램제트 시험을 위해선 **대기권 상층, 고도 25–40km, 속도 마하 4++** 가 필요하다.
  - 이 속도·고도에 도달하려면 보통 아래 중 하나가 필요하다:

    - 로켓 부스터 사용
    - 대형 미사일/로켓 발사체 이용
    - 전용 초음속 캐리어 항공기(B-52 급)에서 공중투하
  - DART-AE는 아직 초기 기술 데모 단계이므로, **Rocket Lab의 HASTE 로켓으로 고도와 속도를 확보**하고
  - 그 뒤 **분리 → 스크램제트 점화 → 마하7 영역 시험비행**을 하는 구조다.

**💡****극초음속 시험은 지상 활주로 이륙 형태로는 불가능**

- - 초고속 비행체는 다음 문제를 반드시 겪는다:

    - **공기저항(Heating) — 수천 °C 열 발생**
    - **플라즈마 형성 → 통신 blackout**
    - **구조물 진동·탄성 변형**
  - 이 환경은 지상 테스트나 풍동으로는 완벽히 재현 불가능하며,
  - 따라서 **대기 상층에서 실제 비행을 하며 검증해야 한다.**

**💡****궤도형/서브오비탈 로켓 발사는 비용과 일정 모두 효율적**

- - 스크램제트 시험은 매우 위험하고 실패 확률이 높다
  - → **소형 로켓 플랫폼에서 버리고 배우는 방식이 효율적**
  - → **HASTE + DART-AE 구조는 반복 가능 시험 플랫폼**

|  |  |  |  |
| --- | --- | --- | --- |
| **방법** | **비용** | **제약** | **실용성** |
| 대형 항공기 공중투하 (B-52, F-15) | 매우 비쌈 | 장비 제한 | 주로 군용 |
| 지상 이륙 | 불가능 | 속도 미달 | 불가 |
| 로켓에 페이로드로 올림 | 저렴 | 반복 가능 | **현재 주류 방식** |

> **시험용은 로켓 발사체 도움**,
>
> **실전용은 자체 로켓 + 스크램제트** **하이브리드** **추진**이 일반적이다.

**🚀 극초음속 비행 테스트의 진짜 목적**

**💡극초음속 비행환경 데이터 수집**

- - 마하 5~10 속도에서는 공기압축으로 인해 표면 온도가 **수천 °C**까지 상승
  - 공기 이온화(ionization)로 인해 **플라즈마 껍질(Plasma sheath)** 형성
  - 이는 통신, 센서, 레이더 전파를 차단하거나 굴절시킴
  - 📌 **플라즈마 blackout 문제 해결 연구가 핵심**

****

**💡레이더·적외선 탐지 회피(stealth) 성능 시험**

- - 극초음속 속도에서는:

|  |  |
| --- | --- |
| **센서 종류** | **영향** |
| 레이더 | 플라즈마가 레이더파를 흡수/굴절 → 추적 어려움 |
| IR 열 영상 | 온도가 너무 높아 탐지 방식이 달라짐 |
| 시각·EO | 고도+열로 인한 난반사, 플룸(배기가스) 왜곡 |

- - 👉 **실제로 얼마나 스텔스인지 실전 데이터가 필요**

****

**💡비행제어와 기동성 확인**

- - 마하 7에서 방향을 1도만 바꿔도 수십 g 하중이 걸려 **기체가 구조적으로 파손되기 쉬움**
  - 또한 shockwave 구조가 변하면서 제어 불안정 발생
  - 그래서 시험은 다음을 확인하는 것

    - 고속 기동 안정성
    - shock-train control
    - 공력 제어(surface) 반응성

**💡통신 & 지휘제어 시험 (C2 link)**

- - 플라즈마 때문에 **GPS·데이터링크·위성통신이 차단될 수 있음**
  - → blackout 구간 극복 기술(레이저 링크, 저주파 통신 등) 시험

---

**✅플라즈마 고착층 (plasma sheath)와 해결책**

**💡왜 극초음속 비행체에서 플라즈마 문제가 생기나?**

- - 비행체가 **마하 5 이상**으로 날면, 앞에서 공기가 충격파(shock wave)를 형성하며 매우 고온이 된다.
  - 이 고온의 공기에서 분자들이 분리·이온화되어 플라즈마(전자와 이온이 포함된 상태)가 비행체 표면이나 주변을 둘러싸게 된다.
  - 이 플라즈마 층이 생기면, 그 안에서 무선/레이더 통신 신호나 레이더 전파가 흡수되거나 반사되어 **“블랙아웃(blackout)”** 현상이 생긴다.
  - 예컨대 지상과의 데이터 통신, 위성 GPS 신호, 탐지기 통신 모두 영향을 받을 수 있다.

**💡플라즈마가 통신/탐지에 어떤 영향을 주는가?**

- - 몇 가지 메커니즘이 있다:

|  |  |
| --- | --- |
| **문제** | **설명** |
| **전파 차단 및 반사** | 플라즈마 주파수(plasma frequency)가 전파의 주파수보다 높으면 전파가 통과하지 못하고 반사됨. |
| **흡수 및 감쇠(collisional damping)** | 전자·이온이 전파 에너지를 흡수하면서 신호가 약해짐. |
| **레이더 단축·반사 패턴 변화** | 탐지 레이더에서 비행체가 예상 외의 산란(scattering) 또는 감쇠 상태에 놓여 탐지가 어려워짐. |

**💡그래서 어떻게 이 문제를 해결하려고 하나?**

- - 플라즈마 블랙아웃 문제를 해결하기 위해 여러 기술적 전략이 연구되고 있다:
  - **✅ 해결 방법들**

    - **저주파 통신(low frequency communication)**

      - 플라즈마가 차단하는 주파수보다 낮거나 다른 방식의 주파수를 이용해서 통신을 유지하는 방법.
    - **고주파/밀리미터파/THz 통신 채널**

      - 플라즈마 층의 전파 차단 주파수 보다 높은 주파수를 활용하는 연구가 있음.
    - **플라즈마 조작 기술**

      - 예컨대 플라즈마 밀도 제어, 전자 빔이나 고출력 마이크로파(HPM) 조사 등을 통해 플라즈마 상태를 바꿔 통신 가능성을 높이는 연구.
    - **통신 창(window) 설계**

      - 기체 설계 시 플라즈마 밀도가 낮거나 통신이 가능한 구역을 만들어 두는 방식. 또한 플라즈마 제거·완화 장치를 적용하는 방식.
  - **🔬 구체적 논문 예시**

    - “Analysis of Low-Frequency Communication of Hypersonic Vehicles” 논문에서는, 플라즈마 층에서 저주파 전파가 흡수·반사되는 메커니즘을 규명하고, 고출력 마이크로파(HPM)를 조사해 저주파 전파 투과성을 개선하는 실험모델을 제시했다.
    - “Review of Leading Approaches for Mitigating Hypersonic Vehicle Communications Blackout” (NASA 기술보고서)에서는 항공우주 플랫폼에서의 블랙아웃 현상, 진단기술, 차단 완화 전략 등을 포괄적으로 정리했다.

**💡극초음속 비행체 운용 측면에서의 의미**

- - 만약 통신이 끊기면 비행체 제어·데이터 수집·지휘명령이 어려워진다 → 운용·안전 리스크 증가
  - 탐지 회피 측면에서는 플라즈마가 오히려 탐지를 어렵게 만들 수 있어서 전략적으로 유리하다 (반대로 통신도 어려움)

    - 이러한 문제를 Golden Dome에서 해결하기 위해 노력중이다.
  - 따라서 극초음속 플랫폼을 설계할 때는 **통신체계의 내성(resilience) 확보**가 매우 중요한 과제이다
