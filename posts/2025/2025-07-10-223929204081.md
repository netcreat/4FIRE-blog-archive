간섭과 측정은 중첩과 얽힘을 소개한 후 다뤘어야 하는데, 얽힘을 다룰때 게이트가 자주 등장했고, 그 이후에 알고리즘을 소개하다 보니 순서가 뒤로 밀렸다.

**5️⃣ 간섭**

간섭(Interference)은 자신의 중첩 상태 안에서 파동처럼 확률진폭들이 더해지거나 상쇄되는 현상이다. 얽힘은 다중큐비트 시스템에서 복잡한 상태를 표현할 수 있게 해주는 기반이라면, 간섭은 계산 결과 중 정답에 가까운 결과를 강조하거나 제거하는 계산 방식이다. 그로버 알고리즘에서 오라클 연산을 소개할때 간단히 간섭을 소개했었다.

|  |  |  |
| --- | --- | --- |
| **목적** | **설명** | **예시 알고리즘** |
| **정답 확률 증가** | 중첩된 상태 중 원하는 해답만 간섭을 통해 진폭 증가 | **Grover’s algorithm** |
| **불필요한 상태 억제** | 쓸모없는 상태는 간섭으로 진폭을 소멸시킴 | **Shor’s algorithm** |
| **계산 결과를 ‘추출’ 가능** | 간섭 없이는 중첩 상태가 흩어져서 아무 의미 없는 값만 측정됨 | 거의 모든 알고리즘 |

양자 상태는 보통 다음과 같이 표현된다.

∣ψ⟩=α∣0⟩+β∣1⟩

이때 α, β는 **복소수 진폭**이고, 이 안에 있는 위상각(*Φ* : phase)이 간섭을 만든다. 이 위상이 **서로 다른 상태 간의 간섭**을 만들어 내어 **여러 큐비트의 상태가 결합할 때 결정적인 역할**을 한다.

극각(*θ*)는 해당 값이 z축을 기준으로 얼마나 기울어졌는지를 나타내는 것으로 간접적으로 관측이 가능한 반면 위상각은 단독적인 의미가 있는 것이 아니라 상대적인 차이만을 나타내기 때문에 직접 측정이 불가능 하다. 오일러 공식을 설명할때 사인파와 코사인파를 소개했는데, *π/2*만큼의 위상차가 있다고 언급했었다. 나는 위상차를 **"파동의 시작 타이밍(또는 지연)"**이라고 표현하고 싶다.

**🌍양자역학에서의 위상**

- 두 파동이 같은 방향, 같은 위상 → 강화 간섭
- 반대 위상 → 상쇄 간섭

이 간섭이 정답 상태를 강조하고,오답 상태는 약화되게 만들 수 있다.

예 :

**🧪 예시: 위상이 다른 두 상태의 상쇄 간섭**

- 두 상태는 위상 차이가 π만큼 남
- 이걸 같은 기준으로 합치면 |1⟩이 사라짐. → 위상이 반대인 부분이 상쇄됨

**🧪예시: 위상이 같은 두 상태의 보강 간섭**

- 둘 다 ∣0⟩|0⟩와 ∣1⟩ 항에 + 부호를 갖고 있어서 위상 차이가 없음.
- 이걸 합치면 (|0⟩+|1⟩)부분은 그대로 있고, 1/√2 가 √2로 더 강해짐.

**🌍양자 컴퓨터에서의 위상의 이용**

- **게이트**

  - 얽힘 편에서 언급했던 Y,Z,S,T 게이트가 위상을 조절한다.

    - Y : Y축을 중심으로 180도 회전 → ∣0⟩→i∣1⟩, ∣1⟩→−i∣0⟩ : 비트가 반전되고, +i와 -i가 붙음 (QEC에 중요)
    - Z : Z축을 중심으로 180도 회전 → ∣1⟩에 위상 π를 곱함 → ∣1⟩→−∣1⟩
    - S : Z축 중심으로 90도 회전 → ∣1⟩→i∣1⟩ :
    - T : Z축 중심으로 9045도 회전 → ∣1⟩→*e**iπ/4*∣1⟩
- **위상 되차기 (Phase Kickback)**

  - 이중큐비트 연산을 수행할때, 제어큐비트(Control Qubit)를 통해 타겟큐비트(Target Qubit)가 바뀌게 되는데, 가장 대표적으로 CNOT 게이트가 있다. 제어큐비트가 0이면 타겟큐비트는 바뀌지 않고, 제어큐비트가 1이면 타겟큐비트가 반전된다.
  - 하지만, CNOT 게이트는 위상 반전 기능이 없고, 위상이 바뀌는 이중큐비트 게이트로는 CZ가 있다.
  - 여기서 위상 되차기란 게이트 연산 수행시 타겟 큐비트만 영향을 미치는게 아니라, **타겟 게이트에 가해진 위상이 제어큐비트로 전이되는 현상**을 가리킨다.

    - 제어큐비트 : |x> (x=0 or 1)
    - 타겟큐비트 : |ψ>
    - 유니터리 연산 U|ψ>=e2πiθ|ψ>

- - - x=0이면 변화없음
    - x=1이면 위상 *e**2πiθ* 추가됨 : 제어큐비트 |x>에 복소수가 곱해전 것처럼 동작해서 마치 제어큐비트가 위상을 받은 것과 같음
  - **예시 : QPE를 통해 Shor 알고리즘** 수행시 사용됨.
  - 비유 : 도장 찍기 기계

    - 제어큐비트 : 기계작동 스위치
    - 타겟큐비트 : 도장 받는 종이
    - 유니터리 : 도장머리 - 찍을때 위상변화를 준다.
    - 타겟에 도장머리로 위상을 찍었더니, 도장머리를 통해 제어큐비트에 위상이 묻어버림 -> 되차기(kickback)

**6️⃣** **측정**

****

**✅ 측정의 기본 개념**

양자 상태는 보통 다음과 같이 중첩되어 있어요:

∣ψ⟩=α∣0⟩+β∣1⟩

여기서 α,β는 복소수 확률 진폭

- 실제 측정하면:

  - 확률 ∣α∣2로 ∣0⟩
  - 확률 ∣β∣2로 ∣1⟩
- 측정 후에는 중첩이 붕괴되어 **하나의 고전적 결과로만 남음**

****

**✅ 양자 컴퓨터에서의 측정의 주요 용도**

|  |  |  |
| --- | --- | --- |
| **용도** | **설명** | **예시 알고리즘** |
| 🟩 **최종 결과 추출** | 계산 후 상태에서 classical 결과 얻기 | Grover, Shor |
| 🟦 **조건 분기(조건문)** | 특정 측정 결과에 따라 **회로 제어** | 양자 텔레포테이션 |
| 🟨 **간접 정보 추론** | 보조 큐비트를 측정해 **오류 감지** | 양자 오류 수정 (QEC) |
| 🟥 **상태 준비** | 측정을 통해 **특정 상태로 collapse** 유도 | GHZ, Bell 상태 생성 |

**📌 Grover 알고리즘**

- 계산 마지막 단계에서 얽힌 중첩 상태가 있음

- 측정을 통해 목표 정답 x\*가 나올 확률을 극대화한 뒤 측정으로 classical 결과 얻음.

****

**📌 양자 오류 수정 (QEC)**

- 여러 큐비트를 얽혀 있는 상태로 만들어, 오류가 난 큐비트 자체는 측정하지 않고, **보조****안실라 큐비트(ancilla)**를 측정해서 간접적으로 오류 위치와 종류를 유추
- 큐비트 상태 자체는 손상시키지 않고 **에러만 추정해서 복구**

****

**📌 양자 텔레포테이션**

- 송신자 A가 **얽힌 큐비트** 2개 중 하나를 측정
- 그 결과에 따라 **수신자 B가 고전 정보를 기반으로 게이트를 선택 적용**
- 결국 **원래 상태가 B에게 전달됨**

→ 여기서 측정은 **정보 이동의 일부**임

****

**📌 일반 연산**

- 대부분의 양자 알고리즘은 최종 결과 직전까지 측정을 하지 않음
- 중첩과 얽힘을 유지한 채 간섭을 조절하면서 계산을 진행
- 측정은 마지막 결과 확인 시점에 단 한 번만

**✅ 측정의 특성**

|  |  |
| --- | --- |
| **특징** | **설명** |
| 비가역적 | 측정하면 상태가 붕괴됨 (되돌릴 수 없음) |
| 확률적 | 결과는 확률적으로 정해짐 (복소수 진폭의 제곱) |
| 파괴적 vs 간접적 | 직접 큐비트 측정은 파괴적, ancilla안실라 큐비트로 우회 가능 |
| 클래스컬 연산과 연결 | 측정 결과는 고전 신호로 변환되어 조건 분기 등에 사용 |

**✅ 측정은 "마지막에만" 하는가?**

현대 양자 알고리즘은 **중간 측정도 적극적으로 사용**합니다.

- **중간 측정 결과에 따라 다음 회로 변경**
- 특히 피드백 제어(양자 텔레포테이션 또는 양자 오류 수정), **변분 알고리즘(VQE 또는 QAOA)**에서 중요

**✅ 측정 방법**

양자 측정은 "**상태 붕괴 + 고전적 신호 추출**"의 조합이다. 즉, 큐비트의 상태를 특정 물리적 반응으로 바꾸고, 이를 **광자/전류/공진기 반응** 등의 방식으로 측정해 **디지털 0 또는 1로 판별**한다.

**1️⃣ 이온 트랩 (Trapped-Ion Qubits)**

**▶ 측정 방식: 형광 측정 (fluorescence detection)**

- 광 검출기 (PMT/APD)로 **형광이 나오는가? 안 나오는가?** 감지
- 형광 있으면 → ∣0⟩|0⟩
- 형광 없으면 → ∣1⟩|1⟩

⚠️ **비접촉, 비파괴적 측정 가능**

⚠️ 매우 높은 정밀도 (99.9% 이상)

****

**2️⃣ 초전도 큐비트 (Superconducting Qubits)**

**▶ 측정 방식: 공진기 반사/위상 변화 측정**

- 큐비트가 연결된 **마이크로파 공진기**에 신호를 쏘면,
- 큐비트 상태에 따라 공진기의 반응(위상/진폭)이 달라짐
- 이를 고전적인 증폭기(JPA 등)로 읽어들임

⚠️ **간접 측정 방식**이고, **측정 후 큐비트는 붕괴됨**

****

**3️⃣ 광자 기반 큐비트 (Photonic Qubits)**

**▶ 측정 방식: 광자 검출기 이용**

- 광자(빛)의 **편광, 위상, 경로** 등을 큐비트로 사용
- 이를 편광 분리기 + 광자 카운터(APD, SNSPD 등)로 분석
- 통계적으로 반복 측정 → 확률 수렴

****

**4️⃣ 실리콘 전자 스핀 큐비트 (Silicon spin)**

**▶ 측정 방식: 스핀-전하 변환 + 전류 감지**

- 전자 스핀을 **양자점**에 저장
- 스핀 상태에 따라 전자가 **터널링 가능한가 여부**가 달라짐
- 전하 센서(QPC, SET 등)로 **전류 변화 감지**

**7️⃣양자 오류 정정 (QEC)**

양자컴퓨터는 매우 강력하지만, 동시에 매우 **깨지기 쉬운 계산기**다.

큐비트가 주변 환경의 작은 흔들림에도 쉽게 무너지고, 얽힘은 사라지며, 중첩은 붕괴된다.

이 문제를 해결하기 위한 가장 강력한 무기는 바로 양자 오류 정정(QEC, Quantum Error Correction)이다.

**✅ 오류 정정의 필요성**

양자정보는 고전정보보다 훨씬 **민감하다**.

그 이유는 양자 상태가 가진 성질 때문이다. 즉, 하나의 큐비트라도 오염되면 전체 계산이 틀어질 수 있다.

|  |  |  |
| --- | --- | --- |
| **성질** | **설명** | **위협 요소** |
| 중첩 | 여러 상태가 동시에 존재 | 외부 노이즈가 상태 붕괴 유도 |
| 얽힘 | 다수 큐비트가 연결된 상태 | 한 큐비트만 깨져도 전체 정보 손상 |
| 비복제성 | 상태를 복사할 수 없음 (No-cloning) | 백업 불가 |

**✅ 양자 오류의 종류**

**🌪️ 탈동조화 (Decoherence)**

- **정의**: 큐비트가 환경과 상호작용하면서 양자 상태(중첩 또는 얽힘)를 잃고 고전적인 상태로 붕괴하는 현상.
- **원인**: 열, 진동, 전자기파, 잡음 등 외부 환경 요인
- **영향**: 계산의 정확도 급감
- **예**: 양자 중첩 상태 |ψ⟩가 시간이 지나면서 |0⟩이나 |1⟩로 붕괴됨

****

**⚡ 게이트 오류 (Gate Errors)**

- **정의**: 양자 게이트(예: X, H, CNOT 등)의 동작이 완벽하지 않아서 잘못된 연산이 수행되는 오류
- **종류**:

  - **1Q 게이트 오류 (1Q Error)**: 단일 큐비트에 대한 연산 오류
  - **2Q 게이트 오류 (2Q Error)**: 두 큐비트 간의 얽힘 연산 오류 (보통 더 크고 복잡함)
- **원인**: 제어 신호의 부정확성, 하드웨어 결함
- 이상적 게이트

- 오류 발생시 (예 : 위상 불안정)→ 위상 차이로 간섭이 틀어지고 계산 결과 오류 발생

****

**📉 측정 오류 (Measurement Errors)**

- **정의**: 큐비트의 상태를 측정할 때 잘못된 값이 나오는 오류
- **원인**: 센서의 민감도, 전자적 노이즈
- **예**: 실제 상태가 |0⟩인데 |1⟩로 읽힘

****

**🔄 비트 플립 오류 (Bit-flip Error)**

- **정의**: 큐비트가 |0⟩ ↔ |1⟩로 바뀌는 오류
- **고전 오류와 유사**
- **기호**: X 연산자에 해당

****

**🔄 위상 플립 오류 (Phase-flip Error)**

- **정의**: 큐비트의 위상이 바뀌어 |1⟩에 −가 붙는 오류 (|1⟩ → −|1⟩)
- **기호**: Z 연산자에 해당

****

**🔀 비트-위상 복합 오류 (Bit-phase flip)**

- **정의**: 비트 플립과 위상 플립이 동시에 발생하는 오류
- **기호**: Y 연산자에 해당

****

**🧬 추가적으로 발생할 수 있는 복합 오류**

- 여러 큐비트에 걸쳐 **얽힘 상태**에서 오류가 전이되거나 퍼질 수 있음
- 이는 단일 큐비트 오류보다 훨씬 복잡하고 예측이 어려움

****

|  |  |  |  |
| --- | --- | --- | --- |
| **오류 유형** | **설명** | **원인** | **대응 방법** |
| 탈동조화 | 중첩/얽힘 붕괴 | 외부 환경과 상호작용 | 격리, 냉각 |
| 게이트 오류 | 잘못된 양자 연산 수행 | 제어 신호의 불안정성 | 보정, 정밀 제어 |
| 측정 오류 | 실제 상태와 측정 결과 불일치 | 센서 노이즈 | 측정 교정 |
| 비트 플립 |  | |0⟩ ↔|1⟩ | 전환 오류 |
| 위상 플립 |  | |1⟩ → -|1⟩ | 위상 변화 오류 |
| 복합 플립 | X + Z 오류 동시 발생 | 복잡한 환경 | QEC 사용 |

**✅** **양자 오류 수정 아이디어**

양자 오류 정정은 관측 없이 오류를 감지하고 수정한다.

그 핵심은 논리 큐비트(logical qubit)를 여러 개의 물리 큐비트(physical qubit)로 확장해 보호하는 것.

**예: 3-큐비트 Bit-flip 코드**

∣0L⟩=∣000⟩,∣1L⟩=∣111⟩

- 하나의 큐비트가 오류를 일으키면 다수결로 복구
- 측정은 정보 자체가 아닌, 오류 여부만 파악하는 "**시차 큐비트(syndrome qubit)**"**안실라 큐비트**"로 수행

  - 큐비트는 측정과 동시에 중첩 상태가 붕괴되기 때문에 데이터를 직접 확인 할 수가 없다.
  - 대신 신드롬안실라 큐비트에 정보를 간접적으로 복사해서 오류가 발생했는지 탐지하는 방법
  - 신드롬안실라 큐비트를 데이터 큐비트들과 얽힘 상태로 만듦
  - 신드롬안실라 큐비트를 측정하여 오류 발생 여부 파악
  - 이 측정값을 신드롬이라고 부르며, 오류 위치나 종류에 대한 힌트 제공
  - 대부분의 QEC 코드에서 신드롬안실라 큐비트를 사용

**✅** **양자 오류 수정 코드 (QEC)**

- Shor 코드

  - 9개 큐비트로 1개 보호
  - 이론적 최초 QEC
- Surface 코드

  - 2D 격자형, 오류 국소 추적
  - 실현 용이
  - 높은 오버헤드(1,000개 ~2,000개)
- LDPC

  - 저밀도 패리티 검사
  - 확장성 뛰어남
  - 양자컴퓨터 버전의 LDPC (qLDPC )
- Steane Code, Color code, Bosonic/GKP Code, Repetion Code 등

**✅ 얽힘과 QEC의 관계**

얽힘은 **쉽게 깨지지만**, QEC를 적용하면 다음이 가능하다:

- 얽힌 상태의 일부가 오류를 겪어도 **복원 가능**
- 멀리 떨어진 큐비트 간 **양자 텔레포테이션 안정화**
- **논리 큐비트 간 얽힘 유지** → 양자 네트워크 기반

****

- Surface Code

  - 초전도체 방식에 알맞음
  - 오버헤드가 너무 큼 : 100개 ~ 수천 개의 물리 큐비트가 필요함
  - Google은 여전히 Surface Code 사용
  - 차원 : 2D 고정

    - ✅큐비트를 바둑반처럼 2차원 격자로 배열하여 하드웨어에서 배선이 간단하고 구현이 쉽다.
    - ❌각 큐비트는 인접한 상하좌우 4개와만 연결이 되기 때문에 오버헤드가 커서 확장성에 한계가 있음
  - 디코딩 알고리즘이 간단함 : (Min-Weight matching 등)
  - qLDPC같은 효율적인 코드로 바뀌는 추세
- LDPC(Low-Density Parity Check)

  - 패리티 검사 행렬이 희소한 오류 정정 코드
  - 원래는 고전 컴퓨터에서 쓰던 오류 정정 코드로, 노이즈 채널에서 탁월한 성능을 가
- qLDPC(Quantum Low-Density Parity Check)

  - 패리티 검사 밀도 낮음
  - 적은 오버헤드 : 10 ~ 100개
  - 차원 : 자유로운 그래프 구조

    - ✅큐비트들이 격자에 제한되지 않고, 임의의 그래프 형태로 연결될 수 있어 연결 자유도가 높고 다양한 최적화 가능함
    - ❌하드웨어 구현이 어렵고 복잡하며, 디코딩도 복잡하고 계산량이 많음
  - 디코딩 알고리즘이 복잡함 (Belief Propagation 등)
- **BB Code(Bivariated Bicycle Code)**

  - **qLDPC** 계열의 대표적 구조
  - 두 개의 고전적 LDPC 코드를 결합해 양자 오류 정정용 스테빌라이저를 만듬
  - 최근 연구에서는 Surface Code 대비 4배 적은 물리 큐비트로 동일 논리 오류율 달성 입증

    - 최근 IonQ가 발표한 BB5 경우 48개의 물리 큐비트를 이용하여 4개의 논리 큐비트를 만들수 있는 반면 Surface Code는 49개의 물리 큐비트로 1개의 논리 큐비트를 만들수 있다.

      - Surface Code - 49:1
      - BB5 - 48:4(12:1)
  - 설계시 인코딩 비율을 미리 조정할 수 있어, 다양한 하드웨어 및 오류 환경에 맞는 최적화 가능
- **Gröss code**

  - IBM이 발표한 최신 **qLDPC 코드**
  - 기존 surface code로 논리 큐비트 한개를 보호하려면 1,000~3,000개 물리 큐비트가 필요하지만, Gröss code는 12 논리 큐비트를 288개 물리큐비트(144 데이터 큐비트 + 144 신드롬안실라 큐비트)로 구현.
  - 24:1 오버헤드
  - 실험용으로 적합.
- 반면에 옥스포드 아이오닉스의 경우처럼 QPU자체의 오류율이 낮아서 오류 정정의 필요성이 우선순위가 낮은 경우도 있다.

**✅ 오류 정정 오버헤드**

오류 없이 동작하는 논리 큐비트 1개를 구현하기 위해 필요한 **전체 물리 큐비트 수 = 데이터 큐비트** **+ 신드롬 큐비트** **+** **보조****안실라 큐비트**

- 데이터 큐비트 : 실제 계산에 쓰이는 큐비트
- 신드롬 큐비트 :

  - 오류를 감지하기 위한 측정용 큐비트.
  - 항상 측정에 사용됨.
  - 주로 오류 정정 코드에서 사용
- 보조 큐비트 :

  - 계산 보조, 상태 준비, 중간 연산 등 특정 디코딩 방식에서 필요할 수 있음 (ancilla, magic state 등)
  - 항상 측정에 사용되지는 않음
  - QEC + 알고리즘 로직 전반에 광범위하게 사용
- 게이트 수 / 측정 횟수 : 반복 측정이나 피드백 회로도 간접적 자원 오버헤드
- 예시

  - Surface Code

    - 1,000~2,000 49~101개 혹은 그 이상의 물리 큐비트 필요 : 오류율 수준, 거리 값에 따라 다름
    - 50%는 데이터 큐비트
    - 50%는 신드롬안실라 큐비트
  - qLDPC Code

    - 논리 큐비트당 100~200 4~24개 정도의 큐비트로 오류 정정가능
    - 업체별 qLDCP Code를 바탕으로 독자 코드 연구 개발 중

**📘 결론: 얽힘을 오래 유지하려면, QEC는 필수다**

양자컴퓨터의 능력은 결국 **얼마나 많은 얽힘을 오랫동안 유지할 수 있는가**로 귀결된다.

이를 위해서 **에러를 실시간으로 감지하고 보정하는 능력**,

즉 **양자 오류 정정**은 필수적인 기반 기술이다. 그리고 이를 위해서는 오버헤드 만큼의 큐비트 개수가 필요하다.
