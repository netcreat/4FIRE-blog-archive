**요약:**

닐스 보어 연구소(Niels Bohr Institute), MIT, NTNU(노르웨이 과학기술대학교), 라이덴 대학교 연구진이 공동으로 “주파수 이진 탐색(Frequency Binary Search)”이라는 새 알고리즘을 개발하여 **실시간으로 큐비트 노이즈를 제어**하는 데 성공했다고 PRX Quantum에서 발표했다.

- 이 방법은 양자 컨트롤러에 통합된 FPGA(Field-Programmable Gate Array)를 사용해 **실험 도중 큐비트 주파수를 직접 추정**한다.
- 데이터를 외부 컴퓨터로 전송해 처리하는 기존 방식과 달리 **지연(latency)을 최소화**할 수 있다.
- 적은 측정 횟수만으로 대규모 큐비트 시스템을 효율적으로 보정(calibration)할 수 있어, 수백만 개 큐비트까지 확장이 가능한 스케일러블한(decoherence 완화) 접근 방식을 제공한다.

**노이즈: “기계 속 유령”**

노이즈는 양자 장치를 작동시키는 데 있어 가장 큰 난관이다.

양자 장치에서 큐비트(qubit)는 핵심 부품이지만, **환경의 미세한 변화에도 극도로 민감**하다.

닐스 보어 연구소, MIT, NTNU, 라이덴 대학교 연구팀은 이번 연구를 통해 **노이즈를 실시간으로 제어할 수 있는 효과적인 방법**을 제시했으며, 이 결과는 **PRX Quantum**에 게재되었다.

**디코히어런스(decoherence)란 무엇인가?**

양자 장치에서 **노이즈**란, 우리가 저장·제어·판독하려는 양자 상태의 코히런스(coherence)를 방해하거나 변화시키는 **모든 환경적 교란 요인**을 의미한다.

이러한 교란은 보통 **디코히어런스**라고 부른다.

양자 장치는 **고전 장치보다 훨씬 높은 정밀도와 민감도**를 제공한다.

따라서 양자 장치가 실현하면 다음과 같은 응용이 가능하다:

- - **정밀 의료 기기** → 정확한 진단 및 치료
  - **분자 및 신약 시뮬레이션** → 혁신적 약물 개발
  - **양자 암호 통신** → 차세대 보안 강화
  - **고속 양자 연산** → 기존 슈퍼컴퓨터 대비 비약적 성능 향상

하지만 이런 이점은 **극도의 디코히어런스 취약성**이라는 대가를 치르게 되며,

노이즈를 제어하지 못하면 **신뢰할 수 있는 정보조차 얻을 수 없게 된다**.

**디코히어런스 완화의 다양한 전략**

큐비트에 영향을 미치는 노이즈는 다음 원인에서 비롯될 수 있다:

- - 주변 물질의 **전기적 잡음**
  - 환경에서 발생하는 **자기장 변동**

이를 해결하는 방법은 다양하다:

1. 1. **큐비트 주변 소재 최적화**
   2. **큐비트 자체의 설계 개선**
   3. **환경 변화에 덜 민감하도록 구조 변경**
   4. **노이즈를 능동적으로 보정하는 방식** → 지난 10~15년간 주류 접근법

연구를 주도한 **Fabrizio Berritta 박사**는 이렇게 설명한다:

> “우리는 노이즈 자체를 측정할 수 있습니다.
>
> 노이즈를 알게 되면, 제어 경로(control path)를 조정해
>
> **디코히어런스를 완화할 수 있습니다**.”

**노이즈 제어에서 속도가 가장 중요하다**

노이즈를 억제하려면 **극도로 빠른 응답 속도**가 필요하다.

기존 방식에서는 실험 데이터를 **양자 장치 → 데스크톱 컴퓨터**로 전송해 분석하는데,

데이터가 도착했을 때는 이미 **노이즈 환경이 변해버린 경우가 많았다**.

결국 **항상 한 박자 늦게 대응**하는 셈이었다.

**“주파수 이진 탐색(Frequency Binary Search)”의 등장**

연구팀은 MIT 교환 연구 기간 동안 Fabrizio 박사의 주도로 “Frequency Binary Search”라는 알고리즘을 개발했다.

- - **Quantum Machines 컨트롤러**에 통합된 **FPGA**에서 직접 동작
  - 컨트롤러가 실험 중 큐비트를 **조작·판독·데이터 수집**을 모두 수행
  - **데스크톱 전송 없이** FPGA에서 **큐비트 주파수를 실시간 추정**

> 환경 요인으로 인해 큐비트 주파수는 항상 변동한다.
>
> 이 알고리즘 덕분에 연구진은 **실험 종료와 동시에**
>
> “실시간 데이터”와 “큐비트 주파수 변화”를 함께 확보할 수 있다.

**FPGA 활용 아이디어의 배경**

연구 초기, Fabrizio 박사와 동료들은 **Jacob Benestad**, **Jan Krzywda**와 함께

효율적인 알고리즘을 고민했다.

> “슈퍼컨덕팅 큐비트를 **마이크로파 드라이브**로 제어하는 방식이 익숙하지 않아,
>
> 몇 주 동안 다양한 옵션을 논의한 끝에 FPGA 활용 아이디어에 도달했습니다.”
>
> — Fabrizio Berritta

MIT의 **Lukas Pahl** 및 **Melvin Mathews**와 협력하여 **실험 검증**을 수행했다. FPGA 자체는 입자 가속기 같은 분야에서 오래 사용됐지만, 프로그래밍에는 **전기공학 + 물리학을 모두 아우르는 전문성**이 필요해 양자 물리 연구자에게는 진입 장벽이 높았다. 그러나 최근 **상용 양자 컨트롤러**가 등장하면서, 연구팀은 **파이썬과 유사한 언어**를 통해 FPGA를 쉽게 제어할 수 있었고, 이를 통해 **코펜하겐뿐 아니라 전 세계 연구실**에서 같은 실험을 쉽게 수행할 수 있는 길이 열렸다.

**미래 전망 — 수백만 큐비트 시대를 대비한 확장성**

Fabrizio 박사는 다음과 같이 말한다:

> “현재 양자 프로세서는 **수천~수만 번의 측정**을 통해 큐비트를 보정합니다.
>
> 하지만 큐비트 수가 늘어날수록 주파수 변동을 감시하는 일은 더 어려워집니다.
>
> 지금은 수십~수백 큐비트 수준에서 작업하지만,
>
> 언젠가 **수백만 큐비트**를 다루게 될 것입니다.
>
> 이 알고리즘을 활용하면 **모든 큐비트를 동시에 보정**하면서도,
>
> **10회 미만의 측정**으로 지수적 정밀도(exponential precision)를 확보할 수 있습니다.
>
> 큐비트 수가 늘어날수록 이 방법의 활용 가치는 더 커질 것입니다.”

**✅****연구 환경**

**💡** **양자 제어 컨트롤러 OPX+**

이스라엘 기업인 Quantum Machines(QM)는 양자 컨트롤 하드웨어 기업에서 생산하는 디바이스로서, 이번 연구에서 핵심역할을 한 **FPGA 기반 실시간 제어 컨트롤러**다.

**💡****OPX+ 주요 특징**

- - **통합 FPGA 기반 양자 제어 컨트롤러**
  - **초저지연 실시간 피드백 루프** 가능
  - **다양한 플랫폼 지원** → 초전도, 이온트랩, 스핀, 광자, 중성원자 등 하드웨어 비종속
  - **클라우드 API 및 Python 호환** → QmPy라는 Python 유사 언어 사용
  - **멀티채널 동기화** → 수십~수백 개의 아날로그/디지털 채널을 ns 단위로 동기화
  - **고속 파형 발생기(AWG)** 및 **고속 ADC** 내장 → 실시간 펄스 합성·판독 가능
  - FPGA 기반으로 “펄스 합성 → 실험 실행 → 데이터 판독 → 우도 업데이트 → 다음 펄스 결정”까지 **수 μs 단위**로 닫힌 루프를 완결하는 하드웨어이다.
  - 이 논문의 **Frequency Binary Search(FBS)** 알고리즘이 실시간으로 동작할 수 있었던 이유도 OPX+ 덕분임.

**💡****Quantum Machines가 제공하는 것**

- - **하드웨어: OPX+ 컨트롤러**

    - FPGA 기반 시퀀싱, 펄스 합성, 멀티채널 동기화
    - **μs 단위 실시간 제어 루프** 가능
    - 아날로그·디지털 제어선 100개 이상 지원
    - Python 스타일 SDK 제공 (QmPy)
  - **소프트웨어 스택**

    - **QmPy**: Python 유사 언어, 실험 시퀀스 정의 및 FPGA 오케스트레이션 제어
    - **QOP (Quantum Orchestration Platform)**: 실험 전체를 클라우드와 로컬에서 관리 가능
    - CUDA-Q, Qiskit, Cirq 같은 SDK와도 통합 지원
  - **주요 고객사 및 파트너**

    - **MIT**: 이번 논문에서 사용
    - **AWS Braket**: 클라우드 양자서비스 연동
    - **NVIDIA**: CUDA-Q 통합 지원
    - **Oxford Ionics / Quantinuum / Rigetti 등** → 일부 고객사

**💡****Frequency Binary Search(FBS)란 무엇인가**

FBS는 **양자컴퓨터 제어에서 큐비트의** **실제 공명 주파수** ωq를 빠르게 찾고 보정하는 **적응형 탐색 알고리즘**이다.

**💡****핵심 아이디어**

- - 큐비트의 **실제 주파수**는 환경 노이즈 때문에 **계속 변동**한다.
  - 정확한 ωq를 알아야 **게이트 펄스**를 해당 주파수에 맞춰 걸 수 있다.
  - 그런데 전통적 방법(스펙트럼 스캔)은 **매번 수천~수만 회 측정**을 해야 해서 큐비트 수가 많아지면 불가능해진다.
  - **FBS는 단 10회 미만의 측정으로 ω****q****를 추정**하고, FPGA를 통해 실시간으로 펄스를 보정한다.

**💡****왜 “binary”인가 — 고전 비트랑 다른 의미**

- - 여기서의 **binary**는 **주파수 탐색 과정**에서:

    - 가능한 ω 범위를 **두 개 구간으로 나눔**
    - 측정을 통해 어느 쪽이 맞는지 판별 → 분포를 절반으로 줄임
    - 다시 남은 구간을 두 개로 나눔 → 반복
  - 즉, 고전적 의미의 이진수(0,1)가 아니라, **분포를 이분(bisection)하는 탐색 전략**인 것이다.

**💡****큐비트의 공명 주파수란?**

- - **2레벨 시스템의 정의**

    - 양자컴퓨터의 큐비트(트랜스몬, 이온, 스핀 등)는 대부분 **2레벨 시스템**으로 동작한다.

      - **|0⟩ → |1⟩** 상태 전이를 일으키는 데 필요한 에너지는

- - - - 여기서 ωq가 바로 **큐비트의 고유 전이 주파수**이다.
      - 이 값은 장치 설계, 전극 전압, 자기장, 스트레인 등 **환경 조건**에 따라 달라지고, 시간에 따라 **드리프트**하기도 한다.
  - 플랫폼별 예시

|  |  |  |
| --- | --- | --- |
| **큐비트 플랫폼** | **전형적 공명 주파수 범위** | **제어 방식** |
| **트랜스몬(초전도체)** | 4 ~ 8 GHz | 마이크로파 펄스 |
| **이온 트** | 1 ~ 10 MHz | RF + 레이저 |
| **스핀 큐비트** | 수 MHz ~ GHz | ESR/EDSR |
| **광자 큐비트** | 1550 nm (≈193 THz) | 위상 변조 |

**💡****왜 공명 주파수를 정확히 찾아야 하나?**

- - **제어 펄스는 “공명”에 맞춰야 함**

    - 양자 게이트(예: π-펄스, Hadamard, CNOT 등)는 **구동 주파수** ωd를 큐비트의 고유 주파수 ωq에 **맞춰서** 설계됨.

      - 이상적 조건: ωd=ωq
      - 오차 존재 시: Δ=ωd−ωq≠0
  - **오프-레조넌스(Off-resonance) 에러**

    - 만약 ωd가 ωq에서 벗어나면, Rabi 진동 각속도가 어긋나서 **게이트 오차**가 생긴다.

- - - Δ: 주파수 오차
    - Ω: Rabi 주파수(게이트 세기)
    - 즉, ωq를 10 kHz만 잘못 알아도, 게이트 충실도가 99.9%에서 98% 이하로 떨어질 수 있다.
    - 이는 양자오류보정(QEC)에서 **논리 큐비트 수를 수십 배로 늘려야 함**을 의미한다.

**💡****공명 주파수와 오류율의 관계**

- - **주파수 드리프트 → 게이트 충실도 저하**

    - **환경 노이즈**(플럭스 잡음, 전하 잡음, 온도 변화, 전극 드리프트 등) 때문에 ωq가 ms~분 단위로 바뀐다.
    - 제어 주파수 ωd를 보정하지 않으면, 점점 **off-resonant** 상태로 가면서 게이트 충실도↓.
  - **오류보정(QEC) 리소스 폭증**

    - 예: 표면코드(Surface Code)에서 논리 오류율 pL은 대략

- - - pg: 게이트 오류율
    - pth: 임계값(~1%)
    - d: 코드 거리
    - 즉, ωq 드리프트로 pg가 0.1% → 1%로 오르면, **논리 큐비트에 필요한 물리 큐비트 수가 수십~수백 배 증가**.

**💡****FBS(Frequency Binary Search)의 역할**

- - **역할**

    - 실시간으로 ωq를 **계속 추적**해
    - ωd를 **즉시 보정**
    - 드리프트가 누적되기 전에 게이트 충실도를 유지
  - **동작 흐름**

    - 1. FPGA에서 Ramsey/Rabi 측정 실행
      2. 결과 m\_k(0/1)을 수집
      3. 우도함수 기반으로 p(ω) 갱신
      4. 후보 범위를 절반으로 좁힘 (Binary Search)
      5. 새로운 ωd 설정 → 실험 반복
    - 이 과정을 10회 미만으로 반복 → **kHz 수준 정밀도로**  **ω****q** **추정**
    - FPGA에서 μs 단위로 처리 → 실시간 보정 가능

**💡****양자컴퓨터 전체에서의 위치**

FBS는 **양자 알고리즘 실행 전에** 또는 **실행 중에도** 활용된다.

|  |  |  |
| --- | --- | --- |
| **단계** | **동작** | **FBS 역할** |
| **사전 캘리브레이션** | 실험 시작 전 ωd 찾기 | ✅ |
| **실시간 안정화** | 환경 변화로 드리프트 발생 | ✅ |
| **게이트 튜닝** | CNOT, CZ 같은 다중 큐비트 게이트 | ✅ |
| **QEC 루프와 연동** | 오류율을 일정 수준 아래로 유지 | ✅ |

**💡****구동 신호 경로 (FPGA → QPU)**

- - **역할**: 큐비트에 게이트 펄스를 걸거나 Ramsey/Rabi 측정을 위한 주파수 탐색.
  - **인터페이스**:

    - **SMA 동축 케이블**(Superconducting Microwave Lines)
    - 또는 **광섬유**(트랩 이온/광자 QPU의 경우)
  - **구성**:

    - FPGA의 AWG(Arbitrary Waveform Generator)가 디지털로 파형 합성
    - DAC(Digital-to-Analog Converter)에서 아날로그 펄스로 변환
    - Cryostat 내부로 저온 동축선 투입 → QPU의 제어 전극 또는 레이저 변조기(AOM/EOM)에 입력

**💡****판독 신호 경로 (QPU → FPGA)**

- - **역할**: 큐비트 상태 ∣0⟩ 또는 ∣1⟩ 측정을 위한 신호 수집
  - **인터페이스**:

    - 트랜스몬·스핀 QPU → **동축선(SMA, 50Ω 매칭)**
    - 트랩 이온·광자 QPU → **광섬유 + 포토다이오드**
  - **구성**:

    - Cryostat에서 증폭된 마이크로파/광학 신호 → FPGA의 ADC로 입력
    - FPGA 내부에서 IQ 신호 디지털화 → FBS 알고리즘에 사용

**💡****클럭·트리거 동기화**

- - FBS가 실시간으로 작동하려면 **QPU와 FPGA 사이에 공통 클럭**이 필요.
  - **하드웨어 연결**:

    - 10 MHz~100 MHz **리퍼런스 클럭**을 FPGA와 QPU에 동시에 공급
    - 펄스 타이밍 오차 ≤ 100 ps 수준 유지
    - FPGA와 AWG, ADC, QPU 간 트리거를 LVDS/TTL로 분배

**💡****Cryostat 환경 연결**

- - 트랜스몬 QPU 같은 경우 QPU는 **10mK 초저온 환경**에 있으므로:

    - 상온 컨트롤러(OPX+) ↔ Cryostat 내부 QPU 사이에 **초저온 호환 동축 케이블** 사용
    - 열 잡음을 줄이기 위해 Attenuator, Isolator, Filter 삽입
  - 트랩 이온 QPU의 경우:

    - FPGA에서 나온 전기신호 → AOM/EOM → 레이저 변조 → 광섬유를 통해 이온에 입사
    - 판독 경로도 광섬유 기반 포토다이오드 또는 PMT로 FPGA에 연결

**✅****FBS가 큐비트별 동기화를 맞추는 방법**

FBS는 FPGA 기반 컨트롤러(OPX+)에서 **각 큐비트 채널을 개별적으로 제어·동기화**한다.

구체적으로 세 가지 레벨에서 동기화가 이루어진다.

**💡****주파수 동기화 (Frequency Synchronization) - 실험 전과 실시간 모두 사용 가능**

- - **원리**

    - 각 큐비트별로 개별 NCO(Numerically Controlled Oscillator)를 FPGA 내부에 할당.
    - NCO가 디지털 방식으로 ωd(i)를 생성하고, 이를 **DAC → AWG → QPU**로 전송.
    - FBS 알고리즘은 각 큐비트의 공명 주파수 ωq(i)를 실시간으로 추정해, ωd(i)를 계속 보정.
  - **구현**

    - FPGA 내부에서 **채널별 Look-Up Table(LUT)** 또는 DDS(Direct Digital Synthesizer)를 사용.
    - 해상도: 주파수 스텝 ≤ **1 Hz** 수준 가능.
    - Qubit별로 독립적인 위상·진폭·주파수 제어.

**💡****시간 동기화 (Timing Synchronization) - 멀티큐비트 게이트와 동시 제어시 사용**

- - **문제**

    - 다중 큐비트 제어에서는 펄스가 정확히 같은 **클럭 사이클**에서 시작해야 함
    - FPGA에서 큐비트마다 개별 채널을 쓰지만, 타이밍이 100 ps만 어긋나도 위상 에러 발생.
  - **해결**

    - OPX+ 같은 FPGA 컨트롤러는 하나의 전역 마스터 클럭(typically 1 GHz)을 사용해
    - **모든 채널을 동기화**.
    - 채널별 펄스 시퀀스는 **FPGA 내부 타임태그** 기반으로 예약되어,
    - 트리거 지연이 전혀 없도록 보장.

**💡****측정 동기화 (Readout Synchronization) - readout 충돌 방지 및 병렬 측정시 사용**

- - **문제**

    - FBS 알고리즘은 큐비트별 **Ramsey/Rabi 측정 결과**를 기반으로 주파수를 추정.
    - 측정 시작 시점과 펄스 종료 시점이 정확히 동기화되어야 함.
  - **해결**

    - FPGA에서 AWG → QPU로 펄스를 보내고,
    - **동일 FPGA의 ADC 채널**에서 판독을 μs 단위로 수행.
    - 펄스 트리거와 측정 게이트를 **동일 클럭 도메인**에서 제어 → 지연 없음.
    - 실시간으로 IQ 신호를 디지털 변환해 FBS 알고리즘에 입력.

**💡****FBS에서 쓰이는 동기화**

|  |  |  |  |
| --- | --- | --- | --- |
| **상황** | **주파수 동기화** | **시간 동기화** | **측정 동기화** |
| **단일 큐비트 제어** | ✅ 필수 | ❌ 불필요 | 선택적 |
| **2큐비트 이상 게이트** | ✅ 필수 | ✅ 필수 | ✅ 필요 |
| **다중 큐비트 병렬 readout** | ❌ 불필요 | ❌ 필요 없음 | ✅ 필수 |
| **FBS 알고리즘** | **중심 역할** | 자동 지원 | 간접 활용 |

|  |  |  |

| **오류 원인** | **설명** | **FBS로 해결 가능?** |
