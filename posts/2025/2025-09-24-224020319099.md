# [연재]양자 오류 정정 (1) - QEC 장치 + 조금의 계산

**💡****배경 – 왜 필요했나?**

- - **1994년**: 미국의 이론 컴퓨터 과학자로 잘 알려진 피터 쇼어(Shor)가 소인수분해 알고리즘(Shor's algorithm)을 발표 → "양자컴퓨터가 고전암호를 깨뜨릴 수 있다"는 충격.
  - 하지만, 곧 독일계 미국인 물리학자인 **롤프 란다우어(Rolf Landauer)** 를 비롯한 많은 물리학자들이 반론을 제기했다:

> "양자 상태는 너무 불안정해서 작은 오류가 축적되면 계산이 곧 무너질 것이다."

- - 즉, **양자 오류 문제**가 해결되지 않으면, 양자컴퓨터는 꿈에 불과하다고 본 것임.

**💡****쇼어(Shor)의 돌파구**

- - **1995–1996년**: 피터 쇼어가 최초의 양자 오류 정정 코드(Shor code)를 제안.
  - 9개의 큐비트를 사용하여 1개의 논리 큐비 보호.
  - 비트 플립(X 오류)과 위상 플립(Z 오류) 모두를 동시에 정정할 수 있었음.
  - 이것이 **양자 오류 정정(QEC)의 시작점**이다.

> 최초의 양자 오류정정은 피터 쇼어가 개발했지만, 그로 하여금 이것을 할 수 있게 만든 것은 란다우어 박사의 "긁".

**💡****다른 연구자들의 기여**

- - **1995년**: **앤드류 스테인**(Andrew Steane)이 독립적으로 7큐비 코드(Steane code)를 발표 → Hamming 코드에서 영감을 받은 CSS 코드.
  - **1996–1997년**: 쇼어, 아하로노프(Dorottya Aharonov), 베네트, 프레스킬 등 연구자들이 **fault-tolerant quantum computation (내결함성 양자 계산)** 개념을 정립.

    - 오류가 존재하더라도, 안정적으로 알고리즘을 실행할 수 있는 방법.
  - **1990년대 후반**: "Threshold theorem" 확립 → 오류율이 특정 임계치(Threshold) 이하라면, QEC를 통해 안정적인 대규모 양자계산이 가능하다는 증명.

**💡****QEC 발전 타임라인**

|  |  |  |
| --- | --- | --- |
| **연도** | **주요 연구자** | **업적 / 사건** |
| **1994** | Peter Shor | **소인수분해 알고리즘 발표** → 양자컴퓨터 가능성 대두. 동시에 "오류 누적 문제"가 심각한 장벽으로 제기됨. |
| **1995** | Peter Shor | **최초의 QEC 코드(Shor 9-qubit code)** 제안. X(비트 플립)과 Z(위상 플립)를 동시에 정정 가능. |
| **1996** | Andrew Steane | **Steane 7-qubit code** 발표. 클래식 Hamming 코드 기반. 더 효율적이고 실용적인 CSS 코드 구조 제시. |
| **1996** | Calderbank, Steane & Shor | **CSS 코드 체계(Calderbank–Shor–Steane code)** 정립. 고전 선형 부호 이론을 양자 코드에 확장. |
| **1996–1997** | Aharonov & Ben-Or, Preskill, Knill & Laflamme | **Fault-tolerant quantum computation** 개념 확립. 게이트/측정 오류까지 안전하게 실행하는 방법론 제시. |
| **1997–1998** | Kitaev | **Stabilizer formalism** 발전, 토릭 코드(Toric code) 구상 → 이후 topological QEC의 기초. |
| **1998–1999** | Knill, Laflamme, Zurek | **Threshold theorem** 증명. 물리적 오류율이 특정 임계치 이하이면 QEC로 안정적인 양자 계산이 가능함을 이론적으로 보장. |
| **2000 이후** | 다양한 그룹 | Surface code, color code 등 대규모 양자컴퓨터를 위한 topological code 연구 본격화. |

**💡****QEC에 영향을 미친 고전 오류 정정 코드**

|  |  |  |
| --- | --- | --- |
| **연도** | **고전 코드** | **QEC와의 관계** |
| **1950 – Hamming code** | [7,4] Hamming code | **Steane code(1996)**가 **양자 Hamming code**로 확장됨. 7큐비트로 1큐비 보호. |
| **1959 – Reed-Solomon code** | 블록 오류 정정 코드 | **Calderbank–Shor–Steane (CSS)** 코드 구조에 영감을 줌. 다중 오류 정정 아이디어 제공. |
| **1960s – BCH codes** | Bose–Chaudhuri–Hocquenghem codes | CSS 코드와 밀접. Steane code도 사실상 BCH [7,4,3] 코드의 양자 확장. |
| **1962(재발견 1996) – LDPC codes** | Low-Density Parity-Check | 오늘날 **qLDPC (quantum LDPC) codes** 연구로 이어짐. 고전 LDPC의 희소 그래프 구조가 대규모 QEC에 적합. |
| **1970s – Goppa codes** | Algebraic geometry codes | 일부 양자 안정자 코드(stabilizer codes) 연구에 활용. 특히 CSS construction에서 기반이 됨. |
| **1993 – Turbo codes** | Iterative decoding | 직접적 영향은 작지만, **반복적(Iterative) 디코딩 기법**이 양자 오류 정정(예: belief propagation decoders)에 아이디어 제공. |
| **2009 – Polar codes** | Capacity-achieving code | 최근 연구에서 **Quantum Polar Codes** 제안. 채널 용량 이론과 QEC의 연결 고리. |

**💡****양자 컴퓨터의 재정의**

- - **첫 번째 시도 정의**

    - 양자컴퓨터는 단순히 양자 계산(quantum computations)을 수행할 수 있는 기계라고 정의한다.
    - 하지만 이 정의는 실제 현실과는 다소 거리가 있다.
  - **더 정확한 정의**

    - 양자컴퓨터는 양자 오류 정정(QEC, Quantum Error Correction)을 수행하고, 거기에 약간의 계산을 할 수 있는 기계라고 보는 것이 맞다.
    - 현재의 기술 수준에서는 계산보다 **오류 억제와 정정**이 훨씬 더 큰 비중을 차지하기 때문이다.
  - **노이즈율 비교**

    - 현재 양자 하드웨어의 노이즈율은 약 10−3 수준이다.
    - 반면 고전 하드웨어의 노이즈율은 10−20까지 낮출 수 있다.
  - 이 격차가 양자컴퓨터의 가장 큰 난제이며, QEC 없이는 실용적 계산이 불가능하다.

**💡****예시 - 쇼어 알고리즘**

- - **연구**: Craig Gidney와 Martin Ekera의 분석

    - 2048비트 RSA 수를 8시간 안에 인수분해하기 위해 필요한 자원량을 계산하였다.
    - 이는 현재 암호 보안을 깨는 가장 대표적인 문제다.
  - **큐비트 요구량**

    - 오류 정정 없는 경우: 약 14,238 큐비트
    - 오류 정정을 적용(QEC)한 경우: 약 22,325,184 큐비트

      - → QEC 때문에 필요한 큐비트 수가 **수천 배 이상** 증가한다.
  - **얽힘 게이트(entangling gate) 비용**

    - 단일 게이트: 2개의 큐비트, 약 100 ns
    - QEC 적용 게이트: 2,925 큐비트, 약 27,000 ns
    - 여기에 추가로

      - 39,339 큐비 초기화
      - 39,339 측정
      - 153,090 CNOT 게이트가 필요하다.

> **양자컴퓨터 = “QEC 장치 +** **조금의 계산****”**
>
> **배보다 배꼽이 더 큰 상황**

**💡****왜 QEC에 많은 자원이 필요한가?**

- - **비교 대상**: 슈퍼컴퓨터(Astra, Sandia National Labs)와 오늘날 양자컴퓨터의 노이즈 수준을 비교한다.
  - **Astra 슈퍼컴퓨터**

    - 페타플롭급 성능, TOP500에 속한 시스템
    - 노드당 하루 약 6개의 오류 발생
    - 노드 하나에 56개 2GHz 프로세서 포함
    - 결과적으로 약 1014 사이클마다 1회 오류 발생
  - **오늘날 양자컴퓨터**

    - 각 큐비트마다 약 103 사이클마다 1회 오류 발생
  - **핵심 차이**

    - 고전 슈퍼컴퓨터는 매우 드물게 오류가 생기지만,
    - 양자컴퓨터는 **큐비 하나하나가 매우 자주 오류를 일으키기 때문에** 오류 정정을 위한 자원이 막대하게 필요하다.
