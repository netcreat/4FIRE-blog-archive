# EDA와 IP - Synopsys Inc (NASDAQ:SNPS)

가끔씩 내 흥미를 끄는 주제를 다루곤 하는 채널인데, 이번에는 반도체 설계 및 공정에 관련된 내용이다. 9월에 올라온 이 컨텐츠를 나오자마자 본 뒤 여느때와 마찬가지로, 기술적인 것들을 찾아보기 시작했다. 참 고맙게도 영상 안에서 각 약자가 어떤 뜻인지 설명을 해준다.

그리고는 1위 기업을 검색하기 시작했다. 그런데, 최근 IonQ와 협력하여 시뮬레이션을 구현했던 Ansys를 시뮬레이션 기업을 인수한 회사가 아닌가.

난 과학과 수학등을 좋아하는 이과생이지만, 어이없게도 인연이라는 것도 꽤 중요시한다.

아마도, 꽤 오래전에 이 영상이 나왔다면, 반도체 공정에 대해 조금 알아보다가 말았을 것이고, 아마 Ansys라는 회사를 인수했다는 것도 몰랐을 것이다. 설령 찾아보다가 발견했다고 쳐도, 그냥 지나쳤을 것이다. 이건 마치, 서울에서 그냥 스쳐 지나가는 무수히 많은 사람들을 타국에 와서 만나면 이유도 없이 반가운 그런 느낌이랄까.

아마 예상하겠지만, 이 글의 내용중 일부는 위 채널의 내용을 참고했음을 미리 명시한다.

---

**✅****반도체 제작 생태계**

초기에는 설계부터 제작까지 모든 것을 전부 처리하는 방식(IDM - Integrated Device Manufacturer)이었지만, 점차 디자인과 생산을 전문으로 하는 기업으로 나뉘기 시작했다.

**💡****IDM (Integrated Device Manufacturer)**

- - IDM은 반도체 칩의 **설계(Design)** 와 **제조(Manufacturing)** 를 모두 내부에서 처리하는 **수직계열 구조**의 기업을 말한다.
  - 대표 IDM 기업

    - **Intel** – CPU/FPGA 설계 + 자체 공장 보유
    - **Samsung Electronics** – 메모리, 시스템 반도체 둘 다 직접 생산
    - **Micron**, **Texas Instruments (TI)** – 메모리, 아날로그 반도체

**💡****Fabless (Fabrication-less)**

- - Fabless는 반도체 칩의 **설계(Design)** 는 직접 하지만, **제조(Fabrication)** 는 외부 파운드리에 맡기는 회사.
  - 즉, 아이디어 및 회로 설계 전문 기업이다.
  - 대표 Fabless 기업

    - NVidia - GPU, AI 가속기, 세계 1위 팹리스
    - Qualcomm - 모바일 AP, 통신칩
    - AMD - CPU, GPU, 생산은 TSMC에 위탁
    - Apple - M시리즈, A시지르 SoC, 생산은 TSMC
    - Broadcom, Marvell - 네트워크, 통신 SoC
  - **Fabless의 강점**

    - 공장을 보유하지 않아 **자본 효율이 높음**
    - 기술 혁신 속도가 빠름 (설계 집중)
    - 고급 엔지니어 중심의 R&D 구조
  - **Fabless의 약점**

    - 제조 공정에 직접 접근 불가
    - 파운드리(제조사)에 **의존도 높음**
    - 공급망 이슈 시 생산 차질 위험

**💡****Foundry**

- - Foundry는 **설계는 하지 않고**, 오직 **남이 설계한 반도체를 위탁 생산하는 회사**.
  - Fabless 고객이 설계 데이터를 넘기면, Foundry는 자사 **공정 노드(5 nm, 3 nm, 2 nm 등)** 로 제조한다.
  - 대표 Foundry 기업

    - TSMC - 세계 1위 (점유율 60% 이상)
    - Samsung Foundry - 시스템 반도체, 메모리 둘 다 가능
    - Intel Foundry Services (IFS) - IDM → Foundry로 확장 중
    - GlobalFoundries - 중 저가 공정 위주
  - Foundry의 핵심 자산

|  |  |
| --- | --- |
| **요소** | **설명** |
| **Fab (공장)** | 수십억 달러 규모의 반도체 생산 시설 |
| **PDK (Process Design Kit)** | 고객이 설계할 수 있도록 제공하는 공정 데이터 패키지 |
| **공정 기술 노드** | 7 nm, 5 nm, 3 nm 등 트랜지스터 미세화 기술 |
| **EUV 장비 (ASML)** | 첨단 노드 생산의 필수 요소 |

**💡****Fabless vs IDM vs Foundry: 비교 요약**

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **Fabless** | **Foundry** | **IDM** |
| 설계 | ✅ | ❌ | ✅ |
| 제조 | ❌ | ✅ | ✅ |
| 예시 | NVIDIA, Qualcomm, AMD | TSMC, Samsung Foundry | Intel, Samsung Electronics |
| PDK 제공 | ❌ | ✅ | 내부 공유 |
| 장점 | 경량 구조, 혁신 속도 | 안정된 생산기반, 공정 리더십 | 전체 통합, 최적화 가능 |
| 단점 | 생산 의존성 높음 | 설계 역량 없음 | 자본 부담 큼 |

**✅****IP (Intellectual Property)**

- - 일반적으로는 지적재산 또는 지식재산을 뜻한다.
  - 즉, 사람이 만든 창작물 중 눈에 보이지 않는 아이디어나 설계 등에 대한 권리를 뜻한다.
  - 그러나, 반도체 생태계에서는 좀더 구체적이고 특화된 내용들을 다룬다. 아래에 이 둘의 미묘한 차이를 표로 나타냈다.
  - 한마디로 표현하면 지적재산의 한 종류로서 반도체 회로 설계 데이터를 자산화한 것이 반도체 IP.

|  |  |  |
| --- | --- | --- |
| **구분** | **일반적 의미의 IP** | **반도체에서의 IP** |
| **정식 이름** | Intellectual Property (지적재산) | Semiconductor / Design IP (반도체 설계 자산) |
| **보호 대상** | 창작물, 상표, 발명, 디자인 등 | **검증된 회로 설계 블록** (디지털 로직, 인터페이스, 메모리 등) |
| **형태** | 문서, 코드, 예술작품, 상표 등 | RTL 코드(Verilog/VHDL), GDSII 파일, 시뮬레이션 모델 등 |
| **법적 보호 수단** | 저작권, 특허권, 상표권 등 | 주로 **저작권 + 계약 라이선스** |
| **거래 방식** | 판매/라이선스 (출판, 음악, 소프트웨어 등) | 라이선스 + 로열티 (칩 출하량 기반) |
| **대표 기업** | 디즈니, 넷플릭스, 나이키 등 | Synopsys, ARM, Cadence, Alphawave 등 |

**💡****반도체 IP의 구체적 예시**

- - 아래의 예시처럼 반도체 IP들은 RTL 코드나 회로 데이터 형태로 존재하며, 고객은 이를 라이선스 받아 자신의 SoC 설계에 포함시킨다.

|  |  |  |
| --- | --- | --- |
| **IP 종류** | **설명** | **대표 공급자** |
| **Processor IP** | CPU, GPU, DSP 등 코어 설계 | ARM, SiFive, Imagination |
| **Interface IP** | PCIe, USB, CXL, DDR 등 I/O 통신 블록 | Synopsys, Cadence, Alphawave |
| **Memory IP** | SRAM, DRAM, HBM Controller 등 | Synopsys, Rambus |
| **Security IP** | 암호화, 보안 부트, TRNG 등 | Synopsys, Rambus |
| **Analog / PHY IP** | PLL, ADC/DAC, SerDes, Clock | Synopsys, Analog Bits |

**💡****IP Top 4**

- - Top 4 가 전체 IP 시장의 75%를 점유하지만, 양강 구도나 마찬가지

    - **Synopsys - 32%, 통신 및 전반적인 IP**
    - **ARM - 30% - 프로세서 IP**
    - Cadence
    - Alphawave

**💡****IP 사업의 본질**

- - 반도체 IP(Design IP)는 쉽게 말해 “검증된 회로 블록을 팔아서 재사용하게 하는 사업”이다.
  - EDA 툴(설계 자동화 소프트웨어)로 직접 만든 회로 중, 범용성이 높은 모듈을 **라이브러리화해 상품화**한 것이 IP이다.

    - 예: PCIe 5.0 컨트롤러, DDR5 메모리 컨트롤러, USB PHY, AES 보안 엔진 등
    - 고객(예: 삼성, TSMC 고객사, 엔비디아 팹리스 팀)은 설계 초기에 이 IP 블록을 사서 자신들의 칩에 포함시킨다.

**✅****EDA (Electronic Design Automation)**

EDA는 반도체 칩을 설계할 때 필요한 각종 작업(논리 회로 설계, 배치·배선, 타이밍 검증, 전력 분석 등)을 컴퓨터가 **자동으로 해주는 소프트웨어 툴 세트**이다.

> 쉽게 말해, 칩 설계 엔지니어가 사용하는 **“AutoCAD + 시뮬레이터 + 디버거”** 같은 역할.

**🧩 주요 회사**

- - **Synopsys** – 31%, Design Compiler, Fusion Compiler, HSPICE, PrimeTime 등
  - **Cadence** – 30%, Innovus, Virtuoso, Spectre, Allegro 등
  - **Siemens EDA (구 Mentor Graphics)** – 13%, Calibre (물리 검증) 등

**⚙️ EDA의 역할 예시**

1. 1. 논리 설계 (Logic Synthesis)
   2. 물리 설계 (Place & Route)
   3. 타이밍 분석 (Static Timing Analysis)
   4. 전력/소모 분석
   5. 레이아웃 검증 (DRC/LVS 등)
   6. 시뮬레이션 및 디버깅
   - → 즉, **반도체 칩을 “디자인”하고 “검증”하는 전체 과정**을 지원하는 툴.

---

**✅****PDK (Process Design Kit)**

- - PDK는 특정 파운드리의 특정 공정을 모델, 규칙, 라이브러리로 추상화한 것.
  - 반도체 **공정(Process)** 에 맞춰 EDA 툴에서 사용할 수 있게 정리한 **물리적/전기적 데이터 세트**이다.

    - 파운드리의 핵심 기술 노하우와 집약된 자산으로, 엄격한 비밀 유지 계약(NDA) 하에 팹리스에 제공된다.
  - (Foundry → 설계회사에 제공)
  - 팹리스 기업의 설계 엔지니어들은 PDK가 있어야만 자신의 설계가 실제 공정에서 문제없이 생산될 수 있을지 정확하게 시뮬레이션 할 수 있다.

**💡****PDK안에는 뭐가 들어있나?**

|  |  |
| --- | --- |
| **구성요소** | **설명** |
| **Design Rule Check (DRC)** | 제조 가능한 최소/최대 간격, 두께, 폭 등을 정의 |
| **Layout vs Schematic (LVS)** | 설계자가 그린 회로가 실제 배치·배선에서 같은 연결을 유지하는지 검증 |
| **Parasitic Extraction (PEX)** | 고속 회로의 신호 지연이나 잡음 영향을 미리 계산 |
| **Antenna Rule / Power Integrity Rule** | 제조 과정에서 정전기나 전압 강하를 방지 |
| **Design for Manufacturability (DFM)** | 수율(Yield) 향상, 결함 가능성 최소화 |
| **SPICE 모델 / Device Model** | 시뮬레이션 시 실제 전기적 거동을 재현 |
| **PCell / Layout Library (Parametric Cell)** | 설계자가 파라미터(폭, 길이 등)만 바꿔 다양한 셀을 자동 생성 |
| **Layer Map / Tech File** | 레이아웃 편집기에서 각 층(Layer)을 구분하고 제조 시 어떤 물질로 되는지 정의 |
| **Timing / Power / Physical Abstract File** | 디지털 설계 자동화(Place & Route) 시 필요한 요약 정보 제공 |

> 쉽게 말하면, “TSMC 3nm 공정으로 설계하려면 이런 규칙, 이런 파라미터를 써라”
>
> 라는 **디지털 설계용 교범(매뉴얼)**.

- 팹리스의 설계자는 파운드리가 제공한 PDK라는 공정 전용 플러그인 세트를 불러와서 반도체를 설계하게 됨.
- PDK는 해당 파운드리의 공정을 담고 있기 때문에 A 파운드리에서 제공한 PDK를 이용해 제작한 설계는 B파운드리에서 사용할 없고, 파운드리를 바꾸려면, 처음부터 설계를 다시 시작해야 한다. 이로 인해 Lock-in효과가 발생하게 됨.

  - 하지만, 메모리 같은 완제품 IP는 여러 공정과 패키징 표준을 동시에 지원하도록 만들어지기 때문에, 팹리스가 여러 파운드리와 계약을 할 수 있다.

    - Nvidia → Samsung, SK Hynics

- 설계가 완료되면 완벽한 설계도면이 나오게 되는데, 최종 설계 파일 포맷으로 저장하게 되고, 그 포맷 중GDS2(Graphic Data System II)을 사용했었는데, 최근에는 용량이 상대적으로 작고, 첨단 공정을 지원하는 OASIS(Open Artwork System Interchange Standard)를 사용하여 저장한 파일을 최종적으로 파운드리에 넘기는데, 이 과정을 Tape-out 이라고 한다.

---

이미 눈치를 챘을 수 도 있겠지만, IP와 EDA의 플레이어에 공통으로 겹치는 회사가 있다.

- - **IP**

    - **Synopsys - 32%**
    - ARM - 30% - Cadence EDA를 주로 사용하지만, Synopsys 와 툴과 솔루션 부분에서 긴밀히 협력함.
    - **Cadence**
  - **EDA**

    - **Synopsys** – 31%
    - **Cadence** – 30%
    - Siemens EDA (구 Mentor Graphics) – 13%
  - Synopsys와 Cadence인데, 두 영역에서 양강구도를 차지하는 회사는 Synopsys가 유일하다.
  - 그리고, 위의 내용을 이해했다면, IP는 결국 EDA를 이용하여 검증된 회로 블록을 설계하는 것이기 때문에,
  - Synopsys와 같은 회사는 자체 EDA 툴로 검증한 IP를 제공하므로, 고객 Lock-in 강화 효과가 더욱 크다.
  - EDA도 PDK처럼 종속성이 강하여, 쉽게 툴을 바꾸지 않는다.

    - 검증 방법론, 스크립트, IP 호환성등에서 영향을 받게됨.
    - 운영적 리스크 우려 (설계 Flow가 붕괴됨).
  - Fabless는 파운드리를 교체하는 것도, EDA를 바꾸는 것도 현실적으로 불가능에 가깝다.

    - EDA를 계속 사용하게 될 것이고, 이미 만들어진 IP를 계속 사용하게 되는 것이다.

> 이러한 이유로, EDA 기반 IP 공급사들이 전체 IP 시장의 약 60 ~ 70%를 차지함.
>
> **Synopsys가 두 시장 모두 키플레이어**가 된 이유이기도 함
