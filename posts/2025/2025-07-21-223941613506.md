# Quantinuum이 구현하는 이온트랩

Published: 2025-07-21T15:54:37.706000+09:00

Original Naver post: https://blog.naver.com/4-fire/223941613506

---

이제 본격적으로 퀀티넘을 알아보자.

- **2014년에 Cambridge Quantum Computing(CQC)와 Honeywell Quantum Solutions(HQS)로 시작**
- **2021년 11월 두 회사의 합병으로 인해 Quantinuum 공식 출범.**
- Honeywell의 이온트랩 기술과 Cambridge Quantum의 소프트웨어 역량이 결합된 기업이다.
- H‑Series 트랩 아이온 시스템은 획기적인 퀀텀 볼륨을 기록하며 상용화를 선도하고 있다

퀀티넘이 발표한 양자컴퓨터의 스펙을 살펴보자.

**✅ 퀀티넘 시스템 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **H1‑1 / H1‑2**  **(2020년, 2021년)** | **H2‑1**  **2023년 5** |
| **물리 큐비트 수** | 12–20 | 56 (all-to-all) |
| **1‑큐비트 충실도** | inf ≈ 1e‑5 ~ 4e‑5 | ≈99.997% |
| **2‑큐비트 충실도** | inf ≈ 1e‑3 ~ 3e‑3 | ≈99.8% |
| **큐비트 연결성** | All‑to‑all | All‑to‑all |
| **특징 기능** | Mid-circuit 측정, 재사용 | Racetrack 설계, FTQC 기본구성, QV 2²⁰ 달성 |
| **메트릭 및 기록** | QV 2,048 | QV 65,536 → 1,048,576; non-Abelian anyons 실험 |
| **로드맵 단계** | 초기 상용화 단계 | 논리 큐비트 + FTQC 시스템 ‘Apollo’ 설계 진입 |

- **2023–2024: H2 시스템**

  - **56개 물리 큐비트**
  - Surface 기반 논리 큐비트(Break-even), **12논리큐비트** 시연
  - Magic State Distillation 등 FTQC 프리미티브 적용
- **중간 단계: Helios**

  - 리소스 확보, **Ba⁺ 지원 ->** **향후 이테르븀을 대체하거나, 포토닉 연결로 진화할 개연성이 높음**
  - 수십~수백 논리 큐비트 구현 예정
- **이어서 Sol**

  - 2D 격자 기반 구조
  - 수백 물리 큐비트, 저에러율(≤2×10⁻⁴), HFS 실험자원 제공
- **2030 전후: Apollo**

  - FTQC의 완성판: **수천 물리 큐비트, 수백 논리 큐비트, 수백만 게이트 처리**
  - 목표 논리 에러율 10-6 이하, 이상적으로 10-10

****

- **이온트랩 구성**

  - Quantinuum은 선형 체인 트랩을 유지하면서도, 양자 볼륨 향상에 따라 체인의 길이와 제어 유연성을 높였다.
  - 고성능 제어 광학계와 안정화된 이온 체인이 강점이다.
- **게이트 제어 방식**

  - Quantinuum/IonQ 모두 레이저 기반 제어 방식이며, 초고정밀 정렬과 안정화를 위해 고가의 레이저 시스템을 필요로 한다.
  - Oxford Ionics는 마이크로웨이브 기반 제어 방식이고, 로드맵에 의하면 아이온큐의 게이트 제어 방식을 마이크로웨이브 방식으로 전환됨.
- **논리 게이트 및 오류 정정**

  - Quantinuum은 Color 코드 기반의 FTQC 실험을 주도하며, 논리 게이트 정제(MSD)도 이미 구현 완료.
- **스케일링**

  - **Quantinuum은 체인을 늘리는 방식에 집중**하고 있고,
  - **IonQ는 다중 모듈 간 포토닉 연결을 통한 확장**에 중점을 둔다.

> **퀀티넘은 바륨이온을 이용하는 연구를 꾸준히 해오고 있지만, 공식적인 로드맵에서 QPU를 서로 연결한다는 계획을 발표한 적은 없다. 현재 공식적인 발표에서는 바륨을 공감 냉각(Symphatetic cooling)용으로 사용중이다.**
>
> **공감 냉각 방식은 이중 종 이온 체인에서 바륨을 냉각하여 이테르븀의 운동 에너지를 간접적으로 줄이는 방식이며, 이는 고충실도 큐비트 운용의 핵심 전략이다.**

****

- **QEC (양자오류정정) 진행 상황**

  - **2024년 Microsoft와 협력하여** **56 큐비트 H2에서 논리 큐비트 12개 생성** **(이전 대비 3배)**
  - **Logical qubit error rate ≈ 물리 오류율의 1/800 수준 .**
  - 2027년까지 100 논리 큐비트 시스템 목표 .
  - 2029년경 FTQC 완성형 시스템 Apollo 출시 예고

**🧪QEC 알고리즘 및 논리 큐비트 구현**

- **Surface/color code 기반 QEC + Microsoft qubit‑virtualization 시스템**

  - Quantinuum H2 시스템과 Microsoft 협업을 통해 **4개의 논리 큐비트를 생성**했으며, **논리 게이트 오류율이 물리 대비 800배 낮아짐을 실험으로 증명**
  - 14,000번 연속 실행에도 오류 없음: “ran more than 14,000 individual instances of a quantum circuit with no errors”
  - 활성 **syndrome** 추출(reader) 포함된 QEC를 구현.
- **2024년 8월 : Tanner-transformed long‑range‑enhanced surface code 기반 QEC**

  - 콜로라도 대학교와 퀀티넘이 공동으로 아카이브에 발표([[2406.02666] Entangling four logical qubits beyond break-even in a nonlocal code](https://arxiv.org/abs/2406.02666))

    - 콜로라도 대학교에서 개발한 long-range-enhanced surface code를 Tanner Code 방식으로 변경하여 적용

      - Tanner 그래프 기반의 classical linear code를 입력으로 받아, 이를 CSS 양자 코드로 확장할 때 **하이퍼그래프 프로덕트(HGP) 방식(qLDPC 계열)으로 구성**됨.
      - CSS 코드(Calderbank-Shor-Steane code)를 Stabilizer로 사용

        - 낮은 Weight Stabilizer
      - non-Local 코드

        - Local 코드(서로 인접한 큐비트끼리만 상호작용)인 Surface Code와 달리 서로 멀리 떨어진 큐비트들 사이에 작용하는 연산 허용 → 이러한 이유로 초전도체 방식에서는 Surface Code를 사용.
    - [25,4,3] 구조

      - 총 사용 물리 큐비트 개수 : 31

        - 물리 큐비트 : 25
        - 보조 큐비트 : 6
      - 논리 큐비트 : 4
      - Distance : 3

        - distance 3은 FTQC를 구동시키기에는 부족한 Distance이다. 실험용 수치임.
        - distance가 5이상은 되어야 논리 오류율이 감소하기 시작하는 단계

          - 현재는 Break even달성 실험용.
    - BP-OSD를 디코더로 사용
- **2024년 11월 : Carbon code 기반 QEC + Microsoft qubit‑virtualization 시스템**

  - Quantinuum H2 시스템과 Microsoft 협업을 통해 발표 ([[2404.02280v3] Demonstration of logical qubits and repeated error correction with better-than-physical error rates](https://arxiv.org/abs/2404.02280v3))

    - **논리 게이트 오류율이 물리 대비 800배 낮아짐을 실험으로 증명**

- **2024년 12월 : Tesseract 기반 QEC**

  - Microsoft Azure Quantum이 설계하고 Quantinuum이 실험 수행 ([[2409.04628] Demonstration of quantum computation and error correction with a tesseract code](https://arxiv.org/abs/2409.04628))

- **Magic State Distillation (MSD)**

  - H1‑1 시스템에서 mid‑circuit measurement + feed-forward, 루프 기반 **MSD 회로가 현실적으로 구현됨**: “first quantum computing team ever to run a real-time magic state distillation protocol on quantum hardware”.

    - [Advances in compilation for quantum hardware – A demonstration of magic state distillation and repeat-until-success protocols](https://arxiv.org/pdf/2310.12106)
  - 후속 연구로는 H2-1(32 큐비트) 시스템에서 **논리 수준 MSD도 진행 중**임.

    - [Experimental demonstration of high-fidelity logical magic states from code switching](https://arxiv.org/pdf/2506.14169)
    - [Breaking even with magic: demonstration of a high-fidelity logical non-Clifford gate](https://arxiv.org/pdf/2506.14688)
- **확장된 논리 시스템**

  - **12 logical qubits까지 실험 완료**: GHZ 상태를 포함한 복잡한 논리 회로 수행, **논리 큐비트 에러율이 물리 대비 약 22배 낮아짐**.
  - 2024년 8월에 콜로라도 대학교와 퀀티넘이 공동으로 아카이브에 발표한 자료([[2406.02666] Entangling four logical qubits beyond break-even in a nonlocal code](https://arxiv.org/abs/2406.02666))에 의하면, "Logical qubits are encoded in a 25,4,3 **Tanner-transformed long‑range‑enhanced surface code**"를 이용하였음.

    - 25 물리 큐비트로 4개의 논리 큐비트를 인코딩하는 LDPC의 특성을 갖는, 변형된 Surface Code를 이용함.
    - distance 3은 FTQC를 구동시키기에는 부족한 Distance이다. 실험용 수치임.
    - distance가 5이상은 되어야 논리 오류율이 감소하기 시작하는 단계
    - 최소 11 이상은 되어야 상업적으로 사용 가능.
