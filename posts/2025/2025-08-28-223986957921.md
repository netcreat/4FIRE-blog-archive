**✅****Sanger Institute, Quantinuum과 함께 Q4Bio 도전 참여**

- Sanger 연구소는 Wellcome Leap의 **Quantum for Bio (Q4Bio)** **챌린지**에 참여하며, **Quantinuum**을 기술 파트너로 공식 선정한다.
- 이 컨소시엄은 옥스퍼드 대학교를 중심으로, Sanger Institute, 케임브리지 대학교, 멜버른 대학교, 키이우 학술 대학교 등과 함께 구성된다.
- 목표는 **고전 컴퓨터 한계를 넘어서는 복잡하고 변동성 높은 게놈 데이터를 처리할 수 있는 양자 알고리즘**을 개발하는 것이다.
- 단기 목표로는 **박테리오파지 PhiX174의 전체 게놈을 양자 컴퓨터에 인코딩하고 처리하는 것**을 계획하며, 이는 **세계 최초의 실험적 시도**가 될 수 있다.
- PhiX174 게놈은 **1980년 Fred Sanger가 이 유전자를 처음 시퀀싱하여 노벨상을 수상**하게 한 바로 그 대상이며, 이번 시도는 양자 컴퓨팅과 유전학 양쪽 모두에서 **중대한 이정표**를 의미한다.
- Quantinuum은 **System H2**라는 자사 양자 컴퓨터를 제공하는데, **56‑큐비트 시스템**으로 Quantum Volume 벤치마크에서 세계 기록(8,388,608 ≈ 223)을 보유하고 있어, **상업적으로 이용 가능한 시스템 중에서도 최고 성능**을 자랑한다.
- Quantinuum 측은 “**양자 컴퓨터가 게놈 연구 한계를 돌파할 수 있도록 최고 성능의 시스템을 지원한다**”라며 협력 의지를 밝혔다.
- 이 협업은 **Human Genome Project 이후 25년이 지난 지금**, **유전학 연구에 또 하나의 혁명적 전환점**이 될 가능성을 보여준다.

**✅ 이번 연구의 구체적 내용**

**💡PhiX174 개요**

- - **종류**: 박테리오파지(세균에 감염하는 바이러스)
  - **발견**: 1963년, Sinsheimer 연구팀이 처음 보고
  - **숙주**: 주로 대장균(E. coli)에 감염
  - **게놈 크기**: 약 **5,386 염기쌍(bp)** → 매우 작은 DNA 바이러스

**💡왜 중요한가?**

- - **세계 최초로 전체 게놈이 해독된 생물**.
  - 1977년 프레더릭 생어(Frederick Sanger)가 이 바이러스의 전체 DNA 염기서열을 해독
  - 이 업적으로 노벨 화학상(1980)을 수상
  - 그래서 **유전체학(Genomics)** 연구의 역사에서 **상징적 의미**가 있는 대상임.

**💡이번 연구에서의 역할**

- - 이번 Sanger Institute와 Quantinuum의 협력에서 **PhiX174 게놈을 양자 컴퓨터로 처리하는 것이 목표**.
  - 즉:

    1. PhiX174의 전체 DNA 서열을 양자 상태(quantum representation)로 인코딩
    2. **양자 알고리즘**으로 변이 분석, 상호작용 예측 등 고전 컴퓨터보다 더 효율적인 데이터 처리를 실험
  - 선택 이유:

    - 게놈 크기가 작아서 **양자 시뮬레이션에 적합**
    - 역사적으로 유전체 연구의 상징성을 가짐

**💡 Quantinuum의 접근**

- - Quantinuum은 자사 **System H2** 양자컴퓨터(56큐비트)를 이용해 PhiX174 게놈을 양자적으로 시뮬레이션할 예정.
  - 성공할 경우:

    - **세계 최초로 양자 컴퓨터 기반 게놈 해석 실험**
    - 고전 컴퓨터가 어려워하는 **다중 상호작용 모델링**에 활용 가능성 입증

**💡양자 - 유전학 융합 전략**

- - PhiX174 게놈을 양자 상태로 시뮬레이션하는 과정은 크게 **4단계**이다.
  - **게놈 데이터 인코딩**

    - Sanger가 제공하는 PhiX174 전체 DNA 서열(5,386 bp)을 **양자 상태로 매핑**
    - 염기서열(A, T, G, C)을 양자 비트열(Qubit string)로 변환

      - A → |00>
      - T → |01>
      - G → |10>
      - C → |11>
  - **양자 상태 진화 시뮬레이션**

    - DNA 염기쌍의 상호작용 해밀토니안(Hamiltonian)을 모델링
    - Quantinuum H2에서 Variational Quantum Eigensolver(VQE)로 시뮬레이션
    - 특정 유전 변이가 단백질 구조와 상호작용하는 방식을 **양자 에너지 최소화 문제**로 풀어냄
  - **양자-고전 하이브리드 분석**

    - 양자 시뮬레이션 결과 → Oxford, Kyiv에서 ML 기반 후처리
    - 고전적 AI 모델과 결합해 변이 패턴, 유전자 발현 조절 네트워크 탐지
  - **임상 데이터와 통합**

    - Melbourne에서 **환자 맞춤형 유전체 데이터**와 매칭
    - 특정 질병 연관성 예측 모델 생성

**💡이번 프로젝트의 의미**

- - **세계 최초**: 전체 바이러스 게놈을 **양자컴퓨터로 직접 인코딩** 시도
  - **실험적 검증**: PhiX174 → 인간 게놈으로 확장 가능성 확인
  - **QML(Quantum Machine Learning)** 실용화의 첫 걸음
  - **유전체학 혁신 가속화**:

    - 현재 인간 게놈 데이터는 **4TB 이상**
    - 고전 컴퓨터로는 계산 불가능한 상호작용 모델을 **양자 하이브리드**로 해결 가능성

**✅ Quantinuum이 파트너로 선택된 이유**

**💡****기술적 이유 — Quantinuum System H2의 압도적 성능**

- - Sanger Institute가 Quantinuum을 선택한 가장 핵심 이유는 **H2 양자컴퓨터의 현재 성능이 업계 최고 수준**
  - **양자 볼륨(QV) 세계 1위** → 대규모 고밀도 연산에 유리
  - **이온트랩 기반 QCCD 아키텍처** → 긴 코히런스 타임(초 단위)
  - **하이브리드 이온(Yb-171 + Ba-137)** → 다파장 제어 가능 → 게놈 염기서열 인코딩에 최적화
  - 즉, **PhiX174 전체 게놈(5,386 bp)을 양자 상태로 인코딩하고 시뮬레이션**하기에 현존 상업용 하드웨어 중 가장 적합

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **항목** | **Quantinuum H2** | **IonQ Forte** | **IBM Heron** | **Google Willow** |
| **큐비트 수** | **56** | 35 | 133 | 105 |
| **아키텍처** | QCCD (혼합 이온) | Photonic Interconnect 준비 | Transmon Superconducting | Transmon  Superconducting |
| **양자 볼륨(QV)** | **2²³ = 8,388,608** | 2²¹ = 2,097,152 | 2¹³ ≈ 8,192 | 미공개 |
| **게이트 충실도** | 99.9% (Mølmer–Sørensen 게이트) | 99.7% | 98% | 99.965% |

**💡연구 전략적 이유 — QEC와 양자-생명정보학 융합 역량**

- - Quantinuum은 단순히 하드웨어만 강한 게 아니다.
  - **QEC(Quantum Error Correction)** 및 **QML(Quantum Machine Learning)** 분야에서 **생명정보학과 결합하기 좋은 기술 스택**을 이미 갖추고 있다는 게 결정적 이유.
  - **QEC(양자 오류 보정) 역량**

    - Quantinuum은 Microsoft와 협력해 **56 물리 큐비트 → 12 논리 큐비트** 변환 실험에 성공했음.
    - **논리 큐비트**는 긴 시뮬레이션에서 발생하는 누적 노이즈를 크게 줄여 줌.
    - 유전체학 모델은 **DNA 염기-단백질 상호작용** 같은 긴 체인 계산을 필요로 하는데, 이는 QEC 없이는 불가능함.
  - **Quantum Machine Learning(QML) 지원**

    - Quantinuum은 자체 **TKET SDK**를 통해 생명정보학 최적화 기능을 제공함.
    - Oxford와 공동 개발하는 **QML 기반 변이 예측 알고리즘**을 바로 H2에서 실행 가능.
    - 예: GWAS(Genome-Wide Association Studies)에서 **수십억 개 변이의 상관관계 분석**을 양자적으로 가속화.

**💡 산업적 이유 — 제약·유전체 분야의 파트너십 네트워크**

- - Sanger Institute 입장에서는 **Quantinuum을 선택하는 것이 산업 생태계 확장에도 유리**.
  - **Quantinuum의 바이오 파트너십**

    - **Merck, AstraZeneca, Roche** 등과 이미 QML 기반 신약개발 공동 연구 진행 중
    - **Cambridge Quantum** 시절부터 화학·생명과학용 양자 알고리즘(QNLP, qChem)에 집중해 왔음
    - Sanger가 바로 Cambridge 인근이라 **기술·데이터 협력에 지리적 이점**도 있음
  - **Q4Bio 챌린지 전략**

    - Wellcome Leap의 Q4Bio 프로그램 자체가 **영국 중심 컨소시엄**임.
    - Cambridge, Oxford, Sanger, Quantinuum 모두 **케임브리지 클러스터**에 기반 → 의사결정 속도↑, 협업 비용↓.

**💡결론**

- - Sanger Institute가 Quantinuum을 선택한 이유는 단순한 하드웨어 우위 때문이 아니다.
  - **Q4Bio 프로젝트에 필요한 조건**을 Quantinuum만 충족하기 때문이다:

    1. **56큐비트 QCCD H2** → 게놈 시뮬레이션에 충분한 연산 능력
    2. **QEC 실험 검증 완료** → 긴 체인 모델링에서 오류 누적 최소화
    3. **Cambridge 중심 바이오-양자 연구 생태계** → Sanger, Oxford, Cambridge, Quantinuum 지리적 연계
    4. **QML-유전체학 통합 경험** → TKET + 생명정보학 최적화 지원
