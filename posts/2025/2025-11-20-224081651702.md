**📌 전체 비교 테이블**

|  |  |  |
| --- | --- | --- |
| **항목** | **Space-based AMTI (Golden Dome)** | **Air-based AMTI (E-7 Wedgetail)** |
| **센서 방식** | IR + Radar Doppler + On-orbit processing | AESA Radar(MESA) + EO/IR + ESM |
| **탐지 환경** | Top-down, global / strategic | Regional / tactical, look-down |
| **Stealth 탐지** | Strong (IR plume + heat signature) | Limited (저 RCS 표적 취약) |
| **극초음속 추적** | Strong (boost-phase IR & midcourse custody) | Weak/limited |
| **Clutter 환경** | Low clutter (space background) | High clutter (sea/urban/mountain) |
| **kill chain 역할** | Track + classify + transport to shooter | Track + BMC2 + command handoff |
| **통신** | OCT/OISL/Laser mesh + Ka + Link-16 relay | Link-16, TTNT, SATCOM direct |
| **지휘 통제** | Strategic node / cloud fusion | Tactical node / onboard fusion |
| **생존성** | ASAT/Cyber risk / resilient due to scale | SAM/AAM high vulnerability |
| **재방문 시간** | Constellation size dependent (persistent) | Continuous within orbit pattern |
| **물리적 한계** | Look-up geometry poor for low-altitude | Look-down strong for low altitude |
| **최적 표적** | hypersonic, cruise, aircraft packages | drones, stealth fighters, UAV swarm |
| **확장성** | Factory scaling, hundreds-thousands | Fleet limited by airframes |

**⚙️ 기술 요소별 상세 비교**

**1. 센서 기술**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| IR/OPIR/MWIR/LWIR multi-spectral, passive | AESA AMTI Radar(MESA), active/active-passive fusion |
| 극초음속 발사 초기 열신호 감지 강점 | look-down Doppler로 저고도·드론·순항미사일 강점 |
| Re-entry / plume long-range | Sea-clutter / terrain masking 해결 |

**2. 신호처리 및 AI**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| orbit-based multi-angle fusion + space cloud processing | onboard real-time fusion + fast decision |
| clutter 적음 → tracking 단순 | clutter 매우 큼 → AI 필수 |
| passive signature classification 중심 | velocity vector / Doppler-shift 기반 motion detection |

**3. 통신·네트워크(Kill Chain Integration)**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| OCT/OISL optical mesh / SATCOM 중계 / high latency risk | TTNT / Link-16 HPA / JWICS / direct shooter uplink |
| JADC2 strategic layer | JADC2 tactical layer |
| data aggregator 역할 | fire control hand-off |

**4. 생존성**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| ASAT / cyber / space EW 위협 | SAM(S-400, HQ-9B), AAM(PL-15), EW 위협 |
| 분산·복수위성으로 resilient | 고가 단일 플랫폼 → vulnerable |

**5. 표적 유형 최적화**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| Hypersonic glide, IR signature missiles, boost phase detection | stealth aircraft, UAV swarm, cruise missile look-down |
| global ballistic context | tactical air dominance context |

**🧠 결론 Summary**

|  |  |
| --- | --- |
| **Space-based AMTI** | **Air-based AMTI** |
| **전략적(Global) 감시 + 극초음속·열 기반 추적** | **전술적(Regional) AMTI + 지휘통제 + fire control handoff** |
| 센싱 중심 | 센싱 + 지휘 + 네트워크 허브 |
| Satellite constellation | AEW&C aircraft fleet |
| Passive thermal tracking | Active radar Doppler tracking |
| Hypersonic strong | Drone/swarm strong |

**🔥 최종 Insight**

> **Space-based AMTI는 위성을 이용해 글로벌 장기 감시 전략을 제공하며**,
>
> **Air-based AMTI(E-7)는 전술작전에서 빠른 Kill chain 연결과 실시간 전장 지휘를 담당한다.**

- - 🛰 **우주는 탐지/추적 중심**
  - ✈️ **항공기는 지휘통제/교전(fire control) 중심**

**Space Development Agency( SDA)의 Proliferated Warfighter Space Architecture(PWSA)와 위성 기반 이동표적탐지(AMTI 등) 센서체계의 관계**

- - PWSA의 Tracking Layer 은 “탐지·추적·식별(Indications, Warning, Tracking, Identification)” 기능을 위해 적외선(IR) 센서 페이로드를 탑재한 위성들로 구성되어 있다.
  - 또한 이 Tracking Layer 위성들은 **광학 통신 터미널(OCT, Optical Communication Terminals)** 을 통해 **다른 위성, 지상단, 플랫폼** 간에 데이터를 송수신할 수 있도록 설계돼 있으며 “in-plane connectivity”나 “optical inter-satellite links” 등이 포함되어 있다는 언급이 있다.
  - 한편, PWSA의 Transport Layer 는 “다수의 위성 메시 네트워크 + 고속 데이터 링크(광학/Ka-/RF) + 센서→슈터(sensor-to-shooter) 연결”을 주요 임무로 삼고 있다.
  - 즉, **Tracking Layer 위성**이 탐지/추적 센서 기능과 동시에 데이터를 다른 플랫폼이나 위성으로 전달할 수 있는 통신 기능을 어느 정도 갖고 있고, **Transport Layer 위성**은 데이터 전송망(network) 역할에 특화되어 있지만 결국 동일한 데이터 흐름(센서-산출 → 통신망 → 사용자) 안에 위치해 있다.
  - 반면, AMTI 위성체계는 **탐지(sensing)** 기능이 중심이며, 센서(EO/IR, 레이더 등)를 통해 이동표적을 탐지하고 이를 정제된 데이터로 만들어 작전 플랫폼에 제공하는 것이 목적이다.
  - 지난 포스팅에도 언급했던 내용인데, SDA에서 정의하는 여러 Layer중에, AMTI는 Custody Layer에 속한다고 생각하면 이해가 쉬워진다.

**🛰️ SDA Tracking Layer(T2) 와 AMTI 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **SDA T2 Tracking Layer** | **AMTI (Air Moving Target Indicator)** |
| **주요 탐지 대상** | 탄도·극초음속 미사일, HGV 등 빠르고 고기동 위협 | 항공기, 순항미사일, 저고도 침투 플랫폼 등 공중 이동 표적 |
| **센서 방식** | **IR(적외선) 기반 MW/MT 센서** + WFOV/MFOV | **레이더 기반 Doppler / MTI 알고리즘** |
| **목적** | 미사일 발사–부스트–글라이드–재진입 단계 추적 | 공중 표적 지속적 추적 및 항공 전장 인식 |
| **배치 궤도** | LEO 대규모 증식형 군집(저지연·고해상) | 현재 시제 단계, 향후 LEO 위성탑재 가능 |
| **전투 연계** | 요격/사격통제 품질의 추적 데이터 제공 | 항공 교전, 조기 경보, 전장 공중 상황관리 |

|  |  |  |
| --- | --- | --- |
| **요인** | **미사일 추적** | **AMTI** |
| **속도 영역** | Mach 5~10+ 초고속 | Mach 0.7~3 수준 |
| **센싱 난이도** | 발사열·플라즈마 신호 기반 추적 | 지상/바다/구름 clutter 제거가 핵심 |
| **Revisit/Dwell 필요** | 단기간 고속 이동 구간 파악 | 동일 지역 장시간 감시 요구 |
| **데이터 지연 허용도** | 극저지연 <초단위> | 상대적으로 높음 |

**통합 가능성 (Absorption 가능성)**

- - 둘 다 **LEO 군집 + 레이저 광링크 OCT + Transport Layer** 기반의 데이터 공유 아키텍처 사용
  - **PWSA/NDSA 내에서 배틀매니지먼트(BM), Transport Layer를 공유**
  - **위성 간 인터링크 + 지상 C2 통합 + 빠른 데이터 처리**가 공통 요구조건
  - **차세대 SDA Custody Layer**에서 AMTI와 Tracking Layer가 연동될 가능성이 높음

> **Space-based AMTI + SDA Tracking Layer는 필수적인 역할 분담 구조다.**
>
> AMTI는 persistent custody & global surveillance
>
> Tracking Layer는 hypersonic fire-control & hard-kill engagement
>
> **둘이 섞이면 완벽한 방어 체계 (Kill-chain seconds 단축)**

**🛰 Custody Layer가 의미하는 것**

- - SDA가 말하는 **Custody Layer = Moving target custody layer**
  - **Ground, maritime, and airborne moving target persistence**

|  |  |
| --- | --- |
| **Custody Layer 범위** | **포함 대상** |
| Ground moving targets | 지상 기동전 / 대포병 / MLRS / armor |
| Maritime moving targets | 함정 / 수상 전력 / 해상 logistics |
| Airborne moving targets (AMTI) | Aircraft / UAV / Cruise missile / Bomber formations |
| Intelligence custody | Behavior pattern / ID / classification history |

- - 따라서 **AMTI = Custody Layer 중 ‘Airborne’ 서브 Capability**이다.

**🎯 한 줄 요약**

- - PWSA는 Tracking + Custody + Transport + Navigation이 합쳐져 완성되는 Kill-web 구조이다.

    - Tracking은 요격을 위한 정밀 추적(engage-quality tracking)
    - **비유 : 경찰 추적 헬기**
  - AMTI는 Custody Layer의 구성 capability

    - Custody는 탐지(detection) 위주로서, Hypersonic 탐지 기능이 있지만, fire-control은 없다.
    - **비유 : CCTV**
  - Navigation Layer는 GPS 대체/보완 PNT 레이어

    - Hypersonic 추적 및 요격을 위해서는 시간과 위치가 매우 정밀해야함.
    - GPS jam/spoof 극복할 수 있어야 하기 때문에 양자 센싱이 필요함.
    - **비유 : 경찰 추적 헬기, CCTV와 스나이퍼의 시계가 동일하게 세팅됨**
