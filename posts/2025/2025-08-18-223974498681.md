**✅****현재 문제 상황**

- - **스핀 → 광자 변환**: (편광 / 주파수 / 시간-bin 중 하나로 인코딩)
  - **두 광자 → 빔스플리터에서 간섭** (HOM 간섭)
  - 동시 검출(코인시던스)이 Herald 신호 역할 → 이때 두 스핀(이온 등)이 얽힘 상태로 전이됨
  - 하지만 실제 성공 확률은 극히 낮음 (10-5 ~ 10-3 수준).
  - 이유는:

    1. 광자 방출 확률 < 1
    2. 광자 손실 (결합·전송·검출 효율)
    3. HOM 간섭 불완전성 (광자 불일치, 잡음 등)

**✅****논문이 제안하는 방향**

이 논문은 단순히 “세 가지 내부 자유도 방식(편광, 주파수, 시간-bin)”을 나열하는 게 아니라,

👉 **얽힘 성공 확률을 끌어올리기 위한 설계 트레이드오프**를 분석한다.

대표적으로:

- - **타입 1 / 타입 2 연결 모델**:

    - Type I: 한 광자 검출만으로 얽힘 → 효율적이지만 fidelity 낮음
    - Type II: 두 광자 동시 검출 → fidelity 높지만 성공률 낮음
  - **DIT vs CPF 게이트**:

    - **Purcell 효과를 활용한 강결합 수신기 기반 광학 캐비티 기술 이용**
    - DIT는 단순 얽힘 생성, 성공률 낮음
    - CPF는 성공 시 바로 게이트 효과, 하지만 실험 복잡

즉, “Herald 얽힘 확률이 낮은 상황에서 어떤 방식(내부 DoF 선택, 외부 모드 이용, 다중 시도 전략 등)이 확률-충실도 트레이드오프를 최적화하는가?”를 다룬 것

---

**✅****스핀-광자 얽힘 방법**

**💡****Type II (두 광자 검출)**

- - 두 QPU(예: 이온 트랩, NV 센터 등)에서 **각각 1개의 광자**를 방출
  - 두 광자가 **중간의 50:50 빔스플리터**에서 만나 HOM 간섭을 함
  - 두 출력 포트에 달린 **두 개의 검출기에서 ‘****동시에****’ 클릭**이 일어나면

    - → 두 QPU의 스핀이 얽혔다는 **Herald 신호**
  - 특징:

    - **충실도(Fidelity)** 높음 (검출 결과가 양자 얽힘을 확정적으로 보장)
    - ❌ 단점: 성공 확률 극히 낮음 (두 광자가 모두 살아서 도착 + 검출되어야 함 → η2 수준으로 떨어짐)
  - 운좋으면 성공

**💡****DIT (Dipole-Induced Transparency) - Type II의 확장판 (캐비티 이용 내부 자유도 선택가능)**

- - 기본 원리:

    - 두 QPU에서 각각 광자 하나씩 방출 → 빔스플리터에서 간섭 → 검출기에서 동시 검출(HOM 이벤트) 발생 시, 두 스핀 얽힘이 ‘성공적으로 생성되었다’고 판정.
  - 여기서 광자의 내부 자유도는 주로 **편광, 주파수, 시간-bin 중 하나**로 스핀과 얽힘을 맺음.

    - 예: 이온 |↑⟩ → 편광 |H⟩, |↓⟩ → 편광 |V⟩
    - 또는 주파수/시간-bin으로 치환 가능
  - 즉, **DIT는 특정 자유도에 국한되지 않고, 주로 ‘광자 간 간섭(HOM interference)이 잘 되는 DoF’를 선택**함.

    - 실제 구현에서는 **편광+시간-bin**을 가장 많이 씀.
  - 운좋으면 성공

**💡****CPF (Controlled-Phase Flip Gate via Photons)**

- - 기본 원리:

    - 두 개의 스핀(예: 이온) 사이에 광자를 매개로 하는 **비국소적 제어 위상 게이트** 수행.
  - 방식:

    - 스핀 상태에 따라 방출되는 광자가 다른 **위상**이나 **경로 차이**를 가지게 만들어서, 최종 간섭 후 위상 플립을 구현.
  - 여기서 핵심은 광자의 **경로(path)·위상(phase) 자유도**를 이용하는 것.

    - 편광 기반으로도 가능하지만, 실제로는 공간 모드(외부 모드 기반)나 **위상 지연**을 더 자주 씀.
  - 특징

    - 작은 불일치도 충실도를 크게 떨어뜨림.
    - 빔스플리터, HOM 진단이 필요 없음
    - 벨상태 측정 정보 교환 필요 없음
  - 거의 매번 성공
  - **강결합 체제 (SCR- Strong Coupling Regime)**

    - 두 원자는 서로 다른 역할을 가지며, 광자는 한 방향으로만 흐른다.
    - 즉:
    - 송신 캐비(emitter)는 얽힌 이온–광자 상태를 생성한다.

      - 이온을 특정 상태에 두고, 캐비티를 통해 광자를 방출시킴.
      - Purcell 효과로 **방출 모드가 거의 전부 캐비티 모드로 수집** → 효율 ↑
    - 수신 캐비티(receiver)는 광자를 받아들여 광자 ↔ 이온 상호작용으로 위상 변화

      - 송신측에서 온 광자가 수신 캐비티에 들어감.
      - 수신 이온이 |1⟩ 상태일 때만 반사 위상 π 변환 (Controlled Phase).

        - **|↑⟩ 상태**: 광자가 캐비티와 공진 → 반사되면서 **π 위상 shift**.
        - **|↓⟩ 상태**: 캐비티와 상호작용 안 함 → 그냥 투과 or 다른 위상 반사.
      - 즉, 수신측 이온과 송신측 광자가 **게이트 연산**을 수행하는 것.
    - 즉, 캐비티는 **스핀 상태를 위상 정보로, 위상 정보를 스핀 상태로 바꿔주는 장치**가 됨.
    - 벨 측정 결과를 별도의 고전채널을 통해 주고 받을 필요가 없음

**💡****캐비티 설계 (Constructions)**

- - **Emission cavity (방출 캐비티)**

    - 목표: 광자가 잘 빠져나가도록(out-coupling) 설계.
    - 장점: 기본적으로 성공 확률을 높일 수 있음.
    - 한계: 광자 스펙트럼이 너무 넓거나(너무 다양한 색), 거울 손실이 크면 fidelity가 낮아짐.
  - **Transmission cavity (DIT, 투과 캐비티)**

    - 목표: 광자를 반대편 거울을 통해 내보내는 방식.
    - 장점: fidelity를 기준으로 최적화할 수 있음.
    - 한계: 손실이 크면 성공률이 급격히 떨어짐.
  - **Reflection cavity (CPF, 반사 캐비티)**

    - 목표: 광자가 캐비티에서 반사되면서 얽힘을 만드는 방식.
    - 장점: 이론적으로 가장 효율적(낮은 손실에서).
    - 한계: 거울 손실에 매우 민감 → 고성능 거울이 꼭 필요.
    - **Cavity QED** (Cavity Quantum Electrodynamics) 수준의 캐비티가 필요

      - 초고 Q-factor (품질인자 ↑)
      - 작은 모드 부피 (모드 볼륨 ↓)
      - 이온 또는 인공 원자와 **정확히 공간·주파수 정합**
      - 단일광자 Purcell 효과를 극대화
  - 단일광자 캐비티 개발현황

    - 단일광자 캐비티는 방출체(이온, 원자, 양자점, NV/SiV 등)와 **캐비티 모드**가 완벽히 일치해야 Purcell 효과로 광자 방출 효율이 올라감.
    - 다양한 방식의 난립 상황이라 양산을 할 수 있는 산업 표준이 없는 상황

      - 미국 국립표준기술연구소(NIST)는 표면 전극 트랩 내에 **섬유 기반 Fabry–Pérot 캐비티**를 통합하여 높은 충실도 원격 얽힘을 달성하는 연구를 수행 중.
      - 영국 NQCC의 **INTERCOM 프로젝트** 역시 **고성능 ion-photon 인터페이스용 캐비티**를 개발하는 데 집중.
      - 옥스퍼드 대학교와 MICRON 프로젝트는 **좁은 광학 캐비티를 이용해 trapped ion 네트워크 대역폭을 확장**하려는 연구

**💡****Lightsynq 방식**

- - **Type-II 프로토콜**과 가장 유사 (두-광자 간섭 방식).
  - 다만 Lightsynq는 이걸 **실제 장거리(수 m ~ 수 km) 광섬유 전송**에서 최적화.
  - 캐비티를 꼭 쓰지 않아도 되며, 대신 **고성능 집광 광학계(렌즈·섬유 결합)와 SNSPD(초전도 나노와이어 광자 검출기)** 를 사용.
  - **멀티모드 병렬화 전략**

    - 단일 인터페이스의 효율을 극적으로 높이려 하기보다는,
    - 여러 개의 time-bin / wavelength / spatial 모드 병렬 채널을 동시에 쏘아 → **성공률을 확률적 합으로 키움**.
    - (즉, 한 번의 시도에서 성공 확률이 낮더라도 100채널 동시에 시도 → 평균 성공률 보장)
  - **광자 변환 (QFC, Quantum Frequency Conversion)**

    - 이온/고체계에서 나온 493nm·737nm·946nm 같은 “짧은 파장”을 통신 최적 파장(1550nm)으로 변환해서 장거리 손실을 최소화.
  - **양자 리피터**

    - **Quantum memory를 이용하여 동시성 문제 극복**
  - **분산 네트워크 최적화**

    - 단일 실험실 안에서 high-fidelity를 추구하기보단,
    - **실제 QKD/네트워크 환경에 적합**하게 설계.
  - IonQ(구 Lightsynq)는 여기에 **광자 파장 변환(1550nm telecom band)** 기술까지 통합해 기존 통신 인프라와 연결하려고 함.

**💡****요약**

- - **Type-II**

    - 가장 기본적이고 안정적인 방식.
    - 성공률 낮지만 검증 많이 됨.
  - **DIT**

    - 캐비티가 손실 있는 상황에서 더 나음.
    - 하지만 실험 난이도 높음.
  - **CPF**

    - **이론적으로는 최고의 성능.**
    - 하지만 초고성능 캐비티와 완벽한 모드 정합이 필요 → **아직 비현실적.**
  - **Lightsynq**

    - 사실상 **Type-II의 실용화 버전**.
    - 캐비티 대신 **렌즈 + 광섬유 + SNSPD + 파장 변환(1550nm)** 같은 현실적 기술로 최적화.
    - 지금 시점에서는 **가장 구현 가능하고 실제로 장거리에서 입증된 방식**.
    - 양자 메모리를 통한 "동시성"문제 제거→ 사실상 **CPF의 장점**을 일부 가져옴.

      - **CPF는 같은 캐비티 내부 상호작용인 반면,**
      - **라이트싱크는 멀리 떨어진 노드 간 연결을 네트워크적으로 가능하게 함**.

**✅****정리 표**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **구분** | **Type-II (기본)** | **DIT (논문)** | **CPF (논문)** | **Lightsynq (IonQ)** |
| **원리** | 두 원격 이온이 각각 광자를 방출 → 빔스플리터 간섭 → 동시 검출(coincidence) | 수신 캐비티에서 광자 통과/차단 여부로 qubit 상태 판별 → 얽힘 형성 | 광자가 두 캐비티를 순차적으로 통과 → qubit 상태에 따라 위상 변화 획득 (Controlled Phase Flip) | 두 이온 광자 → 광섬유 → 빔스플리터 간섭(HOM 효과) → 동시 검출 |
| **캐비티 의존성** | 선택적 (collection 효율 ↑ 위해 쓰기도 함, 필수는 아님) | **필수** (수신 강결합 캐비티 필요) | **필수** (초고Q cavity, 양쪽 strong coupling, mode matching 요구) | 없음 (자유공간 수집 + 섬유 결합 + SNSPD) |
| **장점** | 구현 단순, 오래 검증됨 | 충실도 ↑ (loss에 강함) | 이론적으로 성공률·충실도 최고  BSM 교환 필요 없음 | 장거리 실험 검증됨, 현실적 구현 가능, 기존 통신 인프라와 호환 |
| **단점** | 성공률 낮음 (loss 민감) | 캐비티 제작·정렬 어려움 | 기술 난이도 극도로 높음 (bandwidth/정합 문제) | 성공률 낮음(본질적으로 Type-II), 동기화/검출기 요구 |
| **충실도(Fidelity)** | 중간 (loss 있어도 유지 가능) | 높음 | 매우 높음 (이론 최적) | 중간 (Type-II 수준) |
| **성공률(Success Probability)** | 낮음 | 개선됨 | 가장 높음 | 낮음 (검출기·수집률 보완) |
| **현실성** | 이미 다수 실험 검증 | 연구적, 제한적 실험 단계 | 아직 비현실적 (연구 단계) | 가장 현실적, Lightsynq가 실제 구현 |

CPF 방식을 적용하면 확률적(probabilistic) 얽힘 생성이 아닌 **결정론적(deterministic) 얽힘 생성**이 가능하다.

송신측에서 발생한 광자-이온 얽힘을 수신측 이온과 직접적으로 결합시킬 수 있어, **BSM(벨 상태 측정) 결과를 교환하기 위한 추가 고전 채널이 필요하지 않은 장점**이 있다.

그러나 이는 아직 이론적 단계에 가까운 기술로, 상용화까지는 시간이 필요하다. 따라서 현재로서는 **HOM(Hong–Ou–Mandel) 간섭 기반 방식을 사용**하되, 양자 메모리를 도입하여 **"동시성" 문제를 보완한** Lightsynq의 방식이 가장 현실적이고 효율적인 접근법이다.
