**💡****간단한 정의**

- - **명제:**

    - If XXXX∣ϕ⟩=∣ϕ⟩ the following circuit measures the parity of the number of Z errors on ∣ϕ⟩.

      - 현재(오류가 있을 수도 없을 수 있는) 데이터 상태(∣ϕ⟩)의 네개 큐비트에 동시에 X게이트를 적용했을 때, 원래 상태(∣ϕ⟩)가 된다는 것은 부호가 바뀌지 않는 +1 고유상태(안정자에 의해 "안정")임을 뜻한다.
      - 이 조건을 만족하는 상태로 회로를 돌려보면 해당 네개 큐비트 중에 Z 오류가 몇 개 생겼는지를 짝수/홀수(패리티)로 알 수 있다는 뜻이다.
      - **왜 Z 오류 개수의 패리티가 나오나?**

        - 핵심은 파울리 행렬의 반가환 성질: ZX=−XZ
        - 만약 네 개 중 **짝수 개** 큐비트에서 Z 오류가 생겼다면, XXXX와 가환해서 부호가 그대로야.
        - 만약 **홀수 개**라면, XXXX와 반가환하면서 부호가 뒤집혀 −1이 나오는 원리

          - (-1)#{incident Z}
  - **해석**:

    - 부호공간 Q는 **안정자(Stabilizer)** 집합 SX∪SZ에 의해 정의된다.
    - 즉, 어떤 상태 ∣ψ⟩가 코드공간에 속하려면, 모든 안정자 P에 대해 P∣ψ⟩=∣ψ⟩를 만족해야 한다.

      - Q : **코드 공간**(논리 상태들이 사는 부분공간).
      - ∣ψ⟩ : 그 안의 임의의 상태.
      - SX : X-형 안정자들의 집합(여러 큐비트에 X를 곱한 연산자들).
      - SZ : Z-형 안정자들의 집합(여러 큐비트에 Z를 곱한 연산자들).
      - P∈SX∪SZ : P가 두 집합 중 **어느 쪽이든**에 속함.
      - P∣ψ⟩=∣ψ⟩ : ∣ψ⟩가 **모든 안정자에 대해 +1 고유상태**임(= 그 안정자들을 “만족”함).
  - 여기서:

    - SX: X 타입 안정자 집합 (비트 플립 오류 검출용)
    - SZ: Z 타입 안정자 집합 (위상 플립 오류 검출용)

**💡****핵심 요약**

- - XXXX∣ϕ⟩=∣ϕ⟩ 는 "오류 없으면 그 네자리 X - 안정자 측정값이 +1"이란 뜻.
  - 그 안정자를 안실라 회로로 측정하면, 그 네 자리에서 발생한 Z-오류의 개수의 홀짝(패리티)가 결과로 나온다.

    - 안정자 연산은 수학 연산으 결과로서 값은 +1 또는 -1 이 나오게 된다.

      - ∣00⟩,∣11⟩ → 고유값 +1.
      - ∣01⟩,∣10⟩ → 고유값 −1.
    - 큐비트에서는 이 값을 각각 0과 1로 다시 매핑하여 QEC에서 신드롬으로 사용됨.

      - +1↦0 (에러 없음)
      - −1↦1 (에러 감지)
  - **코드 공간 Q = 모든 안정자( S****X****와 S****Z** **)가 상태를 그대로 두는(+1) 상태들의 집합**이다.

**💡****CSS 코드로 확장된 정의**

- - **해석**

    - **S****X**:{I,X}n에서 선택된 X-타입 안정자 (I,X만 포함된 연산자들)
    - **S****Z**:{I,Z}n에서 선택된 Z-타입 안정자 (I,Z만 포함된 연산자들)
    - **조건**: SX와 SZ의 연산자들이 **짝수 개(overlap even**)로 겹쳐야 한다.

      - → 그래야 서로 가환(Commuting)하고 동시에 측정 가능.
    - Q ≔{|ψ⟩ | P|ψ⟩=|ψ⟩ for all P ∈ SX ∪SZ}

      - 즉, 모든 안정자에 대해 +1 고유값을 갖는 상태들의 집합.
    - 이 조건이 만족되면, CSS 코드(Calderbank–Steane–Shor code)가 된다.

> I 게이트 : 동일값 출력 게이트
>
> X 게이트 : 비트 플립 게이트
>
> Z 게이트 : 위상 플립 게이트

**💡예시**

- - SX={XIXIXIX,IXXIXX,IIIXXXX}

    - 여기서 각 연산자는 7큐빗에 대한 X/I의 조합
    - 즉, X-타입 안정자.
  - SZ={ZIZIZIZ,IZZIIZZ,IIIZZZZ}

    - 마찬가지로 Z-타입 안정자.
  - → 이 집합들이 정의하는 코드가 바로 **Steane code**와 같은 CSS 코드다.

**💡연습문제**

- - "Check the even overlap":
  - SX와 SZ의 연산자들을 곱했을 때, 겹치는 위치에 X와 Z가 동시에 나타나면 **Y**가 되는데, 그 개수가 짝수여야 한다.
  - 짝수 개 → 안정자 보존 (commute-가환)
  - 홀수 개 → 불가능 (anticommute-반가환 → 안정자 코드 정의 불가)
