**✅우리는 왜 지금 히든 피겨스를 다시 떠올리는가**

- - Hidden Figures는 흔히

    - 인종·젠더 서사
    - NASA의 인간 드라마
  - 로 기억되지만, 기술적으로 보면 전혀 다른 영화다.

> ***히든 피겨스는 ‘우주 영화’가 아니라***
>
> ***‘계산 체계가 국가 전략으로 편입되는 순간’을 다룬 영화다.***

- - 이 관점에서 보면, 오늘날 우리가 마주한 **양자컴퓨터, 골든돔, 우주 데이터센터**는
  - 모두 히든 피겨스의 **직계 후손**이다.

**1️⃣ 보이지 않는 승부처: 계산실**

- - 영화에서 실제로 승부가 갈리는 곳은 우주가 아니라:

    - NASA 지하 계산실
    - IBM 메인프레임 앞
    - 인간 계산자와 기계의 경계
  - 여기서 중요한 포인트는 하나다.

    - “정확성”이 아니라 “시간 내 계산”
  - 궤도는 미리 정해져 있지 않음
  - 재진입 각도는 실시간으로 바뀜
  - 계산이 늦으면 → 영웅은 죽음

**2️⃣ IBM 7090 ↔ Quantum Computer**

|  |  |
| --- | --- |
| **1960년대** | **오늘날** |
| IBM 7090 | 양자컴퓨터 |
| 극소수 접근 | 극소수 접근 |
| 국방·우주 우선 | 국방·정보 우선 |
| 인간 계산 대체 | 고전 컴퓨팅 한계 보완 |

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTEyMjNfMTY1/MDAxNzY2NDYyNzE3OTM1.YhxtYZFQLIoE1u7lK2swf3wIyGEpBI9dFt62mP8tjBog.qOjqELmhN54VWthitGoY_qEKT8e8lGBye28kbPC8p5gg.PNG/image.png?type=w800)](#)

출처 : 위키피디아, IBM 7090

- - IBM7090 (위키피디아 참조)

    - 대규모 과학 및 기술 애플리케이션"을 위해 설계된 이전 IBM 709 진공관 메인프레임 컴퓨터의 2세대 트랜지스터 버전
    - 첫 설치는 1959년 12월
    - 1960년에 일반적인 시스템은 290만 달러(**2023년 기 2,300만 달러에 해당**)에 판매되었거나
    - 월 63,500달러(**2023년 기준 501,000달러에 해당**)에 임대할 수 있었다.

      - 스펙

        - 클럭 속도 : 대략 0.5MHz
        - 단어 길이 : 36 비트
        - 메모리 용량 : 약 144KB
        - 입력 방식 : 펀치 카드 (80열)
        - 주요 언어 : FORTRAN
        - 산술 : 고정 소수점 + 부동소수점
      - 오늘날 기준으로는 느리지만, **인간 계산 대비 수백~수천 배** 빠름
  - 양자컴퓨터의 현재 역할은 명확하다.

    - 암호 체계 검증
    - 최적 요격 문제
    - 센서 융합 계산
    - 미래 시뮬레이션
  - 👉 **민간 AI보다 먼저 국방으로 간다**
  - 👉 이 흐름은 IBM과 정확히 동일하다.

**3️⃣ 골든돔은 ‘현대판 NASA 재진입 계산’이다**

- - Golden Dome의 본질은 단순 방어망이 아니다.

> ***우주 기반 센서 +***
>
> ***실시간 연산 +***
>
> ***수 초 내 국가적 판단***

- - 히든 피겨스와의 대응은 놀랍도록 정확하다.

|  |  |
| --- | --- |
| **히든 피겨스** | **골든돔** |
| 캡슐 재진입 | 극초음속 미사일 |
| 실시간 궤도 계산 | 실시간 요격 판단 |
| 계산 실패 = 사망 | 계산 실패 = 국가 타격 |
| IBM 도입 | AI·HPC·양자 도입 |

- - 👉 **우주에 있는 것은 물체지만 전쟁은 계산으로 결정된다**

****

**4️⃣ 계산실이 지상에서 궤도로 올라간 이유**

- - 히든 피겨스의 계산실 특징:

    - 고전력
    - 고발열
    - 고보안
    - 중앙집중
  - 이 조건은 **우주 데이터센터**에서도 그대로 반복된다.

|  |  |
| --- | --- |
| **NASA 계산실** | **우주 데이터센터** |
| 지상 | 궤도 |
| 공랭 | 진공 복사 |
| 유선 연결 | 위성 링크 |
| 인간 접근 | 완전 무인 |

- - 👉 골든돔이 **전쟁의 뇌**라면
  - 👉 우주 데이터센터는 **기억과 사고를 담당하는 피질**이다.

---

**✅계산 권력은 항상 보이지 않는 곳으로 이동한다**

> ***1960년대: 인간 → 메인프레임***
>
> ***2020년대: 메인프레임 → AI + 양자***

- - 히든 피겨스는 과거 이야기처럼 보이지만,
  - 사실은 **지금 벌어지고 있는 미래의 예고편**이다.

> 모든 계산을 사람이 하고, 그나마 최신 컴퓨터라고 도입된 것이 위에 보이는 IBM7090을 이용하여 우주로 로켓을 쏘아 올렸다니, 도저히 믿기지 않는다.
>
> 
>
> 지금으로부터 50년후에도 누군가는 나와 비슷한 생각을 하게 될 것 같다. 35 큐비트 양자컴퓨터로 분자를 계산했다고? QKD를 처음 성공시켰다고?
>
> 저런 기술로 우주에 데이터센터를 만들 생각을 했다고?
>
> 
>
> 인간의 상상력은 참으로 하찮다는 것을 느끼는 하루다.
>
> 그것이 미래에 대한 것이든, 과거에 대한 것이든.
