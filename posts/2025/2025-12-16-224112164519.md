# NVIDIA의 치밀한 전략 (1) - NVLink Fusion이 왜 필요해졌나?

Published: 2025-12-16T21:20:27.663000+09:00

**✅왜 NVLink와 CXL이 등장하게 되었나?**

**📌PCIe vs NVLink 세대별 비교 표**

**1️⃣ NVLink의 탄생 배경**

- - PCIe 1.0 → 2.0 → 3.0은 GPU 연산 가속이 “본격화되기 전”의 CPU 중심 시대 산물이다.
  - AI 시대의 인터커넥트 주도권은 PCIe/CXL이 아니라 NVLink가 쥐고 있다

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **연도** | **상용화 기술** | **성격** | **대표 제품** | **의미** |
| 2019 | PCIe 4.0 | 범용 I/O | NVIDIA A100  (PCIe 버전) | CPU–GPU I/O 대역폭 첫 큰 점프 |
| 2020 | NVLink + NVSwitch | AI 학습 패브릭 | DGX A100 | “GPU 클러스터 = 패브릭” 성립  PCIe는 보조 경로로 밀림 |
| 2021 | PCIe 5.0 | 고속 I/O | NVIDIA H100 (PCIe 버전)  Intel Sapphire Rapids | I/O는 빨라졌지만  GPU-GPU 통신 문제는 해결 못함 |
| 2022 | CXL 1.x | CPU 중심 coherency | Intel Sapphire Rapids | CPU 중심 확장 |
| 2023 | CXL 2.0 | 메모리 풀링 | 메모리 익스팬더 | latency-sensitive 워크로드에는 부적합 |
| 2024 | PCIe 6.0 | 대역폭 확장 | 차세대 서버 CPU | 대역폭 2배  PAM4 + FEC로 지연 증가 |
| 2024~25 | NVLink 5.0 / Fusion | AI 팩토리 패브릭 | GB200 / GB300 NVL72  NVLink Fusion (2025 발표) | CPU/ASIC/QPU까지 흡수  데이터센터 아키텍처 자체를 재정의 |

- - **PCIe는 원래 이런 용도였다**

    - 그래픽 카드
    - 스토리지
    - 네트워크 카드
    - 범용 I/O
    - 👉 **CPU ↔ 장치 통신용**
    - 👉 **가속기 ↔ 가속기 통신은 고려 대상 아님**
  - **GPU가 ‘연산 장치’로 변질(?)됨 (2010년대 초)**

    - CUDA (2007~)
    - 딥러닝 폭발 (2012~)
    - GPU 간 통신 요구 급증
    - 문제:

      - PCIe 3.0 x16 ≈ **32 GB/s**
      - GPU HBM 대역폭은 수백 GB/s
    - 👉 **I/O 대비 연산·메모리 격차 폭발**
  - **NVIDIA의 판단**

    - PCIe 로드맵을 기다리면 AI는 못 한다
    - 그래서:

      - **2014~2016**: NVLink 개발
      - **2016**: Pascal P100 + NVLink 1.0
    - 👉 **NVLink는 PCIe 대체가 아니라, PCIe가 못 하는 영역(GPU–GPU)을 찢어낸 것**

****

**2️⃣ 그럼 CXL은 왜 나왔나?**

- - **표면적 이유 (공식)**

    - 메모리 확장
    - CPU–디바이스 coherency
    - 서버 아키텍처 유연성
  - **실제 동기 (현실)**

    - **NVIDIA가 NVLink로 GPU 세계를 잠금**
    - CPU 벤더(Intel/AMD)는 GPU–GPU 패브릭을 못 만듦
    - 하이퍼스케일러는 NVIDIA 종속이 싫음
  - 👉 그래서 나온 결론:

    - GPU는 못 막아도, CPU 중심의 표준 패브릭은 우리가 만든다

**3️⃣ CXL 컨소시엄 구성**

- - Intel
  - AMD
  - Arm
  - IBM
  - Dell, HPE
  - Google, Meta, Microsoft
  - 👉 **NVIDIA는 주도 멤버 ❌**

> ***❌ CXL = NVLink 대항마***
>
> ***⭕ CXL = PCIe의 확장 + CPU 생태계 방어선***
>
> ***그래서, CXL은 NVLink를 못 이김. 애초에 같은 싸움을 하는 기술이 아님***

---

**✅NVLink Fusion이란?**

- - NVIDIA가 2025년 5월에 발표한 개념/전략으로,
  1. **NVLink Fusion은 NVLink를 개방형 생태계로 확장한 반맞춤형 AI 인프라 플랫폼이다.**

     - NVIDIA GPU뿐 아니라 타사의 커스텀 CPU·ASIC을 NVLink 패브릭에 통합할 수 있도록 한다.
  2. **MediaTek, Marvell, Alchip, Astera Labs, Synopsys, Cadence가 NVLink Fusion 생태계에 참여한다.**

     - 이들은 커스텀 AI 실리콘, 고속 인터커넥트, ASIC 설계·EDA·칩렛 인프라를 제공한다.
  3. **Fujitsu와 Qualcomm은 커스텀 CPU를 NVIDIA GPU와 직접 결합한다.**

     - NVLink 스케일업과 Spectrum-X 스케일아웃을 활용해 랙-스케일 AI 팩토리를 구축한다.
  4. **NVLink Fusion은 이기종 실리콘 데이터센터를 NVIDIA 랙 아키텍처로 표준화한다.**

     - 하이퍼스케일러는 어떤 ASIC이든 사용하면서도 NVIDIA의 랙-스케일 시스템을 채택할 수 있다.
  5. **5세대 NVLink는 GPU당 1.8TB/s 대역폭을 제공한다.**

     - 이는 PCIe Gen5 대비 약 14배 빠른 속도이며, GB200·GB300 NVL72 랙에서 구현된다.
  6. **네트워킹은 Ethernet과 InfiniBand를 모두 포함한다.**

     - ConnectX-8, Spectrum-X Ethernet, Quantum-X800 InfiniBand, 향후 CPO까지 포함하는 엔드투엔드 네트워크를 제공한다.
  7. **NVIDIA Mission Control이 AI 팩토리 운영을 담당한다.**

     - 배포, 검증, 오케스트레이션을 자동화해 대규모 AI 데이터센터 운영을 단순화한다.
  - 한 줄로 요약하면:

> ***NVLink Fusion은 NVIDIA가 AI 데이터센터의 ‘GPU 연결 기술’을 넘어, 이기종 실리콘까지 흡수하는 랙-스케일 AI 인프라 표준을 선언한 것이다.***

**1️⃣ 기존 NVLink와 뭐가 다른가?**

- - **기존 NVLink**

    - **NVIDIA GPU ↔ NVIDIA GPU** 전용
    - 주 용도: 멀티-GPU 메모리 일관성, 대역폭 확장
    - 폐쇄적 생태계 (NVIDIA 내부)
  - **NVLink Fusion**

    - **GPU + CPU + NPU + ASIC + QPU(?)** 까지 연결 대상 확대
    - **칩렛 간(on-package) + 보드 간 + 랙 간** 연결을 하나의 패브릭으로 통합
    - NVLink를 “가속기 중심 시스템 인터커넥트”로 재정의
  - 즉, PCIe / CXL 위에 있는 “AI-First 인터커넥트 계층”이다.

**2️⃣ 왜 “Fusion”이라는 이름인가?**

- - **Fusion의 의미**

    - **이기종 가속기의 융합**
    - **칩렛 + 패키지 + 시스템 + 데이터센터 패브릭의 융합**
    - **메모리·연산·네트워크의 경계 제거**
  - NVIDIA 관점에서는:

> ***“GPU를 중심으로 모든 계산 자원을 융합(Fuse)한다”***

**3️⃣ 핵심 구성 요소**

- - **NVLink-C2C (Chip-to-Chip)**

    - Grace ↔ Hopper에서 처음 등장
    - **칩렛/패키지 내부 수준의 초고속 연결**
    - 사실상 **SoC 내부 버스급**
    - → NVLink Fusion의 **물리적 기반**
  - **NVLink Switch**

    - 수십~수백 개 GPU를 **논블로킹 패브릭**으로 연결
    - GB200 / NVL72 같은 랙 스케일 설계의 핵심
    - → NVSwitch = **AI 전용 스파인 스위치**
  - **외부 가속기 연결 (가장 중요한 포인트)**

    - NVLink Fusion의 “야심”은 여기 있음:

      - NVIDIA GPU ↔ **외부 ASIC**
      - NVIDIA GPU ↔ **타사 가속기**
      - GPU ↔ **전용 AI ASIC / NPU / DPU**
      - (장기적으로) GPU ↔ **QPU**
    - 이때 중요한 개념:

      - **메모리 일관성(shared memory semantics)**
      - **Load/Store 기반 접근**
      - PCIe처럼 “장치”가 아니라 **동등한 연산 노드**

****

**4️⃣ CXL이 있는데 왜 NVLink Fusion이 필요한가?**

|  |  |  |
| --- | --- | --- |
| **항목** | **CXL** | **NVLink Fusion** |
| 설계 철학 | 범용 I/O 확장 | AI/HPC 전용 |
| 지연 | 상대적으로 큼 | 매우 낮음 |
| 대역폭 | PCIe 기반 한계 | 링크당 수백 GB/s |
| 일관성 | 있음 | 더 강한 일관성 |
| 대상 | CPU 중심 | **GPU 중심** |

> ***“AI 데이터플로우에는 CXL로는 부족하다”***

**5️⃣ 왜 지금 이게 중요해졌나?**

- - **배경 ① GPU 단독 시대 종료**

    - AI 모델 → **메모리·통신·전력 병목**
    - GPU 성능 ↑ → **인터커넥트가 병목**
  - **배경 ② 가속기의 폭발적 다양화**

    - AI 전용 ASIC
    - 추론 특화 NPU
    - 네트워크 가속기
    - 양자 가속기(QPU)
  - → **이걸 하나로 묶을 고속 패브릭 필요**
