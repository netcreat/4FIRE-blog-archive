**📌All-Electronic TIQC 아키텍처 개요**

**1. 배경 – 왜 이런 연구가 필요할까?**

- 지금까지 **트랩 이온 양자컴퓨터**는 큐비트를 **레이저 빛**으로 조종하는 게 일반적이었음.
- 문제는 큐비트가 많아질수록:

  - 레이저 빔을 정확히 맞추기가 어려워지고
  - 장치가 커지고 비싸지고
  - 성능이 떨어질 수 있다는 점
  - → 마치 교실에 있는 수백 명 학생에게 각각 손전등 빛을 맞추며 “같이 춤춰!” 하는 것과 같음

**2. 새 아이디어 – “전자 제어” 방식**

- 이 논문에서는 레이저 대신 칩 안에 전선(전류 경로)과 **전극**을 넣어서 큐비트를 움직이고 조종한다.
- **공유 드라이브**:

  - 하나의 큰 전선에 전류를 흘려 **모든 큐비트에 동시에** 자기장을 보낸다.
- **로컬 전극**:

  - 각 구역(존)의 큐비트를 살짝 움직여서 자기장을 세게 받거나, 거의 못 받게 조정한다.
  - → 마치 운동장 스피커에서 음악이 나오고, 학생이 스피커 가까이 가면 크게 듣고, 멀리 가면 작게 듣는 것과 비슷함.
- 이 방식은 **칩 크기가 커져도 성능이 유지**되고, 레이저처럼 정밀하게 빛을 쏠 필요가 없다.

**3. 실험 – 진짜로 가능한지 확인**

연구팀은 7개의 구역(존)을 가진 실험용 칩을 만들고 두 가지 실험을 했다.

- **단일 큐비트 연산**

  - 큐비트를 한쪽으로 살짝 이동시켜 “켜기(활성)” 또는 “끄기(숨김)” 상태로 만듦.
  - 세계 최고 수준 정확도: **99.99916%**
- **두 큐비트 얽힘 연산**

  - 두 큐비트가 동시에 영향을 받도록 자기장을 보내서, **얽힘 상태**를 만듦.
  - 정확도: **99.97%**, 역시 세계 최고 수준
  - 60시간 연속 동작 실험에서도 성능이 거의 유지됨.
  - 

**4. 의미 – 얼마나 크게 만들 수 있나?**

- **칩 구조:**

  - **다층 실리콘 칩 + QCCD 구조(이온 셔틀링)**
  - **2D 유닛 셀 격자 + 연결용 정션 → 전 구역 간 올투올 연결**
  - **균일한 자기장 + 자기 민감도 낮춘 원자 상태 사용**
- 존 간 간격: 350 μm이므로, 이런 방식으로 칩을 카메라 센서 크기(3.5cm × 3.5cm)까지 키우면

  - → **1만 개 큐비트**를 넣을 수 있음.
- 필요한 전력과 냉각 조건도 **시중에 있는 4K(−269°C) 장비**로 충분.
- **배선 한계 극복:**

  - **WISE아키텍처를 이용하여 대부분 전극을 코와이어링(co-wiring) → 약 50~200개의 아날로그 전압 입력으로 전칩 제어 가능**
  - **로컬 전극은 저대역폭이라 멀티플렉싱 가능 → 수백 전극을 하나의 입력에서 구동**
- 제작·보정도 기존 반도체 공정에서 쉽게 할 수 있어서,

  - → **중간 규모 양자컴퓨터**를 빠르게 만들 수 있음

|  |  |  |
| --- | --- | --- |
| **구분** | **레이저 기반 제어** | **전자 제어 기반 제어 (이번 논문 방식)** |
| **동작 원리** | 외부에서 고정밀 레이저 빔을 개별 이온에 쏴서 상태 제어 | 칩 내부의 전류 경로와 로컬 전극을 통해 **마이크로파/전자기장**을 직접 인가 |
| **확장성**  **(Scaling)** | 큐비트 수가 늘어날수록 레이저 빔 정렬·안정화가 어려워짐 → 비용·복잡도 급증 | 공유 전류 경로를 사용해 장치 크기와 무관하게 안정된 제어 가능 |
| **잡음/간섭**  **(Crosstalk)** | 빔의 산란·정렬 오차로 인접 이온 간 간섭 발생 가능 | 로컬 전극으로 전자기장을 세밀하게 국소 조정 → 매우 낮은 크로스토크 |
| **하드웨어 복잡성** | 다수의 고정밀 광학 부품, 정렬 시스템 필요 | 칩 집적 회로(IC) 기반 → 광학 장치 수 최소화 |
| **온도 안정성** | 온도 변화에 민감, 레이저 안정화 장치 필요 | 전자 신호는 온도 영향이 적어 장기 안정성 우수 |
| **게이트 성능**  **(피델리티)** | 고성능 가능하지만, 큐비트 증가 시 유지 어려움 | 단일 큐비트 99.999%+, 2큐비트 99.97% 유지 가능 |
| **장기 안정성** | 레이저 드리프트로 주기적 재보정 필요 | 전자 회로 기반 제어로 수일~수주 연속 안정 동작 가능 |

**1. 전체 개념**

- **TIQC(Trapped-Ion Quantum Computer)** 칩은 마이크로패브리케이션(반도체 공정)으로 제작.
- 칩에는 2D 그리드 형태의 유닛 셀(unit cell)이 반복적으로 배열됨.
- 각 유닛 셀에는:

  - **트랩된 이온 큐비트**
  - **로컬 튜닝 전극(local tuning electrode)**가 포함되어 있음.

**2. 구동 방식**

- **공유 드라이브(shared drive)**:

  - 마이크로파를 이용하여 AC 전류를 흘려서 칩 전체에 걸쳐 교류 자기장(AC magnetic field)을 생성.
  - 한 번의 신호로 모든 유닛 셀에 게이트 구동 가능.
- **개별 제어**:

  - 각 유닛 셀의 로컬 전극에 **DC 전기장**을 걸어, 공유 드라이브와의 결합 세기(coupling strength)를 조절.
  - 이렇게 하면 **동일한 AC 신호**를 받더라도 셀마다 다른 제어 강도를 줄 수 있어 **크로스토크 최소화**.

**3. 실험 장치 (오른쪽 Test device)**

- **형태**: 직선형 **7존(linear seven-zone)** 이온 트랩.
- **전극 배치**:

  - 로컬 튜닝 전극 + 공유 전류 경로(trace)가 **같은 레이어**에 배치.
  - 공유 전류 경로는 **x축 방향**으로 배선.
- **이온 위치**:

  - 전극 위 약 **z ≈ 40 μm** 높이에 부유(trapped).
- **레이저 사용**:

  - **존 4**에서만 이온 로딩·상태 준비·측정에 레이저 사용.
  - 게이트 연산(coherent control)에는 레이저를 쓰지 않음.
- **자기장 배경값**:

  - **정적 자기장 B₀ ≈ 8.5 mT**를 **y축 방향**으로 인가

    - 큐비트 주파수를 안정적으로 설정하고,
    - 마이크로파 자기장과 직교해 제어 효율을 높이며,
    - 이온 y축 이동에 따른 결합 조절 효과를 최대로 만들기 위함이다

> 모든 구역에 동일한 구동 신호를 보내되, 각 구역의 전극에서 DC 전기장으로 “볼륨 조절”을 하듯 제어 강도를 조정 → **확장성 + 낮은 간섭**을 동시에 확보.

**📌확장시 배선 문제**

- 옥스포드 아이오닉스에서 생산중인 양자컴퓨터는 **이온트랩 방식**중 원자를 전기장에 띄워서(트랩) 큐비트로 쓰는 방식이다.
- 큐비트를 늘리려면 더 많은 전극(electrode)과 배선(wiring)이 필요하다.
- **1000개 큐비트**를 기존 방식대로 연결하면, 선이 **수만 개 필요**하고, 칩과 외부 장비를 연결하는 게 거의 불가능해진다.
- → 마치 콘센트를 수천 개 꽂아야 하는 멀티탭을 만드는 상황이다.

**1. WISE 아키텍처**

WISE는 **Wiring using Integrated Switching Electronics**의 줄임말로, 쉽게 말해 “스마트 전선 스위치 시스템”이다.

**핵심 아이디어**

- **전극을 두 종류로 나눔**

  - **동적 전극**: 이온을 이동시키거나 조작할 때 쓰는, 자주 바뀌는 전압
  - **정적 전극(Shim)**: 미세한 전기장 보정, 항상 같은 전압 유지
- **스위치 네트워크**

  - 많은 전극이 소수의 제어장치(DAC)를 공유하도록 스위치로 연결
  - 필요할 때만 원하는 전극에 신호를 보내고, 안 쓸 땐 끊어둠
- **디멀티플렉서(분배기)**

  - 한 개의 전압 발생기(DAC)가 수십~수백 개 전극에 차례로 전압을 설정하고 저장(샘플·홀드)

**2. 결과**

- 기존에는 큐비트 수가 늘면 배선도 똑같이 많이 늘어야 해서 **1000큐비트를 위해 20,000라인이 필요**했지만, WISE를 쓰면 **1000큐비트를 약 200개의 선으로 제어** 가능
- 칩 속에 스위치와 작은 커패시터만 넣어서 전력·면적·데이터 전송량 문제 해결
- 크기는 스마트폰 메인보드보다 작지만, 1000큐비트를 제어할 수 있는 양자칩 설계 가능

> **옛날 방식**: **방마다 전등 스위치와 전선이 따로따로** 있어야 하는 집
>
> **WISE 방식**: 전선은 최소한만 깔고, **집 안에 스마트 스위치 박스를 설치**해서 → “이 방 전등 켜!” 하면 중앙에서 신호를 보내 필요한 곳만 전원을 연결하는 것과 같다.
