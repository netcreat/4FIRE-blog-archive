**🧲스핀과 하이퍼파인상태**

**🔹 스핀(Spin)이란?**

스핀은 입자가 가지고 있는 **내재적인(타고난)** 각운동량이다.

회전하는 물체처럼 보일 수 있지만, 실제 회전과는 다르다.

그러나 **수학적으로는 회전과 비슷한 방식으로 작용**한다.

****

**🔸 전자스핀 S=1/2**

- 전자는 스핀 양자수 s=1/2
- 이는 전자가 **두 개의 스핀 상태**를 가진다는 것을 의미:

  - ms=+1/2 → “스핀 업” ↑
  - ms=−1/2 → “스핀 다운” ↓
- 이것은 전자의 자기적 성질 (예: 자기 모멘트)에 영향을 준다

****

**🔸 핵스핀 I=3/2**

- 원자핵 전체(여러 개의 양성자, 중성자 조합)의 **집합적인 스핀**이다
- 바륨-137의 경우, 이 핵이 *I*=3/2의 스핀을 갖는다는 건:
- 핵의 스핀 상태가 m*I*=−3/2,−1/2,+1/2,+3/2의 **네 가지 상태** 중 하나일 수 있다는 뜻이다.
- 이 값은 **실험적으로 결정된 값**으로, 원자핵 내부 구조에 따라 달라진다.

****

**🧠 두 스핀의 결합 → 하이퍼파인 구조**

전자스핀과 핵스핀이 결합하면, 전체 원자의 상태가 **새로운 스핀 상태**를 형성한다.

이를 통해 **안정상태****에서 하이퍼파인 상태**가 정의된다.

- 결합된 스핀 *F=I+S,I+S−1,...,∣I−S∣*
- 바륨-137에서는:
- I=3/2,S=1/2 → F=2 또는 F=1

**🔸 각 F 상태에서 나오는 m*****F*** **수**

각 F 상태는 자기 z성분 m*F*∈[−F,−F+1,...,F]를 가진다.

|  |  |  |
| --- | --- | --- |
| **F 값** | **가능한 mF** | **상태 개수** |
| 1 | -1, **0**, +1 | 3개 |
| 2 | -2, -1, **0**, +1, +2 | 5개 |

**🔷 왜 하이퍼파인 구조에서는 m*****F*****=0만 사용할까?**

|  |  |
| --- | --- |
| **이유** | **설명** |
| **Zeeman 영향 최소화** | mF=0 상태는 자기장에 덜 민감 |
| **Clock transition** | 외부 자장 변화에 대해 안정된 주파수 전이 |
| **레이저 선택규칙 적합** | ΔmF=0 전이는 제어가 쉬움 |
| **디코히런스 억제** | 위상 잡음에 강함, 스핀-에코에 유리 |

****

**🧲메타안정상태**

> 왜 메타안정 상태를 사용할 경우 mF≠0 상태들도 쓸 수 있고, 큐디트로 확장할 수 있을까? 그 상태들은 Zeeman 등 외부 인자에 영향을 안 받는가?

**🔹 메타안정 상태란?**

- 메타안정 상태는 수명이 매우 긴 들뜬 상태이다.
- 보통 전이 확률이 낮은 전기 이중자극 전이(E2)나 자기 쿼드러플 전이(M2)로만 천천히 감쇠하므로:

  - 수명이 수초~수십 초 이상 가능
  - 측정하기 전까지 안정적으로 유지됨
- 이런 상태는 레이저로 선택적으로 접근 가능

****

**🔸 왜 다양한 mF 상태들을 사용할 수 있을까?**

**✅ 이유 1: 에너지 간격이 크고, 분리 조작 가능**

- 메타안정 상태는 보통 ground state보다 몇 THz ~ PHz 이상 떨어져 있음
- 각 mF상태들도 자기장으로 완전히 분리할 수 있어서 하나씩 주소 지정(addressing) 가능.

> Zeeman 효과가 여전히 존재하지만, **제어 기술로 분리 가능**하고, **상호간 간섭을 줄일 수 있음**.

**✅ 이유 2: 개별 제어 레이저 세팅이 가능**

- 메타안정 상태는 보통 하나의 하위 준위가 아닌 **여러 개의 고정된 구조**로 존재.
- 각 mF 상태에 대해 레이저의 **편광, 주파수, 위상**을 정밀하게 조절하면:

  - 원하는 상태만 선택적으로 조작 가능.
- 이는 큐디트 공간에서 **직접 논리 연산을 할 수 있는 기반**이 됨.

**✅ 이유 3: 단일 잡음 채널의 공통 영향 → 상대 안정성 확보**

- mF 상태들이 서로 Zeeman 효과를 겪는다 해도,

  - **공통적으로 영향을 받음** → 상대적인 에너지 차는 **일정하게 유지 가능**
- 따라서 전체를 하나의 **안정된 다차원 공간(qudit)**으로 유지 가능.

****

**🔬 예시: 25레벨 큐디트 구현**

- 2023년 Quantinuum이나 다른 trapped-ion 그룹에서:

  - 메타안정 상태 내 여러 mF 준위들을 하나하나 정밀하게 조작해
  - **d=25**까지 논리 게이트 구현
- 이를 통해 더 많은 정보 단위를 한 이온에 저장 및 연산 가능.

****

**⚖️ 안정상태 vs 메타안정상태: 외부 간섭 민감도 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **안정상태 (Ground state)** | **메타안정상태 (Metastable state)** |
| **자연수명** | 거의 무한 (붕괴 없음) | 매우 김 (ms ~ 수십 초) |
| **외부 자기장 민감도** | 높을 수 있음 (Zeeman 효과) | 상태에 따라 다름, 더 강하게 분리해서 제어 가능 |
| **광학 간섭** | 광 쿨링, 측정 등에 사용됨 → 외부 레이저 많이 영향줌 | **레이저 직접 영향 거의 없음** |
| **주소 지정(개별 선택)** | 하이퍼파인 분리는 좁은 편 | **넓은 에너지 차이로 선택적 제어 쉬움** |
| **코히런스 시간** | 길지만 잡음에 따라 좌우 | 제어 잘 하면 **더 긴 코히런스** 가능 |
| **큐디트 구성** | 거의 불가능 (2-level) | 다수 mF 상태로 가능 (13, 25레벨 등) |

> **이론적으로는 ground state가 가장 안정한 상태지만**, **실험적으로는 메타안정 상태가 더 정밀하게 제어되고 외부 간섭에 덜 민감하게 만들 수 있다.**

**✅ 요약 정리**

|  |  |  |
| --- | --- | --- |
| **항목** | **Qubit (mF=0 위주)** | **Qudit (메타안정 상태)** |
| 사용 상태 | 대부분 mF=0 | mF=−F ∼ +F 전체 |
| 이유 | Zeeman 잡음 억제 | 주소 지정 및 상대 안정성 |
| 제어 | 주로 clock transition | 멀티 레벨 정밀 제어 |
| 활용 | 고정밀 계산 | 다차원 연산, 적은 이온으로 더 많은 정보 |

****

**🧭 왜 하이퍼파인 상태를 먼저 썼나? (초기 이온트랩 설계 관점)**

**✅ 하이퍼파인 상태는 실험적으로 ‘기본기가 쉬움’**

- **초기화, 측정, 연산**까지 한 에너지 준위 내에서 해결 가능 (레이저 1~2개로 가능)
- 마이크로파로 제어 가능 → 장비가 단순하고 비용이 낮음
- **SPAM (State Prep & Measurement)** 오류율도 낮게 잡기 쉬움

→ 즉, 실험 안정성과 기초 제어성 측면에서 압도적으로 유리

****

**✅ 메타안정 상태는 실험 난이도가 높음**

- 상태가 너무 안정해서 오히려 **초기화/측정이 어려움**

  - (레이저로 건드리기 어려움)
- 전이가 매우 느림 → 측정 시간이 길어짐
- 특정 레이저 파장, 편광, 위상을 매우 정밀하게 조정해야 함

  - → **레이저 시스템 고도화** 필요

****

**✅ 하이퍼파인 기반 시스템으로도 충분히 좋은 QPU를 구현할 수 있었음**

- 예: Quantinuum, IonQ의 초기 QPU는 하이퍼파인 상태 기반으로

  - 2Q 오류율 < 10⁻³,
  - 논리 큐비트 구성 성공,
  - 에러 정정 실험 가능

→ 즉, **기술적으로 안정되고 성능도 나쁘지 않음**

****

**📈 지금은 왜 메타안정 상태가 더 주목받고 있나?**

- 하드웨어 제어 기술, 레이저 정밀도, 다채널 연산 기술이 발달하면서:

  - 메타안정 상태의 넓은 상태 공간을 이용해 큐디트 구현, 논리 큐비트 확장이 가능
- 전에도 소개한 바 있던 2개의 논문은 각각 캐나다 워털루 대학교와 중국의 KAIST라 불리우는 중국과학기술대학에서 발표한 것으로 큐디트를 이용한 실험 구현이다.
- 중국과학기술대학에서의 실험은 이온이 아닌 루비듐을 이용한 광자로 구현한 것이지만, 워털루 대학교에서 발표한 실험에서는 **바륨 이온**을 이용하였다. **이는 곧 상용화로 이어질 개연성이 매우 크다는 것**을 의미한다.

**🔶 포토닉 인터커넥트 연결 시 장단점**

**🟢 장점 (기회)**

|  |  |
| --- | --- |
| **항목** | **설명** |
| **정보 전송량 증가** | 큐디트는 더 많은 정보를 한 번의 얽힘으로 전송 가능. → 양자 네트워크에서 대역폭 상승 |
| **고차원 얽힘 생성 가능** | 두 큐디트 간 얽힘은 더 복잡한 양자 상태를 표현할 수 있음 |
| **에러 내성 향상 잠재력** | 일부 연구에서는 큐디트 기반 얽힘이 노이즈에 더 견고하다고 제안됨 |

**🔴 단점 (도전 과제)**

포토닉 인터커넥트에서도 메타안정상태를 이용하기 때문에, 이온트랩 내부에서도 동일한 방법을 사용한다면 훨씬 더 간결해 질 것 같지만, 몇가지 도전과제가 있다.

- 메타안정상태는 전이 확률이 낮아서 자발방출 없이 오래 유지되고,
- 메타안정상태는 방출을 잘 안하므로, **빛을 뽑아내기가 더 어렵다**.

|  |  |
| --- | --- |
| **항목** | **설명** |
| **광자 상태 매핑의 복잡성 증가** | 큐디트의 각 상태를 광자(예: 편광, 시간, 주파수 등) 상태에 정확히 매핑해야 함 |
| **고차원 얽힘 생성이 어려움** | 큐비트 얽힘보다 안정적으로 고차원 얽힘을 생성하고 유지하기 훨씬 까다로움 |
| **다채널 분해능 요구** | 광학적으로 큐디트 상태 구분을 하려면 분광적 분해능이 높아야 함 (레이저 정밀도↑) |
| **디코딩 복잡성** | 멀티-포톤 검출기, 다중 모드 인터페이스가 필요함 |

**🎯 결론**

지금까지는 각 양자컴퓨터 제조 업체가 새로운 하드웨어를 출시하거나 로드맵을 발표하면 그에 따른 분석이 주를 이뤘는데, 이와 같이 아직 공개된 적 없는 기술이 과연 세상밖으로 나올지, 어느 업체가 엔지니어링 측면에서 성공을 할지 지켜보는 것 또한 흥미진진하다.

> 처음에는 단순하고 정확한 제어가 가능한 하이퍼파인 상태가 우선적으로 선택됨.
>
> 하지만 시간이 흐르며 제어 기술이 고도화되자, 메타안정 상태의 넓은 상태공간과 긴 수명을 활용한 **고성능 큐디트, 논리 큐비트 설계로 진화** 중이다.

****
