**✅Hypergraph Product Code(HGP)란?**

- - **Hypergraph Product Code(HGP)** 는
  - **지난 20년간 가장 중요한 양자 오류정정(QEC) 코드 패밀리 중 하나**로 인정받는 **qLDPC코드**의 한 형태이다.
  - 2009년 **Tillich & Zémor**가 처음 제안했으며, Surface code의 한계를 극복할 수 있는 **장기적 fault-tolerant 양자컴퓨팅 후보**로 간주된다.

**💡그래프 기반 LDPC (Graph-based LDPC)**

- - LDPC의 classical 정의는 **Tanner graph** 기반이다.
  - 그래프 연결을 통해 constraint(검사 규칙) 생성을 하는 구조
  - 즉, Graph-based LDPC = 단일 그래프 구조 기반 local constraint 집합이고, 이것이 양자컴퓨터로 와서, Quantum Tanner code, Expander-based qLDPC가 탄생하였다.

**💡프로덕트 기반 LDPC (Product-based LDPC)**

- - product는 수학이나 컴퓨터에서는 "곱"을 의미한다.
  - Product-based는 그래프 한 개가 아니라 **두 개의 그래프(또는 두 classical LDPC 코드)** 를 사용해 생성한다.

- - 즉, A의 constraint 구조와 B의 constraint 구조를 서로 **겹쳐 2D 구조로 확장**한다.
  - 그래서 “Hypergraph Product”라고 부른다:

    - 두 그래프의 direct product → hypergraph 구조
    - constraint가 1D에서 2D 스케일로 성장

**💡왜 Product-Based가 강력한가?**

- - **Graph 기반의 한계**

    - local 연결 기반 → 거리 증가 제한
    - scaling이 어려움
    - k/n→0 (logical qubit 비율 급감)
  - **Product 기반의 장점**

    - 두 구조의 결합으로 **거리 d가 polynomial 증가**
    - **constant rate 유지 가능**
    - logical error rate 크게 감소

> **인코딩 비율(rate)이란?**
>
> 양자 오류정정 코드(QEC)는 **물리 큐비트 수 (n)와 논리 큐비트 수 (k)**로 구성된다.
>
> 여기서 **인코딩 비율(R-rate)** 은 물리큐비트대비 논리큐비트 (k/n)이다.
>
> 
>
> **상수 인코딩 비율(constant rate)이란?**
>
> **물리 큐비트가 증가해도 논리 큐비트 비율이 0으로 떨어지지 않고 일정하게 유지**되는 것을 말한다.
>
> 
>
> 상수 인코딩 비율은 실질적 양자컴퓨터 확장을 가능하게 하는 QLDPC의 핵심 장점이다.

- - **Product 기반의 단점**

    - Tanner graph 기반 단일 레이어에 비해 구조가 2D로 복잡함
    - 실제 하드웨어에 매핑하기 복잡
    - long-range 연결 필요 - 가까운 qubit만 연결 가능한 하드웨어에서 문제
    - **BP + OSD 같은 고비용 디코더 필요**
    - **회로 깊이가 커지기 쉬움**
    - 노이즈 모델 민감 - 실험적 환경에서 성능 보장 어려움
    - 하드웨어 구현 최적화 기술 요구 - 아직 표준화된 방식 없음
    - 탐색 공간이 너무 컨서 최적의 **classical seed를 찾기 어렵다**.

      - 기존에는 최적의 HGP 코드를 찾기 위해 Machine Learning(ML)기반 최적화를 진행했었다.
      - random search - 무작위 후보 탐색
      - simulated annealing - 반복 최적화
      - reinforcement learning - 성능 기반 행동 강화
      - local transformation - 부분 수정으로 성능 개선

**💡직관적 의미**

- - Classical LDPC 코드 → 작은 부분 구조의 sparse constraint(검사 규칙)
  - **Hypergraph Product → 두개의 작은 classical constraint 블록을 2D로 확장해서 겹침 구조를 만듦**
  - 결과: 매우 강력한 오류 정정 능력

    - 강력한 오류 억제 능력
    - 매우 낮은 논리 오류율
    - 큐비트 오버헤드를 획기적으로 줄일 수 있음

**✅Cyclic Hypergraph Product Code 연구 개요**

**💡Introduction – 서론**

- - 양자 오류정정(QEC)은 실용적인 대규모 양자컴퓨터를 구축하기 위한 필수 기술이다.
  - 현재 가장 널리 연구되는 Surface code는 단순성과 하드웨어 구현성이 뛰어나지만,

    - 논리 큐비트를 유지하기 위해 수천~수백만 물리 큐비트가 필요하며
    - 인코딩 비율 k/n→0, 최소거리 d∼√n의 한계
  - 때문에 장기적으로는 확장성이 좋지 않다.
  - 이 문제를 해결하기 위한 대안으로 **Quantum LDPC Codes(QLDPC)** 가 등장했으며, 그 중에서도 **Hypergraph Product(HGP)** 코드가 가장 유망한 구조로 평가되고 있다.
  - HGP는 **constant rate**, **polynomial 최소거리 증가**, **낮은 logical error rate** 등을 제공한다.
  - 그러나 기존 HGP 연구는 **탐색 공간이 너무 커서 최적** **classical seed(A,B)를 찾기 어렵다는 문제** 때문에 random search, simulated annealing, reinforcement learning 등 ML 기반 탐색 방식에 의존해 왔다.
  - 본 논문은 ML 기반 local optimization의 한계를 넘어, **전역 대칭(global cyclic symmetry)을 강제하여 탐색 공간을 압축하고, brute-force exhaustive search를 현실적으로 가능하게 만드는 새로운** **Cyclic HGP를 제안****한다.**

> **전역적(global) 대칭성이란?**
>
> 시스템 전체에 걸쳐 반복되는 규칙적 구조가 존재하여, 부분적으로가 아니라 전체적으로 동일한 패턴이 적용되는 성질
>
> 
>
> **반대 개념**
>
> Local transformation - 특정 부분만 수정

**💡Background – HGP 및 기존 LDPC 코드 배경 설명**

- - Hypergraph Product(HGP) 코드는 두 classical LDPC 코드 A와 B를 기반으로 구성되며:

- - 이 구조 덕분에:

    - **constant rate** 유지
    - **polynomial distance scaling** 가능
    - **sparse parity constraints** 유지
  - 그러나 classical seed 후보들이 너무 많기 때문에
  - **best-performing HGP 코드를 체계적으로 찾기 어렵다는 근본적인 문제가 있다.**

****

**💡Cyclic HGP (CxC) – 핵심 제안**

- - 본 연구는 A와 B 모두에 **cyclic symmetry**를 부여하여 행렬이 circulant structure를 갖도록 한다.
  - 이 대칭성이 주는 이점:

    - 탐색 공간이 극적으로 축소
    - brute-force full search 가능
    - ML 없이 global optimum 탐색 가능
    - 전체 행렬이 polynomial 하나로 정의 가능
  - 또한 두 서브패밀리를 정의한다:

    - **C2 code**

      - cyclic LDPC code를 자기 자신과 product
      - 기존 ML-HGP보다 **최대 1000배 낮은 논리 오류율**
      - 더 낮은 qubit 오버헤드
    - **CxR code**

      - cyclic × repetition product
      - 단순한 구조 + 더 좋은 안정성 + 낮은 회로 복잡도

**💡Planar QCCD Layout – 아키텍처 적용**

- - 본 논문은 특히 이온트랩 QCCD 플랫폼의 구현성까지 고려한다.

    - 2 × n qubit strip 구조
    - Controlled cyclic shift 기반 syndrome extraction
    - Long-range shuttling 제거
    - **Constant-depth 회로 구현 가능**
  - 즉, 최소거리 d가 증가해도 게이트 깊이는 변하지 않음

    - 일반적으로,거리 d가 커질수록 안정성이 증가하지만
    - **더 많은 stabilizer를 측정해야 하기 때문에 회로 깊이도 커진다.**
    - **→ scale-up이 클수록 연산 시간도 길어지고 누적 오류도 증가한다.**
    - **Cyclic shift 방식을 이용하면 거리가 커지더라도 이미 지정한 안실라 큐비트가 로테이션 하면서 커지는 데이터 큐비트를 전부 커버할 수 있기 때문이다.**
  - 이는 최초로 **QLDPC 기반 fault-tolerant 양자 메모리** 구현의 현실적 가능성을 제시한다.

**💡Conclusion – 결론**

- - Cyclic Hypergraph Product Codes는 ML 기반 최적화를 넘어 전역 대칭성을 통해 탐색 공간을 축소하고 최고 성능 QLDPC 구조를 찾아내는 새로운 패러다임을 연다.
  - 핵심 기여:

    - brute-force 탐색 가능성 확보
    - ML 최적화보다 우월한 성능
    - constant rate + polynomial distance + lower overhead
    - 하드웨어-친화적 constant-depth QCCD 회로 설계 제시
  - 향후 과제:

    - logical gates 설계 연구
    - balanced / lifted product와 결합
    - neutral atom / NV / superconducting 플랫폼으로 확대

      - 기존 HGP 대비 1,000배 낮은 오류율
      - 미리 준비했었던 Flat cyclic layout을 적용시켜 QCCD 최적화 설계

        - 회로 깊이 일정하게 유지함으로써, 연산 시간이 길어져도 누적 오류가 증가하지 않는다.
  - 즉:
  - IonQ는 아래와 같은 세가지를 해결했다.

    - 2Q 충실도를 99.99%로 높였고,
    - 기존 qLDPC 대비 오류율을 1,000배 낮췄으며,
    - 누적 오류를 증가하지 않는 아키텍쳐를 사용함으로써, 확장성의 한계를 극복하였다.
  - **IonQ는 surface code 대신 QLDPC(Cyclic HGP) 기반 FTQC 로드맵을 이미 명확히 준비하고 있었다는 증거**
