**✅****위성의 분류**

**🚀크기 및 폼팩터별 분류**

- - **1️⃣ CubeSat 계열 (표준 모듈형)**

    - **형태:** 10 cm 정육면체 단위(1U)로 구성
    - **특징:** 전 세계 공통 규격(P-POD launch system)으로, 대학·벤처에서도 제작 가능
    - **예시:** SPOOQY-1 (싱가포르), QUBE (독일), Nanobob (프랑스)
    - **용도:** 저비용 실험, QKD 기술 검증, 광원 / 검출기 테스트
  - **2️⃣ Microsatellite / Smallsat (마이크로 / 스몰샛)**

    - **형태:** 맞춤형 (30 ~ 60 cm급 직육면체), CubeSat보다 크고 유연한 설계
    - **특징:** 전력·자세제어 향상, 페이로드 공간 확보 → 상용 임무 가능
    - **예시:** QEYSSat (캐나다), Jinan-1 (중국)
    - **용도:** 지상-위성 QKD 링크, 상용 양자통신 테스트, 소형 관측·통신 위성
  - **3️⃣ Minisatellite / Medium Satellite (미니 ~ 중형)**

    - **형태:** 1 m 이상, 수백 kg 급 플랫폼
    - **특징:** 복합 광학계·고출력 송수신기 탑재 가능, 장시간 궤도 운용
    - **예시:** Micius (QUESS, ≈ 631 kg), SpeQtral-1 (싱가포르)
    - **용도:** 대형 광자 광원, 다중 채널 QKD, 광자 얽힘 분배
  - **4️⃣ GEO / High-Orbit Bus Platform (정지궤도형 대형 위성)**

    - **형태:** 수 m 급 대형 버스, 질량 1 ~ 6 톤
    - **특징:** 24 시간 지구 동기 정지 운용, 고출력 통신 및 중계 시스템
    - **예시:** Jinan-3 (GEO QKD), ESA GEO QKD 프로그램
    - **용도:** 전지구 양자 통신 커버리지, 지속적 얽힘 중계 및 네트워크 핵심 노드

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **구분** | **질량 / 크기 기준** | **설계 형태** | **주요 예시** | **주 용도** |
| **CubeSat** | 1 ~ 25 kg (1U ~ 12U) | 표준 모듈형 | SPOOQY-1, QUBE | 저비용 실험·QKD 검증 |
| **Microsat** | 10 ~ 100 kg | 맞춤형 소형 버스 | QEYSSat | 상용 QKD, 지상링크 |
| **Minisat** | 100 ~ 500 kg | 중형 버스 / 광학계 포함 | Micius | 대형 광자 광원·중계 |
| **Medium Sat** | 500 kg ~ 1 000 kg | MEO | Jinan-2 | 위성-위성 얽힘 네트워킹 |
| **Large Sat** | ≥ 1 000 kg | GEO 정지 통신형 버스 | Jinan-3, ESA GEO QKD | 지속 중계, 글로벌 망 핵심 노드 |

**🧩****각 궤도별 장/단점**

|  |  |  |  |
| --- | --- | --- | --- |
| **항목** | **LEO** | **MEO** | **GEO** |
| 고도(km) | 300–2,000 | 2,000–20,000 | 35,786 |
| 광 손실 | 낮음 | 중간 | 매우 높음 |
| 가시 시간 | 짧음 (5–10분) | 중간 (15–30분) | 연속 (24 h) |
| 필요 위성 수 | 수십 기 | 6–12 기 | 3 기 |
| 지연(latency) | 30 ms | 100 ms | 500 ms |
| 발사/운영비 | 저렴 | 중간 | 매우 높음 |
| 기술 난이도 | 낮음 | 중간 (정밀조향+방사선) | 매우 높음 (광손실+열안정) |
| 대표 예시 | Micius, QUBE | Jinan-2 | Jinan-3, ESA GEO QKD |
| 전략적 위치 | 실험/검증 단계 | 중계/확장 단계 | 상용·전지구 서비스 단계 |

- - 궤도를 올리는 것은 단순한 ‘높이 경쟁’이 아니라, **“지속성·커버리지·네트워크 확장성”을 얻기 위한 필연적 진화 과정**이다.

    - **LEO:** 기술 검증, 단기 QKD 실험 (기초 레이어)
    - **MEO:** 지속적 연결 + 리피터 계층 (중간 레이어)
    - **GEO:** 전지구 서비스 + 네트워크 허브 (상위 레이어)
  - 결국 미래의 양자 네트워크는 **LEO ↔ MEO ↔ GEO 3계층 하이브리드 구조** 형태로 수렴하게 될 가능성이 크다.

    - (LEO 실험/수집 → MEO 중계 → GEO 글로벌 허브)

**✅현재 상황과 IonQ의 전략**

**🧩거대 기업의 접근 : Boeing / Airbus / ESA / CNSA**

- - 이들은 모두 **“Top-Down” 접근** — 즉, 수십억 달러짜리 위성 + 국가망 + 장기 검증으로 간다.

|  |  |  |  |
| --- | --- | --- | --- |
| **기업** | **궤도** | **특징** | **한계** |
| **Boeing (Q4S)** | LEO~MEO | 얽힘 스와핑, 위성–위성 링크 실증 중심 | 기술성숙도 높지만, 대규모 자본 기반의 장기형 프로젝트 |
| **Airbus / ESA (Eagle-1, GEO QKD)** | LEO→GEO | EuroQCI 백본 구축용. 정부·국가망 중심 | 관료적, 상용화 속도 느림 |
| **CNSA (Jinan 시리즈)** | LEO→MEO→GEO | 단계별 국가 프로젝트. 글로벌 커버리지 지향 | 폐쇄적, 상업 파트너 제한적 |
| **Honeywell / Quantinuum (협력사)** | — | 지상 QKD 중심. 위성은 외주 | 시스템 통합은 느리지만, 장기 신뢰성 확보 |

**🧩IonQ + Capella가 취할 수 있는 전략 : Bottom-Up**

- - **IonQ + Capella의 약점**

    - 발사비·위성 질량 한계 (Capella 버스는 100–200 kg급 SAR 중심)
    - GEO급 정밀 조향·열제어 기술 없음
    - IonQ의 페이로드는 아직 TRL(기술성숙도) 4–5 수준
  - **IonQ + Capella이 취할 수 있는 전략**

    - **Quantum Secure Earth Observation Network (QSEON)**

      - → Capella SAR 데이터를 QKD/QNC (Quantum Network Channel) 로 보호하며 지상으로 전송.
    - **Quantum Clock & Sync in LEO**

      - → IonQ microwave ion trap을 정밀 시계 기준으로 활용, 위성간 광자 링크 동기화.
    - **Quantum-AI Imaging Pipeline**

      - → 양자 AI 모델로 SAR 영상 후처리 및 변분 압축(Variational Compression).
    - **Hybrid DOE–AFRL–NASA 테스트베드**

      - → Capella 망을 미 국립연구망(ESnet)과 연결해 실험 데이터 전송 및 얽힘 분배 실증.
  - **1단계 (2025–2027): LEO 테스트 및 페이로드 상용화**
