# SEEQC, 초전도체방식의 구원투수로 등장.

**✅ 핵심 내용**

- - **SEEQC**가 대만 ITRI(산업기술연구원)과 협력하여 **Single Flux Quantum(SFQ) 기반 초전도 디지털 제어칩** 전용 생산라인을 구축.
  - 목표:

    - 고수율(high-yield) 양자 제어칩 생산공정 확립
    - 공정기술 이전(tech transfer)
    - 대량생산(scale-out) 가능한 양자 제어칩 공급망 확보
  - 생산된 칩은 미국 본사로 보내져 **큐비트와 통합 + 저온 테스트** 진행.
  - 이 칩은 **초저전력·고속·저지연** 특성 때문에 **양자 오류정정, 타이밍 제어, readout, 멀티플렉싱** 등 핵심 기능을 cryo 안에서 직접 수행 가능.
  - 이번 확장은 **NVIDIA, NQCC, IBM, DARPA QBI Phase B** 등 SEEQC가 참여 중인 프로젝트에 필요한 대규모 칩 공급을 뒷받침.

---

**🔧 기술적 의미 — 왜 이게 중요한가?**

**📌SFQ(superconducting digital logic) 기반 제어의 본질**

- - 일반적인 초전도 양자컴퓨터(IBM, Google 등)는
  - **상온 room-temperature 전자장치 → 케이블 → 냉동기 → 큐비트** 구조이다.
  - 그러나 케이블 연결이 많아질수록:

    - 열부하 증가
    - 피더 케이블 복잡성 증가
    - 지연(latency) 증가
    - 에러 정정 요구사항 충족 어려움
  - ➡️ 결국 **스케일업 병목**이 된다.

**📌****SEEQC는 제어칩을 아예 냉동기 내부로 넣는다.**

- - SFQ 로직은 **몇 펨토초~피코초 수준의 스위칭**
  - 전력 소비 극도로 낮음 (fW~pW)
  - cryo 환경에서 동작 안정적
  - 즉, IBM·Google도 목표로 하지만 아직 완성하지 못한 “Cryo control + digital error correction on-chip”을 실제 상용 수준으로 밀고 있는 회사가 바로 SEEQC.

---

**🏭 산업·공급망 관점에서 의미**

**📌양자제어칩의 대량생산 라인 확보**

- - 지금까지 양자칩은 대부분:

    - 소량
    - 연구소 수준
    - 초전문 인력 기반 실험적 공정
  - ➡️ **산업화(industrialization) 단계로 넘어가는 것을 의미.**
  - **ITRI**는 TSMC의 기술 기반과 대만 공정 생태계를 가진 곳이기 때문에 고수율, 반복생산, 대량생산 기술에 최적화되어 있음.
  - 이는 미국·EU가 추진 중인 양자·반도체 공급망 분산 전략(탈중국·반중국)과도 맞물린다.

**🤝 NVIDIA / IBM / DARPA QBI와의 연결**

**📌** **NVIDIA**

- - NVIDIA는 *Quantum-Classical Hybrid* 전략을 밀고 있음.
  - SEEQC의 SFQ 제어칩은 **GPU와 양자칩 간의 초저지연 상호작용**에 유리.
  - 즉 **NVQLink** 같은 구조에서 cryo 제어 레이어로 채택될 가능성이 있음.

**📌** **IBM**

- - IBM은 자기들이 새로 개발 중인 **Quantum Control ASIC**을 내부적으로 연구 중.
  - 그러나 SFQ 기반 디지털 제어는 **SEEQC가 더 앞서 있음**.
  - IBM이 이번 협력에 참여하는 이유는:

    - **오류정정 로직의 분산(on-chip/off-chip) 구조 검증**
    - **초전도 생태계 전체의 스케일업 대응**

****

**📌** **DARPA QBI Phase B**

- - DARPA QBI는 **양자컴퓨터의 실제 성능 벤치마킹 표준**을 만드는 초대형 프로젝트.
  - 여기에 쓰일 “대규모 양자시스템 제어 인프라”가 필요하기 때문에 SEEQC는 매우 중요한 역할을 맡게 됨.

- - 미국은 양자·반도체 분야에서 **동맹 기반 공급망 확보**가 필수.
  - 대만은 이미 TSMC 덕분에 세계 최상위 공정 인프라 보유.
  - ITRI는 정부 주도 R&D 기관이라 **국가급 기술 협력**이라는 의미도 있음.
  - ➡️ **미국 NY fab + 대만 fab = 이중 공급망 확보 → 국방/정부 고객에게 매우 중요**

**📌 정리: 이번 뉴스가 의미하는 점**

**✔ 초전도 양자컴퓨터의 “병목(제어칩 복잡성)” 해결 방향을 SEEQC가 산업화 단계로 전진시켰다.**

**✔ ITRI 협력으로 대량생산 가능한 양자제어칩 공급망이 생긴다.**

**✔ NVIDIA·IBM·DARPA** **사업과 직접 연결되어 실제 상용 QEC에 필요한 인프라 확충 효과.**

**✔ 미국 + 대만 이중 공급망으로 지정학적 안정성까지 확보.**

**✅****초전도체 기반 양자컴퓨터의 절대적 약점**

- - **절대 0도 냉각 (수 mK)**

    - 희석식 헬륨 냉각
  - **굵은 동축 케이블**

    - 케이블 길이·수량 증가 → 열부하 증가 → 냉각 효율 저하
  - **실온에 있는 제어기에서 아날로그 마이크로파 파형 생성하여 냉각기 내부의 QPU 제어**

    - 초전도 큐비트(Transmon/Fluxonium)는 **마이크로파( microwave ) 공진기**라서, 게이트 연산이 “파형의 모양, 위상, 진폭, 주파수”를 정밀하게 조절해야 한다.
    - 즉, 트랜지스터를 1·0으로 켜는 게 아니라 “정확한 아날로그 파형을 쏴서 에너지 준위를 바꾸는 방식”이었다.
    - 그래서 실온에서는 다음 장비들이 필요하다.

      - **AWG (Arbitrary Waveform Generator)**

        - 1~10 GHz 영역에서 아날로그 파형 생성
        - 파형 shape, rise time, envelope 등 매우 세밀한 조정 필요
      - **IQ 믹서 / 마이크로파 소스**

        - 여러 개의 고주파 신호를 혼합해서 원하는 위상을 만들어내는 장비
      - **고속 ADC + FPGA 기반 readout 장비**

        - readout 공진기에서 돌아오는 마이크로파 신호를 디지털로 변환
        - 적분, 필터링, threshold 처리하여 큐비트 측정값 생성
    - 냉각기 외부에 위치한 위의 장비들에서 발생한 아날로그 파형으로 냉각기 내부의 QPU를 제어하는 방식
    - → 오실로스코프를 LAN으로 Remote Control하는 것과 비슷한 수준

**📌SEEQC / SFQ 기반 구조의 장점**

- - 제어기가 냉각기 안으로 이동
  - 제어 방식 자체가 아날로그 → 디지털 로직(SFQ)으로 바뀜
  - → 선 수, 열부하, 스케일링 법칙이 통째로 바뀜

**✅NVIDIA·IBM·DARPA가 갖는 이점**

**📌****NVIDIA**

- - SEEQC는 NVQLink의 파트너십을 맺은 업체.

[**NVIDIA NVQLink 협력 업체들**

Nvidia NVQLink에 참여하는 업체가 19개 양자컴퓨팅 업체와 5개의 제어시스템 개발사가 공개되었는데 ...

blog.naver.com](https://blog.naver.com/4-fire/224063317465)

- - NVIDIA는 NVQLink를 통해 QPU-GPU간 실시간(fast feedback) 오류정정 + 알고리즘 적응형 제어를 목표로 함.

    - RT ↔ Cryostat 간 I/O가 느리다
    - 케이블 길이·수량 증가 → 열부하 증가 → 냉각 효율 저하
    - 에러정정을 해야 하는데 **feedback loop가 너무 느림**
    - **→ 성능의 80% 손실**
    - **Cryo 내부에서 디지털 제어가 이루어질 경우**

      - 지연문제 해소

        - 케이블 수 = 대폭 감소
        - 왕복 지연(ms → ns~μs) 수준으로 줄어듦
        - Error correction cycle 속도 ↑
      - 양자 전용 인터커넥트 구현 가능

        - QPU control plane이 **digital packet-based** 신호를 처리
        - GPU→QPU를 **직접 연결하는 인터커넥트** 설계 가능
      - 양자오류정정(QEC)에서 가장 중요한 real-time decoding을 GPU가 독점할 수 있음

        - Syndrome extraction, readout preprocessing을 cryo에서 먼저 처리
        - GPU는 **훨씬 줄어든 데이터만 받아서 빠르게 디코딩**
        - 전체 QEC cycle 시간을 기존 대비 **10~100배 단축** 가능
      - 전력 효율 문제 해결

        - 총 전력량을 늘리지 않고도 양자 가속기를 추가할 수 있다는 의미.
      - 양자 컴퓨팅의 스케일업이 NVIDIA 생태계로 귀속

        - 제어 프로토콜이 GPU-friendly
        - 인터커넥트가 GPU 패브릭에 통합 가능
        - NVQLink 같은 생태계로 QPU가 정식 편입

**📌****IBM**

- - “Transmon 스케일링 한계”를 뒤집을 수 있는 유일한 기술

    - Transmon은 케이블이 너무 많아서 물리적 스케일링이 불가능하다.
    - IBM이 기존 로드맵에서 **4158-qubit Kookaburra** 이후를 명확히 제시하지 못한 이유
    - ➡️ **IBM의 전체 초전도체 로드맵 지속 가능성 확보**
  - **Logical qubit(QEC)까지 가는 길을 앞당김**

    - ➡️ **논리 큐비트 하나 생성에 필요한 물리 큐비트 수가 감소**
    - ➡️ Logical qubit roadmap(2026~2029)을 실제 실현 가능하게 만듦
  - **CryoCMOS는**

    - SFQ에 비해 속도가 수십~수백배 느림
    - CryoCMOS는 여전히 아날로그 파트가 필요
  - 초전도 플랫폼의 ‘존속성’ 확보

    - ➡️ **초전도 플랫폼은 서서히 edge를 잃어가고 있었다.**
    - **SFQ를 통해 다시 스케일링 가능한 후보가 됨.**

****

**📌DARPA QBI**

- - DARPA QBI의 본질을 한 문장으로 요약하면:

    - “양자컴퓨터의 진짜 성능을 평가할 수 있는 표준화된 벤치마크를 만든다.”

      - → 단순히 큐비트 수, 게이트 피델리티로는 실제 성능을 전혀 설명할 수 없기 때문
  - 그런데 QBI가 직면한 가장 큰 문제는:

    - 벤치마크를 하려면 '스케일링된 진짜 시스템'이 필요하지만, 초전도 기반 양자컴퓨터는 제어 인프라 때문에 크게 못 키운다.
  - **QBI가 Cryo-Digital 제어 덕분에 얻게 되는 이득 5가지**

    - 진짜 "대규모 장치"를 벤치마킹할 수 있게 된다
    - QEC(오류정정) 벤치마크가 처음으로 ‘현실적’이 된다
    - 플랫폼 간 공정한 비교가 가능해진다 (Superconducting vs Ion Trap vs Photonics)
    - 하이브리드 HPC–Quantum 벤치마크가 가능해진다 (DARPA가 가장 관심 있는 부분)
    - “정부·국방용 양자 시스템”의 신뢰성 기준을 정할 수 있다

> ***SEEQC가 당시 이런 Cryo 디지털 제어 성과를 좀 더 앞당겨 냈다면 초전도 업체 상당수가 탈락하지 않았을 것***

- - **IBM과 Nord Quantique가 살아남은 이유?**

    - **IBM — CryoCMOS + 모듈러 QPU 로드맵 + 강한 제조 인프라**

      - CryoCMOS 전자공학 개발을 가장 빨리 진행

        - 4 K 에서 동작하는 로직 + DAC/ADC + multiplexer 개발
      - Eagle, Osprey, Heron 등 모듈형 QPU 로드맵

        - QPU를 모듈 단위로 묶어 다중 칩으로 확장
      - HPC-Quantum 통합 전략

        - Qiskit HPC, GPU 기반 디코딩 파이프라인 등
        - QBI 목표인 “실용적 하이브리드 성능 평가”와 일치
    - **Nord Quantique — 초저오류 플럭소늄 + 단일 큐비트 QEC 접근(2D가 아닌 1D 기반)******

      - 플럭소늄(Fluxonium) 기반 초전도체

        - Transmon 대비 10×~100× 더 높은 T1·T2 기대치
        - 에러율 감소 → QEC overhead 감소
      - 독특한 ‘단일 큐비트 QEC’ 구조

        - Nord는 큐비트 하나를 여러 에너지 준위로 구성하여 하나의 물리 큐비트에 부분적인 오류정정 기능을 넣음.
      - 뛰어난 4K 운영 가능성

        - Fluxonium은 Transmon보다 cryo control과의 궁합이 좋음.

          - Fluxonium은 Transmon에 비해 고주파(anharmonicity)가 크고
          - Thermal population에 덜 취약하며
          - 일부 제어/읽기 회로를 higher temperature stage (1–4 K)로 올릴 수 있는 가능성이 있다.
          - Fluxonium 자체는 여전히 mK 범위(10–20 mK)에서 운영된다.

            - → 여기서 혼동하면 안 됨.
          - 다만 제어 전자회로 일부(소형 DAC/ADC, MUX, preamp)를 1–4 K 스테이지로 올려서 처리가 가능하다.

**📌Atlantic Quantum**

- - **Atlantic Quantum은 “플럭소늄 + Cryo 제어 전자공학(디지털화)”을 동시에 밀던 거의 유일한 스타트업**이었다.
  - 그래서 Google이 Atlantic을 인수한 것도 “플럭소늄 물리 + 차세대 제어 아키텍처” 둘 다 노린 전략적 선택이었다.
  - Atlantic은 QBI Phase B에서 탈락했는가?

    - Atlantic은:

      - 기술 방향은 맞았지만
      - Cryo control 실증 수준이 **프로토타입 이전 단계**
      - 공정 인프라 부족
      - 제조·패키징 로드맵이 약함
