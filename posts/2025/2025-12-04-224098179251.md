**✅1. Introduction — AI가 왜 양자컴퓨팅에 필요한가**

**💡** **양자 하드웨어는 아직 NISQ 단계, FTQC로 가려면 난제가 많다**

- - 노이즈·제조 편차·규모 확장의 어려움
  - 오류보정(QEC)도 실시간 디코딩이 어렵고 리소스 엄청 큼
  - 하드웨어, 소프트웨어, 데이터 처리 모두 병목 존재

**💡** **AI는 “비선형 고차원 시스템”을 매우 잘 다루는 도구**

- - 양자컴퓨팅의 난제 특성과 잘 맞는다:

    - 고차원 parameter landscape
    - 불완전·노이즈 데이터
    - 최적화 난이도
    - 설계 공간 폭발(combinatorial explosion)

**💡** **본 리뷰 논문의 구조**

- - AI는 QC 전체 스택(설계 → 회로 준비 → 운용 → QEC → 후처리)에 영향을 미친다.

---

**✅2. AI for Quantum Computer Development and Design**

- - 하드웨어 개발 단계에 AI가 어떻게 도움을 주는가

**💡2.1 System Characterization(시스템 특성 추정)**

- - 핵심: **Hamiltonian Learning + Graybox 모델**
  - **문제가 뭐냐?**

    - 실험 데이터를 통해 장치의 실제 Hamiltonian(고립된 양자계의 뉴턴 방정식이라고 이해하고 넘어가자)을 추정하는 건 매우 시간·비용 많이 듬
    - 노이즈와 제한적 측정 때문에 더 어려움
  - **AI가 해결**

    - ML로 Hamiltonian 파라미터를 추정하면
    - → 필요한 측정 횟수 줄어듦
    - → 비정상적/비마코프 노이즈까지 모델링 가능
    - Graybox 모델

      - physics-based equation(whitebox)

        - NN blackbox
        - → “물리적 제약을 가진 ML 모델”로 안정적인 추론 가능
  - **실사용 예:**

    - photonic circuit 제어전압 추정
    - nuclear-spin environment 학습
    - 양자점(quantum dot) disorder potential 추정
  - 결론: **실험자가 알아내야 했던 시스템 파라미터를 AI가 자동 추론할 수 있게 됨.**

****

**💡2.2 Platform Design(플랫폼 설계)**

- - 하드웨어 제작 과정에서 가장 어려운 것:

    - 제조 편차(variability)
    - 결함
    - 비균일성
    - 복잡한 다중 게이트 구조
  - AI는 **설계 공간 탐색**을 인간 대신 자동화.
  - **예:**

    - 초전도 큐비트에서 2-qubit 게이트 설계를 AI가 탐색
    - 광자 회로에서 entangled-state 생성 구조를 AI가 자동 설계
    - 반도체 큐비트에서 제조 편차를 보정하는 최적 게이트 조건 출력
  - AI는 “새로운 양자 아키텍처 자체 설계”에도 활용됨.
  - 즉, **기존 접근을 뛰어넘은 아키텍처 제안까지 가능.**

****

**💡2.3 Gate and Pulse Optimization(게이트/펄스 최적화)**

- - Quantum control 분야는 RL이 가장 많이 쓰인다.
  - **문제:**

    - 펄스 모양을 바꾸면 fidelity가 달라짐
    - leakage, crosstalk, 환경 잡음 등 고려해야 할 것이 매우 많음
    - 직접 탐색하기엔 조합 폭발
  - AI는 **RL agent가 펄스 형태를 실험적으로 직접 탐색**하여 최적 형태를 찾아냄.
  - **효과:**

    - 초전도/transmon qubits → 더 빠른 CNOT 개발
    - quantum dot → leakage 최소화
    - charge qubit → 노이즈 강건성 증가
  - 즉: **하드웨어 액추에이터 제어를 인간이 아닌 AI가 직접 배우는 시대가 됨.**

---

**✅3. AI for Preprocessing — 회로 준비를 더 똑똑하게**

- - **회로를 작게 만들고, 빠르게 만들고, 최적 파라미터를 더 잘 찾는 것.**

**💡3.1 Quantum Circuit Synthesis(회로 합성)**

- - **3.1.1 Unitary Synthesis**

    - 특정 유니터리를 게이트 셋으로 decomposing 하는 문제.
    - 문제점:

      - 유니터리 차원은 2n → n이 조금만 커도 굉장히 복잡
      - 기존 알고리즘은 combinatorial search라서 비효율적
    - AI의 역할:

      - RL agent가 “순차적 gate 선택”을 통해 회로를 자동 구성

        - RL agent는 강화학습 에이전트 (Reinforcement Learning)로서 보상을 최대화하도록 스스로 학습하는 AI.
        - 사람이 정답을 알려주지 않음 → 스스로 시행착오하며 발견
      - Diffusion 모델이 “노이즈 → 정교한 회로 구조” 생성
      - CNN 기반 embedding으로 3-qubit·multi-gate synthesis 가능

        - CNN(Convolutional Neural Network)의 특기 = **패턴 인식**
    - 즉, **회로 생성을 확률적 탐색에서 학습 기반 탐색으로 전환**

****

- - **3.1.2 Compact Circuit Generation(압축 회로 생성)**

    - 여기서 나온 최고의 예시가 **AlphaTensor-Quantum**.

      - DeepMind의 AlphaTensor를 양자회로 합성에 적용한 버전.
      - RL 에이전트가 다중 텐서 연산을 분해하면서, T-gate 수를 최소화하는 새로운 회로 구조를 “직접 발견”하는 AI.

        - 목표: T-gate 수 최소화
        - Action space: tensor decomposition
        - RL agent가 T-count 최적화 회로 생성
        - domain knowledge(특수 Toffoli gadget 등)를 추가하면 성능 증가
    - 또 다른 핵심 예시는 **GPT-QE(Quantum Engergy)**.

      - transformer가 회로 토큰을 생성
      - loss = 에너지 기대값
      - backprop으로 transformer 학습
      - 결과: 실제 Hamiltonian의 ground state 회로를 점점 더 잘 생성
    - 즉, “회로를 생성하는 GPT” 등장 → 양자회로 LLM 시대.

**💡3.2 Parameter Learning & Transfer**

- - VQE·QAOA 등 variational 회로는 파라미터 최적화가 매우 중요.
  - 문제:

    - 매번 새 문제마다 최적화하면 비용 너무 큼
    - barren plateau 문제로 gradient가 사라짐
  - AI 해결책:

    - 그래프 embedding(Graph2Vec 등)으로
    - 문제 간 유사도를 기반으로 **파라미터 전이(transfer)**
    - meta-learning 알고리즘으로 “학습 방법을 학습”
  - 효과:

    - 최적화 시간이 수배~수십배 줄어듦
    - plateau 문제 완화

**💡3.3 State Preparation**

- - 특정 상태(|ψ⟩)를 생성하는 회로는 원래 exponential depth가 필요.
  - AI 접근:

    - RL agent가 minimal-depth 회로를 찾음
    - genetic algo, Bayesian Optimization 등 다양한 heuristic 병행
    - GPT-QE 회로 생성도 상태 준비에 활용 가능
  - 결과:

    - 기존 대비 훨씬 짧고 효율적인 상태 준비 가능
    - 실험에서 fidelity도 향상

**✅4. AI for Device Control and Optimization**

- - 이 섹션은 AI가 “연구원 대신 장치를 자동 튜닝”하는 내용을 강조.

**💡Semiconductor Quantum Dots**

- - AI 적용이 가장 활발한 분야.
  - **기존 문제:**

    - 게이트 전압 수십 개 이상
    - tuning point 찾기 어려움
    - dot 형성 과정도 비선형적
  - **AI 해결:**

    - CNN으로 charge stability diagram 자동 분석
    - Bayesian Optimization으로 coarse tuning → fine tuning
    - RL로 transport feature 탐색
    - full automation으로 single spin qubit tuning 성공

**💡Superconducting Qubits**

- - AI가 다음을 자동화:

    - qubit characterization
    - mid-circuit measurement 최적화
    - initialization fidelity 향상
    - cavity state control
  - 특히 “model-free RL”은 noise model 없이 pure measurement만으로 control policy 학습.

**💡NV Centers / Trapped Ions / Photonics**

- - 공통점:

    - 환경 잡음(nuclear bath 등) 학습
    - 실시간 Hamiltonian 업데이트
    - multi-parameter calibration 자동화
  - 핵심 메시지:

> ***수동 튜닝 시대가 끝나가고 있고, 완전 자동화가 가능해지고 있다.***

---

**✅5. AI for Quantum Error Correction (QEC)**

- - 가장 중요한 섹션 중 하나.

**💡5.1 Decoding — AI가 기존 디코더를 뛰어넘는 방법**

- - 전통적인 디코더(MWPM)는:

    - scalable하지만
    - time constraint(수백 ns) 하에서 처리 어려움
    - correlated noise를 잘 못 다룸
  - **CNN (Convolutional Neural Network) 기반 디코더**

    - 공간 패턴 인식
    - 4D toric code threshold ~7.1%
    - 공간적 지역성을 잘 포착
  - **LSTM (Long Short-Term Memory)**

    - 시간 패턴 인식
    - syndrome sequence의 시간적 상관성을 포착
    - 구글 Sycamore 데이터에서 outperform
  - **Transformer**

    - 스케일링 & 전이학습
    - variable-length input 대응
    - 작은 코드에서 학습 → 더 큰 코드로 전이 가능
    - 디코더 재훈련 비용 감소
  - **GNN (Graph Neural Network)**

    - syndrome graph를 직접 처리
    - 선형 시간 inference
    - qLDPC에서도 최고 성능
  - **RL 기반**

    - 정책 기반으로 적응형(decision-making) 디코딩
    - faulty measurement, time-correlated noise 대응
    - decoder weight 조정에 활용 가능
  - 핵심 결론:

> ***AI 디코더는 정확도와 속도 두 면에서 차세대 QEC의 필수 기술.***

**💡5.2 Code Discovery — 새로운 오류보정 코드 자체를 AI가 발견**

- - 이건 더 혁신적.
  - **RL agent가 직접 stabilizer code를 설계**

    - 특정 hardware에 최적화된 코드 생성
    - tensor network code geometry 최적화
  - 예:

    - random search 대비 수십배 효율적
    - noise-aware meta-RL agent → 다양한 노이즈 모델에도 강건
    - distance-5 코드 직접 발견
  - 즉:

> ***향후 QEC 코드의 상당 부분은 AI가 직접 설계할 수 있다.***

---

**✅6. AI for Postprocessing**

- - 양자컴퓨터가 출력한 noisy measurement 데이터를 AI가 후처리.

**💡6.1 Observable Estimation & Tomography**

- - Tomography = “보이지 않는 내부 상태를 여러 각도에서 측정해 재구성하는 기술”

    - CT(Computed Tomography)
  - Quantum Tomography (양자 토모그래피)

    - 많은 종류의 측정 데이터를 모아서 미지의 양자 상태 또는 양자 게이트를 완전히 재구성하는 과정
  - 문제:

    - 샘플을 많이 모아야 함
    - tomography는 exponential cost
  - AI 솔루션:

    - ShadowGPT: GPT가 shadow tomography 데이터로 ground-state 등 예측
    - CNN tomography: 기존 Bayesian/MLE보다 error 10배 감소
    - NAQT: RNN으로 adaptive tomography 수행 → 매우 적은 샘플로 정확도 향상

**💡6.2 Readout Measurements**

- - AI로 측정 fidelity 향상:

    - 중성원자 → CNN으로 readout error 56% 감소
    - 이온트랩 → nonlinear NN readout
    - BEC(Bose–Einstein Condensate) 중성원자 → AI-enhanced measurement
  - QEC을 위해 반드시 필요한 요소.

**💡6.3 Error Mitigation**

- - NISQ + 초기 FT 단계에서 매우 중요.
  - **AI를 이용한 PEC(Probabilistic Error Cancellation) / ZNE (Zero-Noise Extrapolation)개선**

    - Random Forest가 ZNE보다 consistently 더 높은 정확도
    - 100-qubit까지 실험적으로 적용
    - small circuits 데이터로 large circuits extrapolation 가능
  - 또한:

    - NN으로 noisy state → purified state 변환
    - autoregressive NN을 이용한 energy minimization 기반 error mitigation
  - 핵심 메시지:

> ***AI는 QEM을 실제 유용한 기술로 만드는 핵심 수단.***

**✅7. Outlook — 앞으로 무엇이 중요한가**

**💡****7.1 Quantum + AI Supercomputing Integration**

- - GPU + QPU + ultra-low-latency network 필요
  - QEC decoding은 classical accelerator와 밀접 통합 필요
  - Hybrid workflow SDK, AI copilot 필수
  - 그들은 이것을 **Accelerated Quantum Supercomputing System**라고 부른다.

**💡****7.2 High-quality Dataset 문제**

- - 실험 데이터가 부족
  - 시뮬레이션 + Neural Quantum States로 대체
  - Fourier Neural Operators(FNO)로 long-time evolution 예측까지 가능

**💡****7.3 Multidisciplinary Collaboration**

- - QC 전용 foundational model 필요
  - AI-assisted quantum algorithm discovery 가능성
  - 이미 회로 생성 알고리즘은 존재 → 전체 알고리즘 레벨까지 확장 가능

> ***AI는 개발 속도를 ‘가속’할 수 있지만,***
>
> ***FT 하드웨어 자체를 대체할 수는 없다.***

> ***AI와 Quantum이 서로의 한계를 메워주는 공진 구조(co-evolution)가 될 것***
>
> ***(AI가 양자를 키우고, 양자가 AI를 지속가능하게 만들고)***

**📌 전체 결론**

1. 1. **AI는 양자컴퓨팅 전체 스택에 필수적인 요소가 되었다.**
   2. **특히 QEC, 회로 합성, 디바이스 튜닝, 에러 완화에서 뛰어난 성능.**
