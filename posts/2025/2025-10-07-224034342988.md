**✅주파수 대역**

**💡****적외선 통신 대역**

|  |  |  |  |
| --- | --- | --- | --- |
| **밴드** | **파장 범위 (nm)** | **중심 파장 (nm)** | **주요 특징 / 용도** |
| O-band  (Original) | 약 1260 – 1360 | ~1310 | 초기 광통신 대역, 분산이 낮은 구간 (near zero dispersion) |

**💡WDM**

- - 아래 그림은 WDM 이라는 기법을 이용할 경우 사용할 수 있는 주파수대역(파장-Wavelength)를 보여준다.
  - 지난 포스팅에서 언급한 바와 같이 O-Band도 일정 거리를 넘어가면 신호 손실이 커서 C-Band를 이용해야 한다. 하지만 인간의 위대함은 여기에서 한번 더 발현한다.
  - 예를 들어 A에서 50Km 떨어진 B 구간까지 여러명이 아주 다양한 용도로 통신을 하고자 할 경우, 각 용도별로 광섬유가 필요할 것이다. 이때, 광섬유를 절약하는 방법이 WDM(Wavelength Division Multiplexing)이다.
  - 동일한 광섬유를 이용하되, 서로 다른 파장을 이용하는 원리다. 문과 출신이어도 AM, FM은 다 알것이고, 이과 출신이라면 TDM(Time Divison Multiplexing), FDM(Frequency Division Multiplexing)이란 단어는 한번쯤 들어봤을 것이다.

**💡CWDM과 DWDM**

- - 아래처럼 서로 다른 대역의 파장을 사용하는 유저가 MUX(서로 다른 파장의 광 신호를 합치는 장비를 일컫는다. Multiplexer를 줄여서 MUX라고 부르고, 동일한 기능을 하는 상대측 장비에서 합쳐진 신호를 다시 분리해서 해당 유저한테 전달해주는 장비를 DEMUX- Demultiplexer라고 부른다)와 DEMUX를 통해서 하나의 물리적인 광섬유를 통해 서로 섞이지 않게 전달하게 된다.
  - 이때 사용하는 다양한 파장을 위의 O-Band에서 L-Band사이에서 나눠 사용하게 되는데, 20nm 단위로 잘라서 사용하는 기술을 CWDM(Coarse WDM)이라 부르고, 0.8nm 단위로 잘라서 사용하는 기술을 DWDM(Densed WDM)이라고 한다.

**✅****중심파장이란?**

**💡****파장 대역은 연속적 → 대표값 필요**

- - O-band, C-band, L-band 같은 대역은 범위(예: C-band = 1530~1565 nm)로 정의된다.
  - 하지만 설계, 측정, 문서화에서는 “대표 값”이 필요합니다. → 그래서 **중심 파장 (~1550 nm)** 같은 값을 지정하는 것.

**💡****분산(Dispersion) 및 손실 최적점**

- - 광섬유는 특정 파장 근처에서 **분산이 최소** 또는 **손실이 최소**가 된다.
  - 예: 1310 nm (O-band): 분산 거의 0 → 초기 이더넷 전송에 사용.
  - 1550 nm (C-band): 손실 최소 + EDFA 증폭 가능 → 장거리 전송에 최적.
  - 따라서 중심 파장은 보통 **그 밴드에서 가장 성능이 좋은 지점**을 기준으로 잡음.

**💡****표준화 (ITU-T DWDM Grid)**

- - ITU-T는 DWDM (Dense Wavelength Division Multiplexing)을 위해 **ITU Grid** 라는 채널별 기준 파장(예: 1550.12 nm, 100 GHz 간격)을 정의했다.
  - 이때 “중심 파장”은 각 채널이 **정렬되는 기준값**이 됩니다.
  - 예: 채널 중심 파장 = 1550 nm ± 0.05 nm → 여기에 맞춰 레이저/필터/증폭기를 설계.

**💡****레이저 및 필터 설계**

- - 실제 레이저는 한 점이 아니라 좁은 **스펙트럼 폭**을 가집니다.
  - 데이터시트나 표준에서 “중심 파장”을 지정하면, 그 값 기준 ± 허용치 안에서 동작한다고 정의.
  - 필터나 AWG (Arrayed Waveguide Grating) 같은 다중화 장치도 **중심 파장**을 기준으로 설계됨.

**💡****실험 및 측정 편의**

- - 시험 장비(광 파워미터, OSA 등)는 특정 기준 파장을 두고 교정됩니다.
  - 그래서 “중심 파장에서의 출력, 삽입 손실, 이득” 같은 값을 스펙에 기재.

**✅****중심파장이 아닌 다른 파장을 사용하면?**

**💡****고전 통신과 중심파장**

- - **고전 통신**에서는 ITU Grid에 맞춰 **중심 파장**을 채택한다.

    - 이유: EDFA, 필터, DWDM 채널, 표준 장비가 다 그 기준에 맞춰져 있음.
    - 따라서 **채널 간 간섭 최소화**, **증폭기 최적 동작**, **장비 호환성** 확보.

**💡****양자통신에서 1350 nm 같은 비표준 파장 사용하는 이유**

- - 양자 메모리 인터페이스(예: SiV, Ba⁺, NV 등)의 원래 방출 파장(737 nm, 493 nm 등)을 변환하다 보면 **ITU 중심 채널에 정확히 맞추기 어려움**.
  - 그래서 “QPM 조건이 잘 맞는 PPLN 조합”이나 “잡음 억제 최적점”을 고려해 1350 nm 같은 **중간 지점**을 선택하는 경우가 있음.
  - 즉, **실험적 타협**이지, 표준 파장 선택은 아님.

**💡****1350 nm를 쓸 때 발생하는 문제**

1. 1. **증폭기 호환성 문제**

      - EDFA는 **C-band(1530–1565 nm)**, L-band(1565–1625 nm)에서만 동작.
      - 1350 nm는 증폭 불가 → 장거리 전송 시 **광손실 보상 불가**.
      - 고전 채널(동기/클록 신호) 증폭기도 못 씀.
   2. **섬유 감쇠(attenuation)**

      - SMF-28 기준 감쇠:

        - 1310 nm 근처 → 0.35 dB/km
        - 1550 nm 근처 → 0.2 dB/km
        - 1350 nm → 더 나쁨 (≈ 0.4 dB/km 이상 가능).
      - 따라서 **손실이 더 크다** = 긴 거리 전송에 불리.
   3. **표준 장비 미지원**

      - DWDM 필터, OADM, AWG 같은 장비들이 ITU Grid 기준(1310, 1550 등)으로 설계됨.
      - 1350 nm는 맞는 필터/채널 모듈 없음 → **장비 호환성 낮음**.
   4. **노이즈 억제 & Raman 산란**

      - 펌프 레이저와 출력 간격 때문에 Raman 잡음 억제가 잘 되는 장점이 있긴 하지만,
      - **상용 부품과 안 맞으니** 결국 연구용 특수 설정 필요 → 상용화 어려움.

**💡****그래서 연구자들이 하는 선택**

- - **실험 단계**: 1350 nm 같은 최적화된 파장 사용 → QPM 조건·잡음 억제 우선.
  - **실용화 단계**: 다시 C-band (1550 nm)로 변환 → 기존 인프라 활용 가능.
  - 실제로도 “737 → 1350 nm (잡음 억제 쉬움) → 1550 nm (표준 전송)” **이중 변환 경로**가 자주 쓰다.

**✅****EDFA(Erbium-Doped Fiber Amplifier)란?**

**💡****기본 개념**

- - EDFA는 **에르븀(Er****3+****) 이온**이 도핑된 광섬유를 활성 매질로 사용한다.
  - 980 nm 또는 1480 nm의 펌프 레이저로 이 에르븀 이온을 들뜨게 시킨 뒤,
  - 1550 nm 근처(즉, 텔레콤 C-band)의 광신호가 지나가면 **자발 방출/유도 방출**로 신호 광자를 증폭시킨다.

**💡****동작 원리**

1. 1. **펌핑**

      - 외부 레이저(980 nm or 1480 nm)를 EDFA에 쏘아 Er**3+** 이온을 들뜬 상태로 올림.
   2. **증폭**

      - 1550 nm 신호광이 들어오면, 들뜬 이온이 에너지를 잃으며 **같은 위상·같은 파장의 광자**를 추가로 방출.
      - 결과적으로 입력 신호가 그대로 증폭.
   3. **출력**

      - 수십 km를 전송해도 신호 세기가 크게 줄지 않고 유지됨.

**💡****장점**

- - **광-전 변환 필요 없음** → 전자 회로 거치지 않고 **광 도메인에서 직접 증폭** 가능.
  - **저잡음** → ASE(Amplified Spontaneous Emission) 잡음은 있지만, 다른 방식보다 SNR 손실이 적음.
  - **대역폭** → 1530–1565 nm (C-band), 1565–1625 nm (L-band) 증폭 가능.
  - **광섬유 통신** 표준에 최적화 → 수백 km 장거리 전송 가능.

**💡****양자통신/네트워킹에서의 의미**

- - EDFA는 원래 **고전 광통신**용 장비지만, 양자 네트워크 실험에서도 종종 **클록(reference pulse)** 같은 **고전 신호**를 증폭할 때 사용된다.
  - 그러나 **단일광자(큐비트 신호)** 에 직접 쓰지는 않는다 → ASE 잡음이 큐비트 fidelity를 깨뜨리기 때문.
  - 그래서 보통은 **1550 nm 참조 타이밍 채널**만 EDFA로 증폭하고, 실제 양자 채널(단일광자)은 **저잡음 검출기(SNSPD 등)** 로 처리한다.

**💡****양자 채널 장거리 해법**

- - 양자 채널 자체는 **EDFA 증폭 불가**라서 별도의 기법이 필요하다:
  1. **양자 리피터(Quantum Repeater)**

     - 중간 노드에 **양자 메모리(Lightsynq 등)** 를 두고,
     - 구간별로 얽힘 분배 → 스와핑·정제 과정을 반복.
     - 목표: 수백 km~1000 km 이상 확장.
  2. **위성 기반 전송**

     - 대기 감쇠(0.1~0.2 dB/km 수준)만 거치므로 수백~수천 km 가능.
     - 중국의 Micius 위성이 대표 사례.

---

**✅****여전히 1550nm으로의 주파수 변환이 필요한가?**

- - 결론부터 말하자면 여전히 의미가 크다.

**💡****파이버 감쇠 최소점**

- - 1550 nm 부근은 **광섬유 손실이 최소 (≈0.2 dB/km)** 이다.
  - O-band(1310–1350 nm)는 **≈0.35 dB/km** 정도 → 거리가 길어질수록 차이가 크다.

    - 예: 200 km 전송 시

      - 1350 nm: 약 70 dB 손실
      - 1550 nm: 약 40 dB 손실
  - 단일광자 수준에서는 이 차이가 **생존 확률**에 직결된다.

**💡****WDM 통합 인프라**

- - 실제 양자 네트워크는 **양자 채널(O-band 또는 변환된 C-band) + 고전 채널(C-band)** 을 같은 파이버에 넣는다.
  - 만약 양자 채널을 1350 nm로 그대로 보내면:

    - 필터, OADM, AWG 같은 **상용 부품** 호환성이 낮음.
  - 1550 nm로 변환하면:

    - 기존 **DWDM Grid** 위에 그대로 얹을 수 있음.
    - 고전 채널 장비와 **인프라 공유**가 가능해져서 상용화 측면에서 유리.

**💡****집적 포토닉스 / 검출 효율**

- - SNSPD 같은 초전도 단일광자 검출기는 **1550 nm 최적화 버전**이 가장 많이 쓰인다.
  - 1350 nm는 여전히 잡음 필터링과 효율 최적화에서 도전이 큼.
  - 따라서 변환 후 1550 nm에서 검출하는 게 **검출 효율·SNR 최적화**에 유리.

**💡****장거리 확장(리피터/위성)**

- - 리피터 없이 수백 km 이상은 불가능 → 결국 얽힘 스와핑/정제를 써야 함.
  - 이때도 **1550 nm 대역에서 노드 간 전송**이 더 효율적 → 표준 DWDM·코어 네트워크 장비 활용 가능.

**✅****양자통신에 고전 채널이 필요하다고?**

- - ⏱ 동기화

    - 민감한 단일 광자의 도착시간을 공유
  - 🎛 위상 안정화

    - 온도 및 진동으로 인해 위상이 흔들리는 것을 PID 제어루프를 돌려 간섭 안정성 유지
  - 🔄 편광 보정

    - 광섬유의 편광이 꼬이거나 섞이면 큐비트 에러가 발생되기 때문에, 고전채널로 참조 신호를 보내어 보정함.
  - 🔐 QKD 프로토콜 메시지 교환

    - Base Reconcilation(기지선 공개)
    - 오류율 추정
    - 비밀키 증류
  - 🔗 얽힘 스와핑/리피터 제어

    - 두 끝단이 얽혀 있다는 것을 고전 채널로 알려야 함.
    - Bell State Measurement (BSM)을 하면, 네 가지 결과(Φ⁺, Φ⁻, Ψ⁺, Ψ⁻) 중 하나를 출력하는데,
    - 이를 구분하여 상대에게 전달하기 위해 2비트 정보 (00, 01, 10, 11)이 필요하다.
  - 📡 인증·네트워크 제어

    - QKD 자체는 무조건 인증된 고전 채널이 필요함.

**✅****그래서 멀리 보내려면 어떻게 해야 하는데?**

**💡****직접 전송의 한계**

- - 1350 nm에서 100 km → 손실 약 35 dB (1억 분의 1 수준).
  - 단일광자 수준에서는 검출기 효율까지 고려하면 사실상 수백 km는 불가능.
  - 위 실험에서는 50km 구현

**💡****해법 A: 1350 → 1550 nm 변환 (QFC)**

- - 양자 채널을 C-band로 변환 후 전송 → 손실 최소점(0.2 dB/km).
  - 그래도 EDFA 증폭은 못 쓰지만, 최소한 감쇠가 줄어 “생존 확률”이 높아짐.
  - 고전 채널 사용 옵션

    - WDM 이용

      - 고전 채널에서 사용하는 전력은 수mW 수준인데 반해, 양자 채널에서 사용하는 전력은 수pW 수준
      - 전력 차이가 109 ~ 1012 배 이상 나기 때문에 서로 간섭이 생기기 쉬움.
      - →두 채널을 수십 nm 이상 떨어진 파장에서 배치해야 하므로, **양자 채널을 1550nm 사용시, 고전채널은 1590nm 또는 1610nm 사용해야함**. (**CWDM 가능**)
    - 별도의 광섬유 이용

      - 광섬유 비용 추가.

**💡****해법 B: 양자 리피터 (Quantum Repeater)**

- - 중간 노드에 **양자 메모리(SiV, NV, Lightsynq 모듈)** 배치.
  - 구간별로 얽힘 생성 → 스와핑·정제 → 장거리 확장.
  - **양자 채널 : 1350nm**
  - **고전 채널 : 1550nm**
  - 40 ~ 80km 마다 양자 리피터를 두고, 지속적으로 증폭을 해야하기 때문에 현실적인 한계

    - 실 환경에서는 더 짧을 수 있음
    - SNSPD를 사용하면 거리를 늘릴 가능성 있음.

**💡****해법 C: 위성 링크**

- - 자유공간 광통신에서는 손실이 훨씬 적음 (≈0.1 dB/km 수준).
  - 중국 “Micius” 위성이 이미 1200 km QKD 성공.
  - **양자 채널** : 1350nm도 사용 가능하지만 **1550nm**가 더 효과적

    - 대기 투과창(transmission window)이 여럿 존재

      - 800–900 nm
      - 1064 nm
      - 1310 nm (O-band 중심)
      - 1550 nm (C-band 중심)
    - 1350nm는 물(H2O)과 CO2 흡수선이 간헐적으로 있어서 전송 효율이 낮기 때문에 1550nm가 더 효과적
    - 실제로 대다수 위성 QKD 프로젝트(예: 중국 *Micius*, ESA 실험)에서는 **850/1064/1550 nm** 를 주로 사용됨
    - 1550nm는 eye-safe limit 때문에 고출력 레이저 사용이 용이함.
  - **고전 채널 : 1590nm** 사용가능.

---

**✅결론**

- - **단기(1–3년)** → **해법 A (QFC + 1550 변환)**

    - 기존 광망과 결합 가능 → Telco/데이터센터에 바로 적용 가능.
  - **중기(5–10년)** → **해법 C (위성 링크)**

    - 국가/군사/대륙간 보안 네트워크에 점차 보급.
  - **장기(10년 이상)** → **해법 B (양자 리피터) + SNSPD 이용**

    - 진정한 글로벌 “양자 인터넷”을 위한 핵심이지만 아직 먼 미래.
