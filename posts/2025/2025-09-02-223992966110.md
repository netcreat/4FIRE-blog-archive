**✅****마이크로소프트의 토폴로지컬 큐비트 비전**

Microsoft는 **스케일 가능한 양자컴퓨터**를 실현하기 위해 **토폴로지컬 큐비트** 개발에 집중한다.

양자기술이 발전할수록 우리는 기존 컴퓨팅으로는 풀기 어려운 문제들에 다가가고 있지만, **큐비트의 취약성**은 여전히 가장 큰 장벽 중 하나다.

- **문제**:

  - 큐비트는 환경 간섭(thermal noise, charge fluctuation, EM interference 등)에 매우 민감해 **쉽게 붕괴**한다.
- **목표**:

  - 토폴로지컬 특성을 이용해 **잡음 내성이 강하고 안정적인 큐비트**를 구현해 더 긴 시간, 더 복잡한 연산을 가능하게 한다.
- **전략**:

  - Microsoft는 **마요라나 제로 모드(MZM)** 기반 토폴로지컬 접근을 선택해 **논리 큐비트 당 물리 큐비트 수를 최소화**하는 로드맵을 추진한다.

**✅****토폴로지컬 큐비트의 핵심 원리**

**💡****토폴로지(Topology) 개념 적용**

- - 토폴로지는 **휘어지고, 비틀리고, 압축되고, 늘어나도 변하지 않는 성질**을 다루는 수학 분야다.
  - 이 성질을 양자컴퓨팅에 적용하면, **큐비트의 논리 상태**를 **위상적(global) 특성**에 저장할 수 있어 국소적 잡음(local noise)에 강해진다.

**💡****두 가지 보호 메커니즘**

- - **전자 분수화(Electron Fractionalization)**

    - 전자를 **두 개의 마요라나 모드**로 분리해 **양자정보를 각각에 나눠 저장**한다.
    - 마치 **RAID-1 미러링**처럼, 한 쪽이 손상되더라도 다른 쪽에서 정보를 복원 가능.
    - MZM이 서로 충분히 멀리 떨어져 있으면 간섭을 거의 받지 않음.
  - **바닥 상태 퇴화(Ground State Degeneracy)**

    - 토폴로지컬 큐비트는 **두 개의 독립적 바닥 상태**를 가지도록 설계된다.
    - 일반 시스템에서는 두 바닥 상태를 구분하기 어렵지만,
    - **토폴로지컬 시스템**에서는 **브레이딩(braiding)** 또는 위상 측정(topological measurement)을 통해 상태를 구분 가능.
    - 결과적으로 환경 잡음에 매우 강한 큐비트 구현이 가능해진다.

**✅****Microsoft의 토폴로지컬 큐비트 개발 과정**

**💡****연구 초기 단계**

- - 시작점: “**토폴로지컬 큐비트를 구현할 수 있는가?**”라는 질문에서 출발.
  - Microsoft는 수학자, 물리학자, 재료과학자, 엔지니어, 컴퓨터 과학자 등 다양한 전문가를 모아 **Station Q**를 설립.
  - 이론 모델을 기반으로 수많은 방정식을 풀고 시뮬레이션을 반복하며 토폴로지컬 큐비트의 가능성을 탐구.

**💡****실험적 접근**

- - **초전도체 + 강한 자기장**을 활용해 위상적 상전이(topological phase transition)를 유도.
  - **선택적 영역 성장(Selective Area Growth, SAG)** 기술 도입:
  - 원자 수준에서 필요한 위치에만 특정 화합물을 증착.
  - 마치 “원자 스프레이”처럼 **큐비트 표면층을 원자 단위로 설계**.
  - InAs-Al 나노와이어 기반 마요라나 제로 모드 실험 → **Albrecht 2016 Nature 논문**에서 초기 증거 확보.

**💡****모델링 + 시뮬레이션 + 제작 + 측정**

- - Microsoft는 토폴로지컬 큐비트 개발을 위해 네 가지 기술 축을 병행한다:

|  |  |  |
| --- | --- | --- |
| **분야** | **목표** | **주요 내용** |
| **이론 & 시뮬레이션** | 모델 검증 | 토폴로지컬 상태 안정성 분석, 설계 최적화 |
| **제작(Fabrication)** | 칩 프로토타입 | 나노 단위의 초전도-반도체 하이브리드 제작 |
| **재료 성장(Materials Growth)** | 표면 품질 확보 | 선택적 영역 성장(SAG), 나노스케일 표면 정밀 제어 |
| **측정 & 제어(Measurement & Control)** | 동작 검증 | 마요라나 신호 검출, 브레이딩 실험 준비 |

**✅****토폴로지컬 큐비트의 의미와 미래**

**💡****Microsoft 전략적 의도**

- - Google, IBM 등은 **표면 코드(Surface Code)** 기반 대규모 오류 정정을 목표로 하지만,
  - Microsoft는 **물리적으로 안정적인 큐비트 자체**를 만드는 데 집중한다.
  - 목표:

    - 1개의 논리 큐비트를 구현하는 데 필요한 **물리 큐비트 수**를 획기적으로 줄임 → **스케일링 효율 극대화**.

**✅****Microsoft의 마요라나 개발 연대기**

**💡****2005~2009년 — Station Q 설립과 초기 이론 연구**

- - **2005년**:

    - Microsoft가 미국 캘리포니아 산타바바라(Santa Barbara)에 **Station Q**라는 양자연구소 설립.
    - 창립자는 **Michael Freedman**

      - 필즈상 수학자, 위상수학(topology) 전문가.
      - 목표: 위상적 보호(topological protection)를 이용한 **오류율이 극도로 낮은 토폴로지컬 큐비트** 개발.
  - 초기 연구 방향:

    - 토폴로지컬 상태를 통한 **브레이딩(braiding)** 연산 이론.
    - 마요라나 페르미온의 존재 가능성에 대한 수학적 모델링.

**💡****2010~2012년 — 마요라나 제로 모드 실험 제안**

- - Microsoft 연구진과 외부 이론가(예: Chetan Nayak, Sankar Das Sarma 등)가

    - **반도체 나노와이어 + 초전도체** 구조에서 마요라나 제로 모드를 만들 수 있다는 예측 논문 발표.
  - 제안된 플랫폼:

    - **InAs 또는 InSb 나노와이어** + **Al 초전도체**.
    - 강한 스핀-궤도 결합 + s-파 초전도 갭 + 자기장 = 위상 초전도 상태.

****

**💡****2016년 — Albrecht 실험 & Microsoft-코펜하겐 Station Q**

- - **2016년**, **Charles Marcus**(코펜하겐 대학 교수, 당시 Microsoft Station Q 소속) 연구팀에서

    - 네이처(Nature)에 역사적인 논문 발표:
    - **Albrecht et al., “Exponential protection of zero modes in Majorana islands”**.
  - 실험에서 **InAs-Al 나노와이어**에서 MZM을 관측하고,
  - 나노와이어 길이에 따라 에너지 분리(ΔE)가 **지수적으로 감소**하는 것을 확인.

    - 이 시점부터 Microsoft는 **코펜하겐 대학 Niels Bohr Institute**와 긴밀히 협력.

****

**💡****2018년 — Delft QuTech 합류**

- - Microsoft는 **QuTech**(네덜란드 Delft University + TNO 합작 연구소)와 파트너십 체결.
  - Delft에서는 **Leo Kouwenhoven** 교수가 Microsoft Station Q 소속으로 합류.
  - 목표: InAs-Al 기반 나노와이어 어레이로 **마요라나 브레이딩(braiding)** 실험 시도.
  - 하지만, **2021년 Nature 2018 논문 데이터 조작 논란**으로 Kouwenhoven 그룹 실험은 사실상 중단됨.

****

**💡****2019~2022년 — 위상적 큐비트 전략 유지**

- - Kouwenhoven 사건 이후에도 Microsoft는 **Charles Marcus** 그룹(코펜하겐)과 협력을 유지.
  - 초점은 **InAs-Al 하이브리드 나노와이어**를 대규모 집적하는 방법으로 이동.
  - Station Q 내부에서는

    - **Michael Freedman** + **Chetan Nayak**(이론) + **Charles Marcus**(실험) 3인 축으로 계속 진행.

****

**💡****2023년~현재 — Azure Quantum + Atom Computing 협력**

- - **2023년**: Microsoft는 Station Q 프로젝트를 **Azure Quantum** 전략에 통합.
  - 목표: 마요라나 기반 토폴로지컬 큐비트를 **Azure 클라우드 서비스**와 연결.
  - **2024년 말**: Microsoft가 **Atom Computing**과 협력 발표

    - → 중성 원자 기반 QPU와 Azure Quantum 플랫폼을 통합하는 로드맵 공개.
    - → 하지만, **토폴로지컬 큐비트 자체는 여전히 InAs-Al 플랫폼에서 진행 중**.

**✅****Microsoft의 전략적 특징**

- - 구글·IBM과 달리 **대규모 오류 정정(QEC)** 대신,
  - **"물리적으로 에러율을 낮추는"** 토폴로지컬 큐비트를 선택.
  - 목표는 **하나의 논리 큐비트를 구현하기 위한 물리 큐비트 수**를 최소화하는 것.
  - InAs-Al 플랫폼을 표준화하여, 칩 수준에서 나노와이어 어레이를 제작 → Azure Quantum과 연동 목표.

Microsoft는 20년동안 마요라나 제로 모드(MZM) 기반 토폴로지컬 큐비트를 연구하였는데, 아직 완전한 시제품이라고 부를만한 칩은 평가가 충분이 끝난 상태가 아니다.

**✅****왜 20년 동안도 완전한 평가를 못받았나**

**💡****MZM 존재 자체를 완전히 증명 못함**

- - InAs-Al 나노와이어 실험에서 제로바이어스 피크(Zero-Bias Peak, ZBP)가 나타나면 보통 MZM의 간접 증거로 해석한.
  - 하지만 **Andreev bound states** 같은 다른 준입자 효과도 **똑같은 신호를 만들 수 있음**.
  - 따라서 **관측 신호가 진짜 MZM인지** 명확히 증명하지 못해 논란이 계속됨.
  - 2018년 Delft Kouwenhoven 논문 → **Nature 철회**

    - Microsoft 코펜하겐 팀(Charles Marcus 그룹) 데이터 재해석 중

**💡****토폴로지컬 큐비트의 물리적 제약**

- - 토폴로지컬 큐비트의 장점은 **노이즈 내성**인데, MZM을 제대로 분리하려면 다음 조건이 필요:

    - **초전도 갭 Δ** 충분히 커야 함
    - **와이어 길이 L** → coherence length ξ보다 훨씬 길어야 함
    - **자기장 B** → Zeeman field 안정적 제어 필요
  - 실제로는 **와이어 품질, Al 증착 균일성, 게이트 노이즈** 등 물리적 제약이 많아 MZM 국소화(localization)가 어렵다.

**💡****브레이딩(braiding) 실험 실패**

- - 토폴로지컬 큐비트의 핵심은 마요라나 교환 연산(braiding)인데,
  - **MZM 존재 → 브레이딩 성공**을 보여준 실험은 **전 세계적으로 한 건도 없음**.
  - Microsoft Majorana 1 역시 **8큐비트 칩**을 발표했지만,

    - 브레이딩 실험 결과 없음
    - 논리 게이트 증명 없음
    - 오류율(fidelity) 데이터 없음

**💡****Majorana 1(2025) 칩의 현재 완성도**

|  |  |  |
| --- | --- | --- |
| **항목** | **Microsoft 주장** | **실제 평가** |
| **큐비트 개수** | 8개의 토폴로지컬 큐비트 | 확인됨 |
| **오류율** | 아직 발표 안 함 | 미측정 |
| **브레이딩 성공 여부** | 목표로 제시 | 미실현 |
| **MZM 검증** | 내부 데이터 보유 | 학계 합의 없음 |
| **상용화 가능성** | 수년 내 가능성 언급 | 대부분 전문가들은 신중론 |

**💡****전문가들의 시각**

- - **긍정론**

    - Majorana 1은 **첫 하드웨어 프로토타입**으로서 의미가 큼.
    - 토폴로지컬 물질 ‘topoconductor’ 기반 설계는 획기적.
  - **회의론**

    - 아직까지 MZM 존재 자체를 명확히 입증 못했는데,
    - Microsoft가 **상업화 로드맵**을 발표한 건 너무 빠르다는 지적.
    - 2018 Delft 논란 이후 학계가 전반적으로 보수적으로 변함.

**💡****결론**

- - Microsoft는 **20년간** 토폴로지컬 큐비트에 올인했지만 **완전한 MZM 검증**과 **브레이딩 실험 성공**을 아직 보여주지 못함.
  - **Majorana 1**은 역사적으로 중요한 첫 칩이지만, **아직 시제품 수준**이고 실질적 완성도는 낮은 편.
  - 상업화까지는 **적어도 5년~10년 이상** 더 필요하다는 게 대체적 전망
