위 그림은 이온기반의 큐비트에서 광자로 변환되어 최종적으로 1550nm 통신 파장으로 바뀌는 모습을 나타낸다.

물론 거리가 가까우면 두번째 파장 변환은 필요 없다.

그리고, 수초내의 동기화가 필요하지 않다면 우측 상단의 SiV0 Color Center도 필요하지 않다.

실제로 바륨 → 광자 → SiV → 스핀 → 다시 광자 → 다른 QPU 의 여러 단계를 거치게 되어 손실과 오류가 누적되기 쉽다.

이 경우 SiV 없이 직접 통신 파장으로 변환시키는 방법도 고려해볼 수 있으나, 광자수집효율이 낮아지고, 메모리 기능을 사용할 수 없다는 트레이드오프가 있다.

---

**✅** **바륨 이온 → SiV → 다른 QPU 데이터 전송 과정**

****

**1️⃣ 바륨 이온에서 광자 방출**

- - 바륨 이온의 내부 양자 상태(예: 하이퍼파인 상태)를 특정 파장(493 nm) 광자로 매핑해 방출.
  - 이 광자에는 바륨 이온의 양자 정보가 **편광·위상·시간빈** 형태로 담김.
  - **양자 텔레포테이션의 핵심 단계**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfNjQg/MDAxNzU1MjU2NTI5MzM2.7wp63iCt7mCs08TeAqigPR-2_adeW0hP6X5ro-rGXbEg.2Rsqwljsx2DmSd_PxdAXeoXKtZhPi60KzEcEFL8B1kkg.PNG/image.png?type=w800)](#)

**2️⃣ 파장 변환**

- - 이 광자를 QFC(예: PPLN, SiN)를 이용해 SiV의 공명 파장(ZPL, 예: 946 nm 또는 738 nm)으로 변환.
  - 변환 과정에서 **위상·편광 정보가 보존되어야 함**.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfNzkg/MDAxNzU1MjUxMTIzODM2.oEkotDIEp-5Dk_zgHVeyuGOEn9hkwH2adx4m5nbS7Qsg.up_rNdV3IggrBrKOcWAD9gRZNJqRTMGMxkv4L0qWD4Ig.PNG/image.png?type=w800)](#)

**3️⃣ SiV에서 광자 → 전자 스핀 매핑**

- - 변환된 광자가 SiV에 흡수되면서, 광자의 양자 상태가 SiV 전자 스핀에 매핑됨.
  - 전자 스핀은 **네트워크 인터페이스** 역할.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfMjYy/MDAxNzU1MjU2MTk2MDk2.RD3p9yJ0Ggqb7dT2T6vcfVnX2PnGPRmy3zkneK4s1bMg.fK33RF1h_bqCHNyVdNNDzutqhBJoxVcAxVna1ol3-uwg.PNG/image.png?type=w800)](#)

**4️⃣ 핵 스핀에 저장(옵션)**

- - 장거리 전송 전 대기 시간이 길면, 전자 스핀 상태를 **29****Si 핵 스핀**으로 SWAP 전송해 장기 보관.
  - 핵 스핀은 ms 단위가 아닌 초~분 단위 코히런스 유지 가능.

**5️⃣ 다시 전자 스핀으로 불러오기(옵션 : 4️⃣번 선택시)**

- - 전송할 시점에 핵 스핀에서 전자 스핀으로 다시 상태를 옮김

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfMjYy/MDAxNzU1MjU2NTg2ODQy.TmuTxxjQTlbDBP3V4Mx8UQPZZMcOZ8zS4CDvT5qxtOAg.iJCDy4OhHh8UUNY0FbRKnmzkoW4tQ0j1OgDBpJGJnR4g.PNG/image.png?type=w800)](#)

**6️⃣전자 스핀 → 광자로 재변환(방출)**

- - SiV 전자 스핀을 레이저로 여기해 ZPL 파장의 광자를 방출.
  - 이 방출 광자에 원래 바륨 이온에서 왔던 양자 상태가 실림.
  - **두번째 양자 텔레포테이션**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfMjUg/MDAxNzU1MjU2NjMxNDMx.1UcoY6uJpELb11mJ5gGtiU0dsroKkqpEKN6g_Ob7K7sg.DdYx8T9z1Qpu3PLLAUXvqk3oK7GFnESydJsTx4iwWBcg.PNG/image.png?type=w800)](#)

**7️⃣파장 변환 및 전송**

- - 필요한 경우, 방출된 광자를 통신 파장(1550 nm)으로 변환해 광섬유로 전송.
  - 반대편 QPU(바륨, 이터븀, 초전도 등)에서 해당 파장을 흡수해 양자 상태를 다시 QPU 내부 큐비트로 매핑.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTVfMjY1/MDAxNzU1MjUxMjgxNTc2.TxmmRJF_dqfFdEUJdEkzS_MQDGYEQdhaD6TrfEiA8xsg.KYzzFiJ9J2T6H7SbLtzeM7I6nhaiUy-o9TImG1R73egg.PNG/image.png?type=w800)](#)

**💡 핵심 요약**

- - SiV는 단순 중간 저장소가 아니라, **광자 ↔ 스핀** 변환기 역할을 양방향으로 수행해야 함.
  - 바륨 → 광자 → SiV → 스핀 → 다시 광자 → 다른 QPU
  - 이렇게 하면 **양자 상태가 손실 없이 장거리 이동** 가능.

---

**✅** **전자스핀 → 핵스핀 변환 과정**

****

**1️⃣ 준비 단계 — 전자스핀 초기화**

- - 먼저 전자스핀(electron spin)을 원하는 상태로 만들어야 한다.
  - NV- 예시: 532 nm 레이저를 짧게 쏴서 ms = 0으로 초기화 (광학 펌핑)
  - SiV0 / SiV-: 특정 ZPL(946 nm 또는 737 nm)과 마이크로파(MW)·라디오파(RF) 펄스 조합으로 초기화
  - 이 단계가 중요한 이유 → 핵스핀은 직접 광학 초기화가 안 되므로 전자스핀을 통해서만 초기화 가능

**2️⃣ 전자스핀과 핵스핀 결합 (하이퍼파인 상호작용)**

- - 전자스핀과 근처 원자핵이 **하이퍼파인 결합**으로 연결

    - **NV****-****의 경우** **14****N,** **15****N, 또는 근처** **13****C 핵스핀**
    - **SiV****-****의 경우** **29****Si 또는 근처** **13****C 핵스핀**
  - 이 결합은 S⋅I 형태의 상호작용이며, 전자스핀 상태에 따라 핵스핀의 공명 주파수가 달라짐

    - 고체 색중심(SiV)이 다음과 같은 이점이 있음

      - 소형화 및 집적성
      - 높은 광자 간섭 품질
      - 네트워크 노드 확장
  - 즉, 전자스핀을 조건부로 제어하면 핵스핀도 함께 제어 가능
  - 이때 RF 펄스를 이용해 특정 전자스핀 상태에 **조건부 핵스핀 회전(conditional rotation)을 구현**

****

**3️⃣ CNOT 형태의 전이 — 전자 → 핵스핀**

- - 양자정보 이전은 보통 **CNOT 게이트 두 번**과 비슷한 구조로 실행

    1. **전자스핀 → 핵스핀** CNOT: 전자스핀 상태에 따라 핵스핀 뒤집기
    2. **핵스핀 → 전자스핀** CNOT: 핵스핀 상태에 따라 전자스핀 뒤집기
  - 실제 구현에서는 SWAP 게이트를 사용해 전자와 핵스핀의 상태를 완전히 교환
  - 이 과정이 끝나면 전자스핀에 있던 양자상태(혹은 고전 정보)가 핵스핀으로 이동

****

**4️⃣ 핵스핀 저장 (메모리 모드)**

- - **핵스핀은 외부 자기장 변화나 전기장 노이즈에 훨씬 둔감** → 밀리초~초 단위로 결맞음 유지 가능

    - NV-의 경우 13C 핵스핀은 수 초, 15N은 수백 ms
    - **SiV****-**의 경우 29Si 핵스핀은 수ms ~ 수십 ms

      - NV-에 비하면 저장 시간을 짧지만 광학 특성이 훨씬 우수함.
  - 장거리 네트워킹에서는 전자스핀을 다시 사용해야 하므로, 핵스핀에 임시 저장 후 전자스핀을 비워둠

**5️⃣ 복원 — 핵스핀 → 전자스핀**

- - 원할 때 다시 SWAP을 실행하여 핵스핀의 상태를 전자스핀으로 되돌림
  - 이후 전자스핀을 광자와 상호작용시켜(광학 방출) **포토닉 인터커넥트**로 전송 가능

**💡 핵심 요약**

- - **전자스핀 초기화 → 하이퍼파인 결합 이용 → SWAP 또는 CNOT 연산 → 핵스핀 저장**
  - 이 방식은 NV, SiV 모두 가능하지만,
  - NV-: 상온에서도 수 초 저장 가능 (특히 13C 사용 시)
  - SiV0: 전자스핀 코히런스는 짧지만, 핵스핀으로 넘기면 수십~수백 ms까지 가능
  - 장거리 전송(QKD, QPU-QPU 연결)에는 **핵스핀 저장 + 전자스핀 재활용이 필수**

**💡 탄소와 질소 동위원소의 핵스핀**

| --- | --- | --- | --- | --- | --- |
| **핵종 기호** | **양성자(p)** | **중성자(n)** | **동위 원소 질량 (u)** | **상태** | **핵스핀** |
| 13C | 6 | 7 | 13.003354835336(252) | **안정** | ½- |

**💡 각 동위원소별 하이퍼파인 상태**

- - **mF 상태 수 = 2F+1**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **핵종 기호** | **핵스핀**  ***I*** | **전자스핀**  **S=1/2** | **가능한 총각운동량**  ***F*** **값** | **총 하이퍼파인 상태수**  **(*****mF*** **상태)** |
| 13C | ½ | ½ | 0, 1 | 1 + 3 = **4** |
| 14N | 1 | ½ | ½, 1½ | 2 + 4 = **6** |
| 15N | ½ | ½ | 0, 1 | 1 + 3 = **4** |
| 29Si | ½ | ½ | 0, 1 | 1 + 3 = **4** |

**💡** **상황 설정**

- - NV- 중심에는 전자 스핀(S)이 있다. (기저 상태에서 S=1)
  - NV- 바로 옆에는

    - 결함을 만든 **질소 동위원자**(14N: 핵스핀 I=1 또는 15N: I=½)
    - 또는 근처의 **탄소 동위원소** 13C(I=½)가 존재할 수 있다.
  - 이 핵스핀(I)은 작은 자기모멘트를 가지고 있어서 전자 스핀과 자기적으로 영향을 주고받는다.

**💡****하이퍼파인 결합의 의미**

- - 전자 스핀과 핵스핀 사이 거리가 매우 가까우면, 전자의 자기장(스핀 자기모멘트)이 핵에 닿고, 핵의 자기장도 전자에 영향을 준다.
  - 이 상호작용을 양자역학적으로 표현하면:

- - - **A** : 하이퍼파인 결합 상수 (MHz 단위, 결합 세기)
    - **S** : 전자 스핀 연산자
    - **I** : 핵 스핀 연산자
    - **S⋅I** : 전자 스핀과 핵 스핀의 정렬 정도(평행/반평행)

**💡** **물리적으로 어떤 효과가 있나?**

- - 전자 스핀 상태에 따라 핵 스핀 에너지가 달라지고, 반대로 핵 스핀 상태에 따라 전자 스핀 에너지가 달라진다.
  - ODMR 측정 시, 이 결합 때문에 주 공명선이 여러 개로 분리(스플리팅)된다.
  - 예: NV-에서 14N(I=1)과 결합하면 m\_I = -1, 0, +1 세 가지 경우 → 주파수가 3개의 피크로 나뉨.
  - 13C(I=½)와 결합하면 2개의 피크로 나뉨.

**💡** **직관적인 비유**

- - 전자 스핀 = 큰 자석, 핵 스핀 = 작은 자석.
  - 둘이 가까이 있으면 **자석 방향이 서로 평행이면 안정, 반대면 불안정** → 에너지 차이가 발생.
  - 이 에너지 차이가 ODMR에서 관측되는 **하이퍼파인 구조**다.

**💡****어떤 상태를 저장에 쓰는가**

- - 양자 메모리로 쓸 때는 **핵스핀의 두 하위준위**를 선택해서 논리적 ∣0⟩, ∣1⟩로 사용한다.
  - 예:

    - **I =** ½ (13C,15N) → 보통 mI=−½ ↔ +½ 두 상태를 선택
    - **I =** 1 (14N) → 세 상태 mI=−1,0,+1 중 두 개만 선택

      - 예: mI=**0 ↔ +1** 또는 mI=**−1 ↔ 0**********
      - 세 상태 모두 쓰는 **qutrit(3레벨)** 운용도 가능하지만, 보통은 2레벨만 쓰는 게 제어가 단순

**💡****변환 동작 방식**

- - 전자스핀과 핵스핀이 하이퍼파인 결합으로 연결되어 있기 때문에,
  - 전자스핀의 특정 mS 상태에서만 핵스핀의 공명주파수가 맞도록 **조건부 RF 펄스**를 걸어준다.
  - 이렇게 하면 전자스핀이 ∣↑⟩일 때만 mI=−½ ↔ +½로 바꾸는 식의 **CNOT 형태 제어**가 가능하다.
  - SWAP 시퀀스를 써서 전자 ↔ 핵스핀 상태를 완전히 교환하면 저장이 끝난다.
  - 즉,

    - 13C,15N → −½ ↔ +½
    - 14N → −1 ↔ 0 또는 0 ↔ +1
    - 이런 식으로 두 핵스핀 하위준위만 논리 비트로 골라 쓴다.

**💡바륨과 컬러센터에서의 하이퍼파인 차이**

- - 원리: **동일한 하이퍼파인 결합**
  - 차이: NV는 **고체 결함**, 바륨 이온은 **자유 이온** → 환경·잡음·결합 세기에서 차이.

**✅** **아이온큐의 현재 기술 개발 현황**

****

**💡 IonQ**

1. 1. **이온–광자 얽힘**: 이미 수년 전부터 안정적으로 구현.
   2. **헤럴드 얽힘(BSM)**: 다중 노드 간 성공 사례 발표.
   3. **광자 → 이온 스핀 변환(수신부)**: 완전한 네트워크 상황에서 성공 사례 없음

      - 일부 실험 논문에서 *동일 QPU 내에서* 광자 정보를 다른 이온으로 매핑하는 데 성공한 사례는 있음.
      - 하지만 **원격 QPU 간 통신 큐비트 수신부**로서 이 과정을 완결한 건 아직 없음
   4. **저장된 스핀 → 광자 재방출 : 아직 미구현**

**💡 Lightsynq**

1. 1. **이온–광자 얽힘**: 구현.
   2. **헤럴드 얽힘(BSM)**: 구현.
   3. **광자 → 스핀 변환**: SiV 기반 수신부 설계 중, 일부 광자→스핀 변환 실험 데이터 존재

      - 737 nm 대역에서 특정 편광/위상 상태의 광자를 SiV의 전자 스핀 상태로 매핑하는 실험 결과 존재
      - 논문 전체 공개는 아니지만, 컨퍼런스·워크숍 발표에서 일부 수치(충실도, 효율) 언급
      - 아직 QFC(예: 493→737 nm 변환) 모듈과 **네트워크 환경에서의 실시간 연동**은 미공개
   4. **저장된 스핀 → 광자 재방출 : 아직 미구현**

**💡IonQ와 Lightsynq는 상호 보완관계**

- - **IonQ**: 지금까지 주력은 **이온 기반 QPU 내부 및 실험실 환경**에서의 텔레포테이션·네트워킹.
  - **Lightsynq**:

    - **SiV 기반 포토닉 인터페이스**(광자 메모리·버퍼) 설계.
    - **장거리 광통신**에 최적화된 하드웨어 구조.
    - **19인치 랙 통합형 양자 네트워킹 노드** → 배치/현장 운용 용이.
  - 즉, IonQ가 강점인 **QPU-레벨 연결**과 Lightsynq의 **네트워크 노드·통신 인프라**를 합치면, **실험실 수준 → 실사용 네트워크 수준**으로 확장 가능.

**💡속도 절약**

- - IonQ가 SiV·QFC·네트워킹 노드를 제로부터 개발하면 수년 소요.

    - → Lightsynq는 이미 **완성도 높은 프로토타입**을 보유.
  - 인수로 **시간 단축 + 특허/노하우 확보** 가능.

**💡과제**

- - 양자 텔레포테이션 실현 (3단계 이상)
  - QFC(파장변환) 자체 개발
