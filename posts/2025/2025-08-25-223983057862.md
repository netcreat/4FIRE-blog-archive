# 광자는 냉각을 좋아해...

Published: 2025-08-25T20:17:18.262000+09:00

Original Naver post: https://blog.naver.com/4-fire/223983057862

---

**✅****광자와 단일 광자**

**💡****단일 광자 (Single Photon)**

- - **광자(Photon)** = 전자기파(빛)의 에너지 최소 단위 → “빛의 양자”
  - 보통 우리가 보는 빛은 수십억 개 이상의 광자가 동시에 움직이는 **고전적 파동**으로 취급 가능하지만, **양자 정보 처리**에서는 **광자 하나씩**을 **개별 큐비트**처럼 제어해야 함.
  - 단일 광자는 에너지가 **E = hν = hc/λ**로 결정됨

    - 예를 들어, λ = 1550 nm (통신용 파장) → **E ≈ 0.8 eV** → 이 정도 에너지를 가진 “**빛 알갱이 하나**”가 단일 광자

**💡****단일 광자가 중요한 이유**

- - **양자정보의 캐리어(Qubit Carrier)**

    - 광자 기반 양자컴퓨터에서는 **한 개 광자 = 한 개 큐비트**.
    - 광자의 다양한 자유도(DOFs - Degree of Fredom)를 사용해 정보를 인코딩:

|  |  |  |
| --- | --- | --- |
| **자유도** | **|0⟩** | **|1⟩** |
| 편광 | ↔ (수평) | ↕ (수직) |
| 시간(time-bin) | t₀ 시점 | t₁ 시점 |
| 경로(path) | 왼쪽 채널 | 오른쪽 채널 |
| 위상(phase) | φ = 0 | φ = π |

- - - 즉, 단일 광자는 **양자컴퓨터에서 큐비트를 구현하는 물리적 입자**

****

- - **얽힘(Entanglement) 생성**

    - 두 개 이상의 단일 광자를 상호작용시켜 **얽힘 상태**를 만듦.
    - 예: Bell 상태 생성

- - - 얽힘은 양자컴퓨팅, 양자통신, 양자네트워크에서 필수적이므로 **광자 한 개 단위로 제어**가 필요

- - **단일광자 기반 보안(QKD)**

    - QKD(Quantum Key Distribution)에서는 **광자 하나에 키 정보를 실어서 전송**.
    - 만약 해커가 도청하려고 하면, 단일 광자의 상태가 **측정 시 붕괴**하기 때문에
    - 해킹 시도가 바로 탐지됨.
    - BB84 프로토콜 같은 양자암호기술의 핵심 원리.

**✅****광자는 무죄**

- - 광자는 질량이 없고 열적 운동도 없어서 **열 잡음(thermal noise)** 영향이 거의 없음.
  - 따라서 **광자의 생성·전송·연산**은 기본적으로 **실온에서 가능**
  - → 광자 자체는 문제가 없다. 다만 강자를 생성하고 측정하는 특정 소자가 문제임.

**💡****포토닉 집적회로**

- - **대부분의 경우 실온에서 동작 가능하지만,**
  - **초전도 기반 위상 변조기나 광자-전기 하이브리드 소자를 사용하면 4K 필요**

****

**💡****단일 광자 방출**

- - 단순히 빛을 켰다 끄는 단순한 생성은 아주 쉽다.
  - 빛 알갱이 하나를 만들어내는 과정

    - **Parametric Down-Conversion (PDC)**: 비선형 결정 사용 → 실온 가능
    - **Quantum Dot SPS**: InAs/GaAs 기반 → 약 4K 필요
    - **Diamond NV 센터**: 4K 또는 실온 모두 가능

**💡****단일 광자 검출**

- - 빛이 특정 경로를 통해서 들어오는지 안들어오는지 체크하는 것 또한 쉽다.
  - 광자소스에서 방출된 단일 광자를 정확히 측정하는 과정
  - 초전도 나노와이어(SNSPD, Superconducting Nanowire Single-Photon Detector) 사용 시 **약 1~4 K**의 극저온 필요

    - SPD (Single-Photon Detector)

      - 단일 광자 검출기
      - 양자컴, QKD, 우주통신 등
    - SPAD (Single-Photon **Avalanche Diode**)

      - SPD의 한 종류로, 반도체 다이오드에서 단일광자 검출
      - LiDAR, 카메라, 일부 QKD
      - **실온에서 작동 가능**
      - **검출 효율 50 ~ 60%**
      - **다크 카운트 높음**
      - 병렬화 어려움으로 인해 스케일링의 한계
    - SNSPD **(Superconducting** Nanowire Single-Photon Detector)

      - SPD 중 초전도체 나노와이어를 쓰는 방식
      - 양자컴에 필수, 고성능 QKD
      - **작동 온도 1 ~ 4K**
      - **검출 효율 > 90%**
      - 다크 카운트 거의 없음
      - 대규모 병렬화 가능
    - 광자 기반 양자 컴퓨터에서는 **수천~수백만 개의 광자 큐비트**를 동시에 검출해야 하는데, 효율이 90% vs 50%면 **전체 회로 성공률**에서 지수적인 차이가 발생하기 때문에, 메이저 기업들은 SPAD 대신 **SNSPD**를 채택함.

---

**✅****왜 SNSPD는 극저온(1~4K)이 필요한가?**

**💡****초전도체 원리**

- - 초전도체는 임계온도(Tc) 이하에서 전기저항이 **0**이 됨
  - SNSPD는 보통 **NbN, WSi, MoSi** 같은 초전도체 재질로 제작.
  - 광자가 초전도 나노와이어에 흡수되면, **국소적으로 초전도 상태가 붕괴 → 저항 생성 → 전압 펄스 발생**
  - → 이 펄스를 검출하면 "광자가 들어왔다"는 사실을 알 수 있음

**💡****극저온 필요성**

- - 초전도 상태를 유지하려면 재료별 임계온도(Tc) 아래로 내려야 함.
  - 예를 들어:

    - NbN: Tc ≈ **10~15 K**
    - → 하지만 노이즈 억제 및 고효율을 위해 **2~3K**에서 동작
    - WSi: Tc ≈ **4K**
    - → 보통 **1K 근처**에서 최적 성능
  - 실온에서는 절대 초전도 상태를 유지할 수 없으므로, SNSPD는 반드시 **헬륨 기반 극저온 냉각기**를 사용

**✅****왜 굳이 SNSPD를 쓰는가**

양자컴의 핵심은 중첩의 원리를 이용하는 것이다. 다시 말해, 고전컴퓨터가 0 또는 1을 확실히 구분하는 것과 달리 확률적으로 0과 1이 동시에 존재하는 상태인 것이다. 그렇기 때문에 양자 컴퓨터의 성능을 결정 짓는 것은 그 확률을 얼마나 높이느냐, 또는 에러율을 얼마나 낮추느냐가 양자컴의 성능을 결정짓는다.

광자의 양자상태를 이용하는 양자컴에서 단일광자 측정은 “양자 알고리즘의 성공률”을 결정짓는 핵심이다.

예를 들어, PsiQuantum의 포토닉 양자 컴퓨터에서 **1,000개의 광자**를 동시에 검출한다고 가정한다면,

- **SNSPD (90%) 사용 시**

  - 전체 성공률 ≈ (0.9)1000≈ **10****-47** → 매우 낮지만 여전히 현실적
- **SPAD (60%) 사용 시**

  - 전체 성공률 ≈ (0.6)1000≈ **10****-220** → 사실상 불가능

즉, **90% vs 60%의 차이가 곱셈으로 누적**되기 때문에 SNSPD 없이는 **양자컴 스케일링 자체가 불가능**

****

**SNSPD**는 광자 통신(포토닉 인터커넥트)과 광자기반 양자컴퓨터 모두 필수적이다.

광자기반과 이온트랩 기반 양자컴퓨터 자체는 냉각이 필요하지 않다. 초전도체기반이나 중성이온 기반에 비해 크게 내세울 수 있는 장점 중 하나다.

하지만, 광자를 검출하기 위한 목적으로 냉각이 필요하기 때문에 액체헬륨 컴프레서와 챔버 등이 필요한 이유다.

그리고, 이 냉각장치는 진공의 압력을 보다 높게 유지하는데도 필요하기 때문에, 현재 양자컴퓨터 산업에서 없어서는 안될 중요한 요소가 되었다.
