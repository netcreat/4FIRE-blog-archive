**✅One-way Trusted Node**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTJfMTMw/MDAxNzU1MDAwNTk4MTEw.0gIitu8hbVa4rJDPAK0B5gTZOGkXetHikewKtPlzzjwg.xA7nWUvudU7DpJjryUUM6u7t4nd1LSLK_1IpJdtUYY0g.PNG/image.png?type=w800)](#)

**💡****Trusted Node QKD에서 통신하는 방법**

- - 위성에 **QKD 모듈(광학계 + 냉각기 + 검출기) 필요 없음**

    - 키 생성 및 송신만 가능
    - 중국의 묵자 위성도 같은 방법
  - A와 B가 **직접 양자 채널을 맺는 게 아니라**, 위성이 **중간에서 키를 분배·변환**
  - **위성을 신뢰해야 하는 이유**

    - 위성은 KA, KB, SK 모두를 알 수 있음 → 만약 위성이 해킹·감청되면 보안 무력화
  - 장점: 구현 단순, 광자 검출기 없이 송신만으로 가능
  - 단점: 위성 보안이 절대적으로 중요
  - rusted Node 구조에서는 **위성이 세 개의 키 모두를 알고 있다는 점**이 보안 취약점이 될 수 있음

1. **위성이 개별 키 생성·전송**

   - **KA**: 위성 ↔ 지상국 A 사이에서 생성한 대칭키
   - **KB**: 위성 ↔ 지상국 B 사이에서 생성한 대칭키

     - → 현재 상태:
     - A는 KA만 알고 있음
     - B는 KB만 알고 있음
     - 위성은 KA와 KB 모두 알고 있음
2. **위성이 세션 키(SK) 생성**

   - 위성은 새로운 세션 키 SK를 만들고,
   - SK를 **KA로 암호화**해 A에 전송 → Enc(KA, SK)
   - SK를 **KB로 암호화**해 B에 전송 → Enc(KB, SK)
3. **A와 B의 세션 키 복호화**

   - A는 Enc(KA, SK)를 KA로 복호화해 SK 획득
   - B는 Enc(KB, SK)를 KB로 복호화해 SK 획득
4. **이후 통신**

   - A ↔ B는 동일한 SK로 대칭 암호(AES 등) 통신 가능

**✅Trusted Node - Bidirectional**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTJfNjIg/MDAxNzU1MDAwNjE0ODAw.7fldideZW1FihuwrzDc641sbhcJTX6LZ3LeiqeT1uOgg.Lv_gqG_9qOTNjARgSk2p97l1nx0eEbXbaK7AtNV5w68g.PNG/image.png?type=w800)](#)

**💡****Trusted Node – 양방향**

- - 위성이 지상국과 **양쪽 방향**(송신·수신)으로 QKD를 수행할 수 있는 구조

****

1. **위성 ↔ 지상국 A**

   - QKD 세션으로 KA 생성
   - A와 위성만 KA를 공유
2. **위성 ↔ 지상국 B**

   - QKD 세션으로 KB 생성
   - B와 위성만 KB를 공유
3. **세션 키 SK 생성**

   - 위성이 SK를 새로 만들거나 KA, KB에서 파생
   - SK를 KA로 암호화 → A에 전송
   - SK를 KB로 암호화 → B에 전송
4. **A ↔ B 통신**

   - 양쪽이 SK를 복호화하여 공유
   - AES 등 대칭키 암호로 데이터 통신

> **특징:** 논리적 흐름은 단방향 Trusted Node와 동일하지만, 필요 시 지상국에서 위성으로 보내는 QKD도 수행 가능 → 역할 전환 가능성 ↑.

**✅MDI-QKD - Bidirectional**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTJfMjQ2/MDAxNzU1MDAwNjI0NDQw.vt7i-wsBb2y5ie_I4RosRfUrx8tAPWx30iRso3DOa8cg.lf6vTqMSO2vgf2-I089CHZ-vmQp2ZlFE5CDlHrTsCXgg.PNG/image.png?type=w800)](#)

**💡****MDI-QKD – 양방향**

- 위성은 **측정만 수행**하고, 키를 만들거나 저장하지 않는 구조

****

1. **지상국 A → 위성** : 양자 상태(광자) 송신
2. **지상국 B → 위성** : 양자 상태(광자) 송신
3. **위성** : 두 광자를 간섭시켜 Bell 상태 측정(BSM) 수행
4. **위성** : 측정 결과를 고전 채널로 공개 (비밀 아님)
5. **A와 B** : 자신이 보낸 데이터 + 위성 측정 결과를 조합하여 SK를 로컬에서 생성

> **특징:** KA, KB가 없으며, 최종 SK는 오직 A와 B만 알고, 위성은 알 수 없음.

**✅차세대 QKD 네트워크 (Quantum Satellite Constellation)**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTJfMjE2/MDAxNzU1MDAwNjM2ODI4.SaJtEl3NV7TXc2OWnLDRwoHz3oOJJCydNuLEayAzcbQg.9I_sxUIvhfb-Y8B5leDtP_hA2kwFSG5YjkHaN5aWVMcg.PNG/image.png?type=w800)](#)

**💡****Trusted Node 방식 (현실적으로 가장 구현 가능)**

- - **위성 1 ↔ 지상국 A** **: QKD 세션 → KA1 생성**
  - **위성 1 ↔ 위성 2** **: QKD 세션 → K12 생성**
  - **위성 2 ↔ 지상국 B** **: QKD 세션 → KB2 생성**
  - **키 브리징:**

    1. **위성 1이 KA1, K12를 이용해 세션 키 SK를 위성 2로 전달**
    2. **위성 2가 KB2로 SK를 지상국 B에 전달**
  - **장점:**

    - **큐브샛이 TX-only여도 가능**
    - **현재 기술로 구현 가능**
  - **단점:**

    - **위성 1, 2 모두** **신뢰해야 함** **(각 키를 알게 됨)**

****

**💡** **MDI-QKD(위성 측정 노드)**

- - **위성 1**이 측정 노드(BSM) 역할: A와 위성 2에서 온 광자를 검출
  - **위성 2**도 BSM 역할을 하려면 양자 메모리 + 정밀 동기화 필요
  - 장점:

    - 위성들이 키를 알 필요 없음 → 보안성 ↑
  - 단점:

    - 두 위성 모두 **검출기+간섭계** 필요
    - 멀티홉이면 양자 메모리 필요 (현재 실용화 전)

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MTJfMzEg/MDAxNzU1MDAwNjU1ODMy.kKc0mv86ZHbmTu4QR7N6z9FnT28pGJnpTSkgCRh_wKcg.FuLim0BhcYuD-pk1z4EOrTlN7aIhFOTpnwXAvKeUjc4g.PNG/image.png?type=w800)](#)

**💡** **혼합 구성 (현실적 대안)**

- - **위성 1 = 풀-피처(송·수신+검출기)**
  - **위성 2 = TX-only 큐브샛**
  - 구조:

    - **지상국 A ↔ 위성 1** : MDI-QKD 또는 Trusted Node
    - **위성 1 ↔ 위성 2 ↔ 지상국 B** : Trusted Node로 브리징
  - 장점:

    - 일부 구간만 위성을 신뢰하면 됨
    - 장비·비용 절감

**✅QKD 위성 비교**

**💡****QKD 장비 구성 비교**

|  |  |  |
| --- | --- | --- |
| **구성품** | **단방향(송신만)** | **양방향** |
| 광자 송신기 | ✔ | ✔ |
| 송신 광학계 | ✔ | ✔ |
| 수신 광학계 | ❌ | ✔ |
| 단일광자 검출기 | ❌ | ✔ |
| 편광/위상 분석기 | ❌ | ✔ |
| 냉각 시스템 | ❌ | ✔ (SNSPD 사용 시) |
| 동기화 모듈 | 일부 | 강화 |
| 전력·열관리 | 보통 | 대폭 증가 |

**💡****양방향 위성 QKD 설계 시 현실적 영향**

- - **무게 증가** **– 광학계 + 냉각기 + 수신 모듈로 수십 kg 이상 증가**
  - **전력 소모 증가** **– 극저온 냉각기만 수십~수백 W, 나머지 전자장비 포함 시 수백 W 추가**
  - **열관리 복잡성** **– SAR처럼 전력 소모 많은 페이로드와 병행 시 설계 난이도 급상승**
  - **위성 크기 제약** **– 소형 CubeSat급에선 사실상 불가능, 중·대형 위성 필요**

****

**💡특징 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **단방향 QKD** | **양방향 QKD** |
| **장비 난이도** | 낮음 (송신기만) | 높음 (송·수신 모두) |
| **전력·열관리** | 적음 | 큼 |
| **위성 크기 요구** | 소형 가능 | 중·대형 필요 |
| **주요 용도** | 키 브로드캐스트, 시범망, 저비용 보안 채널 | 다자간 동적 키 교환, 위성↔위성 양자망, 글로벌 VPN |
| **보안 유연성** | 낮음 (한쪽만 키 생성) | 높음 (양쪽 모두 키 생성) |
| **네트워크 확장성** | 제한적 | 매우 높음 |

**✅****LEO 위성의 포화 가능성**

**💡****실제 운영 가능 수치**

- - **MIT**와 **ESA** 시뮬레이션에 따르면, 충돌 위험을 관리 가능한 수준으로 유지하려면 **적극적인 궤도 청소와 수명 종료 후 재진입**을 전제로 **LEO에서 약 3만~5만 기**까지 안정적으로 운영 가능
  - 현재(2025년 초) **활성 LEO 위성은** **약 8,100기** → 즉, 이론상으로는 **4~5배**까지 늘릴 여지

**💡****계획된 발사 규모**

- - SpaceX Starlink: 최종 계획 **12,000기**, 확장 계획은 **42,000기**
  - OneWeb: 약 648기 (1세대) + 차세대 확장 계획
  - 중국, 아마존 Kuiper, 캐나다 Telesat 등 합치면 **2030년대 초반까지 5만 기 이상 발사 계획**

****

**💡****주요 콘스텔레이션 구성 사례**

- **Trusted-Node 기반 QKD 콘스텔레이션**

  - **연구 모델에서는 LEO 기반 다수의 위성, 지상국 간 인터-위성 링크(ISL)을 활용해 지상국 간 빠르고 안전한 키 공유 구조를 제안**
  - **또 다른 연구는 태양·지구 정합 궤도(Sun-synchronous orbit)를 활용한 큐브샛 QKD 콘스텔레이션을 UK 지역 중심으로 설계한 예시**
- **하이브리드 LEO-GEO QKD 시스템**

  - **일부 설계는 GEO 위성이 LEO 위성들에 키를 먼저 분배하고, LEO 위성들이 지상국에 다시 키를 공급하는 2단 구조를 제안**
- **MDI-QKD 및 엔탱글링 기반 접근**

  - **위성이 얽힌 광자(entangled photon pair)를 동시에 두 지상국에 내려 보내는 형태의 멀티홉 QKD 설계도 제안됨.**
- **큐브샛 QKD 파일럿**

  - **CQuCoM 프로젝트는 ISS에서 큐브샛을 발사해 QKD 실험을 하기 위한 초기 경로를 제시**
  - **향후 대형 콘스텔레이션의 기반이 될 수 있음음**
- **Microsatellite 기반 실시간 QKD 실험**

  - **2024년 발표된 연구에서는 소형 미소위성(microsatellite)과 휴대형 지상 단말을 활용해 실시간으로 QKD를 수행, 실질적인 키 교환이 가능한 구조를 구현**
- **산업·상업적 움직임**

  - **유럽, 특히 ESA에서는 Eagle‑1 같은 실험 위성을 통해 콘스텔레이션 기반 QKD 서비스 가능성을 모색 중.**
  - **스위스 기반 기업 SEALSQ는 WISeSat.Space 프로젝트를 통해 QKD 위성 콘스텔레이션 배치를 추진 중.**

**✅****맺음말**

LEO 위성 궤도는 머지않아 대규모 통신·관측 위성들로 포화될 가능성이 높다. 이러한 환경에서 위성 QKD 인프라를 새롭게 구축하려면, 단순한 대규모 풀-피처 위성 배치보다 **메인 위성과 큐브위성을 결합한 하이브리드 구성**이 더 현실적인 해법이 된다. 메인 위성은 고성능 검출기와 다기능 페이로드로 핵심 QKD 허브 역할을 수행하고, 큐브위성은 경량·저비용으로 커버리지를 확장하며, 유연하게 Trusted Node 또는 부분 MDI-QKD 네트워크를 형성할 수 있다.

이러한 전략은 제한된 궤도·주파수 자원을 효율적으로 활용하면서도, 기술·비용·시간 측면에서 시장 진입 장벽을 낮춰준다. 결국 **지금 이 시점에서 하이브리드 QKD 위성망을 선점하는 것이, 향후 글로벌 양자보안 통신 시장을 주도하는 가장 빠른 길**이다.
