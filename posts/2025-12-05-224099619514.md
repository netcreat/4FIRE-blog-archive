**✅SEALSQ의 EeroQ 전략적 투자**

- - SEALSQ는 “Quantum Made in USA” 전략의 일환으로, 미국 기반 양자 칩 설계 기업 **EeroQ**에 전략적 투자를 단행한다. EeroQ는 초유체 헬륨 위의 단일 전자(eHe)를 이용해 양자컴퓨터를 구현하는 독창적 아키텍처를 개발하고 있으며, 이는 SECALSQ가 지향하는 **소버린(자주적)·확장 가능한 양자 및 PQC 생태계** 구축 방향과 긴밀히 맞닿아 있다.

**📌****EeroQ 기술의 핵심 특징**

1. 1. **초소형 양자 프로세서**

      - 단일 전자를 사용하므로 칩 크기를 엄지손톱만큼 줄일 수 있다.
      - 다른 양자 아키텍처처럼 대형 극저온 인프라가 필요하지 않다.
   2. **CMOS 공정 호환성**

      - 기존 반도체 제조 생태계에서 생산 가능하므로 SEALSQ의 PQC 칩·MCU 제조 역량과 자연스럽게 연계된다.
   3. **고품질 큐비트 기대치**

      - 긴 코히런스 타임
      - 사실상 **all-to-all** 결합 구조
      - 전자를 이동시켜 구조를 재배치할 수 있는 높은 모빌리티
   - 이 점들로 인해 EeroQ는 현존 양자 플랫폼 중 **가장 확장성이 높은 후보 기술** 중 하나로 평가된다.

**📌****SEALSQ의 전략적 의도**

- - SEALSQ는 이번 투자를 통해 다음과 같은 통합 생태계를 강화하려 한다.

    - 상용화된 **PQC 칩**
    - **양자내성 마이크로컨트롤러 유닛 (Post-quantum Cryptography Micro Controller Unit)**

      - MCU는 다음같은 일을 하게 되는데, 양자시대에도 안전한 암호 알고리즘을 탑재한 MCU를 제공한다는 것임.

        - 센서 읽기
        - 장치 제어
        - 간단한 로직 처리
        - 보안기능
    - 미국·UAE 기반 퍼스널라이제이션 센터
    - 향후 개발할 **양자 가속기 칩**
  - 또한, EeroQ가 미국 내 R&D 및 제조 기반을 확장함에 따라 SEALSQ는 미국·유럽의 **국가 주권 기반 양자기술 확보**라는 정책적 목표에도 기여하게 된다.

**📌****리더십 및 윤리 분야**

- - EeroQ는 프린스턴대 Steve Lyon 교수를 CTO로 영입하고 시카고에 9,600sq ft 규모의 R&D 센터를 설립했다.
  - 공동설립자 Faye Wattleton은 2018년부터 **양자 윤리(quantum ethics)** 연구를 이끌며 책임 있는 기술 개발 프레임워크를 구축해 왔다.
  - 이는 SEALSQ가 강조하는 **신뢰 가능한 기술 생태계**와 방향성이 일치한다.

**✅ EeroQ 기술이 무엇이냐**

**📌****EeroQ = 전자를 헬륨 위에 띄워서(quasi-free electron) qubit으로 사용하는 구조**

- - 초유체 헬륨 위에서는 표면이 매우 깨끗함 → **잡음이 극도로 낮음**
  - 전자가 마치 2D로 깔린 트랙 위에서 “떠 있는” 상태

    - → 전자 이동성 높음 → **qubit 위치 이동 가능 (모바일 큐비트)**
    - → Ion shuttling(Quantinuum/IONQ)과 유사하지만, 더 가벼움
  - **전자 = 자연에서 가장 작고 가벼운 안정 입자**

    - → **칩 크기를 thumbnail 규모로 줄여도 됨**

****

**📌그림 설명 - 이온트랩의 전자 버전 → 전자 트랩**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTEyMDVfMjQ3/MDAxNzY0OTMyOTMzOTU3.x0ABvHG27ppRziJzX6FsSJDqNcc7FHyptC1VIiakr0kg.WMWW2Qk6h7QyCHGGoWzNEdwmrj46YRj2BF-TD3QTE-Ag.PNG/image.png?type=w800)](#)

[**Sensing and Control of Single Trapped Electrons Above 1 Kelvin**](https://arxiv.org/html/2412.03404v1)

- - **(a) 초유체 헬륨 표면 위에 전자를 띄우는 기본 구조**

    - 아래 회색 부분은 **실리콘 칩(기판)**
    - 파란색은 **초유체 헬륨(He)**
    - 그 위에 파란 점들 –e (전자)가 떠 있음
    - 전자가 헬륨 표면에 떠 있는 이유:

      - 헬륨 표면은 **완벽히 매끄러운 전기적으로 중성 평면**
      - 전자는 **정전력 + 이미지 차지(image charge)** 효과 때문에 표면 위 10 nm 정도 떠 있게 됨
      - 전극에 전압을 걸어주면 전자를 특정 위치로 트랩(trap) 가능
  - **(b) 실제 장치(SEM 이미지) — 전자 트랩 + 공진기 구조**

    - 이 패널은 **실제 제작된 칩의 SEM(주사전자현미경) 이미지**를 색상 입혀서 보여준다.
    - **1) Split Gate (녹색)**

      - 전자를 가두는 데 사용하는 윗쪽 전극
    - **2) Bottom Gate (갈색)**

      - 전자의 깊이를 조절하는 아래쪽 전극(트랩의 바닥 전압 조절)
    - **3) Trap (노란 점선)**

      - 전자를 실제로 한두 개 잡아두는 위치
      - 바로 이 공간이 “큐비트 자리”
    - **4) Resonator (연보라/파랑)**

      - 마이크로파 공진기
      - 전자와 상호작용하여 전자의 상태를 읽는다
    - **5) Unload 구조 (보라색)**

      - 전자를 다 쓴 후 이동시켜 버리는 통로
    - **6) 냉각기**

      - 1.1K 유지
    - **중요한 점:**

      - 전체 구조는 **2 μm 크기**로 극도로 작다.
      - 이 단순한 전극 패턴이 바로 **큐비트 물리 구조**이다.
      - 레이저 없음, 복잡한 3D 구조 없음 → EeroQ의 단순함이 여기서 증명된다.
  - **(c) FEM(유한요소법) 시뮬레이션 — 전자 트랩의 전기 퍼텐셜 분포**

    - 이 그림은 실제 칩 전극에 전압을 걸었을 때 **전자 한 개가 어떤 위치에 갇히는지**를 수치적으로 계산한 것이다.

      - 색깔 = 전기 퍼텐셜(φ, 전위)
      - 빨간색 = 높은 퍼텐셜
      - 파란색 = 낮은 퍼텐셜
      - 0.01, 0.19 V 등 등전위선(contour)이 그려져 있음
    - 여기서:

      - x축 = 왼쪽/오른쪽
      - y축 = 위/아래
    - 전자(-e)는 **전위가 낮은 곳으로 끌려가** 특정 지점에 가두어진다.
  - **(d) 전자 로딩(Load) / 언로딩(Unload) 시 실제 장치 동작**

    - 이건 **전자 트랩 운영 방식**을 보여준다.

      - 오른쪽 마이크로채널에서 전자를 공급
      - 트랩으로 불러들여(qubit 자리)
      - 작업(게이트 연산, 측정)을 수행한 뒤
      - Unload 채널로 밀어내서 제거
    - 이 그림은 “1개 전자를 선택적으로 잡고, 원하는 시간만 사용하고, 제거하는 과정”을 보여주는 **전형적인 단일전자 큐비트 운영 프로토콜**이다.

**📌 왜 SEALSQ가 이 기술에 투자했나?**

- - **CMOS 공정 호환(반도체 공장에 바로 넣을 수 있음)**

    - PQT(PQC 칩, Secure MCU 등)의 확장성과 동일한 제조 생태계 사용.
  - **초소형 QPU → 엣지·IoT 시나리오까지 확장 가능**

    - WISeSat/WISeKey가 하려는 “IoT + PQC + Secure MCU + LEO 위성”과 향후 결합 가능.
  - **“Made in USA” 전략:**

    - 미국·유럽의 **국가 안보형 양자 주권(quantum sovereignty)** 흐름과 맞음.
  - **EeroQ는 매우 자본 효율적인 아키텍처라는 점을 강조**
  - 초전도/이온/광자 대비:

    - 장비가 거의 없음
    - 큰 냉동기나 레이저 시스템 필요 없음
    - 공정 표준화가 쉬움
    - ⇒ SEALSQ 같은 중형 반도체 기업에게 **현실적인 스케일업 모델**

**📌 SEALSQ가 구축 중인 생태계에 EeroQ가 들어가는 방식**

- - SEALSQ는 이미:

    - **PQC 칩 (양자내성 암호칩)**
    - **Secure MCU (보안 마이크로컨트롤러)**
    - **미국·UAE personalization center (칩 키 삽입 공장)**
    - **IC’ALPS 인수로 ASIC 개발 역량 확보**
  - 즉 “보안 + 반도체 + PQC” 생태계를 구축 중인데, 여기에 **미래 QPU까지 포함시키려는 전략**
  - 이는 WISeSat의 LEO 위성 기반 **PQC 키 배포** 모델과도 연결됨.

**📌 전략적 의미 — 왜 이 시점에 EeroQ인가?**

- - **양자 주권(sovereignty) 강화 미국/유럽 정책과 직결**

    - EU: Chips Act + PQC 전환
    - 미국: NIST PQC 전환 + NSF/DOE의 양자 제조 클러스터
    - SEALSQ는 둘 다에 “infrastructure vendor”로 들어갈 수 있음.
  - **초저전력 IoT(PQC 센서·디바이스)와 QPU의 결합을 염두에 둠**

    - IoT 디바이스는 **배터리로 구동**
    - 안테나와 처리 성능 제한
    - 직접 QKD를 받기 어렵고
    - → PQC 기반 “소버린 키 배포”가 필요
  - SEALSQ의 방향:

    - **IoT 보안(PQC) + LEO 위성(WISeSat) + 향후 소형 QPU(예: EeroQ)**이라는 “전체 스택” 산업을 만들려고 함.
  - **EeroQ의 ‘모바일 전자 큐비트’는 장기적으로 분산/네트워크형 QC에 강함**

    - IonQ의 모듈형 photonic link 전략과는 다르지만, 전자 이동성이 높아 임의 연결성(all-to-all)을 구현 가능.

**📌 기술적으로 보면 EeroQ는 어느 정도 현실성이 있나?**

- - 실험실 단계지만, **CMOS 호환**이라는 점은 매우 큼.
  - Chicago에 9,600 sq ft 규모의 R&D 센터 완공 → 제조 전 단계 진입
  - Princeton의 Steve Lyon CTO 임명 → 기술 신뢰성 획득
  - qubit quality의 신호는 계속 개선되고 있음 (하지만 공개 데이터는 제한적)
  - **결론:**

    - 초전도/이온/광자보다 “더 초기”이지만, 스케일업 관점에서는 **가장 이상적인 모델 중 하나**.

**✅****SEALSQ가 그리는 미래**

- - PQC 기업이 QPU를 직접 만들 필요는 없다.
  - 하지만 ‘QPU가 없는 PQC 기업’은 10년 뒤 전략적 중요성을 잃게 된다.

**📌****과거 보안 모델**

- - crypto library
  - secure MCU
  - HSM
  - PKI

**📌****미래 보안 모델**

- - PQC(소프트웨어/하드웨어)
  - QKD/QDS
  - 양자 인증
  - 양자 안전 ID
  - **QPU-assisted security modules**
  - **양자 난수생성기(QRNG) 포함 보안칩**

**📌시장이 “양자 하드웨어가 포함된 보안 기기”로 이동 중**

- - **대표적인 예:**

    - **정부 ID/스마트카드 → QRNG/PQC + 양자 인증 칩**
    - **IoT 인증칩 → PQC + QPU-assisted 인증 엔진**
    - **국방 통신 → PQC + 양자 난수 + 양자 키 분배(QKD)**
    - **Secure Edge 장비 → PQC + quantum-based attestation**
  - **앞으로의 보안칩(secure MCU, TPM, HSM)은 “양자 보조 기능”을 포함하는 하이브리드 구조로 진화한다.**
  - **즉:**

> ***양자 기능이 아예 없는 PQC 칩은 오래 못 간다.***

**📌SEALSQ는 QPU 자체가 필요해서가 아니라 “QPU 기반 보안칩 생태계”를 만들려는 것**

- - SEALSQ가 원하는 건 ‘양자 가속 기능을 가진 보안 MCU·HSM’을 미래에 출시하는 것.
  - **즉, 다음 같은 제품군을 만들고 싶어 한다:**

    - **PQC + QRNG + QPU-based 인증 엔진**
    - **PQC + 소형 QPU 가속기(chiplet 형태)**
    - **PQC + QPU 난수 기반 secure enclave**
    - **양자 기반 attestation을 포함한 secure microcontroller**
  - **EeroQ의 eHe 아키텍처는 구조가 너무 단순해서 보안칩에 통합 가능한 유일한 QPU 후보에 가깝다.**

    - **이온트랩? → 무게 200kg**
    - **초전도? → 수 톤급 cryo**
    - **포토닉? → 대형 광학계**
    - **eHe(전자-on-헬륨)는?**

      - **1K 수준의 냉각이 요구되기 때문에 → 훨씬 작고 값싼 소형 냉각기 사용 가능**
  - **즉, SEALSQ는 QPU가 필요해서 투자한 게 아니라**

> ***“보안칩의 미래가 QPU를 요구하기 때문에” 미리 그 퍼즐 조각을 확보한 것.***
