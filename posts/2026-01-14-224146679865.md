**✅ 각자 세계 최초**

**📌** **삼성 S3SSE2A (CES 2026 보안 혁신상 수상 칩)**

- - 타입: **Secure Element / eSE(임베디드 보안 칩)**
  - 포지션: AP/MCU 옆에 붙는 **루트 오브 트러스트 전용 칩**
  - 특징

    - CES에서 “**업계 최초 하드웨어 기반 PQC를 탑재한 임베디드 보안칩**”이라고 소개됨
    - **NIST가 선정한 PQC 알고리즘**(Kyber/Dilithium 계열로 추정)을 하드웨어 레벨에서 지원 + 기존 RSA/ECC와 **하이브리드 구조**
    - **CC EAL6+** 등급(매우 높은 보안 평가 등급)으로 인증 받았다고 명시
    - **Thales의 보안 OS와 PQC 라이브러리**가 올라가 있어서, 칩 위에서 바로 PQC 연산을 고속·저전력으로 수행
  - 타깃 영역

    - 스마트폰, 웨어러블, 카드/페이먼트, eSIM/eSE, 모바일·IoT 기기, 커넥티드 디바이스 전반
  - → 한마디로: “**스마트폰·IoT 디바이스 안에 들어가는 초고보안 Secure Element에 PQC를 하드웨어로 박은 삼성+Thales 콜라보 칩**”.

**📌** **SEALSQ Quantum Shield QS7001**

- - 타입: **양자 내성 보안 MCU / SoC (RISC-V 기반 secure microcontroller)**
  - 포지션: 자체 CPU(80MHz RISC-V)가 달린 **프로그램 가능한 보안 마이크로컨트롤러**
  - 특징

    - SEALSQ가 2022년부터 진행한 **QUASARS 프로젝트**의 결과물로,
    - “**hardware-embedded PQC 칩 패밀리(QS7001, QVault TPM)**”라고 홍보
    - Kyber(KEM) + Dilithium(서명)을 전용 하드웨어 가속기로 통합 (NIST PQC 표준 알고리즘)
    - **RISC-V 보안 MCU + PQC 가속기 + TRNG + Secure Boot** 구조, 인터페이스는 SPI/I²C/UART, TPM 호환 패키지 옵션
    - 보안 등급은 **CC EAL5+ 수준**, FIPS/PQC 인증 준비, ANSSI/Common Criteria 요구사항 맞추는 걸 강조
  - 타깃 영역

    - **스마트 그리드 / 에너지 인프라, 스마트 미터**
    - **자동차·EV 충전 인프라**, 산업 제어, 통신 인프라
    - 의료·헬스케어, 금융 단말, 각종 IoT 센서/게이트웨이
  - → 한마디로: “**RISC-V 코어 위에 Kyber/Dilithium 하드웨어 가속기를 얹은, IoT·산업용용 PQC 보안 MCU**”.

**📌 “업계 최초” 싸움: 누가 진짜 먼저야?**

- - 타임라인을 보면:

    - **SEALSQ QS7001**

      - 2025년 10월, 뉴욕 Q+AI 2025 컨퍼런스에서 “**업계 최초 하드웨어-임베디드 PQC 칩**”으로 공식 공개
    - **삼성 S3SSE2A**

      - 2025년 11월경 CES 2026 Innovation Awards 자료에 공개,
      - 2026년 1월 CES에서 **“Best of Innovation in Cybersecurity” 수상**,
      - 설명 문구는 “**업계 최초 하드웨어 기반 PQC를 탑재한 임베디드 보안칩/보안 Secure Element**”
  - 그래서 마케팅 문구를 해석하면:

    - **SEALSQ**:

      - → “보안 MCU/SoC 레벨에서 PQC를 하드웨어로 넣은 **첫 PQC 칩 패밀리**”
    - **삼성**:

      - → “스마트폰·모바일 쪽에서 쓰이는 **임베디드 Secure Element(eSE) 카테고리에서 최초**”
  - **카테고리가 다르게 잡혀 있어서 서로 모순되진 않고, 약간 영역을 나눠서 각자 1등이라고 말하는 느낌**으로 보면 된다.

**📌 기술 구조 차이: eSE vs 보안 MCU**

- - **삼성 S3SSE2A – eSE(임베디드 Secure Element)**

    - 호스트 AP/MCU(스마트폰 AP, IoT SoC 등) **옆에 붙는 작은 보안 칩**
    - 칩 안 OS(Thales) 위에서 **키 저장, 암·복호화, 인증, PQC 연산만 수행**
    - 장점

      - 매우 높은 보안 등급(EAL6+)과 강한 탬퍼링 방어 설계
      - 모바일·페이먼트 에코시스템(EMV, eSIM, NFC 결제 등)과의 호환성·레퍼런스 풍부
      - PQC + 기존 RSA/ECC를 하이브리드로 제공 → **양자 이전·이후 모두 커버**
    - 단점/제약

      - **일반 애플리케이션 로직을 올리는 MCU는 아니고**, 보안 기능 특화 블랙박스에 가까움
      - 시스템 설계 관점에서는 AP/MCU + eSE + 기타 칩 구조 → BOM/보드 설계 복잡도 증가
  - **SEALSQ QS7001 – 보안 MCU(secure RISC-V SoC)**

    - 자체 **RISC-V 코어가 있어서, 이 칩 하나가 곧 “보안 컨트롤러”** 역할
    - PQC 가속기 + 전통 암호 + TRNG + Secure Boot를 통합한 **작은 보안 CPU** 같은 포지션
    - 장점

      - 펌웨어를 직접 짜서 올릴 수 있으므로, **스마트미터·EV충전기·산업제어 등에서 메인 MCU+보안 기능을 한 칩으로 통합** 가능
      - SPI/I2C/UART 등으로 기존 시스템에 붙이기도 쉬움
    - 단점/제약

      - 보안 등급은 EAL5+ 수준으로, 순수 eSE(EAL6+ 이상)보다는 한 단계 아래인 포지션
      - 모바일 결제·통신사 eSIM 같은, 극도로 엄격한 스마트카드/eSE 생태계보다는 **산업/IoT 위주**

****

**📌 PQC 알고리즘 & 하이브리드 전략**

- - **삼성**

    - CES 설명 및 삼성 블로그 기준으로, “NIST에서 승인한 PQC 알고리즘을 하드웨어에 내장”이라고만 쓰고 구체 알고리즘 이름은 언급 안 함
    - Thales OS 측 기사에서는 “PQC 라이브러리” 전체를 언급하면서 **양자 내성 암호 + 기존 RSA/ECC를 동시에 지원하는 하이브리드 방식**을 강조
    - 현실적으로는 **Kyber(키 교환) + Dilithium(서명)** 조합일 가능성이 가장 높음 (NIST 최종 표준)
  - **SEALSQ**

    - 공식 자료에서 **Kyber + Dilithium을 명시**하고, 이 둘을 위한 하드웨어 가속기를 RISC-V MCU에 붙였다고 설명
    - 자체 **PKI/Trust Services**와 연결해서, 칩뿐만 아니라 인증서 발급·원격 프로비저닝까지 패키지로 제공하려는 전략
  - → **알고리즘 면에서는 둘 다 NIST PQC 계열(Kyber/Dilithium 기반)으로 사실상 비슷한 세대**, 차이는 “얼마나 구체적으로 어떤 알고리즘을 마케팅에서 밝히느냐” 정도다.

**📌 어디에 더 잘 맞는 칩인가?**

- - **삼성 S3SSE2A가 강한 쪽**

    - **스마트폰, 태블릿, 웨어러블, 결제 카드, 디지털 키, eSIM/eSE** 같은 모바일 디바이스
    - **최상위급 CC EAL6+ 보안 등급과 Thales OS**를 요구하는 금융·통신·ID 생태계
    - 삼성 모바일/IoT 제품군과의 인하우스 통합 (갤럭시, 스마트워치, 스마트홈 등)
  - **SEALSQ QS7001이 강한 쪽**

    - **스마트 그리드, 변전소, 송전망 센서, 스마트미터** 같이 수명 10–20년 가는 인프라 장비들
    - **EV 충전기, 산업용 컨트롤러, 의료기기, 각종 장거리 IoT/산업용 통신 장비**
    - “메인 MCU + 보안”을 하나로 합치고 싶은 프로젝트 – RISC-V 위에 애플리케이션 로직까지 얹고 PQC는 하드웨어 가속기로 처리하는 구조

**📌 정리: 투자/관심 포인트 관점에서 한 줄씩**

- - **삼성 S3SSE2A**

    - “모바일·컨슈머 생태계에서 PQC eSE를 사실상 표준으로 밀어붙일 수 있는 메이저 플레이어”
    - 하지만 **삼성 전체 실적에서 차지하는 비중은 아직 매우 작은 니치**, 대신 *표준화·생태계 리더십* 관점에서 의미가 큼.
  - **SEALSQ (QS7001, QVault 등)**

    - 회사 자체가 **“PQC 보안칩 + PKI/Trust 서비스”에 올인한 순수 플레이어**라 성공하면 레버리지가 크지만, 기술·시장·규제 리스크도 큼
    - 스마트 그리드, 산업, EV 충전, 의료 등 **인프라 레벨의 장기 설비**에 박히면, 뒤에서 조용히 계속 물량이 나오는 타입의 비즈니스.

**✅ 삼성 S3SSE2A**

**📌 제품 개요**

- - **S3SSE2A**는 삼성반도체가 발표한 **Secure Element(SE)** 형태의 보안 칩으로,

    - **업계 최초로 하드웨어 기반 PQC(Post-Quantum Cryptography)를 탑재**한 제품으로 소개됨.
    - 모바일 및 IoT 기기 전반에서 **독립적인 보안 처리 및 데이터 저장**을 제공하는 디스크리트 보안칩이다.
    - AP(애플리케이션 프로세서)와 독립적으로 보안 연산을 수행하여 **보안성이 강화된 구조**임.
  - 즉, S3SSE2A는 **Secure Element + PQC HW 가속 + turnkey 소프트웨어 스택**을 묶은 통합 솔루션임

**📌 핵심 특징 & 스펙**

- - **하드웨어 PQC 지원**

    - Core

      - SC300 : ARM Cortex-M3 기반 Secure Core
    - Flash

      - 1MB : SE 에서는 꽤 큰 편임
    - ROM : 48KB
    - RAM : 112KB
    - Crypto

      - RSA, ECC, AES, TDES, SHA3, Secure timer, PQC accelerator, TORNADO-E
    - Interface

      - I2C (Inter-Integrated Circuit)

        - 2선 통신(SDA = 데이터, SCL = 클럭)
      - I3C (I2C의 차세대 버전)
      - 2GPIO (2 × General Purpose Input/Output)

        - 단순 입력 또는 출력 신호 처리
      - SPI (Serial Peripheral Interface)

        - 고속 직렬통신
    - 기존 소프트웨어 기반 PQC 대비 **최대 ~17× 빠른 연산 성능**을 달성함.
    - (예: FIPS 204 ML\_DSA65 기준 소프트웨어 335.97ms → 하드웨어+SW 19.02ms 성능)
    - **모듈 격자 기반 PQC 알고리즘을 최적화하여 하드웨어 구현**.
    - 👉 이 성능 차이는 PQC의 높은 계산량을 **하드웨어 가속기**로 처리했기 때문임
    - CPU(SW)만으로 처리할 때보다 훨씬 빠르고 효율적이라는 의미.
  - **독립적 보안 처리 + 저장**

    - AP와 분리된 **독립 SE 구조**로 보안 연산/데이터 저장을 수행함.
    - AP에는 결과만 전달 → AP가 침해당해도 SE 내부 키/데이터는 보호됨.
    - 이는 과거 SE 설계(S3K250AF)와 차별점이다 — 기존 SE는 AP 내 보안 블록에서 연산, 결과 저장만 SE에서 했는데, **S3SSE2A는 연산 + 저장을 전부 자체 처리**함.
  - **통합 보안 턴키 솔루션**

    - 하드웨어 + 소프트웨어가 통합된 **“턴키”** 보안 솔루션으로 제공.
    - 사이드 채널 공격, 하드웨어 리버스 엔지니어링, 결함 주입 공격 등 다양한 공격에 대응 가능하도록 설계됨.
    - → 해커가 전력 분석, EMI 측정, 속도 변조 등으로 키를 탈취하는 공격을 방어하기 위한 대응 기능 포함.
    - 즉, 단순 HW 가속 PQC만이 아니라 **보안 전반(attack surface) 대응**이 설계 목표임.
  - **하이브리드 암호 지원**

    - 기존 공개키 암호(RSA/ECC)와 **PQC**를 **병행 지원**하는 구조로 설계됨.
    - → 현재 시스템과의 호환성을 유지하면서 **양자 대응으로 전환**하는 브릿지 역할 수행.
  - **인증/보안 레벨**

    - 글로벌 CC(Common Criteria) 인증 등 수준 높은 보안 인증을 획득함(보도 기준).
    - → 모바일/IoT용 SE에서 **상용 제품 중 최고 수준**의 보안성이라는 평가를 강조.

**📌 PQC HW 구조 & 처리 용도 요약**

- - Samsung S3SSE2A의 PQC 구조는 다음 요소를 포함함:
  - **PQC 하드웨어 가속기**

    - → 모듈 격자 기반 알고리즘 고속 처리.
  - **독립적인 보안 OS / 라이브러리**

    - → Thales OS/PQC 라이브러리와 함께 동작 가능(Thales 파트너십 기반).
  - **키/데이터 저장**

    - → Secure Element 내부 저장, AP와 격리.
  - **보안 방어 기능**

    - → 채널 공격 / 펄스/결함 주입 저항 설계.

| **항목** | **S3SSE2A 특징** |
| 제품 형태 | Secure Element (SE) |

| 암호 지원 | 기존 PKC(RSA/ECC) + PQC 하이브리드 |
| 보안 인증 | CC 인증/높은 보안 수준 |
| 타깃 응용 | 모바일/IoT 인증/결제/ID |

- - **핵심 캡처**:

    - S3SSE2A는 Secure Element + Hardware PQC + 보안 OS/턴키 솔루션 형태로
    - **양자 시대 대응을 위해 설계된 모바일/IoT 보안 칩**임.

**📌 무엇을 의미하나?**

- - S3SSE2A는

    - Secure Element 계열 → **모바일/IoT 환경에 최적**
    - 독립 SE → AP가 뚫려도 키/데이터 보호
    - 하드웨어 PQC → 양자 공격 대비 준비

**✅** **SealSQ QS7001**

> RISC-V 기반 보안 MCU(Security Micro Controller Unit) + PQC 하드웨어 가속기를 통합한 산업/IoT용 양자내성 보안 SoC

**📌 CPU / 아키텍처 레벨 특징**

|  |  |
| --- | --- |
| **항목** | **내용** |
| CPU | 32bit Secure RISC-V |
| 플랫폼 | Ibex/ETH 기반 |
| 클럭 | 최대 80 MHz |
| 전력 | Low-power + Idle/Power-down 지원 |
| 패키지 | 32-QFN |
| 전압 | 1.62V ~ 3.6V |
| 동작 온도 | -40°C ~ +105°C |

****

- - **중요 포인트:**

    - 이건 금융/산업/자동차 영역에서 쓰기 위한 표준 범위이고, 105°C는 **스마트미터/EV충전기/산업 IoT/옥외 장비용** 환경 스펙이라는 의미.

**📌 메모리 구성 (이게 매우 중요한 구조)**

|  |  |  |
| --- | --- | --- |
| **종류** | **용량** | **용도** |
| FLASH | 512 KB | 코드 + 사용자 데이터 |
| ROM | 128 KB | Crypto 라이브러리 |
| RAM | 80 KB | 실행 메모리 |
| ‣ RISC Core RAM | 60 KB | 일반 실행 코드 |
| ‣ Crypto RAM | 20 KB | PQC/암호용 DMA 버퍼 |
| OTP | 존재 | 키/프로비저닝 |
| Retention | 15년 | 산업용 규격 |
| Write endurance | 100K~500K | Wear-leveling |

- - **핵심 포인트**

    - PQC 알고리즘은 메모리 사용량이 큼 → Crypto 전용 RAM이 따로 있는 이유
    - OTP 영역 존재 → Key injection/Provisioning 대응
    - Flash 용량이 Embedded Secure MCU 치고 큰 편(512KB) → **커스텀 펌웨어 적재 가능**
  - 즉, **단순 보안 액셀러레이터가 아니라 소형 보안 컨트롤러**라는 의미.

**📌 Security 특화 하드웨어 블록**

- - 포함된 하드웨어 보안 요소들:

    - ✓ TRNG (FIPS SP800-90B compliant)
    - ✓ AES 엔진 (128/192/256)
    - ✓ RSA/DSA/ECC/DH 엔진
    - ✓ PQC 엔진 (Crystal-Kyber KEM + Dilithium Signature)
    - ✓ Checksum Accelerator
    - ✓ CRC16/CRC32
    - ✓ DMA
    - ✓ Environmental tamper sensor
    - → Voltage / Frequency / Temperature / Light
    - ✓ Active Shield(케이스 침투 감지)
    - ✓ SPA/DPA/SEMA/DEMA 공격 대응
    - ✓ Fault Injection Countermeasure
    - ✓ Supervisor secure memory
  - 이거 조합이 그냥 MCU가 아니고 **진짜 HSM/TPM급** 구조임.

**📌 I/O & 인터페이스**

|  |  |
| --- | --- |
| **인터페이스** | **속도** |
| Master SPI | 20 Mbit/s |
| Slave SPI | 33 Mbit/s |
| I²C | 1 Mbit/s |
| GPIO | 4개 |
| Timer | 3개 |
| Interrupt Controller | 2-level |
| Reset Circuit | 포함 |

- - 핵심 포인트:

    - → 이건 **보안 MCU로 외부 장치를 제어하거나 반대로 제어받는 구조 둘 다 가능**
    - 예:

      - EV충전기 ↔ 스마트미터 ↔ OEM Gateway 같은 시스템에서 역할 수행 가능.

**📌 PQC (Post-Quantum Cryptography)**

- - 여기서 가장 중요한 스펙:

    - **Crystal-Kyber (KEM) + Crystal-Dilithium (Signature)**
  - 왜 중요?

    - → 이 둘은 **NIST PQC 최종 표준 알고리즘**
    - → RSA/ECC 이후 세대의 암호 스위트 확정
    - → PQC 분야에서 진짜 중요한 하드웨어 지원은 매우 드뭄
  - 즉, QS7001은 **하드웨어 레벨에서 양자 내성 암호를 처리하는** 세계 최초 MCU 계열 중 하나.

**📌 보안 인증 목표**

- - **CC EAL5+ FIPS SP800-90B**
  - 이 조합은 어디용이냐?

    - → **정부·금융·산업 인프라·전력 통신·의료** 인증 시장
  - 여기서 중요한까?

    - 삼성 S3SSE2A는 **EAL6+** → 모바일/페이먼트 쪽
    - QS7001은 **EAL5+** → 산업/인프라 쪽
  - 서로 시장을 침범하지 않고 분할하는 구조.
