**✅****제어 메커니즘의 차이**

**💡** **레이저 기반 제어 (IonQ, Quantinuum 등)**

- - **원리**: 레이저 빔을 이온에 직접 쏘아서 스핀 상태를 바꾸거나, 두 이온 간에 얽힘(entanglement)을 생성.
  - **사용 방식**

    - **개별 제어**: 특정 이온만 선택적으로 조준 → 고정밀 단일 큐비트 연산 가능.
    - **쌍 이온 제어**: Mølmer–Sørensen 게이트 등에서 두 이온의 집단 운동을 유도 → 얽힘 생성.
  - **장점**

    - **높은 정밀도**: 현재까지 가장 높은 게이트 피델리티(99.9% 이상) 달성.
    - **다목적성**: 단일-큐비트, 2-큐비트, 다중-큐비트 연산 모두 가능.
    - **포토닉 인터커넥트와 자연스러운 연계**: 레이저로 이온-포톤 얽힘을 쉽게 생성 가능 → IonQ, Quantinuum, QuEra가 네트워크형 QPU를 목표로 함.
  - **단점**

    - **스케일링 제약**:

      - 이온이 많아질수록 각 이온을 개별적으로 조준하기 위한 레이저 빔의 수와 정렬 난이도가 급격히 증가.
      - 레이저 경로를 위한 광학 부품(beam splitter, AOM, mirror 등)이 기하급수적으로 늘어남.
    - **열 관리 문제**: 고출력 레이저 다수 사용 시 시스템 발열 및 진동이 증가 → 크라이오 환경에서 한계.

****

**💡****마이크로웨이브 기반 제어 (Oxford Ionics, 일부 NIST 실험)**

- - **원리**: 칩 근처에 집적된 마이크로파 전극을 통해 전자기장을 생성해 이온의 스핀 상태를 제어.
  - **사용 방식**

    - **온칩 마이크로웨이브 안테나**를 사용하여 모든 이온을 제어.
    - 경우에 따라 **RF 필드와 전기장 보정**을 병행해 모션 모드 안정화.

      - Shared drive에 AC 마이크로파 적용
      - 각 로컬 큐비트에 DC 인가하여 큐비트 제어

출처 : Oxford Ionics 홈페이지

- - **장점**

    - **광학 부품 대폭 축소**: 수십~수백 개의 레이저 빔 대신 칩 기반 마이크로웨이브 라인으로 제어 → 모듈당 물리적 복잡도 감소.
    - **스케일링 유리**: 다수의 이온을 단일 전극 배열에서 동시에 구동 가능
    - **크라이오 환경 최적화**: 낮은 열 발생 → Oxford Ionics가 Infineon 크라이오 CMOS 공정을 선택한 이유.
  - **단점**

    - **선택성 문제**: 모든 이온에 동일한 마이크로파가 걸리므로 특정 이온만 선택하기 어렵다.
    - Oxford Ionics는 **개별 이온 위치 근처에 배치된 DC전극**을 활용해 해결.
    - **얽힘 게이트 구현 난이도**: 광학적 모션 유도가 아니므로 2큐비트 게이트 속도가 상대적으로 느림 → 이를 극복하기 위해 **cryo +CMOS**로 해결 중.

**💡****스케일링 전략의 차이**

|  |  |  |
| --- | --- | --- |
| **구분** | **레이저 기반** **(IonQ, Quantinuum)** | **마이크로웨이브 기반** **(Oxford Ionics)** |
| **제어 방식** | 레이저 빔을 개별 이온에 직접 조준 | 온칩 마이크로웨이브 전극 사용 |
| **하드웨어 복잡도** | 레이저 경로 및 광학 정렬 매우 복잡 | 칩 패키징 내에서 간단히 구현 가능 |
| **얽힘 생성** | Mølmer–Sørensen, Raman 게이트 등 레이저로 직접 | 마이크로웨이브 + DC 전압 |
| **스케일링 전략** | 포토닉 인터커넥트로 QPU 간 연결 (IonQ, Quantinuum) | Tile 모듈 확장 후 광자 인터커넥트 통합 (Oxford Ionics) |
| **온칩 집적화** | 광학 부품 때문에 집적도 한계 존재 | Cryo CMOS 기반 고집적 가능 |
| **게이트 속도** | 수 μs (IonQ ~1.7μs, Quantinuum ~2μs) | 초기에는 느렸으나 Cryo CMOS 적용으로 3~5μs 목표 |
| **주요 도전 과제** | 레이저 수 증가 → 발열, 광학 노이즈, 정렬 난이도 | 이온 선택성, 마이크로파 크로스토크 최소화 |

**💡****IonQ vs Oxford Ionics vs Quantinuum 관점**

- - **IonQ** → 포토닉 인터커넥트 중심, 레이저 기반 고정밀 제어, 단일 QPU 성능보다 네트워크형 QPU에 강점.
  - **Quantinuum** → 레이저 기반 QCCD 아키텍처, 2D 레이아웃 + 포토닉 인터커넥트 병행, QEC 실험 선도.
  - **Oxford Ionics** → 레이저 대신 마이크로웨이브 기반 Cryo CMOS 칩, Tile 모듈 전략, Infineon 파트너십으로 대량생산 가능성↑.

**💡각 이온별 F레벨의 주파수/파장**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **이온종** | **주 사용 상태** | **F-level splitting** | **파장 λ** | **비고** |
| **Ba-137⁺** | 6S₁/₂ | **8.04 GHz** | 37.3 mm | IonQ, NIST 사용 |
| Ca-43⁺ | 4S₁/₂ | 3.23 GHz | 92.8 mm | Oxford Uni 사용 |

| Sr-87⁺ | 5S₁/₂ | 5.00 GHz | 60 mm | Oxford Uni 사용 |

**Ba-137은 Yb-171보다 낮은 주파수를 가지므로 RF 회로 설계가 조금 더 쉽다는 장점이 있다.**

****

**💡****레이저 주파수 vs 마이크로웨이브 주파수**

|  |  |  |
| --- | --- | --- |
| **구분** | **마이크로웨이브** | **레이저** |
| **Ba⁺ hyperfine 전이** | 약 **8.04 GHz** | 대응하는 광자는 X-band 마이크로파 |
| **Ba⁺ 광학 전이** | — | 493 nm → **607 THz**  650 nm → **461 THz** |
| **주파수 비율** | GHz 수준 | THz 수준 → 약 **10⁵배 이상** 높음 |

**💡****레이저로 hyperfine 상태를 제어하는 원리**

- - **직접 마이크로웨이브 구동과 차이점**

    - 마이크로웨이브는 8.04 GHz 공진을 직접 때려서 F=1 ↔ F=2를 바꾼다.
    - 반면 레이저는 **Raman Transition** 또는 **광학 Raman 게이트**라는 방식을 사용해 **간접 제어**한다.
  - **Raman Transition 방식**

    - **원리**

      - 6S1/2(F=1) ↔ 6S1/2(F=2) 전이는 **직접 레이저로 불가능** (8 GHz는 빛의 파장으로 3.7cm라서 광자가 너무 낮은 에너지).
      - 대신 **두 개의 레이저**(Raman beams)를 써서 가상의 전이(virtual transition)를 유도.
    - **동작 구조**

      - **493 nm와 근접한 레이저 두 개**를 사용.
      - 두 레이저의 **주파수 차이**를 정확히 **8.04 GHz**로 맞춤.
      - 두 빔이 만들어내는 비트 패턴(beat frequency)가 hyperfine splitting과 공진.
      - 이온의 전자 스핀 상태(F=1 ↔ F=2)가 바뀜.
    - 즉, **레이저 자체 주파수가 아니라,** **두 레이저 간의 차이 주파수가 hyperfine 전이에 맞도록 조정****하는 것**.
  - **예시 – IonQ Ba****+** **시스템**

    - IonQ는 **493 nm** 및 **650 nm** 레이저를 사용:

      - 493 nm: 6S1/2 ↔ 6P1/2 전이
      - 650 nm: 5D3/2 ↔ 6P1/2 전이
    - 이 레이저들을 **Raman pair**로 구성해서 두 hyperfine 상태를 제어.

      - 예를 들어:

        - 첫 번째 빔: 607.000 THz (493 nm 근처)
        - 두 번째 빔: 607.008 THz
        - **Δν = 8.04 GHz** → F=1 ↔ F=2 전이 공진.
    - 이 때 **AOM(Acoustic-Optic Modulator)** 또는 EOM(Electro-Optic Modulator)를 사용해 레이저 빔의 **주파수 오프셋**을 8.04 GHz에 맞춤.
    - <https://arxiv.org/abs/2308.05071v2> 에 IonQ에서 사용하는 AOM 도식 소개

**💡****왜 레이저를 쓰는가?**

그렇다면 직접 마이크로웨이브(8 GHz)로 제어하면 간단해 보이는데, 왜 IonQ나 Quantinuum은 레이저 기반을 쓰느냐?

- - **장점**

    1. **개별 이온 선택 제어 가능**

       - 레이저 빔을 특정 이온 하나에만 조준 → 단일 큐비트 제어 용이.
    2. **이온-포톤 얽힘 쉽게 생성**

       - 포토닉 인터커넥트를 위해 레이저가 필수.
    3. **멀티큐비트 얽힘 게이트 속도↑**

       - Mølmer–Sørensen게이트 등에서 이온의 공진 모드를 레이저로 효율적으로 구동.
  - **단점**

    - 레이저 수가 많아질수록 시스템 복잡도↑
    - 고출력 레이저 발열, 광학 정렬, 빔 안정성 문제가 큼

**💡****마이크로웨이브 기반(Oxford Ionics)과 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **레이저 기반 (IonQ)** | **마이크로웨이브 기반 (Oxford Ionics)** |
| 제어 원리 | Raman 비트 주파수로 hyperfine 상태 전환 | 8 GHz 마이크로파를 직접 칩에서 방사 |
| 개별 이온 제어 | 빔 조준으로 가능 | 추가 B-필드 gradient 필요 |
| 얽힘 게이트 | Raman sideband 게이트 | 전기장 gradient + 마이크로파 dressing |
| 광학 부품 | 다수 필요 | 거의 불필요 |
| 스케일링 | 어려움 (레이저 수 ↑) | 칩 기반 확장 쉬움 |

**💡****필요한 레이저 빔의 개수**

- - **Individual Addressing 방식**

    - **레이저 광원 수**: 큐비트 수 × 2 ≈ 많은 수 필요
    - **특징**

      - 각 이온을 개별적으로 조준하는 방식.
      - 이 경우 큐비트 개수에 따라 Raman 빔도 선형적으로 증가.
    - **장점**

      - 각 큐비트에 대해 완전한 독립 제어 가능.
      - 병렬 제어 및 멀티큐비트 얽힘 연산에 유리.
    - **단점**

      - 큐비트 수가 많아질수록 **광학 경로 복잡도 폭발적 증가**.
      - 100큐비트 이상 스케일에서는 유지보수 거의 불가능.
  - **Global Raman Beam 방식 (IonQ, Quantinuum 일부 QCCD)**

    - **레이저 광원 수**: 고정된 2개 또는 3개
    - **특징**

      - 493 nm/650 nm 레이저 각각 한 쌍만 준비.
      - 이 두 빔을 **전체 이온 체인에 한 번에 쏨**.
      - 특정 큐비트만 제어하고 싶을 때는 **AOM/AOD**(Acousto-Optic Modulator)를 이용해 선택적으로 쏨.
    - **장점**

      - 광원 수가 큐비트 수와 무관 → **확장성↑**
      - 빔 안정화·파워 캘리브레이션이 단순.
    - **단점**

      - AOM/AOD가 많아지면 노이즈 증가.
      - 체인 길어질수록 빔의 균일성 유지 어려움.

**✅****EOM/AOM/AOD**

**💡****EOM(Electro-Optic Modulator)**

- - EOM은 전기장(전압)을 이용해 **광위상·세기·편광**을 초고속으로 제어하는 장치.

    - **EO 효과(Electro-Optic effect)**:
    - 결정체(보통 LiNbO3, KDP, BBO 같은 Pockels cell 재질)에 전기장을 걸면 **굴절률이 바뀜**.
    - 굴절률이 바뀌면 레이저 빔의 **위상, 편광, 주파수**가 실시간으로 변함.
    - EOM은 **GHz~수십 GHz 대역까지 초고속 변조 가능**해서, AOM보다 더 빠른 조절에 적합.

**💡****AOM (Acousto-Optic Modulator)**

- - **역할**

    - **레이저 빔의 세기, 위상, 주파수를 제어하는 장치**
    - 레이저를 켜거나 끄는 **스위치** 역할을 하거나,
    - 특정 주파수로 빔을 시프팅(frequency shifting)하는 데 사용.
  - **동작 원리**

    - AOM 내부에 **초음파 발생기**가 있다.
    - 초음파가 매질에 주기적인 굴절률 변화를 만들어 회절격자(diffraction grating)처럼 작동.
    - 입사한 레이저가 0차 빔과 1차 빔으로 분리되는데,
    - 보통 1차 빔만 사용해서 **출력 주파수를 정밀하게 조절**.
  - **양자컴퓨터에서의 사용**

    - **Raman 레이저 두 개**를 준비해도 큐비트별로 다르게 쏴야 할 때가 많음.
    - AOM으로 다음을 제어:

      - **주파수**: 각 큐비트마다 약간 다른 Δν 적용 가능.
      - **위상**: 특정 큐비트에 원하는 게이트 위상 구현.
      - **세기(on/off)**: 필요할 때만 큐비트에 빔을 쏨.
    - IonQ에서는 35큐비트를 제어하려면 **최소 35개의 AOM 채널**이 필요.

|  |  |  |
| --- | --- | --- |
| **구분** | **AOM** | **EOM** |
| **동작 원리** | 초음파 → 굴절률 변화 | 전기장 → 굴절률 변화 |
| **응답 속도** | μs-ns (수 MHz수십 MHz 대역) | **수십 ps~ns** (수 GHz 대역 가능) |
| **변조 가능 항목** | 세기(intensity), 주파수, 빔 차단 | **위상, 주파수, 편광** |
| **효율** | 광손실 낮음(70~90%) | 약간 높음(특히 위상 변조 시) |
| **사용 위치** | Raman 빔 개별 큐비트 on/off, 주파수 시프트 | Raman pair의 beat frequency 생성, 초고속 위상 변조 |
| **IonQ에서 역할** | 빔 분배 및 개별 큐비트 제어 | Δν = 8.04GHz Raman 비트 주파수 생성 |

**💡****AOD (Acousto-Optic Deflector)**

- - **역할**

    - AOD는 AOM과 비슷하지만, **빔의 방향(angle)을 빠르게 바꾸는 데 특화**된 장치다.
    - AOD 내부에서 초음파 주파수를 바꾸면 굴절각이 바뀌어, **빔을 원하는 큐비트 위치로 스캔**할 수 있음.
  - **동작 원리**

    - 초음파 주파수를 바꾸면 회절 패턴이 바뀌어 레이저 빔의 출사각도 변경.
    - **수십 마이크로초 단위**로 빠르게 빔을 다른 이온에 옮겨 쏠 수 있음.
  - **양자컴퓨터에서의 사용**

    - 긴 이온 체인에서 개별 이온을 선택적으로 제어할 때 사용.
    - IonQ, Quantinuum 모두 AOD를 사용해서 **단일 Raman pair**로 여러 큐비트를 빠르게 스위칭.
    - AOM 없이 AOD만 써도 되지만, 보통 **AOM + AOD를 조합**해서 더 정밀 제어를 한.

**💡****SLM(Spatial Light Modulator)**

- - **역할**

    - **SLM**은 말 그대로 **공간적으로(spatial)** 빛을 변조(modulate)하는 장치.
    - LCD나 MEMS(micro-mirror) 같은 픽셀 배열을 이용해,
    - **레이저 빔의 강도·위상·편광을 픽셀 단위로 조절**할 수 있다.
    - 쉽게 말해 **2D에서 레이저 빔을 원하는 패턴으로 "조각"하는 디스플레이 장치**.
  - **동작 원리**

    - SLM의 기본 원리는 **픽셀마다 굴절률 또는 반사율을 전기적으로 조절**하는 것.
    - 대부분 **LCOS-LCD(액정 기반)** 또는 **DMD(MEMS 미러 기반)** 사용.
    - 픽셀 하나하나가 **위상 시프터(phase shifter)** 역할을 해서,
    - 레이저 빔을 공간적으로 패턴화 가능.
    - 소프트웨어에서 "이온 체인 위치 좌표"를 입력하면,
    - SLM이 해당 위치에만 레이저 스팟을 생성.
  - **양자컴퓨터에서의 사용**

    - SLM을 통해 빔의 위상을 조절해서,
    - 이온 체인에서 발생하는 간섭 문제나 렌즈 왜곡을 보정.
    - Quantinuum은 특히 **2D QCCD 아키텍처**에서 SLM을 많이 사용.

**💡****레이저 기반 이온트랩 QPU에서 AOM, AOD, EOM 역할 요약**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **장치** | **주요 역할** | **제어 항목** | **속도** | **위치** |
| **EOM** | Raman 빔의 주파수·위상 변조, 비트 주파수 생성 | 위상, 주파수 | **GHz급** | Raman 소스 근처 |
| **AOM** | Raman 빔 개별 on/off, 세기·주파수 시프트 | 세기, 주파수 | MHz급 | 각 큐비트 채널별 |
| **AOD** | 빔 위치 스캔 | 빔 위치 | μs | 이온 체인 스캔 |
| **SLM** | **2D 빔 패턴 생성** → 병렬 제어 | 세기·위상·편광 | ms~10ms | 다중 큐비트 병렬 제어 |

- - **EOM으로 Raman beat frequency를 만들고**,
  - **AOM으로 빔 세기·위상 개별 조절**,
  - **AOD로 큐비트 위치 선택**까지 조합하는 구조
  - **SLM**은 Quantinuum에서 적극 사용
