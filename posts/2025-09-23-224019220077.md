**✅****BTQ Technologies 나스닥 상장 소식 (2025년 9월)**

**💡****핵심 내용**

- - **상장 승인**:

    - BTQ Technologies Corp.가 **2025년 9월 26일(금)** 부터 **나스닥 글로벌 마켓(Nasdaq Global Market)** 에서 **티커 심볼 “BTQ”** 로 거래를 시작한다.
  - **기존 거래소 현황**:

    - OTCQX: 상장과 동시에 거래 종료
    - CBOE Canada (BTQ)와 Frankfurt 증권거래소 (NG3): 계속 거래 유지
  - **상장 조건**:

    - 미국 SEC에 제출한 **Form 40-F 등록 성명서** 발효 등 규제 요건 충족이 필수

**💡****CEO 발언 (Olivier Roussy Newton)**

- - 나스닥 상장은 회사가 **다음 성장 단계로 도약하는 중요한 진전**
  - 더 넓은 투자자 풀에게 BTQ의 **차별화된 양자 플랫폼**에 접근할 수 있는 기회를 제공할 것이라고 강조

**💡****의미**

- - OTC 시장에서 벗어나 나스닥 글로벌 마켓에 상장함으로써 **글로벌 투자자 기반 확대**
  - 캐나다, 독일, 미국 주요 거래소에 **동시 상장 상태**를 유지 → 유동성 및 신뢰도 강화
  - BTQ가 표방하는 **양자 보안(quantum security)·네트워크 보호 기술** 기업으로서의 입지를 강화

---

**✅****BTQ Technologies 개요**

- - 캐나다 밴쿠버에 본사를 둔 양자 기술 기업이며, 사무소가 시드니에도 있음.
  - 설립자들은 **포스트-양자 암호(post-quantum cryptography, PQC)** 전문가들이며, 양자 컴퓨팅이 본격화됨에 따라 전통 암호 방식들이 위험해질 것을 대비해 보안 솔루션 개발에 중점.
  - 조직 형태는 꽤 수직적(full-stack)이며, 하드웨어 + 소프트웨어 + 암호 알고리즘 + 보안 프로토콜 전반에 걸쳐 제품 및 연구개발을 병행함.

**💡****주요 사업 / 제품 분야**

- - BTQ는 여러 제품과 기술을 운영하고 있으며, 특히 다음 영역에서 두각을 나타냄:

|  |  |
| --- | --- |
| **사업 영역** | **기능 / 역할** |
| **포스트-양자 암호 (PQC) 솔루션** | 기존 암호체계가 양자컴퓨터로부터 공격 받을 가능성에 대비해, 견고한 암호 알고리즘, 서명(signature) 방식, 제로 지식 증명(zero-knowledge proof) 등을 개발. 예: Preon (PQC 서명), PQScale (lattice 기반 PQ 서명 스케일링) 등. |
| **디지털 자산 / 블록체인 / 스테이블코인 보안** | 암호화폐, 스테이블코인, 토큰화 자산(tokenized assets) 등에 양자-안전성(quantum-secure)을 내장하기 위한 프레임워크 및 네트워크 개발. 예: QSSN (Quantum Stablecoin Settlement Network) 을 통해 JPMorgan의 USD deposit token 등의 사례. |
| **Quantum Proof-of-Work (QPoW)** | 기존 Proof-of-Work (PoW) 방식의 블록체인 채굴(consensus) 메커니즘을 양자 기법을 포함하여 설계하고, 고전적 하드웨어에서도 검증 가능한 시뮬레이터 제공. |
| **무작위 수 생성 (Random Number Generation, QRNG)** | 보안 키 생성 등에 필요한, 양자 기반 또는 양자 저항성(randomness) 있는 난수 생성 도구 제공. 제품명 중 QRiNG 등이 있음. |
| **양자 위험 평가 / 도구 / 소프트웨어** | QByte (quantum risk calculator), 다양한 컴파일러, hardware-agnostic 언어 / 툴킷, 알고리즘 및 커뮤니케이션 프로토콜 보안 연구 등. 또한, Macquarie University 등 학계와 협업하여 통신 프로토콜 및 오류 수정(error-correction) 등의 연구 진행. |

**💡****파트너 및 고객 / 적용 사례**

- - 다음은 BTQ와 협업하고 있거나, BTQ 솔루션이 실제로 적용 가능성이 확인된 주요 기관/기업/사례들:

|  |  |
| --- | --- |
| **파트너 / 고객 / 적용 사례** | **내용** |
| **Macquarie University (호주)** | 보안 통신과 양자 알고리즘을 공동 연구. PhD 학생 인턴십, 양자 처리 (quantum processing) 통신 프로토콜 개선 등의 프로젝트. |
| **Sydney Quantum Academy (호주)** | 지역 인재 육성, 학계-산업 협력 등을 위해 협업. |
| **호주 정부 및 NSW 정부** | BTQ Australia 설립, 투자 및 지역 연구 생태계 지원. |
| **블록체인 / 스테이블코인 플랫폼** | QSSN 프레임워크를 통해 JPMorgan의 USD deposit token (JPMD), Circle, Tether 등과 같은 스테이블코인 또는 발행/관리 플랫폼을 quantum-secure 하게 만드는 방안이 시연됨. |
| **규제 / 표준 기관** | 미국의 Post-Quantum Financial Infrastructure Framework (PQFIF) 에서 QSSN이 인용됨. QuINSA (Quantum Industrial Standard Association) 에서 QSSN이 글로벌 표준 이니셔티브로 통과됨. |
