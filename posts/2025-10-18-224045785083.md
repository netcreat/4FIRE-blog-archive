**✅****양자 통신을 위해 필요한 기술과 디바이스**

- - 위와 같이 Alice와 Bob을 위한 양자 네트워크가 아닌 Charlie, David, .... Zoro 등 다양한 네트워크 노드들이 Point-to-point가 아닌 멀터엑세스가 가능한 네트워크를 구성하기 위해서는 고전 네트워크에서 사용되는 개념이 동반되어야 하는데, 이것이 바로 "스위칭"과 "라우팅"이다.

**💡****Quantum Teleporting Switch**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTEwMThfMjMz/MDAxNzYwNzgyMzA4Mzk0.2rBN9eoghl6hSBUs4CTm_xrO1wIzvCadguH3Jtl5gR8g.buxFI4-YaVZidWidJnZPVbIKAl5gDgSZX8q_X0KQjpwg.PNG/image.png?type=w800)](#)

출처 : Cisco Live

- - **Quantum Teleportation Switch**는 얽힘을 “엔드포인트(앨리스–밥)”에서 직접 생성하는 대신 **네트워크 중간 노드**에서 생성해 **분배**하는 역할을 한다.
  - 이 스위치는 **얽힌 광자 쌍(Entangled Pair)** 을 만들어 한 광자는 앨리스에게, 다른 하나는 밥에게 전달한다.
  - 얽힘 생성을 네트워크 중앙에서 처리하므로, 각 단말(사용자)은 직접 얽힘을 생성할 필요 없이 **얽힘 리소스**를 “서비스처럼” 공급받는다.
  - 이 개념은 **양자 인터넷의 라우팅 계층(Quantum Network Layer)** 의 시작점이다.

**💡****Extending Quantum Teleporting — Entanglement Swapping**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTEwMThfMTU1/MDAxNzYwNzgyMzE2MDUx.H4sFHvK_ywp0cedhXLkAn6_fPQSrsV-0J8OvwmABKlog._HJ8p5519aVc5VDMsOty-Q1O2TnxURUoYEyN-Dk7R4Ig.PNG/image.png?type=w800)](#)

출처 : Cisco Live

- - **Entanglement Swapping**은 “얽힘을 중계 노드를 거쳐 이어붙이는 기술”이다.
  - 예를 들어:

    - 첫 번째 쌍: (앨리스–스위치1)
    - 두 번째 쌍: (스위치1–스위치2)
    - 세 번째 쌍: (스위치2–밥)
  - 중간 노드에서 **벨 상태 측정(Bell Measurement)** 을 수행하면, 직접 연결되지 않은 앨리스–밥 사이에도 새로운 **얽힘이 생성**된다.
  - 얽힘이 “점프”하여 멀리 있는 노드 간에 이어진다.
  - 이 과정을 **반복적으로 수행**하면, 멀리 떨어진 두 노드 간의 **엔드투엔드(end-to-end)** 얽힘이 가능해진다.

> 즉, “Entanglement Swapping = 얽힘 릴레이(중계) 기술”이라 할 수 있다.
>
> 실제로 **IonQ**는 Lightsync를 인수함으로써 Quantum Repeater의 기술을 확보하게 되었고, 위의 스위칭 기술로 기존 대비 50배 이상의 속도 향상을 밝힌바 있다. 이는 IonQ에서 최초로 언급했던 Photonic Interconnect의 2단계 또는 3단계에 해당된다.
>
> (2단계와 3단계의 차이는 연구 수준의 연결과 상업용 수준의 빠르고 안정적인 연결의 차이인데, 이미 2단계는 완성한 후 LightSync를 인수했는데, 아직 공식적으로 3단계 완성 발표는 없는 상태임)

- - **Elementary Link Entanglements**

    - 각 라우터(파란 노드)는 **이웃 노드와 짧은 거리의 얽힘(기본 링크)** 을 먼저 만든다.
    - 이는 “광자 페어 전송 + 얽힘 확인(피델리티 측정)” 과정을 통해 완성된다.
    - 각 구간은 손실이 적고 안정적인 **로컬 얽힘**으로 유지된다.
  - **Entanglement Swapping**

    - 인접 링크들을 **순차적으로 벨측정(BSM)** 하여 얽힘을 확장한다.

      - 노드1이 (앨리스–노드1)과 (노드1–노드2)를 벨측정으로 교환
      - 노드2가 (노드2–노드3)과 (노드3–밥)을 벨측정으로 교환
      - → 결과적으로 앨리스–밥 사이에 **직접 얽힘 형성**
    - 이 일련의 교환으로 얽힘은 “Hop-by-Hop” 방식으로 전파된다.
  - **End-to-End Entanglement**

    - 여러 번의 교환(스와핑)을 거친 후, 앨리스와 밥은 **한 쌍의 얽힌 광자**를 공유하게 된다.
    - 이제 두 사람은 **양자 키 분배(QKD)**, **양자 텔레포테이션**, 또는 **분산 양자 연산**을 수행할 수 있다.
  - **Network Failure Event**

    - 현실의 광자 링크는 **손실(loss), 감쇠, 간섭, 디코히런스**에 의해 쉽게 끊어진다.
    - 중간의 한 링크가 손상되면(예: “failed link”),
    - 전체 end-to-end 얽힘이 **붕괴**된다.
  - **Reestablishing End-to-End Entanglement**

    - 네트워크는 **재라우팅(Rerouting)** 또는 **새로운 얽힘 경로 생성**으로 복구한다.
    - 이때 **양자 라우터**는 다음을 수행한다.

      1. 남아 있는 노드들 간 새 얽힘 링크를 만든다.
      2. 스와핑 순서를 다시 조정한다.
      3. 결과적으로 앨리스–밥 사이 얽힘을 복원한다.
    - 이는 고전 네트워크의 “경로 재설정”과 유사하지만, 데이터 대신 **양자 상태의 상관관계**를 복원하는 점이 다르다.

> 멀티 노드간의 안정적인 양자 연결 및 Failover 등이 구현되면 비로소 **양자 네트워크** 또는 **양자 인터넷**이 완성이 되는 것이고, 이것은 IonQ가 발표한 Photonic Interconnect의 4단계에 해당한다.

**✅****Quantum Routing Protocol (QRP)**

**1️⃣ 개념 개요**

- - 양자 라우팅 프로토콜(QRP)은 **얽힘을 네트워크 전역에 분배하고 관리**하기 위한 통신 규약이다.
  - 고전 인터넷에서 패킷이 데이터(payload)를 운반한다면, 양자 네트워크의 패킷은 “얽힘 상태의 상관관계”를 운반한다.
  - 즉, QRP의 목적은 다음과 같다.

    - 어떤 노드들이 얽힘을 공유하고 있는지 **경로를 파악하고**,
    - 필요한 얽힘 쌍을 생성·스와핑·보정하여 **엔드투엔드 연결을 완성**하고,
    - 손실이나 decoherence 발생 시 **재라우팅 및 복원**을 수행하는 것.

**2️⃣ 네트워크 계층 구조 대응표**

|  |  |  |
| --- | --- | --- |
| **고전 네트워크 계층** | **양자 네트워크 대응** | **역할** |
| **Physical Layer** | Quantum Channel (광자 전송) | 광자 이동, 편광/위상 유지 |
| **Data Link Layer** | Elementary Link Protocol (ELP) | 인접 노드 간 얽힘 생성 및 검증 |
| **Network Layer** | Quantum Routing Protocol (QRP) | 여러 링크를 조합하여 얽힘 경로 구성 |
| **Transport Layer** | Entanglement Distribution Protocol (EDP) | 얽힘 품질(피델리티) 유지 및 재시도 제어 |
| **Application Layer** | Quantum Application Layer | QKD, Teleportation, Distributed Computing 등 |

**3️⃣QRP의 주요 동작 절차**

- - **① Route Discovery (경로 탐색)**

    - QRP는 각 노드 간의 **얽힘 맵(entanglement map)** 을 유지한다.
    - 얽힘 가능한 경로를 찾기 위해 **양자 라우팅 테이블**을 사용한다.
    - 이 과정은 고전 네트워크의 OSPF 또는 BGP와 유사하게 작동한다.
    - 예: 가장 높은 피델리티, 가장 낮은 손실, 가장 짧은 지연을 기준으로 최적 경로 선택
  - **② Entanglement Establishment (얽힘 확립)**

    - 선택된 경로의 각 노드 쌍이 **Elementary Link**를 만든다.
    - 각 링크에서 성공 신호(“herald”)가 오면 QRP가 상위 노드로 보고한다.
    - 모든 구간이 성공하면 **엔드투엔드 얽힘 준비 완료**로 표시된다.
  - **③ Entanglement Swapping & Confirmation**

    - 중간 라우터들은 **BSM(Bell-State Measurement)** 을 수행해 얽힘을 이어붙인다.
    - BSM 결과는 QRP 패킷의 **Correction-Code 필드**에 저장되어 다음 노드로 전송된다.
    - 마지막에 앨리스와 밥은 “얽힘 완료(confirmed)” 메시지를 교환한다.
  - **④ Error Detection & Recovery**

    - QRP는 **Fidelity-Tag**가 일정 임계치(예: 0.85) 이하로 떨어지면
    - 자동으로 재시도(retry)를 수행한다.
    - 링크 손실 시, 고전 경로 프로토콜처럼 **대체 경로를 탐색**하여
    - 얽힘을 다시 확립한다.
    - 필요 시 이전 얽힘을 **폐기(entanglement purging)** 하고
    - 새 얽힘을 생성한다.
  - **⑤ Resource Release**

    - 사용 완료된 얽힘 쌍은 “소멸(deallocate)” 상태로 표시된다.
    - 메모리 리소스를 확보하고, Fidelity Monitor는 새 쌍 생성을 허용한다.

**4️⃣QRP의 보조 프로토콜 계층**

|  |  |
| --- | --- |
| **보조 프로토콜** | **역할** |
| **EDP (Entanglement Distribution Protocol)** | 얽힘 생성을 반복하면서 성공률을 높이는 제어 루프 |
| **EPP (Entanglement Purification Protocol)** | 노이즈 얽힘을 고품질 얽힘으로 정제 |
| **QP (Quantum Ping)** | 얽힘 연결의 유효성을 테스트(고전 ping과 유사) |
| **QCMP (Quantum Control Message Protocol)** | 라우터 간 얽힘 상태 통계 공유 |
| **QEC Layer (Quantum Error Correction)** | 얽힘 전송 중 decoherence 보정 |

**5️⃣고전 라우팅과의 핵심 차이**

|  |  |  |
| --- | --- | --- |
| **항목** | **고전 네트워크** | **양자 네트워크** |
| 전송 단위 | 데이터 패킷 | 얽힌 상태(양자 상관관계) |
| 증폭 방식 | 전기 신호 증폭 | 복제 불가 → 스와핑 필요 |
| 오류 제어 | 패킷 재전송(ARQ) | 얽힘 재생성 및 정제(EPP) |
| 동기화 | 시간 지연 허용 | 펨토초 단위 동기화 필요 |
| 복구 방식 | 라우팅 테이블 갱신 | 얽힘 경로 재구성 + BSM 재실행 |
| 보안성 | 암호화 기반 | 물리적 원리 기반(양자 키 분배) |

> **QRP의 철학**
>
> 양자 네트워크에서 “라우팅”이란, 데이터의 경로를 찾는 것이 아니라 **“얽힘의 경로를 최적화”** 하는 것이다.

[**Resource Placement for Rate and Fidelity Maximization in Quantum Networks**](https://arxiv.org/html/2308.16264v3)

- - 이 지도는 **미국 동부와 중서부 지역의 ESnet(미국 연구 네트워크) 서브셋**을 대상으로 양자 리피터 및 보조 노드의 최적 배치를 계산한 결과를 나타낸 것이다.

    - **초록선/검은선** → 양자 얽힘 링크
    - **빨간 사각형 (■)** → 최종 사용자 노드 (End User)
    - **초록 사각형 (■)** → 기존 라우터 (Router) 또는 양자 라우터
    - **검은 원 (● 또는 ○)** → 양자 리피터 또는 후보 노드
    - 채워진 검은 원 (●): 실제로 리피터로 선택된 노드
    - 빈 검은 원 (○): 후보로 남았으나 사용되지 않은 노드
    - **초록 원 (●)** → 보조 라우터 (Auxiliary Router)
    - **초록 원 테두리만 있는 원** → 보조 리피터 (Auxiliary Repeater)
  - 이 네트워크는 **얽힘 분배 간격을 약 60 마일(≈ 100 km)** 로 설정해 가장 긴 기본 링크를 만들도록 최적화됐다.

**💡****시사점**

1. 1. **중간 노드 밀도 증가**

      - 광자 감쇠 문제로 약 **100 km마다 리피터가 필요**하다는 점이 확인된다.
      - 미국 동부–중서부 구간만으로도 약 20개 이상의 리피터 노드가 필요함.
   2. **기존 라우터 활용성**

      - ESnet 같은 국가연구망은 이미 잘 분산된 라우터 구조를 갖고 있어, 양자 라우팅 계층(QRP)을 추가하기에 적합하다.
   3. **보조 노드(Auxiliary Nodes)의 전략적 배치**

      - 일부 보조 노드는 정상 상태에서는 비활성 상태로 두되, 링크 장애나 노이즈 증가 시 즉시 대체 경로로 활용할 수 있게 한다.
   4. **실제 배치 설계 적용성**

      - 이런 모델은 단순히 이론이 아니라, 양자 라우터 및 리피터 실제 설치 경로를 정량적으로 결정할 수 있는 **“Network Planning Tool”** 로 활용 가능하다.
