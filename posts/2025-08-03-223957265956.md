# 양자 네트워트의 사용 사례

Published: 2025-08-03T15:22:17.994000+09:00

Original Naver post: https://blog.naver.com/4-fire/223957265956

---

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTA4MDNfMTIy/MDAxNzU0MjAxNDczODQ3.UjnqNoOFIKyIB8c1FSwNDoV5fnFCh2mw576t3BESEsMg.GRpYDXrgxtjDTdGIDP5UfZrTnX0RuXbbE12RMQTjOKsg.PNG/image.png?type=w800)](#)

인터넷에 올라오는 많은 양자 인터넷 관련된 글을 접했을때, 대부분 양자 얽힘을 몇키로미터까지 했다는 식의 내용이 많은데, 이것은 마치 대략 20년전부터 디지털 카메라가 처음 보급되고 핸드폰에 탑재되던 시기에 몇만화소, 몇백만화소 이런식의 스펙 경쟁을 하던 시절을 떠올리게 된다.

오늘은 양자 네트워크가 어떻게 사용될 것이며, 각각의 사용처에 어떤 기술이 필요할지 살펴보겠다.

****

**📡양자 네트워트의 목적**

****

**1️⃣ 순수 통신 목적 (얽힘 불필요)**

- **설명**

  - 단순히 원격 노드 간 **양자 상태를 전송**하거나 **QKD를 수행**하는 경우이다.
  - 얽힘 없이도 **단일 광자 전송**이나 **측정 기반 프로토콜**만으로 가능하다.
- **예시**

  - BB84 QKD: 송신자가 무작위 편광 상태 광자 전송 → 수신자가 측정
  - 단일 광자 기반 원격 양자 센싱

****

**2️⃣ 신뢰도 향상 목적 (얽힘 필요)**

- **설명**

  - 네트워크 품질이 낮거나 잡음이 큰 경우, 얽힘을 사용해
  - **양자 텔레포테이션**, **얽힘 정제**, **양자 중계기** 같은 기법으로 전송 신뢰도를 높인다.
  - 이 경우 얽힘은 데이터 자체보다는 **통신 채널의 안정화**에 쓰인다.
- **예시**

  - 위성-지상 간 장거리 QKD (예:중국의 세계 최초 양자 통신 위성 묵자-Micius)
  - 얽힘 스와핑을 이용한 다중 홉 양자 링크

****

**3️⃣ 분산 연산 목적 (얽힘 필수)**

- **설명**

  - 여러 양자 노드가 하나의 **논리적 양자 컴퓨터**처럼 동작하려면
  - 노드 간에 큐비트를 직접 이동시키거나 **분산 게이트 연산**을 수행해야 한다.
  - 여기서는 얽힘이 필수적이다.
- **예시**

  - 분산 Shor 알고리즘
  - 다중 노드 양자 시뮬레이션

    - MPI(Message Passing Interface) - 병렬 프로그래밍 표준의 양자 버전
  - IonQ의 **Photonic Interconnect QPU**

---

**🔑광통신의 중요성과 한계**

위의 세가지 사례중에서, 순수통신 목적중 QKD조차도 필요하지 않은 경우(기존의 고전 광통신으로 충분)를 제외하고는 모두 **양자 채널이 필요**하다. 즉, 통신 매체를 이용하여 이동하는 것이 단순한 비트가 아닌 **큐비트**여야 하고, 큐비트를 원거리간 전송하기 위한 매체로서는 **광통신**이 유일하다.

**1️⃣ 왜 대부분 광자를 쓰는가?**

1. **장거리 전송 손실 최소화**

   - 광자는 전기적 중성, 질량이 없어서 **광섬유·자유공간 전송에 유리**하다.
   - 감쇠는 존재하지만, 초전도 케이블로 전자 스핀이나 이온을 보내는 것보다 훨씬 유리하다.
2. **얽힘 생성·검출 기술 성숙**

   - SPDC, QD 기반 단일광자·얽힘 광원 기술이 상용화 수준
   - 단일광자 검출(SNSPD, Si-APD) 기술이 확립
3. **빛의 속도와 위상 안정성**

   - 빠른 전송, 위상·편광 자유도를 이용한 인코딩 가능
   - 시간-편광-위상 등 다양한 DOF(Degrees of Freedom) 활용

> **용어 정리**
>
> **SPDC** : 포토닉 QC에서 광자를 생성하기 위한 기본 요소로서, 펌프 레이저 → 에너지 보존 법칙을 따라 **광자 2개 생성**
>
> **QD(Quantum Dot) :** 여기된 전자가 떨어질 때 **단일광자를 방출**하는 원리
>
> **SNSPD (Superconducting Nanowire Single-Photon Detector)** : 극저온에서 초전도 상태인 나노와이어에 광자가 입사하여 전기 신호를 발생하는 기술로, 검출 효율은 좋지만, 극저온이 필요하다는 단점
>
> **Si-APD(Silicon Avalanche Photodiode)** : 단일광자가 실리콘 반도체에 흡수되어 전기장으로 증폭하여 전기 펄스를 발생시키는 기술로, 상온에서 운용이 가능하지만, 잡음에 취약하다는 단점

**2️⃣ 광자 외 대안 후보**

- **물질 큐비트 직접 전송 (이온/원자/전자 스핀)**

  - **장점**

    - 저장된 상태를 그대로 이동시키므로 변환 필요 없음
  - **단점**

    - 진공, 자기장, 초전도 배선 등 인프라 필요
    - 수 m 이상 이동이 현실적으로 어려움
  - **활용 예시**

    - **이온트랩 내부**에서 이온을 셔틀링
    - **고체 스핀 체인**에서 근거리 양자 상태 전달

→ 사실상 **근거리 칩·실험실 수준 통신**에만 유효

- **음향·기계적 양자 상태 (Phonon, Magnon)**

  - **개념**

    - 초전도체나 스핀 집합에서 **집단적인 진동·스핀파**를 양자 정보 매개체로 사용
  - **장점**

    - 국소적인 칩 내부 전송 가능
  - **단점**

    - **극저온 + 진동 민감**
    - 장거리 전송 불가, 감쇠 매우 큼

→ **칩 내부 인터커넥트**용 후보, 장거리 네트워크에는 부적합

****

- **중간 변환(Transduction) 방식**

  - **전략**

    - 물질 큐비트 ↔ 마이크로파 ↔ 광자 변환
    - 예: 초전도 큐비트 → 마이크로파 포톤 → 광자 변환 후 전송
  - **장점**

    - 기존 **초전도/스핀 기반 QPU**와 양자 인터넷 연결 가능
  - **단점**

    - 변환 효율 <50%, 잡음·손실 문제
  - **연구 예시**

    - JILA, NIST: 기계적 진동자·광자 하이브리드 트랜스듀서 연구
    - Google/IBM: 초전도-광자 변환 실험 중

****

**3️⃣ RF(마이크로파) 주파수는 사용할 수 없나?**

- **단일광자 검출 문제**

  - 양자 통신은 **단일광자 단위**로 동작한다.
  - RF 마이크로파(수 GHz) 대역은 에너지(ℏω)가 너무 낮아 **단일광자 검출이 현실적으로 불가능**하다.
  - 예: 10 GHz 광자 에너지 ≈ 4.1×10-5 eV

    - 열 잡음(kT ≈ 0.026 eV @ 300K)에 완전히 묻힘(634배 크다)
    - 극저온일 경우 마이크로파 광자가 열잡음보다 10배이상 커짐(kT ≈ 2×10-6 eV @ 10~20mK)→ 안정적 동작 가능
- **열 잡음(Blackbody Noise) 압도적**

  - 마이크로파 대역은 열복사 배경 잡음이 크다.
  - **극저온 환경이 아닌 한 단일광자 신호 구분 불가**
  - 실제 초전도 양자컴퓨터에서 마이크로파 신호를 쓰는 이유가 10~20 mK 극저온 환경이기 때문이다.
- **대기 전파창 문제**

  - RF 대역은 지구 대기 통과에는 유리하지만 **양자 상태의 위상 및 편광을 보존하기 어렵다**.

**4️⃣광자 외 대안 없음**

- **광자 외 대안**은 모두 **근거리·실험실 스케일**에 제한된다.

  - **근적외선(약 800~1550 nm)**

    - 장거리 양자 통신·QKD 표준 대역
    - 이유:

      - **단일광자 검출**(Si-APD, SNSPD) 가능
      - 광섬유·대기 감쇠 최소

        - 800 nm: 자유공간에 유리
        - 1550 nm: 광섬유 손실 최소
- 미래에는 **물질 큐비트 ↔ 광자 트랜스듀서**가 발전하면

  - 칩 내부는 전자/이온
  - 장거리 전송은 광자
  - 형태의 **하이브리드 네트워크**가 될 가능성이 높다.

이전 포스팅에서도 언급했듯이 QPU내부의 큐비트와 통신용 큐비트를 서로 다른 것을 사용해야 가장 효율적이다.

→ **아이온큐의 포토닉 인터커넥트는 물질을 광자로 바꾸는 과정이 필요한 대신에, 이온 상태의 큐비트에 레이저로 에너지를 가하면 직접 광자가 방출되는 원리이므로, 트랜스듀서가 필요 없다.**

**5️⃣ 양자 통신에서 광통신의 한계**

- **자유공간 통신 한계**:

  - 날씨(대기굴절, 구름, 비, 눈, 안개), 낮(태양광)
  - 대기 산란/흡수
  - 거리2에 비례해 수신 광자 수 급감
- **장치 및 기술적 한계**:

  - 위성과 기지국간 포인팅 및 정렬 문제
  - 단일광자 검출 한계 → **극저온(SNSPD) 또는 상온에서 사용가능한 개선 기술(Si-APD) 필요**
- **광섬유 통신 한계**:

  - 1550nm 대역 감쇠 ~0.2dB/km

    - 100km → 20 dB 손실 → 1% 신호만 남음
    - 장거리 전송시 중계기/증폭기 필수
  - 분산문제

    - 파장 또는 모드 차이에 따라 펄스가 퍼지는데,
    - 양자 통신은 **펄스 폭과 위상 안정성**이 더 중요함
  - 연결 손실

    - 케이블 연결부에서 손실 발생
    - 장거리 배치시 신호 품질에 영향
- **양자 통신 시 추가 제약**:

  - **증폭 불가**→ **양자 중계기 필요**
  - 단일광자 손실 치명적→ **초저손실 광섬유 필요**

**🔑광통신의 과제 해결 방안**

****

**1️⃣ 정밀 포인팅·추적 문제 해결**

- **문제**

  - 단일광자 신호는 매우 약해, cm 단위 지향 오차도 신호 손실로 이어진다.
  - LEO 위성은 초속 ~7.5 km로 이동하므로 포인팅·트래킹이 매우 까다롭다.
- **해결책**

  - 3중 추적 시스템 적용

    - **GPS·관성항법**으로 초기 궤도 예측
    - **광학 망원경 + 와이드필드 카메라**로 지상국 위치 확인
    - **레이저 비콘 양방향 추적**으로 실시간 정밀 보정 (㎝ 단위)

****

**2️⃣ 광자 손실·대기 산란 문제 해결**

- **문제**

  - 광자는 대기 산란·흡수로 쉽게 사라진다.
  - 낮 시간에는 태양광 배경광이 단일광자 검출을 방해한다.
- **해결책**

  - **야간 통신만 수행** (배경광 최소화)
  - **높은 궤도(500~600 km) 선택** → 대기 통과 경로 최소화
  - **빔 다이버전스 최소화 설계** (약 10 μrad 수준)

    - 빔 다이버전스(Beam Divergence) : 레이저나 광자가 멀리 전파되면서 퍼지는 각도
    - 10μrad 인 경우 레이져를 500km 떨어진 지상국에 쏘게 되면 지상에 도착할때의 직경이 500,000m x 10-5=5m

      - 지상에 도착할 때 빔 직경이 5m라는 의미
      - 다이버전스를 최소화 해야 다음의 이점이 생김

        - **신호 세기 유지**
        - **단일광자 검출 확률 증가**
        - **산란 및 배경광 영향 최소화**
  - **고효율 단일광자 검출기 사용** (Si-APD, 50% 이상 효율)

****

**3️⃣ 단일광자·얽힘 광원 안정화 문제 해결**

- **문제**

  - SPDC 기반 얽힘 광원은 온도·진동에 민감하다.
  - 위성 환경은 진동·열변화가 심하다.
- **해결책**

  - **위성 전용 소형 SPDC** 광원 개발

    - 810 nm 대역 얽힘 광자 쌍
    - 내부 온도 안정화 ±0.1℃
  - **광학 모듈 고정밀 진동 감쇠 설계**
  - **위성 내부 열제어 시스템**으로 안정성 확보

****

**4️⃣ 극저전력 단일광자 검출 및 노이즈 억제**

- **문제**

  - 단일광자 신호는 초약하고, 지상·우주 배경광에 취약하다.
- **해결책**
- **좁은 필터링 + 시간 동기화**

  - 810 nm 협대역 필터
  - 위성-지상 시계를 수 ns 단위 동기화
- 다크카운트 최소화된 **Si-APD 사용**

  - 다크카운트란 실제 광자가 없는데도 검출 신호가 발생하는 현상
- 상온 운용 가능, 100~1,000 cps 수준 다크카운트

****

**5️⃣ 네트워크·운용 전략**

- **문제**

  - 단일 위성으로는 짧은 통신 시간만 확보 가크능
  - 글로벌 링크·실시간 QKD는 어렵다.
- **해결책**

  - **패스 단위 통신 전략**

    - 한 번 통과할 때 5~10분 동안 QKD 수행
    - 하루 수 회 기회 활용
  - **지상 네트워크 연동**

    - 단순 QKD를 넘어, 장기적으로는 **지상 양자망 + 위성망** 통합 필요

****

**6️⃣ 양자 중계기(Quantum Repeater)**

- **필요 이유**

  - 양자 통신에서 **광자 신호는 증폭 불가** (No-Cloning Theorem)
  - 장거리 통신 시 감쇠·잡음 누적으로 신뢰도 급격히 저하
  - → 고전 통신처럼 단순 중계기(Amplifier) 불가능
- **작동 원리**

  - **짧은 구간(50~100 km)마다 얽힘 생성**
  - **중간 노드에서 Entanglement Swapping 수행**
  - 예: A—B, B—C 얽힘 → A—C 얽힘 확장
  - **Entanglement Purification(정제)**

    - 잡음이 많은 얽힘 여러 개 → 신뢰도 높은 얽힘 1개
- **결과**

  - 수백~수천 km 단위로 안정적인 장거리 양자 링크 가능
  - 글로벌 양자 인터넷 핵심 기술
- **Lightsynq**

  - IonQ의 Lightsync 합병은 양자 인터넷 시대를 여는 결정적 연결고리이다. 다음은 Lightsync가 보유한 핵심 기술이다.

|  |  |  |
| --- | --- | --- |
| **기술 요소** | **설명** | **기능** |
| **다이아몬드 색소 중심 (SiV color centers)** | 다결정 광자 소자에 내장된 양자 메모리 | 얽힘 상태 저장 및 Bell 측정 지원 |
| **광자 인터커넥트 (Photonic Interconnect)** | 광자 기반 연결 구조 | 고신뢰도 다중 QPU 간 통신 |
| **Memory‑enhanced repeater** | 얽힘 저장 + 스와핑 기능 결합 | 장거리 얽힘 분배 및 품질 유지 가능 |

**7️⃣ 초저손실 광섬유 (Ultra-Low-Loss Fiber)**

- **필요성**

  - 양자 통신은 단일광자 전송
  - 손실 0.2 dB/km → 100 km에 99% 신호 소실
  - 장거리 QKD·얽힘 분배는 사실상 불가능
- **초저손실 기술**

  - 표준 SMF-28: 0.2 dB/km @ 1550 nm
  - ULLF: 0.14~0.15 dB/km (Fujikura, Corning)
  - 얽힘 분배 거리를 50% 이상 연장 가능
- **한계**

  - 200~300 km 이상 → 여전히 광자 수 거의 0
  - 결국 **양자 중계기와 병행 필요**

---

결국, **양자 통신을 구현하기 위해서는 현재로서는 대안이 없으므로 광통신을 이용해야 한다.**

그리고, **광통신으로 안정적인 양자 채널을 유지하려면 여러 핵심 기술이 필요하며, 그 중심에는 양자 중계기가 있다.**

지구 규모의 양자 채널을 구축하려면 **양자 위성 통신**이 필수적이며,

보안을 유지하기 위해서는 QKD는 두말할 나위 없다.

이 세 가지 영역을 각각 맡는 대표 기업을 꼽자면,

- **양자 중계기** → **Lightsynq**
- **양자 위성 통신** → **Capella Space**
- **양자 암호(QKD)** → **ID Quantique**

이들이 각자의 분야를 책임질 것이다.
