**✅NDSA 와 PWSA**

- - NDSA는 전체 국가 우주 방어 아키텍처의 ‘전략적 개념(umbrella architecture)’이고, PWSA는 그 내부에서 SDA가 구축하는 실제 실행·운영 레이어 기반 체계이다.

**📌 관계 구조**

- - **NDSA (National Defense Space Architecture)**

    - **PWSA (Proliferated Warfighter Space Architecture)** ← SDA 구축

      - Transport Layer
      - Tracking Layer (T1/T2)
      - Custody Layer (T3 AMTI 포함)
      - Navigation Layer
      - Support / Deterrence Layer
    - **OPIR (SBIRS / Next-gen OPIR)** ← SPACE FORCE
    - **HBTSS (Fire-control tracking)** ← MDA + SDA 협업
    - 요격체(Interceptors: GPI/SM-6/GMD/THAAD/Aegis/BMD)
    - 지상 및 해상 전략 레이더

|  |  |  |
| --- | --- | --- |
| **항목** | **NDSA** | **PWSA** |
| 정체성 | 국가 전략 아키텍처 개념 | SDA 실행 아키텍처 |
| 구성 | 여러 부서/기관 시스템 포함 | SDA가 만드는 LEO 위성망 중심 |
| 참여 기관 | Space Force, MDA, NRO, NGA, Navy, Army | SDA 단독 주도 |
| 초점 | 전체 통합 | 전투자 지원 실전 체계 |
| 위치 | 상위 Umbrella | 하위 실행 구조 |
| 위성 궤도 | LEO+MEO+GEO+HEO 전 영역 | Proliferated LEO 중심 |

> **NDSA = 전체 국가 우주 방어 전략의 큰 그림**
>
> **PWSA = SDA가 담당하는 실행 가능한 실체적 분산 LEO 위성 구성**
>
> **Tracking Layer = NDSA와 PWSA의 핵심 축으로서, 미사일 경보·추적·교전 중심의 우주 기반** **Kill-web****을 구축하기 위한 LEO 대규모 분산 위성망의 필수 요소**

>
> **Tracking Layer는 Hypersonic 대응 핵심,**
>
> **Custody Layer(AMTI)는 항공/해상 persistent SA(Situational Awareness) 핵심이다.**

**🚀 HGV (Hypersonic Glide Vehicle)란?**

- - HGV = Hypersonic Glide Vehicle, 극초음속 활공체

|  |  |
| --- | --- |
| **항목** | **설명** |
| 속도 | Mach 5 이상 (약 6,000km/h~12,000km/h) |
| 비행 방식 | 로켓으로 발사 → 대기권 상층에서 “활공 & 기동” |
| 궤적 | **예측 불가, 수평·수직 궤도 크게 변화** |
| 탐지 난이도 | 기존 레이더 / 조기경보 시스템으로 tracking 어려움 |
| 플라즈마 환경 | 고열 → 강한 IR 시그니처 (OPIR로 탐색 가능) |
| 요격 난이도 | mid-course에서 경로 계속 변경 → 요격 매우 어려움 |

**⚔️ Kill Chain vs Kill-Web**

|  |  |  |
| --- | --- | --- |
| **개념** | **Kill Chain** | **Kill-Web** |
| 구조 | 선형(Linear) | 비선형(Distributed Network) |
| 데이터 흐름 | 단방향 | 다방향 / mesh |
| 구성 단계 | Find → Fix → Track → Target → Engage → Assess | 병렬 수행, 센서·슈터·C2 모두 연결 |
| 실패 허용 | 약함 (하나 끊기면 전체 붕괴) | 강함 (경로 다중화, resilience) |
| 시간 | Minutes~Hours | **Seconds** |
| 예 | 이라크전, 단일 조기경보 → 단일 요격 | 골든돔, PWSA, Multi-sensor fusion |
| 대표 기술 | 위계 기반 C2 | AI fusion + distributed space mesh |

> **Kill Chain = 순차적 체인 / Kill-Web = 병렬 연결망**
>
> **Kill Chain은 과거 방식, Kill-Web은 PWSA 기반 Golden Dome 시대의 방식이다.**

> **HGV 대응에는 Kill Chain이 아니라 Kill-Web이 필요하며,**
>
> **Kill-Web의 중심이 SDA PWSA (Transport + Tracking + Custody)이다.**

**💡Epoch 1**

- - 미 우주군 산하의 SSC(Space Systems Command)가 주도하는 프로그램
  - **MEO(Medium Earth Orbit) 위성군 확보 사업**으로, 공식 명칭은 **Resilient Missile Warning & Tracking – Medium Earth Orbit (MEO MW/MT) Program – Epoch 1** 이다.
  - 목적은 **MEO 궤도에 조기경보·추적 센서 위성을 배치하여 극초음속 미사일 및 탄도미사일 위협에 대응**하기 위함이다.
  - Epoch 1 단계에서는 12기 위성(2개의 위성 평면, plane)이 계획되고 있다.
  - 첫 기체 납품은 FY2026 말로 계획되어 있으며, 두 번째 평면은 FY2028 초로 예상됨.
  - 특징

    - MEO 궤도는 LEO보다 고도가 높고 coverage가 넓으며, 지연(latency)과 revisit 시간 관점에서는 LEO보다 불리하지만 **지속 감시(persistent)와 글로벌 커버 측면에서 유리**하다.
    - Epoch 프로그램 구조: 여러 “Epochs(단계들)”로 나누어 **기술 성숙도 및 배치 리스크를 분산시키는 방식**이다.
    - SSC는 Space Development Agency(SDA) 및 Missile Defense Agency(MDA)와 연계하여 ‘복수 궤도, 복수 위성’ 구조로 미사일 경보·추적망을 구축 중이다.

**💡 pLEO vs MEO — 핵심 차이**

|  |  |  |
| --- | --- | --- |
| **구분** | **pLEO (Proliferated Low Earth Orbit)** | **MEO (Medium Earth Orbit)** |
| 궤도 고도 | **500–1,200km** | **2,000–20,000km** |
| 위성 개수 | **수십~수천 개 (proliferated = 대량 분산)** | **소수~수십 개 (기능 중심)** |
| 지연(Latency) | **최저 (20–40ms 수준)** | **중간 (100–200ms 수준)** |
| 해상도(센서) | **가까워서 고해상도** | **거리 증가로 해상도 감소** |
| revisit time | 매우 빠름 (수~수십분) | 느림 (수시간) |
| 장점 | 생존성·확장성·저비용·저지연·대량 커버리지 | 넓은 지역 단일 커버 |
| 단점 | 더 많은 위성 필요, 더 많은 교신·mesh 필요 | ASAT에 취약 (단일 실패점), 고비용 |
| 예시 | Starlink, SDA PWSA, Tracking Layer, AMTI | GPS / Galileo / BeiDou MEO 항법 위성 |
| 주 미션 | 전장 데이터 mesh, 미사일 추적, AMTI, PNT 보조 | 항법·시간(PNT), 광역 통신·전술 백업 |
| Kill-web 역할 | **초단위 실시간 감시/추적/전송** | **시간·좌표 기준 제공(PNT Backbone)** |

**💡“Tranche 2 + SSC Epoch 1”에서의 관계는?**

- - **“Tranche 2(Tracking Layer) + SSC Epoch 1”** 조합은 다음과 같다:

    - Tranche 2는 주로 *LEO 기반 Tracking Layer(저궤도 미사일 탐지·추적)* 측면이다.
    - Epoch 1은 *MEO 기반 미사일 경보·추적 위성군* 측면이다.
    - 둘은 궤도도 다르며 역할도 일부 중첩되지만 **서로 보완적 관계**이다.
  - 따라서 **Epoch 1은 Tranche 2의 단순 복제나 이름 변경이 아니라, 상이한 궤도와 역할(고도, 지속감시, 글로벌 커버리지 확대) 측면에서 별도의 병렬 프로그램**이다.
  - **pLEO = 눈 + 신경망 (real-time sensing & transport)**
  - **MEO = 뇌의 시간/좌표 기준 (navigation & sync)**

**✅PWSA의 Milestone**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTExMjBfMTA4/MDAxNzYzNjE1ODg3Njk3.XR_a2Cyz5Nta66pXyr-RHpSRFzcQP02jpqlRrohzwxgg.xSuhvHd0HDd-I5B7e-ECADjpaeq9ZjnsmeP90HqkuC8g.PNG/image.png?type=w800)](#)

- - **SDA가 2023년 11월 27일에 실증한 세계 최초의 ‘우주 기반 Link-16 전술 데이터 링크’ 성공 사례**.
  - 이 성공은 **PWSA Tranche 0의 가장 중요한 milestone** 중 하나이며, **우주 기반 JADC2(Kill-Web)** 구축의 실질적 출발점
  - 세계 최초로 **저궤도 위성(LEO)에서 지상으로 Link-16 전술 메시지를 직접 전송하는 데 성공**했음을 의미한다.
  - 이전까지는 Link-16 연결은:

    - **항공기 ↔ 항공기**
    - **항공기 ↔ 지상**
    - **지상 ↔ 지상**
    - **해상 ↔ 항공기**
  - 형태가 일반적이었으며,우주에서 전술 네트워크에 직접 connect한 사례는 없었다.
  - Tranche 0 위성(Transport Layer SVs)이 Link-16 신호 송신 노드 역할을 수행
  - 시험 지상군 통제 장소로 직접 메시지를 전달
  - 이는 **지휘통제 체계(C2)가 지상을 경유하지 않고 우주를 경유할 수 있게 되었음을 의미**

**📍기술적 의미**

- - **Beyond-Line-Of-Sight Tactical Connectivity**

    - Link-16은 원래 지구 곡률 때문에 **거리가 300~400km 이상 떨어지면 직접 연결 불가능**하다.
    - 하지만 **LEO 위성을 중계점으로 사용하면 지구 어디든 연결 가능**
    - 즉 **우주가 글로벌 전장 데이터 메시 네트워크의 backbone이 된다.**

****

**📍 전략적 의미**

- - The PWSA Transport Layer is the backbone of JADC2 in space

**🧠 Link-16이란 무엇인가?**

- - Link-16은 NATO 표준 전술 데이터 링크(Tactical Data Link, TDL)로서, 항공기·지상·해상 플랫폼 간 실시간 전술 정보 공유를 위한 디지털 네트워크다.

**💡JADC2란 무엇인가?**

- - Joint All-Domain Command and Control
  - 모든 군종 + 모든 영역(공중/지상/해상/우주/사이버)을 하나의 실시간 Kill-Web으로 연결하는 전장 지휘통제 개념

- - Link-16은 전술 데이터 공유의 중심이고,

  - 위성 기반 Link-16 성공(SDA Tranche 0)은 JADC2 시대의 결정적 전환점이다.
