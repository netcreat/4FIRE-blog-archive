**✅ EPB Quantum Network의 세부 기술**

**1️⃣ EPB Quantum Network의 기본 구조**

- - EPB 네트워크는 **Chattanooga 도시 광섬유망 위에 구축된 metropolitan quantum network testbed**다.
  - 구조

|  |
| --- |
| Quantum Node A  (entanglement source)  │  │ fiber network (EPB)  │  Quantum Node B  (detectors / measurement)  │  control software  (AliroNet) |

- - 특징

    - **dedicated fiber optic channels**
    - **reconfigurable network topology**
    - **quantum equipment hub**
  - 즉

    - 단순 링크가 `아니라 **실험 가능한 네트워크 플랫폼**이다.

**2️⃣ EPB에서 사용한 qubit 기술**

- - EPB 네트워크는 **photonic qubit** 기반이다.
  - 구체적으로
  - **qubit encoding**

    - **polarization qubit**
  - 즉

    - |H> horizontal polarization
    - |V> vertical polarization
  - 이 두 상태로 qubit를 인코딩한다.
  - 광자는 entangled photon pair형태로 생성된다.

**3️⃣ Entanglement 생성 장비**

- - 핵심 장비는 **Qubitekk entangled photon source**다.
  - 보통 구조

    - laser → nonlinear crystal (SPDC) → entangled photon pair
  - 논문에서는

    - **Type-II SPDC biphoton source**가 사용되었다.
  - 생성되는 상태

    - |Ψ> = (|HV> + |VH>) / √2
  - 또는 Bell state

**4️⃣ 실제 실험: Bell + N00N state distribution**

- - 2025 논문에서는 EPB network에서 **Bell entanglement + N00N state** 둘 다 분배하는 실험을 했다.
  - 실험 내용

    - SPDC source에서 photon pair 생성
    - 두 photon을 서로 다른 노드로 전송
    - polarization measurement
    - entanglement verification
  - 결과

    - **4-photon entangled state 생성**
    - **Bell state distribution 성공**
    - **N00N state distribution 성공**

**5️⃣ 가장 중요한 기술: Polarization stabilization**

- - 광섬유에서 가장 큰 문제는

    - fiber birefringence
    - temperature drift
    - vibration
  - 이 때문에 polarization이 계속 변한다.
  - 그래서 EPB network는 **Automatic Polarization Control (APC)** 장비를 사용한다.
  - 기능

    - real-time polarization correction
    - QBER reduction
    - channel fidelity stabilization
  - 예

    - Qunnect **QU-APC**
    - ORNL **APC system**
  - 실험에서는

    - 99% fidelity
    - 99% uptime
  - sub-second correction 성능이 확인되었다.

**6️⃣ Multi-wavelength quantum transmission**

- - EPB가 발표한 중요한 성과

    - **multi-wavelength entanglement transmission**
  - 즉

    - λ1 → entangled photons
    - λ2 → control
    - λ3 → classical channel
  - WDM 환경에서

    - **entangled photon transmission** 성공.
  - 그리고

    - 30시간 uninterrupted entanglement transmission 성공했다.

**7️⃣ EPB 네트워크에 실제 들어간 장비**

- - **quantum hardware**

    - entangled photon source (Qubitekk)
    - single photon detectors
    - polarization controllers
    - quantum optical switches
  - **classical infrastructure**

    - EPB fiber network
    - precision timing
    - WDM channels
  - **control software**

    - **AliroNet**
  - AliroNet은 quantum network orchestration software다.

    - (Aliro에 대해서는 할 말이 많아서 나중에 따로 포스팅을 하겠다.)

**8️⃣ EPB network의 핵심 특징**

- - EPB는 **production network가 아니라 testbed**다.
  - 목적

    - quantum equipment interoperability
    - protocol testing
    - quantum hardware validation
  - 그래서

    - vendor 장비 연결 가능
    - topology 변경 가능
    - 다양한 실험 가능

**✅** **Qubitekk vs Qunnect**

**1️⃣ Qubitekk vs Qunnect 기능 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **Qubitekk** | **Qunnect** |
| 장비 철학 | modular | integrated |
| 핵심 장비 | Bohr-IV | Carina |
| Photon source | SPDC photon | atomic photon |
| 주요 시장 | network testbed | telecom network |
| entangled photon source | 있음 | QU-SRC |
| detectors | 있음 | detector module |
| polarization stabilization | 있음 | QU-APC |
| switching | 있음 | 일부 |
| timing | 있음 | time-tag module |
| orchestration | software stack | Carina system |

**2️⃣Qubitekk에는 있는데 Qunnect에는 없는 것**

- - Qubitekk의 핵심은 **연구용 modular quantum network toolkit**.
  1. **Quantum network switching / node control**

     - Qubitekk 시스템에는

       - **quantum-compatible optical switching**
       - multi-node routing
       - network reconfiguration
     - 같은 기능이 포함된다
     - 이건 **testbed network architecture**를 만들기 위한 기능이다.
     - Bohr 시스템은

       - photon source
       - detectors
       - fiber switches
       - polarization control
       - timing
     - 등을 조합해 **여러 노드가 있는 네트워크를 구성**하도록 설계되었다.
     - ➡️ Qunnect는 기본적으로 **point-to-point entanglement appliance**라 이런 **network switching infrastructure**는 핵심 기능이 아니다.
  2. **다양한 실험 장비**

     - Qubitekk은 연구용 장비가 매우 많다.
     - 예

       - coincidence counter
       - photon correlation electronics
       - quantum lab kits
     - 이 장비들은 **실험 / 교육 / 연구**에 많이 사용된다.
     - ➡️ Qunnect는 이런 **lab instrumentation 제품군은 거의 없다.**
  3. **multi-vendor testbed architecture**

     - Qubitekk은

       - detector
       - source
       - timing
     - 등을 **다른 회사 장비와 조합하는 구조**다.
     - 그래서 Qubitekk = modular quantum network infrastructure다.

**3️⃣Qunnect에는 있는데 Qubitekk에는 없는 것**

- - Qunnect는 **production-style quantum networking hardware**를 만든다.
  - 대표적으로 **Carina platform**이 있다.
  1. **Integrated entanglement networking appliance**

     - Carina는

       - entangled photon source
       - polarization stabilization
       - timing lasers
       - link monitoring
       - orchestration
     - 을 **한 rack 시스템으로 통합**한다.
     - 구성

       - **Qu-SRC** → entangled photon source
       - **Qu-MEM** → Quantum memory
       - **Qu-APC** → polarization stabilization
       - **Qu-LSR** → ultra-stable laser timing
       - **Qu-VAL** → link validation monitoring
     - 이 모든 기능을 **하나의 시스템으로 통합**한 것이 Carina다.
     - ➡️ Qubitekk는 이런 **turnkey appliance 구조가 없다.**
  2. **telecom-compatible entanglement sources**

     - Qunnect의 source는 특징이 있다.

       - **atomic entanglement source**
       - telecom wavelength
       - long-distance fiber transmission
     - Carina 시스템은

       - telecom fiber
       - 최대 **100 km entanglement distribution**
     - 을 목표로 설계되었다.
     - ➡️ Qubitekk는 **SPDC crystal source** 기반이 대부분이다.
  3. **real-time fiber stabilization**

     - Qunnect의 대표 제품
     - **QU-APC**
     - 기능

       - fiber polarization drift 보정
       - entanglement fidelity 유지
     - 이 기술은 **실제 telecom network에서 매우 중요**하다.
     - Qubitekk에도 polarization control이 있지만 Qunnect는 이 기술이 **핵심 제품**이다.

**✅ Qubitekk의 한계**

**1️⃣ Qubitekk는 “quantum link hardware”에 가깝다**

- - IonQ가 인수한 Qubitekk 기술은 본질적으로 **photonic entanglement distribution system**이다.
  - 구성

    - SPDC photon source
    - polarization encoding
    - single photon detector
    - fiber link
  - 즉
  - node A ---- fiber ---- node B이 구조다.
  - 이건 **quantum link**수준이다.
  - 장점

    - 구조 단순
    - 실험 용이
    - 연구 테스트베드 구축 가능
  - 그래서 EPB 같은 **quantum network testbed**에는 매우 적합하다.

**2️⃣ 하지만 Quantum Internet에는 “repeater”가 필요**

- - 장거리 네트워크에서는 문제가 있다.
  - 광섬유 손실

    - 1550 nm fiber loss ≈ 0.2 dB/km
  - 거리 증가하면 100 km → 거의 photon loss
  - 그래서 **quantum repeater**가 필요하다.
  - 구조
  - node A → repeater → repeater →node B
  - 여기서 필요한 기술이

    - **quantum memory**
    - **entanglement swapping**
  - 이다

**3️⃣ Qunnect의 핵심은 quantum memory**

- - Qunnect는 **atomic ensemble 기반 기술**을 사용한다.
  - 구성

    - laser
    - → rubidium atomic vapor
    - → photon entanglement
    - → quantum memory
  - 이 구조의 핵심은 **photon ↔ atomic state 변환**이다.
  - 즉

    - photon qubit
    - → atomic storage
    - → photon qubit
  - 이 기능이 바로 **quantum repeater 핵심 기술**이다.

**4️⃣ Qubitekk에는 quantum memory가 없다**

- - SPDC photon source는

    - laser
    - → nonlinear crystal
    - → photon pair
    - 구조다.
  - 문제

    - photon 생성 확률적
    - photon 저장 불가능
  - 즉

    - memory 없음
  - 그래서

    - entanglement swapping 구조를 만들기가 어렵다.

**5️⃣ IonQ 입장에서 Qunnect가 의미 있는 이유**

- - IonQ의 장기 목표는 distributed quantum computing이다.
  - 구조

    - ion trap QPU → photonic interface → fiber network → ion trap QPU
  - IonQ CEO Niccolo de Masi도 **“networked quantum computers”** 전략을 여러 번 언급했다.
  - 하지만 여기서 문제는 long-distance entanglement다.
  - 이걸 해결하는 기술이 quantum repeater다.
  - 그리고 이 분야에서 **Qunnect는 실제 제품을 가진 몇 안 되는 회사**다.

**6️⃣ Qunnect가 가진 기술 (IonQ에 없는 것)**

- - IonQ / Qubitekk에는 없는 것

    - **① quantum memory**

      - atomic ensemble memory
    - **② entanglement preservation**

      - entanglement storage
    - **③ repeater node architecture**

      - node-level entanglement switching
    - **④ telecom-ready appliance**

      - Carina platform

**7️⃣ 그래서 현재 업계 구조는**

- - 현재 quantum networking stack을 보면
  - **IonQ / Qubitekk**

    - 강점

      - entanglement distribution
      - photonic interface
      - modular network hardware
  - **Qunnect**

    - 강점

      - quantum memory
      - repeater node
      - telecom deployment
  - 그래서 실제로는

    - Qubitekk → link
    - Qunnect → repeater
  - 구조다.

**✅ Quantum Memory**

**1️⃣ Quantum Network에서 Quantum Memory가 필요한 이유**

- - 양자 네트워크에서 얽힘(entanglement) 생성은 확률적(probabilistic)이다.
  - 예를 들어 다음과 같은 네트워크가 있다고 하자.
  - Node A —— Node B —— Node C

    - A–B 얽힘 생성 성공
    - B–C 얽힘 생성 실패
  - 이때 A–B 얽힘을 **잠시 저장**하지 않으면 전체 네트워크 연결이 불가능하다.
  - 그래서 quantum memory의 역할은 다음과 같다.

    - 얽힘 생성 성공 상태 **버퍼링(buffering)**
    - 다른 링크의 성공을 **기다리는 동기화(synchronization)**
    - entanglement swapping을 위한 **중간 저장**
  - 즉 대부분의 경우 quantum memory는

    - 장기 저장(storage) 보다는
    - 짧은 시간 버퍼(buffer)
  - 역할을 한다.
  - 필요한 저장 시간도 보통 μs ~ ms ~ s정도면 충분하다.

**2️⃣ Quantum Memory의 세 가지 주요 구조**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMDhfMTc5/MDAxNzcyOTc1NzkxMTM0.sTUDcjg0AHwJ9yffTVAKsGEw2poCi2gLLxR-tiR31NAg.5LktfFj3lz2icu71nbFXzMiC8jmthP-lfwSK4QMjUB8g.PNG/image.png?type=w800)](#)

- - 현재 연구되는 quantum memory는 크게 세 가지 계열로 나눌 수 있다.
  - **① Photon-only network (memory 없음)**

    - 구조

      - entangled photon source → fiber → detector
    - 특징

      - 구현이 비교적 단순
      - telecom fiber와 호환성 높음
      - rate가 높음
    - 단점

      - 노드에 메모리가 없어
      - 장거리 네트워크 확장이 어려움
    - 대표 사례

      - QKD 네트워크
      - 일부 metro-scale entanglement 실험
  - **② Telecom-style repeater memory**

    - 구조

      - photon → atomic ensemble memory → photon
    - 대표 기술

      - atomic ensemble memory
      - rare-earth crystal memory
    - 이 구조의 특징

      - photon을 **집단 원자 excitation**으로 저장
      - telecom fiber와 자연스럽게 연결 가능
      - quantum repeater 구현에 유리
    - 대표 기업

      - Qunnect
    - 장점

      - telecom network와 높은 호환성
      - 비교적 높은 entanglement rate
    - 단점

      - 저장 시간이 제한적
      - 복잡한 로컬 quantum processing에는 불리
  - **③ Matter-qubit memory (spin 기반)**

    - 구조

      - spin qubit → photon emission → fiber → remote spin qubit
    - 대표 플랫폼

      - trapped ion
      - neutral atom
      - diamond color center (NV / SiV)
    - 특징

      - qubit 자체가 memory
      - coherence time 매우 길음
      - 로컬 quantum operation 가능
    - 대표 연구

      - NV center network
      - trapped-ion photon interface
    - 장점

      - 높은 fidelity
      - entanglement purification 가능
    - 단점

      - photon coupling efficiency 낮음
      - entanglement generation rate 낮음

**3️⃣ Quantum Network의 핵심 성능 지표: Entanglement Rate**

- - 양자 네트워크의 실제 성능은 대부분 다음으로 결정된다.

    - entanglement rate = 1초에 생성되는 얽힘 쌍의 수
  - 대략적인 비교

|  |  |
| --- | --- |
| **플랫폼** | **Entanglement rate** |
| NV center | Hz – kHz |
| trapped ion | Hz – kHz |
| atomic ensemble | kHz – MHz |
| SPDC photon source | MHz – GHz |

- - 즉

    - photon source > atomic ensemble > spin systems 순으로 rate가 높다.
  - 이 차이가 **network architecture 선택에 큰 영향을 준다.**

**4️⃣ Telecom Network에서 NV / Ion memory가 불리한 이유**

- - 대표적인 문제는 photon wavelength이다.
  - 예

    - NV center photon

      - 637 nm
    - 하지만 telecom fiber 최적 파장은 1550 nm이다.
    - 637 nm photon은 fiber loss가 매우 높다.
  - 그래서 필요하다.

    - Quantum Frequency Conversion (QFC)
    - 637 nm → 1550 nm
  - 이 기술이 충분히 효율적이지 않으면 long-distance network 구축이 어렵다.

**5️⃣ Lightsynq가 추구하는 방향**

- - LightSynq Technologies는 다음 구조를 목표로 한다.

    - spin qubit → photon interface → fiber → remote spin qubit
  - 핵심 목표

    - distributed quantum computing
  - 즉

    - QPU ↔ QPU를 연결하는 **photonic interconnect**이다.
  - 구조적으로 보면 quantum datacenter interconnect에 더 가깝다.

**6️⃣ Lightsynq 접근 방식의 장점**

- - spin-based memory의 장점

    - 긴 coherence time
    - 높은 fidelity
    - 로컬 quantum processing 가능
  - 즉 단순한 repeater가 아니라 quantum processing node 로 사용할 수 있다.
  - 장기적으로는

    - entanglement purification
    - fault-tolerant network
  - 등의 고급 기능이 가능하다.

**7️⃣ Lightsynq 방식의 단점**

- - 현재 가장 큰 문제는 두 가지다.
  1. **Entanglement generation rate**

     - NV / ion 방식

       - Hz – kHz
     - telecom photon network

       - MHz
     - 수백~수천 배 차이가 있다.
  2. **Photon coupling efficiency**

     - spin → photon 변환 효율이 낮다.
     - 이를 해결하기 위해 연구되는 기술

       - nanophotonic cavity
       - photonic crystal
       - waveguide coupling

**8️⃣ Lightsynq 기술이 해결하려는 핵심 문제**

- - Lightsynq가 집중하는 기술은 spin ↔ photon interface이다.
  - 목표

    - 높은 photon extraction efficiency
    - 높은 indistinguishable photon generation
    - efficient QFC
  - 이를 통해 higher entanglement rate를 달성하려 한다.

**9️⃣ IonQ가 Lightsynq를 선택한 이유**

- - IonQ의 전략은 다음과 같이 볼 수 있다.

    - modular quantum computer
  - 즉

    - QPU module → photonic link → QPU module 구조의 distributed quantum processor이다.
  - 이 구조에서 필요한 핵심 기술이 바로 matter qubit ↔ photon interface이다.
  - 그래서 IonQ는

    - QPU 기술
    - photonic interconnect
  - 을 동시에 확보하려는 전략으로 Lightsynq를 인수한 것으로 해석된다.

**✅** **IonQ가 Lightsynq와 Qubitekk을 인수한 이유**

**1️⃣ Quantum Network의 실제 구조**

- - 양자 네트워크를 단순화하면 세 가지 층이 있다.

    - Layer 1

      - qubit ↔ photon interface
    - Layer 2

      - quantum network hardware
    - Layer 3

      - quantum processing node
  - 각각의 역할은 다음과 같다.

|  |  |  |
| --- | --- | --- |
| **Layer** | **역할** | **예** |
| L1 | qubit ↔ photon 변환 | LightSynq |
| L2 | 네트워크 장비 | Qubitekk |
| L3 | 계산 노드 | IonQ QPU |

**2️⃣ LightSynq가 하는 일**

- - LightSynq Technologies 기술은 본질적으로 spin qubit ↔ photon 인터페이스다.
  - 즉 ion state → photon emission fiber 같은 것을 가능하게 한다.
  - 이건 **네트워크를 구성하는 가장 기본적인 물리 인터페이스**다.
  - 하지만 이것만으로는 다음이 없다.

    - entanglement routing
    - link control
    - polarization stabilization
    - photon detection control
    - synchronization
  - 즉 **네트워크 운영 기능**이 없다.

**3️⃣ Qubitekk가 하는 일**

- - Qubitekk는 **quantum networking system**을 만든다.
  - 대표 장비

    - Bohr-IV
  - 이 장비는 다음 기능을 포함한다.

    - photon generation control
    - entanglement distribution
    - detection electronics
    - polarization control
    - timing synchronization
    - network orchestration
  - 즉

    - quantum router / network node에 가까운 장비다.

**4️⃣ 쉽게 비유하면**

- - **LightSynq**

    - CPU ↔ Ethernet PHY같은 역할이다.
    - 즉
    - qubit ↔ photon 변환이다.
  - **Qubitekk**

    - router / switch같은 역할이다.
    - 즉 network control이다.

  - 실제 네트워크에서는 약 **100~200 km 이상**부터 entanglement 생성률이 급격히 떨어지기 때문에 **quantum repeater**가 필요해진다.

    - 이때 LightSynq가 구현하는 **spin-photon memory 기반 repeater 노드**도 이론적으로 사용할 수 있다.
    - 하지만 비용, 시스템 복잡도, 그리고 entanglement rate 측면을 고려하면 구조가 단순한 **atomic-ensemble 기반 repeater**—예를 들어 **Qunnect가 지향하는 방식—이 더 효율적일 가능성도 있다.**
  - 그렇다면 IonQ는 장거리 네트워크를 구축할 때 **타 기업의 repeater 기술을 구매해야 할까?**

    - 가능성은 있다. 하지만 항상 그렇지는 않다.
    - 광섬유와 달리 **위성 기반 자유공간 광 링크는 감쇠 특성이 다르다.**
    - 손실이 거리의 제곱에 비례하는 기하학적 확산이기 때문에, **수천 km 거리에서도 단일 링크가 가능**하다.
  - 이 때문에 quantum communication 분야에서는 fiber network + satellite link를 결합한 **hybrid architecture**가 유력하게 연구되고 있다.
  - IonQ가

    - **Skyloom**
    - **Capella**
  - 같은 우주 인프라 기업을 인수한 것도 이러한 맥락에서 해석할 수 있다.
  - 즉 IonQ는 단순히 **quantum computer 제조사**가 아니라

    - QPU + photonic interconnect + space optical network
  - 를 결합한 **global quantum networking infrastructure**를 구축하려는 전략을 추진하고 있는 것으로 보인다.
