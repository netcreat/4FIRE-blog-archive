**📌 핵심 요약**

- - Capella Space는 **세계 최초로 SAR(Synthetic Aperture Radar) 위성에 레이저 기반 OISL(optical inter-satellite link)을 탑재**하여 **SDA Transport Layer와 직접 연동하는 테스트**를 수행한 회사다.
  - 이는 **SAR → Optical Terminal → SDA Transport Layer → 지상 / 전술 네트워크**로 이어지는 실전형 kill-chain을 위한 첫 사례.
  - 👉 **Capella SAR 위성에 설치되는 장비**

    - **OCT (Optical Communication Terminal)** from **Mynaric CONDOR Mk3**
    - SDA NEBULA & OCT standard **full compatibility**
  - 👉 **목적**

    - SAR 영상 데이터를 **레이저 링크를 통해 실시간 전송**
    - SDA Transport Layer의 **저지연 전술 데이터 릴레이 테스트**
    - 향후 JADC2 / ABMS 구조안에서 **sensor-to-shooter 실무 적용**

**🛰 왜 SAR + OISL 조합이 중요한가?**

- - **기존 ISR 방식의 문제**

    - RF 통신은 **속도 & 보안 한계**
    - 다운링크는 **지상국 가시권 기반**, 지연이 크고 즉응성이 떨어짐
  - **SAR + OCT 조합의 변화**

|  |  |
| --- | --- |
| **기존** | **새로운 체계** |
| 몇 시간 단위 ISR | **수초 단위 ISR / strike 가능** |
| 지상국 제한 | **LEO-mesh 라우팅으로 global 전송** |
| 접속가능성 취약 | **Jitter-tolerant laser / encrypted transport** |

**🧠 전략적 관점**

- - SDA PWSA 구조에서 Capella는 **Custody Layer 외부 파트너**이자
  - **Transport Layer의 실제 데이터 소스 역할**을 수행할 수 있는 첫 민간 SAR 회사.
  - **의미**

    - **민군 통합 ISR 시장의 표준 구축**
    - SDA NEBULA/OCT compatibility 사실상 **시장 표준 채택**
    - 향후 **Capella + Skyloom + IonQ** 조합 가능성
    - Skyloom: OISL 전문
    - IonQ: QKD / Q-networking / Q-secure routing 가능성
    - Capella: 고충실도 SAR 영상
