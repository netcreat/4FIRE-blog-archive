**⚡ 주요 결과**

1. 1. **학습 시간 혁신적 단축**

      - 기존 고전적 측정: 지수적 확장 때문에 약 **2천만 년** 소요
      - 얽힘 활용 광자 시스템: 단 **15분**
   2. **광자 플랫폼에서 최초 입증**

      - 기존 구글(슈퍼컨덕팅, 2019), USTC(광자 샘플링, 2020) 등은 “특정 연산 샘플링 우위” 사례였음
      - 이번 연구는 잡음 학습(noise learning)이라는 실제적인 태스크에서 **실험적으로 검증된 양자 우위**를 보여줌
   3. **실험 방식**

      - 광학 압축기(Squeezer, OPO: Optical Parametric Oscillator)로 **얽힌 빔 생성**
      - 하나는 시스템 탐색(Probe), 다른 하나는 참조(Reference)
      - 공동 측정(Joint measurement)으로 잡음을 상쇄 → 더 적은 측정으로 더 많은 정보 확보
   4. **실용성**

      - **텔레콤 파장(1550nm)** + **상용 광학 부품** 사용
      - “완벽한” 장치가 아닌, 현실적 손실이 있는 조건에서도 성능 유지 → **산업 적용성↑**

**💡****광자를 이용한 양자 얽힘 기반 학습 향상**

- - **(a) Conventional learning of a channel**

    - 일반적인(고전적) 방식.
    - 다중 모드 상태(Probe)를 채널(Λ)에 통과시킨 후 출력만 측정.
    - Probe만으로 채널의 특성을 추정해야 하기 때문에 **샘플 복잡도 한계**에 걸림.
  - **(b) Conventional learning of a multi-time process**

    - 시간에 따라 여러 번 작동하는 채널(동일 Λ가 반복되는 경우)을 Probe로 탐사.
    - 출력 측정값을 적응(adaptive)하게 조절해도, **얽힘이 없는 이상 복잡도 하한선은 동일**.
  - **(c)** **Quantum entanglement-enhanced learning**

    - 이번 논문의 핵심 아이디어.
    - Probe(탐색 빔)과 Memory(참조 빔)를 **얽힌 상태**로 준비.
    - Probe는 채널을 통과하고, Memory는 외부에서 보존됨.
    - 두 빔을 **공동 측정(Bell measurement)** → 채널 정보를 훨씬 더 효율적으로 추출 가능.
    - 이것이 **고전적 하한을 뛰어넘는 방법**.
  - **(d) Implementation with squeezed light**

    - 실제 장치 구현 부분.
    - **OPO (Optical Parametric Oscillator)** 2개를 사용하여 **2모드 squeezing (얽힘 상태)** 생성.
    - 두 출력을 간섭(interfere)시켜 Probe/Memory로 분리.
    - Probe는 여러 시점의 채널을 탐색하고, Memory는 참조로 남김.
    - 마지막에 Probe와 Memory 쌍을 **Bell measurement (X, P 측정)** 해서 정보 추출.
  - **(e) Displacement process realization**

    - 채널 Λ는 위상공간에서의 무작위 변위(Random displacement)로 구현됨.
    - 이 변위는 코히어런트 광(coherent light)를 주입해 인위적으로 만듦.
    - 구체적으로는 전기광학 변조기 (IM: Intensity Modulator, PM: Phase Modulator)를 사용하여 Probe에 변위를 줌.

**💡****물리적 과정의 재구성**

- - **(a) 16-mode 채널 복원 (고전적 방법)**

    - x축: b=(b,b,…,b) → 위상공간(displacement space) 좌표
    - y축: λ~(β) → 채널의 특성을 나타내는 **특성 함수(characteristic function)**
    - 회색 선: 참값(True)
    - 색깔 선: 다른 샘플 수 NN
    - N (200, 5000, 100000)로 고전적 방법으로 복원한 결과
    - 샘플 수가 많아질수록 참값에 가까워짐. → 하지만 엄청난 샘플이 필요
  - **(b) 30-mode 채널 복원 (얽힘 기반 Bell 측정)**

    - 같은 특성 함수 복원 작업이지만, 이번에는 **Bell measurement**와 squeezing(얽힘)을 사용
    - 서로 다른 squeezing 레벨(dB 값)이 결과에 반영됨:

      - 여기서의 **dB**는 광자 상태의 **squeezing level**을 로그 단위로 표현한 것.
      - 0 dB (빨간색, 얽힘 없음 → 성능 나쁨)
      - –2.26 dB (연두색, 약간 개선)
      - –4.78 dB (청록색, 큰 개선)
    - 동일한 샘플 수 N=105로도, 얽힘을 쓰면 더 정밀한 복원이 가능
  - **(c) 샘플 복잡도 vs 모드 수**

    - x축: 모드 수 n
    - y축: 필요한 샘플 수 (Sample complexity, 로그 스케일)
    - 회색 점선: Classical LB = 고전적 측정이 절대 넘을 수 없는 이론적 하한선
    - 각 색깔 선: 서로 다른 squeezing(dB) 수준에서의 성능

      - 빨강 (0 dB): 얽힘 없음 → 필요 샘플 수가 폭증
      - 파랑 (–4.95 dB): 강한 squeezing → 필요한 샘플 수가 급격히 줄어듦
    - n=100에서 빨강 vs 파랑 비교:

      - 0 dB → 7.3×1011 샘플 - 너무 급격히 증가하여 실제 표에서는 윗 부분이 잘림.
      - –5 dB → 2.7×105 샘플
      - 두 수의 비율 = (7.3×1011) / (2.7×105) ≈ **2.7×10****6**

        - 로그로 표현 할 경우 약 11.8 orders of magnitude(1011.8배 ) 차이
  - **(d) 가설 검정 (Hypothesis testing) 정확도**

    - x축: 변위 방향 (random / 특정 방향)
    - y축: 올바르게 구분할 확률 P
    - 점선: 목표 성공 확률 1−δ=2/3
    - 얽힘을 사용하면, 훨씬 적은 샘플로도 이 확률을 만족시킬 수 있음

**💡** **전체 메시지**

- - (a): 고전적 측정은 샘플 수를 크게 늘려야 참값 근사 가능
  - (b): 얽힘(Bell measurement) 사용 → 같은 샘플 수로 훨씬 더 나은 성능
  - (c): 얽힘 강도(dB)가 샘플 복잡도를 얼마나 줄이는지 정량적 비교 → 최대 11.8자릿수 절감
  - (d): 실제 태스크(가설 검정)에서도 양자 우위가 입증

**✅ 결론**

- - 이번 연구는 **광자 기반(Photonic)** 플랫폼에서 구현되었다. (OPO로 squeezing 광자 얽힘 생성 → Bell 측정)
  - 하지만 **원리 자체는 광자에만 국한되지 않음**.

    - 얽힘을 가진 두 “부분계(probe + memory)”를 공동 측정하면, 고전적 하한을 돌파할 수 있다는 건 보편적인 사실.
    - 즉, 초전도 큐비트, 이온트랩, 중성원자 같은 다른 플랫폼에서도 이와 비슷한 전략을 이론적으로 설계할 수 있음.
  - **핵심 메시지**: 얽힘이 있으면 고전적 방법이 절대 넘을 수 없는 샘플 복잡도 장벽을 돌파할 수 있다.
  - **광자 플랫폼**은 이번 시연을 가능하게 한 최적의 선택이었지만, 이론적으로는 **다른 플랫폼에도 적용 가능한 일반 원리**다.
