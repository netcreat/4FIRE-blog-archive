**🔑****파울리 배타 원리 (Pauli Exclusion Principle)**

- - **핵심**: 한 원자 궤도(정확히 말하면 하나의 양자상태, 즉 동일한 4개의 양자수 n, l, m\_l, m\_s)를 **두 전자가 동시에 가질 수 없다**.
  - 여기서 **m\_s**는 전자 스핀(±½)이고, 다른 3개의 양자수(n, l, m\_l)가 모두 같으면, **스핀은 반드시 반대 방향**이어야 함.
  - 즉, **같은 궤도(orbitals)** 안에서는 **평행 스핀 불가능**.

**🔑** **훈트 규칙 (Hund’s Rule)**

- - **핵심**: 전자가 여러 개의 에너지 준위가 같은 서로 다른 궤도(degenerate orbitals)에 들어갈 때,

    - **서로 다른 궤도에 먼저 하나씩, 그리고 스핀은 평행**으로 채운다.
    - 예: p-오비탈(px, py, pz)은 서로 다른 m\_l 값을 가짐 → 파울리 원리에 따르면, m\_l이 다르면 m\_s가 같아도 됨.
    - 이렇게 평행 스핀을 선호하는 이유:

      1. **쿨롱 반발 최소화**: 전자들이 서로 다른 공간 궤도에 있으면 전자-전자 반발이 줄어듦.
      2. **교환 에너지(Exchange energy) 안정화**: 양자역학적으로 평행 스핀이 교환 대칭을 만들어 에너지를 더 낮춘다.

**🔑** **파울리 vs 훈트 — 차이점 정리**

|  |  |  |
| --- | --- | --- |
| **구분** | **파울리 배타 원리** | **훈트 규칙** |
| 적용 범위 | **하나의 동일한 궤도** (n, l, m\_l 모두 동일) | **여러 개의 동일한 에너지 준위 궤도** (degenerate orbitals) |
| 스핀 조건 | 같은 궤도에서는 스핀 반대 | 서로 다른 궤도에서는 스핀 평행 |
| 이유 | 4개 양자수 모두 같을 수 없음 | 전자 반발 최소화 + 교환 에너지 안정화 |

**🔑** **NV****-****의 경우**

- - NV-의 e 오비탈은 **m\_l 값이 다른 두 개의 degenerate 상태**.
  - 파울리 원리에 따르면 같은 궤도(m\_l 동일)에선 평행 스핀 불가지만,
  - 다른 궤도(m\_l 서로 다름)에선 m\_s가 동일해도 됨 → 이때 훈트 규칙에 따라 평행으로 채워져 S=1 형성.

**💡 결론**

- - 훈트 규칙은 파울리 원리의 “예외”가 아니라, **파울리 원리를 지키면서** 전자들이 어떻게 배치되어 에너지를 최소화하는지를 설명하는 보조 규칙이다.
  - 즉, 파울리 원리가 ‘들어갈 수 있는 자리의 조건’을 주고, 훈트 규칙은 ‘여러 자리 중 어떻게 앉을지’를 정해주는 셈이다.

---

**✅** **e 오비탈?**

NV 중심에서 말하는 **e 오비탈**은 원자 궤도가 아니라, **결함(defect)에서 형성된 분자 궤도(molecular orbital)** 이름이다.

**💡 왜 NV 중심에 e 오비탈이 있나?**

- - NV 중심은 **질소 1개 + 탄소 3개 + 빈자리 1개**로 이루어진 작은 “분자” 같은 구조를 다이아몬드 격자 안에 갖는다.
  - 이 네 개의 원자가 가진 **sp****3** **혼성 궤도**들이 서로 겹치면서, **결함 고유의 에너지 준위**를 만든다.
  - 이때 결함 준위는 대칭성에 따라 이름이 붙는데, 대표적으로:

    - **a****1** **오비탈** (non-degenerate, 한 에너지 값에 해당하는 양자 상태가 단 하나뿐

      - 예를 들어 1s 오비탈에 유일한 상태 하나만 존재
    - **e 오비탈** (degenerate, 서로 다른 양자 상태(양자수 세트가 다름)가 **동일한 에너지 값**을 가짐)

      - 예를 들어 p-오비탈에서 px, py, pz가 같은 에너지를 갖는 경우

**💡 a****1****, e 오비탈의 의미**

- - **a****1**: 대칭성이 높은 단일 궤도 → 에너지 준위 하나.
  - **e**: 서로 수직 방향으로 배향된 두 개의 동일한 에너지 준위(degenerate 상태) → px, py처럼 m\_l이 다른 상태.
  - 여기서 e 오비탈은 **파울리 원리를 지키면서도** 두 전자가 평행 스핀으로 들어갈 수 있는 자리.

**💡 NV****-****에서의 전자 배치**

NV-의 결함 궤도 전자 배치는 보통 이렇게 설명한다.

1. 1. **a****1** **(하위 에너지)**: 전자 2개 (스핀 반대) → S=0
   2. **a****1****1** **(상위 에너지)**: 전자 2개 (스핀 반대) → S=0
   3. **e (degenerate 궤도)**: 전자 2개 (m\_l 다름, 스핀 평행) → S=1

      - 이 **e 오비탈**이 바로 NV-의 S=1 스핀 상태의 원인이다.
      - 여기서 **훈트 규칙**이 적용되어 전자들이 평행 스핀으로 배치된다.

**💡 학교에서 배우는 s/p/d/f 궤도와의 차이**

- - s/p/d/f는 **원자 궤도** 분류 (n, l, m\_l에 따라).
  - a1, e는 **분자 궤도**의 이름이고, NV 중심 같은 **결함 물질**의 국소 대칭성(C3v group)에서 나온 표기이다.
  - 즉, NV 중심은 원자 하나가 아니라 작은 분자처럼 동작하니까 군론(symmetry group)을 써서 궤도를 분류한다.

**💡 한 줄 정리**

**e 오비탈** = NV 결함 구조에서 대칭성 때문에 생기는 **degenerate 분자 궤도** 이름.

이 두 분자 궤도 상태에 전자가 평행 스핀으로 들어가서 NV-의 S=1이 만들어다.

**✅** **NV 중심과 삼중항(triplet)**

******💡 NV****-** **중심의 전자 배치**

- - NV- 결함은 **질소 1개 + 탄소 자리 하나 비어 있는 공공** 구조
  - NV- 상태에서는 **총 6개의 전자**가 결함의 결합 궤도(defect orbital)에 채워져 있음

    - 질소: 5개의 원자가 전자 중 일부가 결함 궤도에 참여
    - 주변 탄소·공공으로 인해 추가 전자가 채워짐
    - 그리고 NV-는 음전하이므로 전자 1개가 더 있음
  - 결함 궤도의 분자 궤도(diagram)에서 전자들이 **a****1****, e** 궤도에 채워지는데,

    - a1 궤도는 완전히 채워져 있고
    - e 궤도에는 홀 전자가 두 개 존재

**💡 삼중항이 되는 이유**

- - e 궤도에 있는 두 개의 전자가 **파울리 배타 원리**와 앞서 정리한 **훈트 규칙**에 따라 **같은 방향(평행) 스핀**을 가진다.

    - 이렇게 스핀이 정렬되면 **총 스핀 양자수 S = 1**이 된다.
    - S=1이면 가능한 ms 값은 0, +1, −1 → **삼중항(triplet)** 상태.

**💡 물리적 의미**

- - S=1 → 자기적 성질(Zeeman 효과)에 따라 ms 상태별로 에너지가 달라질 수 있음
  - NV 큐비트 동작은 바로 이 ms 상태 차이를 이용해 **마이크로파로 상태 제어**하거나 **광학적으로 구분**하는 원리로 작동한다.

**💡****NV의 스핀 양자수**

- - **NV****-****중심의 전자 스핀 양자수 S = 1이다.**
  - **→ 이것은 전자가 “삼중항(triplet)” 상태를 가진다는 뜻.**
  - **→ 삼중항이란 m****s** **= 0, m****s** **= +1, m****s****ₛ = −1 세 가지 자기양자수 상태가 존재한다는 의미.**

****

**💡m****s****란? (이온트랩과 큐비트 (1) 참조)**

- - ms는 전자 스핀의 자기 양자수(magnetic spin quantum number)이다.
  - S=1인 경우:

    - ms = 0
    - ms = +1
    - ms = −1
  - 외부 자기장이 없을 때 ms = ±1은 서로 같은 에너지를 가지지만(magnetic degeneracy), 자기장을 걸면 제이만만 효과로 에너지가 갈라진다.
  - NV 큐비트에서는 보통 ms=0 상태를 |0⟩, ms=±1 중 하나를 |1⟩로 써서 이준위 시스템을 만든다.

**💡****다이아몬드 NV 중심의 스핀 동역학 (위키피디아 발췌)**

- - 바닥 상태 삼중항과 들뜬 상태 삼중항 사이의 주요 전이는 **스핀을 보존**하는 전이다.
  - 중간 단일항 상태를 거쳐 붕괴되는 경로는 ms = ±1 상태를 mₛ = 0 상태로 변환시켜 스핀 분극(spin polarization)을 유도한다.
  - 흡수와 방출 파장은 **Stokes 이동**으로 인해 서로 다르므로 둘 다 표시된다.
  - 또한 결함 축을 따라 정자기장 B0를 인가했을 때 나타나는 **Zeeman 이동**이 함께 표시된다.
  - 여기서 γnv는 NV 중심의 자이로 자기 비율(gyromagnetic ratio)를 의미한다.
  - 많은 응용에서, 바닥 상태의 두 에너지 준위를 선택하여 **큐비트**로 사용한다.
  - 이 효과적인 2준위 시스템의 전이는 마이크로파장을 이용해 유도할 수 있다.
  - 3E → 1A와 1E → 3A 전이는 **비복사(non-radiative)** 전이이다. 즉, 바닥으로 내려올때 빛이 방출되지 않는다.

**📌 정리**

- - 532 nm: 여기(3A2 → 3E)용 레이저
  - 637 nm: 바닥 상태로 복귀하며 방출하는 ZPL(Zero-Phonon Line) 광자
  - S=1, ms = 0, ±1: 전자 스핀 삼중항 상태의 세 가지 자기 양자수

****

**💡에너지 준위 구조 (위키피디아 발췌)**

- - NV 중심은 바닥 상태 삼중항(3A), 들뜬 상태 삼중항(3E), 그리고 두 개의 중간 단일항 상태(1A와 1E)를 가진다.
  - 3A와 3E 모두 ms **= ±1** 스핀 상태(두 전자 스핀이 같은 방향: 위쪽 정렬이면 ms = +1, 아래쪽 정렬이면 ms = −1)와, 전자 스핀이 반평행인 ms **= 0** 스핀 상태를 포함한다. 자기적 상호작용 때문에 ms = ±1 상태의 에너지가 ms = 0 상태보다 더 높다.
  - 1A와 1E 는 각각 ms = 0인 단일항 상태만 가진다.
  - NV 중심의 결함 축(질소 원자와 공공이 일직선으로 배열된 축)을 따라 외부 자기장을 인가하면 ms = 0 상태에는 영향을 주지 않지만, ms = ±1 준위는 서로 갈라진다(제이만 효과). 이와 유사하게, 주변 환경의 다음과 같은 특성들이 에너지 준위도에 영향을 준다

    - **정자기장의 세기와 방향**: 바닥 상태와 들뜬 상태 모두에서 ms = ±1 준위를 갈라지게 함.
    - **탄성(변형)장이나 전기장의 세기와 방향**: 영향은 훨씬 작지만, 준위별로 더 복잡한 효과를 일으킴.
    - **연속파 마이크로파 복사**: ms = 0 ↔ ms = ±1 전이에 공명하게 인가하면 바닥 상태와 들뜬 상태 내부의 아준위 점유 비율을 변화시킴
    - **가변 파장 레이저**: 바닥 상태와 들뜬 상태의 특정 아준위만 선택적으로 여기할 수 있음.
    - **주변 스핀과 스핀-궤도 상호작용**: NV 중심이 경험하는 자기장을 변화시킴.
    - **온도와 압력**: 바닥 상태와 들뜬 상태 간의 에너지 차이를 포함해 스펙트럼의 다양한 부분을 변화시킴.
  - 이러한 에너지 구조는 다이아몬드나 다른 반도체의 결함에서 전혀 예외적인 것이 아님
  - NV 중심이 큐비트와 양자 센서로 제안된 것은 이러한 구조만이 아니라, **기존 연구 데이터, 제작 용이성, 생체 적합성, 간단한 초기화 절차, 상온 사용 가능성** 등 여러 유리한 요소들이 결합된 덕분이었다.

  - **여기 상태(excited state)**: 3E 삼중항
  - 두 상태 에너지 차: **1.945 eV** → **637 nm** 광자
  - → 이 파장으로 **여기**하거나 **방출** 가능

**2️⃣ 스핀 하위준위 분할**

- - 3A (기본 상태)

    - 스핀 양자수 ms=0,±1
    - ms=0와 ms=±1 사이가 **2.87 GHz** 떨어져 있음
    - (마이크로파로 전환 가능)
  - 3E (여기 상태)
  - ms=0,±1
  - 여기도 ms=0와 ms=±1 사이가 **1.42 GHz** 떨어짐

**3️⃣ 그림에서 “0, ±1” 의미**

- - 여기서 말하는 **0, ±1**은 **전자스핀의 z축 방향 성분** ms.
  - ms=0: 전자 두 개가 서로 반대 방향 (antiparallel) → 스핀 합이 0인 상태
  - ms=+1 또는 ms=−1: 전자스핀이 평행하게 정렬된 상태

**4️⃣ 빠진 부분**

- - 설명에서는 **궤도(degeneracy) 분할**과 **비복사(non-radiative) 전이**는 생략
  - 실제로는 ms=±1에서 여기 상태로 올라갔다가,
  - 비복사 경로(중간 단일항 1A, 1E)를 거쳐 ms=0으로 내려오면서
  - **광학적 스핀 폴라라이제이션**이 일어남

**✅ SiV중심**

**💡** **결정 구조 (Crystallographic)**

- - **SiV**: 다이아몬드 격자 내 **탄소 2개 → 실리콘 1개**로 치환, 그 실리콘은 두 빈자리 사이에 위치.
  - **대칭성**: D3d 점군 대칭(중심 대칭 존재).
  - 이 때문에 정전기장(전하 불균일)에 민감하지 않고, **광학적 안정성** 높음.

**💡** **전자 구조 (Electronic structure)**

- - **SiV****-**:

    - **스핀** ½, 단일 홀 상태.
    - **바닥 상태(****2****E****g****)**, **여기 상태(****2****E****u****)** 각각 2개의 궤도 상태(스핀-궤도 결합에 의해 분리).
    - 4개의 전이가 모두 dipole-allowed → 737~738 nm ZPL (Zero-Phonon Line).
    - **Debye–Waller factor ≈ 0.7** → 방출광의 70%가 ZPL에 들어감 (NV는 ~4%).
    - 전자-포논 결합 약 → 선폭이 매우 좁음.
  - **SiV****0**:

    - **스핀 1** (NV-와 유사한 스핀 구조, 하지만 광학 특성 다름).
    - ZPL: 946 nm, Debye–Waller factor ≈ 0.9 → 거의 모든 방출이 ZPL에 집중.
    - 상온에서 SiV-보다 스핀 코히런스가 양호 (최대 ~20K까지).

**💡** **스핀 동역학 (Spin dynamics)**

- - **SiV****-**:

    - 광학 전이는 전자 스핀을 보존하지만, **빠른 포논 유도 궤도 혼합** 때문에 상온에서는 스핀 디코히런스가 심함.
    - **< 100 mK** 초저온에서만 긴 스핀 코히런스 확보 가능.
  - **SiV****0**:

    - 높은 온도(20K까지)에서도 스핀 코히런스 유지 가능.
    - **핵 스핀(****29****Si)** + **전자 스핀**을 동시에 큐비트로 사용 가능 → 전자 스핀은 통신·인터페이스, 핵 스핀은 메모리 역할.

**💡** **실제 사용 사례**

- - **SiV****-**:

    - 장점: 제작이 쉽고, 현재 상용화된 **다이아몬드 나노포토닉스 공정과 호환성이 좋음**
    - 예: 빠른 광자-광자 얽힘 실험, 다수의 노드를 연결하는 **QKD/QPU 네트워크**
  - **SiV****0**:

    - 장점: ZPL 비율이 매우 높고 **스핀 메모리 성능**이 좋아 **양자 메모리**에 적합
    - 예: 장거리 양자 네트워크에서 **노드 메모리로 사용**, 핵스핀까지 활용해 데이터 보존

**✅ NV** **와 SiV의 차이**

**💡** **싱글릿 / 더블릿 / 삼중항의 정의**

- - 다중도(Multiplicity) 공식:

- - 여기서 **S** = 모든 전자의 스핀 합(총 스핀 양자수)

|  |  |  |  |
| --- | --- | --- | --- |
| **이름** | **총 스핀 S** | **다중도(2S+1)** | **예시** |
| **싱글릿 (Singlet)** | 0 | 1 | 두 전자가 스핀 반대(↑↓) |
| **더블릿 (Doublet)** | ½ | 2 | 홀전자 1개(↑) |
| **삼중항 (Triplet)** | 1 | 3 | 홀전자 2개가 평행(↑↑) |

**💡****NV****-** **vs Si****V****-****의 전자 구조 차이**

- - **NV****-**

    - **기저 상태**: 3A2 → 삼중항(S=1)
    - **여기 상태**: 3E → 삼중항(S=1)
    - 삼중항–삼중항 전이 + **중간에 싱글릿 경유** 경로 존재

      - → 여기서 스핀 상태별로 비복사(non-radiative) 전이가 달라짐.
    - 결과: 특정 스핀(m\_s=0)이 더 잘 여기/발광 루프를 돌게 되고, 다른 스핀(m\_s=±1)은 싱글렛 경로로 빠져 밝기 감소 → **광학적 스핀 초기화** 가능.
    - **ODMR**: 스핀 상태별 발광 강도가 다르기 때문에, 마이크로파로 m\_s 전이를 유도하면 빛 세기 변화로 검출 가능.
  - **SiV****-**

    - **기저 상태**: 2Eg → 더블릿(S=½)
    - **여기 상태**: 2Eu → 더블릿(S=½)
    - 스핀-궤도 결합이 매우 강해, 전자 스핀이 궤도 자유도와 묶여버림(orbital–spin locking).
    - **싱글렛 경유 경로가 사실상 없음** → 광학적으로, 스핀을 선택적으로 바꿔주는 메커니즘이 NV처럼 작동 안 함.
    - 결과: 상온에서는 광학 펌핑만으로 스핀 초기화 거의 불가능 → **저온**, **외부 자기장**, **보조 레이저** 같은 별도 기술 필요.
    - ODMR은 가능하지만, 신호 대비 잡음비가 NV보다 훨씬 낮음.

**💡** **왜 이런 차이가 생기나?**

- - NV-: S=1 삼중항이기 때문에, 스핀-선택적 비복사 경로(삼중항 ↔ 싱글렛)로 쉽게 바꿀 수 있음.
  - **Si**V-: S=½ 더블릿 상태라서, 전이가 스핀 선택적으로 분리되지 않고, 대신 궤도 상태 변화가 주역할 → 스핀 초기화 경로가 약함.
  - 또, SiV⁻는 강한 반전 대칭(inversion symmetry) 구조라서 전자-포논 상호작용 방식이 NV와 다름 → 실온에서는 스핀 상태가 빠르게 섞임(thermal mixing).

**💡** **정리**

- - **싱글렛/더블릿/삼중항** = 전자의 총 스핀 상태에 따른 다중도.
  - NV-는 삼중항 구조 + 싱글렛 경유로 스핀 초기화·폴라리제이션이 쉬움.
  - SiV-는 더블릿 구조 + 강한 스핀-궤도 결합으로 인해 NV 방식이 통하지 않아, 별도 기술이 필요.

**💡** **SiV⁻의 문제점 (상온)**

- - **더블릿 구조**: 기저 상태가 2Eg → 전자 스핀 S=½
  - **스핀-궤도 결합**이 매우 강함 → 전자 스핀과 궤도 자유도가 묶임.
  - 궤도 준위 간 에너지 간격이 약 **50 GHz** (~2.4 K에 해당)밖에 안 됨.
  - 실온(300 K)에서는 이 궤도 준위가 열적으로 쉽게 뒤섞임(thermal mixing) → 스핀 상태 구분 불가.
  - 결과:

    - 스핀 폴라리제이션 거의 불가능
    - 코히런스 시간(T2) 수 ns~μs 수준으로 짧음
    - ODMR 신호 대비 잡음비 낮음

**💡** **극저온(저온)에서 달라지는 점**

- - 극저온(예: 4 K 또는 그 이하)에서는

    - 열에 의한 궤도 준위 점유 변화가 거의 없음
    - 스핀-궤도 락킹 상태가 안정화 → 스핀 상태 유지 가능
  - 이때 보조 레이저나 마이크로파를 써서

    - 스핀 초기화
    - 스핀 판독(ODMR)
    - 장시간 코히런스 확보 가능(T2 수백 μs~ms까지)

**💡** **NV vs SiV 비교**

|  |  |  |  |
| --- | --- | --- | --- |
| **항목** | NV- | **Si**V- | **SiV⁰** |
| 스핀 | 1 (삼중항) | ½ (더블릿) | 1 (삼중항) |
| 펌핑 파장 | 532 nm | 737 nm | 946 nm |
| ZPL 파장 | 637 nm | 737 nm | 946 nm |
| Debye–Waller factor | ~0.04 | ~0.7 | ~0.9 |
| 스핀 코히런스 (상온) | 우수 | 낮음 (mK 필요) | 중간 (20K) |
| 전자-포논 결합 | 강함 | 약함 | 약함 |
| 포토닉 구조 적합성 | 보통 | 우수 | 우수 |
| Stark shift 민감도 | 높음 | 낮음 | 낮음 |

**💡** **왜 NV 대신 SiV를 쓰나?**

- - **광학 인터페이스** 목적이라면 SiV가 유리:
  - ZPL 비율 높음 → 포토닉 인터커넥트 효율 극대화.
  - 선폭 좁음 → 서로 다른 SiV를 거의 동일한 광원처럼 맞출 수 있음(Indistinguishable photons).
  - 나노포토닉 구조에 안정적으로 집적 가능.
  - **단점**:

    - **SiV**-는 상온 스핀 코히런스가 짧음 → 메모리/계산보다 **통신용 인터페이스**에 적합.
    - **장기 메모리** 필요하면 핵 스핀(29Si)이나 **SiV****0**로 보완.

**💡****정리하면,**

SiV는 NV보다 **포토닉 인터페이스 효율**이 훨씬 높아서, 원거리 양자 네트워크(포토닉 인터커넥트)에서 핵심 부품이 될 수 있고,

그 중에서도 **전자 스핀은 광자 송수신**, **핵 스핀은 메모리**로 쓰는 전략이 가능하기 때문에 IonQ 같은 회사가 Lightsynq(이런 기술 보유)를 인수한 것이다.

> **Phonon :** 고체 속에서 원자들이 진동할 때 생기는 진동의 양 (불필요하게 섞이는 노이즈와 비슷한 성질)
>
> **ZPL (Zero Phonon Line) :** 진동이 없이 깨끗한 광자 전이가 생기는 경로를 뜻함.
>
> **DWF(Debye-Waller factor) :** ZPL이 전체 방출 중 차지하는 비율. 값이 높을 수록 전체 방출에서 ZPL이 차지하는 비율이 높다는 의미. SiV-의 DWF가 70%로써, NV-의 4%에 비해 현저히 높기 때문에 **네트워킹에 유리함.**
>
> **Stark Shift 민감도 :**  전기장이 걸렸을때 원자/결함의 에너지 준위가 살짝 바뀌는 현상으로써, 민감도가 낮을수록 전기장 잡음에 강하다는 의미다.
