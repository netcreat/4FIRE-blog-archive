**💡****핵심 기술 및 솔루션**

- - **광(레이저) 통신 터미널 (OCT: Optical Communication Terminals)**

    - Skyloom은 위성 간 혹은 위성↔지상 간 데이터 전송을 위해 레이저 광통신 터미널을 개발·제조하고 있다.
    - 예컨대, “V’ger” 라인, “Scotty” 사용자 터미널, “Uhura” GEO 중계 위성 노드 등이 언급되어 있다.
  - **중계망 & 위성 네트워크 인프라**

    - Skyloom은 지구 관측(EO) 위성들이 생성하는 대량 데이터를 지상으로 전송하는 병목을 없애기 위해, 저궤도 위성 → 지구 또는 저궤도 위성 → 중궤도/정지궤도 위성(relay) → 지상으로 이어지는 광통신 네트워크 구조를 지향한다.
    - 예컨대, Space Compass 와의 협업을 통해 “SkyCompass-1”이라는 GEO 기반 광중계 노드를 아시아태평양 지역에 Q4 2024까지 설치할 계획 등도 발표되어 있다.
  - **고속·저지연·고보안 통신 혜택**

    - 광통신을 쓰면 RF(무선주파수) 통신 대비 다음과 같은 장점이 있다:
    - 전송 용량이 10× ~ 100× 더 많다는 언급.
    - 크기, 무게, 전력 소비가 RF 대비 작다는 설명.
    - RF 신호보다 간섭·도청 등 보안 및 안정성 측면에서 유리하다는 평가.
  - **최근 파트너십·개발 소식**

    - NEC Corporation 와 “100 Gbps 급 우주 광통신 터미널(WARP OCT)” 공동 개발 중이며, 2025년 말까지 완제품화 + 2026년 위성 탑재 예정이라는 발표가 있다.
    - 또한, Axiom Space 와 협업하여 상업용 우주정거장 “ODC T1(Orbital Data Center Tranche 1)” 프로젝트에서 Skyloom의 광통신 링크를 활용한다는 소식도 있다.

**💡****시장·적용 분야**

- - 지구관측(EO) 위성군의 대량 데이터 전송: Skyloom은 EO 위성들이 생성한 이미지·영상 데이터를 지상이나 클라우드로 빠르고 안정적으로 보내는 인프라에 집중하고 있다.
  - 위성인터넷/통신망 확대: 저궤도/중궤도 위성군이 증가함에 따라 위성 ↔ 위성 ↔ 지상의 고속 데이터 전송 수요가 커지고 있으며, Skyloom은 이를 위한 광중계 네트워크를 제공하려는 것이다.
  - 우주 내 데이터센터/처리: 예컨대 Axiom의 프로젝트처럼 우주정거장이나 궤도상의 처리·저장·전송 인프라에서 Skyloom의 광링크가 활용될 가능성이 제기되고 있다.

**💡****왜 중요한가?**

- - 기존 위성통신은 대부분 RF 기반이었고, 지상과의 링크 혹은 위성간 링크의 통신량이 점점 증가하는 환경에서 병목(bottleneck)이 생기고 있다. Skyloom은 이 병목을 광통신으로 풀어주려는 접근이다.
  - 특히 고해상도 이미지·영상·실시간 데이터가 많아지는 EO·AI·우주탐사 환경에서, 데이터를 *제때* 지상 또는 클라우드로 보내는 것이 경쟁력이다.
  - 또한 우주 내 네트워크화(위성 → 위성 → 위성 → 지상) 및 “데이터가 생성된 위성에서 바로 지상 혹은 클라우드로”의 흐름이 중요해지고 있어, 광통신은 이러한 흐름에 유리하다.

**💡****유의사항 / 아직 과제인 부분**

- - 기술 성숙도: 광통신 위성 터미널이나 링크는 여전히 도전 과제가 많다(정밀 포인팅, 횡단대기 간섭, 궤도 안정성 등) — 예컨대 SDA의 상호연동(interoperability) 시험을 여러 업체가 받는 중이라는 언급이 있다.
  - 상업화·대량생산: “100 Gbps WARP OCT 출시·위성 탑재 예정” 등의 발표는 있지만 **운용 현장/상업사용 리스크**가 남아 있다.
  - 시장 수요 및 비즈니스 모델: 위성 데이터를 얼마나 많이, 얼마나 빨리 보내야 하고, 그 비용을 누가 부담할지 등이 시장 논쟁거리이다. 즉, 기술이 있어도 시장이 충분히 뒷받침해야 한다.
  - 인프라 구축 및 운영 비용: 위성↔위성 광링크, GEO 중계 위성, 지상광역 지점(Optical Ground Stations) 등을 포함한 전체 시스템 구축이 쉽지 않다.

**🚀 V’GER (LEO → LEO)**

- - **광(光) 기반 위성 간 링크 (Optical Inter-Satellite Link)**
  - **기술 개요**

    - 과거의 거대하고 고가 위성들이 점차 **소형 위성군(constellation)** 으로 대체되고 있다.
    - Skyloom의 **광통신 터미널(****OCT, Optical Communications Terminal****)** 은 이러한 소형 위성 간 혹은 위성과 지상·항공·해상 플랫폼 간에 **고대역폭(high-bandwidth)** 연결을 제공한다.
    - **V’ger OCT 제품군**은 **우주 기반의(Space-based)**, **SDA(Space Development Agency - 미국 우주개발국) 규격을 준수하는**, **멀티 Gbps급 자율형 레이저 통신 단말기(lasercom terminal)** 로 설계되었다.
    - 이 LEO 링크는 **전(全)지구적 백홀(backhaul)** 및 **네트워크 서비스 인프라**를 구축하기 위한 아키텍처를 지원한다.

- - **주요 특징**

    - **모듈형 설계(Modular Design)** — 다양한 궤도·플랫폼에 유연하게 적용 가능
    - **전송 속도: 1 ~ 10 Gbps급**
    - **LEO-LEO 연결** (저궤도 위성 간 통신)
    - **LEO-Ground 연결** (지상국 직접 전송)
    - **LEO-Airborne 연결** (항공 플랫폼과 통신)
    - **LEO-Maritime 연결** (해상 플랫폼과 통신)

**🛰️ Scotty (LEO → GEO)**

- - **광(光) 기반 위성 간 링크 (Optical Inter-Satellite Link)**
  - **기술 개요**

    - **Scotty**는 **Skyloom 네트워크에 접속하는** **저궤도(LEO) 위성용 사용자 단말(User Terminal)** 이다.
    - 이 단말은 **LEO 위성과 Skyloom의 정지궤도(GEO) 중계** **노드**를 연결하여, **LEO → 클라우드(On-the-Cloud)** 로의 **멀티 Gbps급 데이터 전송**을 가능하게 한다.
    - LEO 위성은 약 **2시간 이내에 지구를 한 바퀴 공전**하기 때문에, **특정 지상 지점과의 통신 가능 시간은 수 분에 불과**하다.
    - 이로 인해, 전통적인 방식으로는 데이터 오프로드(지상 전송)가 극도로 제한된다.
    - 그러나 **Scotty OCT**는 이러한 제약을 극복한다.
    - Skyloom의 **고용량·다중 사용자용 광중계 위성(GEO Relay Node)** 과 직접 연결함으로써,
    - LEO 위성이 **지상국 없이도 항상 네트워크에 연결된 상태**를 유지할 수 있도록 한다.
    - 즉, Scotty OCT를 탑재한 LEO 위성은 더 이상 지상-LEO 간 단기 통신창에 의존하지 않고, **지속적인 데이터 업링크/다운링크**가 가능하다.
  - **🔧 주요 특징**

    - **GEO를 통한 Skyloom 네트워크 접근 지원**
    - **최대 20 Gbps급 LEO–GEO 링크 지원**
    - **반구형(Hemispherical) 시야각(Field of Regard)** — 광추적 범위 확장

**🛰️ Uhura (GEO → GROUND)**

- - **정지궤도 광(光) 중계 위성 (Geostationary Optical Relay Satellite)**
  - **기술 개요**

    - **Uhura**는 Skyloom이 개발한 **정지궤도(GEO) 기반 광중계 위성**으로,
    - **GEO–LEO** 및 **GEO–지상(Ground)** 간의 데이터 전송을 담당하며,
    - **실시간(real-time)** 및 **초저지연(super-low-latency)** 통신을 가능하게 한다.
    - 이 위성은 Skyloom이 직접 설계·제작한 **소형 고용량 다중사용자(multi-user) 광중계 위성**으로,
    - 지구의 자전 속도와 완벽히 일치하는 정지궤도 상에서 **항상 동일한 지점을 바라보며**,
    - 지상국과의 **항시 연결(always-on connection)** 을 유지한다.
    - 또한 Skyloom의 네트워크는 **모든 구간이 광(光) 링크로 구성되어 있으므로**,
    - 기존 GEO 시스템에서 불가피했던 **지연(latency)** 문제를 근본적으로 제거한다.
  - **🔧 주요 특징**

    - **정지궤도 투입 속도:** 5일 이내(Launch → GEO Insertion)
    - **완전 재생형 통신(Fully Regenerative Comms):** 수신·복조·재변조를 통해 신호 품질을 유지
    - **짐벌식 광학 헤드(Gimbaled Optical Heads):**
    - LEO/MEO 위성에서 지상으로 데이터를 중계하기 위한 정밀 조향 시스템
    - **RF 백업 링크 내장:**
    - RF 백업 다운링크를 통해 **99% 이상 링크 가용성(Link Availability)** 확보
    - **전송속도:**

      - 20 Gbps (LEO ↔ GEO, 1550 nm)
      - 20 Gbps (GEO ↔ 지상, 1550 nm)
    - **첫 중계 노드 배치 예정:** 2024년 4분기, **아시아-태평양(Asia-Pacific)** 커버리지

**✅****Skyloom의 주요 기술과 포지션**

**🚀 Skyloom의 실제 기술 방향: “클래식 광통신 인프라”**

- - Skyloom이 개발하는 **OCT(Optical Communication Terminal)** 과 **GEO 릴레이 위성(Uhura)** 은 기본적으로 **레이저 기반의 고속 데이터 전송**을 목표로 하고 있다.

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **목적** | **핵심 기술** | **Skyloom 기술과의 관계** |
| **클래식 광통신** | 초고속 데이터 전송, 백홀 구성 | 레이저 변조(IM/DD, coherent QPSK 등), 포인팅/추적(ATP), 광중계 | ✅ Skyloom의 핵심 기술 영역 |
| **양자통신** | 양자키분배(QKD), 얽힘 전송 | 단일광자원, 편광/위상 얽힘 유지, SPAD 검출기, QBER 관리 | ❌ Skyloom이 현재 직접 다루지 않음 (향후 확장 가능) |

**🌐 Skyloom의 역할: “백홀(backhaul) 인프라”**

- - Skyloom은 **LEO–GEO–지상–클라우드** 구간을 연결하는 **지구 전체의 광통신 백본(backbone)** 을 만드는 데 집중하고 있다.
  - 즉, 이들은 **데이터를 빠르게, 안정적으로, 대용량으로 전송하는 인프라 사업자**로서, 현재 기술은 “클래식(고전적) 광학 통신” 범주에 속한다.

    - 전송 속도: 수 Gbps ~ 100 Gbps급
    - 통신 방식: Intensity Modulation / Direct Detection (IM/DD)
    - 주요 구성: 레이저 송수신기, 짐벌식 포인팅 시스템, adaptive optics

**🧩 QKD와의 관계 — “잠재적 호환성은 있음”**

- - 다만, Skyloom의 기술이 **“양자 통신의 물리적 인프라”로 활용될 가능성**은 매우 높다.
  - 그 이유는 다음과 같다:

    - **QKD도 결국 광자 기반 통신이므로, 동일한 광경로(optical link)를 활용할 수 있음**

      - → Skyloom의 LEO–GEO–지상 간 광링크를 통해 **양자 키 분배용 단일광자 신호**를 보낼 수 있음.
    - **정밀 포인팅 및 추적(ATP) 기술**이 이미 양자 위성통신(QKD satellite link)에 필요한 수준에 근접.

      - → 이는 중국 *Micius* 위성, 유럽의 *Eagle-1*, 캐나다의 *QEYSSat*과 같은 QKD 위성에서 요구되는 기술과 유사함.
    - **1550 nm 파장대**를 사용하는 Skyloom의 시스템은

      - → 기존 광섬유 기반 QKD 채널 및 광검출기(Ge/Si-APD)와 호환성이 높음.

**🔭 정리하자면**

|  |  |  |
| --- | --- | --- |
| **항목** | **Skyloom 현재 목표** | **양자통신(QKD) 관점** |
| **핵심 목적** | 고속 데이터 전송(광 기반 백홀) | 안전한 양자 키 분배 |
| **사용 파장대** | 1550 nm (C-band) | 동일 또는 유사 |
| **전송 방식** | 다중비트 변조 (클래식 통신) | 단일광자 변조 |
| **기술 난이도** | 광정렬·포인팅·대역폭 확보 | 얽힘 유지·광자손실 최소화 |
| **Skyloom의 현위치** | 백홀 인프라로서 “양자네트워크의 물리적 기반”을 제공할 수 있는 수준 | 자체적으로 QKD를 수행하진 않음 |

- - Skyloom은 현재 “양자 통신의 기반이 되는 고전적 광통신 네트워크 인프라”를 구축 중이다.
  - 이 인프라 위에 QKD나 얽힘 전송 기술을 얹는 것은 **별도의 파트너(예: ID Quantique, Qubitekk, or Infleqtion)** 가 수행해야 할 다음 단계이다.
  - 즉, Skyloom은 ‘양자 통신 네트워크의 백본을 깔고 있는 회사’로 보는 게 가장 정확하다.

**✅****기존 인프라를 이용하여 기존의 고대역폭 광통신과 양자 통신에 사용이 가능한가?**

**🧩 1️⃣ 공통적으로 사용할 수 있는 구성요소**

- - 양자통신(QKD 또는 얽힘 분배)은 **광자 단위(single-photon level)** 로 동작하지만, 전송 경로와 제어 계층은 고전 광통신과 거의 동일하다.

|  |  |  |
| --- | --- | --- |
| **구성요소** | **QKD / 양자통신에서 재사용 가능 여부** | **설명** |
| **광경로 (Optical link)** | ✅ 동일 | 자유공간(FSO), 광섬유(Fiber) 모두 동일 물리적 매체 사용 |
| **파장대 (1550 nm 등)** | ✅ 동일 | C-band 파장은 감쇠 최소·안전(eye-safe), 양쪽에서 표준 |
| **포인팅·트래킹 시스템 (ATP)** | ✅ 동일 | 위성·지상 간 정렬 기술 그대로 사용 가능 |
| **광학 안테나 / 렌즈 / 미러 / 빔 익스팬더** | ✅ 동일 | 동일한 빔 형성·수집 기구 |
| **적응 광학(Adaptive Optics)** | ✅ 동일 | 대기 난류 보정은 고전·양자 모두 필요 |
| **시간 동기화 시스템 (GPS·원자시계)** | ✅ 동일 | QKD에서 광자 타임태그 매칭에 필요 |
| **데이터 백홀(클래식 채널)** | ✅ 필수 | QKD에서 key sifting, error correction, privacy amplification 등에 고전 채널 필요 |

- - 👉 즉, **Skyloom이 구축한 광학 링크·포인팅·지상국 인프라**는 양자통신의 물리적 기반으로 그대로 사용

**🚫 2️⃣ 다른 부분 — 광원·변조·검출**

- - 양자통신은 **정보를 광자의 “존재 여부”나 “편광 상태”로 표현**하기 때문에, 기존의 **클래식 통신 방식(IM/DD, QPSK, OFDM 등)** 과는 완전히 다르다.

|  |  |  |  |
| --- | --- | --- | --- |
| **항목** | **고전 광통신** | **양자통신(QKD, Entanglement)** | **차이점** |
| **광원 (Laser Source)** | 강한 연속파(CW) 레이저 또는 펄스레이저 (10¹² 광자/펄스 수준) | 약광(coherent) 또는 단일광자(single-photon) 레벨, 때로는 얽힘광자쌍 | 광자 수 조절·확률적 얽힘 생성 |
| **변조기 (Modulator)** | 진폭/위상/편광 변조기 (기호·파형 부호화) | 편광·위상·시간-bin 등 **양자 상태 변조기** | classical bit ↔ qubit 차이 |
| **검출기 (Detector)** | PIN photodiode, APD, coherent receiver | SPAD, SNSPD (단일광자 검출기) | 감도, 노이즈, 포화 한계가 완전히 다름 |
| **에러 관리** | FEC, ARQ 등 | QBER 기반 에러·보안 판정 | classical error ↔ quantum error 해석 차이 |

- - 👉 따라서 Skyloom의 **레이저 송수신기**와 **검출기 체계**는 QKD용으로 그대로 쓸 수 없고, “단일광자원 + 양자변조기 + SPAD 검출기” 같은 **전용 모듈**로 교체해야 한다.

**🔬 3️⃣ 현실적 하이브리드 접근**

- - 현재 연구와 시제품 개발 방향은 “클래식 인프라 + 양자 모듈” 하이브리드이다.

예시:

|  |  |  |
| --- | --- | --- |
| **회사/기관** | **접근 방식** | **기술 구조** |
| **ID Quantique (스위스)** | 기존 광섬유 백본 위에 QKD 모듈 삽입 | λ-division으로 QKD 채널과 데이터 채널 병행 |
| **Toshiba Europe** | 1550 nm QKD over fiber | DWDM coexistence 시연 |
| **Micius 위성 (중국)** | 자유공간 링크 기반 양자 얽힘 분배 | 고전 채널 + 얽힘 채널 병행 |
| **Skyloom (잠재적)** | GEO–LEO 광링크를 QKD 백홀로 재활용 가능 | 동일 경로에 양자 송수신 모듈 장착 가능 |

- - 👉즉, Skyloom이 **“양자 신호용 송수신 모듈을 추가 장착”** 하면, 현재 네트워크를 그대로 **QKD relay infrastructure** 로 전환할 수 있다.

> **그런데, QKD가 보편화 되기 전까지 고대역폭 광 통신 기술은 다른 어디에 쓰이게 될까?????**
