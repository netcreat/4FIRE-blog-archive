**📌 기술 체계 정의**

- - 우주용 태양광 어레이는 크게 다음 3가지 구조적 요소로 나뉜다:
  1. **에너지 변환 (Energy Conversion)**

     - 태양광 → 전력 변환
     - 주요 기술: 고효율 III-V 계 GaAs 셀, 시리즈 인터커넥트, 방사선 경화
  2. **전개 메커니즘 (Deployables & Kinematics)**

     - 지상에서 접힘 상태로 발사 → 궤도에서 펼침
     - 주요 구성: 힌지, 붐, 보강 방향성 소재, 롤-아웃 텐션 구조
  3. **열/구조 통합 (Structural + Thermal Integration)**

     - 출력, 방사, 진동, 하중 분산, 궤도 수명 제어
     - 우주환경(thermal cycling, radiation, vacuum)에 최적화 필요
  - ROSA는 이 3 요소 중 **(2) Deployables + (3) Structural**에서 강점을 가진다.

**📌 ROSA / iROSA 아키텍처 기술 분석**

- - ROSA (Roll-Out Solar Array)는 이름 그대로 **말아서 수납 → 펼쳐서 구조화**하는 방식의 어레이이다.
  - 핵심 기술 요소는 아래와 같다:
  - **① Roll-out boom**

    - 탄성 저장 에너지를 이용해 전개
    - 모터·전동식이 아니라 구조 내재 에너지를 이용 → **고신뢰성·저복잡성**
    - Space-qualified composite boom 사용
  - **② Flexible blanket solar array**

    - 전개식 유연 패널 구조
    - rigid honeycomb 대신 flexible polymer substrate
    - → 질량 대비 면적 비가 기존 대비 상승
  - **③ Tensioning & locking mechanism**

    - 전개 후 구조 안정화
    - micro-vibration damping 포함
  - **④ Cell efficiency & radiation tolerance**

    - Orbit에 따라 셀 유형은 달라짐
    - ISS, LEO = radiation 상대적으로 낮음
    - Lunar/Mars/GEO = 고방사선 → triple junction III-V GaAs 활용
  - **⑤ Power-per-kg 효율**

    - ROSA의 판매 포인트는 여기 있다:

      - **Power / kg 비율이 높다**
    - 이는 launch cost가 $/kg 기준에서 $/Watt 기준으로 전환되는 시장에서 매우 중요한 지표임

**📌 Heritage (사용 실적) 분석 – 매우 중요**

- - ROSA/iROSA는 **실제 궤도에서 사용된 유일한 roll-out class power system 중 하나**이다.
  - **ISS iROSA upgrade**

    - ISS 수명 연장을 위해 기존 rigid 패널 위에 overlay 방식으로 증설
    - “retrofit solar extension”이라는 독특한 접근
  - **Ovzon-3**

    - 통신 위성 → GEO mission
    - roll-out array heritage 확보
  - **Lunar Gateway PPE**

    - NASA / Northrop Grumman PPE module의 전력공급
    - → 심우주 영역 적용 가능성 증명
  - **이 heritage는 시장 진입장벽을 만든다.**

    - 항공우주에서는 heritage는 아래와 동의어이다:

> *heritage = reliability = contract award likelihood*

**📌 경쟁 기술과 비교**

- - Roll-out array가 경쟁하는 기술은 다음 세 가지:

|  |  |  |
| --- | --- | --- |
| **경쟁 구조** | **핵심 특징** | **한계** |
| Rigid panel (고정형) | 구조 안정성 + 높은 신뢰성 | 질량 높음, 부피 큼 |
| Folded panel (접힘) | 일정한 compactness 제공 | 힌지·동력 시스템 복잡 |
| Wrap-around (drum-wrapped) | 통신 위성에서 오래 사용 | 부피/질량 trade-off |

- - ROSA는 이들 대비 **mass + volume + deployment complexity** 측면에서 유리함.
  - 이를 식으로 표현하면:

    - Deployment Efficiency = (W/m2) / (kg/m2) / (mechanism complexity)
  - ROSA 계열은 이 efficiency가 높다.

**📌 진입장벽 구조**

- - 태양광 어레이는 생각보다 진입장벽이 높다. 이유는:
  - **(A) Qualification Barrier**

    - vibration
    - thermal cycling
    - radiation
    - vacuum material outgassing
    - deployment failure mode
    - → 실패 = 미션 전체 실패
  - **(B) Heritage Barrier**

    - 고객 입찰에서 heritage는 필수
  - **(C) Integration Barrier**

    - 전력 어레이는 우주선 전력망과 연결되어:

      - array → power conditioning → bus → payload
    - 즉 단순한 구조물이 아니라 시스템 구성 요소이다.
    - 이 때문에 **검증된 공급자 수가 매우 적다**.

**📌 경쟁사 비교**

|  |  |  |
| --- | --- | --- |
| **업체** | **포트폴리오** | **우위 영역** |
| Maxar | GEO 버스 + 통신 위성 전력 | 대규모 위성 heritage |

| Airbus Defence & Space | Eurostar + Orion supplier | 유럽 정부/ESA alignment |

- - 단, 이들과 Redwire는 경쟁축이 다르다:

    - Maxar/NG/Airbus = **플랫폼 프라임**
    - Redwire = **전력/전개 서브시스템 전문**
  - 즉 Redwire는 niche 구성요소 시장에서 승부한다.

**📌 시장 구조 관점**

- - 태양광 어레이는 아래 시장에 공급된다:

    - LEO 통신 위성
    - GEO 통신 위성
    - 심우주 Gateway
    - ISS retrofit
    - Lunar surface power
    - planetary missions
  - 앞으로 가장 빠르게 커질 섹터는:

    1. LEO constellation
    2. Lunar Gateway / Artemis pipeline
    3. Surface power for lunar operations
    4. DoD ISR constellation
  - ROSA는 (1)(2)(4)에 바로 맞고 (3)은 후보군이다.

**📌 요약**

- - Redwire solar/deployables의 기술적 포인트는:

    - ✔ Roll-out 메커니즘 경쟁력
    - ✔ heritage 기반 신뢰성
    - ✔ mass/volume 효율
    - ✔ 심우주 적용 가능성
    - ✔ integration capability
    - ✔ niche component specialist 포지션
  - 반면 한계는:

    - ❌ 플랫폼/버스 프라임이 아님
    - ❌ 전력 conditioning까지는 안 감
    - ❌ payload ecosystem 제어권은 약함
    - ❌ 대형 사업의 CAPEX 규모 부족
  - 즉 기술적으로는 강하지만 사업적으로는 **프라임과의 협업이 전제된 생태계 전략**이다.

**📌 TAM / CAGR (글로벌)**

- - Solar Arrays는 오래된 시장이지만 **Station + VLEO + Defense ISR + Lunar**에서 새롭게 성장한다.

|  |  |  |
| --- | --- | --- |
| **세그먼트** | **TAM(2030)** | **CAGR** |
| Commercial Station | **$2.5–3.5B** | ~17–22% |
| Defense ISR (LEO/VLEO) | **$1.2–1.8B** | ~14–19% |
| Exploration (Lunar/Deep Space) | **$0.9–1.3B** | ~11–16% |
| GEO/Comsat Replacement | **$1.0–1.5B** | ~4–6% |

- - **총합 TAM (2030)**: $5.6B–$8.1B 규모
  - CAGR **~12–16%**
  - 과거 대비 **고성장 시장으로 재분류**됨.
