**✅ IRIS****2** **QKD microsatellite pilot mission의 본질**

**📌 목적**

- - 120kg 이하 **QKD 마이크로 위성**
  - EU산 핵심 부품 사용
  - 30개월 내 발사
  - 최소 6개월 궤도 운용
  - 최소 2개 OGS와 키 교환

**📌 계약 범위 (End-to-End)**

|  |  |
| --- | --- |
| **영역** | **포함 여부** |
| 위성 플랫폼 설계 | ✅ |
| QKD 페이로드 설계 | ✅ |
| 발사 서비스 확보 | ✅ |
| 궤도 운용 | ✅ |
| OGS 연동 | ✅ |
| 키 성능 보고 | ✅ |
| 임무 종료 계획 | ✅ |

- - **중요:**

    - EC (European Commission)는 위성을 소유하지 않음.
    - Contractor가 위성, 발사, 운영 모두 책임

**📌 기술적 요구 핵심**

- - **위성 스펙**

    - < 120kg
    - 소형화(SWaP 중시)
    - PAT 포함 광학 터미널
    - EU27 핵심 QKD 부품 필수
  - **반드시 포함해야 할 기능**

    - **필수 KPI**

      - KPI1: Distilled key volume + AES256 key 수
      - KPI2a: QBER
      - KPI2b: Link loss
      - KPI2c: End-to-end loss
      - KPI3: 성공 링크 비율
      - KPI4: Uptime %
  - **혁신 요소 최소 1개 이상 필수**

    - 예시:

      - Entanglement distribution
      - Fibre network 인터페이스
      - Dual wavelength (NIR + C-band)
      - Daylight QKD
      - Real-time distillation
  - 👉 이건 단순 BB84 다운링크 데모가 아니다.
  - **“기술 리더십 증명용”** 파일럿이다.

**📌 가장 중요한 부분 — 참여 제한**

- - **조건:**

    - EU Member State 설립
    - EU 내 활동 수행
    - 제3국 통제 금지
    - Launch prime은 EU 발사체 필수

**📌 Prime 가능 기업 예상**

- - 이 Tender는 사실상:

    - Airbus Defence & Space
    - Thales Alenia Space
    - SES + EU QKD consortium
  - 같은 EU 대형 우주기업 대상이다.
