# Quantum Motion Delivers the Industry’s First Full-Stack Silicon CMOS Quantum Computer

**💡****핵심 내용**

- - Quantum Motion이 표준 **300 mm 실리콘 CMOS 웨이퍼 공정**(기존 반도체 제작 공정)으로 만든 전체 스택(full-stack) 양자컴퓨터를 공개했다.
  - 영국 국가 양자컴퓨팅센터(National Quantum Computing Centre, NQCC)의 Testbed Programme 하에 설치됨.

**💡****구성 요소와 특징**

- - 시스템은 **silicon spin-qubit QPU**, 제어 스택(control stack), 사용자 인터페이스(user interface)를 포함함. 소프트웨어 프레임워크로는 Qiskit, Cirq와 호환됨.
  - 냉각기(dilution refrigerator) 및 제어 전자장치(control electronics)가 포함된 전체 시스템이 **19인치 서버 랙(rack) 3개**로 구성됨. Data-centre 친화적이고 업그레이드 가능하게 설계됨.
  - 보조 장치는 별도로 배치 가능하여, 향후 더 큰 QPU로 확장할 경우에도 시스템 전체 랙 크기는 변하지 않도록 설계됨.

**💡****확장 및 상업적 비전**

- - 이 아키텍처는 **tile-based 구조**로 되어 있어, 칩 위에 여러 타일(tile)을 반복적으로 인쇄(print)함으로써 큐비트 밀도를 높이고 확장 가능하게 설계됨. 수백만(qubits) 규모까지 확장하는 것이 목표임.
  - 또한 AI/머신러닝 기반의 자동 튜닝(tuning)과 보정(calibration) 알고리즘을 포함하여, 장비 운영 효율과 제어의 자동화를 도입함.

**💡****의미**

- - 실리콘 CMOS 공정이라는, 기존 반도체 산업 인프라가 갖춘 제조 기술을 사용함으로써, 양자컴퓨터의 대량생산(mass-manufacturability) 가능성이 커짐.
  - “상업적으로 유용(commercially viable)” 수준으로의 진입 가능성을 보이며, “이 십 년 내” 실용적인 양자컴퓨터 출시를 목표로 함.

**✅****Quantum Motion**

**💡****개요**

- - 설립: **2017년**, 영국 런던/옥스퍼드 중심으로 시작됨. 주요 창립자 중에 UCL(University College London) 및 옥스퍼드 대학 연구자들이 있음.
  - 목표: 실리콘(silicon) 기반의 스핀 큐비트를 사용하여, CMOS 공정에 호환되는, 확장 가능하고 비용 효율적인 양자컴퓨터 아키텍처(fault-tolerant) 개발.
  - 본사 및 활동 범위: 영국 중심이나 호주(Australia)에 연구소 확장함. 국제 인재 확보와 글로벌 협업 중임.

**💡****기술 방식**

1. 1. **실리콘 스핀 큐비트 (Silicon Spin Qubits)**

      - 전자를 양자점(quantum dot)에 가두고 그 스핀 상태(up/down 또는 superposition)를 큐비트로 이용함.
      - 스핀 큐비트는 이론적으로 coherence(양자 상태 유지) 성능이 높으며, 오류 정정(fault tolerance)의 요구에 맞추기 적합하다고 평가됨.
   2. **CMOS 호환성 (CMOS Compatibility, Silicon MOS 프로세스 등)**

      - 기존 반도체 산업에서 사용되는 CMOS 트랜지스터／칩 제작 공정을 활용함으로써 생산 규모(scalability)와 비용 효율성(cost efficiency)을 확보하려 함.
      - 300mm 실리콘 웨이퍼(fab) 기반 프로세스를 사용하여 양자점 배열(quantum dots array)을 제작함.
   3. **크라이오(Cryo) 제어 전자장치 및 자동화된 측정/튜닝**

      - 큐비트가 작동하는 극저온(milli-kelvin) 환경에 제어 전자장치(electronics) 또는 복합(chiplet) 제어 회로(proximal, cryo-CMOS control chip)를 통합함. 잡음(noise)과 연결선(interconnect)의 복잡성을 줄이려 함.
      - 대량의 양자점 수천 개(quantum dots) 측정(characterisation) 작업 및 튜닝(tuning) 자동화 기능 개발함. 예: “Bloomsbury” 칩에서 1,024 양자점(quantum dots)을 하나의 칩에서 작동시키고 짧은 시간 내에 읽어낼 수 있음.
   4. **확장 가능성(Scalability) 및 전체 스택(full-stack) 아키텍처**

      - 단순히 큐비트 하나가 아닌, 큐비트 배열(qubit array), 읽기/쓰기(readout), 제어(control), 보정(calibration), cryo-electronics, 사용자 인터페이스 등 전체 시스템(stack)이 작동 가능하도록 통합 설계함.
      - 타일(tile) 기반 반복 가능 구조로 설계하여, 큐비트 밀도를 높이고 칩 면적당 많은 큐비트를 배치할 수 있게 함.

**💡****성과 및 최근 동향**

- - “Bloomsbury” 칩: 3×3 mm² 면적에 1,024개의 양자점(quantum dots)을 가진 칩을 제작하고, 이 칩을 standard foundry에서 제조함.
  - 실리콘/C-MOS 기반 양자컴퓨팅 프로토타입 시스템을 NQCC(National Quantum Computing Centre, UK)에 구축 완료함. Full stack 시스템이 실제 테스트/검증 단계 진입함.
  - 자금 조달이 활발함: 과거 투자 라운드에서 £42 million 이상 유치함.

**💡****한계 및 도전 과제**

- - 오류율(error rates) 및 코히런스 시간(coherence times) 개선 필요: 스핀 큐비트라도 주변 전자 노이즈, 전압 잡음(voltage noise), 전하 소음(charge noise) 등이 큐비트 성능을 저하함.
  - 제어 회로(control electronics)의 열 잡음(thermal noise) 및 전력 소비(power consumption), 연결선(cabling), 배선(wiring) 복잡성 해결이 필요함. 특히 cryogenic 환경 내에서의 제어 전자 설계가 기술적 난제임.

    - 극저온 필수
  - 논리적 큐비트(logical qubit) 수준의 오류 정정(error correction) 구현까지는 아직 갈 길이 있음. 물리 큐비트(physical qubit) 수가 많아져야 하고, 제어 정밀도, 균일성(uniformity), 재현성(reproducibility) 확보가 중요함.

**✅****퀀텀닷(Quantum Dot) 양자컴퓨터**

**💡****퀀텀닷(Quantum Dot)이란?**

- - 퀀텀닷은 **나노미터 크기의 반도체 구조체**로, 전자(또는 정공, hole)가 내부에 전기적으로 혹은 전위(potential well)에 의해 국한(confined)되어 있는 구조이다.
  - 이 작은 크기 덕분에 전자의 에너지 준위가 연속적이지 않고, “양자화(quantized)” 되어 discrete energy levels를 갖는다. 즉, 인위적인 원자(artificial atom)처럼 동작할 수 있다.

**💡****Quantum Dot Qubit (Spin Qubit 중심)**

- - 퀀텀닷을 이용한 큐비트는 주로 “스핀(spin) 기반” 방식이 많이 연구되고 있다. 기본 아이디어는 다음과 같다:

|  |  |
| --- | --- |
| **구성 요소** | **내용** |
| **시스템 구성** | 반도체 내부에 전자를 하나 혹은 소수 개를 가두는 퀀텀닷과, 이를 제어할 수 있는 게이트(electrical gates), 터널 장벽(tunnel barriers), 주위 마그네틱 필드 등이 필요함. |
| **게이트 조작 (Control / Gate Operations)** | 전기장(gate voltage), 마그네틱 필드(magnetic field), 마이크로파(microwave) or 전자기 펄스(pulses) 등을 이용해서 스핀의 방향을 바꾸거나(superposition 생성), 위상 변이(phase rotation) 등을 수행함. 두 개의 quantum dot을 서로 커플링해서 entangling gate를 만듦. |
| **측정 (Readout / Measurement)** | 전자의 스핀 상태를 읽기 위해, 스핀 상태이 변화가 전류(tunneling current)나 전하(charge) 배리언스(charge sensing) 등에 영향을 주는 방식을 사용. 또는 공명(microwave resonance) 변화 등을 이용하기도 함. |

**💡****장점 및 도전 과제**

|  |  |
| --- | --- |
| **장점** | **설명** |
| **반도체 공정과의 호환성** | 실리콘(silicon)이나 기타 반도체 재료를 사용하면, 기존 semiconductor fabrication 기술(CMOS 등)과의 통합이 가능 → 스케일업(scaling) 가능성이 좋음. |
| **작고 집적 가능** | 작은 크기의 quantum dots 여러 개를 배열함으로서 다수 개 큐비트를 만들 수 있고, 게이트 제어 회로와도 비교적 가까이 배치 가능. |
| **코히런스 개선 가능성** | 특히 spin qubits는 잘 설계하면 잡음(noise) 제거, 게이트 구성의 “sweet spot”을 찾는 등으로 coherence time (양자 상태 유지시간)을 늘릴 가능성이 있음. 최근 연구에서 이런 방향의 진전 있음. |

|  |  |
| --- | --- |
| **단점 / 기술적 과제** | **설명** |
| **코히런스 시간 vs 노이즈** | 전하(charge) 노이즈, 전자 주변의 핵스핀(nuclear spins)과의 상호작용, 온도 변화, 전기 필드 변동 등이 스핀의 상태을 흐트러뜨림 → coherence time이 제한됨. |
| **읽기(readout)의 정확성 및 속도** | 스핀 상태를 정확히, 빠르게 측정해야 하고 측정 과정에서 오차(error)나 누수(leakage)가 발생하기 쉬움. 또한, 측정 장치(센서)와의 간섭(crosstalk) 등의 문제가 있음. |
| **제어 및 커플링 복잡성** | 많은 양자점(quantum dot)을 배열하고, 서로 상호작용하게 하려면 정밀한 전기적 게이트 설계, 터널 장벽 제어 등이 매우 까다로움. 구성 요소 간 간섭(crosstalk) 관리, 균일성(uniformity) 유지 등이 중요함. |
| **온도 및 환경 조건** | 낮은 온도(밀리켈빈 수준), 전자기적 잡음 차폐, 전기적 간섭 최소화, 깨끗한 재료(clean materials) 필요. 인프라 요구가 높음. |

**💡****이온트랩과의 공통**

- - **양자 상태를 가둘 ‘우물(potential well)’이 존재**

    - 이온트랩: 전자기장을 이용해 진공 속에서 이온(원자 하나에서 전자가 빠져나간 입자)을 공중에 띄워 가둠.
    - 퀀텀닷: 반도체 안에서 전자를 **전기적 게이트 전위**로 만든 “나노 스케일 우물”에 가둠.
  - **양자화된 상태(discrete states)를 사용**

    - 이온트랩: 이온의 내부 에너지 준위(전자 껍질의 전자 상태, 보통 하이퍼파인 상태)를 큐비트로 사용.
    - 퀀텀닷: 전자의 스핀 상태(up / down) 또는 전하 상태를 큐비트로 사용.
  - **외부 제어로 연산**

    - 이온트랩: 주로 **레이저**(혹은 마이크로파)를 써서 이온의 내부 상태를 바꾸고, 이온들 간의 집단 진동 모드(phonon)를 이용해 얽힘 게이트를 만듦.
    - 퀀텀닷: **전기장 + 마이크로파 + 자기장**으로 스핀을 제어하거나, 이웃 퀀텀닷과 교환 상호작용(exchange interaction)을 통해 얽힘을 만듦.

**💡****차이점**

|  |  |  |
| --- | --- | --- |
| **구분** | **이온트랩** | **퀀텀닷** |
| **물리적 환경** | 진공 챔버 속에서 개별 이온을 전자기장으로 공중에 띄움 | 반도체 내부에 전자를 가둔 “인공 원자” |
| **작동 온도** | 상온 또는 약간 냉각(실험적으로는 진공에서 레이저 냉각) | 밀리켈빈 수준 극저온(희석 냉동기 필요) |
| **큐비트 정체성** | 원자라는 “자연적인 입자”라서 원자별 특성이 매우 균일 | 반도체 제작 과정에 따라 결함·불균일성이 생기기 쉬움 |
| **스케일링(확장성)** | 수십~수백 이온 정도를 정렬해 제어 가능. 모듈을 광자 인터커넥트로 이어야 확장 가능 | 반도체 CMOS 공정과 호환 → 잠재적으로 **수백만~수십억 큐비트** 집적 가능 |
| **코히런스 시간** | 매우 길다(초~분 단위도 가능) | 주변 핵스핀, 전하 잡음 등으로 더 짧음(보통 μs~ms 수준, 개선 연구 중) |
| **제어 방식** | 레이저(고정밀 광학 시스템 필요) | 전극 게이트와 전자기 신호(반도체 회로 기반) |
