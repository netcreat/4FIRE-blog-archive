# 6G × NTN: 표준이 되는 Access, 경쟁이 되는 Space Backbone

Published: 2026-03-05T22:51:52.303000+09:00

Original Naver post: https://blog.naver.com/4-fire/224205933883

---

**✅ 서론**

- - 최근 6G 논의에서 가장 많이 등장하는 단어 중 하나가 NTN(Non-Terrestrial Networks)이다.
  - 위성, 고고도 플랫폼, 항공 네트워크를 셀룰러 시스템에 포함시키겠다는 개념이다.
  - 하지만 여기서 많은 사람들이 한 가지를 혼동한다.

    - **“6G가 NTN을 포함한다” = 우주 네트워크 전체가 3GPP 표준이 되는 것인가?**
    - 답은 **아니다.**
  - 현실적인 구조는 이렇게 나뉜다.

    - Access (3GPP 표준화) → 6G NTN (RF) → Satellite Network → Space Backbone (Optical Network) → Gateway / Internet

**✅ 6G 주파수 구조 (핵심 개념)**

- - 6G는 하나의 대역이 아니라 **다층 스펙트럼 구조**로 설계된다.

|  |  |  |
| --- | --- | --- |
| **레이어** | **주파수** | **역할** |
| 저대역 | sub-1 GHz | 커버리지 |
| 중대역 | 3-24 GHz | 핵심 트래픽 |
| mmWave | 24-100 GHz | 고속 |
| Sub-THz | 100-300 GHz | 초고속 |

- - 세대별 흐름은 명확하다.

|  |  |
| --- | --- |
| **세대** | **주요 대역** |
| 2G | 900 MHz |
| 3G | ~2 GHz |
| 4G | 2-6 GHz |
| 5G | sub-6 + mmWave (밀리미터파) |
| 6G | mmWave + Sub-THz |

- - - 대역폭 ↑
    - 주파수 ↑
  - 하지만 여전히

    - 저주파 → 커버리지
    - 고주파 → 속도
  - 이 구조는 쉽게 바뀌지 않는다.

    - 이유는 파장이 길수록 **회절과 건물 침투가 가능하고 경로 손실이 작기 때문**이다.

|  |  |  |
| --- | --- | --- |
| **주파수** | **특징** | 파장 |
| 700 MHz | 가장 멀리 감 | ~43 cm |
| 800 MHz | 건물 침투 좋음 | ~38 cm |
| 900 MHz | 커버리지 좋음 | ~33 cm |
| 3.5 GHz | 속도 좋지만 멀리 못 감 | ~8.6 cm |
| 28 GHz | 거의 직선 | ~1 cm |

- - **파장이 길수록 다음이 가능하다.**

    - **장애물 회절 가능**
    - **건물 침투 가능**
    - **안정적 연결**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMDVfNjEg/MDAxNzcyNzE4MzI4NTc0.3hnJGcsG1LVdZGK9Ny-QvvvymcP39VUlrTTFzVEdpHwg.BI1IDQxikMkCnrOda9YkYHM-v8yOv84ZMSJjqhQ6R4kg.PNG/image.png?type=w800)](#)

**✅ 6G PHY 구조 (변조)**

- - 6G에서도 기본 구조는 크게 바뀌지 않는다.

    - OFDM
    - QAM
    - Adaptive Coding
    - Beamforming
  - 다만 QAM 단계는 더 올라간다.

|  |  |
| --- | --- |
| **Modulation** | **bits/symbol** |
| QPSK | 2 |
| 16-QAM | 4 |
| 64-QAM | 6 |
| 256-QAM | 8 |
| 1024-QAM | 10 |
| 4096-QAM | 12 |

- - 하지만 여기서 중요한 사실이 있다.

    - **Direct-to-Phone NTN에서는 이런 고차 QAM을 항상 쓰기 어렵다.**
  - 이유는 단순하다.

    - 폰 안테나
    - 출력
    - 스펙트럼
  - 제약 때문이다.
  - 그래서 Direct-to-Phone NTN은 **Coverage layer 성격**이 강하다.

---

**✅ NTN (Non-Terrestrial Networks)**

- - NTN은 위성, 고고도 플랫폼 등을 포함하는 **비지상 네트워크** 개념이다.
  - 셀룰러 네트워크에서 보면 satellite = cell tower in space에 가깝다.
  - 하지만 이 개념은 갑자기 등장한 것이 아니다.

**📌** **3GPP 표준과 NTN 진화**

|  |  |
| --- | --- |
| **Release** | **내용** |
| Rel-17 | NTN 최초 도입 |
| Rel-18 | 5G Advanced NTN |
| Rel-19 | NTN 성능 개선 |
| 6G | Native NTN 가능성 |

- - Release-17은 **위성과 셀룰러 네트워크의 통합을 가능하게 한 첫 표준**이다.
  - 이를 통해 스마트폰이 **위성과 직접 연결되는 Direct-to-Device 통신**이 가능해졌다.

**📌** **NTN의 중요한 기능**

- - 대표적인 것이 NTN fallback이다.
  - 즉 지상망 → 위성망으로 자동 전환된다.
  - 예를 들어 다음이 가능하다.

    - 도시 → 지상 5G
    - 산악 → NTN
  - 그래서 NTN은 현재로서는 **coverage 확장이나 fallback layer**로 활용되는 경우가 많다.

**📌** **NTN의 3가지 시장**

- - NTN은 하나의 시장처럼 보이지만 실제로는 **세 가지 완전히 다른 구조**다.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **유형** | **단말** | **속도** | **목적** | **대표** |
| Direct-to-Phone | 스마트폰 | kbps ~ Mbps | 커버리지 | ASTS / Starlink D2D |
| Broadband NTN | 전용 단말 | 100 Mbps ~ Gbps | 인터넷 | Starlink |
| Space Backbone | 위성 장비 | 100 Gbps ~ Tbps | 백본 | OISL |

- - 이 세 시장은 기술적으로도 완전히 다르다.

    - Direct-to-Phone은 **RF Access**
    - Broadband NTN은 **위성 ISP**
    - Space Backbone은 **광 네트워크 인프라**

> *만약 6G에서 NTN fallback이 표준 기능으로 자리 잡는다면,*
>
> *direct-to-device 위성 인프라의 전략적 가치가 크게 상승할 가능성이 있다.*
>
> *이런 관점에서* ***AST SpaceMobile*** *같은 기업은 6G NTN 구조의 잠재적 수혜 기업으로 볼 수 있다.*

**✅ RF NTN vs Laser OISL (많이 헷갈리는 부분)**

- - 많은 사람들이 묻는다.

    - **“둘 다 위성 링크인데 왜 QAM이 다르냐?”**
  - 답은 **채널 물리 특성**이다.

|  |  |  |
| --- | --- | --- |
| **항목** | **RF NTN** | **Laser OISL** |
| 매체 | RF | Optical |
| 빔폭 | 넓음 | 매우 좁음 |
| 채널 안정성 | 비교적 안정 | 난류 영향 |
| 페이딩 | 완만 | deep fade |
| 포인팅 요구 | 낮음 | 매우 높음 |

- - 그래서 변조 전략도 달라진다.

|  |  |
| --- | --- |
| **링크** | **주력 변조** |
| RF NTN | OFDM + QAM |
| Laser | PPM / DP-QPSK / Coherent Modulation |

- - - 레이저가 QAM을 못 쓰는 것이 아니라 **채널 안정성이 다르기 때문**이다.

**✅ 중요한 공식 (통신 용량)**

- - 통신 용량은 다음으로 결정된다. (Shannon 용량)

    - Capacity = Bandwidth × Spectral Efficiency

[![](https://postfiles.pstatic.net/MjAyNjAyMjFfMTMg/MDAxNzcxNTk5ODYyMDE1.m0W4Svf8lnHOkbaydsihObm-n22tFIfxn4c6sXdd4n0g.FSfh4MjsB6eP8bi-6tie0a3jMGKjb7QtjS4O14YHHk8g.PNG/image.png?type=w773)](#)

- - 즉

- - - 실제 네트워크에서는 modulation과 coding을 통해 spectral efficiency가 결정된다.
  - 그래서 이런 역설이 나온다.

|  |  |  |
| --- | --- | --- |
| **링크** | **대역폭** | **용량** |
| RF NTN | MHz~GHz | Gbps |
| Optical | THz | Tbps |

> *레이저는 QAM이 낮아도 더 빠르다.*

**✅ 미래 네트워크 구조**

- - 결국 네트워크는 이렇게 된다.

|  |  |  |
| --- | --- | --- |
| **Layer** | **역할** | **기술** |
| Access | 사용자 접속 | RF / 6G NTN |
| Space Backbone | 위성 네트워크 | OISL / Optical |
| Internet | 지상 네트워크 | IP / Fiber |

> ***Access = RF***
>
> ***Backbone = Optical***

**✅ 중요한 구조적 변화**

- - 앞으로 데이터 구조는 이렇게 될 가능성이 높다.

    - Access traffic < Backbone traffic
  - 즉

    - Direct-to-Phone < Satellite backbone 이다.
  - 수백만 사용자의 트래픽이 결국 위성 네트워크로 집중되기 때문이다.
  - 그래서 최근 연구도

    - Tbps OISL
    - coherent optical
    - adaptive optical modulation
  - 쪽으로 집중되고 있다.

---

**✅ 결론**

- - 6G와 NTN은 같은 것이 아니다.
  - 6G NTN이 표준화하는 것은 **Access** 이다.
  - 반면 우주 네트워크의 핵심 경쟁은 **Backbone** 에서 벌어진다.

> *6G NTN은 위성을* ***셀룰러 Access layer로 통합하려는 표준화 노력****이다.*
>
> *하지만 우주 네트워크의 실제 용량 경쟁은* ***Space Backbone(Optical)*** *에서 벌어진다.*
