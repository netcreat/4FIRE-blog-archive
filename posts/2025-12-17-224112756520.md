**✅****뉴스 요약**

- - IonQ와 자회사 ID Quantique(IDQ)는 Cisco와 협력해 스위스 제네바 주 내 두 데이터센터를 **양자 내성 네트워크**로 업그레이드했다. 본 구축은 Cisco의 **SKIP**과 IDQ의 **Solteris Network Appliance**를 통합해, 기존 성능 저하 없이 양자 컴퓨터 위협에 대비한 보안을 구현한 사례다.
  - Cisco Nexus 9000 스위치는 하드웨어 가속 **MACsec** 암호화를 제공하며, SKIP을 통해 외부 키 관리 시스템과 연동된다. Solteris는 **QRNG와 키 관리 소프트웨어**를 결합해 양자 내성 키를 out-of-band 방식으로 분배한다.
  - 이번 프로젝트는 스위스에서 **최초의 실운영 양자 내성 네트워크**로, 공공 인프라를 대상으로 한 포스트 양자 보안 전환의 시작을 의미한다.

**💡MACsec**

- - 정의

    - MACsec (IEEE 802.1AE)은 **이더넷 프레임(Layer 2)을 그대로 암호화**하는 표준이다.
  - 목적

    - 특정 노드 사이의 L2 구간을 암호화하여 도청/감청을 차단하기 위한 표준
  - Use-case

    - 데이터센터 간 링크 (DCI) - 이번 뉴스의 사례
    - 스위치-스위치 / 스위치- 서버
    - 통신사 / 백본 링크
    - 정부 및 금융 에서 요구되는 고신뢰 링크
  - IPSec 대비 차이점

    - L2 기반으로 동작하므로 인접한 디바이스 구간에만 적용 가능
    - 인터넷 구간 사용 불가
    - 라우팅 경유 불가

**💡기존 MACsec의 단점**

- - 기존에는 PSK(Pre-Shared Key)을 사용

- - **🔴키 생성의 문제 (사람이 만든 키)**

    - 사람이 생성하거나 스크립트로 생성
    - 엔트로피 품질 불확실
    - “충분히 랜덤한가?”를 증명하기 어려움
    - 📌 **보안 감사에서 가장 먼저 걸리는 포인트**
  - **🔴키 배포의 문제 (양쪽 수동 동기화)**

    - Site A, Site B에 **완전히 동일한 키** 필요
    - 한 글자라도 틀리면 연결 실패
    - 실패해도 로그는 애매함
    - 📌 실제 현업: “어? 링크는 up인데 암호화가 안 걸렸네…”
  - **🔴키 회전 문제 (거의 안 함)**

    - 키 교체 = 양쪽 동시 작업
    - 야간 작업 필수
    - 장애 리스크 때문에 **사실상 장기 고정**
    - 📌 결과: PSK가 ‘Pre-Shared’가 아니라 ‘Perma-Shared’가 됨
  - **🔴내부자·유출 리스크**

    - 키가 메모, 문서, 패스워드 매니저, 스크립트 에 남음
    - 📌 PSK 하나 유출 = **링크 전체 무력화**
  - **🔴규모 확장 불가**

    - MACSec 링크가 소수명 가능하지만,
    - 50개, 100개가 넘어가면 난감해짐.
  - **🔴양자 보안 관점의 한계**

    - MACsec 자체는 양자 내성 ⭕
    - **PSK의 생성·유통 과정은 전혀 양자 내성 아님**
    - 📌 즉:암호는 강한데, 열쇠 관리가 약함
  - **🔴실제 설정 예**

! 1. 키체인 생성 - key-string 명령어에 64자리 hex 코드를 양쪽 디바이스에 동일하게 입력해야함
key chain MACSEC-KEY
key 1
key-string 0 0123456789ABCDEF0123456789ABCDEF
cryptographic-algorithm aes-256-cmac
! 2. MACsec 정책 정의
macsec policy MACSEC-POLICY
cipher-suite GCM-AES-256
key-chain MACSEC-KEY
! 3. 인터페이스에 적용
interface Ethernet1/1
macsec
macsec policy MACSEC-POLICY

- - **→** ***중앙 키 서비스가 고엔트로피 대칭키를 생성·분배***
  - **SKS (Secure Key Service)**

    - SKS는 “QKD 없이도 쓸 수 있는 소프트웨어 기반 중앙 키 서버”다.

      - 대칭키 생성
      - 키 풀(pool) 관리
      - 키 수명 관리
      - 자동 회전
      - 엔트로피 관리
      - 외부 장비에 키 제공
  - 특징

    - 소프트웨어로 키를 생성하고 관리하기 때문에

      - 별도의 광 통신 채널이 필요하지 않고, 그에 따른 거리 제한도 없다.
      - 구축 비용도 QKD에 비해 저렴한 편
    - SKS 서버와 네트워크 장비사이에서 키를 교환하기 위한 프로토콜 필요

      - SKIP (Cisco’s Secure Key Integration Protocol)

**💡하이브리드 방식**

- - **🏆 장기 최종 목표 (국가·군사·핵심 인프라)**

    - 👉 **QKD + (SKS/PQC) 하이브리드**
    - 이유:

      - QKD:

        - 키 분배의 근본적 안전성
      - SKS/PQC:

        - 확장성
        - 비용
        - 백업 경로
    - 📌 실제 국가 전략의 방향
  - **🏅 엔터프라이즈 현실적 최적해 (대부분의 고객)**

    - 👉 **SKS + SKIP (지금) → PQC (점진적)**

      - **SKS + SKIP 방식은 PQC보다 암호학적으로 안전하지만, 중앙 신뢰를 전제로 하기 때문에**
      - **전 세계 공통 해법이 될 수 없고,**
      - **PQC 위에 "선택적 강화 계층"으로 남게 된다.**
    - 이게 Cisco가 밀고 있는 **정답 루트**

      - 파이버 제약 ❌
      - 비용 현실적
      - 자동 키 관리
      - 지금 바로 배포 가능
    - **🧪 PQC-only는 언제 적합하냐?**

      - 글로벌 인터넷
      - 클라우드
      - 수천 km 거리
      - QKD 불가능 환경

> ***PQC는 모두가 갈 수 있는 길이지만,***

> ***QKD를 기존 네트워크에 ‘자연스럽게’ 붙일 수 있는 길은 지금으로선 Cisco SKIP 하나뿐이다.***

**✅****IDQ Solteris Network Appliance**

**🧠 Solteris 네트워크 어플라이언스란?**

- - **Solteris Network Appliance**는 Quantum Key Management System (Q-KMS)을 구현하는 네트워크 어플라이언스로, 독립형으로 또는 양자키분배(QKD) 네트워크의 확장 장치로 동작한다.
  - ID Quantique (IDQ)의 **Clarion KX 플랫폼**을 내장하고 있으며, NIST 승인 **QRNG(Quantum Random Number Generator)** 기반의 고급 난수(entropy) 소스를 통해 안전한 키 생성을 지원한다.
  - 랙마운트 가능한 하드웨어로, 엔터프라이즈급 성능과 **다양한 물리적 포트, 이중 전원 등 고가용성 요건**을 만족한다.

**📌 주요 기능과 목적**

1. 1. **양자 안전 키 교환 (Quantum-Safe Key Exchange)**

      - Solteris는 양자 컴퓨터의 위협으로부터 안전한 키 교환(Key Exchange)을 제공하여, 현재의 공개키 인프라(PKI) 기반 암호가 곧 위험해질 미래에도 데이터가 안전하게 전송되도록 설계되었다.
   2. **QKD 네트워크 확장**

      - 양자키분배(QKD) 장비를 설치하기 어려운 환경에서도 **QKD 네트워크를 확장**할 수 있도록 도와준다. 기존 네트워크 인프라에서 양자 보안 키를 배포하거나 혼합된(post-quantum + QKD) 방식으로 운영할 수 있다.
   3. **독립형 또는 통합형 배포**

      - **Standalone**: 독립된 Q-KMS 노드로 동작하여 키 관리 및 배포 기능 수행
      - **QKD 확장**: 클라리온 KX 기반의 QKD 시스템과 통합되어 대규모 양자 네트워크 구축 지원
   4. **다중 공급업체 및 미래 확장성**

      - 다양한 벤더의 QKD 시스템 및 암호화 장비들과의 상호운용성을 제공하며, **양자 위협 시대에도 유연한 네트워크 보안 인프라 구축**을 목표로 한다.

**1️⃣ 물리 계층: QKD 링크 (광섬유)**

- - **두 데이터센터 사이에 전용 광섬유**가 있고
  - 그 위에서 **IDQ의 QKD 시스템**이 동작
  - 결과물은 데이터가 아니라 **“동일한 비밀키를 양쪽에서 동시에 생성”**
  - 📌 핵심

    - 키는 **전송되지 않음**
    - 도청 시 **물리적으로 탐지 가능**
  - **대표적인 방식인 BB84를 예로 개념적으로 설명을 하자면,**

    - 비유: 친구랑 비밀 암호를 주고받는데, 편지를 두 가지 종류의 암호글씨(예: 세로쓰기와 가로쓰기) 중 하나로 무작위로 쓴다고 생각하면 된다.
    - 원리: 송신자(Alice)가 광자의 편광(또는 위상)을 무작위 기저로 부호화해서 보내고, 수신자(Bob)도 무작위 기저로 측정한다.
    - 기저가 맞으면 같은 비트를 얻고, 기저가 다르면 쓸모없는 값이 나온다.
