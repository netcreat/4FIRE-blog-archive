**✅ 핵심 요약**

**1) 세계 최초: 소프트웨어 기업이 자체 QPU 운영**

- - 기존에는 IBM, Google, Rigetti, Quantinuum처럼 **하드웨어 기업**만 자체 QPU 운영.
  - Horizon Quantum이 **직접 조립·통합한 양자컴퓨터를 본사(싱가포르)에 구축**.
  - 순수 소프트웨어 기업이 자체 시스템을 운영하는 것은 업계 최초.
  - → 이는 하드웨어-소프트웨어 공동 최적화(co-design)를 목표로 하는 전략적 전환.

**2) 완전한 하드웨어–소프트웨어 통합 테스트베드 구축**

- - Maybell(극저온 플랫폼) + Quantum Machines(OPX 제어 전자장치) + Rigetti(초전도 QPU)의 **모듈형 구성**.
  - 특정 벤더에 종속되지 않고, **최고 성능 부품을 조합한 맞춤형 시스템**.
  - 👉 *“최고의 모듈들을 조합해 자신만의 시스템을 만든 것”*

**3) 모듈형 설계 → 다양한 아키텍처 실험 가능**

- - 제어 전자장치나 QPU를 쉽게 교체할 수 있는 구조.
  - 초전도뿐 아니라, 향후 이온트랩/중성원자/포토닉 등 **다양한 하드웨어와의 통합 실험** 가능.

**4) Triple Alpha 개발환경과 깊은 통합**

- - Horizon의 IDE이자 실행 스택인 **Triple Alpha와 하드웨어 제어 시스템을 직접 연결**.
  - 이론–실제 하드웨어 간 간극을 줄이고, 디버깅·최적화 능력 강화.
  - 이번 시스템을 통해:

    - Triple Alpha ↔ 제어 전자기기(OPX) ↔ QPU
    - 간 **완전 통합 및 핸드셋 튜닝 가능**
  - 즉, 소프트웨어가 QPU 물리 제어 레이어까지 깊게 관여할 수 있음.

**5) 기업 전략적 의미**

- - 하드웨어-소프트웨어 공동 최적화 역량 확보 → **양자우위(quantum advantage) 달성에 유리**.
  - 향후 SPAC 상장(dMY Squared와 합병) 과정에서 **기술적 신뢰도를 크게 강화**.

**6) Triple Alpha를 통해 외부 개발자에게도 접근 가능 예정**

- - 자체 QPU를 Triple Alpha 플랫폼에서 이용 가능하도록 제공할 계획.

**✅ 왜 이것이 중요한가?**

**💡산업적 포인트**

1. 1. **소프트웨어 선도기업이 ‘하드웨어 최적화권’을 갖는다**

      - 기존 QC 소프트웨어 회사는 클라우드 QPU에 의존 → 내부 제어 로직 접근 불가.
      - Horizon은:

        - QPU 파형(pulse), calibration, scheduling까지 직접 제어 가능
        - → **속도·정확도·에러 감소 최적화에서 경쟁우위** 확보.
   2. **모듈형 아키텍처 → 여러 종류의 하드웨어를 직접 검증**

      - Horizon의 핵심 가치: **“어떤 QPU에서도 돌아가는 통합 개발환경”**
      - 이를 위해:

        - 초전도 → 이미 확보
        - 향후 trapped-ion, neutral-atom, photonic 등도 추가 가능
        - 여러 제어 전자장치(OPX, Zurich Instruments 등) 교체 가능
        - 여러 QPU 공급사(Rigetti → Oxford Ionics → Pasqal → Quantinuum…)와 실험 가능
      - 즉, **Horizon이 “양자 분야의 Android OS”가 되려는 전략의 기반 확보**.
   3. **기업가치 측면: SPAC 합병 직전의 기술적 신뢰도 확보**

      - 이번 발표는 dMY Squared와의 SPAC 상장 과정에서 기업 가치 정당성을 강화.
      - 단순한 소프트웨어 스타트업 → 실제 QPU 운영 능력을 갖춘 **hybrid quantum infrastructure 기업**으로 포지셔닝.

**💡기술적 포인트**

1. 1. **Full-stack control**

      - 파형 제너레이션
      - 실시간 피드백
      - error mitigation
      - scheduling / compilation tuning
      - → 모든 레이어 직접 손댈 수 있음.
   2. **Hardware-in-the-loop 개발 가능**

      - Triple Alpha IDE에서 작성된 코드를
      - → 컴파일
      - → 스케줄
      - → pulse 레벨로 변환
      - → 물리 QPU에서 실행
      - 이 과정을 **전부 하나의 회사 내부에서 반복할 수 있게 됨.**
   3. **‘이상적인 이론 모델 ↔ 실제 장비’ 간 격차 감소**

      - 실험기반 튜닝이 가능해지므로:

        - execution latency 최적화
        - 게이트 펄스 shaping 개선
        - 에러 모델 학습
        - 경로 기반 스케줄 최적화
        - 등이 소프트웨어 업데이트만으로도 빠르게 반영됨.

**💡 경쟁사 대비 Horizon의 차별점**

|  |  |  |
| --- | --- | --- |
| **회사** | **강점** | **한계** |
| **Quantinuum, IBM** | 자체 QPU + 자체 SW | Vendor lock-in 구조 |
| **Q-CTRL, Classiq, Riverlane** | 뛰어난 소프트웨어 | 하드웨어 접근 불가 → 최적화 한계 |
| **Horizon Quantum** | **소프트웨어 회사인데도 하드웨어 직접 제어** → *full-stack control* | QPU 연산규모는 아직 작을 가능성 |

****

- - Horizon은 사실상 **“하드웨어 없는 소프트웨어 회사”라는 기존 양자 SW 기업의 구조적 약점을 깨는 첫 사례**임.

**💡 왜 Rigetti였나?**

- - Rigetti는 다음 장점을 가짐:

    - QPU를 모듈 형태로 제공(Foundry 사업 기반)
    - 제3자에게 제공 가능한 few vendors 중 하나
    - Quantum Machines OPX와 완전 호환
    - 소형 testbed용 QPU 공급 경험 있음
  - 👉 *“가장 쉽게 가져다 붙여서 연구용 시스템 만들기 좋은 초전도 QPU 공급사”*

**

**💡 Horizon Quantum의 향후 전략 방향 추정**

1. 1. **다중 QPU testbed 구축**

      - 앞으로 trapped-ion, neutral-atom 등 다른 공급사 장비도 넣어 **멀티-QPU 연구소**가 될 가능성.
   2. **Triple Alpha를 ‘OS’로 발전**

      - 현재는 IDE지만, 미래에는:

        - Quantum OS
        - Hardware abstraction layer (HAL)
        - Unified pulse scheduler
        - Hybrid classical-quantum orchestrator
        - 로 확장될 전망.
   3. **하드웨어-최적화 compiler stack 개발**

      - OpenQASM3, MLIR, QIR, custom IR 전부와 상호 동작하도록 확장될 수 있음.

**💡 정리: 이번 발표가 가진 진짜 의미**

- - **Horizon은 단순 SW 스타트업이 아니다 → Full-stack quantum infrastructure 기업으로 변신 중**
  - **모듈식 testbed는 ‘양자 소프트웨어 OS’ 경쟁에서 강력한 무기**
  - **SPAC 상장을 앞두고 기술적 신뢰도를 크게 강화**
  - **산업 전반에서도 '소프트웨어 중심 하드웨어 통합'이라는 새로운 트렌드 시발점**

  - 전액 보통주(common equity)로 구성 → 투자자들이 장기적 가치 상승을 기대한다는 의미.

    - “Triple Alpha는 미래의 **Quantum OS 플랫폼**이 될 것이다.”
    - “우리는 실제 하드웨어까지 통제하면서 시장의 중심으로 들어가고 있다.”
    - “이 전략은 IonQ와 Fortune 50 기업 같은 업계 최상위 플레이어도 인정했다.”

**6) Horizon의 가치가 더 높아진 이유**

    - → “실제로 QPU를 돌릴 수 있다.”
  - **플랫폼 비전의 시장 검증**

  - **SPAC 상장 과정에서의 신뢰성 강화**

**✅ 최종 정리: 왜 이 두 뉴스가 결합될 때 의미가 폭발하는가**

**💡****기술적 전환**

- - Horizon은 소프트웨어 기업임에도 **직접 조립한 QPU를 운영하는 첫 회사**가 됨.

**💡****플랫폼 전략의 산업적 인정**

- - IonQ의 투자는 Horizon의 **Cross-platform Quantum OS 전략이 하드웨어 회사에도 반드시 필요한 인프라**임을 보여줌.

**💡****재무적 기반 확보**

- - PIPE + SPAC을 통해 **137M 달러 현금 확보** → 멀티-QPU 테스트베드 확장 가능.

**💡****시장 포지셔닝 변화**

- - Horizon은 이제 “양자 소프트웨어 회사”가 아니라
  - **“양자 하드웨어-소프트웨어 통합 플랫폼 기업”**,
  - 즉 **Quantum OS 기업**으로 재정의됨.

> 예전에는 한국에서 컴퓨터를 삼보컴퓨터에서 완제품을 구입하던 시절이 있었다. (PC 보급의 시작은 애플이었지)
>
> 물론, 컴퓨터에 어느정도 지식을 갖춘이들은 용산 전자상가에 직접 가서 원하는 케이스부터 팬까지 부품을 별도로 구매해서 조립하는 조립PC의 붐이 일었다.
>
> 요즘에는 에누리나 다나와 같은 가격비교사이트를 통해서 직접 온라인 구매를 하게 되거나, 완제품 노트북이 왠만한 데스크탑에 버금가기 때문에, 다시 완제품 노트북 수요가 늘었다.
>
> 양자컴퓨터도 삼보 → 조립 시대로 넘어가는 중이다.
