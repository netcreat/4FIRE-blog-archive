- - 시드니대학교 연구팀은 칩 스케일 Brillouin 레이저 내에서 발생하는 **Brillouin cascading 현상**을 억제하는 새로운 방법을 제시하였음.
  - 레이저 공진기 내부에 **나노미터 규모의 Bragg 격자 구조(photonic bandgap)를 형성**하여, 잡음을 발생시키는 **기생 모드의 밀도 상태를 원천적으로 제거**하였으며, 그 결과 **잡음 없는 단일 모드 출력과 고출력 동시 달성이 가능**하게 되었음.
  - 본 기술 적용 시,

    - **레이징 임계치가 6배 증가**
    - **기본 모드의 출력이 2.5배 향상**
    - **초저잡음, 초협대역 레이저 스펙트럼 확보**
  - 또한 이 Bragg 격자는 **레이저 빛을 이용하여 재구성 가능**하므로,

    - 단일모드 ↔ 다중모드 모드 간 전환이 가능하고
    - 추가적인 칩 재제작 과정이 필요하지 않음.
  - 이는 **양자컴퓨팅, 정밀센싱, 위성항법(GPS), 저잡음 주파수 빔(combs), 양자 네트워크 통신** 등 미래 핵심 기술의 발전을 가속화할 것으로 기대됨.

**🌟 Brillouin 레이저란?**

- - Brillouin Laser(브릴루앙 레이저)는 **Brillouin 산란(Stimulated Brillouin Scattering, SBS)** 효과를 이용해 구동되는 특수 레이저이다.
  - 프랑스의 물리학자 **레이먼드 브릴루앙 (Léon Brillouin, 1889–1969)** 의 이름에서 유래했다.

    - 그는 물질 내부에서 빛이 **음향 파(phonon)** 와 상호작용해 산란되는 현상 — 즉, **빛-음향 상호작용에 의한 주파수 이동(scattering)** 을 이론적으로 설명한 사람이다.
  - 기본 구조는 일반 레이저와 비슷하지만, 광섬유 또는 포토닉 칩 내부에서 광(光)이 음향(phonon)과 상호작용하여 생성되는 ‘Stokes 파’를 사용해 레이저를 증폭한다.

**📌 핵심 원리**

|  |  |
| --- | --- |
| **요소** | **설명** |
| **SBS(Stimulated Brillouin Scattering)** | 강한 레이저 광이 물질 내에서 **음향 파(phonon)** 를 유도하고, 이로 인해 **뒤로 되돌아오는(Backscattering) Stokes 빛**이 생성됨 |
| **Brillouin gain** | 이 산란된 빛이 다시 증폭 과정을 거쳐 레이징(lasing) 조건에 도달 |
| **결과** | 매우 **좁은 라인폭(ultra-narrow linewidth)**, **높은 위상 안정도(coherence)** 의 빛 생성 |

- - 즉, **빛 + 음향 상호작용 기반의 극도로 안정된 레이저**이다.
  - 레이저 중에서도 **가장 순수한(coherent)** 빛을 만들 수 있다는 점이 핵심 경쟁력이다.

**🔥 왜 지금 연구가 중요해졌나?**

- - Brillouin 레이저는 매우 순수한 빛을 만들 수 있지만,
  - 출력을 높이면 **Brillouin cascading → parasitic modes 생성 → 잡음 증가** 문제가 발생했다.
  - 이번 Sydney 연구는

> **Photonic bandgap(Bragg grating)** 으로 parasitic 모드를 원천 차단하여
>
> **더 높은 출력 + 더 깔끔한 스펙트럼** 을 구현한 최초 사례

- - 즉,
  - **🔹 양자 네트워크 / 위성 광링크 / QEC / photonic computing 상용화의 핵심 기초가 해결됨**
