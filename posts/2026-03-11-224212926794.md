# 빈 공과대학교와 중국 연구팀, 4상태 광자 양자 게이트 구현

Published: 2026-03-11T19:28:01.061000+09:00

Original Naver post: https://blog.naver.com/4-fire/224212926794

---

> 오스트리아의 **빈 공과대학교**(TU Wien)와 중국 협력 연구팀이 4준위 광자 시스템(쿼딧, qudit)에서 작동하는 새로운 얽힘(entangling) 양자 논리 게이트를 구현하는 데 성공했다.
>
> 이 연구가 무엇인지 어떤 의미를 갖는지 분석해보겠다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMTFfMTAx/MDAxNzczMjIyNTYxMzAx.TcpHJT4G9EjNP1KfiepO-wgMhNQ_AuDvYh1ZStxVbwIg._JSwj-g1QIfo7D94hfzDAOYxkBeVnXnoE3OnHkPSmbUg.PNG/image.png?type=w800)](#)

[Heralded High-Dimensional Photon-Photon Quantum Gate](https://arxiv.org/html/2407.16356v1)

- - **주요 계산 광자**

    - **Photon 1**
    - **Photon 4**
  - 이 두 개가 실제로 **연산을 수행하는 qudit**
  - **보조 광자 (auxiliary photons)**

    - **Photon 2**
    - **Photon 3**
  - **이들은 게이트를 구현하기 위해 추가된 보조 입자**
  - **HD Beam splitter**

    - **특정 OAM 상태만 경로가 바뀜**
  - 이 그림은 결국 **광자 1번과 광자 4번에게 특별한 규칙을 한 번 적용하는 장치**다.
  - 그 특별한 규칙이 바로 **CPF gate**이다.
  - 이 게이트의 규칙은 아주 단순하게 말하면:

    - 두 광자가 모두 “맨 마지막 상태”에 있을 때만 부호를 바꾼다.
    - 나머지는 건드리지 않는다.

---

**✅ 논문 핵심 요약**

**1️⃣ 연구 목적**

- - 기존 광자 기반 양자컴퓨팅은 대부분 **2차원 상태(qubit)** 기반이다.
  - 하지만 이 논문은 **고차원 상태(qudit)** 를 사용해 **광자-광자 양자 게이트**를 구현하는 것을 목표로 한다.

    - qubit → 2 상태
    - qudit → d 상태 (이 연구는 **d=4**)
  - 고차원 시스템의 장점:

    - 동일한 photon 수로 **더 큰 상태공간**
    - **더 적은 게이트로 동일한 계산**
    - **양자 통신 보안 강화**
  - 하지만 광자 사이에는 **직접적인 상호작용이 거의 없기 때문에** 두 광자 간 entangling gate 구현이 어려운 문제가 있다.

**2️⃣ 연구의 핵심 아이디어**

- - 연구팀은 다음을 구현했다.
  - **4차원 qudit-qudit entangling gate**

    - 구현된 게이트:

      - **CPF (Controlled Phase Flip) gate**
    - 동작 원리:

      - 특정 상태일 때만 위상을 반전

        - 두 광자가 둘 다 마지막 상태에 있으면, 그 항에 마이너스 부호를 붙인다.
        - 여기서 d는 차원을 가리키지만, 우리는 4차원을 주로 다루게 되니, d=4라고 정의할 수 있다.

- - - - 나머지 상태는 그대로 유지.
      - 예를 들어 두 광자의 가능한 상태 조합이 있다고 해보자.

        - |0,0⟩
        - |0,1⟩
        - |1,2⟩
        - |3,2⟩
        - |3,3⟩
        - 이 중에서 **오직 |3,3⟩만** 바뀐다.
      - 즉:

        - |0,0⟩ → 그대로
        - |0,1⟩ → 그대로
        - |1,2⟩ → 그대로
        - |3,2⟩ → 그대로
        - |3,3⟩ → **−|3,3⟩** 다.

**3️⃣ 왜 중요한가**

- - 4차원 qudit 게이트를 기존 qubit 게이트로 분해하면 **최소 13개의 entangling gate 필요**
  - 하지만 이 논문에서는 **한 번의 native qudit gate로 구현**
  - 즉 **고차원 컴퓨팅 효율 향상**

****

**4️⃣ 광자 인코딩 방법**

- - 이 연구의 핵심 기술:

    - **Orbital Angular Momentum (OAM)**

      - 광자는 회전하는 파동 모양을 만들 수 있다. 이것을 OAM이라고 한다.
      - 즉, 광자가 소용돌이 모양으로 회전하는 공간 모드를 이용한다.
      - 예시:

|  |  |
| --- | --- |
| **qudit state** | **OAM** |
| |0⟩ | ℓ = −2 |
| |1⟩ | ℓ = −1 |
| |2⟩ | ℓ = 0 |
| |3⟩ | ℓ = +1 |

- - - 즉, **광자의 공간 wavefront 구조**를 이용한 다차원 정보 인코딩이다.

**5️⃣ 실험 구조**

- - 실험은 다음 구성으로 이루어진다.
  - **사용 광자**

    - 총 **4개 photon**

      - photon 1 → control qudit
      - photon 4 → target qudit
      - photon 2,3 → auxiliary photon
    - 광자 생성:

      - **SPDC (spontaneous parametric down-conversion)**
    - BBO crystal 사용.
  - **핵심 장치**

    - 논문 실험의 핵심:
    - **High-dimensional OAM beam splitter**
    - 역할:

      - 특정 OAM 상태만 다른 경로로 분리
      - 광자 간 간접 interaction 구현

**6️⃣ Heralded gate**

- - 이 게이트는 **heralded gate**다.
  - 의미:

    - 게이트 성공 여부를 **measurement로 확인 가능**
  - 장점:

    - destructive measurement 불필요
    - larger circuit에 사용 가능
  - 하지만 성공 확률:

    - **1/8** (이론적).

**7️⃣ 실험 결과**

- - 측정된 성능:
  - **process fidelity**

- - 그리고 실제로

    - product state → entangled state 생성 확인
    - entangled state fidelity

**8️⃣ 기술적 기여**

- - 논문이 만든 핵심 기술:
  - **① High-dimensional OAM beam splitter**

    - 다차원 OAM 상태 분리
  - **② OAM phase-locking technology**

    - Mach-Zehnder interferometer 안정화
    - → **3시간 이상 안정 유지**
  - **③ heralded qudit entangling gate**

    - photonic qudit gate 최초 실험 구현

**9️⃣ 연구 의미**

- - - 이 연구는 다음 분야에 중요하다.
  1. **고차원 양자컴퓨터**

     - qudit 기반 광자 quantum computing
     - 참고) 이온트랩에서는 메타안정상태와 하이퍼파인상태를 적절히 사용하게 되면 충분히 Qudit 사용이 가능하다.
  2. **양자 네트워크**

     - photonic qudit = 네트워크에 매우 적합
  3. **양자 통신**

     - high-dimensional QKD
     - Bell state analysis
     - quantum teleportation

**🔟** **핵심 내용**

- - 보통 광자는 서로 상호작용을 거의 안 한다.
  - 그래서 광자 + 광자 = entangling gate를 만들기 어렵다.
  - 그런데 이 논문은 4차원 photonic qudit에서 entangling gate 를 실험적으로 구현했다.

    - 기존의 2상태 큐비트(qubit)를 넘어, **광자 하나당 4개의 양자 상태**(쿼딧)를 사용하는 게이트
    - 일반적인 **편광(polarization)** 인코딩 대신 광자의 궤도 각운동량(orbital angular momentum, OAM)을 활용
    - 두 광자의 얽힘 생성 및 해제(entanglement / disentanglement)를 제어 가능
    - 게이트 성공 여부를 알려주는 **헤럴디드(heralded) 프로토콜** 적용 → 실용적 신뢰성 향상

> *양자컴퓨터에서는 고차원(qudit) 접근이 주로* ***광자 기반 양자컴퓨터에서 특히 의미가 크다.*** *반면* ***양자 네트워크는 정보 전달 매개체로 광자를 필수적으로 사용하기 때문에****, 이러한 기술은 양자 네트워크에서* ***더욱 결정적인 역할을 할 것으로 전망된다.***
