# Astera Labs (1) - 기술 분석

**✅ Astera Labs**

**📌 회사 개요**

- - **회사명:** Astera Labs, Inc.
  - **설립:** 2017년
  - **창업자:** Jitendra Mohan, Sanjay Gajendra, Casey Morrison
  - **본사:** 미국 캘리포니아주 **San Jose (산호세)**
  - **산업:** 반도체 / AI 인프라 및 데이터센터 연결 기술
  - **기업 형태:** 상장 기업 (Public) — NASDAQ 거래소 "ALAB"
  - Astera Labs는 자체 웨이퍼를 제조하지 않는 **팹리스(fabless)** 반도체 회사로, 데이터센터와 AI 시스템에서 빠른 데이터 전송, 메모리 연결, 고성능 신호 처리 등에 특화된 **연결 솔루션(Connectivity)** 칩과 시스템을 설계·판매한다.

**📌 설립 배경**

- - Astera Labs는 2017년 **Texas Instruments의 고속 인터페이스 사업부**에서 일하던 엔지니어들이 **AI와 머신러닝 시대의 데이터 센터 연결 병목 문제**를 해결하기 위해 설립했다.
  - 기존 연결 기술이 빠르게 발전하는 데이터센터 트래픽을 충분히 처리하지 못한다고 보고, 이를 개선할 목적에서 출발했다.

**📌 IPO 및 상장**

- - Astera Labs는 **2024년 3월 20일경**에 나스닥(NASDAQ)에서 **IPO(기업공개)를 완료**했고, 그 이후 주식이 공개 시장에서 거래되고 있다.

    - 상장 직후 주가는 공모가 대비 크게 상승하며 성공적인 데뷔를 기록했다.
    - 현재 **티커 심볼:** **ALAB**
    - IPO를 통해 수익금은 연구 개발 확대, 글로벌 인프라 및 팀 확장 등에 쓰였다.

**📌 주요 발전 및 확장**

- - 2024~2025년 사이 Astera Labs는 다음과 같은 성과를 쌓았다:

    - **글로벌 R&D 센터 확대:** 캐년(Canada), 인도 (Bengaluru) 등 연구 및 개발 거점 확대
    - **본사 확장:** 2025년에 산호세 본사 확장
    - **생산 협력:** TSMC 등 주요 반도체 파운드리와의 협력 강화
    - **제품 포트폴리오 확장:** PCIe/CXL 연결 제품, 스마트 케이블, 고속 신호 처리 칩 등 강화

**📌 제품 및 기술**

- - Astera Labs가 제공하는 핵심 제품군은 다음과 같다:

    - **고속 데이터 전송 및 연결 칩** (PCIe/CXL retimers, controllers)
    - **Smart Cable Modules**
    - **COSMOS 소프트웨어 플랫폼** (대규모 시스템에서의 연결 관리 및 최적화)
  - 이들 제품은 AI 데이터센터, 클라우드 서버, 대규모 컴퓨팅 환경에서 병목 없는 데이터 흐름을 지원하는 핵심 기술로 사용됩니다.

**📌 현재 상태 (2024–2026)**

- - Astera Labs는 상장 이후에도 성장세를 유지하고 있다:

    - 상장 주식(ALAB)은 나스닥에서 활발히 거래되며, 시가총액 $30B 규모로 평가받고 있다.
    - **2025년 3분기 기준 흑자 전환**
    - 재무 실적 및 미래 전망도 AI 인프라 수요 증가와 함께 주목받고 있다.

**📌** **“어떤 병목”을 노리는 회사인가?**

- - **NVIDIA**:

    - **Compute + NVLink + DPU**
    - → Compute + Fabric 전체를 잡고, “AI 팩토리 전체를 한 회사 스택 안에 넣는 것”이 목표.
  - **Broadcom**:

    - **Fabric Switching**
    - → 이더넷 AI 네트워크의 **스위치 대역폭/지연/전력** 병목을 해결.
  - **Marvell**:

    - **SerDes/Optics**
    - → **DPU + SerDes + 스토리지/통신** 병목을 처리 (다수 벤더에 IP/칩 공급).
  - **Astera Labs**:

    - **Memory Fabric**
    - → **PCIe/CXL 링크의 거리·신호 무결성·메모리 확장**이라는 “GPU/CPU에서 한 두 hop 떨어진 병목”을 해결.

**📌 왜 이 분석이 중요하냐?**

- - AI는 앞으로:

    - **Compute →** **Interconnect** **→ Memory → Optics** 순서로 병목이 이동한다.
  - 현재 병목은:

    - HBM
    - NVLink/PCIe
    - CXL
    - Optics
    - SerDes
    - Power
  - 여기서 Astera가 해결하는 지점이 정확히 GPU Cluster Memory Bottleneck
  - 이 포지션 **진짜 좋음**

    - 그래서 시장이 PSR 40x도 감수하는 것

**✅ 1. Astera Labs – CXL/PCIe/케이블 계층 Pure-Play**

**📌** **1-1. 역할 요약**

- - **Memory & CXL 인터커넥트 전문 회사**
  - 서버 안/밖에서 **CPU ↔ GPU/TPU/NPU ↔ CXL 메모리 풀 ↔ NVMe SSD**를 연결하는 고속 PCIe/CXL 신호 보정(리타이머)와 **CXL 메모리 컨트롤러, Smart Cable Module**에 특화.

**📌** **1-2. 제품 패밀리**

- - **① Aries – PCIe/CXL Smart Retimer**

    - **PCIe 5.0/6.0, CXL 2.0/3.0** 지원.
    - 고속 링크(64 GT/s급)에서:

      - Equalization
      - CDR(Clock Data Recovery)
      - Jitter 억제
    - 보드·커넥터·케이블을 거치며 망가지는 신호를 복원해서 **채널 리치(Reach)를 3배 이상 연장**.
    - AI/클라우드 서버에서:

      - GPU ↔ CPU
      - CPU/GPU ↔ CXL 메모리
      - CPU/GPU ↔ NVMe JBOG
      - CPU/GPU ↔ NIC/DPU
    - 를 잇는 **PCIe/CXL 트리 전체에 삽입**되는 리타이머.
    - 리타이머를 비롯한 기본 내용은 아래 두 포스트를 참고하자.

- - **② Aries Smart Cable Module (SCM) – Active Electrical Cable용**

    - Active Copper Cable(AEC)의 양 끝에 들어가는 **리타이머+신호처리 칩 모듈**.
    - **PCIe/CXL over cable**을 6–7m 이상까지 늘려서,

      - 랙 내/랙 간 GPU 서버 ↔ 외장 GPU 박스
      - GPU ↔ CXL 메모리 박스
      - GPU ↔ NVMe 박스
    - 같은 구성을 가능하게 함.
    - 7m급 AEC로 **멀티 랙 GPU 클러스터 데모** 이미 다수 시연.
  - **③ Leo – CXL Memory Controller**

    - DDR 기반 **CXL Type-3 메모리 디바이스/풀 구현용 컨트롤러**.
    - **CXL 2.0/3.0** 기반으로,

      - CPU나 GPU에서 보이는 **공유 메모리 풀**의 한 축.
    - “서버당 고정된 DRAM/HBM”을

      - → “랙/클러스터 단위에서 공유되는 메모리 풀”로 바꾸는 역할.
  - **④ Taurus – AEC Paddle Card 등 서브 패밀리**

    - AEC/케이블/보드용 보조 솔루션 패밀리.

**📌** **1-3. AI 데이터센터에서 하는 일**

- - Astera가 담당하는 건 한 줄로 정리하면 **“GPU/CPU 패키지를 벗어난 직후부터 랙/랙 간까지의 전기 신호 구간”**.
  - 구체적으로:

    - 서버 내부:

      - GPU ↔ CPU ↔ CXL 메모리 ↔ NVMe JBOG ↔ NIC/DPU사이의 **PCIe/CXL 링크 리타이밍**
    - 랙 내부/랙 간:
    - GPU 서버 ↔ 외장 GPU 박스 ↔ CXL 메모리 박스 ↔ NVMe 박스를 연결하는 **Active Copper Cable 끝단에 SCM 탑재**
  - AI 워크로드 특성상 GPU 클러스터가 **랙을 넘어서 포드·존으로 확장**되면서, PCIe 6.0 / CXL 3.0 (PAM4 기반, 채널 짧고 SI 최악)의 물리적 한계를 DSP 리타이머와 케이블 설계로 깨는 포지션.

> *“GPU와 HBM은 남이 만들고,*
>
> *그걸* ***랙·클러스터 단위로 연결·확장·풀링****하는 I/O 계층을 맡는 회사”*

**✅ 2. Marvell – SerDes + DPU + 스토리지/네트워크 하이브리드**

**📌** **2-1. 핵심 라인업**

- - **① PAM4 SerDes & PHY**

    - **56G / 112G / 224G PAM4 SerDes IP** 보유.
    - 이 IP가 들어가는 곳:

      - 스위치 ASIC
      - NIC/DPU
      - Coherent/Non-coherent Optical 모듈
      - 액티브 케이블, 칩렛 간 고속 링크
    - 5nm 공정의 **224G Long-reach SerDes** 데모:

      - lane당 200Gb/s급 신호를 AEC/칩렛 링크로 전달.
    - 결과적으로:

      - 800G / 1.6T 이더넷 포트
      - 224G/lane 계열 액티브 케이블
      - 고속 칩렛 인터커넥트
      - 의 기반 기술을 제공.
  - **② OCTEON 10 DPU / SmartNIC**

    - Arm Neoverse V2/N2 계열 코어, 5nm 공정.
    - PCIe 5.0, DDR5, 내장 스위치(1Tbps급 등) 통합.
    - 기능:

      - IPsec/TLS 암호화
      - 압축/스토리지 프로토콜 처리
      - vRouter, vFW, vLoad Balancer 등 네트워크 기능 오프로딩
    - 용도:

      - 클라우드 DC, 5G, Edge, HPC, Hyperscaler 워크로드에서 **CPU 대신 네트워크·보안·스토리지를 처리하는 SoC**.
      - SmartNIC/SmartDPU 카드 형태로 대형 DC에 탑재.
  - **③ 스토리지 컨트롤러 (Bravera 등)**

    - SSD/HDD 컨트롤러, 스토리지 가속 솔루션 분야에서 오랜 강자.
    - NVMe-oF, 엔터프라이즈 스토리지, 백업/리플리케이션 구조에 깊이 침투.
  - **④ 스위치 ASIC (Innovium 인수)**

    - Innovium 인수로 Hyperscaler용 이더넷 스위치 ASIC 시장 진입.
    - Broadcom에 이어지는 **2선 스위치 실리콘 벤더** 포지션.

**📌** **2-2. AI 데이터센터에서의 위치**

- - AI 팩토리에서 Marvell은 주로:

    - **DPU/SmartNIC 계층**

      - OCTEON 기반 DPU가 CPU 대신 네트워크/보안/스토리지 프로토콜 처리.
      - “GPU는 연산에, DPU는 IO/보안/네트워크에”라는 역할 분리 실현.
    - **PHY/SerDes 계층**

      - 스위치/NIC/가속기에 들어가는 고속 SerDes IP로 **112G/224G 링크 신호 품질과 Reach를 담당**.
      - 액티브 케이블, 칩렛 링크, CPO 등 고속 IO의 기반.

> ***NVIDIA가 자기 패브릭(NVLink/IB/Eth)을 직접 깎는다면,***
>
> ***Marvell은 여러 벤더에게 “DPU + 고급 SerDes/PHY”를 파는 공급자.***

  - 등을 최적화.

**✅ 4. NVIDIA – Compute + Fabric 풀스택**

**📌** **4-1. Scale-up: NVLink / NVSwitch**

- - **NVLink**: GPU ↔ GPU 간 고대역폭·저지연 링크.
  - **NVSwitch**:

    - 여러 GPU를 완전 연결(full-bisection) Mesh처럼 묶는 전용 스위치.
    - GB200 / Rubin 세대에서 NVLink 5/6 기반으로 **GPU당 수 TB/s급 대역폭** 제공.
  - 결과:

    - 같은 랙/섀시/모듈 내부에서 GPU들을 사실상 **하나의 거대한 메모리/컴퓨팅 풀**처럼 사용.

**📌** **4-2. Scale-out: InfiniBand(Quantum) / Ethernet(Spectrum-X)**

- - **Quantum-2 InfiniBand**

    - 400Gb/s per port, In-Network Computing, RDMA, SHARP 등 AI/HPC용 기능 집약.
    - 전통적 HPC/슈퍼컴퓨터, 일부 AI 슈퍼클러스터에서 패브릭 역할.
  - **Spectrum-X Ethernet**

    - “AI 전용 향상된 이더넷 패브릭” 컨셉.
    - 스위치(Spectrum-4/5/6) + SuperNIC(ConnectX-8/9) + DPU(BlueField)까지 SerDes 계층을 통일한 AI용 이더넷 스택.
    - RDMA/RoCE, 트래픽 스케줄링, Congestion 제어 등을 **AI 트래픽 패턴에 최적화**.
    - 자료에 “end-to-end 100G SerDes from switch to DPU to GPU”라고 할 정도로 **PHY 레벨까지 통합 설계**.
  - **미래: 실리콘 포토닉스 + CPO**

    - GTC/Hot Chips 발표에서:

      - 1.6Tbps급 포트
      - CPO
      - 실리콘 포토닉스 로드맵 공개.
    - 40만~100만 GPU급 AI 팩토리에서는 “플러그형 광모듈 + 구리” 방식으로는 **전력·비용 감당 불가**라는 판단.
    - 향후 Quantum-X / Spectrum-X에서 CPO가 기본 옵션이 될 가능성 큼.

**📌** **4-3. DPU / SuperNIC 계층**

- - **BlueField DPU**:

    - 보안, 스토리지, 가상화, 네트워크 인프라 서비스를 GPU/CPU에서 떼어내서 처리.
  - **ConnectX / SuperNIC**:

    - InfiniBand/Ethernet NIC로서 RDMA, GPUDirect, RoCE를 통해 GPU에 직접 붙는 네트워크 엔진.

> *“랙 안에서는* ***NVLink/NVSwitch****로 GPU를 묶고,*
>
> *랙 밖에서는 InfiniBand 또는 AI 전용 이더넷(Spectrum-X)로 이어서*
>
> *GPU부터 스위치, NIC, DPU, 소프트웨어 스택까지 통합한* ***엔드투엔드 AI 클러스터 플랫폼****을 만든 회사.”*

**📌 Interconnect 로드맵**

- - 인터커넥트는 두 갈래로 간다:

    - Scale-Up (in-node) → NVLink / NVSwitch Scale-Out (rack+) → Ethernet / InfiniBand
  - **Scale-Up 로드맵**

    - NVLink 세대:

      - NVLink 4: Hopper
      - NVLink 5: Blackwell
      - NVLink 6: Rubin
    - NVSwitch도 랙 단위로 확장 중 → 576 GPU → 1152 GPU 같은 클러스터가 단일 패브릭처럼 작동.
  - **Scale-Out 로드맵**

    - 여기서 **Ethernet vs InfiniBand** 논쟁이 있음.
    - 현재 상황:

      - HPC: IB 강세
      - AI Hyperscaler: Ethernet 강세
      - Enterprise AI: Ethernet 확정적 승리
    - 왜 Ethernet이 AI에서 강해지나?

      - AI는 All-to-All 통신 + QoS + RDMA + Congestion 제어가 핵심인데, 이것이 이미 Ethernet 스택에서 구현 가능해졌기 때문
    - 이를 강화하는 것이:

      - RoCE v2
      - In-Network Compute
      - Adaptive Routing
      - JCT 최적화
    - **Broadcom Tomahawk 6 / Jericho 3-AI가 여기서 사실상 레퍼런스**

**📌 PCIe 로드맵**

- - PCIe는 6.0부터 PAM4 들어오고 지옥됨:

|  |  |  |
| --- | --- | --- |
| **Gen** | **Transfer** | **Encoding** |
| 3.0 | 8GT/s | NRZ |
| 4.0 | 16GT/s | NRZ |
| 5.0 | 32GT/s | NRZ |
| 6.0 | 64GT/s | PAM4 |
| 7.0 | 128GT/s | PAM4 |

- - PAM4로 바뀌는 순간:

    - 노이즈 ↑
    - Reach ↓
    - Jitter ↑
    - Channel loss ↑
    - BER ↑
  - 그래서 필연적으로 등장하는 게:

    - → **Retimer 시장**
  - **즉 Astera가 올라타는 게 바로 이 지점.**

**📌 패키징/파운드리 관점**

- - 이제 AI 인프라는 **CoWoS+HBM**이 사실상 전쟁터

    - CoWoS capacity = GPU capacity
    - HBM capacity = GPU capacity
  - 즉 **TSMC + SK hynix**가 전체 AI 생태계의 Supply bottleneck
  - 그러니까 진짜 강한 플레이어는:

    - NVIDIA를 포함한 GPU 벤더 + HBM 벤더 + 패키징 벤더
  - Astera/Marvell/Broadcom은 그 위에 올라타는 형태임
