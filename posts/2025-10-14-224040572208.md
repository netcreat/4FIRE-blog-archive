# Telstra와 SQC이 QML을 활용한 네트워크 예측 분석을 성공적으로 시연 성공

Published: 2025-10-14T10:38:34.677000+09:00

**개요**

- - **프로젝트 기간:** 12개월
  - **참여 기관:** Telstra + Silicon Quantum Computing (SQC)
  - **핵심 목표:**

    1. SQC의 양자 리저버 시스템 *Watermelon*이 네트워크 성능 예측에 활용될 수 있는지 검증
    2. 기존 딥러닝 모델 대비 성능 및 학습 효율 비교

**주요 성과**

- - **정확도:** Telstra의 최신 딥러닝 모델과 동등한 수준의 예측 정확도 달성
  - **학습 속도:** 딥러닝 모델이 몇 주 소요되는 반면, *Watermelon*은 **단 며칠 만에 학습 완료**
  - **하드웨어 효율:** GPU 등 고성능 장비 없이도 동일 성능 구현 → **비용 및 에너지 절감 효과**
  - **응용 가치:**

    - 실시간 트래픽 변화 예측 및 자원 재할당
    - 장애 발생 전 선제적 대응
    - 사용자 맞춤형 서비스(예: 실시간 대역폭 조정)

**기술적 배경**

- - **Quantum Reservoir Computing (QRC)**

    - 양자 시스템의 내재적 동역학(quantum dynamics)을 정보 처리에 이용하는 구조
    - 전통적 딥러닝이 “데이터 → 통계적 근사” 방식이라면, QRC는 초위(superposition)와 얽힘(entanglement)을 통해 다중 패턴을 병렬적으로 처리함
    - 결과적으로 **시계열 예측(time-series forecasting)**, **노이즈나 결측치가 많은 데이터 처리**에 특히 강함
  - **Watermelon 시스템**

    - SQC가 개발한 **양자 리저버(quantum reservoir)**
    - 내부에서 양자 특성을 활용해 “비선형적 피처(feature)”를 생성
    - 이 피처를 기존 AI 모델에 입력함으로써 **학습 효율과 정확도 향상**
    - 현재 다수의 산업 고객과 시범 운영 중

**관계자 발언**

- - **Shailin Sehgal (Telstra 글로벌 네트워크 및 기술 총괄)**

> “Telstra의 복잡한 네트워크 운영 경험과 SQC의 첨단 양자 기술이 결합해
>
> 실제 고객 경험을 개선할 혁신적 가능성을 보여주었다.
>
> 양자 시스템이 기존 인공지능을 보완하여
>
> 더 빠른 인사이트와 나은 결과를 낼 수 있음을 입증했다.”

- - **Michelle Simmons (SQC CEO, 퀀텀 컴퓨팅 선구자)**

> “이 협력은 양자 기술이 연구실을 넘어
>
> 실제 산업 문제 해결에 적용된 매우 드문 사례다.
>
> Watermelon은 복잡한 고전적 데이터에서
>
> 숨은 관계를 찾아내며 학습 시간을 극적으로 단축시켰다.
>
> 원자 단위 정밀도와 순도를 기반으로 구축된 시스템이
>
> 실질적·상용화 가능한 솔루션으로 발전하고 있음을 보여준다.”

**의미와 전망**

|  |  |  |
| --- | --- | --- |
| **구분** | **기존 딥러닝 모델** | **SQC Watermelon 양자 리저버** |
| 학습 시간 | 수 주 | 수 일 |
| 하드웨어 | GPU 다수 필요 | CPU 기반도 가능 |
| 데이터 내성 | 낮음 (노이즈 취약) | 높음 (비선형 동역학 활용) |
| 확장성 | 제한적 | 대규모 시계열 및 분산 데이터에 적합 |
| 응용 가능 분야 | 네트워크 분석, 고객 패턴 분석 | 네트워크 예측, 자원 계획, 워크로드 관리 |

**산업적 파급효과**

- - **통신 인프라 최적화:** 실시간 대역폭 조절, 네트워크 혼잡 예측
  - **운영 비용 절감:** 전력·하드웨어 자원 사용량 대폭 감소
  - **AI+Quantum 하이브리드 모델 실증:** 호주 내 양자-산업 융합의 상징적 사례
  - **디지털 주권 강화:** Telstra와 SQC의 협력은 “호주 자체 기술 기반 양자 인프라”를 구축하는 전략적 이정표로 평가됨
