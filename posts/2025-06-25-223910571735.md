**🧬** **큐비트 물리 구현: 바륨 이온 (Ba⁺)**

Oxford Ionics는 큐비트로 바륨 이온(Ba⁺)을 채택하였다. 바륨은 전기장에 민감하게 반응하는 특성을 지녀 이온트랩에서의 정밀한 제어가 가능하며, CMOS 공정과의 높은 호환성 덕분에 상용 반도체 기술로도 구현이 가능하다. 이 이온은 수 분 이상 안정적으로 양자 정보를 유지할 수 있는 긴 코히런스 타임을 제공하며, 하이퍼파인 전이 기반의 clock qubit 구조로서 1GHz 대역에서 마이크로파 제어가 가능하다. IonQ도 동일하게 바륨이온을 큐비트로 사용하는데, 그 이유가 약간 상이하다. IonQ가 바륨을 선택한 가능 큰 이유는 통신파장(1500nm)와 호환되는 레이저로 제어가 가능해서이다.

**🧲 이온 선택 이유:** 전기장 반응성 + CMOS 호환

|  |  |
| --- | --- |
| **항목** | **설명** |
| **무게** | 가벼움 → 전기장으로의 민감도 ↑ → 정밀 제어 가능 |
| **이온 스펙트럼** | 1GHz 하이퍼파인 전이 → 마이크로파 기반 제어 가능 |
| **집적광학 호환성** | 칼슘보다 뛰어남. UV 요구하지만 산업 표준 재료와 호환 |

**⌛** **물리적 큐비트 특성**

- **코히런스 타임**: 최대 10분 (측정 장비 한계가 병목)
- **스핀 상태**: 하이퍼파인 상태 (F=0, F=1) (바륨은 F=1, F=2)
- **초정밀 시계 기술에서 사용되는 안정 상태 활용**

****

**📐 칩 아키텍처 및 제어 구조 (QCCD 기반 구조)**

칩은 전극층, 마이크로파 안테나층, 그리고 집적광학 구조로 구성된 다층 아키텍처를 갖는다. 제어 신호는 DC 전압, 마이크로파, 광신호의 세 가지로 구성되며, 이들은 각각 큐비트의 위치 제어, 논리 연산, 상태 측정/리셋 등에 사용된다. 로컬 DC 제어는 큐비트 이동에, 글로벌 마이크로파 제어는 병렬 연산에 적합하게 설계되어 전체 제어 구조가 단순하면서도 확장 가능하다.

**🏗️ 층별 구조: 전극 → 안테나 → 집적광학**

|  |  |  |
| --- | --- | --- |
| **계층** | **기술 요소** | **기능** |
| 상단 | 금속 전극 패턴 | 이온 트랩 전위 형성, 이온 이동·배열 |
| 중간 | 안테나 구조 | 마이크로파 신호 생성 → 게이트 연산 |
| 하단 | 집적 광학 | 측정 및 상태 준비용 광 경로 (자외선/가시광) 삽입 |

**🔌 제어 신호 분류: DC, 마이크로파, 광**

|  |  |  |
| --- | --- | --- |
| **신호 유형** | **파형** | **주요 기능** |
| **DC 전압** | 수백 mV | 트랩 전위 형성, 이온 위치 조정, 게이트 on/off |
| **마이크로파 (MW)** | ~1GHz | 코히런트 게이트 (1Q, 2Q) 수행 |
| **광신호** | 493nm, 650nm 등 | 이온 냉각, 상태 준비, 측정 |

**🧰 로컬 vs 글로벌 제어: 전기장 기반 이동으로 큐비트 선택**

- 모든 제어는 **전기장 기반** → 크로스토크 최소화
- **자기 안테나** 없이도 **큐비트 선택적 조정 가능**
- (위치 이동 → 공간 분리 → 선택적 제어)

> QCCD = **Quantum Charge-Coupled Device**, 이온을 칩 위에서 **이동**시키며 연산하는 방식

**🎛️ 시스템 제어 전략 (Control Fabric)**

Oxford는 연산 특성에 따라 코히런트 연산과 소산 연산을 구분하여 제어 신호를 설계한다. 코히런트 연산에는 정밀한 위상 제어가 가능한 마이크로파 신호가 활용되고, 측정/리셋 같은 소산 연산은 허용 오차가 넓은 설계를 통해 제어 자원의 효율성을 높인다. 수천 큐비트를 제어하기 위해 다중화 기술(Mux)을 활용하여 수백 개의 채널로 다수 큐비트를 관리하는 구조가 채택되었다.

****

**🎯** **제어 원칙**

- **코히런트 연산**: 오류 누적이 심각 → 엄격한 정밀 제어 필요
- **비코히런트 연산 (리셋, 측정)**: 허용 오차 ↑ → 광장으로 병렬 처리

**🌐 글로벌 제어: 마이크로파로 병렬 신호 공급**

|  |  |  |
| --- | --- | --- |
| **구분** | **예시** | **설명** |
| 글로벌 | 마이크로파 신호 | 전체 큐비트에 동일하게 인가 |
| 로컬 | 전극 전압 | 개별 큐비트 위치 이동 → 특정 큐비트만 제어 |
| **광신호** | 493nm, 650nm 등 | 이온 냉각, 상태 준비, 측정 |

**📶 다중화(Mux): 수천 큐비트를 수백 채널로 제어**

- **Multiplexing** + **샘플-홀드(S/H)** 방식
- 수천 큐비트 제어 → 수백 채널로 축소 가능
- 로그 스케일로 제어 채널 수 증가

****

**🛠️ 설계 및 제조 공정**

QPU 칩은 8, 32, 256 큐비트 단위의 유닛 셀을 반복하여 확장 가능하도록 설계되어 있다. 설계는 EDA(Electronic Design Automation-전자설계자동화) 툴과 MEMS(Micro-Electro-Mechanical Systems) 시뮬레이터를 통해 기존 반도체 산업 기술과 호환되며, 레이저나 정렬이 필요하지 않기 때문에 생산성과 일관성이 높다. DUV(Deep Ultraviolet) 공정과 일반적인 탑메탈 금속 배선 공정만으로 충분하여, 28nm 이하의 첨단 노드가 필요하지 않다.

****

**🧩** **칩 설계 철학**

- **유닛 셀 아키텍처**: 8→32→256 큐비트 → 반복 가능 구조
- **MEMS + CMOS 기반 설계**
- 모든 설계는 산업 표준 툴(EDA)로 가능
- 고전 전자 회로처럼 시뮬레이션 가능

**🧱 제조 공정 호환성: DUV, 탑메탈 공정으로 충분 (28nm 필요 없음)**

|  |  |  |
| --- | --- | --- |
| **요소** | **요구 스펙** | **의미** |
| 해상도 | 마이크로미터 수준 | EUV 공정 불필요 (28nm 이하 미사용) |
| 정렬 오차 | 수 μm 이내 | 광학적 ±10μm 허용 |
| 표면 결함 | 비민감 | 이온은 40μm 위에 떠 있음 |

**🏭** **제조 파트너: Infineon**

- **표준 재료, 공정 사용 가능**
- **트랩 이온 QPU 다수 고객 보유** → 공급망 안정성 확보

****

**⚙️ 병렬성 및 확장성**

하드웨어는 다수의 큐비트에서 병렬적으로 1큐비트 및 2큐비트 게이트를 실행할 수 있는 구조로 설계되어 있다. 단일 웨이퍼 내에서 1/4~1/8 크기 칩을 조합하여 수십만 큐비트 수준으로 확장할 수 있는 Scale-In 전략이 적용되며, 필요 시 여러 웨이퍼를 글루잉(gluing) 방식으로 물리적으로 연결해 논리적 단일 시스템으로 구성하는 Scale-Out 전략도 준비되어 있다.

**🧵** **병렬 게이트**

- 하드웨어 수준에서 게이트 **완전 병렬화 가능**
- 회로 중간 측정, 리셋까지 병렬화

**📏 Scale-In (칩내 확장): 웨이퍼 ¼–⅛ 크기 칩에 수십만 큐비트 집적**

|  |  |
| --- | --- |
| **요소** | **수치** |
| 유닛 셀 | 8~32 큐비트 반복 |
| 칩 크기 | 최대 웨이퍼 ¼–⅛ |
| 최종 목표 | 수십만 물리 큐비트 (단일 칩) |

**🧱 Scale-Out (멀티웨이 확장): 웨이퍼-웨이퍼 조립(gluing) 방식**

- **글루잉(gluing)** 방식 웨이퍼 조립
- 오차 보정 기반의 정렬 → "하나의 거대한 트랩"으로 작동

****

**🧊 냉각 및 진공**

QPU는 약 10K의 극저온에서 안정적으로 작동하며, 이는 상용 MRI 냉동기를 통해 구현 가능하다. 이는 발열에 대비한 접근이 아닌 진공상태를 유지하기 위한 냉각인것이다. 진공 환경은 외부 기계적 펌프 없이도 밀봉 재료 혹은 저온 응축 기술을 활용하여 안정적으로 유지된다. 전체 시스템은 크고 복잡한 극저온 인프라 없이도 일관된 성능을 확보할 수 있도록 설계되었다.

**🌡️ 운영 온도: 약 10K**

|  |  |
| --- | --- |
| **항목** | **값** |
| 작동 온도 | 약 10K |
| 냉각 전력 | 10만 큐비트 기준 수십 kW |
| 진공 유지 | 필수. 충돌 방지 목적 |

**🌪️** **진공 확보 방식**

- **재료 선택 + 포장 방식**
- 또는 **냉각 기반 불순물 응축**
- "햄 샌드위치 넣어도 진공 유지"

**🔋** **상용 냉각기 사용**

- **MRI 장비용 상용 냉각기 재활용 가능**
- 수주 내 납품 가능한 산업용 장비 사용

****

**🛡️ 오류 정정 및 코드 유연성**

2큐비트 연산의 충실도가 99.99% 99.97%이상으로 매우 높아, 거리 2~3 수준의 낮은 오류 정정 코드만으로도 충분한 연산 안정성을 확보할 수 있다. 알고리즘 실행 도중에도 오류 정정 코드를 실시간으로 교체할 수 있으며, 오류 디코딩은 FPGA 기반으로 수행되어 높은 유연성과 업그레이드 가능성을 제공한다. 고비용 ASIC이 필요 없어 설계와 유지 비용도 절감된다.

**🧠 충실도 기반 전략: 2Q < 10****-4** **→ 낮은 거리 코드 가능**

**🔁 실시간 코드 변경: 회로 중간에서도 알고리즘 교체 가능**

**⚡ 디코딩 경량화: FPGA 기반, ASIC 불필요**

|  |  |
| --- | --- |
| **항목** | **전략** |
| 코드 거리 | 낮은 거리 사용 가능 (충실도 높음) |
| 코드 종류 | 서피스, LDPC 등 교체 가능 |
| 실행 환경 | FPGA 기반, ASIC 불필요 |
| 실시간 변경 | 가능 (코드 스왑, 구간별 코드 다변화) |

> FPGA= **Field-Programmable Gate Array**의 약자로, **현장에서 프로그래밍 가능한 논리 소자 배열**을 의미함. 쉽게 말해, 사용자가 **원하는 방식으로 회로를 직접 구성할 수 있는 칩**

**⚡ 에너지 소비 구조**

QPU 자체는 약 100W 정도의 전력을 소비하며, 제어 회로까지 포함해도 전체 시스템은 약 1~2kW 수준의 전력으로 구동된다. 냉각 시스템까지 포함하더라도 전체 전력 소비는 수십 kW 내외로, 고성능 서버 장비와 유사한 수준이다. 이로써 데이터센터 통합이 가능할 만큼의 에너지 효율성을 확보하였다.

**🔋 QPU 전력 소비: 1만 논리 큐비트 ≈ 100W**

**🧮 제어 회로 소비: 약 1~2kW**

**❄️ 냉각 전력: 10K에서 수십 kW, 상용 장비 사용 가능**

|  |  |
| --- | --- |
| **항목** | **수치** |
| QPU 소모 전력 | 1만 논리 큐비트 ≈ 100W |
| 전체 시스템 전력 | 몇 kW (제어 포함) |
| 냉각 전력 | 수십 kW (10K 냉각 기준) |

****

**💰 단가 경제성 (Unit Economics)**

Oxford의 QPU는 비반복 엔지니어링(NRE)을 제외하고, 1만 논리 큐비트 시스템 기준으로 약 1천만 달러 이하의 단가를 목표로 한다. 생산된 장치 간 성능 편차가 거의 없으며, 공정 수율이 매우 높아 대규모 양산에 최적화되어 있다. 병렬 운용이 가능해 장비당 단위 성능당 비용을 더욱 낮출 수 있다.

****

**💸 1만 논리 큐비트 시스템: <$10M (반복적으로 발생하지 않는 초기 고정비용(NRE-Non-Recurring Engineering) 제외)**

**🏭 재현성: 장치 간 성능 차이 없음, 수율 극대화**

**🔁 병렬성 기반 생산성: 많은 장치 운용 → 비용/연산 최적화**

|  |  |
| --- | --- |
| **항목** | **수치 및 해석** |
| 1만 논리 큐비트 장치 가격 | <$10M (NRE 제외) |
| 단위 제조비 | 낮음 (표준 CMOS) |
| 설계비 | 초기 NRE만 존재, 이후 복제 가능 |
| 재현성 | 실험자 간 동일 시스템 간 성능 차이 없 |

**🧳 포터블 & 데이터센터형 시스템**

전체 시스템은 약 1㎥ 이내의 부피로 설계되어 표준 19인치 랙에 장착 가능하며, 팔레트 단위로 이동할 수 있다. 외부 환경으로부터의 진동이나 온도 변화에도 견디도록 설계되어 서버룸 환경에서 바로 운영할 수 있다. 이로 인해 양자컴퓨터를 특수시설이 아닌 일반 데이터센터에 배치할 수 있는 실질적 가능성이 열린다.

**✅ 정리: Oxford Ionics QPU 설계의 경쟁 우위**

Oxford Ionics의 QPU 설계는 기술적 정교함보다는 상용화를 위한 실용성과 경제성에 초점을 맞춘 전략으로 평가된다. 바륨 이온 기반의 마이크로파 제어는 고충실도와 산업 호환성을 동시에 만족시키며, 칩 아키텍처와 제어 구조는 병렬화와 확장성에 최적화되어 있다.

표준 CMOS 공정을 활용한 제조 방식은 낮은 단가와 높은 수율을 가능하게 하며, 유닛 셀 기반 모듈화와 웨이퍼 스케일 확장 구조는 향후 논리 큐비트 수만 개 규모로의 진화를 뒷받침한다. 냉각 시스템 역시 상용 장비로 충분히 커버 가능하고, 전체 전력 소비와 시스템 크기 또한 데이터센터 환경에서 운용하기에 적합하다.

종합적으로 볼 때, Oxford Ionics는 복잡한 정밀 광학 기반 시스템에 비해 훨씬 실용적이고 유연한 대안을 제시하며, 대규모 병렬화, 낮은 단가, 고효율 운용을 통해 양자컴퓨터의 현실적 배치 가능성을 가장 앞당긴 사례 중 하나로 꼽힌다.

|  |  |  |
| --- | --- | --- |
| **측면** | **특성** | **효과** |
| **물리 구현** | 바륨 이온, 마이크로파 제어 | 높은 충실도 + 산업 호환성 |
| **제어 아키텍처** | 로컬 전기장 + 글로벌 마이크로파 | 병렬성, 신호 단순화 |
| **제조 방식** | 산업 CMOS 활용 | 낮은 비용, 높은 수율 |
| **확장 전략** | 유닛 셀 → 웨이퍼 확장 | 단일 기술로 논리 큐비트 수만 개 가능 |
| **오류 정정** | 낮은 거리 코드, 유연성 ↑ | FPGA 기반 운영, 실시간 교체 |
| **에너지/냉각** | 저전력, 상용 냉각기 사용 | 데이터센터 통합 용이 |
| **경제성** | <$10M, 고재현성 | 병렬 운용에 최적화된 구조 |

**✅ 종합 정리: QPU 아키텍처 비교: Oxford Ionics vs IonQ**

|  |  |  |
| --- | --- | --- |
| **측면** | **Oxford Ionics** | **IonQ** |
| **큐비트 물리 구현** | 바륨 이온 (Ba⁺), clock qubit | 이터븀(Yb⁺), 최근 바륨(Ba⁺)으로 전환 중 |
| **큐비트 수** | 상용: 64 → 256 설계 중 | 상용: 35 (Forte), 29 (Aria) |
| **게이트 제어 방식** | 마이크로파 + 전기장 (on-chip) | 고정된 레이저 빔 배열 |
| **상태 측정/준비** | 집적 광학 (CMOS에 내장) | 자유공간 광학 (외부 레이저) |
| **코히런스 타임** | 수십 초 ~ 수 분 | 수 초 |
| **게이트 충실도** | 1Q: 99.9993%, 2Q: 99.97% 이상 | 1Q: 99.9%, 2Q: 98~99.5% |
| **병렬 게이트** | 완전 병렬 구조 (셀 단위 동시 제어) | 부분 병렬 (레이저 배열 한계) |
| **확장 전략** | 유닛 셀 → 웨이퍼 단일칩 확장 → 이후 글루잉 | 다중 트랩 조합 및 포토닉 인터커넥트 계획 |
| **오류 정정** | 낮은 코드 거리 가능, 실시간 코드 스왑 | 서피스 코드 실험 중 |
| **제조 파트너** | Infineon (CMOS 팹), 표준 MEMS 공정 | 자체 모듈 + 계약 업체 |
| **냉각 조건** | 약 10K, 상용 크라이오 가능 | 상온 유지, 광학 시스템 안정 필요 |
| **물리 설계 난이도** | 저온 고진공 + 고전 제어, EDA 모델링 용이 | 정렬 어려움, 대규모 배열은 공정 복잡 |
| **시스템 크기/이동성** | 랙 마운트형, 1㎥ 수준, 포터블 가능 | 랙 사이즈 시스템 (고정형) |
| **단위 경제성** | 💰 <$10M (1만 논리 큐비트 기준) | 💸 수십~수백만 달러 |
| **제품 배포 현황** | NQCC, CyberAgentur 등 고객 납품 | AWS, Azure 상용 클라우드 QPU 제공  AFRL, Quantum Basel 납품 |
| **특징 요약** | **엔지니어링 최적화 + 확장성 집중** | **레이저 기반 직관적 설계, 초기 상용화 선도** |

**🔍 종합 분석**

|  |  |  |
| --- | --- | --- |
| **비교 항목** | **Oxford Ionics** | **IonQ** |
| **확장성** | ✅ 셀-기반 모듈화, 웨이퍼 스케일 가능 | 🔄 포토닉 인터커넥트 구상 중 |

**Oxford Ionics**는 산업 호환성과 확장성을 최우선으로 고려한 설계를 통해, 상용화를 위한 실용적 양자컴퓨터 구현에 가장 근접한 기업이다. 제조 비용이 낮고 병렬성과 모듈화 설계가 뛰어나며, 데이터센터 환경과도 통합이 용이하다. 다만, 냉각 시스템이 필요하다는 점에서 초기 도입 장벽은 일부 존재한다.

**IonQ**는 양자컴퓨팅의 클라우드 상용화를 선도한 기업으로, 기술 상용화 속도가 빠르고 접근성이 뛰어나다. 하지만 레이저 정렬 기반의 광학 구조는 확장성 면에서 구조적 한계를 지니며, 병렬화나 경제성에서 Oxford 대비 상대적으로 불리하다.

하지만 최근 이 두 기업이 합병을 함으로 인해 두 기업이 지니고 있는 장점들은 더욱 부곽시키고, 단점들은 상쇄시킬 수 있는 시너지 효과가 날 수 있을 것이다. 즉, 상용화 가능성과 비용 효율성 측면에서 봤을때, IonQ의 시스템이 미래 양자 인프라 구축의 유력한 후보로 부상할 수 있다.
