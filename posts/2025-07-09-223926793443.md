마찬가지다, 수학적인 용어들이 많이 나오지만, 무시할 건 무시하는게 정신건강에 이로우니 너무 긴장하지 마시라.

**2️⃣ 얽힘 (Entanglement) — 떨어져 있어도 연결된 상태**

두 개 이상의 큐비트가 **얽힌 상태**에 있으면, 각각의 큐비트가 독립적으로 존재하지 않는다.

즉, 한 큐비트를 측정한 결과가 다른 큐비트의 상태에 **즉시 영향을 준다**.

가장 유명한 얽힘 상태 중 하나는 **벨 상태(Bell state)**이다. 여기서 벨상태란, 두 개의 큐비트가 서로 강하게 얽혀 있어서, 한 큐비트의 상태를 측정하면 다른 큐비트의 상태가 즉시 결정되는 양자 상태를 말하여, 다음과 같은 네 가지 상태로 표현된다.

이해를 돕기 위해 각 상태별 그래프를 첨부하고, 그에 맞는 게이트 이름을 부여하였으나, 게이트는 그 이후에 소개되니, 잠깐 참고 넘어가자.

**1️⃣얽힘의 전형적인 예**

- 위 수식을 해석하면 다음과 같다.

  - 큐비트 A와 B가 동시에 **0이거나 1**임.
  - 측정하기 전까지 두 상태가 **동시에 존재**.
  - 측정 시 A가 0이면 B도 0, A가 1이면 B도 1 → **완전 동기화**
  - **큐비트(빨간원)와 위상(파란원)이 동일한 것을 볼 수 있다.**

I 게이트

****

**2️⃣ 위상 반전 : 간섭 조건에 따라 다른 결과가 나올 수 있음**

- 위 수식을 해석하면 다음과 같다.

  - 역시 A와 B는 **항상 같은 값**, 하지만 **위상차 − 존재**
  - 이 위상차는 간섭 실험이나 텔레포테이션 연산에서 중요한 역할을 함
  - 지난글에서 소개한 블로흐 구면을 다시 보자. A값이 무엇이든, B는 180도 반대 위상에 위치한다.
  - 왼쪽 그림은 θ는 π/5, ϕ가 π/6일때의 모습이고, 오른쪽 그림은 위상이 반대가 되어 θ는 π/5, ϕ가 7π/6일때의 모습이다.
  - **큐비트(빨간원)은 그대로이고, 위상(파란원)만 뒤바뀐 것을 볼 수 있다.**

Z 큐비트 : 위상 반전

****

**3️⃣확률 반전 : 얽힘을 이용한 양자 암호 (QKD)에서 자주 사용됨**

- 위 수식을 해석하면 다음과 같다.

  - A가 0이면 B는 1, A가 1이면 B는 0 → **항상 반대값**
  - 상태는 대칭적이며, 한 큐비트만 보면 랜덤이지만 둘은 상관관계 있음
  - 왼쪽 그림은 θ는 π/5, ϕ가 π/6일때의 모습이고, 오른쪽 그림은 모두가 반대가 되어 θ는 4π/5, ϕ가 π/6일때의 모습이다.
  - **위상(파란원)은 그래로이고, 큐비트(빨간원)의 값만 뒤바뀐 것을 볼 수 있다.**

X 게이트 : 확률 반전

****

**4️⃣확률 / 위상 반전 : 다중 큐비트 상태 구성의 가장 기초가 됨.**

- 위 수식을 해석하면 다음과 같다.

  - 반대값 + 위상차 존재
  - 이 상태는 **페르미온 성질**을 흉내내는 경우나, **다자 간 얽힘 변형**에서 쓰임
  - 왼쪽 그림은 θ는 π/5, ϕ가 π/6일때의 모습이고, 오른쪽 그림은 모두가 반대가 되어 θ는 4π/5, ϕ가 7π/6일때의 모습이다.
  - **위상(파란원)과 큐비트(빨간원) 모두 뒤바뀐 것을 볼 수 있다.**

X ⓧ Z 게이트 : 확률 반전과 위상 반전 모두 해당

[Bloch Sphere Simulator | Quantum Visualization Tool](https://ctokx.github.io/blochsphere/) 에서 직접 값을 바꿔가며 차이를 비교하시면 이해가 더 빠르다.

**얽힘의 힘**

얽힘은 단순히 신기한 현상이 아니다. **양자 텔레포테이션**, **양자암호**, **양자네트워크** 등 다양한 양자 기술의 핵심 기반이다.

****

**✅ 대표 얽힘 생성 게이트: Mølmer–Sørensen (MS) 게이트 - IonQ가 사용하는 얽힘 게이트**

이 게이트는 이온의 **공동 진동 상태**와 \*\*내부 상태(큐비트)\*\*를 상호작용시켜 다음과 같은 얽힘을 만든다:

- X,Y: 파울리 행렬
- θ=π/4: 얽힘 최대화

MS 게이트는 **이온 여러 개를 동시에 얽히게 만들 수 있어**, 다중 큐비트 얽힘(예: **GHZ**-Greenberger–Horne–Zeilinger 상태 - 다음편에 소개) 생성에 유리하다.

****

**✅ 이온트랩에서 얽힘을 만드는 원리**

이온트랩에서는 얽힘을 만들기 위해 \*\*이온들 간의 공통 진동 모드(motional mode)\*\*를 활용한다.

모든 이온은 전기장 내에서 일정한 집단 진동을 하고 있으며, 이를 통해 큐비트 간 상호작용을 유도한다.

주요 단계:

**(1) 큐비트 초기화**

- 모든 이온을 레이저로 ∣0⟩ 상태로 초기화

**(2) 중첩 생성**

- Hadamard 게이트(H)를 통해 첫 번째 이온을 중첩 상태로 만듦:

**(3) 양자 논리 게이트 실행**

- 특정 진동 모드(예: center-of-mass 모드)를 공통 채널로 사용하여,
- CNOT 또는 Mølmer–Sørensen 게이트로 얽힘 생성:

이 과정에서 이온 간 거리, 진동 주파수, 레이저 위상 등이 정밀하게 조절되어야 한다.

**✅ 벨상태를 게이트의 조합으로 풀이**

자 그럼 위에서 살펴본 4개의 벨상태를 위 과정으로 풀어보자. 그전에 추가 설명을 하고 가겠다.

****

**📚텐서곱(ⓧ) 연산**

텐셔곱이란, 큐비트 연산을 정의할때, 첫번째는 첫번째끼리, 두번째는 두번째끼리 적용하는 것을 의미한다.

예시

(H⊗I)∣01⟩ 는 첫번째 큐비트(0)에 아다마르 게이트(H)를, 두번째 큐비트(1)에 항등게이트(I)를 적용하라는 의미다.

****

**1️⃣얽힘의 전형적인 예**

**2️⃣ 위상 반전 : 간섭 조건에 따라 다른 결과가 나올 수 있음**

위의 1️⃣과정후에 위상반전을 위한 Z게이트를 추가(과정3)한 것과 같다.

**3️⃣확률 반전 : 얽힘을 이용한 양자 암호 (QKD)에서 자주 사용됨**

위의 1️⃣과정후에 위상반전을 위한 X게이트를 추가(과정3)한 것과 같다.

**4️⃣확률 / 위상 반전 : 다중 큐비트 상태 구성의 가장 기초가 됨.**

이전 3개의 상태와는 달리, 두번째 큐비트에 X게이트를 적용해 확률 반전을 한 후 H게이트, CNOT게이트를 각각 적용후, 마지막에 위상반전용 Z게이트를 적용한다.

****

**3️⃣ 양자 게이트 (Quantum Gate) — 큐비트에 연산을 가하는 장치**

고전 컴퓨터에서 AND, OR, NOT 같은 게이트가 존재하듯, 양자컴퓨터에도 다양한 연산 게이트가 존재한다.

양자 게이트는 **큐비트의 상태를 회전시키거나 얽힘을 생성**하는 연산이다.

****

**✅ 단일 큐비트 게이트**

양자컴퓨터에 적용되는 여러 단일 큐비트를 아래에 정리했다.

위에서도 수식에 행렬이 나와서 당황했겠지만, 생각보다 어렵지 않다.

행과 열을 순서대로 곱하면 답이 나오는 간단한 원리를 아래 3가지 게이트를 예를 들어 보았으니 쉽게 이해할 수 있을 것이다. 나머지 게이트에 대한 내용도 마찬가지다.

|  |  |  |  |
| --- | --- | --- | --- |
| **게이트** | **기호** | **행렬 표현** | **기능 설명** |
| **Pauli-I** | I |  | 동일 값 출력  게이트 타이밍 맞추는 목적 |
| **Pauli-X** | X |  | 0과 1의 확률 반전 |
| **Pauli-Y** | Y |  | Y축 기준 회전 |
| **Pauli-Z** | Z |  | 위상 반전 |
| **Hadamard** | H |  | 중첩 생성 |
| **Phase (S)** | S |  | 위상 90° 회전 |
| **T 게이트** | T |  | 위상 45° 회전 |
| **Rx(θ)** | - |  | X축 기준 회전 |
| **Ry(θ)** | - |  | Y축 기준 회전 |
| **Rz(θ)** | - |  | Z축 기준 회전 |

- Pauli -X, Y, Z는 **파울리의 배타원리**를 정의한 물리학자 볼프강 파울리의 이름을 딴 것이다.
- Y,Z,S,T 게이트

  - 특정 축을 기준으로 회전하거나 위상을 변환시켜 큐비트 간 간섭 효과를 유도하여 원하는 결과 확률을 높이거나 낮춘다.
  - 위상 플립, 비트 플립 오류를 감지 및 수정하는 데 필수적으로 사용 - 특히 QEC에 반드시 필요함.

**✅ 이중 큐비트 게이트**

|  |  |  |  |
| --- | --- | --- | --- |
| **게이트** | **기호** | **행렬 표현** | **기능 설명** |
| **CNOT** | CX |  | 타깃 큐비트 반전  얽힘 유도 / 논리 연산 |
| **CZ** | CZ |  | 타깃 큐비트 위상 반전  얽힘 유도 / 논리 연산 |
| **SWAP** | SWAP |  | 큐비트 재배치, 회로 최적화 |
| **iSWAP** | iSWAP |  | 얽힘 생성, 특정 물리적 구현에서 사용 |

이러한 게이트들을 조합하면 **양자 알고리즘의 모든 연산을 구성**할 수 있다.

**✅** **이 모든 게 어떻게 연결될까?**

1. **초기화**: 큐비트를 ∣0⟩ 상태로 설정
2. **중첩 생성**: Hadamard 게이트 등으로 여러 상태의 중첩 생성
3. **얽힘 유도**: CNOT 등으로 큐비트 간 얽힘 생성
4. **계산 수행**: 다양한 양자 게이트로 알고리즘 구현
5. **측정**: 결과를 고전적인 0 또는 1로 얻음

****
