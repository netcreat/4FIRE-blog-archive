**✅양자 컴퓨팅 제조사**

**1️⃣ Trapped Ion (이온 트랩 기반)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **IonQ** | Ba⁺ 이온 체인, 레이저 게이트 + QCCD 아키텍처(Tempo/AQ 시리즈) — 최고 충실도(99.97 %) 레벨 선도 |
| **Quantinuum** | Honeywell Ion Trap H 시리즈 + QCCD (Helios/H2 기반); 엔터프라이즈 보안 및 QEC 리더 |
| **Oxford Quantum Circuits (OQC)** ❌ | (*혼동 주의: 이름 비슷하지만 이온 아님*) → 아래 슈퍼컨덕팅 참조 |

- - **특징 요약:** 고정밀 게이트·높은 충실도 강점 / 확장성은 물리적 한계(체인 길이) 존재.

**2️⃣ Neutral Atom (중성원자 기반)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **QuEra** | 하버드·MIT 스핀오프, **Rydberg 상호작용 256 큐비트 Aquila QPU**, AWS Braket 상시 제공 |
| **Pasqal** | 프랑스 INRIA·Institut d’Optique 스핀오프, 산업용 Orion QPU, CUDA-Q 통합 |
| **Atom Computing** | Sr 원자 3D 격자, >1000 물리 큐비트, MS 공동 상용기 개발 |
| **Infleqtion (ColdQuanta)** | Rb/Cs 원자 Sqale 플랫폼 + 센싱 · RF · 타이밍 통합형 멀티모달 하드웨어 |
| **Anyon Computing** | 중국계 연구 스핀오프, Rydberg 상태 통제 연구 중심(상용 단계 이전) |

- - **특징 요약:** 확장성·2D 배열 강점 / 레이저 정렬·게이트 정밀도 도전.

**3️⃣ Superconducting Qubits (초전도체 기반)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **Oxford Quantum Circuits (OQC)** | 3D Superconducting Loop “Coaxmon” 아키텍처 — 영국 상용 클라우드 서비스 제공 |
| **Rigetti Computing** | Transmon 칩, Aspen · Ankaa 시리즈, QCS 클라우드 서비스 보유 |
| **IQM Quantum Computers** | 핀란드 출신 Transmon 집적칩, 유럽 국가별 양자 센터 납품 (핀란드·스페인 등) |
| **SEEQC** | Digital-SFQ 방식 초전도 로직 + Cryo ASIC 통합형 “Hybrid Classical/Quantum” 칩 |
| **Quantum Circuits Inc. (QCI)** | Yale 스핀오프, Transmon 기반 **gmon** · **modular cavity bus** 기술 연구 |
| **Diraq** ❌ | (*실리콘 기반 이므로 아래로 이동*) |

- - **특징 요약:** 제조 표준화 성숙 / 냉동 복잡·배선 확장 도전.

**4️⃣ Semiconductor / Spin Qubits (실리콘 · 반도체 스핀 기반)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **Diraq (Australia)** | Si/SiGe 양자점 스핀 큐비트, UNSW 기반, CMOS 공정 호환 특허 강세 |
| **Silicon Quantum Computing (SQC)** | Michelle Simmons 교수 팀 (UNSW), 단일 원자 정밀 제어 기술 · 10 큐비트 시연 |
| **Quantum Motion (UCL · Oxford)** | CMOS 공정 활용 스핀 큐비트 집적화 플랫폼, Cryo 제어 칩 연구 |

- - **특징 요약:** 실리콘 반도체 공정 재활용 가능 / 양자점 잡음 · 온도 안정성 이슈.냉동 복잡

**5️⃣ Photonic (광자 기반)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **ORCA Computing** | 다중 파장 광자 메모리 · QKD · 하이브리드 HPC 연동 — Amazon · MoD 납품 |
| **Quandela** | 프랑스 기반 단일 광자 소스 · 인터페로미터 칩, “Perceval” 클라우드 QPU 운영 |
| **Alice & Bob** | Cat State (Schrodinger 고양이형) 광자/초전도 하이브리드 코드 — 자체 오류보정 논리 큐비트 상용화 진행 |

- - **특징 요약:** 상온 동작 · 네트워킹 친화적 / 광자 손실 · 에러율 관리 복잡.

**6️⃣ Control / Middleware (양자제어 및 운영 플랫폼)**

|  |  |
| --- | --- |
| **기업** | **주요 특징** |
| **Quantum Machines (QM)** | FPGA 기반 **OPX+ 컨트롤러** · 양자 운영체제(QOS) 플랫폼 제공 — 모든 하드웨어 타입 지원 |

- - **특징 요약:** 하드웨어 중립 제어 · 컴파일 플랫폼 리더.

**🧩** **정리**

- - 중성원자 계열은 확장성·광자 통합성이 탁월하고, 이온 트랩은 정밀도·충실도에서 선도적이다.
  - 초전도 및 실리콘 스핀 계열은 반도체 공정 기반으로 산업화 속도가 빠르며, 광자 기반은 네트워크 통신 통합에서 두각을 나타내고 있다.
  - Quantum Machines는 이 다양한 하드웨어 계열을 연결하는 제어 운영 플랫폼 핵심 공급자 역할을 한다.

**✅제어 시스템 개발사**

**1️⃣ Keysight Technologies**

- - **본사:** 미국 캘리포니아주 Santa Rosa
  - **성격:** 글로벌 테스트·측정 장비 대기업 (전 Agilent Technologies에서 분사, 2014)
  - **주력 사업**

|  |  |
| --- | --- |
| **구분** | **설명** |
| **전자 계측 장비(Test & Measurement)** | 오실로스코프, 신호발생기, 스펙트럼 분석기, 네트워크 분석기, 전원 공급 장치 등 |
| **통신·반도체·자동차·항공 방위산업용 계측 솔루션** | 5G/6G, 위성통신, 전력전자, RF 칩 테스트 |
| **양자컴퓨팅 제어 시스템 (Quantum Control Systems)** | 2019년 **SpinQ, Rigetti, IQM, Zurich Instruments** 등과 협력 시작. 이후 자사 **PXIe 모듈 기반 Arbitrary Waveform Generator (AWG)** 와 **신호분석기**를 이용한 **양자 큐비트 제어/측정 플랫폼** 제공 |
| **Quantum Control System QCS** | Keysight QCS는 FPGA 기반으로, QPU 제어 및 실시간 피드백 기능을 지원. Labber Software(실험 오케스트레이션 툴)와 통합. |

- - **특징**

    - **범용성** : 초전도, 트랩드이온, 스핀, 중성원자 등 다양한 플랫폼에 맞춘 오픈 구조.
    - **규모의 경제** : 일반 산업 계측 장비와 부품 공유 → 가격/유지보수 우위.
    - **통합 SW 생태계** : PathWave, Labber로 연구소–산업 간 연결.

**2️⃣ Qblox (네덜란드, 델프트 기반)**

- - **본사:** Delft, Netherlands
  - **기원:** TU Delft 및 QuTech 스핀오프 (2018 설립)
  - **주력 사업**

|  |  |
| --- | --- |
| **구분** | **설명** |
| **모듈형 양자 제어 하드웨어** | **Cluster** 시리즈 (AWG + RF 신호발생 + 디지털 I/O 통합) – FPGA 기반 저지연 시스템 |
| **Quantum Stack Integration** | Cryogenic QPU → Room-temperature controller → Classical computer까지 연결하는 ‘End-to-End Control Stack’ 제공 |
| **사용 분야** | 초전도, 스핀, 트랩드이온 등 다양한 연구소·산업 QPU 벤더 대상 |

- - **특징**

    - **저지연( <100 ns )** : FPGA 기반 하드웨어 시퀀서로 빠른 게이트/피드백.
    - **고집적 모듈 구조** : 19-inch 랙에 AWG·Readout·Mixer 기능 통합.
    - **소프트웨어 플랫폼 QBlox API / QLab** : Python 기반 실험제어 SDK.
    - **대표 고객** : IQM (Finland), Rigetti (Europe), Oxford Ionics (연구협력), QuTech 내 Quantum Internet Testbed.
  - **시장 포지션**

    - **“유럽형 Quantum Machines”** : 제어-계측 전용 기업 중 연구기관 밀착도 최고.
    - NVQLink 생태계에도 참여.

**3️⃣ Qubic Technologies (영국)**

- - **본사:** 옥스퍼드( Oxford ), 영국
  - **기원:** Oxford Instruments 및 University of Oxford 연구진 출신 ( 2020 설립 )
  - **주력 사업**

|  |  |
| --- | --- |
| **구분** | **설명** |
| **Cryogenic & Quantum Control Electronics** | 초전도 큐비트 및 스핀 큐비트용 저온 제어 전자기기 개발 |
| **Qubit Readout Electronics** | GHz 대역 readout chain ( LNA, Mixer, ADC/DAC ) 최적화 |
| **통합 Cryo-Control Rack** | 냉동기 ↔ 제어기 ↔ QPU 연결 전체 솔루션 |
| **고객군** | Oxford Ionics, Rigetti UK, National Quantum Computing Centre (NQCC) 등 |

- - **특징**

    - **Cryogenic integration** : 저온 전자부와 상온 제어부를 직결, 케이블 길이 및 노이즈 감소.
    - **Superconducting QPU 전문화** : 초전도 큐비트 플랫폼용 전자 계측 특화.
    - **NQCC 공급사** : 영국 국가 양자컴퓨팅 센터 내 컨트롤 시스템 공급.

**4️⃣ Zurich Instruments (스위스)**

- - **본사:** Zurich, Switzerland
  - **성격:** 정밀 계측 및 양자 제어 장비 전문 기업 (2008 설립)
  - **주력 사업**

|  |  |
| --- | --- |
| **구분** | **설명** |
| **Lock-in Amplifiers & Impedance Analyzers** | 초정밀 신호 측정 장비 (기존 아날로그 계측 사업 루트) |
| **Quantum Computing Control System (HDAWG / UHFQA / SHFSG / SHFQA / PQSC)** | 완전한 QPU 제어-측정 플랫폼. 각 모듈이 waveform generation, readout, sequencer 기능 담당 |
| **QCCS (Quantum Computing Control System)** | 다중 큐비트 실험을 제어하는 통합 시스템, Quantum Orchestration Level 제공 |
| **주요 고객** | ETH Zurich, IBM Zurich, Google Quantum AI (Europe labs 협력 가능성), Oxford Ionics 테스트 베드. |

- - **특징**

    - **모듈형 통합성 극대화** : AWG, DAQ, Sequencer, Trigger 등 모두 동기화.
    - **QCoDeS 및 LabOne 소프트웨어 연동** : Python 기반 제어 프레임워크.
    - **경쟁사** : Quantum Machines (OPX), Qblox (Cluster).

5️⃣**Quantum Machines**

- - **본사:** 이스라엘 텔아비브 (Tel Aviv)
  - **성격:** 양자 컴퓨팅 제어 시스템 전문 기업 (2018년 설립, 하드웨어 + 소프트웨어 통합형 플랫폼 제공)
  - **주력 사업**

|  |  |
| --- | --- |
| **구분** | **설명** |
| **양자 제어 하드웨어 (OPX / OPX+)** | FPGA 기반의 모듈형 양자 제어기. 큐비트 게이트 파형 합성, 측정, 디코딩, 피드백을 μs 단위로 실시간 처리. 초전도·트랩드이온·스핀 등 다양한 플랫폼 지원. |
| **소프트웨어 플랫폼 (Quantum Orchestration Platform)** | 제어기(OPX) 위에서 실험 시퀀스, 측정 결과 분석, 실시간 피드백 루프를 통합 관리하는 오케스트레이션 환경. Python API 기반으로 기존 실험 스택과 연동. |
| **Quantum Machine Language (QM QUA)** | 큐비트 제어를 위한 고수준 프로그래밍 언어. 조건문·루프·피드백 연산 등을 FPGA 레벨로 직접 컴파일하여 나노초 단위 응답 가능. |
| **GPU 연동 및 NVQLink 통합** | NVIDIA CUDA-Q 및 NVQLink 생태계와 통합 중. GPU와 FPGA 간 μs 결정성 피드백 루프를 지원하며, RTH(Real-Time Host) 모듈 탑재. |
| **Quantum Cloud Control (QCC)** | 원격 실험실·클라우드 환경에서 QPU 제어 테스트 가능한 API 서비스. 양자 하드웨어 벤더와의 통합 테스트 인프라 제공. |

- - **특징**

    - **결정성 실시간 제어:** FPGA 및 RTH 엔진을 통해 나노초~μs 수준의 하드리얼타임 루프 구현.
    - **하드웨어 + 소프트웨어 완전 통합형 플랫폼:** 제어 장치(OPX+) 와 오케스트레이션 SW (QOP/QUA)가 단일 스택으로 작동.
    - **플랫폼 범용성:** 초전도, 이온트랩, 스핀, 중성원자 등 모든 주요 큐비트 기반 지원.
    - **NVQLink 하드웨어 파트너:** NVIDIA 공식 생태계 에서 GPU–QPU 하드웨어 루프 를 시연한 유일한 제어 시스템 기업.

      - 5개 제어 시스템 개발사 중 유일하게 2023년부터 공동 협력하여 GPU 통합을 완성했음
      - GPU ↔ OPX+ ↔ QPU
    - **글로벌 채택:** Quantinuum, IQM, QuEra, Rigetti 등 주요 QPU 벤더에 제어 플랫폼 공급.

> **RTH가 중요한 이유**
>
> GPU는 **수천 개 병렬 쓰레드**로 동작하지만, 타이밍 제어 정밀도는 **마이크로초 단위** 이상이다.
>
> FPGA는 **나노초 수준 타이밍 제어**가 가능하지만, 복잡한 연산은 어렵다.
>
> ➡ 그래서 그 사이에 RTH가 있어야 두 쪽의 타이밍·데이터 throughput을 맞춰줄 수 있다.
>
> 즉, RTH는 GPU와 FPGA 간 **결정성(Deterministic)** 피드백 루프를 보장하는 하드웨어 중계기

> **FPGA+RTH+GPU 구조가 필수인가?**
>
> **양자 오류정정(QEC)** 은 μs-level 피드백 루프가 없으면 불가능하다.
>
> →GPU에서 디코딩한 결과를 즉시 큐비트에 재적용해야 하므로, CPU / OS 경로를 통하면 지연 > 10³ 배.
>
> **AI 보정 및 ML-adaptive 게이팅** 도 GPU-QPU 양방향 피드백이 필요.
>
> **NVQLink 로드맵** 자체가 “FPGA ↔ GPU 결정성 DMA 링크”를 표준화하려는 목적.
>
> 즉, QPU 벤더가 어떤 플랫폼을 쓰든
>
> ➡ **Control System 벤더는 이 루프를 하드웨어로 완성하지 못하면 양자 하드웨어 공급망에서 탈락**한다.

**✅정리**

- - 현재 양자컴퓨팅 산업의 무게중심은 단순한 QPU(양자 프로세서) 성능 경쟁에서 벗어나, **제어·동기화·연산 간 실시간 통합**을 구현하는 쪽으로 이동하고 있다.
  - 이 과정에서 **제어 시스템(Control System)** 은 더 이상 주변 장치가 아니라, **양자 시스템의 두뇌이자 신경망**으로 기능하게 된다.
  - 이 글에서 살펴본 다섯 개발사는 각기 다른 기술 전통을 기반으로 이 새로운 패러다임을 향해 수렴하고 있다.
  - 그중에서도 **Quantum Machines** 가 GPU–FPGA–QPU를 하나의 결정성 피드백 루프로 묶어낸 첫 사례이며,
  - **Keysight + Zurich Instruments** 연합은 산업 표준화와 대규모 제조 역량을 결합한 가장 강력한 상업적 축을 형성하고 있다.
  - 결국 향후 경쟁의 핵심은 “누가 GPU-QPU 피드백을 하드웨어 수준에서 완성해, 실시간 오류정정(QEC)과 AI-보정 제어를 동시에 구동시킬 수 있는가” 에 달려 있다.
  - 이 능력을 확보한 기업이 차세대 양자 생태계의 표준을 주도하게 될 것이며, 현재 그 중심에 서 있는 기업이 바로 **Keysight Technologies** 와 **Quantum Machines** 다.
