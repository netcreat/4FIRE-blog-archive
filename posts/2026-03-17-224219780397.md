# Soverign Compute와 Quantum Computing

---

**✅ 테슬라는 왜 파운드리 ‘공장’을 만들려고 하는가**

- - 최근 Tesla가 ‘Terafab’이라는 개념을 준비하고 있다는 이야기가 계속 나오고 있다.
  - 겉으로 보면 단순하다. “자기들이 쓸 칩을 직접 만들겠다”
  - 하지만 이걸 조금만 다르게 보면 완전히 다른 질문이 등장한다.
  - 과거 제조업은:

    - 부품을 사서
    - 조립해서
    - 제품을 만들었다
  - 그런데 지금 테슬라는:

    - **칩을 설계하고**
    - **그 생산 구조까지 통제하려고 한다**
  - 이건 단순한 비용 절감이나 효율 개선이 아니다.

    - **“컴퓨팅을 누가 통제하는가”라는 문제다**
  - 그리고 이 흐름은 테슬라 하나의 이야기가 아니다.

    - AI → GPU 부족
    - 반도체 → 공급망 병목
    - 국가 → 기술 자립 경쟁
  - 이 모든 것이 하나의 방향으로 수렴한다:

    - **“앞으로는 칩을 잘 만드는 것보다 칩을 확보하고 통제하는 것이 더 중요해진다”**
  - 이제 이 질문을 Quantum으로 확장해보자.

    - **IonQ의 SkyWater 인수는 이 흐름을 훨씬 더 극단적으로 보여주는 사례다**

> ***NVIDIA tax***
>
> ***삼성, SK, NVIDIA - 깐부 회동***
>
> *이 모두가 GPU나 Memory 수급을 통제하지 못해서 벌어진 해프닝이다.*
>
> **

**✅ 반도체 부족은 끝난 문제가 아니다**

- - 많은 사람들이 반도체 부족을 과거의 사건으로 생각한다.
  - 하지만 현실은 다르다.

**📌 수요는 구조적으로 폭발하고 있다**

- - AI 모델 증가
  - 데이터센터 경쟁
  - 국가 단위 투자
  - 👉 수요는 계속 증가한다

**📌 공급은 구조적으로 제한되어 있다**

- - EUV 장비 → 극소수
  - advanced node → 소수 기업
  - HBM → 제한된 공급
  - 👉 공급은 빠르게 늘릴 수 없다

**📌 지정학이 개입했다**

- - 공급망 분리
  - 국가 간 경쟁
  - export control
  - 👉 결론은 명확하다:

> ***칩 부족은 이벤트가 아니라 구조다***

**✅ 하드웨어 산업의 핵심: Iteration**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMTdfMjIy/MDAxNzczNzMxMjA1MTM0.izn0GEilYITF-hckH8u_JdSwx5nFjD3Wime1Hi75yiIg.UjS5YLVyFNxzE_EfYOuQFvbReBWzgqt6oCjM9qvN0twg.PNG/image.png?type=w800)](#)

**📌 Tape-out**

- - 👉 설계를 생산으로 넘기는 순간
  - 설계 = 도면 그리기
  - tape-out = **“이대로 만들어 주세요” 하고 공장에 넘기는 것**

**📌 실제 과정**

1. 1. 칩 설계 (logic, layout)
   2. 검증 (simulation)
   3. 최종 파일 생성 (GDSII)
   4. 👉 **fab에 전달 → tape-out**
   5. 웨이퍼 생산 시작

**📌 Iteration**

1. 1. Tape-out A → 칩 생산
   2. 테스트 → 문제 발견
   3. 수정
   4. Tape-out B
   5. 다시 테스트
   - 👉 이걸 계속 반복

**📌 현실**

- - 한 번 반복 = 수개월
  - 👉 그래서:

**📌 Tape-out A, B, C, D 의미**

- - IonQ 얘기랑 연결하면:

    - A → 첫 시도 (버그 많음)
    - B → 수정
    - C → 성능 개선
    - D → 거의 완성 단계
