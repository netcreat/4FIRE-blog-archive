출처 : D-Wave 홈페이지

양자 어닐링(Quantum Annealing)은 **특정 종류의 최적화 문제를 빠르게 풀기 위해 설계된 양자 계산 방식**이다. 반면, 우리가 흔히 말하는 게이트 기반 양자 컴퓨터(Gate-based quantum computer)는 **범용 양자 계산**을 목표로 한다. 이 둘은 **철학, 작동 방식, 응용 분야** 모두에서 상당히 다르다. 아래에서 구조적으로 비교 설명하겠다.

**🧠 개념 비교**

|  |  |  |
| --- | --- | --- |
| **구분** | **양자 어닐링 (Quantum Annealing)** | **게이트 기반 양자 컴퓨터 (Gate-based QC)** |
| **목표** | 최적화 문제의 최소값/최대값 탐색 | 범용 양자 알고리즘 수행 |
| **철학적 기반** | **아다바틱** **분변적 양자 계산** (Adiabatic Quantum Computing) | 양자 회로 모델 (Quantum Circuit Model) |
| **주요 원리** | **양자 터널링**을 활용한 에너지 최소화 | 양자 게이트 조작을 통한 알고리즘 수행 |
| **사용자 제어** | 초기 **해밀토니안 설정**만 하면 자동으로 진화 | 게이트 시퀀스를 직접 설계해야 함 |

> **adiabatic이란,**
>
> **“분변(分變)” - 서서히 변화 또는 조심스럽게 변한다는 의미다. 즉 시스템을 천천히 변화시켜서, 원래의 상태를 유지하는 방식을 의미함.**

**⚙️ 작동 방식 비교**

**✅ 양자 어닐링**

- 시스템은 처음에 간단한 양자 상태(기초 해밀토니안)에서 시작한다.
- 시간이 지남에 따라 점점 문제의 해밀토니안(Hₚ)으로 변환된다.
- **아다바틱** **분변적** **정리**에 따르면, 변화가 충분히 느리면 시스템은 항상 최저 에너지 상태(Ground state)에 남는다.
- 이 최저 에너지 상태가 곧 **최적 해답**이다.

****

**✅ 게이트 기반 양자 컴퓨터**

- 큐비트를 초기화하고, 양자 게이트(U1, U2, …)를 순차적으로 적용하여 양자 회로를 구성한다.
- 중간에 중첩(Superposition), 얽힘(Entanglement)을 활용해 계산이 전개된다.
- 마지막으로 측정(Measurement)을 통해 결과를 얻는다.
- 다양한 알고리즘 실행 가능: Shor(소인수분해), Grover(탐색), VQE(화학 시뮬레이션) 등.

****

**🧭 비유로 이해하기**

- **양자 어닐링**: 골짜기 지형 위에서 구슬이 가장 낮은 지점을 찾아가는 과정 (전체 지형 = 문제)
- **게이트 기반 QC**: 미세 조작 로봇 팔로 정해진 순서에 따라 부품을 조립하는 공정 (논리 회로 = 알고리즘)

**🎯 개념 정리**

**🔹1. 해밀토니안(Hamiltonian) – 양자 시스템의 ‘에너지 지도’**

**📌 정의**

해밀토니안은 **양자 시스템의 에너지 상태를 수학적으로 표현하는 연산자**이다.

즉, "이 시스템의 에너지 구조가 어떻게 생겼는지", 그리고 "각 상태의 에너지가 얼마인지"를 알려준다.

양자역학에서는 이 해밀토니안을 사용해서 다음을 예측한다.

- 어떤 상태가 가장 안정적인가? (Ground state)
- 시간이 지나면 어떻게 진화할까?
- 측정하면 어떤 확률로 결과가 나올까?

> **수학적으로는 H (Hamiltonian) 연산자라고 쓰고, 이걸 시스템의 상태 |ψ⟩에 적용하면 에너지를 얻는다.**
>
> **H |ψ⟩ = E |ψ⟩ → 해밀토니안이 |ψ⟩라는 양자 상태에 작용하면, 그 상태의 에너지 E를 알려준다.**

**📌 직관적 비유**

- 해밀토니안은 **지형도**이다.
- 양자 시스템은 **공**이고, 그 지형 위에서 가장 낮은 곳(= 최소 에너지 상태, **Ground State**)으로 굴러간다.
- 우리가 원하는 **최적의 해답**이 바로 그 낮은 곳에 숨겨져 있다.

****

**📌 왜 중요하냐면?**

- **해밀토니안을 알면 그 양자 시스템의 모든 물리적 행동을 예측할 수 있다.**
- 양자 컴퓨터는 이 해밀토니안을 직접 구현해서:

  - 문제를 **에너지 형태로 변환**하고
  - **최저 에너지를 자동으로 찾아주는 방식**으로 계산한다 (양자 어닐링에서).

**📌 예: 최적화 문제 맵핑**

- 어떤 조합 최적화 문제를 해밀토니안으로 바꾸면, 가능한 해마다 서로 다른 에너지를 갖게 다.
- 이 중 가장 에너지가 낮은 상태가 **정답**이 된다.

예를 들어, 다음 같은 문제를 해밀토니안으로 바꾸면,

“3개의 스위치를 껐을 때 비용이 최소가 되게 하라”

여기서 H가 해밀토니안이다. 양자 어닐링 시스템에서는 이 수식을 에너지 함수로 이해하고, 최소 에너지를 갖는 z1, z2, z3 조합을 자동으로 찾아낸다.

이것은 0과 1 또는 +1과 -1으 ㅣ값을 가지는 변수들 간의 조합 최적화 함수이다.

수학적으로는 이산 최적화 (duiscrete optimization) 문제이고, 변수의 양이 많을 경우, 고전적인 방법으로 풀면 경우의 수가 너무 많아 NP(Nondeterministic Polynomial)-난해 문제에 속하게 되는데, 이것을 양자컴퓨터로 풀면 훨씬 쉽게 풀 수 있다.

해밀토니안 기반 양자 어닐링은 여러 변수가 동시에 얽혀 있는 상황에서 최적 또는 최소값을 찾는 과정이다. 이를 수학적으로 보면, **고차원 에너지 함수의 전역 최소값(global minimum)**을 찾는 문제와 동일하다. 방식은 약간 다르지만, 전에 소개했었던 편미분과 동일한 개념이다.

**🔹2.** **아다바틱** **분변적 (Adiabatic) – 느리게 변화를 주면 상태가 따라온다**

**📌 정의**

아다바틱 분변적 정리(Adiabatic Theorem)는 다음을 말한다:

> “양자 시스템이 어떤 해밀토니안의 최저 에너지 상태에 있을 때, 그 해밀토니안이 **천천히** 변하면, 시스템은 항상 새로운 해밀토니안의 최저 에너지 상태로 따라간다.”
>
> **대신 연산 속도가 느리다는 단점이 있다.**

**📌 작동 원리**

1. 시스템을 **쉽고 에너지가 명확한 초기 해밀토니안**의 Ground State에 넣는다.
2. 천천히 우리가 풀고 싶은 문제를 나타내는 해밀토니안으로 **스무스하게 변형**시킨다.
3. 그러면 시스템은 **계속 Ground State**를 유지하게 되고, 마지막엔 **문제의 해답**이 된다.

**📌 비유**

- 놀이기구의 레일(= 해밀토니안)을 천천히 바꾸면, 공은 항상 레일을 따라가서 **가장 낮은 위치**에 머무다.
- 레일을 너무 빨리 바꾸면 튕겨나가거나 중간에 멈춰요. → 해답을 못 찾게 됨.

****

**📌****예를 통한 요약**

|  |  |  |
| --- | --- | --- |
| **개념** | **설명** | **비유** |
| **해밀토니안** | 양자 시스템의 에너지 상태를 나타내는 수학적 표현 | 지형도, 레일 구조 |
| **Ground State** | 가장 낮은 에너지의 상태 | 계곡 바닥, 공이 굴러 멈춘 지점 |
| **분변적 정리** | 해밀토니안을 느리게 바꾸면 시스템이 항상 최저 에너지 상태에 남는다 | 천천히 기울어지는 레일을 따라 움직이는 공 |

**🎯 양자 어닐링에서의 활용**

- 시작: H₀ (쉬운 문제) → Ground State로 세팅
- 천천히 변화: H₀ → H₁ (실제 문제 해밀토니안)
- 끝: H₁의 Ground State를 측정 = **문제의 해답**

****

**🔷 3. QUBO란?**

QUBO (Quadratic Unconstrained Binary Optimization)는 "제약 없는 2차 이진 최적화 문제"를 말한다.

이름을 하나씩 뜯어보면 더 잘 이해된다:

|  |  |
| --- | --- |
| **용어** | **의미** |
| **Quadratic** | 항이 **2차까지** 포함됨 (예: xi,xixj) |
| **Unconstrained** | **제약 조건이 없음** (하지만 페널티로 넣어서 간접 처리) |
| **Binary** | 각 변수는 **0 또는 1**의 값을 가짐 |
| **Optimization** | 어떤 함수를 **최소화 또는 최대화**하려는 문제 |

**📌 수식 형태**

QUBO 문제는 다음과 같은 수학적 표현을 가진다:

- xi∈{0,1}: 이진 변수
- Qi,j: 주어진 가중치 (문제의 정보가 들어있음)
- 최적화 목표: Q(x)를 가장 작게 만드는 x의 조합을 찾기

****

**📌 왜 QUBO를 쓰는가?**

D-Wave와 같은 **양자 어닐링기**는 문제를 해밀토니안 형태로 바꿔서 풀어야 한다.

QUBO는 이 해밀토니안과 **형태가 거의 동일**해서 바로 사용 가능:

즉,

- QUBO = **문제를 이진 2차 함수로 만든 버전**
- 양자 어닐링 = **이 QUBO를 물리적으로 해밀토니안으로 바꿔 에너지를 최소화하는 장치**
- **수학적 최적화 문제 표현에서 양자 장치에서 구현 가능한 물리 모델로 변환하는 과정이 필요함.**

> **참고 : 단백질 접힘을 소개할 때 등장했던 HUBO는 QUBO보다 상위 개념이다.**
>
> **QUBO는 2차항까지 포함하는 함수인데 반해 HUBO는 3차 이상 항을 포함한다.**
>
> **따라서, 고차 논리식이 필요한 문제인 경우에는 QUBO만 지원하는 어닐링 방식에서는 이론적으로 가능하긴 하지만 복잡도가 매우 증가하여 게이트 방식에서 HUBO를 구현한다.**

****

**🔷 4. 양자 터널링이란?**

고전 알고리즘은 에너지 지형에서 **로컬 미니멈**에 갇히기 쉽지만, 양자 어닐링은 **양자 터널링**을 통해 다음과 같은 일이 가능:

- 좁은 에너지 장벽을 **뚫고 지나감**
- 더 낮은 **글로벌 최소값**으로 빠르게 이동

---

**⚛️ 그런데 양자 어닐링은 어떻게 푸나?**

**양자 터널링과 에너지 최소화로 직접 최소점을 찾아간다.**

**🔹 과정 요약**

1. 문제 설정 → QUBO 또는 Ising 모델로 변환
2. QUBO → 해밀토니안으로 변환
3. 모든 해 (x1,x2,...,xn)의 조합을 **동시에 중첩 상태로 설정**
4. 시간에 따라 해밀토니안을 천천히 변화 (**아다바틱****분변적으로**)
5. 양자 터널링으로 로컬 최소값을 뛰어넘음
6. 최종 상태 측정

즉,

- **모든 경우를 한 번에 고려하고**
- **양자 물리의 성질을 활용해서**
- 에너지가 가장 낮은 조합(=최적해)을 선택하는 방식이다.

****

| 탐색 방식 | 편미분 → 기울기 탐색 | 해밀토니안 변화 + 양자 터널링 |
| 수학적 도구 | 미분, 라그랑주 승수법 등 | 양자역학, 아다바틱 분변적 정리 |
| 병렬성 | 없음 → 순차 탐색 | 있음 → 중첩과 터널링 활용 |

**📌 목표:**

> N개의 도시가 주어졌을 때, 모든 도시를 **한 번씩 방문하고 다시 출발 도시로 돌아오는** 경로 중
>
> **총 이동 거리가 가장 짧은 경로를 구하라**

**✅ Step 1: 이진 변수 정의**

우리는 각 도시에 어떤 순서로 방문하는지를 나타내는 이진 변수를 정의한다.

- 도시 수: N
- xi,t: 도시 i를 시간 t에 방문하면 1, 아니면 0

예: 도시가 4개일 때

- x2,3=1 → 도시는 2번, 시간은 3번째 순서에 방문

총 변수 수: N×N

**✅ Step 2: 제약 조건을 수식화**

TSP는 두 가지 제약 조건이 반드시 필요다:

1. 시간마다 도시 하나만 방문

2. 도시는 한 번만 방문

우리는 이 제약 조건들을 위반하면 패널티가 큰 값을 주는 방식으로 QUBO에 포함시킨다.

**✅ Step 3: 목적 함수 = 이동 거리 최소화**

도시 간 거리 행렬이 Di,j라고 하면,

**✅ Step 4: QUBO 구성**

QUBO는 다음과 같이 구성된다:

Q(x)=A⋅(제약 조건 항)+B⋅(총 이동 거리 항)

- A: 제약 위반 시 큰 패널티를 주는 계수
- B: 실제로 줄이고 싶은 이동 거리 항

실제로는 이걸 2차 항 xixj의 합으로 정리한다 → D-Wave나 양자 어닐링기가 직접 처리 가능

**✅ Step 5: QUBO → 해밀토니안**

이 때:

- 각 xi는 큐비트와 1:1 매핑된다.
- D-Wave 등은 이 해밀토니안을 실제 장치에 구현해서,
- 가장 낮은 에너지를 갖는 큐비트 조합 = 최단 경로를 자동으로 찾아낸다.

**📌 큐비트 개수 차이가 큰 이유는?**

**🔹 어닐링 큐비트: 수천 개 가능**

D-Wave의 큐비트는 "정밀 제어용 논리 연산"이 아니라 "스핀 계의 상호작용을 모사"하기 위한 아날로그 장치에 가깝다.

- 게이트 없음 → 게이트 정확도 요구도 없음
- 단순한 제어 (bias, coupling) → 수천 개까지 스케일업 가능
- 다만, 연결성(connectivity)은 제한적 → Chimera, Pegasus topology 등

**→ 그래서 물리 큐비트 수는 많지만, 연산 능력은 한정적임**

****

**🔹 게이트 기반 큐비트: 소수지만 정밀도 매우 중요**

IBM, Google 등의 게이트형 QC는 양자 알고리즘 실행을 위한 정밀 제어가 필요하다.

- 단일 큐비트 게이트, 이큐비트 게이트 모두 매우 높은 정밀도(>99.9%) 요구
- 양자 오류 보정(QEC)을 하기 위해선 수백개의 물리 큐비트로 논리 큐비트 1개 구현 필요
- 현재는 오류 정정 없이 소규모 알고리즘을 테스트하는 NISQ (Noisy Intermediate-Scale Quantum) 시대

**→ 큐비트 수는 적지만, 범용성과 정밀도를 목표로 함**

**📡 게이트 기반 양자 컴퓨터에서는 어닐링으로 풀 수 있는 최적화 문제를 풀 수 있나?**

게이트 기반 양자 컴퓨터에서 변분법을 사용하는 알고리즘으로는 대표적으로 VQE와 QAOA가 있다. 자세한 사항은 아래 알고리즘편을 참고바람.

> **여기서 변분(變分)은 앞서 말한 분변(分變)과는 다르다.**
>
> **분변(分變,Adiabatic)****은 천천히 변화한다는 의미로써, 퀀텀 어닐링이 여기에 해당 되지만,**
>
> **변분(變分, Variational)****은 변하는 함수들 중 최적값을 찾는 방법론을 의미하고, VQE, QAOA가 여기에 해당된다.**
>
> **참고로 BF-DCQO는** **비분변(非分變, Non-Adiabatic)****, 즉 어닐링과는 반대로 빠르게 게이트를 적용하고 파라미터 조정을 반복한다.**
>
> **QAOA는 변분(變分, Variational)적인 알고리즘이면서, 형식상 어닐링 구조를 일부 계승했지만 빠른 게이트 조합으로 진행하기 때문에 본질적으로 비분변(非分變, Non-Adiabatic)적이다.**

**🔶 QAOA vs VQE vs 어닐링**

- VQE는 고전 + 양자 하이브리드 방식의 최적화를 사용하는 방식

  - 보통 화학 Hamiltonian을 쪼개서 Pauli 항으로 나눠 측정
- QAOA는 양자 어닐링을 게이트 기반으로 디지털화한 알고리즘이다.

  - 이론적으로는 어닐링에서 풀 수 있는 문제를 게이트 기반 양자 컴퓨터에서 가능
- 양자 어닐링 구조는 양자 시스템이 직접 최소 에너지 상태로 수렴하는 방식

  - 게이트와 회로가 없고 단일 진화(아다바틱 분변적)
- 이론적으로 QAOA가 양자 어닐링을 대체할 수 있지만, 현실적으로는 아직 완전한 대체는 어렵고, 각각의 강점과 제약이 달라서 "부분 대체 + 병존"이 더 현실적인 시나리오다.
