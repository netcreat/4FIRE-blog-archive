# Microsoft 양자컴퓨터 로드맵(2023년)

Published: 2025-09-02T23:27:42.359000+09:00

Original Naver post: https://blog.naver.com/4-fire/223993018803

---

결론부터 말하자면 2023년에 6단계 마일스톤을 발표하면서 1단계 달성이라고 했는데, 2025년 현재 2단계 달성한 상태다.

**✅****토폴로지컬 큐비트 기반 양자 슈퍼컴퓨터 로드맵**

**💡****6단계 마일스톤**

|  |  |  |  |
| --- | --- | --- | --- |
| **단계** | **목표** | **달성 상태** | **특징** |
| **1** | 마요라나 제로 모드(MZM) 생성 및 제어 | ✅ 달성 | 토폴로지컬 위상 실험 검증 |
| **2** | **하드웨어 보호 큐비트** 구현 | ✅ 달성 | 자체 오류 억제 능력 내장 |
| **3** | 고품질 하드웨어 보호 큐비트 | 예정 | 브레이딩 기반 안정성 향상 |
| **4** | **멀티 큐비트 QPU** | 예정 | 병렬 양자 알고리즘 실행 가능 |
| **5** | **Resilient QPU** (Level 2) | 예정 | 논리 큐비트 기반 안정적 연산 |
| **6** | **Quantum Supercomputer** (Level 3) | 장기 목표 | ≥1M rQOPS, 실질적 양자 우월성 달성 |

**✅****하드웨어 보호 큐비트(Hardware-Protected Qubit) 특징**

Microsoft는 기존 트랜스몬(transmon), 스핀(spin), 게이트몬(gatemon) 큐비트 대신 **마요라나 기반 토폴로지컬 큐비트**를 개발한다.

|  |  |
| --- | --- |
| **항목** | **목표 성능** |
| **크기** | ≤ 10 µm → 100만 큐비트를 신용카드 크기 칩에 집적 |
| **속도** | 연산 시간 ≤ 1µs → 문제 해결 속도 수십~수백 배 향상 |
| **제어** | 디지털 전압 펄스 기반 → 대규모 QPU 제어 가능 |
| **안정성** | Topological Gap Protocol(TGP) 검증 완료 |
| **확장성** | 웨이퍼 스케일 집적 → 단일 모듈 QPU 가능 |

**✅****rQOPS (reliable Quantum Operations Per Second)**

**💡****정의**

- - Q: 신뢰할 수 있는 **논리 큐비트 수**
  - f: 논리 클록 속도(Hz)
  - pL: 논리 오류율
  - rQOPS는 **규모(Scale)**, **속도(Speed)**, 신뢰성(Reliability)을 통합한 성능 지표다.

**💡****rQOPS 목표**

|  |  |  |  |
| --- | --- | --- | --- |
| **문제 범위** | **rQOPS 목표** | **논리 오류율 pL** | **의미** |
| **단순 재료 시뮬레이션** | 1M | ≤ 10⁻¹² | 상관된 전자 시스템 모델링 가능 |
| **복잡한 화학/재료 문제** | 1B | ≤ 10⁻¹⁸ | 신소재·신약 탐색 가속 |

- - 현재 모든 QPU는 **rQOPS = 0**,
  - Level 2에서 최초의 rQOPS > 0을 달성,
  - Level 3에서 **≥ 1M rQOPS** 달성이 목표다.
