**✅ 투자 관점 분석**

**📌 기술 로드맵**

- - AI 인프라 로드맵은 4개의 축이 같이 움직인다.

    - **Compute → Memory → Interconnect → Optics/Power**
  - 이를 시간축으로 깔면 아래처럼 된다:

    - 2023–2025 → Compute Dominant
    - 2025–2027 → Memory + Interconnect Dominant
    - 2027–2030 → Optics + CXL Fabric + Power Dominant
    - 2030+ → Silicon Photonics + Disaggregation Full Adoption
  - **이것을 조금 더 세분화 하면**

    - HBM → CXL → NVLink → Ethernet Fabric → Optical → Photonics
  - **여기서 기업 가치가 생기는 지점은 3개:**

    - 성능 병목 발생 시점
    - 표준 전환 시점
    - 생태계 락인 시점

|  |  |  |  |
| --- | --- | --- | --- |
| **기업** | **병목** | **표준** | **락인** |
| NVIDIA | Compute | NVLink/IB | CUDA |
| Broadcom | Networking | Ethernet | Switching |
| Marvell | SerDes/DPU | Ethernet/CXL | 고객 설계 |
| Astera | I/O/CXL | PCIe/CXL | Design-in |

**✅ 각 기업의 투자 관점 (Bull Case)**

**📌 NVIDIA — “AI 인덱스” + “플랫폼 독점”**

- - **Bull Thesis:**

    - GPU는 AI Compute에서 사실상 **독점적 위치**
    - NVLink/NVSwitch + IB/Spectrum 패브릭으로 **분산학습 전체 구간 장악**
    - CUDA/NCCL/DOCA/NIM 등 **소프트웨어 Moat**
    - Hyperscaler/국가/지자체/기업/국방 등 **고객 다변화**
    - Blackwell → Rubin → 이후 포토닉스 세대까지 로드맵 명확
  - **투자 관점 핵심:**

    - NVIDIA는 더 이상 “GPU 회사”가 아니라 **AI 데이터센터 플랫폼**
  - NVIDIA는 사실상 **AI GDP에 대한 패시브 인덱스** 역할.

**📌 Broadcom — “AI Networking Fabric Cash Machine”**

- - **Bull Thesis:**

    - AI 클러스터의 70~80%가 **Ethernet**으로 대체되는 중
    - Tomahawk/Jericho는 사실상 **Hyperscaler 표준**
    - 51.2T → 102.4T 스위치 전환(= 800G/1.6T Optics TAP)
    - 224G SerDes 수요 급증
    - CPO/Linear Drive Optics 전환으로 경쟁 우위
    - AI 채택으로 **DCF 형태의 반복 매출 구조** 형성
  - Broadcom의 장점:

    - 성장 + 수익성 + 배당 + FCF + M&A 능력 + 고객 잠금
  - AI 수혜주 중 드물게 **안정/방어적**인 구조.

**📌 Marvell — “DPU + SerDes + Storage + Mixed Exposure”**

- - **Bull Thesis:**

    - Hyperscaler 상대로 **OCTEON DPU** 채택 확대
    - 112G → 224G → 448G SerDes 전환기 수혜
    - 스토리지/통신/클라우드에 **동시에 레버리지**
    - Innovium 인수로 스위치 ASIC 재진입
    - AI + Telco + Cloud CAPEX 모두 수혜
  - NVIDIA와 Broadcom의 사이에 놓인 중간 레버리지 베타

**📌 Astera Labs — “CXL + PCIe Retimer + Smart Cable + Memory Expansion Pure-Play”**

- - **Bull Thesis:**

    - CXL 2.0/3.0가 2026~2030에 **데이터센터 표준**이 될 시나리오
    - GPU 외부 메모리 풀링, NVMe Pooling, JBOG 시장 개방
    - PCIe 6.0/CXL 3.0 PAM4에서 SI 문제가 폭발 → **리타이머 필수화**
    - Smart Cable Module로 **랙-랙 GPU 확장 수혜**
    - Hyperscaler 초기 채택 시작
    - 경쟁자 적고 완전 니치 + 높은 진입장벽
  - “메모리/인터커넥트 병목에 대한 퓨어 레버리지 플레이”

**✅ 각 기업의 투자 관점 (Bear Case)**

**📌 NVIDIA Risk**

- - 고객이 Hyperscaler 중심 → **Bargaining Power Risk**
  - ONNX 등 **표준화 리스크**
  - Open AI 자체 HW 가능성
  - 국방/규제 리스크
  - 정신나간 CapEx 사이클 역전 위험
  - 하지만 Moat이 너무 강해서 근본 Bear가 힘듦.

**📌 Broadcom Risk**

- - Ethernet vs IB 경쟁에서 패할 경우 (현재 가능성 낮음)
  - Hyperscaler Verticalization 리스크
  - CPO 타이밍 실패 시 전환 비용 증가

**📌 Marvell Risk**

- - OCTEON 성장이 Hyperscaler에 너무 좌우됨
  - Innovium integration 불확실성
  - 경쟁: NVIDIA BlueField, AMD Pensando

**📌 Astera Labs Risk (꽤 중요함)**

- - CXL 도입 타이밍
  - CXL이 CPU/Game-changer가 될지 여부
  - Retimer 시장의 Timing + ASP 하락 위험
  - PSR 30~40x 밸류 → **멀티플 압축 리스크**
  - Hyperscaler에서 디자인아웃 리스크
  - CXL이 GPU 패키지 내부로 통합되는 경우
  - Astera의 Bear Case는 아주 명확함:

    - “만약 CXL 도입이 늦어지거나, NVIDIA/AMD/Intel이 자체 Fabric 내부 메모리 확장을 우선시하면?”
    - PSR은 40x에서 15~20x로 압축될 수 있음.

**📌 시나리오 트리 (중요)**

  - **시나리오 2 — AI 수요는 유지 + 모델 크기 계속 증가 (Bull)**

    - → Interconnect 병목 폭발
    - → Broadcom/Marvell/Astera의 성장률이 NVIDIA보다 높아질 수 있음
  - **시나리오 3 — 모델 크기 감소 + Algorithm efficiency 증가**

    - → NVIDIA는 영향 적음 (여전히 Compute 필요)
    - → Networking계는 다소 조정 → Astera는 가장 타격
  - **시나리오 4 — Hyperscaler Vertical Integration**

    - → NVIDIA/Broadcom 모두 잠금
    - → 중간 벤더(DPU, Retimer)는 리스크 증가

**📌 Moat 분석**

|  |  |

  - 즉 투자자는:

    - **“Moat vs 레버리지 vs 타이밍”을 동시에 봐야 함**

**✅ M&A 가능성 분석**

**📌 왜 AI 인프라 시장에서 M&A가 중요한가?**

- - AI 인프라 시장은 결국 **두 가지 방향**으로 움직임:

    1. **Compute 중심 수직화**
    2. **Fabric/Memory 중심 해체(disaggregation)**
  - 둘 다 아이러니하게 **M&A를 촉발**한다.
  - 왜냐면:

    - Compute는 **엔드투엔드 통합**(ex: NVIDIA)
    - Fabric/Memory는 **칩렛/광/패키지 분해**
  - 가 필요하기 때문.
  - 즉 지금 시장은 “**GPU는 붙이고, GPU 밖은 떼는**” 구조로 감
  - 이게 M&A를 부르는 핵심 이유.

**📌 Astera Labs – 누가 데려가기 좋은가?**

1. 1. **Broadcom이 Astera를 인수하는 그림**

      - 장점:

        - 기존 PLX + 스위치 + SerDes + Optics + CXL까지 “데이터센터 IO 풀스택” 완성.
        - Hyperscaler향으로 “Broadcom만 붙이면 연결 레이어 올인원” 제안 가능.
      - 단점:

        - 가격: Astera가 이미 비싸서 프리미엄 얹으면 딜 가격이 매우 큼.
      - **확률: 60~70%**
   2. **Marvell이 인수**

      - 장점:

        - DPU + SerDes + CXL + Retimer 조합으로 “CPU ~ GPU ~ 메모리 ~ 스토리지” 전 구간 시너지.
      - 단점:

        - 재무 사이즈/레버리지, 통합 난이도.
      - **확률: 45~50%**
   3. **CPU 벤더(AMD/Intel)가 인수**

      - 장점:

        - 자신들의 CXL 생태계에 강제 편입.
        - EPYC/Xeon 플랫폼 차별화.
      - 단점:

        - Astera의 강점이 다양한 플랫폼에 파는 “중립 벤더”라는 점인데, 특정 CPU 진영으로 들어가면 매력이 감소할 수도 있음.
      - **확률: 30~35%**
   4. **NVIDIA 인수**

      - 가능성은 낮지만, 그림은 깔끔함:

        - GPU→CXL→HBM/DDR 풀까지 “메모리 패브릭” 완성.

          - 메모리 패브릭이 CUDA처럼 락인될 가능성 큼
        - 다만 NVIDIA는 보통 자신이 가장 직접적으로 쓰는 핵심(네트워크, DPU, 소프트웨어)을 우선 인수해왔고,
        - CXL은 **CPU진영 중심 표준**에 가깝기 때문에 바로 삼키진 않을 가능성이 큼.
      - 확률: **20~25% 정도**

> ***Astera는 M&A Exit 가능성 매우 높음***
>
> ***전략적으로 가장 어울리는 쪽은 Broadcom·Marvell·CPU벤더(AMD/Intel).***
>
> *다만 지금 밸류(PSR 30~40x)를 감안하면,*
>
> *“상대가 많이 급할 때”나 “AI/CXL 패닉 국면”에나 나올법한 딜.*

**📌 Marvell, Broadcom, NVIDIA – 서로 간 M&A 가능성**

- - NVIDIA ↔ Broadcom:

    - 규제 + 규모 + 직접 경쟁 관계 → **사실상 딜 불가급.**
  - Broadcom ↔ Marvell:

    - 이론상 시너지는 크지만, 역시 규제 리스크 + 시장 독점 우려.
  - 현실적인 그림은:

    - 이 세 회사가 서로를 사는 것보다,
    - **Astera / Credo / Alphawave / Coherent optics 스타트업**들을 각자 골라 가져가는 “조각 모으기” 형태에 가깝다.

    - **AI 제국의 중심부.**
