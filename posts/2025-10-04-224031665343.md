# Fortune Future 50 (2025)

[Fortune Future 50 | 2025 | Fortune](https://fortune.com/ranking/future-50/2025/)

Fortune Future 50은 포춘지가 보스턴 컨설팅 그룹의 데이터를 기반으로 발표하는 미래성장 동력이 돋보이는 50개 기업 리스트이다.

참고로 2023년과 2024년 리스트를 살펴보면, 아래와 같다.

|  |  |  |
| --- | --- | --- |
| **순위** | **2023년** | **2024년** |
| 1 | **Snowflake** | Atlassian |
| 2 | Datadog | Roblox |
| 3 | CrowdStrike Holdings | Monday.com |
| 4 | Roblox | **HubSpot** |
| 5 | Li Auto | OpenAI |
| 6 | Cloudflare | SambaNova Systems |
| 7 | BILL Holdings | Klaviyo |
| 8 | ZoomInfo Technologies | Rippling People Center |
| 9 | DoorDash | **Snowflake** |
| 10 | EVE Energy | Blueprint Medicines |

**💡****비교 및 변화 요약**

- - 몇 가지 눈에 띄는 변화들이 있다.

    - **Snowflake**는 2023년 1위 → 2024년 9위로 후퇴 → 2025년 다시 1위 복귀
    - **Roblox**는 2023년 4위 → 2024년 2위로 올라갔고 → 2025년 상위 10위 안에서는 보이지 않음
    - **HubSpot**은 2024년 4위로 강세 → 2025년 상위 10위 안 유지 (6위)
    - 2025년 상위권에는 **Databricks, Celonis, DataRobot, Astera Labs, Samsara, IonQ, Wayve, Netskope** 등 2023~2024년에는 없거나 낮은 순위였던 기업들이 새롭게 부상
    - 반대로, 2023년 상위권이었던 **Datadog, CrowdStrike, Li Auto, Cloudflare, BILL, ZoomInfo, DoorDash, EVE Energy** 등은 2025년 상위 10위에서는 보이지 않음
    - 2024년 상위권이었던 **Atlassian, Monday.com, OpenAI, SambaNova, Klaviyo, Rippling, Blueprint Medicines** 등도 2025년 1~10위권에는 없음
  - 이런 변화는 기술 트렌드 변화, 기업의 성장 궤도, 시장 환경 등이 반영된 것으로 보이고, 특히 **AI / 데이터 / 클라우드 / 혁신 플랫폼** 쪽 기업들이 2025년 리스트에서 강한 모습을 보인다고 볼 수 있다.

**💡****계속 순위권에 등장한 기업들 (지속 진입 기업 사례)**

- - 다음 기업들은 최소 2023년 리스트에 포함되었고, 2025년에도 리스트에 등장한 것으로 보이는 회사들이다.

    - **Snowflake**

      - 2023년 1위로 등장함
      - 2025년 이미지 기준 1위에도 있음
    - **HubSpot**

      - 2025년 상위권에 있고, 2024년 리스트에서도 이름 보임 (2024년 4위)

**✅****Snowflake**

**💡****개요 / 핵심 정보**

- - **회사명**: Snowflake Inc.
  - **설립 / 본사**: 2012년에 설립됨. 본사는 미국 몬태나주 보즈먼(Bozeman, Montana) 쪽을 중심으로 함.
  - **사업 영역 / 제품**:

    - 클라우드 기반의 데이터웨어하우스 및 데이터 플랫폼 제공
    - 여러 클라우드 인프라 환경(AWS, Azure, GCP 등) 위에서 동작 가능
    - 데이터 저장, 분석, 공유 기능, 그리고 AI/앱 구축 지원 기능 등을 포함한 솔루션 제공
  - **고객 기반 / 규모**:

    - 수천 개의 조직들이 Snowflake를 사용 중임
    - 2024년 기준으로 10,000개 이상의 고객사 보유 (e.g. Forbes Global 2000 기업 포함)
    - 매일 수십억 건 이상의 쿼리 처리됨
  - **비즈니스 특징 / 강점**:

    - 서버리스, 관리형( fully managed ) 플랫폼 모델을 채택 → 인프라 관리 부담을 줄임
    - 확장성, 동시성 처리 능력, 낮은 지연(latency) 등이 경쟁력 요소
    - AI 또는 데이터 응용 프로그램 개발을 지원하는 기능 점점 강화하는 방향으로 진화 중임
  - **최근 동향 / 과제**:

    - AI와의 연계 강화: Anthropic 등 AI업체와의 협업 추진 보도 있음
    - 실적 호조 및 가이던스 상향 조정 사례 있음
    - 다만 경쟁 심화, 오픈소스 대체 기술 위협 등이 도전 과제로 거론됨

**💡재무 현황 및 경쟁사**

- - 재무현황

    - 2025 회계연도 4분기 기준 실적 발표에서, 분기 매출은 **986.8 백만 달러**로 전년 대비 약 27 % 증가함.
    - 제품 수익(product revenue)은 약 **943.3 백만 달러**로, 전년 대비 약 28 % 증가한 수치임.
    - 다만 영업비용 증가 등으로 아직 수익성은 완전히 확보한 상태는 아님. 일부 분석에서는 상당한 적자 구조가 지속되고 있다고 분석됨.
    - 재무 건전성 측면에서는 현금 보유 여력, 무부채 상태 등이 언급되며, 혁신 및 투자를 지속할 수 있는 여지는 있음.
  - **수익 구조 특징 / 비즈니스 모델 요인**

    - 소비 기반 요금 모델 (usage-based pricing) 체계를 사용 — 고객이 사용하는 저장량, 컴퓨팅 자원, 데이터 처리를 기준으로 요금을 매김
    - 스토리지(storage) + 컴퓨팅(compute) + 데이터 전송/서비스 기능 등이 제품 수익의 주요 구성 요소
    - 플랫폼 확장: 데이터 공유, 애플리케이션 개발 기능, AI/ML 워크로드 지원 등이 추가 수익원으로 점점 강화되는 추세
    - 멀티 클라우드 지원 (AWS, Azure, GCP 등) 구조 덕분에 고객 유연성을 제공함
  - 경쟁사

    - **AWS (Amazon Redshift, AWS Glue, AWS Athena 등 통합 데이터·분석 서비스)**
    - **Microsoft Azure (Synapse Analytics 등)**
    - **Google Cloud (BigQuery 등)**
    - **Databricks** — 데이터 분석, 머신러닝/AI 플랫폼 경쟁자로 자주 언급됨.
    - **오픈소스 / 데이터 레이크하우스 솔루션** (예: Apache Iceberg, Delta Lake 통합 솔루션 등)
    - **Snowflake와 유사한 다른 클라우드 데이터 플랫폼 제공업체들**

**✅****HubSpot**

**💡****개요 / 핵심 정보**

- - **회사명**: HubSpot, Inc.
  - **설립 / 본사**: 2006년에 MIT 졸업생들이 창업함 (Brian Halligan, Dharmesh Shah)
  - **사업 영역 / 제품**:

    - CRM (고객 관계 관리) 플랫폼 중심으로, 마케팅 허브, 세일즈 허브, 서비스 허브, 콘텐츠 관리, 운영/데이터 관리 허브 등 통합 SaaS 제품군 제공
    - 인바운드 마케팅(Inbound Marketing) 개념을 중심 전략으로 삼음
  - **고객 기반 / 규모**:

    - 전 세계 여러 규모의 기업들이 사용 중임
    - 직원 수 수천 명급이며, 연 매출 규모도 크게 성장 중임
  - **비즈니스 특징 / 강점**:

    - 사용자 친화적 UI/UX와 통합된 마케팅·영업·서비스 워크플로우 제공
    - 다양한 타 시스템(예: 이메일, 광고 플랫폼, 기타 CRM 등)과 연계 가능한 확장성
    - 무료 CRM 버전 등 저진입 장벽 정책을 통해 소규모 기업에도 확산 전략
  - **최근 동향 / 과제**:

    - 2023년 이후 AI 기능 강화 움직임 있음 (HubSpot AI 런칭 등)
    - Google(Alphabet)의 인수 가능성 보도도 있었음 → 이후 인수 포기 보도까지 있었음
    - 경쟁이 치열한 CRM / 마케팅 자동화 시장에서 지속적인 기능 혁신과 고객 유지가 중요

**💡재무 현황 및 경쟁사**

- - 재무 현황

    - 허브스폿은 주요 수익원이 **구독(subscription) 수익** 쪽이 매우 크고, 기타 전문 서비스 및 부가 서비스도 일부 수익을 차지함
    - 최근 보고된 분기 기준으로 구독 수익이 증가 추세이며, 회사의 현금 / 유동성 상태도 괜찮다는 분석이 있음. 예: GuruFocus 보고에서는 구독 수익이 $603.8M → $698.7M으로 증가했다는 언급 있음.
    - 다만 순이익은 적자를 보인 경우가 있고, 경쟁과 투자 확대 등이 비용 부담 요인으로 작용함.
    - 강한 현금 흐름(operating cash flow) 구조를 가졌다는 평가가 있음. 예를 들어 허브스폿의 운영 현금 흐름이 안정적이라는 보고가 있음.
  - **수익 구조 특징 / 비즈니스 모델 요인**

    - Freemium 또는 무료 CRM 기본 제공 → 이후 유료 허브 (마케팅, 영업, 서비스, CMS 등) 확장 모델을 통해 업그레이드 유도
    - 통합 허브 (Marketing Hub, Sales Hub, Service Hub 등) 제품군을 묶어서 제공 → 플랫폼 확장 / 크로스셀 가능성
    - 타 시스템 연동 및 확장 (API, 마켓플레이스, 연계성) 강화
    - 점점 AI 기능, 자동화 기능, 워크플로우 최적화 기능 등을 제품 차별화 요소로 추가 중
  - 경쟁사

    - **Salesforce** — CRM & Sales/Service 플랫폼 분야에서 강력한 경쟁자
    - **Adobe (Marketo, Adobe Experience Cloud 등)** — 마케팅 자동화 및 통합 솔루션 경쟁
    - **Microsoft Dynamics 365** — CRM + ERP + 통합 비즈니스 앱 포트폴리오
    - **Oracle (Oracle CX / Oracle Marketing Cloud 등)**
    - **Zoho CRM, Pipedrive, ActiveCampaign 등 SMB 중심 CRM / 마케팅 자동화 솔루션**
    - 또, Google 등의 대형 플랫폼이 CRM/마케팅 영역으로 확대할 가능성도 잠재적 경쟁 위협으로 여겨짐

**💡****Astera Labs**

- - **개요 / 배경**

    - Astera Labs는 반도체 / 하드웨어 계열 회사로, 특히 AI/ML 인프라나 데이터 집약적 시스템에서의 연결성(connectivity) 문제를 해결하는 기술을 개발하는 회사.
    - 본사는 캘리포니아주 산타클라라에 있고, 2017년 설립됨.
  - **사업 모델 / 제품 / 특징**

    - **메모리 / 연결성 플랫폼 (Connectivity solutions)** 제공: 예를 들어 “Leo Memory Connectivity Platform”, “Aries Smart Retimers (PCIe)”, “Taurus Ethernet Smart Cable Modules” 등이 제품 포트폴리오임.
    - 데이터 인프라의 병목 해결에 초점: 대용량 데이터 처리가 필요한 AI / ML 시스템에서 메모리 접근, 전송 지연(latency), 신호 무결성(signal integrity) 등을 개선하는 하드웨어 솔루션
    - 개방형 표준 기반 솔루션 강조: 특정 벤더 종속성을 줄이는 방향으로 설계됨.
  - **시장 / 기회**

    - AI 및 ML 인프라 투자 확대 → 고성능 연결성 / 메모리 대역폭 수요 증가
    - 데이터센터, 고성능 컴퓨팅(HPC), 클라우드 인프라 등 다양한 응용처 존재
    - 하드웨어 계층에서의 혁신은 상대적으로 진입 장벽이 높지만, 성공 시 오래 지속 가능한 경쟁 우위 가능

**💡****Samsara**

- - **개요 / 배경**

    - Samsara는 IoT(사물인터넷) + 텔레매틱스 기반의 운영 플랫폼 회사
    - 2015년에 설립되었고, 샌프란시스코에 본사를 둠.
  - **사업 모델 / 제품 / 특징**

    - **Connected Operations Platform**: 차량, 장비, 센서, 비디오, GPS, 기타 IoT 데이터 등을 통합해 운영 현황을 실시간으로 모니터링 / 분석
    - **플랫폼 + 앱 마켓플레이스**: 사용자는 솔루션을 필요에 따라 앱 형태로 추가 가능
    - 주요 적용 분야:운송 (fleet), 건설, 물류, 제조, 공공 부문 등
    - 하드웨어 + 소프트웨어 결합 모델: 센서 기기, 카메라, 게이트웨이 등 하드웨어 구성요소와 클라우드 플랫폼이 같이 작동
  - **시장 / 재무 동향 / 특징**

    - 2023년 기준 연간 반복 매출(ARR)이 $1B를 돌파했다는 발표 있음.
    - 2024년 매출 약 $937M, 순손실 약 $287M 기록했다는 독일 위키백과 자료 있음.
    - 고객사 확장 및 국제 진출 지속
    - 산업 현장의 디지털 전환 추세가 Samsara 제품의 수요 증가 요인

**💡****Netskope**

- - **개요 / 배경**

    - Netskope는 클라우드 보안 회사야. “클라우드 스마트 / 데이터 중심 보안 플랫폼”을 표방함.
    - 2012년에 설립되었고, 캘리포니아주에 본사를 두고 있음.
  - **사업 모델 / 제품 / 특징**

    - **Netskope One**: 통합 보안 플랫폼으로, 클라우드, 웹, 개인 어플리케이션까지 포괄하는 보안 제공
    - **서비스 보안 경계(Security Service Edge, SSE)** 및 **클라우드 접근 보안 중개자(CASB, Cloud Access Security Broker)** 기능 제공
    - 주요 기술 요소: 데이터 손실 방지(DLP), 위협 탐지 및 대응, 제로 트러스트(Zero Trust) 보안, 마이크로 세그멘테이션 등
    - - **NewEdge (보안 전용 사설 클라우드 인프라)** 도 제품군에 포함됨.
  - **시장 / 동향 / IPO 등**

    - 많은 기업들이 클라우드 전환하면서 보안 수요 급증 → Netskope의 시장 기회 확대됨
    - 경쟁사로는 Zscaler, Cato Networks, Cradlepoint 등이 언급됨.
    - 최근 IPO 진행 보도 있음 (2025년 기준) — 9억 달러 규모 조달 뉴스가 보도됨.
