> Rydberg는 스웨덴의 물리학자인 요하네스 로베르트 뤼드베리(Johannes Robert Rydberg)에서 유래되었으며, 영어식으로는 리드버그로 읽는다.

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/9/9d/Rydberg%2C_Janne_%28foto_Per_Bagge%3B_AFs_Arkiv%29.jpg/250px-Rydberg%2C_Janne_%28foto_Per_Bagge%3B_AFs_Arkiv%29.jpg)](#)

출처 : 위키피디아, 요하네스 뤼드베리

**✅리드버그 — 중성원자를 계산기로 바꾸는 순간**

**💡** **왜 중성원자는 그냥 두면 서로 간섭하지 않는가**

- - 지금까지의 상태를 다시 떠올려보자.

    - 원자들은 광학 집게 위에 안정적으로 앉아 있고
    - 각 원자는 0과 1, 혹은 그 중첩 상태를 가질 수 있다
  - 하지만 여기까지는 아직 **각각의 독립적인 큐비트**일 뿐, 서로 아무 일도 하지 않는다.
  - 이건 중성원자의 장점이자 한계다.

    - 장점: 잡음이 적고 조용하다
    - 한계: 그냥 두면 **아무 계산도 일어나지 않는다**
  - 양자컴퓨터가 되려면 큐비트들 사이에 **의도적인 상호작용**이 필요하다.
  - 중성원자 기반에서는 이 역할을 맡는 것이 바로 **리드버그 상태**다.

**💡****리드버그 상태란 무엇인가**

- - 리드버그 상태는 원자의 전자가 **아주 높은 에너지 준위로 들뜬 상태**다.
  - 이 상태에서 전자는 평소보다 훨씬 멀리 퍼진다.

    - **양자컴퓨터용 광학 집게는 보통 4~6 μm 전후**
    - **전자 구름 크기: 수십~수백 nm**

      - **이로 인한 강력한 전기장이 생겨서 수 μm 밖에 있는 이웃 원자의 에너지 준위를 밀어낼 수 있다.**

[![](https://www.researchgate.net/publication/308994604/figure/fig1/AS%3A1132502005616679%401647020927868/a-Two-Rydberg-atoms-in-different-electronic-states-and-with-spatial-separation-R-The.jpg)](#)

[**(a) Two Rydberg atoms in different electronic states and with spatial... | Download Scientific Diagram**](https://www.researchgate.net/figure/a-Two-Rydberg-atoms-in-different-electronic-states-and-with-spatial-separation-R-The_fig1_308994604)

- - 말 그대로 원자의 “크기”가 커진다.
  - 이 비유는 단순한 표현이 아니다.

    - 전자 궤도가 커지고
    - 전기적 영향 범위가 커지며
    - 다른 원자와 강하게 느끼기 시작한다
  - 평소에는 조용하던 중성원자가 리드버그 상태에 들어가는 순간, **주변을 강하게 밀어내는 존재**로 바뀐다.
  - 중성원자 기반 양자컴퓨터는 이 성질을 아주 **제한적**으로, 아주 **짧은 시간 동안**만 사용한다.

**💡리드버그 상태를 위한 레이저**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNTEyMzFfOTAg/MDAxNzY3MTg0NTkxMDg0.zX5Yrmt1h6aoCnSLJQJPBGtL3bv6ANH0Cyl82De2nSog.i2mnPUeaYIqsKZVDwrXdVUxbL9vg8gedB2ZACbI04lAg.JPEG/Schematic-view-of-the-N-type-Rydberg-atom-with-the-relevant-energy-level-str.jpg?type=w800)](#)

[**Schematic view of the N-type Rydberg atom with the relevant energy... | Download Scientific Diagram**](https://www.researchgate.net/figure/Schematic-view-of-the-N-type-Rydberg-atom-with-the-relevant-energy-level-structure-of-the_fig3_318675939)

- - 리드버그 레이저는 가시광–자외선 영역이고, 한 번에 올리지 않고 보통 2단계(이광자)로 올린다.
  - **왜 “직접 한 번에” 못 올리나?**

    - 리드버그 상태는:

      - 주양자수 n∼50–100
      - 에너지 간격이 **너무 작고**
      - 직접 바닥상태 → 리드버그 전이는

        - 선택 규칙
        - 필요한 파장
        - 레이저 기술
      - 측면에서 **현실적으로 매우 어렵다**
    - 그래서 거의 모든 실험·QC는 이광자 전이(two-photon transition)를 쓴다.
  - **루비듐 (Rb-87)**

    - **5S****1/2** **→ 5P****3/2**

      - 파장: **780 nm**
    - **5P****3/2** **→ nS / nD (리드버그)**

      - 파장: **≈****480 nm** **(청색)**
      - 👉 **780 nm + 480 nm**
      - → 리드버그 QC의 “교과서 조합”
  - **세슘 (Cs-133)**

    - **6S****1/2** **→ 6P****3/2**

      - 파장: **852 nm**
    - **6P****3/2** **→ nS / nD**

      - 파장: **≈****509 nm**
      - 👉 **852 nm + 509 nm**
    - **Infleqtion의 경우 459nm + 1040nm 사용**

      - **중간 상태를 6P****1/2** **대신 7P****1/2** **사용**

        - 산란률 감소
        - 레이저 잡음에 덜 민감
        - 선택 규칙 제어 쉬움
        - Stark shift 엔지니어링 유리
      - 459/1040 nm 조합은

        - 블로케이드 세기 ↑
        - 누설 전이 ↓
        - 게이트 오류 ↓

**💡****“옆사람이 크면 동시에 1이 안 된다”**

- - 리드버그 상호작용의 핵심은 리드버그 블로케이드(blockade)다.
  - 직관적으로 설명하면 이렇다.

    - 원자 A가 리드버그 상태가 되면
    - 그 주변 공간의 에너지 구조가 바뀐다
    - 그 결과, 가까이 있는 원자 B는
    - 같은 리드버그 상태로 올라갈 수 없게 된다
  - 그래서 다음 규칙이 생긴다.

    - **“이웃한 두 원자는 동시에 리드버그 상태가 될 수 없다.”**
  - 이 규칙은 누군가가 임의로 만든 제약이 아니다.
  - **물리 법칙이 강제로 만들어낸 조건**이다.
  - 그리고 바로 이 조건이 양자 논리가 된다.

**💡****블로케이드는 어떻게 계산이 되는가**

- - 이제 이 물리 현상을 큐비트 언어로 번역해 보자.

    - |0⟩ : 리드버그가 아닌 상태
    - |1⟩ : 리드버그로 올라가는 경로를 포함한 상태
  - 두 원자가 있을 때,

    - |00⟩, |01⟩, |10⟩ 상태는 가능하지만
    - |11⟩ 상태는 **물리적으로 금지**된다
  - 이건 논리 게이트의 핵심 구조다.

    - 허용된 상태(|01⟩, |10⟩)는

      - 리드버그 상태를 잠깐 거쳤다가
      - 돌아오며 **위상을 얻는다**
    - 금지된 상태(|11⟩)는

      - 아예 올라가지 못함
      - **다른 위상 경로를 가진다**
      - 👉 결과적으로 아래와 같은 조건부 위상 게이트(CZ)가 만들어진다.

- - 이 조건이 있으면 조건부 연산, 위상 변화, 얽힘 생성이 자연스럽게 따라온다.
  - 중요한 점은 이것이다.

> *중성원자 양자컴퓨터에서는* ***논리를 구현하려고 억지로 제어하지 않는다.***
>
> *물리가 이미 만들어 놓은 규칙을 계산에 이용한다.*

**💡** **얽힘은 명령이 아니라 결과다**

- - 많은 설명에서는 “얽힘을 만든다”고 말한다.
  - 하지만 리드버그 기반에서는 이 표현이 조금 부정확하다.
  - 더 정확한 표현은

    - **얽힘은 금지된 상태 때문에 자연스럽게 생긴다.**
  - 두 원자가 동시에 리드버그 상태가 될 수 없다는 사실 때문에 상태들은 서로 독립적으로 진화할 수 없게 된다.
  - 그 결과,

    - 한 원자의 상태를 알면
    - 다른 원자의 상태도 자동으로 제한된다
  - 이 상관관계가 바로 얽힘이다.
  - 중성원자 기반에서는 얽힘이 “특별한 기술”이라기보다 **리드버그 상호작용의 부산물**에 가깝다.

**💡****왜 평소에는 리드버그를 쓰지 않는가**

- - 그렇다면 이런 질문이 생긴다.

    - **“그럼 항상 리드버그 상태로 두면 되지 않나?”**
  - 리드버그 상태는

    - 수명이 짧고
    - 외부 잡음에 민감하며
    - 불필요한 상호작용을 만든다
  - 그래서 중성원자 기반 양자컴퓨터는 리드버그를 **상시 상태로 유지하지 않는다**.

    - 필요할 때만
    - 아주 짧게
    - 정확히 조절해서
  - 상호작용을 “켜고 끄는 스위치”처럼 사용한다.
  - 이 덕분에 중성원자는

    - **평소에는 조용하고**
    - **계산할 때만 시끄럽다**
  - 라는 독특한 성격을 갖는다.

**✅이온트랩과 중성원자의 비교**

**💡리드버그 vs 쿨롱 상호작용**

- - **리드버그 상태의 3대 장점**

    1. **상호작용이 매우 강함**

       - 전자가 멀리 나가 → 전기적 영향 급증
    2. **거리 조절 가능**

       - 원자 간 거리 = 상호작용 세기
    3. **ON / OFF가 명확**

       - 레이저 끄면 즉시 사라짐
    - 비유 : 평소엔 각자 자리,필요할 때만 팔 벌려 간섭
  - **이온트랩의 쿨롱 상호작용의 장점과 단점**

    - **장점**

      - 상호작용이 매우 안정적
      - 긴 코히런스 시간
    - **치명적 단점**

      - ❌ 상호작용을 **끄기 어렵다**
      - ❌ 이온 수가 늘면 **모두가 서로 영향**
      - ❌ 제어 복잡도 급증
    - 비유 : 모두가 항상 서로 밀고 있는 만원 지하철

| --- | --- | --- |
| **항목** | **이온트랩** | **중성원자** |
| 기본 상호작용 | 항상 있음 | 거의 없음 |
| ON/OFF | 어려움 | 매우 쉬움 |
| 확장 시 복잡도 | 급증 | 완만 |
| 제어 철학 | 정밀 | 단순·병렬 |

**💡 이온트랩: 얽힘의 메커니즘 (MS 게이트 기준)**

- - **핵심 아이디어**

    - 여러 이온이 **같은 전기장 트랩**에 있음
    - 트랩 안에는 **공통 진동 모드**가 존재
    - 레이저가 이 진동 모드를 살짝 흔들면서
    - 이온의 내부 상태 ↔ 진동 상태를 엮음
  - **결과**

    - 이온 A의 상태 변화 → 진동 모드 변화
    - 진동 모드 변화 → 이온 B에 영향
    - → **A와 B가 얽힘**
  - **수식적으로는**

    - 스핀–포논 결합
    - 2차 효과로 스핀–스핀 결합 생성
  - 👉 **얽힘은 항상 “트랩 전체를 공유”**

****

**💡 중성원자: 리드버그 얽힘의 메커니즘 (요약)**

- - **핵심 아이디어**

    - 원자 하나를 **리드버그 상태**로 올리면 전자 궤도가 엄청나게 커짐
    - 주변 원자의 에너지 준위를 **강하게 밀어냄**
  - 이게 바로 **리드버그 블로케이드**.
  - **두 원자 A, B가 있을 때**

    - A가 리드버그로 올라가면
    - B는 에너지 준위가 틀어져서
    - **같이 못 올라감**
  - → “둘 다 여기될 수 없음”이라는 **조건부 규칙**이 생김
  - → 이 규칙이 **조건부 위상**을 만들고
  - → 그게 **얽힘**
  - 👉 **공통 모드 필요 없음, 거리만 맞으면 됨**

| 연결 준비 | 거의 없음 | 필요할 수 있음 |
| 병렬성 | 제한적 | 매우 큼 |
| 체감 속도 | 제한적 | 시나리오 의존 |
| 진동 바닥상태 필요 | 거의 필수 | 필요 없음 |
| 모션 민감도 | 매우 높음 | 상대적으로 낮음 |

**💡 “위상” 관점에서 본 본질적 차이**

- - **이온트랩**

    - 얽힘 = **스핀 ↔ 진동 ↔ 스핀**
    - 진동 위상, 온도, 모드 스펙트럼이 중요
  - **중성원자**

    - 얽힘 = **조건부 에너지 이동 → 위상 축적**
    - 본질적으로 **위상 게이트**
  - 👉 그래서 중성원자 얽힘은

    - “누가 올라갈 수 있느냐”가 아니라
    - “얼마의 위상을 얻었느냐”가 핵심

**💡 확장성에서 갈리는 이유**

- - **이온트랩의 한계**

    - 이온 수 ↑ → 진동 모드 수 ↑
    - 모드 스펙트럼 복잡
    - 게이트 느려짐
    - 제어 난이도 폭증
  - **중성원자의 장점**

    - 각 원자는 **자기 포텐셜 우물**
    - 얽힘은 **로컬 상호작용**
    - 배선이 없다.

      - 초전도: 배선 지옥
      - 이온트랩: 전극 설계 지옥
      - 중성원자: ❌ 배선 없음
      - 👉 레이저는 **공중에서 다중 제어 가능**
    - 배열을 바꾸면 연결성도 바뀜

      - 광집게 배열은 **동적으로 재구성 가능**
      - 필요 없는 원자 제거
      - 원하는 구조로 재배치
      - 👉 이건 다른 플랫폼이 거의 못 하는 능력
    - 2D, 3D 확장 자연스러움

      - 이온트랩: 기본은 1D
      - 중성원자: 처음부터 2D 격자
      - 👉 오류보정(QEC)에 **구조적으로 유리**
    - 수가 늘어도 설계가 안 바뀐다.

      - 50개 → 500개 → 5000개
      - 원리 동일
      - 구조 동일
      - 제어 방식 동일
      - 👉 이게 진짜 “스케일링”
  - 👉 그래서:

    - **소수 고정밀** → 이온트랩

      - 포토닉 인터커넥트로 확장 시도
    - **대규모 병렬** → 중성원자

      - 아직 게이트 기반의 상용화 제품 부
  - **중성원자의 단점**

    - 리드버그 상태 수명 짧음

      - 최근 Harvard 의 University Professor이자 QuEra의 창업자인 Mikhail Lukin 교수는 3,000개 이상의 중립 원자(87Rb) 큐비트를 2시간 이상 연속 유지하는 실험 성공하였음.
    - 레이저 안정성 요구 높음
