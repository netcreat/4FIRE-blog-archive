# Google, PQC 전환 시기를 1년 앞당기다

Published: 2026-03-28T17:06:22.280000+09:00

Original Naver post: https://blog.naver.com/4-fire/224232533011

[Google’s timeline for PQC migration](https://blog.google/innovation-and-ai/technology/safety-security/cryptography-migration-timeline/)

**✅ 핵심 내용 요약**

**📌 왜 갑자기 서두르나**

- - 양자컴퓨터 발전 속도 ↑ (하드웨어 + 오류정정)
  - RSA 같은 기존 암호 깨질 가능성 현실화
  - 특히 위험한 시나리오:

    - 👉 **“지금 데이터 저장 → 나중에 해독 (store now, decrypt later)”**

****

**📌** **목표: 2029년까지 PQC 전환**

- - 기존: 업계 기준 약 2030
  - 변경: **구글 내부 목표 2029**
  - 👉 의미:

    - “양자컴퓨터 등장 시점”이 아니라 **리스크 대비 시점을 앞당긴 것**

****

**📌** **어디부터 바꾸나 (핵심 전략)**

- - 구글이 특히 강조하는 부분:

    - 인증 (Authentication)
    - 디지털 서명 (Digital Signature)
  - 👉 이유:

    - 서명이 깨지면
    - → 신뢰 자체가 붕괴 (악성 코드 위장 가능)

**📌** **이미 진행 중인 것들**

- - Android (예: Android 17 → PQC 서명 도입)
  - Chrome
  - Google Cloud
  - 👉 즉, **연구 단계가 아니라 이미 배포 단계**

****

**📌** **업계에 던지는 메시지**

- - “우리만 하는 게 아니라 너희도 빨리 준비해라”
  - 표준 (NIST) + 산업 전환 속도 압박

---

**✅ 뉴스의 의미**

**📌** **구글의 포지션은 이거임**

1. 1. **인프라 사업자**

      - Cloud, Android, Chrome
      - → PQC를 “서비스 기능”으로 포함
   2. **플랫폼 표준 세터**

      - 브라우저 / OS / 클라우드에 PQC 넣으면
      - → 산업 전체가 따라가야 함
   3. **양자컴퓨팅 플레이어**

      - 내부적으로 양자컴 연구도 병행

**📌 중요한 포인트**

- - 👉 이건 “보안 업데이트”가 아니라 **시장 신호다**
  - **의미 해석:**

    - QKD / PQC / Quantum Security 시장 열림
    - 기업들:

      - → 지금부터 예산 잡아야 함
    - 정부:

      - → 규제 + 의무화 준비

**📌 한 단계 더 해석**

- - 👉 구글은 지금 이렇게 말하는 중:

    - “양자컴퓨터가 언제 오든 모르겠지만 그 전에 우리는 다 바꿔놓겠다”
  - 즉,

    - 기술 타이밍이 아니라 **리스크 기반 전략**
