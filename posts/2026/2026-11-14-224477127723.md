# IonQ 임원 보상은 적절한가? 연봉·성과급·RSU·PSU의 신·구 경영진 비교

Published: 2026-11-14T22:05:58+11:00

Original Naver post: https://blog.naver.com/4-fire/224477127723?fromRss=true&trackingCode=rss

---

**✅ 연봉·성과급·정기 PSU와 타사 비교**

- - IonQ의 2025년 신임 경영진 보상은 공시상 총액이 매우 크지만, 상당 부분은 **3년치 조건부 PSU의 회계상 평가액**과 일회성 영입·이직 보전 RSU다. 공시 총액을 1년 실제 수령액으로 해석하면 결론이 왜곡된다.
  - 이 글에서는 **① 연봉·연간 성과급 ② 일회성 보상을 제외한 정기 장기보상 ③ PSU 지급 주식 수 ④ 구 경영진·비슷한 시기 상장한 기술기업 비교** 순으로 분석한다.
  - 분석 기준: 2025 회계연도, 2026년 공개된 SEC Proxy Statement. 모든 금액은 미국 달러(USD)이며, 확인된 사실과 비교 계산을 구분한다.

---

**✅ 1. 보상 항목을 먼저 구분해야 한다**

|  |  |  |
| --- | --- | --- |
| **구분** | **의미** | **실제 수령·평가 시점** |
| Salary (급여) | 계약상 연봉·재직기간에 따른 기본급 | 근무기간에 따라 지급 |
| STI / Annual Bonus | Short-Term Incentive: 1년 성과급 | 2025년은 현금 50% + RSU 50% |
| RSU | Restricted Stock Unit: 주로 재직조건을 충족하면 지급 | 각 베스팅 시점에 주식 확정 |
| PSU | Performance Stock Unit: 성과목표 달성에 따른 주식 | 2025~2027 성과 평가 후 2028년 초 확정 |
| LTI | Long-Term Incentive: RSU·PSU 등을 포괄하는 장기보상 | 다년간 성과·재직 조건 |
| Accounting Value | 회계상 주식보상 평가액 | 실제 현금 수령액 또는 매출 달성액 아님 |

- - **PSU는** 성과 100% 달성을 가정해 설정한 **목표 주식보상 가치**다. 실제 매출 목표 수치는 별도의 비공개 성과지표다.
  - 정기 LTI의 3년 목표가치를 3으로 나누는 것은 **연간 환산 비교**일 뿐, 그 금액이나 주식이 매년 추가 지급된다는 뜻이 아니다.

**✅ 2. 기본급은 왜 낮게 보이고, 성과급 100%는 현금인가?**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **2025년 임원** | **계약상 연봉** | **목표 보너스** | **2025 실제 급여** | **2025 인정 성과급** |
| de Masi (CEO) | $500K → $700K | 100% | $501,705 | $772,625 |
| Singh (CFO·COO) | $500K | 100% | $160,985 | $247,917 |
| Dacier (CAO·CLO) | $550K | 75% | $256,250 | $295,969 |
| Acosta (대외협력) | $500K | 75% | $119,318 | $137,812 |
| Millard (CBO) | $500K | 100% | $52,083 | $80,208 |

- - 2025년 실제 급여가 연봉보다 낮은 주된 이유는 임원들이 **연중에 취임**해 근무기간만큼 급여를 받았기 때문이다. de Masi는 2월 CEO 취임 후 8월 회장 겸임에 따라 연봉이 인상됐다.
  - 보너스 목표 **100%**는 목표 달성률 100%일 때 연봉과 같은 금액의 **성과급 기회**를 뜻한다. 현금 100% 지급을 보장하지 않는다.
  - 2025년 IonQ가 인정한 연간 성과 달성률은 **154%**다. 성과급은 **절반 현금·절반 RSU**로 정해졌으며, RSU 부분은 2026년 3월 10일 베스팅 조건이다.
  - 예컨대 Singh의 성과급 $247,917은 대략 현금 $123,959 + RSU 목표가치 $123,958로 구성된다. 이는 3년 PSU와는 **별개의 연간 성과급**이다.
  - 공시 근거: [2026 Proxy p.37~38 — Base Salary / Annual Incentive](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

  - 공시 근거: [2026 Proxy p.42 — Summary Compensation Table](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

**✅ 4. 일회성 보상을 제외한 신임 임원 정기 PSU**

- - **이번 비교에서 제외:** 입사 유인(Sign-on) RSU, 전 직장 보상 포기분의 이직 보전(Make-whole) RSU, 회장 승진·특별 인정 RSU, PSU 목표수정에 따른 추가 회계평가액.
  - **이번 비교에 포함:** 정기 LTI에 해당하는 3년 PSU의 계약상 목표가치와 목표·최대 주식 수. 연간 성과급 50% RSU는 별도의 STI이므로 PSU 수량과 합산하지 않는다.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **임원** | **3년 PSU 목표가치** | **연간 환산** | **목표 주식 수 (3년 전체)** | **최대 주식 수 (200%)** |
| de Masi | $27.0M | $9.0M | 902,105 | 1,804,210 |
| Singh | $18.0M | $6.0M | 427,452 | 854,904 |
| Dacier | $12.0M | $4.0M | 282,952 | 565,904 |
| Acosta | $7.5M | $2.5M | 94,949 | 189,898 |
| **합계** | **$64.5M** | **$21.5M** | **1,707,458** | **3,414,916** |

- - 모든 PSU 주식 수는 **2025~2027년 3년 전체**에 대한 조건부 수량이다. 2027년 말 성과 평가 후 조건에 따라 2028년 초 지급될 예정이다. 매년 이만큼 새로 받는 것이 아니다.
  - Millard는 2025년 11월 말 합류했기 때문에 그의 정기 PSU는 2026~2028년을 대상으로 2026년에 별도 부여했다(3년 목표가치 $10M, 연간 환산 약 $3.33M). 위 2025년 PSU 합계에는 포함하지 않았다.
  - 최대 주식 수는 목표 수량의 200% 지급을 가정한 한도이며, 실제 달성 여부는 미확정이다.
  - 공시 근거: [2026 Proxy p.27~30 / p.43~44 — Annualized LTI, Grants of Plan-Based Awards](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

**✅ 5. 구 CEO,CFO와 비교하면 보상 수준이 얼마나 상승했나?**

**📌 CEO: Chapman과 de Masi의 PSU 비교**

|  |  |  |
| --- | --- | --- |
| **구분** | **Peter Chapman (구 CEO)** | **Niccolo de Masi (신 CEO)** |
| PSU 부여일 | 2024.12.16 | 2025.02.26 |
| PSU 성과기간 | 2024.12~2026.12 (약 2년) | 2025~2027 (3년) |
| PSU 계약상 목표가치 | $5.0M | $27.0M |
| 목표 PSU 총수량 | 119,588주 | 902,105주 |
| 최대 PSU 수량 | 358,764주 (300%) | 1,804,210주 (200%) |
| 비교용 기간 환산 주식 수 | 119,588 ÷ 약 2 = 59,794주/년 | 902,105 ÷ 3 ≈ 300,702주/년 |
| 성과지표 구성 | 매출 50% + 기술 50% | 매출 90% + 기술 10% |
| 주가 허들 | 있음 (미달 시 최대 100%) | 별도 주가 허들 확인되지 않음 |

- - **CEO의 목표 PSU 총수량은 약 7.54배**(902,105 ÷ 119,588), 최대 지급 수량은 약 5.03배다. 다만 두 계약은 부여 시점 주가·평가기간·최대 지급조건이 모두 다르다.
  - **기간 환산은 설명용이다.** Chapman은 2024년 12월부터 2026년 말까지 약 2년, de Masi는 2025~2027년 3년을 대상으로 한다. 약 2년과 3년으로 나누면 목표 주식 수의 연간 환산은 약 5.03배다. 이는 실제 매년 지급되는 수량이 아니다.
  - **Chapman을 일반적인 3년 정기 PSU 수급자로 간주하면 안 된다.** 그는 2023년 본인 요청으로 PSU를 받지 않았고, 2024년 12월 보상으로 $5M PSU와 **2024·2025년 각 $10M 현금 인센티브**를 승인받았다. 이 현금보상은 PSU 수량 비교에서 제외했지만 구 CEO의 총보상을 평가할 때 무시해서는 안 된다.
  - Chapman의 $5M ÷ 약 2년 = 약 $2.5M/년과 de Masi의 $27M ÷ 3년 = $9M/년을 비교하면 약 3.6배이지만, **전임 CEO의 정규 반복 LTI와 동일한 기준의 인상률이라는 뜻은 아니다.**
  - 근거: [2024년 12월 Form 8-K Item 5.02 — Chapman PSU·현금 보상](https://www.sec.gov/Archives/edgar/data/1824920/000119312524283171/d921213d8k.htm); [2025 Proxy p.23, p.29·Grants of Plan-Based Awards](https://www.sec.gov/Archives/edgar/data/1824920/000095017025059289/ionq-20250428.htm); [2026 Proxy p.27·p.43](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

**📌 CFO: Kramer와 Singh의 PSU 비교**

|  |  |  |  |
| --- | --- | --- | --- |
| **지표** | **구 CFO Thomas Kramer** | **신 CFO·COO Inder Singh** | **평가** |
| 정기 LTI 구조 | 연간 RSU ⅓ + PSU ⅔ | 3년 정기 LTI는 PSU 100% | 성과연동 비중 증가 |
| 연간 정기 RSU 목표 | $0.917M | $0 | RSU 제외 |
| 연간 정기 PSU 목표 | $1.833M | $6.000M | 약 3.27배 |
| **연간 정기 LTI 목표 합계** | **$2.750M** | **$6.000M** | **약 2.18배** |
| PSU 성과기간 | 2023~2026 (4년) | 2025~2027 (3년) | 기간 다름 |
| PSU 목표 총수량 | 458,880주 | 427,452주 | 약 6.8% 감소 |
| PSU 연간 환산 수량 | 114,720주 | 142,484주 | 약 24.2% 증가 |
| PSU 최대 총수량 | 1,376,640주 (300%) | 854,904주 (200%) | 기존 조건이 더 큼 |

- - Kramer의 **458,880주 ÷ 4 = 114,720주**는 2023~2026년 **4년치** PSU이기 때문이다. Singh은 **427,452주 ÷ 3 = 142,484주**로 2025~2027년 **3년치**다. 실제 매년 베스팅되는 수량은 아니다.
  - Kramer의 연간 정기 LTI $2.75M은 2024년 RSU 목표 $916,667이 정기 LTI의 ⅓이라는 회사 설명으로 역산한 **설계 기준값**이다. 2023년 부여한 4년치 PSU를 매년 새로 부여한 것은 아니다.
  - 신임 CFO의 **달러 기준 정기 보상 목표는 크게 늘었지만**, PSU 목표 총주식 수는 소폭 감소했다. 2023년과 2025년의 부여 주가 차이 및 평가기간 차이가 있기 때문이다.
  - 기존 PSU의 최대 300% 지급에는 별도 주가 허들이 있었다. 허들을 충족하지 못하면 최대 지급률은 100%로 제한되는 구조였다.
  - 근거: [IonQ 2023 Form 8-K Item 5.02](https://www.sec.gov/Archives/edgar/data/1824920/000119312523215147/d508363d8k.htm); [2025 Proxy p.29 — 정기 LTI 구조](https://www.sec.gov/Archives/edgar/data/1824920/000095017025059289/ionq-20250428.htm); [2026 Proxy p.28~29](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

**✅ 6. PSU는 실제로 어떤 성과에 따라 지급되는가?**

|  |  |  |
| --- | --- | --- |
| **계약 구조** | **구 경영진 2023 PSU** | **신임 경영진 2025 PSU** |
| 성과기간 | 4년(2023~2026) | 3년(2025~2027) |
| 매출 목표 비중 | 50% | 90% |
| 기술(AQ) 목표 비중 | 50% | 10% |
| 최대 지급률 | 300% (주가 허들 조건) | 200% |
| 직접적인 주가 허들 | 있음 | 2025 PSU에는 별도 허들 확인되지 않음 |
| 실제 매출 목표 수치 | 일부 비공개 | 핵심 목표 수치 비공개 |

- - 2025년 PSU 지급률은 기본적으로 **매출 성과 지급률 × 90% + 기술 성과 지급률 × 10%**로 계산한다. 매출 최대(200%)·기술 미달(0%)이라면 전체 목표 PSU의 **180%**가 지급될 수 있다.
  - de Masi의 경우 목표 902,105주를 100% 달성하면 902,105주, 최대 200% 달성하면 1,804,210주가 지급된다. 실제 현금가치는 당시 주가에 따라 달라진다.
  - 2025년 8월 회사는 PSU의 **매출 성과목표를 수정**했지만 수정 전후의 목표 숫자를 공개하지 않았다. 목표를 쉽게 만들었는지, 합리적으로 조정했는지는 공시만으로 확정할 수 없다.
  - 근거: [2023 8-K Item 5.02](https://www.sec.gov/Archives/edgar/data/1824920/000119312523215147/d508363d8k.htm); [2025 PSU 계약 Exhibit 10.2](https://www.sec.gov/Archives/edgar/data/1824920/000095017025027713/ionq-ex10_2.htm); [2026 Proxy p.28 및 p.39](https://www.sec.gov/Archives/edgar/data/1824920/000119312526197487/ionq-20260430.htm).

**✅ 7. 주주 희석 부담은 얼마나 되는가?**

|  |  |  |
| --- | --- | --- |
| **정기 2025 PSU 대상** | **주식 수** | **2025년 말 발행주식 대비** |
| 정기 PSU 목표 총량 (4명) | 1,707,458주 | 0.471% |
| 정기 PSU 최대 총량 (4명) | 3,414,916주 | 0.942% |
| 목표 수량 3년 단순 연평균 | 약 569,153주 | 연 0.157% 상당 |

- - 분모는 2025년 말 발행주식 **362,592,722주**다. 이 표는 정기 PSU의 잠재 규모를 비교한 것이며, 주식 전량이 2025년에 실제 발행·희석됐다는 뜻이 아니다.
  - 3년 단순 연평균은 경제적 규모 비교용이다. PSU가 2025·2026·2027년에 균등하게 베스팅되는 것은 아니다.
  - 향후 실제 희석은 PSU 달성률뿐 아니라 추가 발행, M&A, 옵션 행사, 주식보상 전반에 따라 달라진다.

**✅ 9. 결론 — 보상 ‘총액’보다 성과조건을 검증해야 한다**

- - **CEO 비교:** Chapman의 2024년 12월 PSU 목표 119,588주($5M)와 de Masi의 2025년 PSU 목표 902,105주($27M)는 총량에서 약 7.54배 차이가 난다. 다만 Chapman의 2023년 PSU 수령 거절과 2024·2025년 각 $10M 현금 인센티브를 함께 봐야 하므로 같은 정기 LTI 설계의 인상률이라고 단정해서는 안 된다.
  - **확인:** IonQ 신임 CFO의 연간 정기 장기보상 목표 $6M은 전임 CFO의 정기 LTI 설계값 약 $2.75M보다 약 **2.18배**다. PSU 목표가치만 비교하면 약 3.27배다.
  - **확인:** 하지만 신임 CFO의 PSU 목표 **총주식 수** 427,452주는 구 CFO의 458,880주보다 적다. 달러 기준 증가율을 그대로 희석 증가율로 해석할 수 없다.
  - **확인:** 신임 PSU의 매출 가중치는 50%에서 90%로 증가했고, 2025년 중 성과목표가 수정됐다. 구체적인 성과목표 숫자가 비공개이므로 난이도를 완전히 검증하기 어렵다.
  - **타사 비교:** IonQ CEO의 정기 장기보상은 고성장 기술기업 상단이지만 유사 사례가 있다. CFO·COO 보상은 비교 대상에서 높은 편이다. 다만 서로 다른 회계평가·부여 주기 때문에 정확한 업계 평균과 동일시해서는 안 된다.
  - **판단:** ‘보상 규모가 상승했다’는 사실은 분명하다. ‘성과 대비 비정상적으로 과도하다’는 최종 판단에는 **비공개 PSU 매출·기술 목표, 수정 전후 난이도, 실제 2028년 지급률** 확인이 필요하다.
