# Cisco Quantum Summit 2026 Day 1 — Quantum Position Verification(QPV)

Published: 2026-10-19T20:23:06+11:00

Original Naver post: https://blog.naver.com/4-fire/224446825415?fromRss=true&trackingCode=rss

---

**✅ Quantum Position Verification(QPV) — 양자 인터넷의 첫 킬러앱이 될 수 있을까?**

- - 2026년 10월 Cisco Quantum Summit Day 1에서 **JPMorgan Chase의 Kaushik Chakraborty**는 「Quantum Position Verification: Physics-Backed Location Attestation for Metro-Scale Quantum Networks」를 발표했다. 앞선 Qunnect의 Mehdi Namazi도 이를 실제 양자 네트워크 응용으로 소개했고, 패널에서는 Boeing의 Makan Mohageg이 사용자에게 **정량화 가능한 가치**를 제공할 수 있는 기술이라고 평가했다.
  - QPV(Quantum Position Verification, 양자 위치 검증)는 상대방이 **주장한 장소에서 실제로 응답했는지** 검증하는 기술이다. GPS처럼 현재 좌표를 계산하는 서비스라기보다, **위치를 속이려는 공격자가 존재하는 상황에서 특정 위치에 있었다는 사실을 인증**하는 보안 프로토콜에 가깝다.

[![](https://blogfiles.pstatic.net/MjAyNjEwMThfMjk3/MDAxNzkyMzE4NDc2MTc2.TmzaOlE-h3Nn045GCH8NURxj98X_drurg7JvU-JJpasg.IAoViBYccAsvJjbLs5UpQAfDF503lb8jvnCgG6Rb04Ag.PNG/image.png?type=w1)](#)

- - 이번 발표의 주목할 성과는 **JPMorgan Chase–Qunnect의 Loss-Tolerant QPV 실증**이다. 상용 부품으로 약 60m의 실험을 수행했고, 약 22분의 순수 데이터 수집으로 제한된 공격 모델에서 위치 검증 성공을 보고했다.
  - 하지만 **60m 실증과 광역 도시망 서비스는 다른 단계**다. 이 글에서는 실제 논문·발표의 숫자를 유지하면서 QPV의 작동 원리, 구현 조건, 보안 한계, 킬러앱 가능성을 따져본다.

**✅ 1. 왜 ‘나의 위치’를 증명해야 하는가?**

- - 가령 은행의 고액 거래 승인 서버가 **시드니의 승인된 데이터센터 안에서** 동작해야 한다고 해보자. 현재는 디지털 서명으로 누가 거래에 서명했는지 확인할 수 있지만, **그 서명이 정확히 어디서 이루어졌는지**는 서명 자체로 보장되지 않는다.
  - IP 주소는 VPN·프록시로 달라질 수 있고, GPS·Wi-Fi 정보나 기기 내부 위치 데이터도 조작되거나 신뢰할 수 없는 방식으로 전달될 수 있다.
  - QPV가 겨냥하는 것은 이런 틈이다. 미리 측정해 둔 신뢰할 수 있는 여러 검증 지점이 **정해진 시간 안에 특정 양자·고전 정보를 처리해 응답할 수 있는 위치**를 확인한다.
  - **Spacetime Seal(시공간 인증서)**이란 이 검증 결과를 서명·거래 기록과 결합해 “누가, 언제, 어디서”라는 속성 가운데 위치와 시간을 독립적으로 증명하려는 응용 개념이다. QPV만으로 사용자의 신원까지 자동 증명되는 것은 아니다.

**📌 GPS·일반 위치추정과 QPV의 차이**

|  |  |  |
| --- | --- | --- |
| **구분** | **주로 확인하는 것** | **공격과 보안 관점** |
| GPS·IP 위치정보 | 관측 또는 보고된 좌표 | 보고값 변조, 중계, 스푸핑 등에 별도 방어 필요 |
| 고전적 Distance Bounding | 신호 왕복시간으로 거리 상한 제한 | 특정 조건에서 유용하지만, 여러 공격자가 협력하면 위치 검증이 어려워질 수 있음 |
| QPV | 특정 시공간 위치에서만 가능한 양자·고전 동시 응답 | 빛의 속도·양자복제불가 성질 등을 활용하지만 보안 가정이 반드시 필요 |

**✅ 2. QPV는 어떤 원리로 동작하는가?**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMTlfOTkg/MDAxNzkyNDAwODgxNTQ5.uoehbOILRkY201QprFagOc7WcpjV_u4PsBQm2pbp58kg.BecIBwjosxUx0kk65qqCweWs4LxYw3okKc2cBvD1Z60g.PNG/image.png?type=w800)](#)

- - 핵심 요소는 **Verifier(검증자)**와 **Prover(위치 증명자)**다. V0와 V1은 위치를 알고 신뢰할 수 있는 검증 지점이고, P는 그 사이 어딘가에 있다고 주장하는 대상이다.
  - 두 검증자가 서로 다른 정보 x, y를, P가 주장한 위치에 **거의 동시에 도착하도록** 보낸다. P는 양쪽 정보를 모두 받은 뒤 지정된 연산 또는 측정을 수행하고 결과를 되돌려준다.
  - 검증자들은 **정답인지**와 **정해진 시간에 돌아왔는지**를 함께 확인한다. 어느 한쪽에만 가까운 공격자는 다른 쪽 정보가 도착할 때까지 기다려야 하므로 시간 제약을 받는다.

[![](https://blogfiles.pstatic.net/MjAyNjEwMThfMjc1/MDAxNzkyMzE4NzA5NDUy.ob9CnejaRfi9GYNwDAcJF1Refxyc-4l-OFaAYITa-CAg.iC4HlMXPm5opOKsFzJ7Rqj5iP7lGGOfe3iIa91fEfIgg.PNG/image.png?type=w1)](#)

**📌 왜 고전적 정보만으로는 부족한가?**

- - 공격자 A와 B가 진짜 P의 좌우에 배치돼 있다고 생각해 보자. 고전 정보 x, y라면 각각 정보를 복사해 상대방에게 전달하고, 함께 정답을 계산한 뒤 각 검증자에게 응답하는 **협력 공격(Colluding Adversaries)**을 설계할 수 있다.
  - 양자 상태는 다르다. 모르는 양자 상태를 **완벽하게 복사할 수 없다는 No-Cloning Theorem** 때문에 복사본을 양쪽 공격자에게 나누어 주는 식의 전략이 제한된다.
  - 또한 상대방에게 고전적 정보를 전달하거나 양자 정보를 이동시킬 때 **빛보다 빠르게 전달할 수 없다는 상대론적 인과관계**의 제약을 받는다.
  - 하지만 이것이 “양자는 절대로 위치 위조가 불가능하다”는 뜻은 아니다. 공격자들이 미리 엄청난 규모의 얽힘을 공유할 수 있으면 일반적인 위치 기반 암호는 원리적으로 깨질 수 있다는 No-Go 결과가 있다. 실제 보안은 **공격자가 가진 얽힘·계산 자원·질의 횟수 등 위협 모델**에 의존한다.

**✅ 3. 가장 중요한 구분 — 일반적인 QPV와 이번 실증의 LT-QPV는 다르다**

- - 발표의 앞부분에서 Kaushik은 이해하기 쉬운 일반형 QPV를 설명했다. **검증자가 양자 상태를 보내고**, 증명자가 받은 고전 정보로 측정 기저를 계산해 양자 상태를 측정하는 방식이다.
  - 그러나 2026년 JPMorgan–Qunnect 논문에 사용된 **Loss-Tolerant QPV(LT-QPV)**는 방향을 바꿨다. **증명자 P가 얽힌 광자쌍을 생성하고**, 한 광자를 신뢰된 양자 검증자 V0로 전송한다. 나머지 광자는 P가 잠시 보관한다.
  - 이 차이가 핵심이다. 먼 광섬유 구간에서 광자가 사라지더라도 검증자 쪽이 광자를 아예 검출하지 못한 라운드는 적절한 인과관계 조건에서 버릴 수 있으므로, **채널 손실이 공격자에게 유리한 가짜 성공으로 바뀌는 문제를 피하도록** 설계했다.

**📌 실제 LT-QPV 한 라운드의 흐름**

|  |  |  |
| --- | --- | --- |
| **순서** | **실제 동작** | **검증 포인트** |
| ① 얽힘 준비 | P가 Bell Pair |Φ⁺⟩=(|00⟩+|11⟩)/√2 생성 | 한 광자 1,324nm는 V₀로, 다른 795nm는 P에 보관 |
| ② 도전값 발송 | V₀·V₁이 서로 다른 임의값 x, y를 전송 | 두 값이 P가 주장한 위치에서 정해진 순간에 만남 |
| ③ 측정 기저 결정 | α=f(x,y)로 측정 기저 선택 | 실험은 16개 기저와 FPGA 기반 제어 사용 |
| ④ 양자 측정 | P와 V₀가 대응하는 기저에서 광자 측정 | 얽힘에 따른 측정 결과의 상관관계 비교 |
| ⑤ 답변 및 판정 | P가 측정 결과를 두 검증자에게 반환 | 시간·효율·QBER·응답 불일치율을 모두 확인 |

- - **핵심:** “Loss-Tolerant”는 **광자가 손실되지 않는다**는 뜻이 아니다. 검증자 측 광자 손실에 대한 **보안 증명의 구조를 개선했다**는 뜻이다. 링크가 길어지면 수신률·검증시간 등 실제 성능은 여전히 나빠질 수 있다.
  - 또한 이번 설계는 검증자 측 **신뢰할 수 있는 측정 장치**를 가정한다. 검증자의 장비까지 믿을 필요 없는 Device-Independent QPV와는 다른 보안 모델이다.

**✅ 4. JPMorgan은 QPV를 어떻게 실제 서비스로 끌어오려 했나?**

- - Kaushik은 발표에서 두 방향의 연구를 소개했다. 하나는 실제 양자 광학 장비에서 **측정 기저를 다양화하고 손실·공격을 고려한 QPV**를 강화하는 것이고, 다른 하나는 **양자컴퓨터가 만든 Certified Randomness를 이용해 검증자–증명자 사이의 양자통신을 없애는 방식**이다.
  - 두 연구 모두 위치 검증을 다루지만 **사용하는 자원과 네트워크 요구사항이 다르다.**

[![](https://blogfiles.pstatic.net/MjAyNjEwMThfMjUx/MDAxNzkyMzE4ODI3Njgy.QmDwt2nvD5n-DuiBVteQe0yrqRVNrf1AP6UcgKm-x1Ug.R8ZrhuCsqwxYXBnIJUmrf4Mp3UiCd-KJBrcelKbRV08g.PNG/image.png?type=w1)](#)

|  |  |  |
| --- | --- | --- |
| **연구** | **무엇을 제안했나** | **양자 네트워크와의 관계** |
| Multi-basis QPV  arXiv:2506.03549 | 여러 측정 기저와 엄밀한 보안 분석으로 손실 및 일반화된 공격 조건에 대응 | 실제 광자 전송·측정 장비가 필요할 수 있음 |
| Classically Verifiable Position Verification (CVPV)  arXiv:2410.03982 / Nature Communications 2026 | 양자컴퓨터의 Certified Randomness·Proof of Quantumness와 위치 검증을 연결 | 검증자–증명자 간 통신은 고전적일 수 있으나, 증명자 측 양자 계산 능력·암호학적 가정이 필요 |

**📌 그렇다면 후자는 QPV의 킬러앱 논리를 약화시키는가?**

- - 일부 그렇다. **고****전 통신만으로 검증 가능한 CVPV**가 충분한 서비스에서는 양자광학 네트워크를 매번 새로 구축할 필요가 없다.
  - 반대로 대규모 QPU 없이 비교적 작은 광학 장치와 가까운 검증 인프라를 활용하려면 **광자 기반 LT-QPV**가 경쟁력 있는 접근일 수 있다.
  - 따라서 QPV 전체가 상용화되더라도 반드시 양자 네트워크 장비의 매출과 1:1로 연결된다는 의미는 아니다. 어떤 변형 프로토콜이 경제성을 확보하는지 함께 살펴야 한다.

|  |  |  |
| --- | --- | --- |
| **구분** | **광학형 LT-QPV** | **CVPV** |
| 양자 광학 링크 | 필요 | 불필요 |
| Prover | 얽힌 광자 생성·측정 | 양자컴퓨터로 지정된 계산 수행 |
| Verifier | 최소 하나의 양자 검증기 | 모두 고전 검증기 가능 |
| 주요 자원 | Bell Pair, 광자 검출기 | 양자 연산, Certified Randomness |
| 현재 단계 | 제한된 조건의 실험 실증 | 보안 이론과 NISQ 구현 가능성 연구 |

**✅ 5. Qunnect와 함께 실증한 Loss-Tolerant QPV의 실제 성과**

- - 협력 논문 「Loss-Tolerant Quantum Position Verification for Metropolitan Area Networks」는 2026년 9월 공개됐다. JPMorgan Chase·Qunnect 등이 참여한 연구다.
  - 논문은 **상용 기성품(COTS)**으로 광학 얽힘 광원·편광 측정·FPGA 제어를 구성했고, 실제 위치 검증의 통계적 판정 기준을 통과했다고 보고했다.
  - 중요하게도 **이 실증은 도시 전체에 걸친 광역 네트워크 구축 결과가 아니라 짧은 거리의 실험**이다. “Metro-Scale”은 **확장 가능한 프로토콜 설계·예상 적용 범위**를 가리킨다.

**📌 숫자를 읽을 때 주의할 점**

- - 실험에서 인증 성공 기준은 **QBER만 낮으면 되는 구조가 아니다.** 증명자의 검출 효율이 너무 낮아도 실패하고, 두 검증자에게 보낸 답변이 불일치해도 실패한다.
  - 실험의 통계적 보안 설정은 **ε\_com=10⁻², ε\_sou=10⁻²**이며, 실증 시 공격자는 **동일 분포 독립 공격(i.i.d.)과 제한된 질의 횟수**라는 조건에서 평가했다. 금융 서비스용 최종 보안수준을 입증한 것으로 간주해서는 안 된다.
  - 논문이 계산한 위치 불확실성 영역은 검증자들의 위치를 포함하지 않는다. 이것이 해당 실험에서 주장한 고전적 거리추정 대비 장점이다.
  - **1초 미만 인증**은 고효율 검출기·소스·빠른 스위칭 도입을 전제로 한 연구진의 **향후 성능 전망**이다. 이번 시연에서 실측한 인증시간이 아니다.

**✅ 6. 구현하려면 어떤 하드웨어와 소프트웨어가 필요한가?**

|  |  |  |
| --- | --- | --- |
| **구성요소** | **실제 역할** | **경제성·운영상 고려** |
| 신뢰된 Quantum Verifier(V₀) | 광자의 편광 측정, 검출 시각 기록 | 고가 검출기·광학 제어장치에 대한 신뢰 및 보호 필요 |
| Classical Verifier(V₁ 등) | 도전값 전송, 도착시간 측정, 응답 검증 | 기존 광통신·무선·타임스탬프 인프라를 활용 가능 |
| Prover 측 광원 | 795/1324nm 얽힘 광자쌍 생성 | 실증 설계에선 각 증명자에 얽힘 광원·측정 장치가 필요 |
| 광학 채널 | P가 생성한 1,324nm 광자를 V₀로 보냄 | 도시 광섬유 손실·편광 흔들림·연결 비용 |
| 광자 임시 보관 | 고전 도전값이 도착할 때까지 다른 광자를 보유 | 실험은 42m 광섬유 지연선; 도시망 확대 시 보관시간 증가 |
| FPGA·클럭 동기화 | 지연을 줄인 x, y 발송·측정 기저 제어 | 시간 예산과 보안 경계를 직접 결정 |
| 운영 소프트웨어 | 장비 관리, 라운드 집계, 인증서 발급·감사 | 통신사업자·금융사 시스템에 통합돼야 서비스화 가능 |

**📌 왜 양자 검증자 한 대로도 충분하다고 했나?**

- - 2026년 LT-QPV 설계에서는 **검증자 중 하나만 광자 측정 능력**을 갖춘다. 다른 검증자는 고전 메시지와 시간을 확인하므로, 모든 검증 지점에 복잡한 양자광학 장치를 설치하는 방식보다 확장성이 좋아질 수 있다.
  - 그러나 **증명자 P가 얽힌 광자쌍을 생성해야 한다는 부담**이 있다. 검증자 수를 줄이는 것이 곧 전체 하드웨어 비용이 낮다는 의미는 아니다.
  - 또한 이번 논문의 도시망 적용도는 **기술 아키텍처 제안**이며, 여러 증명자와 고전 검증자가 흩어진 실제 도시에서 모든 위치를 2D·3D로 검증한 실증은 아니다.

**✅ 7. 공격자가 무한한 얽힘을 갖고 있다면 안전한가?**

- - **아니다.** Buhrman 등의 위치 기반 양자암호 연구는 적절한 모델에서 공격자들이 제한 없는 사전 공유 얽힘을 가진다면 무조건 안전한 위치 검증이 불가능함을 보였다.
  - JPMorgan의 LT-QPV는 이를 부정하지 않는다. **Quantum Random Oracle Model(QROM)**에서 계산 능력·질의 횟수가 제한된 공격자를 상정하고 통계적 보안 분석을 수행한다.
  - 특히 이번 장비는 검증자의 측정 기저 변경 속도가 제한돼 **일반적인 상관된 협력 공격(General Attacks)에 대한 장비 수준의 실증까지 완료한 것은 아니다.** 논문은 빠른 스위치와 훨씬 많은 유효 라운드가 필요할 수 있다고 명시했다.
  - 양자 검증자의 광검출기 공격(Detector Blinding)이나 광학 장비를 역으로 탐색하는 공격(Trojan-Horse) 같은 **측정 장치의 구현 취약점**도 별도로 방어해야 한다.

**📌 광역망 확대에서 남은 기술적 조건**

|  |  |  |
| --- | --- | --- |
| **과제** | **현재 결과 또는 조건** | **남은 작업** |
| Challenge 보안 강도 | 실험은 x,y 각각 4비트 도전값 | 128/256비트와 SHA3 같은 해시로 확대 |
| 공격모델 | 실증은 i.i.d.·질의 제한 | 빠른 Verifier 측 Pockels Cell, General Attack 보안 실증 |

**✅ 8. QPV는 왜 QKD보다 빠르게 상용화될 가능성이 있나?**

- - **용도가 다르다.** QKD는 먼 두 통신 당사자가 비밀 키를 만들거나 나누는 것이 목표이고, QPV는 특정 위치에서의 응답이 진짜인지 확인하는 것이 목표다.
  - 따라서 QPV는 반드시 대륙 간 Quantum Internet을 먼저 요구하지 않는다. 은행 데이터센터·거래소·병원·정부청사처럼 **한 도시 안에 검증자가 배치돼 있는 구역**만으로도 서비스 가치를 검증할 수 있다.
  - 특히 기업이 이미 갖고 있는 **기존 광섬유와 고전적 시간 동기화 인프라**를 일부 활용할 수 있다는 점에서 초기 투자비를 낮출 여지가 있다.
  - 반면 QKD와 달리 **위치 자체의 보안 인증**을 판매하는 신규 시장을 형성해야 하므로, 고객이 해당 인증서에 실제 비용을 지불할지 아직 검증되지 않았다.

**📌 우선 검토할 수 있는 응용**

|  |  |  |
| --- | --- | --- |
| **응용** | **QPV의 잠재적 역할** | **채택 장애요인** |
| 금융 거래·전자 공증 | 승인 작업이 허용된 관할권·시설에서 발생했는지 검증 | 인증 지연, 규제 수용 여부, 기존 HSM과 연동 |
| 데이터 주권·Sovereign Cloud | 특정 서버·비밀 연산이 허용 장소에서 실행됐다는 증명 보조 | 가상화·워크로드 이동성, 고객·기기 신원 결합 |
| 데이터센터 물리 보안 | 중요한 장치가 승인 위치에서 요청했는지 검증 | 기존 물리 출입통제와 비용 대비 효용 비교 |
| 군사·중요 인프라 | 중요 장비 또는 명령 발신 지점의 위치 인증 | 신뢰 인프라·가용성·공격모델 보장 |
| QKD 인증 | 고전 메시지를 주고받는 장치의 위치 인증 보완 | 별도의 키 관리·인증 체계와 결합 필요 |

**✅ 9. 정말 근미래 Quantum Networking의 킬러앱이 될까?**

- - **찬성할 근거는 분명하다.** QPV는 “양자컴퓨터가 언젠가 완성되면 무엇을 할 수 있나”가 아니라, **기존 금융·보안 시스템의 불충분한 위치 신뢰 문제**를 겨냥한다. Kaushik의 연구 발표와 패널에서 Mehdi·Makan이 반복적으로 QPV를 언급한 이유다.
  - 또한 JPMorgan과 Qunnect가 **실제 장비를 사용해 측정 가능한 판정 결과**를 공개했다는 점은 연구실 단계에서 의미 있는 진전이다.
  - 그러나 **킬러앱으로 확정하기에는 이르다.** 아직 수십 분의 시험시간, 짧은 거리, 제한된 공격 모델, 고가 또는 복잡한 Prover 광원, 부족한 도시망 실증이 남아 있다.
  - **비용의 관건**은 “증명자 한 대당 Quantum Hardware 비용”과 “기존 인증 방식 대비 방지할 수 있는 손실”이다. 수백만 달러 규모 거래의 규제·법적 위험을 줄인다면 일부 고가 고객에겐 의미가 있을 수 있지만, 일상적 사용자 인증에서는 비용과 지연이 불리할 수 있다.
  - 또한 검증자 간 양자통신이 필요 없는 **Certified Randomness 기반 CVPV**가 실용화된다면, 위치 검증 수요가 증가해도 그 이익이 반드시 광섬유 Quantum Network 구축으로 이어지지는 않을 수 있다.

**✅ 10. 앞으로 무엇을 확인하면 상용화라고 인정할 수 있을까?**

- - **첫 번째:** JPMorgan–Qunnect가 실제 설치된 **수 km~수십 km 도시 광섬유**를 사용해 위치 검증을 재현해야 한다.
  - **두 번째:** 서명·금융 거래에 필요한 **초 단위 또는 1초 미만의 인증시간**과 반복 사용 시 안정성을 입증해야 한다.
  - **세 번째:** 여러 검증자를 이용한 **2D·3D 위치 인증**과 일반화된 협력 공격 대응 능력을 보여야 한다.
  - **네 번째:** 은행·통신사업자 고객이 사용하는 인증 시스템과 연동하고, 인증 서비스 가격 및 운영비를 공개해야 한다.
  - **다섯 번째:** “Quantum Position Verification”이라고만 하지 말고 **어떤 신뢰 모델을 사용했는지** 공개해야 한다. Trusted Measurement, Device Independent, Certified Randomness 기반 CVPV는 서로 다른 조건을 갖는다.

**✅ 종합분석 — 양자 인터넷의 첫 킬러앱은 계산이 아닐 수도 있다**

- - Cisco Quantum Summit Day 1에서 가장 인상적인 부분은 **양자 네트워크를 연구실에서 산업현장으로 옮길 때 무엇을 팔 수 있는지**를 질문했다는 점이다. Kaushik은 그 후보로 위치의 물리적 신뢰성을 선택했다.
  - 양자 네트워크는 오랫동안 QKD와 분산 양자컴퓨팅으로 설명돼 왔다. 그러나 **QPV는 대규모 FTQC를 기다리지 않고도 제한된 도시망에서 기존 고객의 문제를 해결할 가능성**을 보여준다.
  - 특히 이번 실증은 단순한 원리 설명을 넘어 **상용 광학 부품, 측정 가능한 QBER·효율, 사전에 정의한 판정 기준, 실제 실험 데이터**를 제시했다는 점에서 의미가 있다.
  - 그렇지만 이 성과는 **완성된 보안 제품**이 아니다. 2026년 실험은 짧은 거리와 특정 공격 가정에서 성공했고, 아직 2D·3D 광역망, 빠른 응답, 장치 보안, 경제성은 별도로 검증해야 한다.
  - **현재로서는 QPV를 “근미래 킬러앱의 강력한 후보”라고 평가할 수 있지만, “최초의 상용 킬러앱이 확정됐다”고 표현하는 것은 이르다.** 앞으로 기대해야 할 소식은 새로운 이론 논문만이 아니라, 실제 금융 고객이 사용한 시공간 인증 서비스의 운영 실적과 경제적 효과일 것이다.
