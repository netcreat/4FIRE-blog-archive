# ✈️ 태평양 상공에서 13.5Mbps — Hawaiian A330-200의 Starlink는 어떻게 작동할까

- - 하와이안항공 A330-200을 타고 태평양을 건너면서 Starlink를 직접 사용해봤다.
  - 기내에는 승객이 상당히 많았지만 웹서핑, SNS, ChatGPT 등을 사용하는 데 거의 불편함이 없었다. 실제 Google 인터넷 속도 테스트를 해보니 **다운로드 13.5Mbps, 업로드 5.51Mbps, 지연시간 156ms**가 나왔다.
  - 그런데 Starlink가 공개한 항공기용 성능은 이보다 훨씬 높다. 왜 실제 단말에서는 13.5Mbps가 나오는 것일까?

**✅ Hawaiian A330-200에는 Starlink 안테나가 두 개 들어간다**

**📌 기종에 따라 Starlink 설치 방식이 다르다**

- - Starlink Aviation은 모든 항공기에 동일한 안테나 구성을 적용하지 않는다.
  - 항공기 크기와 구조, 필요한 네트워크 용량 등에 따라 설치 방식과 STC(Supplemental Type Certificate)가 달라진다.
  - 현재 Starlink의 인증 목록에는 Airbus A330이 **FAA STC ST04732NY**로 등록돼 있다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA5MDdfMjM5/MDAxNzg4NzY5ODExOTM4.fBCrtWD8nl3MI4VcBwB91rYDcHLF_QmVzHYoHJAvbLcg.AWT1QcDv0WHmMuU1z11RetrSjwJNrgkE3TRPyIKePQkg.PNG/image.png?type=w800)](#)

- - Hawaiian Airlines는 2024년 이미 보유한 **24대의 A330 전체에 Starlink 설치를 완료**했다.

    - [Hawaiian Airlines Now Offering Fast and Free Starlink Wi-Fi Across Entire Airbus Fleet - Alaska Airlines, Hawaiian Airlines and Horizon Air](https://news.alaskaair.com/releases/hawaiian-airlines-now-offering-fast-and-free-starlink-wi-fi-across-entire-airbus-fleet/)

    - Airbus A321neo
    - **Airbus A330-200**
    - Boeing 777-300
  - 그리고 이 dual-antenna 구성은 항공기 전체에서 **최대 1Gbps의 peak throughput**을 제공할 수 있다고 SpaceX가 밝혔다.

**✅ 1Gbps인데 왜 내 휴대폰에서는 13.5Mbps가 나올까**

**📌 1Gbps는 승객 한 명의 속도가 아니다**

- - 여기서 가장 중요한 점이다.
  - **1Gbps는 승객 한 명에게 제공되는 속도가 아니라 항공기 전체 Starlink 링크의 최대 aggregate capacity다.**
  - 대략적인 구조는 다음과 같다.

|  |
| --- |
| Starlink Satellite Network  ↓  Aero Terminal # 1  +  Aero Terminal # 2  ↓  Aircraft Network  ↓  Cabin Wi-Fi AP  ↓  수백 명의 승객 |

- - 따라서 항공기 전체가 확보한 수백 Mbps~1Gbps급 용량을 승객들이 공유하게 된다.
  - SpaceX가 현재 공개하는 일반적인 Starlink Aviation 성능은 다음과 같다.

|  |  |  |
| --- | --- | --- |
| **Plan** | **Download** | **Upload** |
| Regional 25GB | 250 Mbps | 44 Mbps |
| Regional Unlimited | 500 Mbps | 44 Mbps |
| Global Unlimited + Performance Antenna | **1 Gbps** | **100 Mbps** |

- - - <https://starlink.com/fo/support/article/faeb6f25-84d5-ab15-2395-023f252a67a8>

---

**✅ 수백 명이 접속하는데도 왜 생각보다 빠를까**

**📌 모든 사람이 동시에 최대 속도를 사용하는 것이 아니다**

- - 예를 들어 250명이 탑승했다고 해서,
  - **1,000Mbps ÷ 250명 = 1인당 4Mbps**
  - 처럼 단순 계산할 수는 없다.
  - 실제 인터넷 트래픽은 대부분 burst 형태이기 때문이다.

    - 웹페이지: 페이지를 불러올 때만 순간적으로 사용
    - Messenger / KakaoTalk: 대부분 idle
    - Instagram/X: 사진이나 영상을 불러올 때만 burst
    - YouTube: 일정량 buffer 후 잠시 idle
    - Netflix: 지속적이지만 adaptive bitrate 사용
    - ChatGPT: 전송 데이터 자체는 매우 작음
  - 결국 **250명이 동시에 최대 bandwidth를 요구하는 경우는 거의 없다.**
  - 네트워크 관점에서는 일종의 **statistical multiplexing**이다.
  - 회사에서 250명의 직원이 1Gbps 인터넷 회선을 함께 사용해도 일반 업무에서는 큰 문제가 없는 것과 비슷하다.

**✅ 실제 측정 결과는 13.5Mbps / 5.51Mbps**

- - 내가 Hawaiian A330-200 안에서 직접 측정한 결과다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA5MDdfMjg5/MDAxNzg4NzcyMDY3NTY3.hLU0YRG0dUomkzxJ_CV8npmO9EviCvMU3Nsv00UphDMg.tjjtgQKuH-6kYeKfMEHJXthErGle6wimQn1nZLoHZSMg.PNG/image.png?type=w800)](#)

- - 숫자만 보면 Starlink의 수백 Mbps와 상당히 차이가 나 보인다.
  - 하지만 이것은 오히려 정상적인 결과일 가능성이 높다.
  - 항공사는 한두 승객이 수백 Mbps를 독점하지 못하도록

    - 사용자별 traffic management
    - flow별 QoS
    - congestion management
    - application traffic shaping
  - 등을 사용할 수 있다.
  - 다만 이번 한 번의 테스트만으로 Hawaiian이 **13~15Mbps의 per-user rate limit을 걸었다고 단정할 수는 없다.**
  - 다른 승객의 사용량이나 당시 Starlink beam의 capacity에 따라 달라질 수도 있다.

**✅ 13.5Mbps가 생각보다 충분한 이유**

**📌 기내에서 필요한 속도는 그렇게 크지 않다**

- - 13.5Mbps면 일반적인 사용에서는 상당히 여유가 있다.

    - 웹서핑: 충분
    - ChatGPT: 충분
    - SNS: 충분
    - 음악 스트리밍: 충분
    - 1080p 동영상: 대부분 가능
    - 화상통화: 네트워크 상태만 안정적이면 가능
    - 사진 업로드: 5.5Mbps upload면 충분
  - 그래서 실제 사용하면서 **“속도가 13Mbps밖에 안 나온다”는 느낌을 거의 받지 못했다.**
  - 오히려 항공 Wi-Fi에서는 최고 Mbps보다 **latency와 연결 안정성**이 체감 품질에 더 큰 영향을 미친다.

---

**✅ 기존 항공기 위성 인터넷과 Starlink의 가장 큰 차이**

**📌 GEO 대신 LEO를 사용한다**

- - 기존 항공 인터넷 상당수는 정지궤도(GEO) 위성을 사용했다.

|  |
| --- |
| Aircraft  ↓  약 36,000km  ↓  GEO Satellite  ↓  Ground Gateway  ↓  Internet |

- - GEO 위성은 지구에서 약 35,786km 떨어져 있기 때문에 왕복 시간이 길다.
  - Starlink는 훨씬 낮은 지구 저궤도(LEO)의 위성 constellation을 이용한다.

|  |
| --- |
| Aircraft  ↓  Starlink LEO  ↓  Starlink Network  ↓  Internet |

- - 따라서 기본적인 propagation delay 자체가 크게 줄어든다.
  - 이 때문에 단순 다운로드 속도뿐 아니라

    - 웹페이지 클릭
    - 메시지
    - ChatGPT
    - VPN
    - 실시간 애플리케이션
  - 같은 interactive traffic에서 체감 차이가 크게 난다.

**✅ 태평양 한가운데서도 인터넷이 되는 핵심 — Laser ISL**

**📌 바로 아래에 지상국이 없어도 된다**

- - 하와이와 미국 본토 사이를 비행하면 항공기 아래에는 수천 km 동안 육지가 거의 없다.
  - 그런데도 Starlink가 계속 작동한다.
  - 그 이유 중 하나가 Optical Inter-Satellite Link, 즉 위성 간 레이저 통신(ISL)이다.
  - 개념적으로는 다음과 같은 경로를 사용할 수 있다.

|  |
| --- |
| A330-200  ↓  Starlink Satellite A  ↓ Laser  Starlink Satellite B  ↓ Laser  Starlink Satellite C  ↓  Ground Gateway  ↓  Internet |

- - 즉 항공기 바로 근처에 Starlink gateway가 없어도 데이터를 여러 위성을 거쳐 육지까지 전달할 수 있다.
  - 이 구조가 항공과 해상에서 Starlink가 특히 강력한 이유다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA5MDdfMjE0/MDAxNzg4Nzc0MTA1NTYx.r4j9vtieDOS2eSvYFvIIwLdPr2YiXqipkdJOmNFVnSYg.VhJexhqfyNroN0L93uadkPjWK8qRGgDFaX0XAAB9Zr8g.PNG/image.png?type=w800)](#)

**✅ A330의 두 Starlink 안테나는 서로 다른 위성을 볼까**

**📌 항상 그렇다고 단정하면 안 된다**

- - A330-200에는 Starlink 안테나가 두 개 있지만,

    - **Terminal # 1 → Satellite A**
    - **Terminal # 2 → Satellite B**
  - 처럼 항상 서로 다른 위성에 붙는다고 공개적으로 확인된 것은 아니다.
  - 두 phased-array terminal은 비행 중 계속 위성을 추적하고 beam switching 및 handover를 수행한다.
  - 따라서 특정 순간에는 서로 다른 위성 또는 beam을 사용할 수도 있고, 네트워크 상태에 따라 다른 방식으로 자원을 사용할 수도 있다.
  - SpaceX가 dual-terminal 내부의 구체적인

    - satellite selection
    - load balancing
    - bonding
    - path selection
  - 알고리즘까지 공개하고 있지는 않다.
  - 확실하게 말할 수 있는 것은 **A330-200에 두 안테나를 설치함으로써 항공기 전체 capacity를 최대 약 1Gbps 수준까지 확대했다는 것**이다.

**✅ 그런데 Starlink에 접속했는데 왜 T-Mobile이 뜰까**

- - 처음 Wi-Fi에 연결했을 때 조금 의아했던 부분이다.
  - Starlink에 접속했는데 captive portal에 **T-Mobile**이 등장한다.
  - 결론부터 말하면, **인터넷망이 T-Mobile이라는 뜻이 아니다.**
  - Alaska Airlines와 Hawaiian Airlines는 T-Mobile과 협력해 Atmos Rewards 회원에게 Starlink Wi-Fi를 무료로 제공하는 정책을 도입했다.
  - 현재 Alaska/Hawaiian도 이를 아주 명확하게 표현한다.

    - **Free Wi-Fi thanks to T-Mobile, powered by Starlink**
  - 즉 역할을 나누면 다음과 같다.

**📌 T-Mobile**

- - 무료 Wi-Fi 제공을 지원하는 commercial partner
  - 로그인 및 captive portal experience와 연계
  - T-Mobile + Atmos 회원에게 보다 seamless한 sign-on 제공

**📌 Starlink**

- - 실제 항공기와 인터넷을 연결하는 satellite network
  - LEO satellite constellation
  - Aero Terminal
  - 위성 간 Laser ISL
  - terrestrial network 연결
  - 즉,

|  |
| --- |
| [서비스 / 인증]    Passenger  ↓  Hawaiian / Alaska Portal  ↓  Atmos Rewards / T-Mobile |

- - 와

|  |
| --- |
| [실제 Data Plane]    iPhone  ↓  Cabin Wi-Fi  ↓  Starlink Aero Terminal  ↓  Starlink Satellite  ↓  Internet |

- - 을 구분해서 볼 필요가 있다.
  - **T-Mobile은 서비스와 access 측 파트너이고, 실제 데이터를 운반하는 망은 Starlink다.**

**✅ Ping 156ms가 나온 이유는 뭘까**

- - 실제 측정에서 가장 흥미로웠던 값은 다운로드 13.5Mbps보다 오히려 **156ms latency**였다.
  - Starlink가 일반적으로 제시하는 latency보다 상당히 높다.
  - 가능한 이유는 여러 가지다.

    - 항공기가 태평양 상공에 있음
    - 위성 간 Laser ISL을 여러 번 거칠 가능성
    - terrestrial network까지의 추가 거리
    - 기내 Wi-Fi network latency
    - Google speed-test infrastructure
    - 현재 satellite/beam congestion
  - 따라서 전체 경로는 대략 다음과 같을 수 있다.

|  |
| --- |
| iPhone  ↓  Cabin AP  ↓  Starlink Aero Terminal  ↓  LEO Satellite  ↓  Laser ISL  ↓  LEO Satellite  ↓  Laser ISL  ↓  Ground Gateway  ↓  Starlink / Internet Backbone  ↓  Speed-test Server |

---

**✅ 결국 Starlink Aviation의 진짜 장점은 ‘1Gbps’라는 숫자만이 아니다**

- - 이번 비행에서 실제로 느낀 것은 최고 속도보다는 **항공기에서 인터넷을 사용하는 방식 자체가 바뀌었다는 점**이다.
  - Hawaiian A330-200에는

    - **2개의 Starlink antenna**
    - 항공기 전체 **최대 약 1Gbps peak capacity**
    - LEO satellite constellation
    - electronically steered phased array
    - satellite handover
    - Laser ISL
    - 기내 전체 Wi-Fi network
  - 가 결합돼 있다.
  - 그리고 실제 승객 한 명에게는 그 bandwidth 중 필요한 만큼이 배분된다.
  - 내가 직접 측정한 결과는 **13.5Mbps Down / 5.51Mbps Up / 156ms** 였다.
  - 숫자만 놓고 보면 엄청난 속도는 아니다.
  - 하지만 중요한 것은 **승객이 가득 찬 A330-200이 태평양 상공을 날고 있는 상황에서도 웹, SNS, 영상, ChatGPT를 큰 불편 없이 사용할 수 있었다는 것**이다.
  - 몇 년 전까지만 해도 장거리 비행은 일반인들이 쉽게 겪을 수 있는 인터넷 단절의 한 예였다.

    - "엄마 좀 있면 이륙하니까, 전화 안돼"
    - "지금부터 연락 끊기니까, 착륙하면 볼 수 있게끔, 관련 내용 이메일로 보내주세요".
  - 실제로 이번 비행에서는 재미있는 해프닝도 하나 있었다.

    - 비행 중 카카오톡으로 전화가 왔고, 상대방이 몇 시 비행기냐고 묻기에 “지금 비행기 타고 가는 중이다”라고 답했다.
    - 그런데 돌아온 말은 뜻밖에도 “입만 벌리면 구라야.”였다.
    - 결국 영상통화로 전환해 실제 기내 캐빈을 보여주고 나서야 내가 정말 비행기 안에 있다는 것을 믿었다.
  - Starlink 이후에는 기준 자체가 조금씩 바뀌고 있는 것 같다.

    - 예전에는 “왜 비행기에서는 인터넷이 이렇게 느리지?”라고 생각했다면,
    - 이제는 오히려 “비행기인데 왜 이렇게 평범하게 인터넷이 되지?”라는 생각이 먼저 든다.
