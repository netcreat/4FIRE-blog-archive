# 영국 Quantum Leap과 우주 양자 로드맵

Published: 2026-10-29T08:04:07+11:00

Original Naver post: https://blog.naver.com/4-fire/224457341737?fromRss=true&trackingCode=rss

---

**✅ £20억의 진실, 기술의 확장, 그리고 지연된 ProQure**

- - 2026년 3월 17일 영국 정부는 최대 **£2 billion(20억 파운드)**의 Quantum Leap 투자 패키지를 발표했다. 양자컴퓨터 공공조달, 양자 네트워킹, 양자 센싱·항법을 산업화하기 위한 계획이었다.

✅ 서론 2026년 3월, 영국 정부는 총 20억 파운드 규모의 양자 투자 패키지를 발표하며 하나의 명확한 목표...

- - 그리고 2026년 10월 27일에는 **Quantum Technology Roadmap for Space**가 발표됐다. 이번에는 위성 QKD, 우주용 원자시계, 양자센서, 미래 양자 네트워크가 등장했다.
  - 그렇다면 10월에 별도의 £20억 우주 예산이 추가된 것일까? 아니면 기존 예산의 사용처가 달라진 것일까? 동시에 10월 1일부터 시작했어야 할 ProQure의 선정 결과는 왜 아직 공개되지 않았을까?
  - 이번 글은 앞서 작성한 글을 바탕으로 두 공식 발표와 공모 일정을 다시 대조한 후속 분석이다.
  - **핵심 결론:** 10월 로드맵에 등장한 £20억은 3월 Quantum Leap을 명시적으로 재인용한 금액이다. 우주 기술의 개발 방향은 새롭게 구체화됐지만 **우주 전용 신규 £20억 예산은 발표되지 않았다.** 또한 ProQure의 10월 1일은 완성된 양자컴퓨터 공개일이 아니라 Phase 1 프로젝트 시작 예정일이다.

**✅ 1. 10월 발표문에 실제로 £20억이 있는가?**

**📌 정확한 원문 위치: Introduction and Context → UK Policy Context**

- - 영국 정부의 [Quantum Technology Roadmap for Space 원문](https://www.gov.uk/government/publications/quantum-technology-roadmap-for-space/quantum-technology-roadmap-for-space)에서 **UK Policy Context** 항목을 보면 다음 문장이 나온다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMjlfMjQ5/MDAxNzkzMjE5Nzc2NDc4.n_b4aAoDz27QRWV_ztS683lMhb_QYsKoFidfT1Aa03wg.95zjZsnJ8NRhp6nBlbxWUGlLalEcKipb6SjPVADlLlcg.PNG/image.png?type=w800)](#)

- - 이 문장은 단순히 £2 billion이라는 숫자만 언급한 것이 아니다. **Quantum Leap**이라는 기존 정책명과 **DSIT, 2026**이라는 출처까지 함께 제시한다.
  - 2026년 3월 17일 [Quantum Leap 공식 보도자료](https://www.gov.uk/government/news/uks-quantum-leap-tohelp-beat-diseasedeliver-high-paid-jobs-and-strengthen-national-security-as-first-country-in-the-world-to-roll-out-quantum)는 “A pioneering programme worth up to £2 billion of government investment ...”라고 발표했다.
  - 두 문서의 정책명·규모·출처·발표 시점을 교차 확인하면, **10월의 £20억은 3월 투자 패키지를 정책적 배경으로 다시 인용했다**고 판단하는 것이 타당하다.
  - 단, 엄밀히 말하면 3월 정부 발표는 **최대(up to) £2 billion**이며, 10월 문장은 £2 billion이라고 간략히 표현한다. 이 차이를 새로운 추가 재원 또는 전액 집행 완료로 해석해서는 안 된다.

|  |  |  |
| --- | --- | --- |
| **검증 항목** | **3월 Quantum Leap** | **10월 Space Roadmap** |
| 정책명 | Quantum Leap 신규 발표 | Quantum Leap 명시적 재인용 |
| 금액 | 최대 £2B | £2B 인용 |
| 담당·출처 | DSIT·HM Treasury | DSIT, 2026 |
| 돈의 성격 | 범정부 양자기술 투자·조달 | 기존 투자계획을 정책 배경으로 기재 |
| 우주용 신규 예산 | 별도 항목 없음 | 별도 항목 없음 |
| 해석 | 실행 예산의 틀 제시 | 우주용 기술 우선순위·개발경로 제시 |

- - **확인된 사실:** 10월 발표에는 우주 분야만을 위한 별도 £20억 배정 내용이 없다.
  - **확인되지 않은 사항:** 향후 우주 프로젝트 비용이 모두 기존 £20억에서 충당되는지, 또는 UK Space Agency·국방·국제협력 등 별도의 재원을 사용할지는 아직 특정할 수 없다.

**✅ 2. 두 발표는 예산·기간·성격에서 어떻게 다른가?**

|  |  |  |
| --- | --- | --- |
| **비교** | **2026년 3월 Quantum Leap** | **2026년 10월 Space Roadmap** |
| 발표일 | 2026-03-17 | 2026-10-27 |
| 문서 성격 | 투자·조달 계획 발표 | 미션 중심 기술·산업 로드맵 |
| 예산 | 최대 £2B | 신규 확정 예산 미공개 |
| 핵심 기간 | 향후 4년 및 2030년대 초 조달 | 0~5년, 5~10년, 10~15년(약 2040년까지) |
| 주요 목표 | 양자컴퓨터 구축, 공급망 육성, 양자기술 상용화 | 우주용 양자 탑재체의 인증·궤도 실증·운영 서비스 |
| 양자컴퓨팅 | ProQure를 통한 경쟁형 개발·검증 | 주로 지상에서 우주 응용 계산 지원 |
| 양자 네트워킹 | 부품·서브시스템의 개발과 공급망 | 위성 링크 및 장기적인 얽힘 네트워크 |
| 센싱·항법 | 다양한 산업 분야 적용 | 우주 원자시계, 관성센서, 자력계, 중력계 |
| 실제 계약 | 공모 및 조달 절차 존재 | 이 문서 자체는 계약 공고가 아님 |

- - **3월 발표**는 국가가 어떤 기술에 얼마를 투자하고 어떻게 기업을 선별할지에 무게를 둔다.
  - **10월 발표**는 그 기술이 위성 플랫폼에서 실제로 동작하려면 어떤 추가 하드웨어·시험·인증이 필요한지 설명한다.
  - 따라서 양자 전략의 적용 범위를 우주까지 구체화했다는 의미는 있지만, 그것만으로 **예산 증액이나 조달 개시**를 확정할 수는 없다.

**✅ 3. 기존 £20억 예산의 실제 구성**

- - 3월 정부 발표는 대규모 양자컴퓨터의 **후속 공공조달 최대 £1B**와 향후 4년 동안의 **양자기술 연구개발·인력·시설 지원 £1B 초과**를 함께 설명한다.
  - 아래 항목은 서로 다른 상위·하위 예산이 섞여 있어 단순 합산하면 중복 계산이 된다. 특히 £125M와 £205M는 더 큰 투자 패키지에 속한 세부 항목이다.

|  |  |  |
| --- | --- | --- |
| **예산 항목** | **발표 규모** | **우주 로드맵과의 관련성** |
| 대형 양자컴퓨터 공공조달 | 최대 £1B | 위성군 최적화 등 지상 계산 응용과 간접 연계 |
| 양자기술 R&D·인력·시설(상위 묶음) | £1B 초과 / 향후 4년 | 네트워킹·센싱 등의 여러 하위 투자 포함 |
| 양자컴퓨팅 개발 | £500M 초과 | 양자컴퓨팅 시스템과 알고리즘 |
| 양자 네트워킹 | £125M | 광자 소스·검출기·메모리·양자 인터페이스 |
| 양자 센싱·항법 | £205M | 양자시계·관성항법·중력계·자력계 |
| 인프라 확대 지원 | 추가 £90M | 시험설비·제조역량 등과 잠재적 연계 |
| 우주 양자기술 전용 | 별도 금액 없음 | 위성 QKD·우주용 시계·궤도 실증 배정액 미공개 |

- - 금액과 항목의 근거는 [2026년 3월 17일 발표의 Notes to editors](https://www.gov.uk/government/news/uks-quantum-leap-tohelp-beat-diseasedeliver-high-paid-jobs-and-strengthen-national-security-as-first-country-in-the-world-to-roll-out-quantum)다.
  - 특히 네트워킹 £125M 전체가 위성 QKD용이거나, 센싱·항법 £205M 전체가 우주 원자시계용인 것은 아니다.
  - 4월에 개설된 [Commercial Quantum Networking 공고](https://www.ukri.org/opportunity/contracts-for-innovation-enabling-commercial-quantum-networking/)의 실제 모집 재원은 **총 £20M**이었다. 이것은 국가 차원의 £125M 네트워킹 분야와 구분되는 개별 공고 규모다.
  - 10월 로드맵은 우주 기술의 필요성을 제시하지만 위 항목 중 얼마를 우주 기술에 할당한다고 새롭게 정하지 않는다.

**✅ 4. 사실 우주 양자 네트워크는 2026년 처음 등장한 것이 아니다**

|  |  |  |
| --- | --- | --- |
| **시점** | **정책·사업** | **우주 관련 의미** |
| 2023년 3월 | National Quantum Strategy | 양자기술의 10년 국가 전략 출발 |
| 2023년 12월 | National Quantum Strategy Missions | 2035년 대규모 양자 네트워크와 위성 국제연결 목표 명시 |
| 2025년 11월 | SpeQtre 발사 | 영국 정부 £7M 지원 우주 QKD 실증 |
| 2026년 3~4월 | Quantum Leap / ProQure / 네트워킹 공고 | 예산·후속 조달·기술 공급망 육성 구체화 |
| 2026년 10월 | Quantum Technology Roadmap for Space | 우주용 하드웨어·검증·인프라 개발 경로 구체화 |

- - [2023년 National Quantum Strategy Missions](https://www.gov.uk/government/publications/national-quantum-strategy/national-quantum-strategy-missions)의 Mission 2는 **2035년까지 대규모 양자 네트워크를 배치**하고, 국제 양자 네트워크를 **위성 링크(satellite links)**로 연결한다는 목표를 이미 제시했다.
  - [UKRI의 2025년 11월 28일 발표](https://www.ukri.org/news/satellite-launch-to-test-unhackable-quantum-communications-tech/)에 따르면 SpeQtre 위성도 £7M의 영국 정부 자금 지원을 받아 발사됐다. 이는 2026년 10월 문서 이전부터 우주 QKD 실증이 추진됐다는 사례다.
  - 따라서 **3월 보도자료에 우주 전용 예산이 없었다**는 관찰과, **영국 국가 전략에 위성 양자 네트워크가 이전부터 포함돼 있었다**는 사실은 모순이 아니다.
  - 10월 발표의 새로움은 위성 양자 네트워크라는 아이디어 자체가 아니라, 그 목표를 달성하기 위한 비행 인증과 공급망·통합 단계까지 구체적으로 다룬 데 있다.

**✅ 5. 기술 비교: 10월에 구체적으로 추가된 것은 무엇인가?**

|  |  |  |
| --- | --- | --- |
| **분야** | **3~4월 개발·조달 초점** | **10월 우주 적용의 구체적 과제** |
| Quantum Computing | QPU·풀스택·운영 테스트베드 | 지상 기반 위성군 최적화·시뮬레이션 |
| Quantum Networking | 광자 소스·검출·메모리·인터페이스 | 위성 광링크·얽힘 분배·네트워크 통합 |
| QKD | 보안 네트워킹 관련 기술·부품 | 위성–지상 QKD, 기존 광통신과 Hybrid Optical Payload |
| PQC | 양자내성 전환이라는 범용 목표 | 위성 명령 인증·Secure Boot·위성 간 링크 |
| Optical Clock | 정밀 시간·항법 | 우주용 광학시계·소형 레이저·주파수 콤 |
| Quantum Time Transfer | 초정밀 동기화 연구 | 위성 간·지상 간 정밀 시간 전달과 궤도 실증 |
| Quantum Sensing | 의료·국방·인프라·항법 센싱 | 냉각 원자 관성센서·자력계·중력계·Rydberg RF |
| Space Qualification | 일반 산업용 성능·프로토타입 평가 | 방사선·진동·진공·열·SWaP·수명 검증 |

- - 우주 로드맵은 세 가지 시간 구간을 제시한다. **0~5년은 부품 개발·지상 검증, 5~10년은 선택적 궤도 실증, 10~15년은 반복 공급과 운영 확대**에 초점을 맞춘다.
  - 이 시점들은 확정된 납품일이 아니라 기술성숙도에 따른 계획의 범위다.
  - 예를 들어 기존 OCT(Optical Communication Terminal)의 광통신 실적이 있어도 단일광자 수준 QKD를 지원한다고 단정할 수 없다. 광자 검출, 잡음 제어, 지향·획득·추적(PAT), 링크 가용성 등을 별도로 검증해야 한다.
  - 위성 QKD가 성공해도 양자메모리와 얽힘 스와핑을 이용한 글로벌 양자 인터넷이 완성됐다는 뜻은 아니다.
  - 이 부분에서 특히 주목할 표현은 Hybrid Optical Payloads이다.

    - 기존 레이저 통신 장비가 고속 데이터를 전송하면서 동일한 위성 플랫폼에서 QKD를 지원하는 구조를 의미하는데, 이는 최는 AFRL에서 후속 자금을 확보하면서 발표된 Free-Space Optical Link와 연결된다.

- - 영국 사이버보안 당국(NCSC)는 2025년 8월 공식 문서 [Quantum networking technologies](https://www.ncsc.gov.uk/paper/quantum-networking-technologies)에서 정부 및 군사 애플리케이션에 대한 QKD 사용을 지원하지 않는다는 입장을 명확히 밝혔고, 2026년 6월 DSIT가 공개한 [QKD 연구 보고서](https://www.gov.uk/government/publications/quantum-key-distribution-research-report)에서도 이 입장을 다시 명시했다. 이는 미국 국방부와 동일한 입장이다.

    - UK Space Agency는 QKD 실증을 통해 미래 우주 양자 네트워크를 구축할 산업 역량을 확보하려는 것이다. 반면 NCSC는 기존 정보 시스템의 보안 문제를 해결하는 데 QKD가 PQC보다 충분한 추가 가치를 제공하는지 회의적이다.
    - 즉, 영국이 위성 QKD 개발을 지원하는 것과 영국 정부가 QKD를 국가기밀 통신 보호 수단으로 채택하는 것은 별개의 결정이다.

**✅ 6. 그런데 ProQure는 원래 10월 1일 시작하기로 하지 않았는가?**

- - 그렇다. [ProQure Phase 1 공식 공고의 Dates / Eligibility](https://apply-for-innovation-funding.service.gov.uk/competition/2439/overview/06423ffe-b763-4cac-b83b-f80208dfe2f2#dates)에는 프로젝트가 **2026년 10월 1일에 시작**하고 **2028년 9월 30일까지 종료**해야 한다고 명시돼 있다.
  - 다만 이는 **Phase 1 개발 프로젝트의 계약상 시작 예정일**이다. 10월 1일에 완성된 양자컴퓨터를 공개하거나 최종 국가 공급자를 발표한다는 약속은 아니다.
  - Phase 1은 최대 10개 기업의 풀스택 양자컴퓨터 개발·운영 테스트베드 검증을 위한 혁신 계약이며, 지금 단계에서 완성 시스템을 구매하는 조달이 아니다.

- - 지원자 통보일은 공개 공고를 검색·수집하는 시점에 따라 8월 11일과 9월 3일 두 표기가 확인됐다. 변경 이유와 개인별 실제 통보 날짜는 확인되지 않았으므로 하나를 최종 완료일로 단정하지 않는다.
  - 계약 수여 예정일(9월 17일)과 프로젝트 시작 예정일(10월 1일)은 공고에서 분명히 제시된 기준일이다.
  - 실제 계약 승인 전에 임의로 프로젝트를 시작할 수 없으며, Innovate UK의 승인을 받아야 한다는 조항도 공고에 포함된다.

**✅ 8. IonQ의 영국 전략과 연결하면**

- - 4월 글에서는 Oxford Ionics를 중심으로 영국의 대형 양자컴퓨터 조달을 분석했다. 10월 우주 로드맵은 그 외 기술 포트폴리오가 어떤 우주 응용과 연결될 수 있는지 보여준다.
  - 아래 표는 기술과 로드맵의 연관성을 살펴본 **분석적 대응**이며, 영국 정부가 해당 기업을 수주기업으로 선정했다는 뜻이 아니다.

|  |  |  |
| --- | --- | --- |
| **IonQ 관련 기술·기업** | **3~4월 정책과의 접점** | **10월 우주 로드맵과의 접점** |
| Oxford Ionics / IonQ QPU | ProQure의 풀스택 양자컴퓨팅 | 지상에서의 위성군·궤도·통신 최적화 응용 |
| Qubitekk·Lightsynq | 양자네트워킹 부품·양자 인터페이스 | 장기적인 위성 얽힘 분배·양자메모리 |
| ID Quantique | QKD·단일광자 검출 관련 역량 | 위성 QKD 링크와 양자 광학장비 |
| Skyloom | 공고와 직접적 접점은 제한적 | 우주 광통신 OCT·PAT·광학 통합 |
| Vector Atomic | 정밀 시간·항법·센싱 | 우주용 시계·PNT·시간 동기화 |
| Capella Space | 직접적인 공고 대상은 아님 | 위성 플랫폼·임무 통합의 잠재적 연결 |

- - 특히 **Skyloom의 광통신 실적 = 위성 QKD의 완성**은 아니다. 또 **Qubitekk·Lightsynq의 지상 얽힘 기술 = 글로벌 우주 양자 네트워크 상용화**도 아니다.
  - 영국 정부의 실제 계약과 연결하려면 공급망 등록, 우주 인증, 궤도 실증 계약, 성능 검증 결과를 별도로 확인해야 한다.
  - 반대로 ProQure 선정 기업 공개가 지연됐다고 해서 Oxford Ionics/IonQ가 탈락했거나 선정됐다고 추론할 수도 없다.
  - 결국 두 발표는 IonQ의 서로 다른 사업영역과 관련성을 갖지만, 실제 수주 확정은 **개별 계약 공고와 수여 결과**로 판단해야 한다.

**✅ 9. 결론: 영국의 양자 전략은 돈을 늘린 것인가, 적용 범위를 넓힌 것인가?**

- - **첫째, £20억은 두 번 발표된 별개의 예산이 아니다.** 10월 로드맵이 3월 Quantum Leap과 DSIT(2026)을 직접 언급하므로 동일 정책 재인용이라는 판단에 명확한 근거가 있다.
  - **둘째, 10월 발표는 의미 없는 반복이 아니다.** 기존 국가 양자전략의 우주 관련 목표를 구체적 기술·인증·실증 경로로 발전시켰다.
  - **셋째, 영국의 우주 양자 전략은 2026년에 갑자기 시작된 것이 아니다.** 2023년 Mission 2의 위성 국제 연결 목표와 2025년 SpeQtre가 선행한다.
  - **넷째, ProQure는 기존 일정상 10월 1일에 개발을 시작해야 했다.** 그러나 그날은 완성 컴퓨터 공개일이 아니며, 10월 19일 의회 답변은 계약 수여 절차의 진행 상태를 재점검할 필요가 있음을 보여준다.
  - **다섯째, 앞으로 가장 중요한 것은 금액을 재인용하는 보도자료가 아니라 실제 계약이다.** Phase 1의 최종 기업 명단과 계약 체결일, 그리고 위성 QKD·우주 원자시계·양자 네트워크 분야의 별도 공고가 나와야 기술 로드맵이 매출 가능한 시장으로 구체화됐다고 볼 수 있다.
  - 지금까지 영국이 보여준 일관된 방향은 **컴퓨팅은 단계형 조달, 네트워킹은 부품 공급망 육성, 센싱은 응용·실증, 우주는 이 세 기술을 우주 시스템으로 전환하는 장기적 통합 경로**라는 것이다.
