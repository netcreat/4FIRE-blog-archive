**✅ 1. EUV 없이 최첨단 반도체를 만들 수 있을까?**

- - 최근 일론 머스크의 Terafab이 반도체 산업에서 다시 주목받고 있다.
  - 특히 Terafab이 기존 EUV 노광 방식의 한계를 어떻게 극복할 것인지가 관심사다.
  - 다만 2026년 10월 7일 머스크가 Terafab에서 EUV를 전면 배제한다고 공식 발표했다는 사실은 확인되지 않는다.
  - 최근 확인된 발표는 Tesla와 SpaceX가 Terafab을 직접 건설·운영하고 TSMC는 일부 시설을 임차할 수 있다는 내용이다.
  - 머스크가 앞서 관심을 보인 FEL(Free-Electron Laser) 역시 EUV 자체를 없애는 것이 아니라 EUV 광원을 바꾸는 접근법이다.
  - 그런데 여기서 더욱 흥미로운 기업이 등장한다.
  - 바로 **Kepler Computing**이다.

    - Kepler는 EUV 광원을 개선하려는 회사가 아니다.
    - 아예 EUV에 의존하지 않고 새로운 소재와 3차원 집적으로 높은 메모리 밀도를 구현하겠다는 회사다.
    - 특히 GlobalFoundries(GF)가 직접 투자하고 제조 파트너로 참여했다는 점이 눈길을 끈다.
  - 이번 글에서는 다음 질문을 살펴본다.

    - Kepler는 어떤 사람들이 설립한 기업인가?
    - EUV 없이 어떻게 최첨단 공정 수준의 메모리 밀도를 만들겠다는 것인가?
    - Ferroelectric Memory는 기존 FRAM과 무엇이 다른가?
    - 28nm CMOS와 3D stacking은 어떻게 결합되는가?
    - SRAM과 HBM을 실제로 대체할 수 있는가?
    - GF는 왜 5,000만 달러를 직접 투자했는가?
    - Kepler는 정말 HVM(High-Volume Manufacturing)에 도달할 수 있을까?
    - Tesla·SpaceX의 Terafab과 협력할 가능성은 얼마나 될까?
    - 성공한다면 ASML과 EUV 중심의 반도체 공급망에는 어떤 변화가 생길까?

**✅ 4. EUV 없이 어떻게 Leading-Edge Density를 만든다는 것인가?**

**📌 기존 반도체 산업의 방식 — XY Scaling**

- - 전통적인 반도체 발전은 트랜지스터를 더 작게 만드는 방향으로 진행됐다.

    - 28nm → 14nm → 7nm → 5nm → 3nm → 2nm로 진화해 왔다.
  - 이러한 미세화는 같은 면적에 더 많은 트랜지스터를 배치할 수 있게 한다.
  - 그러나 공정이 미세해질수록 노광, 식각, 증착 및 검사 과정의 복잡성이 커진다.
  - DUV로도 다중 패터닝을 통해 상당한 미세화가 가능하지만, 복잡성과 비용이 증가한다.
  - 이에 최첨단 공정에서는 EUV의 중요성이 매우 높아졌다.

**📌 Kepler의 방식 — Cell Architecture + Material + Z Scaling**

- - Kepler는 완전히 다른 접근법을 제시한다.

    - 더 작은 트랜지스터를 만드는 대신 메모리 셀 구조를 바꾼다.
    - 새로운 비선형 분극 소재를 사용한다.
    - 수직 방향으로 메모리 소자를 집적한다.
    - 칩 사이를 3D Integration으로 더 가깝게 연결한다.
    - 이러한 공정을 기존 CMOS 제조시설에 추가한다.
  - 따라서 Kepler가 28nm 공정으로 고밀도 메모리를 만든다고 할 때 중요한 것은 실제 트랜지스터 선폭이 아니다.
  - **단위 면적당 얼마나 많은 유효 메모리 기능을 구현할 수 있는가**가 핵심이다.

  - 또한 28nm 공정에 새로운 기술을 적용하면 트랜지스터 자체가 실제 7nm로 작아진다는 의미도 아니다.
  - 노드 이름은 실제 최소 선폭이나 메모리 성능을 직접적으로 표시하는 단위가 아니기 때문에, 이러한 등가 비교에는 특히 주의해야 한다.

    - **28nm Transistor Performance ≠ 7nm Transistor Performance**
  - 그러나 특정 메모리 구조의 유효 밀도에서는 새로운 소재와 3D 기술로 그 격차를 줄일 가능성이 있다는 것이다.

**✅ 5. 첫 번째 핵심 기술 — Ferroelectric Memory**

**📌 Ferroelectric은 무엇인가?**

- - Ferroelectric은 강유전체를 의미한다.
  - 강유전체는 외부 전기장에 따라 내부 전기분극의 방향이 변하고, 전기장을 제거해도 일정한 분극 상태를 유지할 수 있다.
  - 이를 0과 1의 정보 저장에 활용할 수 있다.
  - 일반적인 DRAM은 커패시터에 저장된 전하를 이용한다.
  - 일반적인 SRAM은 트랜지스터로 구성된 래치 회로에 정보를 저장한다.
  - 강유전체 메모리는 분극 상태를 이용하므로 비휘발성 메모리 구현이 가능하다.

**📌 SRAM과 무엇이 다른가?**

- - 가장 널리 사용되는 SRAM 메모리 셀은 일반적으로 6개의 트랜지스터를 사용하는 6T 구조다.

    - 6T SRAM은 빠르고 반복적인 읽기·쓰기에 적합하다.
    - 그러나 한 비트를 저장하는 데 필요한 회로 면적이 상대적으로 크다.
  - Kepler는 이러한 면적 문제를 기존과 다른 소재 및 셀 구조로 해결하려 한다.
  - 반면 강유전체 기반 메모리는 저장 기능을 분극 소재와 커패시터 구조에 맡길 수 있다.
  - 일부 회로에서는 SRAM보다 적은 트랜지스터로 높은 저장 밀도를 구현할 수 있다.
  - 하지만 이것이 곧 모든 강유전체 메모리가 SRAM보다 빠르거나 작다는 것을 뜻하지는 않는다.
  - 선택소자, 센싱 회로, 읽기 방식, 배선, 내구성까지 포함한 전체 셀 설계가 중요하다.

**📌 Kepler는 단순한 FRAM 업체가 아니다**

- - 기존 FRAM 또는 FeRAM은 강유전체를 사용하는 대표적인 메모리 기술이다.
  - 하지만 Kepler의 특허들을 살펴보면 FeRAM이라는 특정 제품 유형에만 국한되지 않는다.
  - 오히려 **Non-linear Polar Material**이라는 넓은 개념을 반복적으로 사용한다.
  - 이 때문에 Kepler가 사용하는 정확한 소재와 셀 구조를 일반적인 1T1C FeRAM으로 단정하기는 어렵다.

**✅ 6. Kepler 특허가 보여주는 실제 기술 방향**

**📌 1T1C와 1TnC 구조**

- - Kepler의 특허에는 1T1C뿐 아니라 1TnC 구조가 등장한다.

    - 1T1C는 하나의 트랜지스터와 하나의 커패시터를 결합하는 방식이다.
    - 1TnC는 하나의 트랜지스터에 여러 개의 커패시터를 결합하는 구조를 의미한다.
  - 이러한 기술은 복수의 저장소자를 효율적으로 연결하거나 읽기·쓰기 회로를 공유하는 데 활용할 수 있다.
  - 다만 1TnC라고 해서 무조건 n개의 커패시터가 n개의 독립적인 비트를 저장한다는 의미는 아니다.
  - 실제 저장 비트 수는 회로구성, 상태 수, 읽기 방식, 센싱 마진에 따라 달라진다.

| **특허** | **주요 내용** | **기술적 의미** |

    - 저장소자당 필요한 회로 면적을 줄인다.
    - 여러 커패시터와 트랜지스터를 새로운 방식으로 연결한다.
    - 강유전체 계열 소재를 메모리뿐 아니라 논리연산에도 활용한다.
  - 특히 Low-Power Multiplier 특허는 Kepler가 처음부터 메모리 사업에만 머무를 생각이 없었음을 보여준다.
  - 하지만 특허에 포함된 구조가 모두 실리콘에서 검증됐거나 양산 중이라는 뜻은 아니다.
  - 실제 상용화 대상은 아직 확인이 필요하다.

**✅ 7. 35번의 복합소재 개발 — Kepler의 두 번째 차별점**

**📌 기존 HZO FeRAM과 동일한가?**

**✅ 8. 두 번째 핵심 기술 — 3D Stacking**

**📌 단순히 HBM처럼 칩을 쌓는 것이 아니다**

- - Kepler의 3D 기술은 크게 두 영역으로 구분할 필요가 있다.
  - 첫 번째는 Device-Level 3D다.

    - 기존 CMOS 트랜지스터 위에 새로운 메모리 소자를 적층한다.
    - XY 방향으로 트랜지스터를 계속 축소하지 않아도 저장소자의 수를 늘릴 수 있다.
    - 이 과정에서 신소재, 전극, 커패시터 및 배선 공정의 호환성이 중요하다.
  - 두 번째는 Die-Level 또는 Package-Level 3D다.

    - 별도로 제조한 칩을 수직으로 연결한다.
    - Compute Die와 Memory Die를 더 가깝게 배치한다.
    - 많은 수의 짧은 인터커넥트를 구현할 수 있다.
    - 데이터 이동에 필요한 에너지와 지연시간을 줄일 가능성이 있다.

**📌 밀도 향상의 원리**

- - 단순화하면 메모리의 유효 밀도는 다음 요소의 영향을 받는다.

    - **Effective Density ≈ (셀당 저장 비트 수 × 유효 적층 층수 × 면적 효율) / 단층 셀 면적**
  - 예를 들어 동일한 footprint에서 메모리 층수를 8개로 늘릴 수 있다면 이론적으로 저장 용량을 크게 증가시킬 수 있다.
  - 그러나 주변 회로, 배선, 선택소자, 오류정정 및 제조 결함으로 인해 실제 유효 밀도는 단순히 8배가 되지 않는다.
  - 따라서 몇 층을 쌓았느냐보다 실제로 얼마나 많은 양품 비트를 구현했는지가 중요하다.

**📌 Kepler의 특허에서는 Wafer Bonding도 등장한다**

- - US12446231B1은 비선형 분극 소재가 들어간 커패시터를 웨이퍼 본딩으로 트랜지스터와 결합하는 제조 방법을 설명한다.
  - 별도로 형성한 메모리와 트랜지스터 구조를 접합한 다음 전기적으로 연결하는 방식이다.
  - 관련 특허군에는 적층 커패시터와 Hybrid Bonding 기반 집적 방법도 등장한다.
  - 이러한 접근은 메모리 소재에 필요한 열처리 조건과 로직 트랜지스터의 공정 조건을 분리하는 데도 도움이 될 수 있다.
  - 다만 실제 Kepler 제품이 어느 형태의 본딩을 채택할지, 적층 층수가 얼마인지는 공개된 자료만으로 확정할 수 없다.

**✅ 9. 세 번째 핵심 — Advanced Packaging과 데이터 이동**

**📌 AI의 문제는 연산만이 아니다**

- - AI 가속기에서 전력과 성능을 제한하는 중요한 요소 중 하나는 메모리와 프로세서 사이의 데이터 이동이다.
  - 수많은 가중치와 활성화 데이터를 반복적으로 이동시켜야 한다.
  - 메모리 대역폭이 부족하면 연산기가 충분한 성능을 내지 못한다.
  - 데이터를 멀리 이동시키면 전력소모도 증가한다.
  - Kepler는 메모리를 연산기에 더 가깝게 배치하고, 더욱 많은 수의 짧은 연결을 구현하려 한다.
  - 이는 단순히 메모리 용량을 늘리는 것과는 다른 차원의 개선이다.

**📌 칩을 가깝게 붙이면 왜 전력이 줄어드는가?**

- - 배선의 전압 스윙과 용량이 동일하다는 단순한 조건에서 데이터 전송에 필요한 동적 에너지는 대략 정전용량과 전압 제곱에 비례한다.
  - 따라서 신호가 이동하는 거리를 줄여 배선 용량을 낮출 수 있다면 전력 절감의 여지가 생긴다.
  - 실제로는 드라이버, 리시버, 클록, 버퍼, 반복기 등의 회로 전력도 함께 고려해야 한다.
  - Kepler는 여기서 한 단계 더 나아간다.
  - 장기적으로는 기존 CMOS보다 훨씬 낮은 전압에서 동작하는 새로운 Gain Element 또는 논리소자까지 개발하려 한다.
  - Act II에서는 300mV 미만, 이상적으로는 100mV 이하의 동작 전압을 기술적 지향점으로 언급한다.
  - 이는 메모리 자체의 문제를 넘어 새로운 Logic Device까지 개발하겠다는 의미다.

**✅ 12. Kepler의 Fablet — 기존 팹을 업그레이드한다**

**📌 새로운 첨단 팹을 처음부터 건설하지 않는다**

- - Kepler는 기존 반도체 제조시설에 자체 제조 모듈을 추가하는 개념을 제안한다.
  - 회사는 이를 Fablet이라고 표현한다.
  - 기존 CMOS 공정을 그대로 활용하면서 새로운 소재와 3D 제조공정을 추가하는 방식이다.

**📌 Fablet의 의미**

- - 기존 팹은 CMOS 트랜지스터를 만든다.
  - Kepler의 추가 공정은 새로운 메모리 소재와 구조를 구현한다.
  - 이후 메모리·로직 통합 및 패키징을 수행한다.
  - 이를 통해 EUV 기반 신규 첨단 공장을 건설하는 부담을 줄이겠다는 구상이다.

**📌 GF와의 초기 공정 전환**

- - WIRED 보도에 따르면 Kepler는 GF와의 초기 구축 과정에서 약 8개월 만에 차세대 공정을 구현했다고 설명했다.
  - 일반적인 신규 공정 구축의 약 24개월과 비교한 주장이다.
  - 그러나 이 숫자를 GF의 전체 28nm 팹이 단 8개월 만에 완전히 다른 양산시설로 전환됐다는 의미로 해석해서는 안 된다.
  - 초기 기술 통합과 상업적 HVM은 서로 다른 단계다.

**📌 설비투자비를 10분의 1로 줄일 수 있을까?**

- - Kepler는 기존 팹을 업그레이드하면 신규 첨단 공장 건설 대비 약 10분의 1 수준의 CAPEX로 제조능력을 확보할 수 있다고 주장한다.
  - 그러나 이는 회사가 제시한 제조경제성 목표다.
  - 실제 생산원가가 자동으로 90% 감소한다는 뜻은 아니다.
  - 추가 소재 비용, 전용 장비, 검사, 수율, 재작업, 패키징 및 감가상각을 모두 고려해야 한다.
  - 그럼에도 이 접근법이 실현된다면 GF와 같은 기존 팹 운영사에는 매우 매력적인 사업모델이 될 수 있다.

**✅ 13. GF는 Kepler 외에도 새로운 메모리를 준비하고 있다**

**📌 RAAAM의 GCRAM**

- - 2026년 9월 2일 GF는 RAAAM Memory Technologies와 새로운 GCRAM(Gain-Cell RAM) 공동개발을 발표했다.
  - GF의 FDX 플랫폼에서 테스트 칩 Tape-out을 완료했다고 밝혔다.
  - 일반적인 SRAM 대비 면적 40% 감소, 소비전력 최대 60% 감소를 목표로 한다.

**📌 Kepler와 RAAAM은 같은 기술이 아니다**

|  |  |  |
| --- | --- | --- |
| **비교** | **Kepler** | **RAAAM** |
| 접근법 | 강유전체·신소재 및 3D | Gain-Cell CMOS |
| 공정 전략 | 기존 팹에 신소재 공정 추가 | 기존 CMOS 플랫폼 활용 |
| 초기 시장 | AI 메모리, SRAM/HBM 및 중간 계층 | 온칩 SRAM 대체·보완 |
| GF의 역할 | 지분 투자 및 제조 파트너 | 기술 공동개발 |
| 핵심 검증 과제 | 신소재·적층 수율 | GCRAM 성능·고객 인증 |

- - 두 회사는 SRAM의 면적과 전력 문제를 해결한다는 점에서 일부 경쟁하지만 사용하는 기술은 다르다.
  - GF는 한 종류의 차세대 메모리에 모든 것을 거는 대신 여러 기술을 병행하고 있다.
  - 따라서 케플러가 성공한다면 GF의 Specialty Foundry 전략을 더욱 강화하는 하나의 중요한 축이 될 수 있다.

**✅ 15. 테라팹과 Kepler는 실제로 연결될 수 있을까?**

**📌 Terafab의 목적**

- - Tesla와 SpaceX가 추진하는 Terafab은 장기적으로 연간 1TW 규모의 AI 컴퓨팅 하드웨어 생산을 목표로 하는 프로젝트다.
  - 핵심 구상은 반도체 설계, Logic, Memory, Advanced Packaging을 수직적으로 통합하는 것이다.
  - 주요 수요는 Tesla의 자율주행·Optimus와 SpaceX의 우주 기반 AI 컴퓨팅이다.
  - 실제 건설과 생산규모, 제조 파트너의 역할은 아직 변화할 수 있다.

**📌 Kepler와 방향성이 맞는 이유**

- - Terafab은 막대한 AI 컴퓨팅 생산능력을 확보하려 한다.
  - Kepler는 AI 메모리 생산에 필요한 초기 설비투자와 전력소모를 줄이려 한다.
  - **양측 모두 기존 반도체 산업의 제조경제성을 개선하려는 목적을 가지고 있다.**
  - 특히 Kepler의 기술이 실제로 기존 28nm 팹에서 고밀도 AI 메모리를 생산할 수 있게 한다면 Terafab은 메모리 공급의 추가 선택지를 확보할 가능성이 있다.

**📌 시나리오 1 — GF에서 생산한 Kepler 메모리 공급**

- - 가장 현실적인 초기 협력 후보로 평가한다.

    - Kepler가 GF에서 메모리를 제조한다.
    - Tesla 또는 SpaceX가 이를 별도의 평가 과정을 거쳐 AI 시스템에 도입한다.
    - Terafab이 신소재 제조공정을 직접 설치하지 않아도 된다.
  - 이 경우 제품 성능과 공급망 안정성을 먼저 검증할 수 있다.
  - 다만 양측 사이의 공급계약이나 고객 평가가 진행되고 있다는 공개 근거는 아직 없다.

**📌 시나리오 2 — Terafab 내부에 Kepler Fablet 설치**

- - 장기적으로는 더 흥미로운 시나리오다.
  - Terafab이 기존 CMOS 제조공정을 운영한다.

    - 여기에 Kepler의 신소재 및 적층 메모리 공정을 추가한다.
    - 같은 제조단지에서 Logic, Memory, Packaging을 통합한다.
    - 이 방식은 Terafab의 수직통합 전략과 잘 맞는다.
  - 그러나 GF에서 검증한 공정을 다른 팹에 이전하는 데는 상당한 기술적 위험이 있다.
  - 장비, 공정조건, 웨이퍼, 오염관리 및 수율을 다시 검증해야 한다.
  - 따라서 가능성이 있다고 해서 단기간에 실현할 수 있는 구조는 아니다.

**📌 시나리오 3 — HBM과 SRAM 사이의 새로운 AI 메모리**

- - 초기 상용화 관점에서 가장 주목할 만한 기술적 활용 모델이다.
  - 기존 HBM을 완전히 제거하지 않고 Kepler의 고밀도 메모리를 추가한다.
  - 모델 데이터나 추론용 중간 데이터를 더 효율적으로 저장한다.
  - GPU와 메모리 사이의 데이터 이동과 시스템 전력소모를 줄인다.
  - 이 경우 HBM4 이상의 모든 성능을 처음부터 대체할 필요가 없다.
  - 특정 AI 워크로드에서 비용 대비 성능이 뛰어나다는 것만 입증해도 시장성이 생길 수 있다.

**📌 시나리오 4 — SpaceX의 우주 기반 AI**

- - 우주 컴퓨팅에서는 전력, 발열, 크기, 질량 및 방사선에 대한 신뢰성이 중요하다.
  - Kepler의 높은 메모리 밀도와 낮은 에너지 소비 목표는 이러한 환경에서 매력적일 수 있다.
  - 그러나 비휘발성 강유전체 메모리라고 해서 자동으로 방사선 내성이 보장되는 것은 아니다.
  - 실제 우주 환경 적용을 위해서는 별도의 검증이 필요하다.

**📌 협력 가능성 종합 판단**

|  |  |  |
| --- | --- | --- |

- - 여기서 기술적 적합성이 높다는 것은 협력 확률이 높다는 의미가 아니다.
  - 현재 공개자료로는 Kepler와 Tesla·SpaceX·Terafab 사이의 직접적인 계약을 확인할 수 없다.
  - 따라서 협력은 어디까지나 산업 구조를 바탕으로 한 가설이다.

**✅ 16. Terafab과 Kepler가 EUV를 대하는 방식은 다르다**

**📌 머스크의 FEL은 EUV를 없애는 기술이 아니다**

- - 머스크가 관심을 보인 FEL은 Free-Electron Laser를 뜻한다.
  - 현재 ASML의 EUV 장비는 레이저를 이용해 주석 플라스마에서 EUV 광을 만들어내는 LPP 방식에 의존한다.
  - FEL은 고에너지 전자빔과 자기장 구조를 이용해 고에너지 광을 생성하는 다른 방식이다.
  - 만약 FEL을 EUV 광원으로 사용한다면 광원을 만드는 방식이 달라지는 것이지 EUV 노광 자체가 사라지는 것은 아니다.
  - 아직 Terafab이 FEL-EUV를 실제 양산 공정으로 도입한다는 확정 발표도 확인되지 않는다.

**📌 Kepler는 정말 EUV 미세화에 대한 의존도를 낮춘다**

- - Kepler는 기존 CMOS 위에 새로운 메모리 소자를 쌓고, 3D 집적을 활용해 유효 밀도를 높이려 한다.
  - 따라서 적어도 목표로 하는 메모리에서는 최신 EUV 공정을 사용하지 않고도 경쟁력 있는 밀도를 구현하겠다는 것이다.
  - 두 접근법의 차이는 명확하다.

    - **Terafab/FEL:** EUV 광원과 제조 인프라의 병목을 다른 방식으로 해결할 가능성
    - **Kepler:** 새로운 소재와 3D 집적으로 EUV 미세화 자체를 우회
    - **GlobalFoundries:** 기존 제조시설에 새로운 기술을 통합해 부가가치를 확대
  - 현재 확인된 사실과 장기 기술 목표를 구분한다면 이 세 가지 전략은 서로 경쟁하기보다 보완적으로 발전할 가능성도 있다.

**✅ 17. 성공한다면 ASML 중심의 반도체 지정학에 어떤 변화가 생길까?**

**📌 ASML의 EUV 독점이 당장 무너지는 것은 아니다**

- - 최첨단 CPU와 GPU의 고성능 로직 트랜지스터는 여전히 3nm 및 2nm급 공정에 크게 의존한다.
  - Kepler는 아직 메모리를 먼저 상용화하려는 단계다.
  - 따라서 Kepler가 SRAM이나 HBM 일부 시장에 진출했다고 해서 ASML의 EUV 시장 전체가 즉각 위협받는 것은 아니다.

**📌 하지만 메모리 분야의 제조경제성은 달라질 수 있다**

- - Kepler의 전략이 성공한다면 기존 28nm급 CMOS 생산시설에서도 높은 밀도의 AI 메모리를 제조할 수 있는 기회가 생긴다.
  - 이는 일부 제품에서 새로운 첨단 EUV 팹 건설에 대한 의존도를 낮출 수 있다.
  - 특히 GF처럼 성숙 공정과 특수 공정을 보유한 파운드리에 유리할 수 있다.

**📌 반도체 산업의 지정학적 병목도 이동할 수 있다**

- - 현재 첨단 반도체 제조에서 가장 중요한 병목 중 하나는 EUV 장비 및 선단 공정 제조능력이다.
  - Kepler처럼 EUV 없이 고밀도 메모리를 구현하는 기술이 상용화된다면 일부 메모리의 공급망을 더 많은 제조시설로 분산할 수 있다.
  - 미국과 동맹국의 기존 생산시설을 활용할 가능성도 확대된다.
  - 그러나 이는 공급망 의존성 자체가 사라진다는 뜻은 아니다.
  - 새로운 강유전체 소재, 증착·식각장비, 계측장비, Wafer Bonding, Advanced Packaging이 또 다른 핵심 기술이 될 수 있다.
  - 결국 **기존 EUV 중심의 병목이 Materials·3D Integration·Packaging으로 일부 이동하는 것**이다.

**📌 더 중요한 것은 Act II — Logic Replacement**

- - Kepler의 장기 목표는 메모리에만 머무르지 않는다.
  - 회사는 Act II에서 새로운 저전압 논리소자를 개발하고, 기존 CMOS의 에너지 및 밀도 한계를 넘어서는 것을 목표로 한다.
  - 실제로 비선형 분극 소재 기반 논리회로 관련 특허들도 보유하고 있다.
  - 장기적으로 새로운 Logic Device가 상용화된다면 그때는 EUV 기반의 선단 로직 제조경제성에도 더 직접적인 영향을 줄 수 있다.
  - 하지만 이는 메모리 상용화보다 훨씬 장기적이고 불확실성이 높은 도전이다.
  - 현재로서는 Act I의 HVM 검증이 먼저다.

**✅ 19. 결론 — EUV를 없애는 것이 아니라 EUV 없이도 경쟁할 수 있는 방법을 만든다**

- - Kepler Computing은 단순한 FRAM 스타트업으로 보기 어려운 기업이다.
  - 강유전체 소재, 새로운 메모리 셀 구조, 3D 집적, 첨단 패키징, 제조공정 통합과 장기적인 논리소자 개발을 동시에 추진하고 있다.
  - 특히 관련 특허를 살펴보면 1TnC, Multi-Capacitor Cell, Shared Gain Element, Wafer Bonding, Low-Power Logic까지 기술적 방향이 상당히 폭넓다는 것을 알 수 있다.
  - 무엇보다 주목할 것은 GlobalFoundries와의 관계다.
  - GF는 약 5,000만 달러를 직접 투자하고 28nm 기반 제조공정을 제공하고 있다.
  - Kepler는 실제 생산공정에서 약 2,000장의 웨이퍼를 처리했으며, 2027년 싱가포르 생산 확대를 목표로 한다.
  - 이는 실험실 단계의 기술이 제조시설과 연결되기 시작했다는 의미다.
  - 그러나 HVM 수율, 제품 신뢰성, 고객 인증과 경제성에 대해서는 앞으로 더 많은 검증이 필요하다.
  - Tesla와 SpaceX의 Terafab 역시 흥미로운 비교 대상이다.
  - Terafab은 대규모 AI 칩 생산능력을 확보하려 한다.
  - Kepler는 기존 반도체 제조시설을 활용해 AI 메모리의 공급능력과 전력 효율을 높이려 한다.
  - GF는 그러한 신기술을 기존 생산 인프라에 통합하는 역할을 맡고 있다.
  - 세 기업 사이의 직접적인 협력 관계가 확인된 것은 아니다.
  - 하지만 대규모 AI 컴퓨팅에 필요한 메모리 공급량과 제조비용을 줄여야 한다는 산업적 과제에서는 상당한 공통점이 있다.
  - 나는 Kepler의 성공 여부를 판단할 때 2nm나 3nm라는 노드 이름보다 실제로 얼마만큼의 메모리를 얼마나 낮은 전력과 비용으로 생산할 수 있는지에 더 주목해야 한다고 생각한다.
  - 그 숫자들이 실제 상용 제품에서 입증된다면 GF의 기존 제조시설은 새로운 의미를 갖게 될 것이다.
  - 그리고 반도체 산업에서도 더 이상 최첨단 노광장비를 사용하는 것만이 고밀도 반도체를 만드는 유일한 경로는 아니게 될 수 있다.
  - **EUV의 시대가 끝나는 것은 아니다.**
  - **그러나 모든 반도체 성능 향상이 더 작은 트랜지스터와 더 비싼 EUV 장비에만 의존해야 한다는 전제가 약해질 가능성은 있다.**
  - 결국 Kepler가 시험하고 있는 것은 새로운 메모리 소자 하나가 아니라 반도체 산업의 새로운 경제학이다.
  - 더 작게 만드는 경쟁에서 더 잘 쌓고, 더 좋은 소재를 사용하며, 기존 생산시설을 더욱 효율적으로 활용하는 경쟁으로 확장될 수 있는 것이다.
  - 그리고 Kepler가 정말 HVM에 성공한다면 GlobalFoundries는 그 변화의 초기 수혜자 가운데 하나가 될 가능성이 있다.

**✅ 용어 정리**

**📌 ALD는 무엇이고 HfO****2****, ZrO****2** **같은 것은 왜 중요한가**

- - **ALD = Atomic Layer Deposition**

    - 원자를 거의 한 층씩 쌓듯 아주 얇은 막을 만드는 증착공정이다.
    - 수 nm 수준의 정확한 두께 제어가 가능하다.
    - 새로운 memory, transistor, quantum device에서 굉장히 중요하다.
    - 각 재료는 대략 이렇게 보면 된다.

|  |  |  |
| --- | --- | --- |
| **재료** | **이름** | **주 용도** |
| **HfO2** | Hafnium Oxide | High-k dielectric, ferroelectric memory |
| **ZrO2** | Zirconium Oxide | High-k, HfO2와 섞어 ferroelectric HZO 형성 |
| **Al2O3** | Aluminium Oxide | 절연막, passivation, barrier |
| **TiO2** | Titanium Oxide | High-k, optical/센서/저항변화 소자 |
| **TiN** | Titanium Nitride | 전극, diffusion barrier, metal layer |

- - - 특히 중요한 조합이:

      - **HfO****2** **+ ZrO****2** **→ HZO(Hafnium Zirconium Oxide)**
    - 다.
    - 특정 조성과 열처리를 사용하면 ferroelectric 특성이 나타날 수 있어서:

      - FeRAM
      - FeFET
      - ferroelectric capacitor
    - 같은 차세대 memory에 사용할 수 있다.
    - 그래서 SkyWater가 HfO**2**와 ZrO**2** ALD를 지원한다는 것은 **ferroelectric memory 같은 새로운 소자를 개발할 기본적인 공정도구를 가지고 있다**는 의미다.
    - 단, 이것만으로 Kepler 공정을 그대로 만들 수 있다는 뜻은 아니다.
  - **Low-temperature BEOL**

    - **BEOL = Back End Of Line**

      - transistor를 만든 뒤 위에:

        - metal wiring
        - via
        - dielectric
        - interconnect
      - 를 만드는 공정이다.
    - Low-temperature가 중요한 이유는 새로운 물질 중에는 높은 온도를 견디지 못하는 것이 많기 때문이다.
    - 예:

      - ferroelectric material
      - quantum material
      - photonic material
      - bonded die
    - 따라서 기존 CMOS를 먼저 만든 뒤, 그 위에 새로운 소재를 낮은 온도로 추가할 수 있다.
    - 이게 SkyWater 같은 custom fab에서 상당히 중요한 능력이다.

**📌 Adeia의 ZiBond와 DBI는 무엇인가**

- - 둘 다 **chip을 아주 촘촘하게 붙이는 bonding technology**다.
  - **ZiBond**

    - 두 wafer/die의 평평한 절연층을 직접 붙인다.
    - solder bump 없이도 매우 얇게 접합할 수 있다.
  - **DBI**

    - **Direct Bond Interconnect**

      - ZiBond에서 한 단계 더 나아가
      - 절연층을 붙이는 동시에 **metal contact까지 직접 연결**한다.
    - 그래서:

      - pitch를 더 작게 만들 수 있고
      - 높이가 낮고
      - 전력 소모가 줄고
      - bandwidth가 높아질 수 있다.

**📌 W2W, D2W, D2D는 무엇인가**

- - **W2W = Wafer-to-Wafer**

    - wafer 전체와 wafer 전체를 붙인다.
  - **D2W = Die-to-Wafer**

    - 잘라낸 chip 하나씩을 wafer 위에 붙인다.
  - **D2D = Die-to-Die**

    - chip 하나와 chip 하나를 붙인다.
  - W2W는 생산성이 좋지만 두 wafer의 die 위치와 수율이 잘 맞아야 한다.
  - D2W는 필요한 good die만 골라 붙일 수 있어 heterogeneous integration에 훨씬 유연하다.
  - 그래서 SkyWater가 **W2W → D2W/D2D**로 확대한다는 것은 chiplet과 여러 종류의 device를 조합하는 능력이 커진다는 의미다.

**📌 Silicon Interposer / Hybrid Bonding / FOWLP / TSV-last / RDL**

- - 이것들은 모두 **Advanced Packaging** 기술이다.

|  |  |
| --- | --- |
| **기술** | **쉽게 말하면** |
| **Silicon Interposer** | 여러 chip을 연결하는 silicon 중간판 |
| **Hybrid Bonding** | solder bump 없이 die를 직접 고밀도로 붙임 |
| **FOWLP** | wafer 밖으로 재배치해서 package를 크게 만드는 방식 |
| **TSV-last** | chip 공정을 끝낸 뒤 마지막 단계에 TSV를 만듦 |
| **RDL** | chip의 contact 위치를 다시 펼쳐주는 금속 배선 |

- - **Silicon Interposer**

    - 예를 들어 GPU와 HBM 사이에 있는 큰 silicon 연결판이다.
    - 매우 많은 신호를 짧은 거리로 연결할 수 있다.
  - **Hybrid Bonding**

    - chip을 거의 직접 붙이는 방식이다.
    - 기존 microbump보다 훨씬 미세한 pitch를 만들 수 있어:

      - chiplet
      - HBM
      - 3D logic
      - quantum
      - photonics
    - 에서 중요하다.
  - **FOWLP**

    - **Fan-Out Wafer Level Packaging**
    - 작은 die의 contact를 바깥쪽으로 넓혀 package를 만든다.
    - 즉 substrate 없이 얇고 작은 package를 만들기 좋다.
  - **TSV-last**

    - TSV를 transistor 공정 중간이 아니라 **후반에 추가**한다.
    - 장점은 기존 wafer process를 크게 바꾸지 않고 3D integration 기능을 넣기 쉽다는 것이다.
  - **RDL**

    - **Redistribution Layer**
    - chip pad 위치를 다른 위치로 재배치하는 얇은 metal wiring이다.
    - Chiplet packaging에서 거의 필수적인 기술이다.

**📌 RRAM — Resistive RAM**

- - 여기서부터는 메모리다.
  - **원리**

    - 기존 DRAM이나 SRAM처럼 transistor 상태 자체를 저장하는 대신 **물질의 저항상태**를 이용한다.
    - 개념적으로:

      - 전압을 가하면 oxide 내부에 conductive filament가 만들어지거나 사라지면서 저항이 달라진다.
  - **가장 큰 특징**

    - **전원을 꺼도 데이터가 남는다.**

      - 즉 Non-Volatile Memory다.
    - SRAM:

      - Power OFF → 데이터 사라짐
    - RRAM:

      - Power OFF → 데이터 유지
  - **어디에 좋은가**

    - MCU firmware
    - IoT
    - Edge AI
    - Embedded NVM
    - 일부 neuromorphic / in-memory computing 연구
  - **Flash와 경쟁할 수 있는 이유**

    - embedded Flash는 advanced process와 결합하기가 점점 어려워진다.
    - RRAM은 상대적으로 **BEOL 쪽에 memory element를 추가**할 수 있다는 장점이 있다.
    - 그래서 GF는 이를 22FDX+ 같은 플랫폼과 결합하려 한다.

> **RRAM = 저항 변화를 이용해 전원이 없어도 정보를 유지하는 메모리**

**📌 GCRAM — Gain-Cell RAM**

- - 이건 RRAM과 완전히 다른 종류다.
  - **휘발성 메모리**다.
  - **왜 주목받나**

    - 일반 SRAM은 보통 **6T SRAM**
    - 즉 bit 하나에 transistor 6개 정도를 사용한다.

      - 6T → 1 bit
    - 문제는 면적이다.
    - GPU/CPU에 cache를 많이 넣으려면 엄청난 transistor 면적을 차지한다.
    - GCRAM은 이 구조를 줄이는 것이 목표다.
    - 예를 들어 gain-cell 구조는 구현에 따라 대략:

      - 2T / 3T → 1 bit
    - 같은 형태가 가능하다.
  - **DRAM과 비슷한 면도 있다**

    - capacitor 또는 transistor node에 charge를 저장하기 때문에 시간이 지나면 charge가 빠진다.
    - 그래서 **refresh가 필요할 수 있다.**
    - 하지만 별도의 고난도 DRAM capacitor를 반드시 사용할 필요가 없고 logic CMOS와 integration하기 좋다는 것이 장점이다.
  - **GF + RAAAM 목표**

    - GF와 RAAAM이 추진하는 GCRAM의 핵심 목표는 기존 SRAM 대비:

      - 면적 ↓
      - 전력 ↓
      - Logic process와 쉽게 통합
    - 이다.
    - 특히 **SRAM replacement / large on-chip cache**가 큰 목표다.

> **GCRAM = SRAM보다 적은 transistor로 같은 종류의 빠른 on-chip memory를 만들려는 기술**

**📌 RRAM과 GCRAM은 이름은 비슷하지만 완전히 다르다**

|  |  |  |
| --- | --- | --- |
|  | **RRAM** | **GCRAM** |
| 저장 원리 | 저항 | 전하 |
| 비휘발성 | **O** | X |
| 전원 꺼짐 | 데이터 유지 | 사라짐 |
| Refresh | 보통 불필요 | 필요 가능 |
| 주요 경쟁 | Flash / eNVM | **SRAM** |
| 주요 용도 | Code storage | Cache / working memory |

- - **RRAM은 Flash 쪽을 노리고, GCRAM은 SRAM 쪽을 노린다.**

**📌 GaN — Gallium Nitride**

- - 이건 silicon 자체가 아니다.
  - **Gallium + Nitrogen**으로 이루어진 wide-bandgap semiconductor다.
  - **왜 Silicon보다 좋은가**

    - GaN은 높은 전압과 높은 주파수에서 매우 강하다.
    - 대략적으로:

      - Breakdown voltage ↑
      - Switching frequency ↑
      - Power density ↑
      - Efficiency ↑
      - Device size ↓
  - **전원장치에서는**

    - 기존 silicon MOSFET:

      - AC/DC → 전압 변환 → Switching loss → Heat
    - GaN:

      - 더 빠른 switching → 작은 inductor/capacitor → 작은 power supply → 전력효율 ↑
    - 그래서 휴대폰 충전기부터 AI 데이터센터까지 쓰인다.
  - **AI 데이터센터에서 중요해지는 이유**

    - AI rack의 전력은 급격히 커지고 있다.

      - Grid → AC/DC → 800V / 400V → 48V → VRM → GPU
    - 각 전압을 바꿀 때 손실이 발생한다.
    - 데이터센터 전체가 수십~수백 MW까지 커지면 **1~2% 효율 차이조차 엄청난 전력과 냉각비 차이**를 만든다.
    - 그래서 GaN과 SiC가 중요해진다.
  - **RF에서도 GaN**

    - GaN은 power만 하는 것도 아니다.
    - 높은 주파수와 높은 출력이 가능하기 때문에:

      - Radar
      - SATCOM
      - 5G/6G
      - Defense RF
    - 용 **RF Power Amplifier**에도 적합하다.
  - 그래서 GF는 **Power GaN + RF GaN** 양쪽을 모두 노린다.

> **GaN = 적은 손실로 큰 전력 또는 고주파 신호를 처리하는 화합물 반도체**
