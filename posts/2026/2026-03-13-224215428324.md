**📌 Chicago vs Cambridge vs Duke/Maryland**

- - IonQ는 최근 **University of Chicago**와 **University of Cambridge**와 협력 관계를 발표했다.
  - 겉으로 보면 두 협력은 비슷해 보이지만, 실제로는 **목적, 기술 배치, 전략적 의미**에서 차이가 있다.
  - 또한 많은 투자자들이 궁금해하는 부분은 다음이다.

    - 두 대학 모두 **주식을 받은 것처럼 보이는데 구조가 무엇인가**
    - 왜 **Duke / Maryland 때와 SEC 문서 구조가 다른가**
  - 이를 단계적으로 정리하면 다음과 같다.

---

**✅ Chicago vs Cambridge 협력의 핵심 차이**

- - 두 협력은 공통적으로 다음을 목표로 한다.

    - quantum computing
    - quantum networking
    - quantum sensing
    - quantum security
  - 하지만 협력의 **핵심 목적**은 다르다.

|  |  |  |
| --- | --- | --- |
| **항목** | **Chicago 협력** | **Cambridge 협력** |
| 핵심 목적 | 연구 플랫폼 구축 | IP 확대 + 상용화 |
| 전략 방향 | 연구 생태계 활용 | 연구 → 상업화 |
| IonQ 기대 효과 | use case 발굴 | 특허/IP 생성 |
| 전략적 의미 | 미국 연구 허브 | 유럽 전략 거점 |

- - 즉 구조적으로 보면

    - **Chicago** → 연구 중심 협력
    - **Cambridge** → 연구 + 상용화 구조
  - 이다.

---

**✅ 배치되는 기술의 차이**

- - 두 협력은 설치되는 시스템도 다르다.

|  |  |  |
| --- | --- | --- |
| **항목** | **Chicago** | **Cambridge** |
| Quantum Computer | next-generation system | 6세대 256-qubit chip-based system |
| Quantum Network | entanglement distribution network 포함 | 네트워크 언급은 있으나 핵심은 컴퓨터 |
| Cloud access | 언급 없음 | IonQ quantum cloud 제공 |

- - 핵심 차이는 다음과 같다.

    - **Chicago**

      - → Quantum computer + quantum network 테스트베드
    - **Cambridge**

      - → 256-qubit QPU 기반 연구 및 IP 창출

---

**✅ 연구 생태계 연결 구조**

- - 두 협력은 연결되는 연구 네트워크도 다르다.

|  |  |  |
| --- | --- | --- |
| **항목** | **Chicago** | **Cambridge** |
| 연구 네트워크 | Chicago Quantum Exchange | UK Quantum ecosystem |
| 주요 기관 | Argonne, Fermilab | UK Quantum Hubs |
| 전략적 의미 | 미국 국립연구소 연결 | 영국 국가 프로그램 연결 |

- - 즉

    - Chicago는 **미국 national lab ecosystem**
    - Cambridge는 **UK national quantum program**
  - 과 연결된다.

---

**✅ Cambridge 협력에서 IP와 상용화가 명시된 근거**

- - Cambridge 발표에는 다음 문장이 직접 등장한다.

    - **“accelerate quantum research commercialization”**

      - → 연구 상용화
    - **“expand IonQ’s intellectual property portfolio”**

      - → IP 포트폴리오 확대
    - 또한 다음 문장이 핵심이다.

      - **“The partnership will** **generate intellectual property** **to be shared under established licensing terms.”**
  - 즉 구조는

    - 연구
    - → IP 생성
    - → 라이선스
    - → 상용화
  - 이다.

---

    - **“covering the resale by the selling stockholder”**
  - 즉

    - IonQ가 대학에 주식 지급
    - 대학이 시장에서 매각 가능
    - IonQ가 resale registration 제출

**📌 IonQ가 대학 협력에서 약 ~1% 지분을 사용하는 이유**

- - 두 경우 모두 **IonQ 총 발행주식 대비 약 ~1% 수준**이다.

    - 이는 우연이라기보다 IonQ가 대학 협력에서 사용하는 **일종의 표준 구조**일 가능성이 높다.
  - 이 정도 지분 규모는 몇 가지 목적을 동시에 충족한다.

    1. **대학을 장기 이해관계자로 만드는 구조**

       - 대학이 단순 연구 파트너일 경우 협력은 프로젝트 단위로 끝날 수 있다.
       - 하지만 대학이 IonQ의 주주가 되면 상황이 달라진다.
       - IonQ의 기술 발전과 기업 가치 상승이 대학에도 직접적인 이익이 되기 때문이다.
       - 즉 협력 구조는 다음과 같이 변한다.
       - 연구 협력

         - → 공동 이해관계
         - → 장기 파트너십
    2. **의미 있는 파트너이지만 지배력은 없는 수준**

       - 약 1% 지분은 전략적으로 적절한 크기다.
       - IonQ는 **대학을 전략 파트너로 묶으면서도 경영권에는 영향을 주지 않는 수준**을 선택한 것이다.
    3. **현금 대신 equity를 사용하는 연구 투자 구조**

       - IonQ가 대학 협력에서 제공하는 것은 상당히 크다.

         - 양자컴퓨터 설치
         - 연구소 건설 지원
         - 공동 연구 프로그램
         - 연구 인프라 제공
       - 이러한 협력은 사실상 **대규모 연구 투자**에 해당한다.
       - 따라서 IonQ는 cash + equity 혼합 구조를 사용한다.
       - 이는 현금 부담을 줄이면서도 협력 파트너에게 장기적인 upside를 제공한다.

> *IonQ의 ~1% 지분 구조는 단순한 보상이 아니라*
>
> ***대학을 장기적인 quantum ecosystem 파트너로 묶는 전략적 설계****라고 볼 수 있다.*

---

**✅ Duke / Maryland와 구조가 다른 이유**

- - IonQ의 초기 협력은 완전히 다른 성격이었다.

|  |  |
| --- | --- |
| **대학** | **협력 성격** |
| Duke | 핵심 IP 라이선스 |
| Maryland | 핵심 IP 라이선스 |

- - IonQ의 핵심 기술

    - trapped-ion architecture
    - multi-qubit gate design
    - laser control
  - 대부분이 이 두 대학 연구에서 나왔다.
  - 그래서 계약 구조는

    - IP license + royalty + small equity 였다.
  - 이 계약은 **Material contract**였기 때문에 IPO 문서(S-1)에 공개되었다.

---

**✅ 현재 협력의 성격 (Ecosystem 전략)**

- - 현재 IonQ 협력의 목적은 다르다.

|  |  |
| --- | --- |
| **초기 전략** | **현재 전략** |
| IP 확보 | ecosystem 구축 |
| 기초 물리 | 응용 연구 |
| 기술 이전 | 산업 협력 |

- - Chicago / Cambridge 센터의 역할은

    - Quantum computer installation
    - + quantum network testbed
    - + industry collaboration
    - + talent pipeline
    - 이다.

> ***Quantum innovation hub*** *이다.*

---

**✅ 왜 대학에 더 큰 지분을 지급하는가**

- - 지분이 커진 이유는 다음 때문이다.
  - IonQ가 제공하는 것

    - quantum computer
    - 연구소 건설 참여
    - 연구 협력
    - 인력 개발
  - 이것은 사실상 **대규모 연구 투자**다.
  - 그래서 구조는 cash + equity 혼합 구조가 된다.
  - 또 하나 중요한 이유는 **인재 확보**이다.
  - Chicago와 Cambridge는 세계 최고 수준의 양자 연구 인력을 보유하고 있다.

---

**✅ 전략적 의미**

- - IonQ 전략은 점점 명확해지고 있다.
  - 구조는 다음과 같다.

    - Quantum computing
    - Quantum networking
    - Quantum sensing
    - Quantum security
  - 그리고 대학 협력은

    - **Quantum ecosystem** 구축 전략의 일부다.

---

**✅ 핵심 정리**

- - Duke / Maryland

    - → **IonQ 기술의 출발점 (IP 확보)**
  - Chicago / Cambridge

    - → **IonQ 글로벌 quantum ecosystem 구축 거점**
