# 궤도 위의 데이터센터: 대역폭의 한계는 어디인가?(1)

---

얼마전까지만 해도 GPU 품절 현상으로 전세계, 모든 기업이 홍역을 치룬 적이 있다.

지금은 그 품절 현상이 메모리로 이동중이다.

이러한 불균형 현상은 비단 컴퓨팅 산업에서만 발생되는 것은 아니다.

한창 모든 사람이 꿈을 이루기 위해 서울로 모여드는 시기가 있었다(고 한다).

사람이 점점 모여드니 거주 시설 부터 시작해서 한두개가 불편한게 아니었다.

이러한 인구과밀화 문제를 해결하기 위해서 정부에서는 대도시 주변에 위성 도시를 건설하기 시작했다.

분당, 일산이 1세대 위성 신도시였다면, 김포, 용인, 수지, 판교 등이 그 뒤를 잇는 위성도시가 되었다.

비싼 주거비를 감당하기 힘든 사람일수록 먼저 위성 도시로 빠져나가기 시작했다. 물론 이 중엔 투자에 눈이 밝아서, 여러 불편함을 감수하고서라도 저가에 주택 및 아파트를 매입하고 한 시간 이상의 고된 출퇴근을 하던 사람도 더러 있었다.

처음에는, 그동안 꿈꿔왔던 내집을 마련하여 행복하였기 때문에, 한시간의 출퇴근길도 그리 고되지 않았다. (왕복 2시간임에도 퇴근할때 쯤이면 출근할때의 고통스러운 기억은 잊을 수 있는 어리석음이 있었기에 견딜 수 있었다.)

"어차피 그시간을 아낀다고 생산적인 일을 하는 것도 아닌데"라는 생각에, 그동안 게을리 했던 영어 공부를 버스에서 시작하였고, 과음을 한 다음날은 그야말로 떡실신을 하여, 강남 한복판인 종점에 도착해도 잠을 못깨서, 급기야 내리던 사람이 툭툭 쳐서 깨워주기도 하였다.

영어공부와 쇼츠 시청, 잠을 반복하면서(점점 쇼츠와 잠의 비중이 더 늘어가기만 했지만) 몇년을 버티다 보니 집값이 많이 올랐단 말에 왠지 벼락부자가 된 듯한 착각이 들기도 하였고, 이를 자랑삼아 떠들던 사람이 늘어날 수록, 외곽으로 나가는 사람의 수는 더욱 많아졌다.

출퇴근 하는 사람들이 많아지다 보니, 교통 체증이 점점 심해져서, 초창기에는 한시간이면 충분한 거리를 10분 20분 늘어나면서 이제는 1시간 30분이 당연시되었고, 어쩌다가 사소한 충돌사고나 차량 고장이라도 발생하는 날엔 2시간은 각오를 해야했다.

그나마 예전에는 무조건 앉아서 갈 수 있었는데, 신도시가 더욱 확장되면서 종점이 더 멀어졌고, 나보다 훨씬 멀리 사는 사람들이 이미 좌석을 차지해서, 앉아서 갈 수 있는 확율은 점점 줄어들었다. (이러한 광역 버스의 특성상, 중간에 정류장도 많지 않고, 위성도시에서 승차한 대부분은 중간에서 내리는 일은 없기 때문에 좌석이 없는 경우 너무 절망적이게 된다.)

1시간 반을 버스에서 보내고 나면, 회사에 도착하기도 전에 머리속은 퇴근을 생각하기 마련이다.

"이대론 도저히 안되겠다, 경차라도 하나 사야겠다." 경차를 사고 한동안 신이 나서 운전이 전혀 힘들지도 않았고, 예전엔 엄두도 낼 수 없었던 주말 교외 드라이브도 가능하게 되었다.

하지만, 이 즐거움도 오래가진 못했다. 자가 출퇴근을 하는 사람이 늘수록 교통체증은 더욱 가속화되었고, 이젠 2시간이 기본이 되어갔다. 직장 동료는 살짝 비웃기까지 한다. "사대리, 차량 유지, 괜찮아?" 난, 요즘 기름값도 부담되고, 운전도 힘들어서 다시 버스타고 다녀. 요즘엔 생각보다 덜 힘들어졌어. 버스 전용차선 때문에 오히려 더 빨리 도착하더라고.

"나는 왜 시대에 역행하면서까지 개고생을 자처하고 있었을까?"하는 생각에 현타가 세게 왔다.

**📌 RF가 주력이었던 이유**

- - **RF (S / X / Ku / Ka 대역)**

    - TT&C(제어/텔레메트리): 주로 **S-band**
    - ISR 이미지 덤프: **X-band**
    - 광대역 인터넷/백홀: **Ku / Ka-band**
  - **왜 RF가 기본이 되었나?**

    - 구름·비에도 “완전 차단”은 거의 없음
    - 안테나 지향 정밀도 요구가 광보다 훨씬 낮음
    - 수십 년 운용 경험 + 규제 체계 확립
    - 99.9%+ 가용성 확보 용이
    - 즉, **“안정성”이 압도적 장점**.

**📌 레이저(광통신)가 등장한 이유**

- - **Optical / Laser - OISL (Optical Inter-Satellite Link), FSO(Free-Space Optical)**

    - 매우 좁은 빔 → 간섭 거의 없음
    - 대역폭 이론적 한계가 매우 높음 (THz 영역)
    - 높은 스펙트럼 효율 (coherent + QAM)
    - 감청/재밍에 상대적으로 강함
  - 즉, **“용량과 보안성”이 압도적 장점**.

**📌 RF vs Laser 핵심 비교표**

|  |  |  |
| --- | --- | --- |
| **항목** | **RF** | **레이저 (Optical)** |
| 주파수 | GHz | ~200 THz |
| 빔 폭 | 넓음 | 매우 좁음 |
| 지향 정밀도 요구 | 낮음 | μrad 수준 |
| 구름 영향 | 감쇠 | 완전 차단 가능 |
| 대역폭 잠재력 | 수십~수백 Gbps | Tbps 이상 가능 |
| 간섭 | 존재 | 거의 없음 |
| 재밍/감청 | 상대적으로 쉬움 | 어려움 |
| 가용성 | 매우 높음 | 날씨 의존 |
| 기술 성숙도 | 매우 높음 | 빠르게 성장 중 |

**📌 가장 큰 차이: “성능 vs 가용성”**

- - 레이저는 성능이 압도적
  - RF는 가용성이 압도적
  - 구름이 오면:

    - RF = degraded
    - Laser = 0
  - 이 차이가 구조를 결정한다.

**📌 왜 아직 RF가 기본인가?**

- - 상업 인터넷은:

    - 99.9~99.99% uptime
  - 광 단일 링크는:

    - 날씨에 따라 90~95% 가용성 가능
  - 그래서 현실은:

    - 위성간의 연결 (ISL) : 레이저
    - 지상 연결

      - Optical Gateway (고속, 날씨 좋을 때)
      - RF Gateway (항상 켜짐, 보험 역할)
  - 즉,

    - 레이저 = 성능 레이어
    - RF = 안정성 레이어

**✅ RF와 레이저의 최대 대역폭**

**📌 이론적 한계 – Shannon 용량**

- - 통신 용량은:

- - - **B** = 사용 가능한 대역폭
    - **SNR** = 신호대잡음비
  - 즉, RF의 근본 한계는 대역폭(B) 과 SNR 에 의해 결정된다.

**📌 위성 RF에서 현실적인 대역폭**

- - **Ka-band (주력)**

    - 업링크: 27.5–30 GHz (~2.5 GHz 폭)
    - 다운링크: 17.8–20.2 GHz (~2.4 GHz 폭)
  - 하지만 이걸:

    - 전부 한 위성이 독점 못함
    - 여러 빔으로 분할
    - 여러 사업자가 나눔
    - 규제 제한 존재
  - 현실적으로 **한 링크당 수백 MHz ~ 1 GHz** 사용이 일반적.

**📌 현실적인 처리량 계산 예시**

- - **가정**

    - 대역폭: 1 GHz
    - 고차 변조: 64APSK
    - 스펙트럼 효율: ~5~6 bit/s/Hz
  - 그럼:

    - 1 GHz × 6 bit/s/Hz = **6 Gbps**
    - 여러 채널 묶으면 수십 Gbps 가능
  - 실제로:

    - Starlink V2 Mini 전체 처리량 ≈ **90~100 Gbps (전체 합산)**
    - 게이트웨이 RF 링크는 위성당 수십 Gbps 추정

**📌 RF 대역을 더 올리면?**

- - **📶 Q/V-band (40–75 GHz)**

    - 대역폭 더 넓음
    - 이론적으로 수십 GHz 확보 가능
  - 하지만:

    - 비에 매우 약함
    - 대기 흡수 증가
    - 하드웨어 복잡도 급증

**📌 물리적 한계 3가지**

- - **① 스펙트럼은 유한하다**

    - RF는 규제 자산이다.
    - 광처럼 “대역이 무한”하지 않다.
  - **② 빔폭 한계**

    - RF 빔폭:

      - θ≈λ/D
    - 파장이 길수록

      - 빔이 넓다 → 간섭 증가 → 재사용 제한
    - 광은 λ가 수천 배 짧다.

      - → 극도로 좁은 빔 가능
      - → 공간 재사용성 압도적
  - **③ SNR 한계**

    - 고차 QAM은 높은 SNR 필요.
    - RF는:

      - 전력 제한
      - 증폭기 비선형성
      - 대기 손실
    - 때문에 256QAM 이상은 위성에서 거의 안 씀.

**📌 RF vs Optical 대역폭 구조 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **RF (Ka)** | **Optical** |
| 사용 가능 대역폭 | 수 GHz | 수 THz |
| 빔 폭 | mrad | μrad |
| 채널 수 | 제한적 | WDM 수십~수백 |
| 단일 링크 용량 | 수~수십 Gbps | 수백 Gbps~Tbps |
| 가용성 | 매우 높음 | 날씨 의존 |

**📌 결론: RF의 실질적 한계**

- - **현실적 위성당**

    - 수십 Gbps ~ 100 Gbps 수준
  - **이론적으로 밀어붙여도**

    - 수백 Gbps 정도가 상한선
  - **Tbps?**

    - 현실적으로 거의 불가능
  - 왜냐하면:

    - 대역폭 부족
    - 규제 문제
    - 빔 간섭
    - 고차 변조 한계

> *RF는 안정적이지만* ***확장성이 선형적으로 증가한다.***
>
> *더 넓은 대역폭 확보 (규제 필요)*
>
> *더 많은 빔 재사용*
>
> *더 많은 위성*
>
> *반면 레이저는* ***곱셈 구조로 증가가능****하다.*
>
> *고차 QAM*
>
> *WDM (파장 다중화)*
>
> *심볼레이트 증가*

**✅ 고차 QAM이 뭔지 궁금해? 일단 변조와 검출부터 배우고 와.**

**📌 변조 방식**

- - 현존하는 모든 통신 수단에는 공통점이 있다.
  - 사전에 서로 약속한 규칙이 반드시 존재한다.
  - 그 규칙이 없다면,
  - 그 어떤 행위도 “정보 전달”이 아니라 단순한 물리 현상에 불과하다.
  - 영화 《엑시트》의 예

    - 영화 엑시트에서 스마트폰 불빛을 “따따따 따 따 따 따따따” 박자에 맞춰 켰다 껐다 하는 장면이 나온다.
    - 왜 그것이 구조 신호가 될 수 있었을까?
    - 그 이유는 단 하나다.

      - “··· --- ···”가 SOS라는 사전 약속(규칙) 이 있었기 때문이다.
    - 그 규칙을 모르는 사람에게는 그저 불빛이 깜빡이는 것일 뿐이다.

**📌 통신의 세 가지 필수 요소**

- - 구조 신호가 제대로 전달되기 위해서는 최소한 세 가지가 필요하다.
  1. **사전 정의된 규칙 (Protocol / Modulation Rule)**

     - 어떤 패턴이 어떤 의미를 갖는지 약속해야 한다.

       - 짧은 빛 = 점
       - 긴 빛 = 선
       - 조합 = SOS
     - 이게 없다면 통신은 성립하지 않는다.
  2. **전달 매체 (Medium)**

     - 정보는 반드시 **어떤 물리적 매체**를 통해 이동해야 한다.

       - 소리 → 공기
       - 전파 → 전자기파
       - 빛 → 광자
     - 우주 통신에서는

       - RF 전파
       - 레이저 광
     - 이 매체가 된다.
  3. **변조와 검출 (Modulation & Detection)**

     - 여기서 기술적인 핵심이 등장한다.
     - 통신은 결국 이렇게 요약된다:

       - 의미를 물리량에 “실어 보내는 것”이 변조(Modulation),
       - 그 물리량에서 다시 의미를 “읽어내는 것”이 검출(Detection)이다.

> ***💡 스마트폰 불빛 예로 다시 보면***
>
> *불빛을 켰다 껐다 한다 →* ***변조***
>
> *상대방이 깜빡임을 보고 점/선을 해석한다 →* ***검출***
>
> *점/선을 문자로 바꾼다 →* ***복호(Decoding)***
>
> *이 세 단계가 모두 있어야 통신이 완성된다.*

**📌 광통신에 그대로 적용해보면**

- - 빛을 사용한다는 건:

    - 정보를 빛의 어떤 속성에 실어서 보내는 것
  - 빛이 가진 속성은 여러 가지다:

    - 세기 (Intensity)
    - 위상 (Phase)
    - 주파수 (Frequency)
    - 편광 (Polarization)
  - 이러한 속성중 어떤 것을 규칙으로 사용하는지 살펴볼 차례다.

**📌 IM-DD**

- - **"불 켜졌나?" 체크하는 방**
  - **IM-DD = Intensity Modulation – Direct Detection**

    - **Intensity Modulation (IM)**: 빛의 **세기(광 파워)** 를 시간에 따라 바꿔서 정보(0/1 또는 PAM4 레벨)를 싣는 방식
    - **Direct Detection (DD)**: 수신기가 **포토다이오드로 “세기만”** 재서 전기 신호로 만드는 방식
    - 포토다이오드는 기본적으로 ∣E∣2 (전기장 크기의 제곱, 즉 파워)만 보기 쉬움
    - 그래서 **위상(phase) 정보는 기본적으로 잃어버림**
  - 대표 예:

    - OOK(켜짐/꺼짐), NRZ
    - **PAM4** (세기 레벨 4단계)
    - 데이터센터 단거리(예: 100G/400G DR/FR 계열)에서 흔함

> ***IM-DD에서 수신기는:***
>
> *빛의 세기만 감지*
>
> *캐리어는 건드리지 않음*
>
> *이건 복조라기보다 광 신호를 전기 신호로 바꾸는 “검출”*

**📌 Coherent - 이번 주제의 핵심**

- - "빛이 얼마나 밝은가(amplitude) + 어느 각도로 회전해 있는가(phase)” 두 정보를 모두 사용하는 통신 방식
  - 보통 그냥 **Coherent (Optical) Communication / Coherent Detection** 이라고 부른다.
  - 핵심 구성:

    - 송신부

      - 빛의 **진폭(amplitude)** 과 **위상(phase)** 을 함께 써서 변조

- - - - 대표 변조: **QPSK, 16QAM, 64QAM…** (대부분 I/Q 기반)
    - 수신

      - 강한 기준 레이저 **LO (Local Oscillator)** 를 수신기에서 만들어서
      - 신호광과 **간섭(혼합)** 시킨 다음,
      - **I/Q(복소수) 성분**을 복원하는 방식

        - I = In-phase
        - Q = Quadrature
      - [잠깐] 머리를 너무 많이 사용해서 힘들다면 아래의 가장 아름다운 수식을 감상하면서 휴식을 취하자.

    - 보통 **optical hybrid + balanced photodiodes + ADC + DSP** 조합

      - **optical hybrid**

        - 신호광(Es) + LO(ELO)를 섞어서 0°(I)와 90°(Q) 성분으로 분리해주는 광 회로
        - 구조적으로는

          - 여러 개의 50:50 beam splitter와 90° 위상 지연기를 조합한 장치
          - 출력은:

            - I+ / I-

        - **각 출력은 포토다이오드(PD)로 들어간다.**
        - **중요한 점:**

          - **PD는 전기장 E를 직접 보는 게 아니라**
          - **즉, 세기(intensity) 에 반응한다**

        - **보통 4개 :** I+, I-, Q+, Q-

          - Q 성분 → 차동 검출 → 2개 PD
        - 차동 검출의 목적:

          - LO 세기 잡음 제거
          - 공통 노이즈 제거
          - 간섭 성분 강화

>

>
> *즉, 둘은* ***변조만의 차이****가 아니라* ***검출(수신) 방식의 차이****가 더 본질임*

**✅** **그럼 다시 본론으로 돌아와서, 서두에서 말한 "고차 QAM"은 도대체 뭔대?**

**1️⃣ QAM이 뭐냐부터**

- - QAM = **Quadrature Amplitude Modulation**

    - → 직교 진폭 변조
  - 의미는:

    - I축 (In-phase)
    - Q축 (Quadrature, 90° 회전)
  - 이 두 축에 각각 진폭 값을 주는 방식이다.
  - 그래서 신호를 이렇게 쓴다:

- - 즉, **2차원 평면에 점을 찍는 방식**이다.
  - 이 점들의 집합을 **Constellation**이라고 부른다.

**2️⃣“고차 QAM”이란?**

- - QAM에서 “차수(Order)”는 Constellation 점의 개수다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAyMjFfOTAg/MDAxNzcxNjAwMDM4MjEy.DuGVLMehVad8zwPhkEYWVYPJkPgEvh6nJ7DJOzCgeZIg.JXLDGJ3wyIi5B6vC-mMfLthAiWdHHOvCQzi4b0t9jjwg.PNG/image.png?type=w800)](#)

|  |  |  |
| --- | --- | --- |
| **변조** | **점 개수** | **심볼당 비트** |
| QPSK | 4 | 2bit |
| 16QAM | 16 | 4bit |
| 64QAM | 64 | 6bit |
| 256QAM | 256 | 8bit |

- - 공식은:

- - - M = 점 개수
    - 👉 점이 많아질수록 “고차 QAM”이다.

**3️⃣왜 필요하냐?**

- - 핵심은 이것 하나다:
  - 같은 대역폭에서 더 많은 데이터를 보내기 위해서
  - 다시 Shannon 용량을 보자

- - 여기서 B(대역폭)는 유한하다.
  - 대역폭을 무한히 늘릴 수 없다면?

    - 👉 한 Hz 안에 더 많은 비트를 넣어야 한다.
    - 그게 고차 QAM이다.

**4️⃣직관적으로 이해해보자**

- - QPSK는 원 위에 4개 점.
  - 16QAM은 정사각형에 16개 점.
  - 64QAM은 8×8 격자.
  - 256QAM은 16×16 격자.
  - 점이 많아질수록:

    - 점 간 간격이 좁아짐
    - 잡음에 더 민감
    - 더 높은 SNR 필요

**5️⃣ 왜 고차 QAM이 어려운가?**

- - 고차 QAM은:

    - 위상 정확도 필요
    - 진폭 정확도 필요
    - 선형 증폭기 필요
    - 낮은 잡음 필요
  - 그래서 필요한 것:

    - 높은 SNR / OSNR
    - 낮은 위상 잡음 (레이저 linewidth)
    - 강력한 DSP

**6️⃣ RF와 광에서의 의미**

- - RF:

    - 256QAM 흔함 (WiFi, 5G)
    - 채널 조건 좋으면 가능
  - 광:

    - OSNR 조건 더 빡셈
    - 장거리일수록 차수 낮춤
    - DCI에서 16QAM, 64QAM 주로 사용

**7️⃣ 왜 우주 통신에서 중요하냐?**

- - 우주에서는:

    - 대역폭 제한
    - 전력 제한
    - 안테나/망원경 크기 제한
  - 그래서:

    - 같은 전력, 같은 대역폭에서 더 많은 비트를 보내야 한다.
    - 고차 QAM은 “대역폭을 아끼는 기술”이다.

---

**✅** **그럼 고차 QAM 사용하면 끝!?**

**1️⃣ 수학적으로는 가능하다**

- - 다시 Shannon 공식을 불러오면,
  - SNR이 충분히 높다면, 256QAM 혹은 그 이상도 가능하다. 물론 이론적으로.
  - OSNR만 확보되면 우주에서도 고차 QAM 가능.

**2️⃣ 문제: 우주에서 오는 빛은 너무 약하고 변동이 심하다.**

- - 평균 전력 감소

    - 빔 확산
    - 거리 감쇠
  - 동적 이슈

    - Scintillation - 뜨거운 아스팔트에서 피어나는 아지랭이
    - Pointing jitter - 흔들리는 차안에서 눈썹 그리기
    - 구름 차단
  - 이러한 여러 이유로 SNR이 시간에 따라 계속 출렁거린다.

**3️⃣ 고차 QAM의 치명적 약점**

- - 점이 촘촘할수록:

    - SNR (Signal-to-Noise Ratio)이 조금만 떨어져도

- - - - - - - 단위를 보통 dB(데시벨)로 표현하기 때문에,
            - SNR (dB) =

- - - BER (Bit Error Rate)가 급격히 증가

      - 총 전송 비트 수에서 에러가 난 비트 수의 비율

        - 예를 들어, 1,000,000 비트를 보냈는데 100비트가 틀렸다면 BER=10-4
        - **OISL, OCT, Tbps 광통신** 같은 경우에는
        - BER 10-12 ~ 10-15 수준이 기본 요구

|  |  |
| --- | --- |
| **변조** | **대략적 필요 SNR** |
| QPSK | ~10 dB |
| 16QAM | ~17 dB |
| 64QAM | ~23 dB |
| 256QAM | ~28–30 dB |

- - 차이는 몇 dB지만 통신에서는 몇 dB가 생사를 가른다.

    - SNR이 10이면, 10dB
    - SNR이 100이면, 20dB
    - SNR이 200이면, 23dB

      - 2~4 dB 차이인데 오류율이 100~1000배 차이 난다.
      - 이게 “생사를 가른다”는 의미다.

|  |  |
| --- | --- |
| **dB** | **SNR** |
| 3 dB | 2 |
| 10 dB | 10 |
| 20 dB | 100 |
| 23 dB | 200 |
| 30 dB | 1000 |

**4️⃣ 링크 설계의 진짜 기준**

- - 위성 통신은 보통:

    - “평균 성능”이 아니라 “최악 조건에서도 유지되는 성능”을 기준으로 설계한다.
  - 왜?

    - 상업 서비스는 99.9% 이상 가용성이 필요하기 때문.
  - 고차 QAM은:

    - 평균 OSNR이 충분해도
    - 순간 OSNR이 떨어지면 링크 붕괴

**5️⃣ 그래서 현실은 적응형이다**

- - 실제 시스템은 이렇게 한다:

    - 조건 좋으면 64QAM
    - 나빠지면 16QAM
    - 더 나빠지면 QPSK
  - 이를:

    - **Adaptive Modulation** 이라고 한다.

**6️⃣ 우주에서 구간별 차이**

- - **🚀 LEO–LEO (ISL)**

    - 대기 없음
    - 상대적으로 안정
    - 고차 QAM 가능성 높음
  - **🌍 LEO–Ground**

    - 대기 영향
    - 변동성 큼
    - 보통 차수 낮춤

**7️⃣ 또 하나의 문제: 전력과 열**

- - 고차 QAM은:

    - 높은 선형성 필요
    - 고속 ADC 필요
    - DSP 연산량 증가
    - 전력 소모 증가
  - 우주에서는 전력 = 금이다.

**8️⃣ 그래서 답은 “조건부 가능”**

- - 고차 QAM은:

    - 가능하다
    - 하지만 항상 쓰는 게 아니라
    - 조건 좋을 때만 쓰는 전략적 카드다
