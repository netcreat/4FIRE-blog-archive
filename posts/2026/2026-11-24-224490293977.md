# IonQ가 노리는 또 다른 시장

**✅ 양자보안, GPS 없는 정밀 시간, 그리고 미국 정부 조달**

**✅ 1. PQC와 QKD — 경쟁 관계가 아니라 서로 다른 실패 모드**

- - 기존 RSA·ECC의 취약점, AES와 키 설정의 차이, HNDL은 이미 상세히 다뤘다. [양자보안 심화 (1) — RSA·ECC·PQC·AES](https://blog.naver.com/4-fire/224462489845) / [양자보안 심화 (2) — AES 비밀키의 공유와 보호](https://blog.naver.com/4-fire/224463838699)
  - 이번 글의 핵심은 PQC를 범용 기반으로 삼고, 장기 기밀 유지가 필요한 일부 회선에 QKD를 추가하자는 것이다. QKD는 전자서명이나 데이터 암호화 자체를 대신하지 않으며 인증된 고전 채널이 필요하다.

**📌 두 키를 결합하면 무엇이 달라지는가?**

- - 예를 들어 ML-KEM으로 얻은 공유 비밀 S₁과 QKD로 얻은 S₂를 안전한 키 도출 함수에 넣어 세션 키를 생성할 수 있다. K = KDF(S₁, S₂, context)는 개념적 표현이며 특정 IonQ 구현 사양은 아니다.
  - 적절히 설계된 결합기에서 적어도 하나의 비밀이 안전하게 유지된다면 다른 비밀이 노출되어도 최종 키를 보호할 수 있다. 단, 인증·키 결합 방식·엔드포인트·난수·키 관리까지 안전해야 한다. 단순히 두 기술을 함께 설치한다고 보장되는 것은 아니다.
  - SIKE가 2022년 암호분석으로 깨진 사례는 PQC 후보도 실패할 수 있음을 보여준다. ML-KEM과 다른 수학적 기반을 사용하는 HQC를 백업으로 선택하는 것과 QKD를 추가하는 것은 서로 다른 위험 분산 전략이다. ML-KEM이 현재 깨졌다는 의미는 아니다.

|  |  |  |
| --- | --- | --- |
| **방식** | **보호 원리** | **제약** |
| ML-KEM | 격자 기반 공유 비밀 수립 | 수학적 가정 및 구현 보안 |
| HQC | 코드 기반 대체 KEM | 표준화·제품 지원 일정 |
| QKD | 양자 상태 측정과 비밀키 생성 | 광 경로, 인증, 장비 신뢰 |
| 하이브리드 | 독립적인 비밀을 결합 | 검증된 결합기와 키 수명주기 관리 |

**📌 Q-KMS가 중요한 이유**

- - 지난 11월 19일 글 [IonQ의 국제 양자보안망 전략](https://blog.naver.com/4-fire/224483612297)에서 한국–싱가포르 구간의 QKD–PQC 연동과 Clarion KX, ETSI 014/020을 다뤘다. 이번 글은 키를 소비하는 VPN·암호화 장비와 키 공급원을 분리하는 관점을 뒷받침한다.
  - 다만 구간별 QKD/PQC 연결과 동일 세션에 두 공유 비밀을 결합하는 것은 서로 다른 설계다. 제네바 현지 QKD와 제네바–서울 PQC VPN 사례만으로 모든 회선이 이중 키 결합을 사용한다고 볼 수 없다.
  - IDQ의 키 관리 플랫폼과 IDEMIA의 HSM 연동, Elisity의 접근 제어는 각각 키 공급, 키 보호, 접근 통제라는 다른 층에 해당한다. 통합의 가능성은 있지만 하나의 완성된 제품 또는 확정 계약이라는 증거는 아니다. 관련 글: [양자보안 심화 (4) — QSPM·QKD·HSM·Elisity](https://blog.naver.com/4-fire/224463889105)

**📌 미국 국방시장에서는 오히려 QKD 제약을 봐야 한다**

- - IonQ는 NSA의 국가안보시스템 QKD 비권고와 국방부의 양자내성 보안 수단 관련 제한을 명시했다. 따라서 미국 PQC 의무화가 곧 미국 국방 QKD 의무 구매로 이어진다는 해석은 틀리다.
  - QKD의 추가 가치가 성립하려면 통제 가능한 양단 장비, 광 경로, 장기간 기밀성, 별도 예산 및 해당 기관의 승인 정책이 필요하다. 위성 중계도 신뢰 노드 여부와 기상·키 생성률을 고려해야 한다.

**✅ 2. Holdover — GPS가 끊겨도 시간은 얼마나 정확해야 하는가?**

- - 기존 글 [GPS, Iridium STL, 그리고 양자센서 기반 PNT의 진화](https://blog.naver.com/4-fire/224331891240) 및 [Vector Atomic의 Evergreen-05 정체](https://blog.naver.com/4-fire/224371808261)에서 PNT 구조와 EG-05/30의 스펙을 비교했다. 이번에는 구매자가 실제로 평가해야 할 시간 유지 성능에 초점을 맞춘다.
  - GPS에 동기화된 시계는 외부 기준으로 내부 발진기를 보정한다. 외부 신호가 끊기면 내부 발진기만으로 시간을 유지한다. Holdover는 허용 시간 오차를 초과하기 전까지의 기간이다.

**📌 시간 오차는 왜 누적되는가?**

- - 일정한 상대 주파수 오차 y가 있으면 시간 오차는 Δt = yT이다. 예를 들어 y = 10-9이면 하루(86,400초) 후 86.4 μs의 오차가 발생한다.
  - 주파수 자체가 일정한 속도 D로 변하면 Δt = y₀T + ½DT2라는 근사 모델을 사용할 수 있다. 초기 오차가 무시되고 선형 노화만 지배할 때 오차가 시간의 제곱에 비례한다. 실제 시계에서는 온도, 진동, 랜덤 노이즈와 보정 알고리즘도 영향을 준다.
  - 빛은 1 ns 동안 약 30 cm 이동한다. 이는 신호 거리 환산 오차이지 모든 위치 측정에서 실제 위치 오차가 반드시 30 cm라는 뜻은 아니다.

**📌 서로 다른 원자시계의 성능을 어떻게 비교할까?**

|  |  |  |  |
| --- | --- | --- | --- |
| **시계** | **허용 오차** | **유지 기간 또는 시험 결과** | **주의점** |
| 루비듐 | 100 ns | 약 6시간 | CISA 수치, 구성에 따라 다름 |
| 표준 세슘 | 100 ns | 11일 | 동일 조건 현장 시험 아님 |
| 고성능 세슘 | 100 ns | 72일 | 크기·환경 조건 고려 |
| Evergreen-05 | 1 ns | 10일 | IonQ가 제시한 이동 플랫폼 성능 |
| Evergreen-30 | 일일 드리프트 | 약 300 ps/일, 20일 해상 시험 | 고정 오차 한계 시험과 다름 |

- - 위 표는 IonQ의 인용 자료와 제품 설명을 정리한 것으로 동일 환경·동일 오차 기준의 독립 벤치마크가 아니다. EG-05의 1 ns/10일은 평균 상대 주파수 오차로 단순 환산하면 약 1.16×10-15이다. 이는 Allan deviation이나 보장된 모든 순간의 주파수 오차와 다르다.
  - 표준 세슘의 100 ns/11일과 EG-05의 1 ns/10일은 허용 오차 기준에서 약 100배 차이가 난다. 이를 제품 전체 성능이 무조건 100배라는 의미로 확대해서는 안 된다.
  - 기존 비교에서 EG-30은 29 L, EG-05는 5 L로 약 5.8배의 부피 차이가 있었다. EG-30의 1초 안정도 25 fs와 EG-05의 50 fs를 보면 소형화가 모든 성능의 향상을 뜻하지 않는다. 핵심은 SWaP와 현장 환경에서의 정밀도다.

**📌 광학시계의 경쟁력과 검증 항목**

- - 광학시계는 요오드 분자의 광학 전이 등 고주파 기준을 레이저로 추적하고, 광주파수 빗(frequency comb)으로 전자회로에서 활용 가능한 주파수에 연결한다. 높은 기준 주파수는 정밀 측정의 이점이 있지만 레이저 안정화와 환경 제어가 중요하다.
  - 실제 구매에서는 허용 오차, 보정 적용 여부, 온도·충격·진동, 전력 재인가 후 안정화 시간, GPS 복구 시 재동기화 시간, 시험 반복성과 신뢰구간까지 확인해야 한다. IonQ는 자체 장비의 비보상 성능을 공개한다고 설명한다.
  - 통신망에서도 GNSS 대체 기준은 PTP(IEEE 1588)·SyncE와 함께 운용할 수 있다. 원자시계가 시간을 보존하더라도 네트워크 전송 비대칭, 경계 시계 오차, 지연 변동은 별도로 관리해야 한다. 원자시계 자체는 위치를 계산하는 독립 항법 장치가 아니다.
  - 과거 DARPA 제조계약 분석: [DARPA, IonQ로부터 차세대 원자시계 제조 계약](https://blog.naver.com/4-fire/224370109407) 및 [DARPA 원자 시계 계약 업데이트](https://blog.naver.com/4-fire/224371133438). 기존 계약의 확정 물량과 옵션은 구별해야 하며 이번 블로그는 추가 수주 발표가 아니다.

**✅ 3. 연방정부 PQC 전환 — 규정이 매출보다 먼저 움직인다**

- - 기존 [트럼프의 양자 행정명령 전격 분석](https://blog.naver.com/4-fire/224324949868) 및 [NIST PQC 전환 지침 최종 확정](https://blog.naver.com/4-fire/224457006220)에서 정책과 알고리즘 전환을 다뤘다. 이번 IonQ 글은 정부 기관뿐 아니라 납품업체의 준비 일정에 초점을 맞춘다.
  - IonQ가 설명한 EO 14412의 핵심은 적용 대상 정부 고가치 자산과 고영향 시스템의 키 설정 및 서명 전환과, 적용 대상 계약업체에 대한 별도 FAR 규칙 제정이다. 국가안보시스템은 별도 일정이며 모든 계약업체에 동일 요구가 적용되는 것은 아니다.

|  |  |  |
| --- | --- | --- |
| **일정** | **대상** | **의미** |
| 2026-10-22 | 기관 | 전환 계획 제출 기한 |
| 2026-12-19 | FAR Council | PQC 관련 규칙안 기한 |
| 2027-03-19 | FAR Council | 취약점 공개 관련 규칙안 기한 |
| 2030-12-31 | 적용 기관·계약업체 | 기관 키 설정 전환 및 계약업체 준수 목표 |
| 2031-12-31 | 적용 기관 | 전자서명 전환 |
| 2035 | NIST/OMB 전환 일정 | 관련 기존 알고리즘 퇴출 및 전환 목표 |

- - 위 일정은 IonQ의 정책 설명에 근거하며 최종 FAR 조문과 적용 범위는 이번 글에서 별도로 확정되지 않았다. 계약업체의 서명 전환이 기관보다 1년 앞설 가능성도 규칙안에 따라 달라진다.
  - FIPS 203은 ML-KEM, FIPS 204는 ML-DSA, FIPS 205는 SLH-DSA에 해당한다. 알고리즘 표준 준수와 실제 암호 모듈 검증은 별개이며, 모든 공급업체가 세 알고리즘을 전부 사용해야 한다는 뜻도 아니다.

**📌 왜 지금부터 준비해야 하는가?**

- - 암호 자산 인벤토리 → 위험 분류 → 제품·라이브러리 교체 → 상호운용 테스트 → 인증·배포 → 장기 운영으로 이어지는 작업은 단순 소프트웨어 패치가 아니다. VPN, TLS, SSH, PKI, 코드서명, HSM, 펌웨어와 공급망 전체가 영향을 받을 수 있다.
  - IonQ가 인용한 GAO 보고서는 24개 CFO Act 기관의 준비 부족을 지적하지만, 그 조사 상태는 2026년 6월 행정명령 이전을 반영한다. 이를 현재 24개 기관의 실시간 진척도라고 해석하면 안 된다.
  - 정부 조달 공고가 최종 규정 이전에 PQC 지원을 요구할 수 있기 때문에 실질적인 경쟁 시점은 2030년보다 빠를 수 있다. 관련 글: [PQC 탐지, 스위치가 열쇠가 될까요?](https://blog.naver.com/4-fire/224461135839).

**✅ 4. 종합 분석 — IonQ의 정부 사업과 투자자가 볼 지표**

|  |  |  |
| --- | --- | --- |
| **사업 영역** | **고객의 문제** | **추적할 증거** |
| PQC·Q-KMS | 암호 전환 및 키 관리 | 제품 인증, 조달 공고, 상용 계약 |
| QKD | 특정 장기 기밀 회선 | 정책 허용, 상호운용, 구축 수주 |
| Elisity | 접근 제어와 자산 가시성 | 통합 기능, 고객 채택과 반복 매출 |
| Vector Atomic | 외부 시간 기준 상실 | 독립 성능 시험, 납품·옵션 행사 |

- - 세 글의 공통점은 미래 양자컴퓨터의 성능만 팔겠다는 것이 아니라 현재 고객이 운영 중인 인프라의 전환 문제를 다룬다는 점이다. 양자컴퓨터 상용화와 별개로 발생하는 보안·정밀 시간 수요에 접근할 가능성이 있다.
  - 다만 보안 장비의 공공조달 시장은 기존 HSM·네트워크·PKI 업체의 경쟁이 치열하고, 광학시계는 환경 검증과 생산 확장이 필요하다. 제품 포트폴리오가 넓다는 사실만으로 시장 지배력이나 매출을 계산할 수 없다.
  - 특히 12월 FAR 규칙안의 적용 대상, IDQ와 기존 기업 인프라의 상용 연동, EG-05의 제조·납품, 후속 옵션 행사 여부가 향후 확인할 핵심이다. 세 블로그가 같은 날 게시됐다는 사실은 마케팅 방향의 단서이지 특정 계약 발표가 임박했다는 증거는 아니다.
