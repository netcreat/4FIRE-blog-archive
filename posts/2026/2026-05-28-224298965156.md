**📌 FOWLP**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA1MjhfMTMy/MDAxNzc5OTQ0MDE2MTA5.8-3xr99cOJicqx8yqXlm5HEBEc-Yw4ZEk_Rsfl8j1SAg.dujX6oH_kldMWqpIP1XKZNQSne5AqFKVcJ4MqN_SLR8g.PNG/image.png?type=w800)](#)

- - FOWLP = Fan-Out Wafer-Level Packaging
  - 근데 사실 개념은 생각보다 단순하다.
  - **기존 칩 패키징은 이런 느낌이었다**

    - 예전에는 칩을 기판(substrate)에 올리고, 배선을 하는 패키지구조였다.
    - 즉 칩 아래에 “작은 메인보드” 같은 substrate가 들어간다.
    - 문제는:

      - 크기 커짐
      - 전력 손실
      - latency 증가
      - 배선 길이 증가
    - 가 생깁니다.
  - **FOWLP는 substrate를 줄여버린다**

    - FOWLP는 칩을 molding material 안에 묻어버린 뒤, 그 위에 직접 배선(RDL: Redistribution Layer)을 만든다.
    - 즉 “작은 메인보드”를 없애고, 칩 바로 위에서 wiring을 하는 느낌이다.
    - 그래서 더 얇고, 더 작고, 더 빠르고, 전력 효율이 좋아진다.
  - **7. 왜 “Fan-Out”이냐?**

    - 칩보다 바깥쪽까지 배선을 “펼쳐서(fan-out)” 연결하기 때문이다.
    - 즉 작은 칩 위의 연결을, 바깥으로 넓게 확장해서

      - 메모리
      - RF
      - sensor
      - 다른 칩
    - 들과 연결하기 쉬워진다.
  - **8. Deca Adaptive Patterning이 왜 중요하냐?**

    - 여기서 재미있는 부분이 나온다.
    - 보통 FOWLP의 가장 큰 문제는 칩 위치가 미세하게 틀어지는 것이다.
    - 칩이 조금만 움직여도 배선이 안 맞아서 수율이 깨진다.
    - Deca는 여기서 **“그냥 실제 칩 위치를 측정해서,** 배선을 그 위치에 맞춰 다시 그리자”라는 접근을 한다.
    - 즉:

      - optical scan으로 위치 측정
      - software가 routing 자동 수정
      - 다시 배선 생성
    - 구조다.
    - 이걸 Adaptive Patterning이라고 부른다.
    - 그래서 수율 상승, 비용 감소 ,throughput 증가 효과가 크다.
  - **9. 왜 SkyWater가 이걸 먼저 밀고 있나?**

    - 중요한 건 FOWLP는 현실적으로 SkyWater가 가장 빨리 production-ready에 접근 가능한 기술이라는 점이다.
    - 왜냐하면:

      - Deca 기술은 이미 상당 부분 proven
      - RESHAPE 자금으로 tooling 구축 중
      - defense low-volume/high-mix 시장과 잘 맞음
    - 이기 때문이다.
    - 반면:

      - silicon interposer
      - hybrid bonding
    - 은 훨씬 난이도가 높고, 아직 capability build-up 단계에 더 가깝다.
    - 즉 현재 SkyWater 전략은 사실상:
    - **현재**

      - FOWLP로 실제 manufacturing ramp
    - **이후**

      - interposer + photonics integration
    - **장기**

      - hybrid bonding + ultra-dense systems
    - 순서에 가깝다.

- - HBM 구조를 보면:

  - 역할을 합니다.
  - 즉 “칩끼리 매우 촘촘하게 연결해주는 실리콘 배선판”이다.
  - 대표:

    - TSMC CoWoS
    - Intel EMIB 일부 구조

**📌 TSV-las**

- - TSV = Through Silicon Via
  - 즉 실리콘을 관통하는 수직 배선.
  - 3D 적층에서:

    - memory stack
    - stacked die
  - 연결에 사용된다.
  - TSV-last는 공정 후반에 TSV를 형성하는 방식인데, 주로:

    - 비용
    - yield
    - heterogeneous integration flexibility
  - 때문에 사용된다.

- - Interposer는 생각보다 오래됐다.
  - 사실 시작은 2019년 DoD IBAS 프로그램.
  - 여기서

    - BRIDG

**📌 Hybrid bonding**

- - 예전에는 칩과 칩을 연결할 때, 사이에 solder bump 또는 microbump라 불리우는 작은 “납땜 공” 같은 걸 넣었다.
  - 문제는 침 사이 대역폭 요구량이 폭발적으로 증가하면서, 금속 공 방식은 아무리 작게 만들어도 한계가 있어서 병목이 되기 시작했다.
  - Hybrid bonding은 아예 bump를 없애고, 칩 표면을 완전 평평하게 만든 뒤, 칩과 칩을 직접 붙이는 방식이다.
  - Hybrid라는 이름이 붙은 이유는, Copper-to-copper 연결과 Oxide-to-oxide 결합, 즉 전기적 연결과 기계적 결합을 동시에 하기 때문이다.
  - 여기서 난이도가 갑자기 급상승한다.

    - 왜냐하면 이건 사실상 “원자 수준 정밀 제조”에 가깝기 때문이다.
    - 필요한 조건이 굉장히 까다롭다.

      - 표면이 극도로 평평해야 함
      - alignment 오차가 거의 없어야 함
      - contamination 거의 없어야 함
      - thermal distortion 관리 필요
      - wafer warpage 문제 해결 필요
    - 즉 “칩을 붙인다”수준을 넘어, 초정밀 재료공학 + 공정제어 문제다.
  - 그래서 실제로 high-volume 양산 가능한 회사가

    - TSMC
    - Intel
    - Samsung
  - 정도밖에 없다.
  - SkyWater도 이걸 알고 있다.
  - 그래서 지금은 **“Adeia와 함께 capability를 확보하는 단계”**에 가깝다.
  - 즉 production leader가 아니라, **future roadmap positioning**에 더 가깝다.

**📌 그럼 왜 SkyWater가 이걸 말하냐?**

- - 여기가 핵심이다.
  - SkyWater가 진짜 원하는 건 **“HBM을 직접 만들겠다”**가 아니라, **“고밀도 heterogeneous integration capability를 확보하겠다”**이다.
  - 필요 분야

    - Photonic integration
    - RF + compute integration
    - Quantum / cryogenic integration
