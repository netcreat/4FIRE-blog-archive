# 미국이 믿고 맡길 수 있는 반도체 공장은 어디인가 — DMEA Trusted Foundry 지형도와 진짜 경쟁력

Published: 2026-10-07T10:58:22+11:00

Original Naver post: https://blog.naver.com/4-fire/224433756102?fromRss=true&trackingCode=rss

---

**✅ DMEA Trusted Foundry를 왜 따로 봐야 하는가**

- - GlobalFoundries와 SkyWater를 비교하다가 미국 국방부 산하 DMEA의 **Trusted Supplier 생태계**까지 들어오게 됐다.
  - 2026년 9월 3일 최신 DMEA 지도에는 **79개의 Trusted Supplier**가 올라와 있다.
  - 하지만 79개 모두가 wafer를 직접 만드는 파운드리는 아니다.
  - DMEA는 반도체 공급망을 설계부터 제조·패키징·테스트까지 여러 단계로 나눠 인증한다.
  - 따라서 단순히 “DMEA 인증을 받았다”는 것만으로 생산능력이나 기술력을 판단하면 안 된다.
  - 더구나 같은 Category 1A라도 한쪽은 연구·prototype 중심이고 다른 한쪽은 연 수십만 장의 wafer를 생산하는 상업 HVM fab일 수 있다.
  - 결국 Trusted Foundry는 최소한 다음 다섯 가지를 함께 봐야 한다.

    - **Trust × Technology × Capacity × Production Maturity × Accessibility**
  - DMEA도 Trusted Supplier의 역할을 classified·unclassified IC의 chain of custody 확보, 공급 중단 위험 완화, 변조 방지, reverse engineering 및 민감정보 노출 방지로 정의한다.
  - 동시에 Trusted Foundry Program은 MPW와 prototype뿐 아니라 **high-volume production까지 지원**한다고 명시한다.
  - 최신 DMEA Accredited Supplier List는 아래 공식 자료에서 확인할 수 있다.

    - <https://www.acq.osd.mil/asds/dmea/tapo/docs/tp/Accredited-Supplier-List-3SEPT26.pdf>

**✅ Category와 Scope는 완전히 다른 개념이다**

**📌 Category는 보안 수준이다**

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **의미** | **Classified** | **Unclassified** |
| **Category 1A** | 가장 높은 수준의 Trusted 보호조치 | O | O |
| **Category 1B** | Trusted unclassified full-flow 생산 | X | O |
| **Category 2 등 과거 표현** | 현재 1A/1B와 단순 상하관계로 보면 안 됨 | 별도 조건 | 별도 조건 |

- - Category 1A는 DoD가 부여하는 가장 높은 Trusted Foundry 등급으로 설명된다.

    - Qorvo Richardson의 1A 인증은 classified 프로그램까지 지원하며 Qorvo도 이를 DoD의 최고 등급이라고 명시한다.

      - <https://ir.qorvo.com/news-releases/news-release-details/triquint-accredited-dod-category-1a-trusted-foundry>
    - GF 역시 Malta와 Burlington을 포함한 미국 제조시설이 **Category 1A**라고 밝히고 있다.

      - <https://gf.com/news-and-events/news/u-s-government-accredits-globalfoundries-to-manufacture-trusted-semiconductors-at-new-york-facility>
    - SkyWater Minnesota도 생산규모 wafer fab 자체가 Category 1A 인증을 받았다.

      - <https://www.skywatertechnology.com/skywater-technology-foundry-achieves-cat1a-trusted-foundry-accreditation-from-u-s-department-of-defense>
    - Tower의 JSTF는 Category 1A에 더해 **1B**도 획득했는데, Tower는 1B를 상업 fab에서 Trusted unclassified full-flow wafers를 생산하기 위한 인증으로 설명한다.

      - <https://ir.towersemi.com/news-releases/news-release-details/jazz-semiconductor-trusted-foundry-jstf-announces-accreditation>
  - 따라서 1A → 1B를 단순히 기술력 1등급 → 2등급처럼 해석해서는 안 된다.

**📌 최신 DMEA 명단에는 Category가 표시되지 않는다**

- - 2026년 9월 3일 Supplier List에는 개별 supplier의 **Scope of Accreditation**은 표시되지만 1A/1B는 표시하지 않는다.
  - 따라서 정확한 Category는 해당 facility의 DMEA certificate나 기업의 공식 accreditation 발표를 별도로 대조해야 한다.
  - 이 글에서도 공개적인 1A/1B 근거를 확인할 수 있는 경우와 단순 DMEA Accredited 상태를 구분해서 표시한다.
  - 2026년 9월 3일 최신 DMEA Accredited Supplier List는 Category 1A·1B를 직접 표시하지 않고 Scope of Accreditation만 공개한다.
  - 따라서 본문의 Category 표기는 최신 Supplier List에서 추론한 것이 아니라 각 기관의 DMEA accreditation 발표·인증서·공식 자료를 별도로 대조한 결과다.
  - 공개적으로 site-level Category를 확인하지 못한 경우에는 임의로 Category 1A라고 추정하지 않았다.

**✅ Scope는 “Trusted 환경에서 어디까지 할 수 있느냐”다**

|  |  |
| --- | --- |
| **Scope** | **실제 의미** |
| **Design** | IC 설계, layout, 설계 IP를 Trusted 환경에서 처리 |
| **Aggregation** | 여러 die·IP·공정·공급자를 하나의 Trusted 제품으로 통합 |
| **Broker** | Trusted 공급자 선정, 주문, 조달, chain of custody 관리 |
| **Mask Data Parsing** | GDS/OASIS를 mask writer용 데이터로 변환 |
| **Mask Manufacturing** | 실제 photomask/reticle 제작 |
| **Foundry** | FEOL/BEOL wafer fabrication |
| **Post-Processing** | thinning, bumping, TSV, RDL 등 wafer 후공정 |
| **Packaging/Assembly** | die attach, flip-chip, wire bonding, module/package 조립 |
| **Test** | wafer probe, electrical test, final test 등 |

- - DMEA는 현재 Design, Aggregation, Broker, Mask Manufacturing, Foundry, Post Processing, Packaging/Assembly, Test 등을 별도 accreditation 영역으로 관리한다.
  - 따라서 Category 1A라는 말보다 실제로 투자·산업적으로 더 중요한 경우도 있다.
  - 예를 들어 Category 1A라도 Packaging/Assembly만 인증받았다면 그것은 Category 1A wafer fab과는 전혀 다른 의미다.

**📌 GF Malta와 MIT Lincoln Laboratory가 좋은 예다**

| **항목** | **GF Malta** | **MIT Lincoln Laboratory** |
| DMEA | **Category 1A** | **Category 1A** |

| 대표 Silicon Node | **12nm FinFET** | **90nm FD-SOI** |
| 목적 | Commercial + Defense | R&D + Prototype |
| 공개 Capacity | **400K wafers/year** | 상업 WSPY 없음 |
| 강점 | **Scale / HVM** | **첨단 R&D / Prototype** |

- - 둘 다 최고 수준 Trusted 인증을 가졌지만 산업적 의미는 완전히 다르다.
  - 따라서 DMEA 분석에서는 Category 1A라는 체크박스보다 **그 뒤에 붙어 있는 생산성격**을 봐야 한다.

**✅ Node 숫자를 단순 비교해서도 안 된다**

**📌 12nm와 70nm가 항상 12nm의 승리는 아니다**

- - DMEA 공정표에는 다음과 같은 숫자가 동시에 등장한다.

    - GF 12nm FinFET
    - BAE 70nm GaAs pHEMT
    - MIT 90nm FD-SOI
    - Northrop 100/150mm III-V
  - 그러나 이 숫자는 서로 같은 의미가 아니다.
  - Silicon CMOS node와 GaAs/GaN HEMT gate length는 직접 비교할 수 없다.
  - 따라서 비교할 때는 우선 소재와 용도를 분리해야 한다.

**📌 Silicon 기준으로만 보면**

|  |  |
| --- | --- |
| **구간** | **의미 있는 Trusted 후보** |
| **<20nm** | **GF Malta — 12nm FinFET** |
| **20~65nm** | GF, onsemi EFK |
| **65~90nm** | SkyWater Texas, SkyWater Minnesota, MIT LL |

    - advanced packaging
  - 에 걸쳐 상당히 폭넓은 Trusted manufacturing capability가 존재한다.
  - 그러나 모든 Trusted Fab은 같지 않다.

    - 어떤 곳은 국가연구소이고, 어떤 곳은 defense captive fab이고, 어떤 곳은 외부 고객을 받는 대형 commercial foundry다.
  - 따라서 앞으로 DMEA fab을 볼 때는 **Category만 보는 것이 아니라 Trust × Technology × Capacity × Production Maturity × Accessibility를 동시에 볼 필요가 있다.**

    - 이 기준으로 보면 GF는 미국 Trusted ecosystem에서 **가장 폭넓은 기술과 상업 HVM을 동시에 가진 업체 중 하나**다.
    - SkyWater는 절대 규모에서는 GF보다 작지만 **custom process·신소재·quantum·advanced packaging**이라는 다른 방향에서 매우 독특한 위치를 갖는다.
  - 그렇다고 GF와 SkyWater만 중요한 것은 아니다.

    - Tower는 SiGe·RF·Photonics, onsemi는 Power·Sensor, Qorvo와 MACOM은 GaN·GaAs, Honeywell은 Rad-hard, Northrop은 방산 microelectronics와 III-V, SRI는 legacy sustainment에서 각각 대체하기 어려운 전문성을 갖는다.
    - MIT Lincoln Laboratory와 Sandia 역시 commercial HVM과는 다른 방식으로 Quantum·Photonics·신소재의 upstream R&D를 담당한다.
  - 따라서 다음 편에서 GF와 SkyWater를 비교할 때도 이 업체들을 각 기술영역의 **benchmark**로 활용할 필요가 있다.
  - MIT Lincoln Laboratory와 Sandia는 당장 대규모 wafer 매출을 만드는 commercial fab은 아니지만 차세대 quantum·photonics·materials technology를 발전시키는 중요한 upstream 역할을 한다.
  - 특히 Sandia는 IonQ 초기 ion trap 제작부터 2026년 공식 MOU까지 이어지는 관계를 갖고 있어 IonQ의 quantum manufacturing 전략을 이해할 때 별도로 볼 가치가 있다.
