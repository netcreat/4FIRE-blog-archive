**✅ 시계의 기본 공식**

- - 모든 시계의 구조는

    - Time = (number of cycles) / (frequency)
  - frequency가 **얼마나 정확하고 안정적이냐**가 시계의 성능을 결정

    - **진자식 - 괘종시계**
    - **기계식 크로노미터**

      - 기계식 시계의 끝판왕
      - 스위스 공식 크로노미터 검사기관을 통과해야 판매 가능
      - 제작 난이도가 극악이라 인간이 만들 수 있는 기계식의 끝
    - **쿼츠(Quartz crystal)**

      - 성질: **압전 효과**

        - 전기를 주면 진동
        - 진동하면 전기 신호 생성
      - 대표 주파수:

        - **32,768 Hz (2****15****)**
      - 전자적으로 쉽게 다룰 수 있기 때문에 작고 싸게 만들 수 있고, 충분히 안정적으로 동작하기 때문에 일반 시계에 널리 사용됨
    - 원자 시계

      - 원자 또는 분자의 전이를 이용하여 진동을 생성함.
      - 여기서 전이란 자연이 정해놓은 각 원자나 분자가 가진 고유한 주파수를 이용하는 것이다.

        - 전이란 이온트랩에서 사용하는 이온을 들뜨게 만드는 것과 개념이 같다.
        - 다만, 이온트랩에서는 게이트를 수행해야 하기 때문에 전이된 상태가 오래 지속되어야 하는 반면,
        - 원자 시계에서는 들뜬 상태가 오래 지속될 필요가 없고, 오래 지속되면 오히려 성능이 떨어진다.
        - 오히려 들뜬 상태가 지속되는 시간보다, 얼마자 자주 들뜰 수 있는 상태를 찾는 것이 핵심이다.
      - 👉 전이는 **자연이 제공하는 ‘완벽한 진동자’**

****

**📌 굳이 원자까지 가는 이유?**

- - 주파수가 높을수록:

    - 한 번 흔들려도
    - 상대 오차가 작아짐
  - 그리고:

    - 쿼츠는 **온도·노화·응력**에 취약
    - 원자 전이는 **자연 상수**

| --- | --- | --- |
| **진동자** | **주파수** | **안정성** |
| 쿼츠 | 10⁴ Hz | 낮음 |
| 루비듐 | 10⁹ Hz | 높음 |
| 세슘 | 10⁹ Hz | 매우 높음 |
| 요오드(광학) | 10¹⁴ Hz | 극도로 높음 |

**✅ 원자 시계**

**📌 전통적 원자시계 (마이크로파 기반)**

- - **세슘 (Cesium, Cs-133)**

    - **용도**: 국가 표준시(초의 정의)
    - **전이**: 마이크로파(9,192,631,770 Hz = 9.19 GHz) - 전이가 가장 강하게 일어나는 조건

      - 원자가 직접 9.19GHz로 뛰는 것이 아님
      - **원자는 단지 기준일뿐, 발진기가 제대로 동작하는지 감시하는 역**
      - 발진기가 초당 9,192,631,770번 진동을 하고,
      - 그 진동을 카운트 해서 9,192,631,770번=1초
    - **장점**: 절대 표준, 장기 안정성
    - **단점**: 크고 비싸며 소형화 한계
    - **👉 “1초”의 정의 그 자체**
  - **루비듐 (Rubidium, Rb-87)**

    - **용도**: 위성·통신·군용 타이밍
    - **전이**: 마이크로파
    - **장점**: 작고 저렴, 실사용에 적합
    - **단점**: 정확도는 세슘보다 낮음
    - 👉 GPS·통신 장비에 가장 흔함

**📌 차세대 광학 원자시계 (Optical Atomic Clock)**

- - **요오드 (Iodine, I****2****) – 분자**

    - **전이**: 광학(~5×1014Hz = 수백 THz)
    - **장점**:

      - 레이저 안정화에 매우 좋음
      - **상온·견고·소형화 유리**
    - **단점**:

      - 단일 원자 대비 궁극 정확도는 낮음
    - 👉 **현장형·군용·GNSS 대체에 최적**
    - 👉 Vector Atomic의 **핵심 상용 선택지**
  - **스트론튬 (Strontium, Sr-87)**

    - **전이**: 광학
    - **장점**: 세계 최고 수준 정확도
    - **단점**:

      - 레이저·냉각 복잡
      - 실험실 중심
    - 👉 NIST·PTB 같은 **국가표준 랩**에서 사용
  - **이터븀 (Ytterbium, Yb-171)**

    - **전이**: 광학
    - **장점**: 스트론튬과 비슷한 최고 성능
    - **단점**: 시스템 복잡
    - 👉 차세대 표준 후보
  - **알루미늄 이온 (Al****+****)**

    - **전이**: 광학
    - **장점**: 이론적 최상 정확도
    - **단점**:

      - 이온 트랩 필요
      - 극도로 복잡
    - 👉 “궁극의 정확도”, **실험실 전용**

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **원자/분자** | **타입** | **정확도** | **소형화** | **현장 배치** | **대표 용도** |
| 세슘 | 마이크로파 | 중 | ❌ | ❌ | 초의 정의 |
| 루비듐 | 마이크로파 | 중- | ⭕ | ⭕ | GPS·통신 |
| **요오드** | **광학** | **높음** | **⭕** | **⭕** | 군·GNSS 대체 |
| 스트론튬 | 광학 | 최고 | ❌ | ❌ | 국가 표준 |
| 이터븀 | 광학 | 최고 | ❌ | ❌ | 차세대 표준 |
| 알루미늄 이온 | 광학 | 최고+ | ❌ | ❌ | 연구용 |

**📌 왜 Vector Atomic은 요오드를 쓰나?**

- - 핵심 이유는 - “랩에서 제일 정확한 시계”가 아니라 “현장에서 실제로 쓰이는 광학 시계”가 목표이기 때문

    - 냉각 필요 없음
    - 진동·온도 변화에 강함
    - 랙마운트 가능
    - 군·우주·GNSS 대체에 바로 연결
  - 그래서:

    - **NIST** → Sr / Yb
    - **Vector Atomic / IonQ** → **Iodine**
  - 이라는 선택이 갈린다.

> *지금까지의 구조는 루비듐이나 세슘 원자시계를 탑재한 GPS로 부터 시간 정보를 받아왔다면,*
>
> *이제는 더 정확한 원자시계를 자체 보유하게 됨으로써,* ***시간의 주권(time sovereignty)****을 확보하게 되는 것이다.*

**📌 GPS를 이용하여 시간을 동기화 하는 방법**

- - 각 위성은 3개의 루비듐 기반의 원자시계를 보유
  - 미 해군 천문대와 양방향으로 RF 신호를 주고 받으면서 위성 시계의 오차를 측정하고 보정함
  - 지상의 사용자 수신기는

    - 위성 시계를 직접 믿는 것이 아니라
    - 여러 위성의 시간 차이(TOF)를 이용해 위치와 시간을 계산함
  - → 정확한 시간은 항상 멀리 있고, 위성 또는 그 외 여러 이유로 시간 동기화를 못할 가능성 있음
  - → 거리가 멀기 때문에 딜레이가 발생됨.

**✅ Comb이란?**

- - Frequency comb은 빛을 ‘정확히 간격이 같은 수천~수백만 개의 주파수 선’으로 쪼개서,
  - 광학 주파수(THz)를 마이크로파(MHz·GHz)와 정확히 연결해 주는 장치다

**📌 왜 comb이 필요했는지 다시 문제부터**

- - 세슘:

    - 9.19 GHz → 전자적으로 바로 셀 수 있음
  - 요오드:

    - ~500 THz → ❌ 직접 셀 수 없음
  - “그럼 그냥 나누면 되지 않나?”

    - 1014을 **정확도를 잃지 않고** 나누는 전자회로는 없음
    - 👉 **중간 번역기 필요** → comb

**📌 comb의 두 개의 핵심 숫자**

- - Comb은 사실 **두 개의 마이크로파 신호**로 완전히 정의됨.
  1. **반복률 (repetition rate, fr)**

     - 펄스가 반복되는 주기
     - 보통: **100 MHz ~ 1 GHz**
     - 👉 전자적으로 직접 측정 가능
  2. **오프셋 주파수 (f₀)**

     - 전체 comb이 얼마나 밀려 있는지
     - 이것도 마이크로파 영역
     - 👉 역시 측정 가능
  - 이 둘을 이용하여 광학 주파수를 "**정수** × 마이크로파"로 표현할 수 있게 됨.

**📌 그래서 comb이 가능한 이유 (물리적 원리)**

- - comb은 사실:

    - **초단 펄스 레이저**
    - 펄스가 매우 정확한 간격으로 반복

      - | pulse | pulse | pulse | pulse |
    - 시간 간격이 정확하면

- - - 푸리에 변환 결과가 **주파수 comb**

**📌 왜 comb이 “혁명”이었나**

- - comb 이전:

    - 광학 시계 = 서로 비교 불가
    - 마이크로파와 연결 불가
  - comb 이후:

    - 광학 ↔ 마이크로파 연결
    - 서로 다른 광학 시계 비교 가능
    - 초 정의 재정의 가능
  - 👉 그래서 **노벨상(2005)**

****

**📌 요오드 시계 + comb = 왜 올인원인가?**

- - 요오드:

    - 안정한 광학 기준
  - comb:

    - 그 기준을

      - 마이크로파 출력
      - 광학 출력
      - 로 동시에 배포
  - 👉 **한 전이 → 모든 인프라**

****

**📌 전체 흐름**

1. 1. **요오드 분자의 광학 전이**

      - 특정 광학 주파수에서 전이가 가장 잘 일어남
      - 이 전이를 기준으로 **레이저를 락(lock)**
      - → **광학 발진기**
   2. **그 광학 발진기를 frequency comb에 연결**

      - comb은 **광학 펄스 레이저**
      - comb의 모든 선이 요오드 전이와 **위상적으로 연결**
      - 👉 이 시점에서 **요오드의 “시간 정보”가 comb 전체에 복사됨**
   3. **comb에서 두 종류의 출력을 동시에 얻음**

      - **(A) 광학 출력**

        - 1064 nm 기준 레이저
        - 1560 nm comb light
        - 👉 광 네트워크, 광학 메트롤로지, 양자 링크용
      - **(B) 마이크로파 출력**

        - comb의 반복률(fr)
        - 또는 comb–레이저 비트 신호
        - → **10 MHz, 100 MHz, 1 PPS**
      - 👉 기존 통신·레이더·데이터센터 인프라용

> ***아주 짧은 비유***
>
> *요오드 전이 =* ***마스터 시계***
>
> *comb =* ***변속기***
>
> *광학 출력 =* ***전기차용 포트***
>
> *마이크로파 출력 =* ***내연기관용 포트***

[2308.12457](https://arxiv.org/pdf/2308.12457)

- - **Optical Two-Tone Time Transfer**

    - 광학 원자시계의 근본적인 문제점 해결

      - 정밀도를 네트워크로 전달 및 동기화 할 방법이 없었다.
      - GPS / 마이크로파 기반 시간전달

        - → **ps(10****-12****s) 수준**
      - 광학 시계 자체

        - → **fs ~ as(10****-18** **s) 수준**
    - **Vector Atomic의 핵심 해법: Two-Tone Optical Time Transfer**

      - **기존 방식의 문제**

        - **초단펄스 + 주파수 comb 2개 필요**
        - **장비 크고 복잡**
        - **자유공간·이동 플랫폼에 취약**
      - **VA의 방식 (Two-Tone)**

        - **주파수 comb는 그대로 사용**
        - **대신:**

          - **두 개의 CW 레이저(telecom DFB)만 링크에 송수신**
          - **두 레이저의 주파수 차이(Δf)로 “synthetic fringe” 생성**
        - **시간 지연 =**

          - **두 레이저가 겪은 위상 차이의 차이**
        - **핵심 아이디어**

          - “시간 지연 = 주파수 영역에서의 선형 위상 기울기
          - → 두 점만 찍어도 복원 가능”

**📌** **파운드리가 중요해지는 이유 (핵심 5가지)**

1. 1. **반복성 (Repeatability)**

      - 연구실:

        - “한 대 잘 만들면 됨”
      - 제품/군납:

        - “**100대가 전부 같은 성능**이어야 함”
      - 레이저 패키징
      - 광학 경로 정렬
      - RF/광 인터페이스
      - 이게 **손작업이면 게임끝**

        - ➡ **파운드리 공정 없이는 불가능**
   2. **집적도 (Integration)**

      - 지금 구조를 보면:

        - 원자/분자 셀
        - 레이저 광학 집적 소자
        - frequency comb
        - RF / ADC / DAC
        - 제어 ASIC
      - 이걸:

        - 나사 + 케이블 + 광섬유로 버티면 ❌
        - **Si photonics / RF IC / control ASIC**으로 묶어야 ⭕
      - 👉 이 순간부터:

        - 광학 + RF + 전자 혼합 반도체 문제
   3. **환경 내성 (Ruggedization)**

      - 6G 진동
      - 열 진공
      - 10년 방사선
      - 이건:

        - 논문 실력 ❌
        - **패키징·소재·공정 실력 ⭕**
      - 👉 “원자는 멀쩡한데, 패키지가 죽는” 경우가 대부분

        - ➡ **국방/우주 파운드리 경험 필수**
   4. **IP 보호 & 분리 생산**

      - 이 분야는 특히 치명적임

        - 고객 A: 국방
        - 고객 B: 위성
        - 고객 C: 상업 네트워크
      - 모두:

        - 같은 공정
        - 다른 설계
        - **완전한 IP 분리** 요구
      - ➡ **일반 상업 파운드리로는 불가**
      - ➡ **SkyWater 같은 ‘secure foundry’ 전용 영역**
   5. **스케일 전환 시점 (가장 중요)**

      - 지금은: “몇 대”
      - 곧: “수백~수천 노드”
      - 예:

        - GNSS 대체
        - 양자 네트워크 노드
        - 우주 Q-PNT
      - 이 순간:

        - 랩 장비 회사는 죽고 제조 플랫폼 회사만 살아남음
