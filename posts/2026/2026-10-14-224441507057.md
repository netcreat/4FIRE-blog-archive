# 코닝을 유리회사로만 보면 놓치는 것 — 반도체 원재료부터 Glass Core·GlassBridge까지

Published: 2026-10-14T17:50:40+11:00

Original Naver post: https://blog.naver.com/4-fire/224441507057?fromRss=true&trackingCode=rss

---

**✅ 코닝은 단순한 광섬유 회사가 아니다.**

- - 코닝(Corning)을 AI 데이터센터용 광섬유 회사로만 보면 전체 그림의 상당 부분을 놓치게 된다.
  - 코닝은 **Hemlock Semiconductor의 초고순도 polysilicon**부터 **Advanced Packaging용 Glass Carrier**, 차세대 **Glass Core**, 현재의 **FAU(Fiber Array Unit)**, 미래의 **GlassBridge**까지 서로 다른 반도체·광학 공급망 층에 걸쳐 있다.
  - 다만 이 사업들은 모두 같은 단계에 있지 않다. Hemlock·Glass Carrier·FAU는 이미 상용 영역이고, Glass Core와 GlassBridge는 차세대 성장 옵션에 가깝다.
  - 따라서 코닝의 핵심을 ‘Glass Substrate 시장 지배자’라고 단정하기보다, **반도체 원재료·패키징·광연결의 여러 병목에 동시에 노출된 소재·공정 기업**으로 보는 편이 더 정확하다.

---

**✅ 코닝은 반도체 공급망의 여러 층에 걸쳐 있다**

- - 코닝의 반도체·AI 인프라 포지션은 한 제품으로 설명하기 어렵다. 아래 표처럼 서로 다른 공급망 층에서 현재 사업과 미래 옵션이 겹쳐 있다.

|  |  |  |  |
| --- | --- | --- | --- |
| **공급망 층** | **코닝의 자산** | **현재 상태** | **핵심 의미** |
| 실리콘 원재료 | Hemlock Semiconductor의 hyper-pure polysilicon | 상용·대규모 | 반도체 wafer보다 앞단의 핵심 원재료 |
| Advanced Packaging | Glass Carrier, precision glass, ultra-low TTV glass | 상용 + 차세대 개발 | wafer thinning·fan-out·2.5D/3D packaging 공정 지원 |
| 차세대 Package Substrate | Glass Core용 fusion process·유리 조성·TGV 대응 기술 | 시장 형성·개발 단계 | organic core를 대체할 수 있는 차세대 substrate 후보 |
| PIC–Fiber 연결 | FAU, V-groove fiber array, specialty fiber | 상용 | 현재 silicon photonics와 외부 fiber를 정밀 연결 |
| 차세대 CPO | GlassBridge | 초기 개발·검증 | glass-waveguide 기반 detachable PIC-to-fiber 인터페이스 |
| 데이터센터 물리망 | Optical fiber·cable·connectivity | 기존 핵심 사업 | AI 클러스터의 대규모 광연결 인프라 |

- - 이 구조의 장점은 특정 한 기술의 성공 여부에만 의존하지 않는다는 데 있다.
  - Glass Core의 대량 채택이 늦어도 Glass Carrier와 기존 광통신 사업이 있고, GlassBridge 상용화가 늦어도 FAU는 이미 현실의 PIC–fiber 연결에 사용되고 있다.

---

**✅ Hemlock: 코닝은 반도체의 ‘시작점’에도 걸쳐 있다**

- - 코닝의 2025 Global Impact Report Appendix는 Hemlock Semiconductor에 대한 코닝의 지분을 **80.5%**로 설명한다.
  - Hemlock은 반도체와 태양광에 쓰이는 **hyper-pure polysilicon**을 생산한다.
  - 미국 상무부는 2025년 Hemlock을 **미국 소유의 유일한 hyper-pure polysilicon 제조업체**이며, leading-edge semiconductor에 필요한 순도를 생산할 수 있는 전 세계 약 5개 업체 중 하나라고 설명했다.
  - 미국 CHIPS Incentives Program은 Michigan의 신규 제조시설을 위해 Hemlock에 최대 **3억2,500만 달러**의 직접 지원을 확정했다.
  - 즉 코닝의 AI·반도체 노출은 데이터센터 fiber에서 끝나지 않고, silicon wafer가 만들어지기 전 원재료 단계까지 이어진다.

|  |  |  |
| --- | --- | --- |
| **단계** | **역할** | **코닝과의 연결** |
| Hyper-pure polysilicon | 고순도 실리콘 원재료 | Hemlock Semiconductor |
| Single-crystal ingot / wafer | 반도체 wafer 제조 | 코닝의 직접 핵심 제조 영역은 아님 |
| Logic / HBM | GPU·CPU·Memory die | 코닝의 직접 제조 영역은 아님 |
| Advanced Packaging | 여러 die를 패키지로 통합 | Glass Carrier·Glass Core 관련 기술 |
| Optical Connectivity | PIC·switch와 외부 fiber 연결 | FAU·GlassBridge |

**✅ Glass Carrier와 Glass Core는 전혀 다른 제품이다**

- - **Glass Carrier**는 완성 패키지 안에 남는 substrate가 아니다. wafer thinning, fan-out, 2.5D/3D packaging 중 wafer나 panel을 임시로 지지하는 공정용 유리다.
  - 코닝은 자사 glass carrier를 silicon wafer thinning, fan-out, advanced 2.5D/3D packaging용 temporary bonding에 공급한다고 설명하며, 이미 **top-tier 고객에게 수십만 장의 wafer**를 출하했다고 밝히고 있다.
  - 코닝은 조절 가능한 CTE, ultra-flat surface, 낮은 TTV, 투명성을 활용한 laser bonding/debonding을 장점으로 제시하며, Advanced Packaging Carrier가 공정 중 warpage를 **최대 40%** 줄일 수 있다고 설명한다.
  - **Glass Core / Glass Substrate**는 반대로 최종 package 구조에 남는 차세대 substrate 소재다. 기존 organic core를 대체하면서 더 큰 package와 높은 interconnect density를 지원하는 방향으로 개발되고 있다.
  - 코닝은 proprietary fusion process로 dimensional stability·ultra-flat surface·낮은 TTV를 구현하고, Through Glass Via(TGV) 형성과 metallization에 맞춘 유리 조성을 개발하고 있다고 밝힌다.

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **Glass Carrier** | **Glass Core / Substrate** | **Silicon Interposer** |
| 패키지에 남는가 | 아니오. 공정 후 분리 | 예 | 예 |
| 주요 역할 | 박막화·fan-out·2.5D/3D 공정 지지 | 칩과 PCB 사이의 배선·기계적 기반 | GPU·HBM·chiplet 사이 고밀도 연결 |
| 대표 구조 | Temporary bonding | TGV·RDL 등 | TSV·RDL 등 |
| 코닝의 위치 | 이미 상용 공급 | 유리 소재·공정 기술의 강한 후보 | Interposer 본체 소재 공급자는 아님 |

---

**✅ Glass Core 시장에서 코닝이 이미 압도적인가?**

- - **아니다.** 현재 공개 자료만으로 코닝이 Glass Core 또는 완성 Glass Substrate 시장에서 압도적인 점유율을 확보했다고 말할 근거는 없다.
  - Glass Core 시장 자체가 아직 대규모 HVM(high-volume manufacturing) 점유율을 안정적으로 비교할 단계까지 성숙하지 않았다.
  - 미국에서는 SKC 자회사 **Absolics**가 Georgia Covington에 glass substrate 시설을 구축하고 있으며, 미국 CHIPS 프로그램도 해당 프로젝트에 최대 **7,500만 달러**를 지원했다.
  - 따라서 코닝의 강점을 ‘완성 Glass Substrate 시장 1위’로 표현하기보다, 여러 substrate·packaging 업체가 활용할 수 있는 **precision glass·carrier·fusion process·TGV 대응 소재 역량**으로 보는 편이 타당하다.

---

**✅ 현재 PIC와 Fiber는 어떻게 연결되는가? 핵심은 FAU다**

- - Silicon photonics PIC 내부 waveguide와 외부 single-mode fiber는 optical mode 크기가 다르기 때문에 단순히 맞대는 것만으로는 낮은 손실을 얻기 어렵다.
  - 현재 고성능 시스템에서는 PIC edge의 coupler와 정밀 정렬된 **FAU(Fiber Array Unit)**를 연결하는 방식이 널리 사용된다. surface·vertical coupling 구조도 함께 사용된다.
  - FAU는 여러 가닥의 fiber를 V-groove 등에 정밀하게 고정해 fiber core를 PIC의 광경로에 맞추는 수동 광부품이다.
  - Corning은 edge-coupled FAU와 vertically coupled FAU를 모두 제공하며 silicon photonics와 CPO용 fiber-to-chip 연결 제품군을 상용 운영하고 있다.

|  |  |  |  |
| --- | --- | --- | --- |
| **연결 방식** | **구조** | **장점** | **주요 고려사항** |
| Edge Coupling + FAU | PIC edge coupler ↔ FAU ↔ Fiber | 낮은 손실·고성능 구현에 유리 | 정밀 alignment와 조립 공정 필요 |
| Vertical / Surface Coupling | Fiber ↔ surface/grating coupler ↔ PIC | wafer test·패키징 유연성 | 설계에 따라 손실·파장·편광 특성이 달라짐 |
| GlassBridge | Fiber connector ↔ glass waveguide ↔ PIC | detachable·고밀도·serviceability 잠재력 | 아직 초기 개발·비상용 단계 |

**✅ GlassBridge는 FAU의 완전한 대체재가 아니라 차세대 선택지다**

- - GlobalFoundries와 Corning은 2025년 9월 GF의 silicon photonics platform을 위한 **detachable fiber connector** 공동 개발을 발표했다.
  - GF 발표에서 GlassBridge는 **glass-waveguide 기반 edge-coupler**로 설명되며 GF platform의 V-groove와 호환되도록 설계됐다.
  - 핵심은 detachable 구조다. 영구 접착형 fiber attach와 비교해 조립·테스트·교체·서비스 관점에서 새로운 선택지를 제공할 수 있다.
  - 하지만 코닝은 2026년 7월 공식 입장에서 GlassBridge가 **아직 초기 개발 단계이며 상용화되지 않았고 commercial-scale production에도 도달하지 않았다**고 명시했다.
  - 코닝은 또한 GlassBridge가 모든 FAU를 대체하는 범용 솔루션이 아니라, density·assembly process·응용 조건에 따라 **전통적 FAU의 대안 중 하나**가 될 수 있다고 설명했다.
  - 따라서 지금 GlassBridge의 시장점유율을 계산하는 것은 의미가 없다. 중요한 것은 향후 CPO 설계에서 실제 design-in과 양산이 얼마나 늘어나는가다.

---

**✅ TSMC–GlobalFoundries의 20억 달러 Silicon Interposer 계약과 코닝의 관계**

- - 2026년 10월 8일 GlobalFoundries는 TSMC와 **다년간 20억 달러 규모**의 제조 계약을 발표했다. GF는 New York Malta에서 TSMC의 CoWoS advanced packaging ecosystem용 **silicon interposer** 생산 능력을 추가한다.
  - 여기서 핵심 소재는 이름 그대로 **silicon**이다. 코닝의 glass가 silicon interposer 본체를 대체한다고 해석하면 안 된다.
  - GF의 공식 발표에도 Corning은 이 interposer 계약의 공급업체로 언급되지 않았다. 따라서 **‘TSMC–GF 계약 = 코닝 직접 매출’**이라고 연결할 근거는 없다.

**📌 간접적인 연결고리는 어디에 있는가**

- - **첫째, Glass Carrier 가능성**이다. 코닝의 glass carrier는 2.5D/3D packaging과 wafer thinning 공정에 적합하다. 다만 GF가 이번 TSMC 물량에 Corning carrier를 사용한다고 공개한 것은 아니므로 이는 **잠재적 간접 수혜** 수준으로 봐야 한다.
  - **둘째, GF Fotonix와 GlassBridge**다. GF는 한쪽에서 TSMC CoWoS용 silicon interposer 생태계에 들어가고, 다른 한쪽에서는 Corning과 fiber-to-PIC 연결을 공동 개발하고 있다.
  - **분석:** 장기적으로 advanced packaging과 CPO가 더 가까워진다면 GF를 매개로 silicon interposer·silicon photonics·Corning optical connectivity가 같은 제조 생태계 안에서 접점을 넓힐 가능성이 있다. 이는 현재 확정된 제품 구조가 아니라 전략적 가능성이다.

|  |  |  |
| --- | --- | --- |
| **영역** | **코닝 영향** | **판단 근거** |
| Silicon interposer 본체 | 직접 영향 낮음 | 본체 소재가 silicon이며 Corning은 계약 공급업체로 공개되지 않음 |
| Interposer 공정용 Glass Carrier | 잠재적 간접 수혜 | 2.5D/3D 공정 적용성은 있으나 GF의 Corning 사용 여부는 미확인 |
| GF Fotonix + GlassBridge | 장기 전략적 의미 | GF가 silicon photonics와 CoWoS interposer 양쪽 생태계에 참여 |

**✅ 코닝의 진짜 경쟁력은 ‘유리 하나’가 아니라 공급망의 폭이다**

- - 코닝의 강점을 가장 잘 설명하는 표현은 완성 제품의 독점보다 **picks-and-shovels**에 가깝다.
  - 반도체 시작점에는 Hemlock polysilicon, packaging 공정에는 Glass Carrier, 차세대 substrate에는 Glass Core, 현재 photonics에는 FAU, 미래 CPO에는 GlassBridge가 서로 다른 시간축으로 존재한다.
  - 특히 Glass Core와 CPO가 동시에 성장한다면 코닝은 ‘패키지 아래의 glass’와 ‘PIC 옆의 glass’라는 두 영역에서 동시에 성장 옵션을 갖는다.
  - 반대로 Glass Core나 GlassBridge 중 하나의 상용화가 예상보다 늦어져도 기존의 carrier·FAU·fiber 사업이 존재한다는 점이 포트폴리오 관점의 강점이다.

|  |  |  |
| --- | --- | --- |
| **공급망 위치** | **코닝의 자산** | **평가** |
| 반도체 원재료 | Hemlock hyper-pure polysilicon | 현재 상용·전략자산 |
| 반도체 제조·패키징 공정 | Glass Carrier, ultra-low TTV glass | 현재 상용 |
| 차세대 package substrate | Glass Core 소재·fusion process·TGV 대응 조성 | 개발·시장 형성 단계 |
| 현재 PIC–Fiber | FAU, V-groove, specialty fiber | 현재 상용 |
| 차세대 CPO | GlassBridge | 초기 개발·검증 |
| 데이터센터 물리망 | Optical fiber·cable·connectivity | 기존 핵심 사업 |

    - → Corning 잠재 수혜: ★★★☆☆

    - → Corning 전략적 잠재력: ★★★★★

**✅ 결론 — ‘Glass Substrate 1위’보다 더 흥미로운 이유**

- - 코닝이 현재 Glass Core/Substrate 시장을 압도적으로 지배한다고 말할 수는 없다.
  - GlassBridge 역시 아직 상용 점유율을 논할 단계가 아니다.
  - 그럼에도 코닝의 전략적 가치는 작지 않다. 하나의 완제품을 독점해서가 아니라 AI·첨단 패키징·CPO가 성장할수록 반복적으로 필요한 **유리·광학·실리콘 원재료 기술**에 넓게 걸쳐 있기 때문이다.
  - 따라서 코닝을 완성 Glass Substrate의 ‘TSMC’처럼 보기보다는, 여러 제조업체가 필요로 하는 소재·공정·광연결의 **picks-and-shovels 기업**으로 보는 편이 현재 공개 자료에 더 잘 맞는다.
  - 앞으로 확인해야 할 핵심은 **Glass Core의 실제 HVM 채택**, **GlassBridge의 상용 design-in**, **GF Fotonix와의 양산 확대**, 그리고 advanced packaging용 glass가 코닝 실적에서 차지하는 비중의 변화다.
