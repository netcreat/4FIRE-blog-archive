**✅ 1. SP-CORE부터 SP-NLO까지: 여섯 가지 모듈**

|  |  |  |
| --- | --- | --- |
| **모듈** | **공식 기능 명칭** | **소재와 하는 일** |
| SP-CORE | Low-loss routing | SiN 도파로, bends·splitters·rings·MZI·crossings·heaters |
| SP-PKG | Optical I/O | Tapered fiber와 SiN 칩의 저손실 결합, 극저온 호환 패키징 |
| SP-LAS | Active III-V | III-V 레이저·증폭·변조·광출력 모니터 |
| SP-DIA | Diamond integration | Diamond 막과 SiN 결합, 양자 메모리·센싱 인터페이스 |
| SP-NBN | Photon counting | Niobium nitride SNSPD 온칩 단일광자 검출 |
| SP-NLO | Nonlinear optics | Thin-film lithium niobate를 이용한 주파수 변환과 전기광학 변조 |

- - SP-PKG의 PKG는 Packaging, SP-DIA는 Diamond, SP-NLO는 Nonlinear Optics, SP-NBN의 NbN은 Niobium Nitride라는 의미와 연결된다. 그러나 SP-CORE·SP-LAS 등은 공식 페이지에서 제공하는 모듈명이며 모든 접두어를 회사가 별도의 약어 풀네임으로 정의한 것은 아니다.

    - SP-CORE는 빛이 이동하는 공통 배선이며,
    - SP-LAS는 광원·증폭,
    - SP-NLO는 변환,
    - SP-DIA는 메모리 연결,
    - SP-NBN은 검출,
    - SP-PKG는 칩과 광섬유 연결을 담당한다.
  - 여섯 모듈 모두 하나의 상용 칩에 이미 통합됐다는 뜻은 아니다. **모듈 조합마다 별도 통합 공정과 성능 검증이 필요하다.**

**✅ 2. LN·PPLN·TFLN·BTO·Diamond는 서로 무엇이 다른가?**

**📌 PPLN과 TFLN은 경쟁 소재가 아니다**

|  |  |  |
| --- | --- | --- |
| **용어** | **정식 명칭** | **정확한 개념** |
| LN | Lithium Niobate (LiNbO₃) | 강한 2차 비선형 광학·전기광학 성질을 갖는 결정 |
| PPLN | Periodically Poled Lithium Niobate | 결정 분극 방향을 주기적으로 반전시켜 준위상정합 구현 |
| TFLN | Thin-Film Lithium Niobate | 박막 구조에서 광모드를 가두고 칩 집적을 가능하게 함 |
| PP-TFLN | Periodically Poled Thin-Film Lithium Niobate | 박막 구조와 주기적 분극 반전을 결합 |
| BTO | Barium Titanate (BaTiO₃) | 높은 전기광학 계수를 지닌 강유전체 |
| Diamond | Diamond / Color Center | SiV·NV 등 색중심의 스핀과 광자를 연결하는 양자 메모리·센싱 소재 |

- - PPLN의 핵심은 광학 주파수 변환 시 발생하는 위상 불일치를 주기적 분극 반전으로 보정하는 QPM(Quasi-Phase Matching)이다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMzBfMjM2/MDAxNzkzMzQ0MjA2NTY1.Iv7FGlRtVXfSjF9SyTWel97S4IFlARPolrf_7clZHyog.G7RHLGxVFpDjTZkM3FhAW8ksgZiY_znOdgjaVQ2nZoAg.PNG/image.png?type=w800)](#)

- - TFLN의 핵심은 LN을 얇은 박막과 미세 도파로로 가공해 광학장 구속과 회로 집적을 강화하는 데 있다. 따라서 PP-TFLN처럼 두 방식을 동시에 적용할 수 있다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMzBfMTYx/MDAxNzkzMzQ0MjIwNjk2.TtX8uurEcMgqDS84SoP7e9OnUgGnAhYsyaLRL-yE-08g.AKMb6-s5lfLd6ZAR1UtEMdFZxQ1qWo8gfYmYAu9DoZUg.PNG/image.png?type=w800)](#)

- - SkyWater의 SP-NLO는 TFLN을 사용하고, 공개 자료에 주기적 분극 반전 TFLN 소자 사례도 포함돼 있다.

**📌 왜 비선형(Nonlinear) 광학인가?**

- - 선형 광학에서는 빛의 전기장 E에 대한 물질의 분극 P가 대체로 비례한다. LN은 이 반응에 E의 제곱항(2차 비선형 감수율)이 존재한다.
  - 이 제곱항 때문에 단일 주파수 빛에서 2배 주파수(Second-Harmonic Generation)가 나타나거나, 서로 다른 두 빛의 주파수 차이·합에 해당하는 성분이 발생할 수 있다.
  - 비선형이라는 말은 빛의 경로가 구부러진다는 뜻이 아니라, **물질이 빛의 전기장에 반응하는 관계가 단순한 직선 비례가 아니라는 뜻**이다.

- - 여기서 주목할 것은 E2 항이다.
  - 예를 들어 하나의 빛이 다음처럼 진동한다고 가정하겠다.

- - 2차 비선형 반응에는 E2가 들어간다.

- - 삼각함수 항등식을 사용하면,

- - 여기서 처음에 없던 2ω, 즉 원래 빛의 두 배 주파수가 나타난다
  - DFG(Difference-Frequency Generation)는 두 광학 주파수의 차를 이용해 새로운 파장을 생성한다. 예시로 493nm와 약 776nm의 주파수 차는 약 1352nm 부근에 해당한다.

- - 양자 네트워크에서 중요한 것은 단순 파장 이동이 아니라 광자의 양자 상태를 보존하면서 낮은 잡음과 높은 효율로 변환하는 것이다.

**📌 BTO는 LN을 대체하는가? Diamond도 대체할 수 있는가?**

- - BTO는 Barium Titanate(티탄산바륨, BaTiO3)의 약자로, Psiquantum에서 사용되는 소자다.

    - BTO는 LN보다 더 강한 Pockels 전기광학 응답을 보일 수 있어 광학 위상 변조기 분야의 대체 후보가 된다. 하지만 실제 소자의 크기와 전압은 결정 방향, 광학 모드, RF 설계, 손실, 제조 균일성에도 좌우된다.
    - BTO 역시 2차 비선형성을 가지므로 광학 주파수 변환도 원리적으로 가능하지만, PPLN·PP-TFLN의 성숙한 공정과 양자 광자 변환 품질까지 자동으로 대체하는 것은 아니다.
    - Psiquantum이 BTO를 사용하는 결정적인 이유는, PsiQuantum의 광자 양자컴퓨터는 Fusion-Based Quantum Computing(FBQC)을 기반으로 하고, 여기서 중요한 것은 광자 생성뿐 아니라 광자들이 어디로 이동할지 실시간으로 결정하는 기술이다.

      - 광자쌍 생성은 확률적이다.
      - Fusion 연산 역시 본질적으로 확률적인 성공·실패 결과를 가진다.
      - 따라서 여러 광원을 병렬로 운용하고, 성공한 광자를 필요한 경로로 보내는 Multiplexing이 중요하다.
      - 이를 위해 빠르고 손실이 작은 광학 스위치가 필요하다.
    - 결국 PsiQuantum이 BTO를 선택한 것은 LN이 주파수 변환에 부적합해서가 아니라, 대규모 광학 스위칭에 필요한 강한 전기광학 응답과 저손실·저전력 집적 가능성을 높게 평가했기 때문이다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMzBfOTYg/MDAxNzkzMzQ0Mzk4NDkx.Ywb6VB-lonRLm8tSnY0dqcDB_dJfSlEjVY4JKRaYDHQg.LhqroD3IwYtKWBaheI2rCACqsG8Rs39-BwJD1ualc3Ug.PNG/image.png?type=w800)](#)

- - Diamond 색중심의 스핀 메모리는 빛의 파장을 바꾸는 LN과 역할이 다르다. 일반적인 순수 LN 변환기나 BTO 변조기로 SiV 스핀 메모리를 직접 대체할 수는 없다.
  - 따라서 SP90의 목표는 어느 한 물질로 모든 기능을 해결하는 것이 아니라 **Diamond–SiN–LN–III-V–검출기 사이의 이종 소재 통합**이다.

**✅ 3.** **그런데 이 모든 소재를 패키징할 때 0.2dB 손실을 달성했다는 것인가?**

- - 이 부분은 정확하게 구분할 필요가 있다.
  - SkyWater의 10월 27일 발표 원문에서는 다음과 같이 설명한다.

    - We have reproducibly demonstrated losses below 0.2 dB at visible wavelengths.
  - SkyWater는 SP-PKG의 가시광 tapered-fiber 인터페이스에서 **0.2dB 미만** 손실을 반복적으로 실증했다고 밝혔다.
  - Diamond, Silicon, LN, III-V 등의 모든 소재 간 연결에서 0.2dB 미만을 확보했다는 뜻은 아니다.
  - **광학 손실은 각 단계에서 누적된다**

    - 총 손실은 각 구성요소에서 발생하는 손실을 모두 합산해야 한다.

- - - 여기서 dB로 환산된 손실을 사용한다
  - 예를 들어 다음의 각 구간에서 손실이 발생한다면,

    - Diamond → SiN 결합 : 0.5dB
    - SiN 전파 → 0.3dB
    - 파장 변환 → 1.5dB
    - Fiber 결합 → 0.2dB
    - 합계 2.5dB 손실일 경우 최종 광자 전달 확률은 56.2%로 낮아진다.
  - dB(데시벨)은 손실의 비율을 로그로 표현한 것이므로 이를 투과율로 변환하면 다음과 같다.

|  |  |  |  |
| --- | --- | --- | --- |
| **광학 손실** | **투과율** | **손실률** | **비고** |
| 0.2dB | 95.50% | 4.50% | SkyWater 발표 상한으로 계산 |
| 0.4dB | 91.20% | 8.80% | 0.2dB 결합면 2개를 가정 |
| 2.5dB | 56.23% | 43.77% | 가상 전체 경로의 합산 손실 |
| 3.0dB | 50.12% | 49.88% | 전체 경로에서 광자의 약 절반이 사라짐. |

**✅ 4. 웨이퍼를 이미 출하했다면 고객의 칩 회로가 들어간 것 아닌가?**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMzBfMjI2/MDAxNzkzMzQ3MTkxNjUz.41qoDI3KIQoBVpQODgLkXzkC9B4Y6wQg1AZdx5qpiDwg.hEMdSKV-qRPh5pgkVOgqVreXAE1wpjKg16hVZKOgxpYg.PNG/image.png?type=w800)](#)

- - 고객별 웨이퍼에는 해당 설계의 광학 회로 패턴과 필요한 공정 레이어가 포함될 수 있다. SP90은 하나의 고정 회로가 아니라 여러 고객의 광학 집적회로를 제조하는 공통 공정 플랫폼이다.
  - SkyWater는 SP-CORE 다이가 포함된 200mm 웨이퍼와 **이온트랩용 맞춤형 레이어를 추가한 200mm SP90 웨이퍼**를 공개했다. 이는 공정이 실제 웨이퍼에 적용됐음을 보여준다.
  - 그러나 사진 속 웨이퍼가 바로 출하된 제품인지, 어느 고객의 어떤 설계인지, 이온 포획과 모든 광학 모듈을 통합했는지 등은 공개되지 않았다.
  - 2026년 10월 SP90 웨이퍼 출하는 분명한 제조 진전이지만, 모든 모듈의 완전 통합·고수율 양산·종단 간 성능 검증을 의미하지 않는다. SkyWater는 완전 인증된 플랫폼의 2027년 출시를 목표로 설명한다.

**📌 45개 다이 측정과 25장 웨이퍼 평가는 서로 다르다**

- - SkyWater는 493nm, 650nm, 1762nm 등에서의 전파 손실 공간 분포를 소개하며 광학 손실 지도당 45개 다이 위치를 측정했다고 설명한다.
  - 별도로 25장 웨이퍼 PVD 박막 연구에서 두께와 굴절률을 조사했다. 이를 25장 모든 웨이퍼의 광학 손실 양산 통계라고 혼동해서는 안 된다.
  - 광손실 지도별 색상 척도도 서로 다르므로 그림 색깔만으로 파장별 절대 손실의 우열을 비교할 수 없다.

📌 **SkyWater SP90의 현재 광도파로 손실 수준은?**

- - SkyWater는 SP90의 200mm 웨이퍼에서 실제 측정한 SiN 광도파로의 전파 손실(Propagation Loss)과 공정 균일성 데이터를 공개했다. 참고로 데이터에서 사용되는 파장은 바륨기반의 QPU에서 사용되는 에너지 준위 전이에 사용되는 파장이다.

    - **493nm / 저온 SiN 공정:** 1.56dB/cm
    - **1762nm / 저온 SiN 공정:** 0.40dB/cm
    - **1762nm / 고온 SiN 공정:** 0.13dB/cm
    - **650nm:** 별도 다이에서 0.30dB/cm 측정

| **파장** | **에너지 준위 전이** | **주요 역할** |
| 493nm | 6S₁/₂ ↔ 6P₁/₂ | 냉각, 형광 상태 판독, 광자 생성 |
| 650nm | 5D₃/₂ ↔ 6P₁/₂ | Repumping, 냉각 사이클 유지 |
| 1762nm | 6S₁/₂ ↔ 5D₅/₂ | Optical Qubit 제어, 준안정상태 전환 |
| 614nm | 5D₅/₂ ↔ 6P₃/₂ | 준안정상태 초기화 등에 사용 |

- - 여기서 고온과 저온은 양자컴퓨터의 동작 온도가 아니라 **웨이퍼 제조 공정의 온도**를 의미한다. 고온 공정은 광학 손실을 낮추는 데 유리하지만, 저온 공정은 다른 반도체 소자 및 소재와의 이종 집적에 유리하다.
  - 특히 바륨 이온의 냉각·광자 인터페이스에 사용되는 **493nm에서는 1cm 전파 시 약 30%의 광자가 손실**된다. 따라서 현재 SP90은 가시광 영역의 도파로 손실을 추가로 개선할 필요가 있다.
  - 다만 이 수치들은 앞서 설명한 0.2dB 미만의 광섬유-칩 결합 손실(Coupling Loss)과는 별개다. 실제 광학 시스템의 전체 손실을 계산하려면 도파로 전파 손실과 결합 손실, 주파수 변환 손실 등을 모두 고려해야 한다.
  - 이번 결과는 SP90이 45개 다이 전체에서 광학 손실을 측정하는 웨이퍼 수준의 공정 검증 단계에 진입했음을 보여준다. 그러나 최종 양산 수율이나 완성된 양자 광학 시스템의 성능까지 입증한 것은 아니다.

**✅ 5. OnRamp는 누구를 위한 프로그램이며 무엇을 제공하는가?**

- - 2026년 10월 27일 발표된 OnRamp는 연구실 단계의 양자·포토닉스 스타트업이 파운드리와 제조 개발을 시작할 수 있도록 지원하는 프로그램이다.
  - 선정 팀은 SkyWater 엔지니어와 소재·공정 호환성, 설계 제조 가능성(DFM), 패키징·이종 집적 위험을 검토하고 자신들이 소유하는 제조 개발 로드맵을 확보한다.
  - 선정된 기업은 SkyWater 내부 SP90 개발 런을 활용한 초기 프로토타입 웨이퍼에 **유료**로 접근할 수 있다. 기술 적합성과 웨이퍼 가용성, 엔지니어 인력에 따라 참여가 결정된다.
  - 무료인 것은 선정 팀에 제공되는 초기 기술 검토 지원이지, 모든 고객에게 웨이퍼를 무료 제조한다는 뜻이 아니다.
  - 기존 MPW(다중 프로젝트 웨이퍼)와 유사한 비용 절감 효과를 기대할 수 있지만 OnRamp가 실제로 여러 고객 회로를 한 웨이퍼에 혼합하는지까지 공식적으로 확정한 것은 아니다.

**✅ 6. IonQ의 Lightsynq·Nexus·SkyWater 통합 전략**

- - IonQ의 SkyWater 인수 이후 광학 시스템 개발 지식(Lightsynq), III-V 집적 기술(Nexus Photonics), SiN·Diamond·LN 공정과 광학 패키징(SkyWater)을 서로 연결하는 방향이 공식 발표에서 나타난다.
  - 특히 Lightsynq 출신 Mihir Bhaskar가 SkyWater Quantum Solutions를 이끌면서 연구실 수준의 양자 광학 장치를 반도체 생산 공정으로 옮기는 과제를 맡고 있다는 점이 중요하다.
  - 이온트랩 QCCD의 레이저 채널 제어, Diamond 양자 메모리의 통신 파장 연결, 단일광자 검출과 극저온 광섬유 패키징 등은 이 플랫폼이 겨냥하는 문제들이다.
  - 다만 SP90이 이온 이동·운동 가열·게이트 충실도 같은 QCCD 내부 병목을 직접 해결하는 것은 아니다. 또한 다수 인수 기술의 통합 성과가 상업적 매출과 양산 수율로 이미 검증됐다는 뜻도 아니다.
  - SkyWater는 IonQ만을 위한 폐쇄형 파운드리가 아니라 Qolab 같은 외부 고객도 지원한다. 고객 IP와 공정 접근 통제에 관한 실제 계약 조건은 개별적으로 확인해야 한다.

**✅ 7. 결론 — 중요한 것은 개별 소재가 아니라 시스템 전체의 제조 수율이다**

- - SP90의 경쟁력은 특정 한 소재가 가장 우수하다는 주장이 아니다. 서로 다른 소재가 담당하는 광자 생성·이동·변환·저장·검출 기능을 공동 공정과 패키징 안에 통합하는 능력이다.
  - 광자 패키징에서 낮은 결합 손실을 달성한 사실은 의미가 크지만, 실제 양자 네트워크에서는 Diamond → SiN → TFLN → Fiber 전체의 손실·잡음·충실도·수율을 확인해야 한다.
  - 기술적으로 가장 중요한 다음 검증 항목은

    - ① 고객별 실제 웨이퍼 수율
    - ② 파장별 도파로 손실의 통계
    - ③ 주파수 변환 효율과 양자 잡음
    - ④ 전체 광학 경로의 End-to-End Loss
    - ⑤ 극저온 반복 동작 안정성이다.
  - **SP90의 초기 웨이퍼 출하는 제조 기반의 실체를 보여준다. 그러나 완전한 양자 포토닉스 시스템의 양산 입증과는 분명히 다른 단계다.**
