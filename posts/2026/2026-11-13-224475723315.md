# IBM Nighthawk r3 전격 공개

Published: 2026-11-13T17:08:40+11:00

Original Naver post: https://blog.naver.com/4-fire/224475723315?fromRss=true&trackingCode=rss

---

**✅ 520큐비트, 1,040큐비트 연결 계획, Starling 로드맵과 경쟁 기술 비교**

- - **2026년 11월 11일**, IBM은 Quantum Developer Conference에서 차세대 초전도 프로세서 **Nighthawk r3**를 발표했다. 2027년 520개 프로그래밍 가능 큐비트를 탑재한 칩 2개를 연결해 1,040큐비트 시스템을 구성한다는 목표다. [1][2]
  - 이번 발표는 단순히 큐비트 수가 늘었다는 뉴스가 아니다. IBM은 기존의 **120큐비트 칩 여러 개를 연결하는 전략에서 520큐비트 대형 칩 두 개를 연결하는 구조**로 방향을 수정했다.
  - 동시에 2029년까지 **200개 논리 큐비트·1억 회 양자 연산**을 목표로 하는 Starling 오류정정 시스템의 연구 진척도 공개했다. 다만 Nighthawk r3, 연결형 1,040큐비트 시스템, Starling은 모두 **현재 완제품이 아니라 계획 또는 개발 단계**다. [1][3]
  - 분석 기준일은 **2026년 11월 13일**이다. 숫자는 각 기업의 공식 발표와 논문에 근거하며, 확인된 성과·향후 목표·계산상 추정을 구분한다.

**✅ 1. Nighthawk r1·r2·r3는 어떻게 달라졌나?**

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **Nighthawk r1** | **Nighthawk r2** | **Nighthawk r3** |
| 시기·상태 | 2025년·기존 운영 | 2026년 9월부터 접근 가능 | 2026.11 발표·2027년 목표 |
| 프로그래밍 가능 큐비트 | 120개 | 120개 | 520개 |
| 전체 물리 양자 요소 | 338개 | 458개 | 2,034개 |
| 회로 연산 규모 | 5K 목표 | 7.5K 초과 실행 발표 | 10K 목표 |
| 처리량 | 고속 리셋 도입 전 | 초당 최대 100,000회+ 샘플링 | r2의 고속 구조 계승 목표 |
| 초기화 | 기존 초기화 | 독립적 고속 리셋 120개 | 빠른 리셋 구조 확대 계획 |
| 칩 간 연결 | 연구용 L-coupler 실험의 기반 | 모듈 연결 연구 중 | L-coupler 10개 인터페이스 설계 |
| 연결형 시스템 | 단일칩 또는 연구 실증 | 실제 120q 운영 | 520×2 = 1,040q (2027 목표) |

- - **r1 → r2:** 계산용 큐비트 수는 120개로 유지하면서 120개의 고속 리셋 요소를 추가했다. IBM은 100,000회 이상/초의 회로 반복 실행이 가능해져 샘플 수집의 병목을 줄였다고 발표했다. [4]
  - **r2 → r3:** 단일 칩에서 직접 프로그램할 수 있는 큐비트를 120개에서 520개로 4.33배 확장하는 계획이다. 다만 계획된 게이트 수 10K만으로 실제 오류율이 r2와 동일하다는 것은 보장되지 않는다. [1]
  - r2의 약 **400ns 리셋 시간**이라는 운영 사양과, IBM이 설명한 리셋 회로 활성화 시 유효 T1을 약 25ns까지 줄인다는 물리적 메커니즘은 서로 다른 측정값이다. [4][5]
  - 회로당 샘플링 속도는 회로 깊이·측정 방식·제어 흐름에 따라 달라진다. **초당 10만 회가 모든 알고리즘에서 가능한 연산 속도라는 의미는 아니다.**

**📌 7.5K, 10K, 15K, 100M이라는 숫자의 정확한 뜻**

|  |  |  |  |
| --- | --- | --- | --- |
| **기호** | **규모** | **해석** | **상태** |
| 5K | 5,000 | Nighthawk r1 세대 회로 연산 목표 | 기존 로드맵 |
| 7.5K | 7,500 | Nighthawk r2에서 실행한 2큐비트 연산 규모 | 실제 공개 성과 |
| 10K | 10,000 | Nighthawk r3의 회로 연산 목표 | 2027년 목표 |
| 15K | 15,000 | Nighthawk 2028년 회로 연산 로드맵 | 이전·현행 로드맵 목표 |
| 100M | 100,000,000 | Starling의 오류정정 환경에서 수행할 장기 연산 목표 | 2029년 목표 |

- - K는 1,000, M은 100만을 뜻한다. **7.5K는 7,500큐비트도, 초당 7,500게이트도 아니다.** IBM은 특히 Nighthawk의 회로 복잡도를 2큐비트 게이트 수로 설명한다. [2][5]
  - 한 회로에 2큐비트 게이트가 7,500개라는 것과 7,500단계 깊이라는 것은 다르다. 병렬 게이트가 있으면 전체 게이트 수와 회로 깊이가 다르다.
  - Nighthawk의 수천 회 물리 연산과 Starling의 1억 회 내결함성 연산은 오류정정 방식이 달라 **같은 품질의 게이트를 단순 배율로 비교한 숫자가 아니다.**

**✅ 3. 338개·458개·2,034개인데 계산용 큐비트는 왜 적은가?**

- - IBM이 Nighthawk에서 공개하는 전체 물리 양자 소자 수에는 사용자가 직접 프로그램하는 큐비트뿐 아니라, 이들 사이를 연결하는 **커플러**와 리셋을 돕는 **양자 요소**도 들어간다. 따라서 전체 물리 양자 소자 수를 곧바로 계산 가능한 큐비트 수로 읽으면 안 된다. [4][5]
  - **r1:** 120개 계산 큐비트 + 218개 Tunable Coupler = 338개.
  - **r2:** 120개 계산 큐비트 + 218개 커플러 + 120개 독립 리셋 소자 = 458개. 이 분해는 IBM 공식 원문에 명시되어 있다. [4]
  - **r3:** 520개 계산 큐비트와 전체 물리 양자 요소 2,034개는 공식 발표치지만, IBM이 2,034개를 각 부품 종류로 나눈 상세 표는 현재 확인되지 않았다. [1]

**📌 왜 520+994+520=2,034가 정확히 맞아떨어지는가?**

- - N을 프로그래밍 가능한 큐비트 수, a와 b를 직사각형 격자 가로·세로 개수라 할 때

    - **N=a×b**이다.
  - 좌우·상하의 최근접 연결마다 커플러가 하나씩 필요하다면

    - **C=a(b−1)+b(a−1)=2N−a−b**이다.
  - 총 물리요소수

    - P=N+C
    - P=N+(2N-a-b)=**3N-a-b**
  - 계산 큐비트마다 리셋 요소를 하나씩 추가하는 r2형 설계에서는

    - **P=N+C+R**
    - **P=N+(2N-a-b)+N=4N−a−b**가 된다.
  - **r1:** a×b=10×12=120을 대입하고 리셋 요소를 빼면 P=3×120−10−12=**338**.
  - **r2:** 같은 격자와 리셋 요소 120개를 가정하면 P=4×120−10−12=**458**.
  - **r3:** a×b=20×26=520일 경우 C=2×520−20−26=**994**, 따라서 P=520+994+520=**2,034**가 정확히 나온다.
  - **구분:** r1·r2의 세부 구성은 공식 확인 사실이지만, r3의 **20×26 격자와 994/520 분해는 숫자가 일치하는 역산 모델**일 뿐 확정 설계도가 아니다. L-coupler 10개의 구성 요소가 2,034에 어떻게 반영되는지도 별도 확인이 필요하다.

**📌 칩이 더 커지면 계산용 큐비트 비율은?**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **세대·모델** | **계산용 N** | **전체 P** | **N/P** | **해석** |
| Heron r2/r3 | 156 | 332 | 47.0% | 별도 구조·집계 기준 |
| Nighthawk r1 | 120 | 338 | 35.5% | 별도 리셋 요소 미포함 |
| Nighthawk r2 | 120 | 458 | 26.2% | 계산 큐비트당 리셋 1개 |
| Nighthawk r3 | 520 | 2,034 | 25.6% | 전체 수 공식, 상세 분해 미공개 |

- - 큰 정사각형 격자에서는 a+b가 약 2√N이므로 r2형 설계의 근삿값은 **P≈4N−2√N**이며, **N/P는** **대형화될수록 약 25%로 수렴**한다.
  - 다만 이것은 **최근접 결합 하나당 커플러 1개·큐비트당 리셋 요소 1개**라는 특정 구조의 산식이다. 더 많은 비국소 연결이나 공유 버스, 새 리셋 방식 등을 쓰면 달라진다.
  - **물리 양자 요소 대비 계산 큐비트 비율**은 **물리 데이터 큐비트 대비 논리 큐비트 인코딩 효율**과 완전히 다르다. Starling의 qLDPC 논리 큐비트는 위 25% 공식을 적용할 수 없다.

**✅ 4. Tunable Coupler, C-coupler, L-coupler, M-coupler는 무엇인가?**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMTNfMTky/MDAxNzk0NTQ3MjM0NTky.v8wHOv1ErUxMuO8ltKex4hPqD-g8zl9048hesHzJvtog.-OdiC_aQXIgP_g13wlXRx0vYBKWpJ7f--h7gZl0ZmHQg.PNG/image.png?type=w800)](#)

|  |  |  |  |
| --- | --- | --- | --- |
| **구분** | **물리적 연결 범위** | **핵심 기능** | **주요 관련 기술** |
| Tunable Coupler | 인접 큐비트 또는 다른 소자 | 결합 강도 조절·2큐비트 게이트·리셋 경로 제어 | Heron·Nighthawk |
| C-coupler | 같은 칩 내부 비인접 큐비트 | 멀리 떨어진 큐비트를 저손실로 연결해 qLDPC 연결 그래프 구현 | Loon·Starling 연구 |
| M-coupler | 가까이 놓인 별도 칩 사이 | 인접 칩을 이음새처럼 연결하는 칩 간 결합 | Crossbill 등 연구 |
| L-coupler | 다른 QPU·모듈 사이(미터급) | 초전도 케이블의 양자 마이크로파 모드로 상태 전달·원격 게이트 | Nighthawk 실험·Starling |

- - **Tunable Coupler**는 결합을 조절한다는 기능 분류다. **C-coupler**는 IBM이 qLDPC를 위해 개발한 **칩 내부 장거리 결합 구조**를 가리킨다. 두 용어는 같은 분류 축이 아니므로, 모든 C-coupler가 단순히 기존 근접 커플러와 동일한 회로라는 의미는 아니다. [3][7]
  - **C-coupler의 고정 배선은 항상 얽힘 상태라는 뜻이 아니다.** 정해진 두 큐비트 사이에 물리 경로가 존재하는 것이고, 실제 얽힘은 제어된 양자 게이트 실행 중 생성된다.
  - 직접 연결되지 않은 A와 C는 A–B–C 경로에서 중간 큐비트 B를 사용해 간접적으로 얽힐 수 있다. 예를 들어 초기 |000⟩에서 H(A), CNOT(A→B), CNOT(B→C), CNOT(A→B)를 순서대로 수행하면 **(|000⟩+|101⟩)/√2**가 되어 A와 C는 얽히고 B는 |0⟩로 돌아간다.
  - 다만 우회 게이트와 SWAP이 많을수록 회로가 길어지고 오류가 누적될 수 있다. IBM이 먼 연결을 C-coupler로 직접 제공하려는 이유다.

**✅ 5. Starling의 qLDPC 설계에서 실제로 무엇이 진전됐나?**

- - IBM은 2029년 **논리 큐비트 200개·1억 회 양자 연산**을 수행하는 Starling 시스템을 목표로 한다. 이는 Nighthawk r3의 520개 **물리 계산 큐비트**와 같은 지표가 아니다. [3]
  - 이전 BB(qLDPC) 설계에서 **큐비트당 연결 수 6개를 5개로 줄였다**. **칩 하나에 C-coupler가 5개 있다는 뜻이 아니라** 각 큐비트의 연결 그래프 차수를 낮춘 것이다.
  - IBM은 모듈 설계의 Josephson junction 약 **5,000개를 2,000개**로 줄였다고 밝혔다. 특정 소자 하나가 작아졌다는 의미보다 제조하기 어려운 접합 소자의 수가 60% 줄었다는 의미가 크다.
  - 접합당 목표 수율 99.95%를 적용하면 완벽한 접합만 가진 칩의 단순 확률은 **0.9995^5000≈8.2%**, **0.9995^2000≈36.8%**다. IBM의 설명인 대략 12개 중 1개에서 3개 중 1개로의 개선과 수치상 부합한다. 단, 실제 웨이퍼 최종 수율은 배선·결함·검사 등 추가 변수의 영향을 받는다.
  - C-coupler 길이는 **20mm**까지 확대됐고, 배선층은 기존 2층에서 3층으로 늘어났다. IBM은 공진기 품질계수 Q가 1천만을 넘었다고 보고했다. 이는 비국소 연결이 오류정정 성능을 심하게 훼손하지 않도록 만드는 데 중요하다. [3]
  - **Relay-BP 디코더**는 Starling의 요구 성능을 충족한다고 IBM이 발표했으며, 2nm 공정 기반 실시간 디코더 ASIC을 개발 중이다. 다만 디코더 성능 요건 충족이 전체 Starling의 논리 연산 실증을 의미하지는 않는다.
  - 연구 과제에는 논리 메모리·논리 처리 장치(LPU)·매직 스테이트 주입/증류·유니버설 어댑터·극저온 제어 ASIC의 통합이 남아 있다. 단일 기능의 성과를 전체 FTQC 구현으로 혼동해서는 안 된다. [3]

**📌 기존 Nighthawk를 그대로 확대해 Starling을 만드는가?**

- - **아니다.** Nighthawk는 오류 완화로 실용적인 물리 회로의 범위와 처리량을 늘리는 계열이다. Starling은 qLDPC 인코딩, 논리 연산, 실시간 디코딩과 모듈 확장을 통합하는 **별도 내결함성 아키텍처**다.
  - Nighthawk에서 검증한 고속 리셋·칩 간 연결·극저온 제어 기술이 Starling에도 도움이 되지만, 논리 연산 성능을 확보하려면 별도의 코드와 하드웨어 구성이 필요하다.

**✅ 6. L-coupler는 초전도 케이블로 어떻게 QPU 사이에 얽힘을 만드는가?**

- - 마이크로파도 전자기파이고, 양자화된 마이크로파 모드에는 **마이크로파 광자(photon)**가 존재한다. 광자라는 말이 반드시 눈에 보이는 가시광선만을 뜻하지는 않는다.
  - IBM의 L-coupler는 **계산 큐비트 → 연결용 L-qubit → 가변 결합기 → 초전도 알루미늄 동축 케이블 → 상대편 L-qubit**으로 이어지는 결맞음 양자정보 전송 경로다. 단순한 디지털 0·1 데이터를 복제하는 링크가 아니라, 위상과 중첩을 보존하며 양자 상태를 이동시키는 방식이다. [9]
  - IBM은 2026년 10월 **80cm 초전도 케이블 4개**로 Nighthawk r1 칩 2개를 연결했다. 전송 충실도는 평균 **99.00%**, 최고 **99.3%**, 원격 CZ 게이트 충실도는 평균 **94.75%**였다. 원격 얽힘 상태 생성도 수행했다. [9]
  - **상태 전달 충실도 99%**와 **칩 간 CZ 게이트 충실도 94.75%**는 다른 지표다. 게이트 오류가 더 높기 때문에 링크 수만 늘리면 FTQC가 완성된다는 뜻은 아니다.
  - Starling은 모듈당 **100개 이상 L-coupler**를 **약 0.1% 수준 오류율**로 동작시키는 목표를 제시한다. 현재 4개 링크의 실증과는 상당한 기술적 간격이 있다. [3]

**📌 전체 구간이 초전도체여야 멀리 송수신할 수 있나?**

- - IBM이 개발 중인 미터급 링크는 낮은 온도와 저손실 초전도 케이블을 활용한다. 같은 극저온 환경 내에서는 높은 결맞음 전달에 유리하지만, **상온을 지나 수십 km를 마이크로파 단일광자로 직접 전달하는 것은 열잡음과 감쇠 때문에 매우 어렵다.**
  - 5~10GHz 마이크로파 광자는 상온의 열에 비해 에너지가 작다. 예를 들어 6GHz에서 상온 300K 열광자 점유수는 약 10³ 규모이므로, 증폭 없이 약한 양자 신호만 보존하기 어렵다.
  - IBM은 공식적으로 약 **1m**의 극저온 L-coupler, 약 **1~10m** 범위의 추가 극저온 링크 연구, **km급**에서는 광학 변환기를 이용하는 방식으로 연결 단계를 구분한다. **마이크로파 양자 통신의 전체 경로가 원리상 반드시 초전도체여야 한다는 뜻은 아니지만**, 현재 고충실도 장거리 실용 링크에서는 광 변환이 훨씬 현실적이다. [10]

**✅ 7. 결국 장거리·이기종 QPU 연결은 광 인터커넥트가 필요하지 않을까?**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMTNfMTI0/MDAxNzk0NTQ3MzcyMzU4.Tx_06RSWT3VYNwOlvA527tLBrqmrQUdv6myjCW-C23Yg.jkdMJQCXHJ3o_orYH7Kjsq0LffEEEE61IKhZq4SKcfIg.PNG/image.png?type=w800)](#)

- - 방향성은 그렇다. 장거리 양자 네트워킹에서는 **약 1,550nm 텔레콤 대역의 광자**를 광섬유로 보내는 방법이 유리하다. 가시광선으로 한정할 필요가 없다. 파장이 맞고 광섬유 손실이 적은 통신용 광이 핵심이다. [10]
  - IBM도 2025년 Cisco와 함께 **마이크로파↔광 양자 트랜스듀서**와 광 기반 QPU 연결 연구 계획을 발표했다. 초전도 QPU가 내는 마이크로파 양자 상태를 광 신호로 바꿔 원거리로 보내기 위한 것이다. [10]
  - 이기종 연결에서는 주파수 변환뿐 아니라 양자 상태 인코딩, 모드 정합, 광자 검출, 시간 동기화, 성공 신호(heralding), 양자 메모리, 게이트 텔레포테이션 프로토콜까지 맞춰야 한다.
  - **광으로 변환하는 것만으로 초전도 QPU와 이온트랩 QPU를 즉시 상호 연결할 수 있는 것은 아니다.** 전송만 성공하는 것과 안정적인 원격 논리 게이트를 구현하는 것은 별개다.

**✅ 8. IBM L-coupler와 IonQ Photonic Interconnect는 어떻게 다른가?**

|  |  |  |
| --- | --- | --- |
| **비교 항목** | **IBM L-coupler** | **IonQ Photonic Interconnect** |
| 양자 정보 매개 | 극저온 전송선의 마이크로파 양자 모드 | 광학 광자 및 광자-물질 얽힘 |

  - IBM의 **99% 상태 전달 충실도**와 IonQ의 **1kHz 얽힘 생성률**은 지표가 전혀 다르다. 한쪽이 99이고 다른 쪽이 1,000이라는 이유만으로 성능 우열을 정할 수 없다.
  - IBM은 같은 냉동기 내부의 밀접한 모듈 결합, IonQ는 광자 매개 네트워크 확장 연구에서 서로 다른 경로를 택했다. 장기적으로는 초전도 기반도 광 인터페이스를 추가해야 이기종·원거리 양자 네트워크에 본격적으로 참여할 수 있다.

  - Rigetti Ankaa-2 논문에는 **84개 계산 큐비트 + 149개 Tunable Coupler**가 명시되며, IQM Crystal 20 공식 제품 자료는 **20개 계산 큐비트 + 30개 커플러**로 전체 물리 큐비트 50개라고 표기한다. [16][17]
  - 커플러는 계산을 지원하는 소자다. 연산용 비율이 36%라고 해서 **나머지 64%의 계산 큐비트가 불량하거나 작동하지 않는다는 뜻이 아니다.**
  - 제조사별 **physical qubit** 정의가 일치하지 않는다. 특히 커플러·리셋·공진기·보조 큐비트의 포함 방식이 다르므로, 단순한 비율만으로 제조사 간 성능 순위를 매길 수 없다.

**📌 연결 차수로 계산한 하드웨어 오버헤드 근삿값**

- - N개 계산 큐비트가 평균 d개 다른 큐비트와 연결되고 **연결마다 독립 커플러 1개**가 있다면, 커플러 수는 C≈dN/2, 계산용 비율은 **f≈1/(1+d/2)**가 된다.
  - d=2는 약 50%, d=3은 약 40%, d=4는 약 33.3%, d=5는 약 28.6%, d=6은 약 25%다. 여기서 실제 격자 경계의 낮은 연결 수를 무시했다.
  - 리셋 요소가 큐비트당 하나씩 추가된다면 f≈1/(2+d/2)이므로, d≈4의 큰 격자는 약 25%가 된다.
  - **반례:** 공유 공진기·고정 결합·멀티큐비트 버스 등은 결합마다 Tunable Coupler 1개라는 가정을 깨므로 이 산식이 적용되지 않는다. 또한 Starling의 qLDPC 연결 수 5개를 곧바로 완성품의 전체 요소 비율로 환산하는 것도 부정확하다.

**✅ 10. 그럼 현재 IBM 하드웨어는 다른 양자컴퓨터 방식과 비교해 어느 수준인가?**

- - 비교에는 **실제 고객 제공·실험 데이터**와 **발표만 된 차기 제품**을 같은 등급으로 놓지 않는 원칙이 필요하다. 물리 큐비트 수·게이트 충실도·논리 성능·실행 속도·모듈 연결은 서로 다른 축이다.
  - 아래 숫자는 가장 최근에 확인한 기업별 대표 시스템의 공개 사양이다. 동일한 측정 프로토콜로 시험한 횡단 비교 실험이 아니므로 **종합 성능 순위로 읽으면 안 된다.**

**📌 ① 다른 초전도 방식과 비교: Google과 Rigetti**

- - **Google Willow**는 105큐비트 칩에서 물리 큐비트를 더 사용해 논리 오류를 줄이는 below-threshold 실험을 보고했다. 2026년 10월에는 Willow에서 **매직 스테이트 cultivation으로 오류 약 40배 감소, T-state 논리 충실도 99.99%**를 발표했다. 따라서 물리 큐비트 숫자만 보면 IBM r3 계획이 더 크지만, **오류정정 연구의 실증 단계**에서는 Google의 성과를 별도로 평가해야 한다. [18][19]
  - **Rigetti**는 2026년 11월 10일 공시에서 108큐비트 Cepheus 칩렛 시스템의 **중앙값 2큐비트 게이트 충실도 99.5%**를 보고했다. 12개 9큐비트 칩렛을 조합하는 전략이며, IBM의 대형 단일 칩·미터급 모듈 결합과 공학적 접근이 다르다. [20]
  - IBM r2는 100K+ 샘플/초라는 강한 반복 처리량을 공개했다. Google·Rigetti의 2큐비트 충실도와 직접 순위 비교하려면 같은 회로·동일 조건의 실측 데이터가 필요하다.

**📌 ② 이온트랩 방식과 비교: IonQ·Quantinuum**

- - **Quantinuum Helios**는 98개 물리 큐비트와 전방향 QCCD 연결, 공시된 평균 2큐비트 게이트 오류율 약 **7.9×10****-4**(충실도 약 99.921%)를 제시한다. 회사는 50개 논리 큐비트 기능도 소개하지만, 이 숫자가 **50개 범용 내결함성 논리 큐비트의 무제한 연산 보장**을 뜻하지는 않는다. [21][22]
  - Quantinuum은 2026년 10월 **논리 메모리 충실도 99.9995%**를 발표했다. 이는 특정 오류정정 메모리 지표이며, IBM의 7.5K 게이트와 동일한 벤치마크는 아니다. [23]
  - **IonQ Superion 256**은 2026년 9월 발표 당시 통합 256큐비트 칩 제작과 첫 이온 포획에 성공했다고 공개했다. 주문은 받고 있지만 고객 납품은 2027년 예정이다. 즉 256개 큐비트를 모두 높은 충실도로 운용한 상용 완제품과 동일시하면 안 된다. [24]
  - IonQ의 향후 10K·수백~수천 논리 큐비트 로드맵도 매우 공격적이지만 **목표치**다. IBM의 Starling 2029 목표와 비교할 때 실제 달성 수치가 아니라 단계별 검증을 비교해야 한다. [25]
  - 이온트랩은 일반적으로 높은 게이트 충실도와 큐비트 연결 유연성이 강점이지만, 이온 이동·게이트 속도·제어·광 네트워크의 확장이 중요하다. IBM 초전도 게이트의 빠른 속도는 오류정정 비용과 연결성 문제를 해결해야 완전한 장점이 된다.

**📌 ③ 중성원자와 광 기반 방식 비교**

- - **QuEra Gemini**는 260개 원자 큐비트와 저장·얽힘 영역을 분리한 재배치 구조를 활용한다. 공식 사양은 2큐비트 게이트 충실도 99.2%, 샷 속도 1회/초를 표기한다. 따라서 큐비트 수가 260개라도 IBM r2의 높은 샘플링 속도와는 전혀 다른 실용 특성을 갖는다. [26]
  - **Atom Computing AC1000**은 1,200개 이상의 중성원자 물리 큐비트, 중간 측정 및 재사용 기능을 제품 사양으로 내세운다. 물리 큐비트 확장 규모는 이미 520q r3의 발표 수치를 넘지만, 동시에 수행하는 논리 게이트 깊이·오류정정 능력은 별도 지표다. [27]
  - 중성원자는 큰 배열과 원자 이동으로 연결 구조를 유연하게 조정할 수 있지만, 원자 손실·재배치·레이저 제어·게이트 속도는 중요한 과제다.
  - **광자 기반 양자컴퓨터**는 전송과 모듈 연결에 유리한 광 모드를 활용하지만, 광원·검출기·광 손실·광학적 비결정성 게이트와 FTQC 자원 확보 문제를 해결해야 한다. 이 글은 아직 공개 검증된 동급 시스템 벤치마크가 부족해 특정 광자 플랫폼을 수치 순위에 넣지 않는다.

**✅ 11. 투자자·연구자 관점: 이번 IBM 발표를 어떻게 평가할 것인가?**

- - **긍정적 해석:** IBM은 r2의 고속 반복 실행을 실서비스에 제공하고 있으며, r3에서 수백 큐비트 단일칩 설계로 확장을 준비한다. 기존 9칩 다중 연결안보다 인터페이스 수와 조립 복잡도를 줄일 수 있다는 점은 공학적으로 의미가 있다.
  - **기술적 부담:** 520큐비트 대형 칩에서는 제조 수율, 신호선 길이, 캘리브레이션, 누화 및 동시 게이트 성능의 난도가 높아진다. IBM은 Nighthawk r3에 필요한 내부 신호선 길이가 r2보다 크게 늘어날 것으로 설명한다. [3]
  - **핵심 변수:** Starling은 수백 큐비트로 보여주는 오류정정 PoC보다 훨씬 큰 다중모듈 시스템이다. **논리 오류율 × 연산 깊이 × 실제 시간**을 동시에 만족해야 한다.
  - **경쟁 구도:** Nighthawk r3의 520은 물리 계산 큐비트이고, Quantinuum의 50 논리 큐비트 시연이나 IBM Starling의 200 논리 큐비트 목표와 같은 단위가 아니다. 차이가 큰 숫자를 한 그래프로 놓고 성능 격차라고 주장하면 오판한다.
  - **종합 판단:** 2026년 IBM의 강점은 실가동 QPU와 수많은 샘플을 처리하는 실행 시스템을 개발하고, 차세대 대형 QPU 및 FTQC 구성요소를 병렬로 개선하고 있다는 점이다. 다만 **Nighthawk r3 공개가 Starling의 성공을 입증한 것은 아니다.**

**✅ 12. 최종 정리**

- - **IBM의 새 뉴스:** 2026년 11월 11일 Nighthawk r3의 **520 프로그래밍 가능 큐비트, 2,034 물리 양자 요소, 10K 회로 연산, L-coupler 10개 설계**를 발표했다. 2027년에는 두 칩을 연결한 1,040큐비트 시스템을 목표로 한다.
  - **새 로드맵의 핵심:** Nighthawk는 단일칩 대형화를 강화했고, Starling은 2029년을 유지하며 qLDPC·C-coupler·디코더·극저온 모듈의 동시 개발을 강조한다.
  - **연결 기술의 층위:** Tunable Coupler는 인접 결합을 제어하고, C-coupler는 칩 내부의 비국소 연결을 제공하며, L-coupler는 서로 다른 QPU 간 마이크로파 양자 상태 전달을 가능하게 한다.
  - **양자 네트워크의 장기 방향:** 초전도 마이크로파 링크는 극저온·단거리에서 유리하지만, 원거리·이기종 연결에는 높은 효율과 낮은 잡음을 동시에 달성하는 **마이크로파↔통신광 양자 변환**이 필요하다.
  - **산업 경쟁력의 올바른 기준:** QPU의 큐비트 숫자뿐 아니라 실제 게이트 오류, 회로 깊이, 실행 속도, 논리 오류율, 모듈 연결, 공정 수율, 그리고 검증된 상용 제공 여부를 함께 봐야 한다.
  - **최종 결론:** Nighthawk r3는 2027년 초전도 대형 칩 경쟁에서 주목할 계획이지만, 2026년 현재 Google·Quantinuum·IonQ·중성원자의 다양한 실측 성과보다 전반적으로 앞섰다고 단정할 근거는 없다. **각 아키텍처는 서로 다른 병목을 해결 중**이며, 2027~2029년의 FTQC 검증이 진정한 비교의 기준이 될 것이다.
