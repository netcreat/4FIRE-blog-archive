# EQC는 레이저를 줄였는데, 왜 SP90 광도파로 손실이 중요할까?

Published: 2026-11-04T18:46:12+11:00

Original Naver post: https://blog.naver.com/4-fire/224464875535?fromRss=true&trackingCode=rss

---

**✅ Superion 256에서 10K까지**

- - IonQ의 새로운 Superion QPU는 EQC(Electronic Qubit Control)로 양자 게이트를 전자적으로 구동한다. 그렇다면 레이저와 광도파로는 더 이상 필요하지 않을까?
  - 그렇지 않다. **양자 게이트를 제어하는 것**과 **이온을 냉각·초기화·판독하고 광자를 전달하는 것**은 서로 다른 문제다. EQC가 전자를 담당하더라도 후자의 광학 기능은 남는다.
  - SkyWater는 SP90에서 493nm·650nm·1762nm 파장의 SiN 광도파로 손실을 공개했다. 특히 493nm의 1.56dB/cm라는 수치는 눈에 띈다. 다만 이 수치가 Superion 256의 실제 게이트 충실도 저하를 의미하지는 않는다.

**✅ 1. 광도파로는 전기 신호를 빛으로 바꾸는 장치가 아니다**

- - 광도파로(Optical Waveguide)는 이미 생성된 빛을 칩의 원하는 위치로 전달하는 **광학 배선**이다. 빛을 만들어내는 레이저, 빛의 세기·위상을 조정하는 변조기, 빛을 검출하는 포토디텍터와 역할이 다르다.
  - 이온트랩 QPU에서 빛의 흐름은 한 방향만 있는 것이 아니다.

    - ① 외부 레이저 → 광섬유·도파로 → 이온
    - ② 이온의 형광 → 수집 광학계·도파로 → 검출기
    - ③ 이온에서 나온 광자 → 광학 회로·광섬유 → 다른 QPU 같은 경로가 모두 가능하다.
  - 광도파로의 전파 손실(dB/cm)은 **실제로 그 도파로를 지나는 광자**에만 적용된다. 형광을 외부 렌즈로 직접 수집한다면 SP90 내부 도파로의 전파 손실을 그 경로에 적용할 수 없다.

|  |  |  |
| --- | --- | --- |
| **구성요소** | **주요 역할** | **SiN 도파로와의 관계** |
| 레이저 광원 | 특정 파장의 빛 생성 | 외부 또는 집적 광원에서 빛 공급 |
| 광도파로(SiN) | 빛을 칩 안에서 전달·분배 | 전파 손실(dB/cm) 발생 |
| Grating / Fiber Coupler | 광도파로↔이온·광섬유 사이 결합 | 별도의 결합 손실(dB) 발생 |
| 광검출기 | 형광·단일광자 검출 후 전기 신호 생성 | 수집·검출 효율이 중요 |
| EQC 안테나·전극 | 전자기장으로 이온 양자 게이트 수행 | 도파로가 전자적 게이트를 직접 구동하지 않음 |

---

**✅ 2. EQC는 모든 레이저를 제거하는 기술이 아니다**

- - [Oxford Ionics의 기술 설명](https://www.oxionics.com/our-technology/)에 따르면 EQC는 실리콘 칩의 집적 안테나에 교류 전류를 흘려 진동 자기장을 만들고, 이를 이용해 양자 게이트를 수행한다. 레이저를 사용한 게이트 제어를 전자적 방식으로 대체하는 것이다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMDRfMjMx/MDAxNzkzNzc2OTU4NjEx.PLhH6L0jmAeWSzNt8zHjjHG7A0djDoRqWkh7OCgDRM0g.41wsBWV_qL4fS8hIJtW-voP691rC61Y8FfRkR5GTGrEg.PNG/image.png?type=w800)](#)

- - 그러나 같은 공식 설명은 **상태 준비(Preparation)와 측정(Measurement)에 사용하는 레이저가 진공 챔버 외부의 서버 랙에 있다**고 명시한다. 또한 전자회로와 집적 포토닉스 기술이 QPU 칩에 포함된다고 설명한다.
  - [IonQ의 2026년 9월 Superion 발표](https://www.ionq.com/news/ionq-launches-superion-product-line-industry-leading-upgradeable-platform-designed-to-scale-manufacturable-fault-tolerant-quantum-computing)는 Superion 256의 QPU 패키지가 Light Delivery, EQC, 이온 포획·이동, 준비·판독에 필요한 기능을 통합한다고 설명한다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMDRfNTEg/MDAxNzkzNzc2OTk1NjQy.cmfT_5L99UybwlOmm5apQRyKDZE1-wJlQAZgJ9teD9Ag.ZtixqZYri971nVnyKtBIDYZ1RutPCr2DRcVQXUni7T4g.PNG/image.png?type=w800)](#)

- - **확인되지 않은 사항**도 있다. Superion 256에서 493nm·650nm·1762nm가 각각 어떤 경로로 전달되는지, 형광을 외부 렌즈로 수집하는지 또는 온칩 도파로·검출기로 수집하는지, 그리고 SiN 광도파로가 SP90 공정인지에 대한 구체적 공개 자료는 확인되지 않는다.

|  |  |  |
| --- | --- | --- |
| **기능** | **EQC 도입 후** | **레이저·광학계의 필요성** |
| 이온 포획·이동 | 전기장·전극으로 수행 | 포획 자체는 레이저 도파로와 별개 |
| 단일·2큐비트 게이트 | 집적 안테나의 전자적 제어 | 게이트용 레이저 의존성 감소 |
| 냉각·상태 준비 | 광학 과정 유지 | 레이저 전달 필요 |
| 형광 판독(SPAM) | 광자 수집 및 상태 구분 | 광학 수집·검출 필요 |
| 원격 얽힘 | 별도의 광자 인터페이스 필요 가능 | 광자 발생·수집·변환·검출 설계에 의존 |

**✅ 3. SP90에서 공개된 도파로 손실은 실제로 얼마인가?**

- - SkyWater는 2026년 10월 27일 [SP90의 웨이퍼 측정 자료](https://www.skywatertechnology.com/a-closer-look-inside-sp90/)를 공개했다. SP90의 공통 광학 기반은 200mm 웨이퍼 위의 SiN이며, 회사가 제시한 지원 파장 범위는 400~2,000nm 이상이다.
  - 광학 손실 지도는 파장·공정 조건별로 45개 다이 위치를 측정한 결과다. 측정값은 초기 샘플 기반 데이터이며 보증된 양산 제품 규격이 아니다.

|  |  |  |  |
| --- | --- | --- | --- |
| **파장** | **SiN 제조 공정** | **평균 전파 손실** | **웨이퍼 3σ / 측정 범위** |
| 493nm | 저온 · Back-End 호환 | **1.56dB/cm** | 0.51dB/cm / 1.23~2.03dB/cm |
| 1762nm | 저온 · Back-End 호환 | **0.40dB/cm** | 0.12dB/cm / 0.308~0.466dB/cm |
| 1762nm | 고온 · Front-End | **0.13dB/cm** | 0.04dB/cm / 0.109~0.159dB/cm |
| 650nm | 별도 다이 측정 | **0.30dB/cm** | 45개 다이 웨이퍼 평균과 별개 |

- - **저온·고온은 QPU가 동작하는 온도가 아니라 웨이퍼의 증착·열처리 등 제조 공정의 열 예산**을 뜻한다. 저온 공정은 기존 소자 위에 다른 소재·레이어를 추가하기에 유리할 수 있지만, 이번 자료에서는 동일한 1762nm에서 고온 공정이 더 낮은 손실을 보였다.
  - 단, 공정 온도 외에도 막 두께·재료 구성·도파로 단면 등 설계 차이가 있을 수 있다. 손실 차이의 원인을 온도 하나로 단정할 수는 없다.
  - **25장 웨이퍼 측정**은 별도의 PVD 박막 두께·굴절률 조사다. 25장 모두에서 광학 손실이나 양산 수율을 검증했다는 뜻이 아니다.
  - 색상으로 그린 각 웨이퍼 손실 지도는 서로 다른 색상 척도를 사용하므로 색깔만으로 파장 간 손실을 비교해서는 안 된다.
  - **그림:** SkyWater의 SP90 광도파로 전파 손실 지도와 별도 25장 웨이퍼 박막 측정 자료.

**✅ 4. 493nm·650nm·1762nm는 바륨 이온에서 무슨 역할을 하나?**

- - Oxford Ionics 기반의 EQC 플랫폼은 바륨 이온(Ba⁺)을 활용한다. 해당 이온의 대표적인 광학 전이는 SP90이 측정한 파장과 겹친다.
  - 하지만 특정 파장을 측정했다는 사실만으로 그 파장이 Superion 256의 해당 광학 배선에 사용됐다고 확정할 수는 없다.

|  |  |  |  |
| --- | --- | --- | --- |
| **파장** | **Ba⁺ 에너지 준위 전이** | **대표적인 기능** | **EQC 관점** |
| 493nm | 6S₁/₂ ↔ 6P₁/₂ | 냉각, 형광 판독, 광자 방출 | SPAM·광자 인터페이스에서 중요할 수 있음 |
| 650nm | 5D₃/₂ ↔ 6P₁/₂ | Repumping, 냉각 사이클 유지 | 레이저 광출력 전달·분배가 중요 |
| 1762nm | 6S₁/₂ ↔ 5D₅/₂ | 준안정상태 전환, Optical Qubit·Shelving 제어 | 필요한 전이를 쓸 경우 중요. EQC 게이트 광원이라고 단정 금지 |
| 614nm | 5D₅/₂ ↔ 6P₃/₂ | 준안정상태 재설정 등에 사용 가능 | 이번 SP90 손실 측정표에는 수치 미제공 |

- - 1762nm의 5D₅/₂ 전이는 장수명 준안정상태를 이용한다. 그러나 EQC의 전자적 양자 게이트와 1762nm 광학 전이를 동일한 제어 방법으로 이해해서는 안 된다.
  - 493nm가 칩 안에서 단일광자를 실어 나르는 경로인지, 레이저 조사용 경로인지에 따라 손실의 중요성이 완전히 달라진다.

**✅ 5. 1.56dB/cm는 실제 길이에서 얼마나 큰 손실인가?**

- - **전파 손실 계수(dB/cm)와 실제 광자 손실률(%)은 다르다.** 도파로 길이가 ℓ(cm)일 때 총 손실은 α(dB/cm) × ℓ(cm)이고, 투과율은 10−총손실(dB)/10이다.
  - 따라서 493nm에서 1cm를 통과한다면 10−1.56/10 ≈ 0.6982, 즉 약 69.82%가 통과하고 **약 30.18%가 손실**된다.
  - 이 계산은 해당 손실 계수가 길이에 따라 일정하다는 가정이다. 실제 칩의 전체 광학 손실이나 검출 효율, 양자 게이트 충실도를 직접 측정한 결과가 아니다.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **길이** | **493nm 저온** | **650nm 별도 다이** | **1762nm 저온** | **1762nm 고온** |
| 1mm | 3.53% | 0.69% | 0.92% | 0.30% |
| 2mm | 6.93% | 1.37% | 1.83% | 0.60% |
| 5mm | 16.44% | 3.39% | 4.50% | 1.49% |
| 10mm (1cm) | 30.18% | 6.67% | 8.80% | 2.95% |
| 20mm (2cm) | 51.25% | 12.90% | 16.82% | 5.81% |

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMDRfMTY1/MDAxNzkzNzc3NDIxNDc3.wLCMm-s1u8Vb8tm66LOhOoQduyC09lb-tbcfm9Nkqwsg.cvHHnWzAVhoDHKyh5PSDVVddiHs-uNfEuM4WP8jSEJUg.PNG/image.png?type=w800)](#)

- - **5mm를 기준으로** 493nm는 약 16.44%를 잃지만, 1762nm는 저온 약 4.50%, 고온 약 1.49%가 손실된다.
  - **1cm를 기준으로** 493nm는 약 30.18%, 1762nm 저온 약 8.80%, 고온 약 2.95%가 손실된다.
  - 같은 1762nm에서 고온 SiN의 평균 전파 손실 계수 0.13dB/cm는 저온 0.40dB/cm보다 67.5% 낮다. 이는 dB/cm 계수 비교이지 광자 투과율이 67.5% 높다는 의미는 아니다.
  - 650nm의 숫자는 별도 다이에서 나온 값이므로 웨이퍼 평균을 바탕으로 한 세 조건과 동등한 통계적 신뢰성을 가진다고 해석하면 안 된다.

**📌 도파로의 길이는 정말 cm 단위일까?**

- - 실제 사례로 2024년 Sandia 연구진의 [다중 이온 사이트 집적 광학 논문](https://www.nature.com/articles/s41467-024-47882-5)에는 약 **5mm**의 도파로가 등장한다. 광섬유 입력부터 여러 트랩 사이트까지 빛을 전달하기 위해 분배기와 출력 Grating을 사용했다.
  - 이 연구는 이터븀(Yb⁺) 이온의 369nm·435nm 등 다른 파장을 이용했고 SkyWater SP90이나 IonQ Superion의 실측이 아니다. 일반화된 표준 길이도 아니다.
  - 따라서 1~2mm는 짧은 국부 배선 가정, 5mm는 실증된 규모의 참고 사례, 10~20mm는 더 긴 라우팅을 검토하는 설계 시나리오로 구분하는 것이 타당하다.
  - 특히 다수 이온 사이트를 연결하는 분기 구조에서는 광원에서 각 목적지까지의 **실제 광학 경로 길이**와 분배기 손실을 따로 계산해야 한다.

**✅ 6. 광학 손실이 실제로 영향을 주는 QPU 성능은 무엇인가?**

|  |  |  |
| --- | --- | --- |
| **적용 분야** | **전파 손실이 커지면** | **영향이 나타나는 성능** |
| 레이저 냉각·Repumping | 이온에 도달하는 광출력 감소 | 냉각·상태 준비 시간, 출력 보정 부담 |
| 형광 상태 판독 | 검출할 수 있는 광자 수 감소 | SPAM 오류, 신호 대 잡음비, 판독 시간 |
| 1762nm 광학 전이 | 전이 구동에 사용할 광량 감소 | 해당 전이를 쓰는 경우 제어 시간·안정성 |
| 원격 얽힘용 단일광자 | 광자 생존 확률 감소 | 얽힘 생성률·반복 시도 횟수 |
| EQC 전자적 게이트 | 도파로 손실과 직접 결합되지 않음 | 게이트 충실도와 일대일 연동 아님 |

**📌 냉각용 레이저와 단일광자는 왜 다르게 봐야 하나?**

- - 냉각이나 상태 준비에 사용하는 레이저는 광출력이 감소하면 입력 레이저 출력을 높여 일정 부분 보정할 수 있다. 5mm에서 493nm 손실이 16.44%라면 동일한 출력 확보에 약 19.7% 높은 입력광이 필요하다는 계산이 나온다. 단, 산란·잡음·광원 최대 출력·열 영향은 별도 검토 대상이다.
  - 반면 이미 방출된 형광 또는 원격 얽힘에 활용할 단일광자는 손실된 광자를 단순히 레이저 출력 증가로 되살릴 수 없다. 이 경우에는 검출 수율과 필요한 반복 횟수에 영향이 더 직접적이다.

**📌 원격 얽힘에서는 두 광자가 모두 살아남아야 할 수 있다**

- - 예를 들어 493nm 광자가 양쪽 QPU에서 각각 5mm의 SP90형 도파로를 지난다고 가정하면 한 경로의 광자 투과율은 약 83.56%다.
  - **두 광자를 모두 필요로 하는 프로토콜**이라면, 그 두 구간을 통과하는 광자 생존 확률은 0.8356 × 0.8356 ≈ **69.8%**다. 즉 다른 손실이 전혀 없더라도 전파 구간만으로 두 광자 동시 생존 기회 약 30.2%를 잃는다.
  - 다만 이것은 **실제 IonQ 원격 얽힘 성공률이나 얽힘 충실도 측정치가 아니다.** 광자 검출 방식, 광학 간섭, 주파수 변환, 배경 잡음과 성공 신호 조건에 따라 최종 수치가 달라진다.
  - 일반적으로 광자 손실은 얽힘 생성률을 떨어뜨리지만, 성공으로 판정된 얽힘의 조건부 충실도가 같은 비율로 떨어진다고 단정할 수는 없다.

**✅ 7. 256큐비트에서 10,000큐비트로 가면 외부 레이저가 병목이 될까?**

- - 문제는 외부에 레이저가 있다는 사실 그 자체보다, **몇 개의 광원을 몇 개의 이온에 어떤 방식으로 분배할 것인지**다. 광원 하나를 다수 채널이 공유할 수도 있고, 병렬 광원 그룹과 광학 스위칭을 함께 사용할 수도 있다.
  - 만약 하나의 빔을 256개 또는 10,000개 채널에 동시에, 균등하게 분할한다면 이상적인 분배만 고려해도 각 출력으로 가는 광파워는 각각 1/256 또는 1/10,000이 된다. 이는 약 24.1dB 및 40dB의 분배 비율에 해당한다.
  - **위 수치는 설명용 극단적 가정**이다. 실제 장치는 단일 광원에서 모든 큐비트를 동시 개별 조사하도록 설계할 필요가 없으며, 광원 공유·다중화·구역별 병렬화로 다른 구조를 선택할 수 있다.
  - 광학 구동뿐 아니라 보조 큐비트 판독이 얼마나 빨리 병렬로 수행되는지, 형광을 얼마나 효율적으로 수집하는지, 시분할 방식이 오류정정 주기와 충돌하지 않는지도 중요해진다.

| --- | --- | --- |
| **확장 병목** | **발생 원인** | **검증해야 할 기술 지표** |
| 광원·파워 예산 | 분배 채널 증가와 손실 누적 | 경로당 광파워, 광원 수, 여유 출력 |
| 도파로·결합 수율 | 배선·분배기·결합면 증가 | 파장별 실제 경로 손실, 다이별 편차 |
| 측정 병렬성 | 다수 이온의 형광을 제한 시간에 수집 | 동시 판독 채널 수, SPAM, 판독 지연 |
| 크로스토크·전하 | 광산란과 전극 주변 절연체 전하 | 인접 채널 간섭, 이온 안정성 |

- - IonQ는 [Superion 10K 로드맵](https://www.ionq.com/blog/innovating-manufacturing-and-scaling-highlights-from-ionq-investor-day-2026)에서 온칩 CMOS, Quantum Multiplexed I/O, Walking Cat 같은 기술을 강조한다. 하지만 이는 전자 제어 확장 전략과 관련된 설명이며, 10,000큐비트 규모의 광학 상태 준비·판독 성능이 모두 실증됐다는 뜻은 아니다.
  - 10K의 광학 설계에서 실제 경로 길이, 광원 분배 방식, 동시 판독 가능한 이온 수가 공개되어야 이 병목을 정량적으로 평가할 수 있다.

**✅ 8. SkyWater에서 Superion 256을 만들었다는 사실과 SP90 적용은 다르다**

- - [IonQ 공식 발표](https://www.ionq.com/news/ionq-launches-superion-product-line-industry-leading-upgradeable-platform-designed-to-scale-manufacturable-fault-tolerant-quantum-computing)에 따르면 Superion 256의 QPU는 IonQ와 SkyWater가 공동 설계·제조했고, 2026년 9월 기준 프로토타입에서 최초 이온 포획에 성공했다. 고객 인도는 2027년 목표다.
  - SkyWater는 별도로 [SP90 웨이퍼가 이미 출하됐다](https://www.skywatertechnology.com/i-spent-a-decade-waiting-on-quantum-wafers-now-im-joining-the-foundry-that-can-actually-deliver-them/)고 밝혔다. 다만 출하된 SP90 고객 웨이퍼와 Superion 256 QPU 웨이퍼를 동일한 것으로 볼 근거는 제시되지 않았다.
  - **같은 파운드리에서 만든 칩이라도 동일한 공정 스택을 썼다고 단정할 수 없다.** SP90은 SiN 포토닉스의 공통 플랫폼이며, Superion의 정확한 포토닉스 레이어·Waveguide 재료·광학 경로는 아직 미공개다.
  - 따라서 493nm 1.56dB/cm를 Superion 256의 실측 성능으로 직접 대입하는 주장은 성립하지 않는다. 해당 광도파로가 실제로 사용됐다는 사실부터 확인해야 한다.

**✅ 9. 앞으로 무엇을 확인해야 할까?**

- - **① 실제 공정 구성:** Superion 256·10K에 SP90의 SiN 레이어가 적용되는지, 다른 집적 광학 공정과 어떻게 구분되는지.
  - **② 파장별 실제 배선:** 493nm·650nm·1762nm 가운데 어떤 파장이 광섬유·온칩 도파로·자유공간 렌즈로 전달되는지.
  - **③ 경로 길이와 End-to-End Loss:** 광섬유 입력부터 이온, 그리고 이온에서 검출기까지 경로별 총 손실이 얼마인지.
  - **④ 판독·얽힘 시스템 지표:** SPAM 충실도·검출 시간·동시 판독 채널 수·원격 얽힘 성공률과 조건부 충실도.
  - **⑤ 웨이퍼 및 패키징 통계:** 다이 간 손실 변동, 파장별 수율, 통합 후 성능, 광학·전기 접속 신뢰성.
  - **⑥ 10K 확장 구조:** 광원을 공유하는 범위, 광학 분배·스위칭 방식, 필요한 동시 판독 처리량.

**✅ 10. 결론 — EQC의 다음 병목은 광학 I/O일 수 있다**

- - EQC는 이온트랩의 큰 난제였던 광학 게이트 제어의 복잡도를 전자적 제어로 옮겼다. 이것은 매우 중요한 기술적 진전이다.
  - 그렇다고 양자컴퓨터에서 빛이 사라진 것은 아니다. 냉각·상태 준비·형광 판독·원격 광자 인터페이스에는 여전히 정교한 광학 기술이 필요하다.
  - SkyWater SP90의 초기 데이터에서 **493nm 1.56dB/cm는 긴 경로와 단일광자 수집에 부담이 될 수 있고**, 1762nm의 0.13~0.40dB/cm는 동일 길이에서 상대적으로 낮은 전파 손실을 보인다.
  - 하지만 **SP90의 측정값 = Superion의 실제 광학 손실**은 아니다. 같은 SkyWater 제조라는 사실만으로 동일 공정을 사용했다고 단정할 수 없으며, 실제 레이아웃·광학 경로가 공개되어야 한다.
  - **필자의 판단:** Superion이 256에서 10K 이상으로 확장될 때 검증해야 할 다음 과제 중 하나는 전자적 게이트 자체보다 **광학 전달·병렬 판독·광자 수집의 집적과 수율**일 가능성이 있다. 이는 기술적 가설이며 아직 공개된 10K 제품 성능으로 확인된 결론은 아니다.
