**✅ 1. 이번 발표의 핵심 메시지**

- - **행사:** Cisco Quantum Summit 2026 Day 2, 2026년 10월 7일.
  - **발표자:** Pete Shadbolt, PsiQuantum 공동창업자 겸 최고과학책임자(CSO).
  - **첫째, 상용 FTQC는 다수의 칩과 모듈을 연결하는 시스템 문제가 된다.** IBM, IonQ, Pascal, PsiQuantum의 확장형 아키텍처를 나란히 소개하면서, 단일 칩의 큐비트 수만으로는 상업적으로 유용한 연산 능력을 확보하기 어렵다고 설명한다.
  - **둘째, 광자 양자컴퓨팅의 핵심은 광학적 손실을 낮추면서 다수의 광학 부품을 고수율로 생산하는 데 있다.** 광자 발생·분배·경로 선택·Fusion·검출을 하나의 통합 제조 플랫폼으로 가져가는 방향이다.
  - **셋째, PsiQuantum이 구축한 고속 광스위치 기술은 AI 데이터센터의 Optical Circuit Switching(OCS)에도 적용할 가능성이 있다.** 이번 자료는 양자컴퓨팅 인프라 개발과 포토닉스 플랫폼 사업의 교집합을 보여준다.
  - **판단 유보:** 부품 제조 능력과 스위치 시제품은 중요한 성과이지만, 대규모 논리 큐비트·전체 시스템 오류율·실제 상용 OCS 고객 확보가 함께 입증된 것은 아니다.

  - **필자 해석:** PsiQuantum의 분산형 설계는 광섬유가 무조건 우월해서가 아니라, 단일 장비의 환경 제어·제조 한계를 우회하기 위한 선택이라는 메시지다.

**✅ 2. Fusion-Based Quantum Computing의 작동 방식**

**📌 물질 큐비트와 다른 광자 기반 접근**

- - PsiQuantum은 광자 자체를 정보 매체로 사용한다.
  - PsiQuantum의 아키텍처는 단일 광자 발생 → 광경로 스위칭·멀티플렉싱 → 작은 얽힘 자원 상태(Resource State) 준비 → Fusion 측정 → 오류정정 가능한 대규모 연산 구조 구축으로 정리할 수 있다.
  - Fusion은 광자 기반 Bell 상태 측정 계열의 동작으로, 별도 얽힘 자원들을 측정을 통해 연결한다. 광학적 Fusion 시도의 성공은 확률적이므로 실패를 관리하는 설계가 필수적이다.
  - 광섬유를 통한 칩 간 연결에 적합하다는 이점이 있지만, 광자는 손실되면 같은 양자 상태를 광증폭기로 단순 복원할 수 없다. 따라서 낮은 손실, 고속 스위칭, 중복 자원 및 QEC가 모두 중요하다.

**📌 실제 연결에서는 광섬유 양 끝에 더 많은 문제가 숨어 있다**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMTdfMjg1/MDAxNzkyMjI5NTY2Mzg1.tjC86Ji_drCmg2LadtwcSxR7FyMzKUWj9m5p5CjdVYcg.PcEs4LA-LA0tIsjXz7Z4nZofITSML3VbtPyTYHSr1dMg.PNG/image.png?type=w800)](#)

- - Pete는 Microwave-to-Optical 변환, Polarization 또는 Time-bin 인코딩, Chip-to-Fiber Coupling, Vacuum Feedthrough, 광섬유 안정화, 광스위칭, 단일 광자 검출을 하나의 연결 체인으로 제시했다.
  - **진공 챔버 벽을 통과하는 광섬유**나 움직일 때 변하는 광섬유 편광처럼 실험 논문에서 상대적으로 덜 강조하는 요소도 실제 장비에서는 성능과 신뢰성을 결정한다고 설명했다.
  - 기존 이온트랩의 두 광자 간섭을 이용한 Heralded 원격 얽힘과 광자 기반 Fusion이 관련된 광학 메커니즘을 공유한다는 점도 언급했다. 단, 두 기술의 전체 연산 속도는 동일하지 않다.
  - **판단:** 분산 FTQC의 병목은 광전달 속도만이 아니라 **광자 생성→연결→검출의 전체 손실 예산과 자동 운용성**이다.

**📌** **실제 Fusion은 어떻게 일어나는가?**

- - 예를 들어 두 개의 칩이 각각 얽힌 광자 쌍을 준비한다고 가정하자.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMThfMjg3/MDAxNzkyMjg1MjMwNDE2.mmNFVC2KW2ldQTPrYFbRRnhtUb7PflFSVlyxsxTjsi8g.OqIpViwehMDtkqQTjaKarjUzYI4G3uQw-lABc_ef5oAg.PNG/image.png?type=w800)](#)

- - 중요한 것은 Fusion에 투입된 광자 B와 C는 측정 과정에서 소모되지만, 그 결과로 나머지 광자 A와 D 사이의 얽힘 관계를 형성할 수 있다는 점이다.
  - 이를 반복하면 작은 얽힘 자원들을 더 큰 양자 연산 네트워크로 연결할 수 있다.
  - 또한 A와 D가 물리적으로 같은 칩에 있을 필요도 없다.
  - 이것이 PsiQuantum이 광섬유 인터커넥트를 중요하게 생각하는 이유다.

**✅ 3. 분산 FTQC의 광자 손실 예산: 50%와 98%**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMTdfMjMx/MDAxNzkyMjI5NjE3MjEw.1ptsf0yNLm8Io8Lu-dEAMaJ93De9XXJz6P_pw5-tTl0g.I4krHK2w9VKgQFiUAwMZnywVPIaeTgXpLl_ZgZK7BZYg.PNG/image.png?type=w800)](#)

**📌 2009년 연구: 알려진 위치의 손실에 대한 50% 임계값**

- - Stace·Barrett·Doherty의 *Physical Review Letters*(2009) 연구는 위치를 알 수 있는 손실(Located Loss / Erasure)에 대해 위상학적 오류정정 코드가 상당한 내성을 가진다는 점을 입증했다.
  - Pauli 연산 오류가 없는 이론적 조건에서 최대 손실 허용치는 50%에 도달할 수 있다. 이는 특정 위상학적 코드와 오류 모델의 임계값이다.
  - 광자 손실과 Pauli 오류가 동시에 발생하면 두 오류에 대한 허용 범위가 상충한다. 그러므로 “50%의 광자를 잃어도 실제 장비가 정상 동작한다”로 일반화해서는 안 된다.

**📌 2014년 연구: 98% 링크 손실을 감수하는 분산 컴퓨팅 모델**

- - Nickerson·Fitzsimons·Benjamin의 *Physical Review X*(2014) 연구는 소규모 물질 큐비트 셀 사이에 매우 손실이 큰 광학 링크가 있더라도, Heralded 얽힘과 정제·반복 시도를 이용하는 구조를 검토했다.
  - 해당 연구의 모델에서는 초당 200만 회(2 MHz) 얽힘 생성을 시도하는 링크에 광자 손실 98%를 적용해도, 조건에 따라 kHz급 안정자 측정 클록이 가능하다고 제시했다.
  - 98% 손실 허용은 더 많은 반복 시도와 얽힘 생성 시간을 교환하는 구조에서 도출한 결과다. PsiQuantum의 광자 기반 Fusion 아키텍처 자체가 98% 손실을 견딘다는 실증은 아니다.
  - **핵심 해석:** 분산 FTQC의 실현 가능성은 단순한 손실률 하나가 아니라 성공 여부의 식별, 충실도, 재시도 속도, 부품 수, QEC 사이클의 총합으로 평가해야 한다.

**📌 50%와 98%를 동시에 인용한 이유는 손실과 속도의 교환관계다**

- - Pete는 2009년의 약 50% 위치가 알려진 손실 임계값과 2014년의 최대 98% 손실을 감수하는 이종 분산 아키텍처를 양 끝 사례로 설명했다. **둘은 같은 장비의 성능이 아니다.**
  - 98% 손실도 처리할 수 있다는 연구의 의미는 손실이 중요하지 않다는 뜻이 아니라, **더 많은 얽힘 생성 시도와 기다리는 시간**을 지불하면 오류정정이 가능할 수 있다는 뜻이다.
  - 따라서 실제로 비교해야 할 것은 단순한 손실 허용률이 아니라 **손실과 충실도, 반복 시도 속도, QEC 수행 시간의 총합**이다.

**📌 50%와 98%는 서로 다른 대상을 잃는다는 뜻이다**

|  |  |  |
| --- | --- | --- |
| **비교 항목** | **50%: Stace 외(2009)** | **98%: Nickerson 외(2014)** |
| 손실 대상 | 위상학적 QEC 구조의 **위치가 알려진 큐비트 손실** | 분산된 물질 큐비트 셀 사이의 **광자 링크 손실** |
| 어떻게 대처하나 | 손실 위치를 활용해 코드와 측정 경로를 재구성 | Heralding·재시도·얽힘 정제와 물질 큐비트의 대기 |
| 대가 | Pauli 오류까지 정정할 수 있는 여유가 줄어듦 | 더 많은 연결 시도와 시간·보조 자원이 필요 |
| 적용 범위 | 특정 코드·오류 모델의 이론적 임계값 | 특정 분산 아키텍처의 수치 모델 |
| PsiQuantum 실증인가 | **아니오** | **아니오** |

- - **핵심 정리:** 50%는 PsiQuantum의 실제 광회로에서 광자를 절반 잃어도 된다는 주장이 아니며, 98%는 PsiQuantum의 Fusion 기반 양자컴퓨터가 광자를 98% 잃어도 정상 운영된다는 의미가 아니다.

**✅ 4. 인터커넥트 성능은 어떻게 비교해야 하는가?**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjEwMTdfMTA3/MDAxNzkyMjI5NjM0ODIz.PWrX_fHIJhAvmBiKb7d10TVC3r2lcVnCFovA3uBIZZIg.2-3PByPFyw0oQZE_Q69jTRi9t4HiDsey-b1SehvU9yMg.PNG/image.png?type=w800)](#)

- - Pete는 여러 물리 플랫폼의 인터커넥트 하위 기술을 두 개의 그래프에 배치했다. 왼쪽은 유효 손실(Effective Loss)과 불충실도(Infidelity), 오른쪽은 원격 얽힘 생성 속도와 불충실도의 관계를 보여준다.
  - **Infidelity = 1 − F:** 값이 낮을수록 기대한 양자 상태에 더 가깝다는 뜻이다. 손실이 줄어도 상태 충실도가 낮으면 실제 FTQC에 불리할 수 있다.
  - **Conditional:** 성공한 광자 검출·연결 이벤트를 선택한 뒤 계산한 성능이다. **Unconditional:** 실패·손실까지 포함한 지표다. **Model Reference:** 실제 실증점이 아닌 모델상의 기준점이다.
  - 그래프의 FBQC 목표 영역은 저손실·저오류 방향을 나타낸다. 서로 다른 실험의 점이 가까워도 하드웨어 구성과 측정 조건이 동일하지 않으므로 단순 순위를 매기기 어렵다.
  - IonQ의 kHz급 원격 얽힘 생성 속도와 PsiQuantum의 GHz급 광스위치 대역폭은 비교 대상이 다르다. 의미 있는 최종 지표는 논리 오류율을 제어하면서 수행하는 실제 오류정정 연산 처리량이다.

|  |  |  |
| --- | --- | --- |
| **비교 지표** | **의미** | **유리한 방향** |
| Effective Loss | 실제 링크에서 발생하는 광자·정보 손실 | 낮을수록 좋음 |
| Infidelity (1−F) | 목표 상태와 실제 상태 사이의 불일치 | 낮을수록 좋음 |
| Entanglement Generation Rate | 단위 시간당 원격 얽힘 생성량 | 다른 조건이 같다면 높을수록 좋음 |
| Conditional / Unconditional | 성공 사례만 평가했는지 실패까지 포함했는지 | 동일한 기준으로 비교해야 함 |

**📌 1kHz Bell 쌍 생성도 아직 충분하지 않다는 평가**

- - Pete는 관련 논문에서 각종 전송·간섭·변환·검출 실험을 모아 발표하면서, 여러 분야가 좋은 결과를 내고 있지만 여전히 **더 낮은 손실과 더 높은 충실도**가 필요하다고 평가했다.
  - 그는 당일 앞선 IonQ의 발표에서 나온 **약 1kHz의 Bell-pair 생성**을 매우 인상적인 성과로 평가했다. 그러나 실제로 빠르고 유용한 분산 FTQC를 만들려면 원격 얽힘 충실도와 생성률을 더 높여야 한다는 입장이다.
  - 원격 인터커넥트는 제조 가능하고 현장에서 지속적으로 관리하기 쉬워야 한다. 가능하면 통신 파장에서 동작해 저손실 광섬유와 범용 통신 장비를 사용할 수 있어야 한다고 주장했다.
  - **필자 해석:** PsiQuantum이 IonQ의 연구를 인정한 뒤 자신들의 강점으로 연결하는 부분이다. 빠른 얽힘 1회보다 확장 가능한 링크를 반복 생산·운영할 수 있는지가 핵심이다. 하지만, 이미 소개한 패널 토론회에서 향후 1년동안의 목표를 묻는 질문에 Pete가 1MHz Bell state 생성이라고 말을 하자마자 Mihir가 1년안에 KHz에서 MHz로 높이는 것은 사실상 불가능하다고 반격을 한 바 있다.

**📌 누적 광자 손실은 왜 중요한가?**

- - 광자의 전송 손실을 데시벨(dB)로 나타내면 광자 생존 확률은 **P****survival** **= 10****−L/10**으로 계산할 수 있다. 여기서 L은 총 손실(dB)이다.
  - 예시로 한 단계당 0.1 dB의 손실을 갖는 소자를 여러 번 통과한다고 가정하면, 개별 부품의 작은 손실도 누적되어 광자 생존율을 떨어뜨린다.
  - 아래 표는 이해를 위한 산술 예시이며, PsiQuantum 실제 시스템의 전체 경로 측정값이 아니다.

|  |  |  |
| --- | --- | --- |
| **통과 단계** | **누적 손실** | **광자 생존 확률** |
| 1 | 0.1 dB | 약 97.7% |
| 5 | 0.5 dB | 약 89.1% |
| 10 | 1.0 dB | 약 79.4% |
| 20 | 2.0 dB | 약 63.1% |

**📌 BTO(Barium Titanate) 스위치의 전략적 의미**

- - BTO는 티탄산바륨이며 전기광학 효과를 이용해 빛의 위상을 빠르게 바꿀 수 있다. 적절한 광학 회로와 결합하면 높은 속도로 광경로를 선택·전환한다.
  - PsiQuantum은 수많은 확률적 단일광자 발생·Fusion 시도 가운데 유효한 광경로를 선택하기 위해 빠르면서도 손실이 낮은 스위치가 필요하다.
  - **10 GHz는 소자 수준의 전기광학 응답 능력에 관한 수치다.** 32포트 또는 72×72 전체 시스템의 경로 재설정 속도를 의미한다고 해석할 수 없다.
  - 슬라이드의 수치와 2025년 Nature 논문의 측정값은 동일한 시험 조건을 보장하지 않는다. 구형 실증 수치와 신규 부품 목표·측정 사양을 혼합해서는 안 된다.

**📌 새로운 광원: 캘리브레이션을 자동화하는 것보다 없애는 편이 낫다**

- - Pete는 AI를 이용한 양자컴퓨터 캘리브레이션의 가능성을 인정하면서도, 더 좋은 방법은 **애초에** **개별 캘리브레이션이 필요 없는 소자**를 만드는 것이라고 설명했다.
  - 기존의 공진형 광자 발생기는 Thermal Phase Shifter를 사용해 광학 특성을 조정했다. 문제는 같은 칩에 극저온 초전도 검출기가 있음에도 가열 소자가 수백 도로 올라갈 수 있다는 점이다.
  - 새로운 광원은 제조 공정 제어와 구조 설계 개선으로 **공진 구조의 별도 보정·제어를 제거**했다고 주장했다. 별도 필터링·보정 없이 높은 Hong–Ou–Mandel 간섭 가시도를 기록했다고 설명했다.
  - 이는 PsiQuantum 모든 소자에서 보정이 필요 없다는 뜻이 아니다. 특정 광원 구조의 개선이다. 그러나 다수의 광원을 운영할 때 온도·전력·설정 복잡성을 줄일 수 있다는 점에서 제조 확장과 직결된다.

**📌 광자 수까지 구별해야 하는 이유**

**✅ 9. 양자컴퓨팅에서 AI 데이터센터 OCS로 확장될 수 있는가?**

**📌 Optical Circuit Switching(OCS)의 원리**

- - 일반적인 패킷 스위치는 광신호가 들어오면 필요에 따라 광전변환하고 패킷을 해석·버퍼링·전송한다. OCS는 광경로 자체를 정해 지정된 송신부와 수신부 사이에 광학 회로를 형성한다.
  - OCS는 중간 단계의 불필요한 광전변환을 줄여 대규모 데이터센터의 전력·대역폭·네트워크 구조 측면에서 장점이 있을 수 있다.
  - 반면 경로를 설정해야 하고 혼잡·짧은 패킷·수많은 동시 흐름 처리에는 제약이 있다. Ethernet 패킷 스위치와 OCS가 모든 영역에서 완전히 대체 관계인 것은 아니다.
  - 광신호를 데이터로 처리하지 않고 통과시키더라도 양쪽 종단의 트랜시버, 장비 제어, 광경로 품질 관리는 여전히 필요하다.

**📌 PsiQuantum의 사업 기회와 아직 모르는 것**

|  |  |  |
| --- | --- | --- |
| **적용 분야** | **기술적 연관성** | **현재 판단** |

| 칩 간 양자 인터커넥트 | 저손실 광경로와 광섬유 결합 | 핵심 기술 요소 |

  - 하지만 자료만으로 일반 데이터센터 고객을 확보했는지, 스위치가 상용 판매되는지, 매출·원가 경쟁력이 어느 정도인지는 확인할 수 없다.
  - 따라서 OCS는 **확인된 응용 가능성과 아직 검증되지 않은 사업성**을 구분해 평가하는 것이 적절하다.

**📌 Pete가 밝힌 OCS 개발 단계 — 8×8 실증, 64×64 테이프아웃, 72×72 개발**

- - Pete는 Google TPU v4에서 사용했던 MEMS 거울 기반 광회로 스위치를 높이 평가하면서도, 자유공간 광학과 움직이는 부품에 의존한다는 구조적 특징을 지적했다.
  - PsiQuantum은 움직이는 부품 없는 Monolithic Photonic Switch를 목표로 한다. 발표에서는 **8×8 데이터센터용 OCS를 제작했고 NVIDIA RFP에 기재된 3dB 손실 목표보다 낮은 손실을 달성**했다고 주장했다.
  - **64×64는 Tape-out 완료, 72×72는 개발 진행 중**이라고 설명했다. 따라서 슬라이드 36의 랙형 72×72 표현은 완료·양산 실증과 분리해서 읽어야 한다.
  - NVIDIA가 제시한 RFP 성능 목표를 충족했다는 발언을 **NVIDIA 납품계약·발주·인증**으로 해석할 근거는 제시되지 않았다.

**📌 데이터센터 OCS가 FTQC 제조를 위험에서 벗어나게 하는 방법**

- - Pete는 기존 데이터센터용 스위치를 수천 대 생산할 수 있게 되면, 같은 기술을 이용하는 양자컴퓨터의 **패키징·조립·부품 조달·공급망 위험을 낮춘다**고 말했다.
  - 따라서 OCS는 단순한 부업이나 잠재 매출원이 아니라 **양자 장비를 상용 제조 규모로 끌어올리기 위한 검증 경로**라는 점이 분명해진다.
  - 이는 사업 전략에 관한 Pete의 설명이며, 실제 데이터센터 고객 확보와 OCS 매출은 별도로 확인해야 한다.

**📌 종합 평가**

- - **실증된 것:** PsiQuantum은 고성능 광자 발생·간섭·Fusion·인터커넥트 구성요소와, 이를 대규모로 제조·시험할 수 있는 포토닉스 기반을 확보했다. Nature 2025 실증값과 Cisco 발표의 개별 부품 수치가 이를 뒷받침한다.
  - **해석:** 이번 발표에서 높은 가치를 갖는 것은 단일 광자 큐비트 숫자보다 낮은 손실과 높은 제조 재현성을 추구하는 반도체 포토닉스 플랫폼이다. 필요한 광학 연결 수가 늘어날수록 이 플랫폼의 중요성도 커진다.
  - **아직 입증되지 않은 것:** 사용자 수준에서 연산 가능한 대규모 FTQC, 대규모 논리 큐비트 유지, 손실을 반영한 전체 시스템 오류율 및 OCS 상용 사업성과다.
  - **결론:** PsiQuantum이 실질적인 FTQC 경쟁력을 확정하려면 제조한 부품을 하나의 대규모 시스템으로 연결해, 광자 손실과 확률적 Fusion 실패가 있는 상황에서도 안정적인 논리 오류정정 연산을 수행한다는 사실을 보여줘야 한다.

**📌 Multiplexing이 Breakeven을 넘었다는 발언의 의미와 한계**

- - Pete는 지금까지 광자 양자컴퓨팅 플랫폼이 설득력 있는 논리 큐비트 실증을 거의 보여주지 못한 이유를 **광원과 게이트의 비결정론적 성공률**로 지적했다.
  - 독립된 시도의 성공 확률이 p일 때 N개 시도를 병렬로 수행해 적어도 한 번 성공할 확률은 **1−(1−p)****N**이다. 하지만 실제 시스템은 선택 스위치·도파관·검출기에서 광자를 잃기 때문에 확률 증가 효과와 추가 손실을 함께 비교해야 한다.
  - Pete는 좋은 광학 부품을 확보하면서 PsiQuantum이 **멀티플렉싱을 늘릴수록 오히려 성능이 감소하던 영역에서, 늘릴수록 성능이 향상되는 영역**으로 이동했다고 주장했다.
  - 그가 언급한 실험으로는 8개 광원 실험, 64포트 스위치, 더 큰 규모의 극저온 멀티플렉싱 실험을 위한 수백 개 광원·검출기의 탑재가 있다.
  - **강조:** 이는 멀티플렉싱의 하드웨어 자원 대비 순성능 이득을 주장하는 것이며 **논리 큐비트의 QEC Breakeven, Fault-Tolerant Logical Gate 또는 유틸리티급 FTQC를 실증했다는 뜻이 아니다.**

  - **논리 큐비트:** 고충실도 단일 Fusion을 넘어 실제 오류정정 논리 상태와 논리 게이트가 실증되는가.
  - **생산 수율:** 생산·시험 가능한 부품 수뿐 아니라 완성 모듈의 수율과 패키징 비용은 얼마인가.
  - **사업·구축:** 냉각 설비를 갖춘 여러 챔버를 연결해 장기간 안정적으로 운용할 수 있는가. 데이터센터 OCS의 외부 고객·발주·생산도 검증되는가.

**📌 종합 결론: 스위치가 아니라 확률의 경제성을 바꾸려는 발표다**

- - 이번 발표에서 Pete가 보여주려 한 것은 광학 부품의 최고 성능을 나열하는 데 그치지 않는다. **확률적인 광자 생성·Fusion 실패 문제를 제조 가능한 저손실 스위치와 대량 병렬화로 극복할 수 있는 단계로 옮기고 있다**는 주장이다.
  - GlobalFoundries의 300mm 제조공정, 자동 광섬유 패키징, 캘리브레이션을 제거한 광원, 고속 BTO, 광자 수 검출은 모두 이 하나의 문제를 해결하기 위해 연결된다.
  - 데이터센터 OCS는 FTQC 제조 경험을 일반 시장에서 반복적으로 검증하고 패키징·공급망 위험을 낮출 수 있다는 점에서 전략적 의미가 있다.
  - **그러나 최종 승부는 논리 큐비트다.** 250m 연결의 충실도, GHz 스위치, 월간 수백만 개 소자 시험이 곧 논리 오류정정이 된다는 의미는 아니다. 다음에 확인해야 하는 것은 실제 다중 모듈에서의 QEC 기반 논리 연산이다.

**📌 상업적 경쟁력의 마지막 관문은 플랜트 단위의 경제성이다**

- - **기술 측면:** 멀티플렉싱 성공률과 FTQC 오류정정 성능이 모두 입증되어야 한다. 개별 부품이나 광스위치 포트 수가 늘었다는 사실만으로 완성형 양자컴퓨터의 계산 성능이 높아졌다고 볼 수 없다.
  - **고객 제공 측면:** 고객이 원격으로 이용한다면 PsiQuantum의 대형 시설이 서비스를 제공할 수 있다. 반대로 고객이 직접 양자컴퓨터를 보유·운영한다면 같은 수준의 냉각·광학·제어 인프라가 필요할 수 있다.
  - **비용 측면:** 반도체 칩을 대량 제조하는 것과 수백 개의 Cryostat을 포함한 양자 데이터센터 전체를 경제적으로 운영하는 것은 다른 문제다. 최종 비교 기준은 **논리 연산당 총소유비용(TCO)**과 신뢰성이다.

**✅** **필자가 이해한 PsiQuantum의 구조와 현 개발 상황**

|  |  |
| --- | --- |
| **질문** | **정확한 해석** |
| 칩당 24개 광자 발생기가 탑재되나? | Pete가 소개한 현재 광원 칩의 구성 |
| 48개 광자 발생기 칩을 개발 중인가? | 이미 Tape-out했다고 발표 |
| 24~48개가 현재 제조 한계인가? | 제조상의 절대 한계라기보다 모듈형 확장 전략 |
| 광자 발생기 1개 = 물리 큐비트 1개? | 광원은 시간에 따라 광자 큐비트를 반복 생성할 수 있음 |
| 칩 사이 얽힘을 위해 OCS가 필요한가? | 얽힘 자체는 광자 간섭·측정·Fusion으로 구현 |
| 72×72의 의미는? | 72×72는 데이터센터용 OCS 개발 목표이다. |
| 유용한 FTQC를 위해 거대한 플랜트가 필요한가? | 현재 PsiQuantum이 선택한 대규모 분산 아키텍처에 해당 |
| 일부 부품이 아직 FTQC 목표 사양에 도달하지 못했나? | Pete가 명확하게 인정 |
| 약 1년 후 모든 FTQC가 완성된다 | 일부 부품의 사양 달성 전망이지 전체 시스템 완성 시점이 아님 |

- - PsiQuantum의 현재 광자 기반 양자컴퓨터는 24개 광원 칩을 사용하고 있으며, 48개 광원 칩은 Tape-out을 완료했다.

    - PsiQuantum은 SFWM(Spontaneous Four-Wave Mixing, 자발적 사광파 혼합)이라는 비선형 광학 현상을 이용한다.

      - 레이저의 펌프 광자 2개에 해당하는 에너지가 Signal Photon과 Idler Photon 한 쌍으로 전환될 수 있다.
      - 하지만 레이저 펄스를 쏠 때마다 반드시 광자 쌍이 생성되는 것은 아니다.
      - 이 과정은 양자역학적으로 확률적인 자발적 변환 과정이다.
    - 따라서 광자발생기는 매번 100%의 확률로 광자를 생성하지 않기 때문에 어느 광원 포트에서 광자가 나오던지, 성공한 광자를 Fusion 연산에 공급하거나 OCS로 보내기위해서 양자 컴퓨터 내부에 32포트 짜리 내부 멀티플렉서가 필요한 것이다.
    - 가령 단일 광원의 성공 확률이 10%라면, 독립적인 24개 광원 중 최소 하나가 성공할 확률은 약 92%다.
  - PsiQuantum은 개별 칩의 집적도를 극단적으로 높이는 대신, 많은 광학 칩을 제조하고 고속 광스위칭과 광섬유 네트워크를 이용해 연결하는 모듈형 확장 전략을 채택했다.
  - 이는 광자 발생과 Fusion 연산이 확률적으로 성공하기 때문에, 많은 병렬 자원을 투입해 전체 성공률을 높여야 한다는 광자 양자컴퓨팅의 특성에서 비롯된다.
  - 이 과정에서 높은 광자 검출 효율을 확보하기 위한 Cryostat과 대규모 냉각시설이 필요하다.

    - Cryostat 하나에 수백 개의 광학 칩을 넣는다.

      - IEEE Spectrum에서는 캐비넷 하나당 250개의 칩셋을 수용한다고 밝혔다.

        - <https://spectrum.ieee.org/fanless-liquid-cooled-ai-servers-coolit>
    - 하나의 건물에 수백 개의 진공 챔버를 설치한다.
    - 이들을 통신용 광섬유로 연결한다.
    - 수백만 개의 양자 소자가 하나의 코히런트 시스템으로 동작하도록 만든다.
    - 따라서 PsiQuantum이 목표로 하는 상업적 규모의 FTQC는 수백 개의 광학 칩을 포함한 Cryostat 수백 개를 광섬유로 연결하는 **건물 규모**의 시스템이다.
    - 광자 생성과 Fusion 연산의 확률적 실패를 극복하기 위해 막대한 병렬 하드웨어 자원이 필요하기 때문이다.

- - 현재 PsiQuantum은 핵심 광학 부품과 제조·패키징 기술에서 상당한 진전을 보였으나, 일부 부품은 여전히 목표 사양에 도달하지 못했고 대규모 논리 오류정정 및 완전한 FTQC 시스템의 실증도 남아 있다.
  - 필자 해석: PsiQuantum은 칩 단위의 무리한 집적을 피하는 대신, 병렬 하드웨어와 대규모 시스템 통합으로 광자 양자컴퓨팅의 확률적 한계를 극복하려 한다. 이는 기술적으로 일관된 전략이지만, 제조 가능한 광학 칩의 확보가 전체 양자컴퓨터의 경제성까지 보장하지는 않는다.
  - 결국 PsiQuantum의 상업적 경쟁력을 판단하려면 광원 수나 광스위치 포트 수보다, 건물 규모의 시스템에서 실제로 구현하는 논리 큐비트 수, 연산 처리량, 총설치비용과 운영비용을 확인해야 한다.

**✅** **주요 기술 용어 정리**

|  |  |  |
| --- | --- | --- |
| **용어** | **의미** | **PsiQuantum에서 중요한 이유** |
| BTO | 티탄산바륨(Barium Titanate), 전기광학 물질 | 짧고 빠르며 손실이 작은 위상 변조·스위칭 소자 |
| SiN | 질화규소(Silicon Nitride) | 저손실 온칩 광도파관 |
| PIC | Photonic Integrated Circuit | 광자 발생·필터·경로 제어·검출을 칩에 집적 |
| HOM | Hong–Ou–Mandel 간섭 | 광자의 구별불가능성과 광학 Fusion 성능 평가 |
| Fusion Gate | 광자 간섭·측정으로 얽힘 자원 상태를 연결하는 연산 | 광자 기반 FTQC 연산의 기본 메커니즘 |
| Multiplexing | 다수의 확률적 시도에서 성공 결과를 선택 | 유효 광자 공급률을 높여 확률적 실패를 보완 |
| Heralding | 측정을 통해 얽힘 성공 여부를 확인 | 실패한 링크를 감지하고 재시도·후속 제어 |
| Feed-forward | 앞선 측정 결과에 따라 다음 광경로·연산을 결정 | 나노초급 동적 광학 제어 |
| SNSPD | 초전도 나노와이어 단일 광자 검출기 | 높은 단일 광자 검출 효율 확보 |
| PNR | Photon Number Resolving | 광자 유무뿐 아니라 검출된 개수 구분 |
| Cryostat / Cryoplant | 극저온 챔버 / 대형 냉각 설비 | 초전도 검출기와 광학 모듈 운영 |
| Edge Coupling / FAU | 칩 끝단의 광섬유 결합 / Fiber Array Unit | 고밀도 광섬유 자동 정렬·저손실 패키징 |
| Tape-out | 칩 설계를 제조 단계로 넘기는 절차 | 설계 완료이지 작동 실증·상용화가 아님 |
| OCS | Optical Circuit Switching | 광경로 재구성; 데이터센터 OCS와 양자용 선택 스위치는 요구 사양이 다름 |

- - **중요한 구별:** GHz급 BTO 변조기 대역폭은 전체 32×32 또는 72×72 광스위치가 초당 수십억 번 완전한 경로 재설정을 수행한다는 뜻이 아니다.
