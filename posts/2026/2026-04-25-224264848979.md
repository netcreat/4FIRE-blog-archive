**✅ Abstract**

- - 양자 네트워크는 양자 인터넷의 핵심 기반이다.
  - 하지만 현재 구현들은 **스위칭 구조의 부재**로 인해 여전히 **고정된 point-to-point 연결**에 머물러 있다.
  - 우리는 Universal Quantum Switch (UQS)를 제안한다.
  - 이 장치는 **얽힘을 깨지 않으면서 동적으로 라우팅**할 수 있는 기반 기술로, 다음 기능을 제공한다:

    - 온디맨드(non-blocking) 라우팅
    - encoding 방식에 독립적인 정보 처리
    - 서로 다른 양자 시스템 간 **모달리티 변환 (interoperability)**
  - 우리는 **thin-film lithium niobate 기반 프로토타입**을 제작하여 다음 성능을 실험적으로 입증했다:

    - ≤ 4% decoherence 유지
    - 1 MHz 수준의 고속 스위칭
    - 이론적으로 최대 1 GHz 재구성 가능성
  - 이 결과는 **다중 노드 환경에서 동적 얽힘 분배를 처음으로 입증한 사례**이며, **이기종 양자 네트워크를 위한 확장 가능한 핵심 빌딩 블록**을 제시한다.
  - lithium niobate는 PPLN QFC에서 주로 사용되는 것으로 자세한 내용은 이전 포스트 참고바란다.

**✅ Introduction**

- - 양자 네트워크는 서로 떨어진 양자 시스템들을 연결하여 다음과 같은 응용을 가능하게 한다:

    - 분산 양자 컴퓨팅
    - 분산 양자 센싱
    - 양자 암호
  - 하지만 현재 시스템은 다음과 같은 한계를 가진다:

    - **문제 1 — 고정된 연결 구조**

      - 현재 네트워크는 **노드 간 고정된 point-to-point 링크**에 의존한다
      - 이 구조는:

        - 확장성 부족
        - 자원 활용 비효율
    - **문제 2 — 얽힘의 확률적 특성**

      - 얽힘은 확률적으로 생성되기 때문에:

        - 네트워크가 커질수록
        - 자원 요구량이 급격히 증가
    - **문제 3 — 스위칭 기술 부재**

      - 클래식 네트워크는 optical switching 기반
      - 하지만 **기존 스위치는 양자 상태를 깨뜨린다**
    - **문제 4 — 이기종 시스템 문제**

      - 서로 다른 양자 시스템은

        - polarization
        - time-bin
        - frequency
      - 서로 다른 encoding 사용
      - 이들을 연결하려면 **modality 변환이 필수**

- - 우리는 다음을 해결하기 위해 Universal Quantum Switch (UQS)를 제안한다
  - **기능**

    - 얽힘 유지하면서 라우팅
    - non-blocking 동작
    - encoding-agnostic 처리
    - 모달리티 변환 지원
  - **의미**

    - 기존 static network → dynamic network 전환
    - distributed quantum computing 가능
    - entanglement-as-a-service 구현 기반

**✅ Universal Quantum Switch Architecture**

**📌 전체 구조 (3단계)**

- - 논문은 스위치를 3개의 블록으로 나눈다:

    - (1) Input QSC → (2) Switch Matrix → (3) Output QSC

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjA0MjVfMTQ0/MDAxNzc3MTAwMzQxMzE2.4wTAic96XUiC_pDoUemzjbHOe5xZ-ChIcb0MgOrGiZ4g.8jGqw3fZRRLykOF22MDsCmRCVAabJbB5LssB6TSGxZ0g.PNG/image.png?type=w800)](#)

- - 입력된 양자 상태는 QSC(Quantum State Converter)를 통해 **path encoding으로 변환**된다.
  - 이렇게 변환된 상태는 **두 개의 동일한 photonic switch를 통해 라우팅**된다.
  - 이후 출력 단계에서 출력 QSC가 양자 정보를 **원하는 encoding 방식으로 다시 변환**한다.

**📌 Input QSC (Quantum State Converter)**

- - **역할**

    - 다양한 encoding을 하나의 공통 형식(path)으로 변환
  - **입력 예시**

    - polarization (H/V)
    - time-bin
    - frequency-bin
  - **출력**

    - **path encoding**
  - **왜 필요한가**

    - photonic switch는 **path 기반으로만 동작**
  - **핵심 의미**

    - “모든 양자 상태를 공통 언어로 번역”

**📌 Switch Matrix**

- - **구조**

    - MZI (Mach-Zehnder Interferometer) 기반
    - **non-blocking**
    - **all-to-all 연결 가능**
  - **특징**

    - classical optical switch와 유사하지만:
    - **quantum coherence 유지 필수**
    - **중요한 설계 포인트**

      - logical |0⟩ / |1⟩ → 서로 다른 switch로 라우팅
      - 두 경로는 **완전히 동일 (indistinguishable)** 해야 함
  - **핵심 의미**

    - “정보를 바꾸지 않고 위치만 바꾼다”

**📌 Output QSC**

- - **역할**

    - path encoding → 원하는 encoding으로 복원
  - **예**

    - path → polarization
    - path → time-bin
    - path → frequency
  - **특징**

    - modular (plug-in 가능)
    - 다양한 조합 지원
  - **핵심**

    - **heterogeneous 시스템 연결 가능**

****

**📌 Architecture의 핵심 개념**

- - **Encoding-Agnostic**

    - 어떤 encoding이든 동일하게 처리
  - **Non-blocking**

    - 동시에 여러 연결 가능
  - **Coherence Preservation**

    - 스위칭 중에도 얽힘 유지
  - **Reconfigurable**

    - 원하는 포트로 동적 연결

**✅ Implementation and Validation**

**📌 구현 (Implementation)**

- - **플랫폼**

    - **TFLN (Thin-Film Lithium Niobate)**
  - **이유**

    - 빠른 EO modulation
    - 낮은 loss
    - photonic integration 가능

**📌 장치 구조**

- - **QSC**

    - PRS (polarization rotator splitter)
    - polarization → path 변환
  - **Switch Matrix**

    - 2×2 MZI 기반
    - TO + EO modulators
  - **제어 방식**

|  |  |
| --- | --- |
| **방식** | **역할** |
| TO (thermal) | 느린 조정 (≤ kHz) |
| EO (electro-optic) | 빠른 switching (≤ GHz) |
| 상온 가능 | 극저온(4K 이하) 필 |

- - **핵심**

    - **dual-control 구조**

**✅** **연구 평가**

**📌 이 논문의 스위치 구조**

- - 하나의 중앙 스위치
  - 가능한 것:

    - A → B
    - A → C
    - B → D
  - 불가능한 것:

    - A → B → C (중간 경유)
    - multi-hop forwarding
    - routing table 기반 path 선택
  - 고전 네트워크에서의 **L2 switch에 가깝다.**

|  |  |  |
| --- | --- | --- |
| **개념** | **Classical** | **이 논문** |
| 구조 | L2 switch | Quantum switch |
| 연결 | MAC 기반 | path 기반 |
| 기능 | 포트 간 연결 | 얽힘 분배 |
| hop | single-hop | single-hop |

**📌 왜 multi-hop이 안 되나?**

- - **이유 ①: 측정 문제**

    - 중간 노드에서:

      - measurement → 얽힘 깨짐
  - **이유 ②: memory 없음**

    - 중간 노드에:

      - quantum memory 없음
      - buffer 없음
  - **이유 ③: coherence 유지 어려움**

    - 여러 hop 지나면:

      - decoherence 폭발

**📌 그럼 multi-hop은 어떻게 하나?**

- - **필요 기술**

    - quantum repeater

      - entanglement swapping

        - A와 C가 중간 노드인 B를 통해 얽힘을 생성할 경우 B가 각 노드와의 얽힘을 하고 나서 최종적으로 A-C의 원격 얽힘을 생성시킴.
      - quantum memory

        - entanglement 저장
        - timing 맞춤
        - synchronization
      - error correction

        - purification
        - QEC
      - Routing Protocol

        - 어떤 경로 선택?
        - 어떤 노드 사용?
        - resource allocation
  - 이 논문은:

    - repeater 아님
    - routing protocol 아님
    - 대신 **“switch fabric layer”**

****

**📌 제품화까지 얼마나 걸리나?**

- - 이 논문은 **칩 레벨 prototype (TRL 3~4 수준)**

    - 동작 증명 ✔️
    - 소형 PIC 구현 ✔️
    - coherence 유지 ✔️
  - 하지만:

    - 네트워크 장비 ❌
    - 시스템 통합 ❌
    - field deployment ❌
  - **핵심 병목**

    - insertion loss 증가
    - N 커지면 **신호 사라짐 (photon loss)**
    - entanglement 확률
    - RF / phase control
  - **현실적인 결론**

**✅ 맺음말**

- - 이번 논문이 제시하는 Universal Quantum Switch는 **얽힘을 생성하는 것이 아니라, 생성된 얽힘을 어떻게 분배하고 연결할 것인가**라는 문제에 대한 해답을 제시한다.
  - 이는 기존 양자 컴퓨팅 기업들이 주로 집중해온 QPU 중심의 접근과는 분명히 다른 방향이다.
  - 예를 들어 IonQ는 높은 충실도의 큐비트와 원격 얽힘을 기반으로 **분산 양자 컴퓨팅을 구현하는 데 초점을 맞추고 있으며**, 반대로 Cisco는 **그러한 시스템들을 연결하는 네트워크 레이어**를 구축하는 데 집중하고 있다.
  - 즉, 양자는 단순히 서로 다른 방향으로 발전하고 있는 것이 아니라, **하나의 전체 시스템을 구성하는 서로 다른 레이어에서 진화하고 있다고 보는 것이 더 정확하다.**
  - 다만 아직까지는 이 두 기술 모두 완전한 양자 네트워크로 이어지기에는 부족한 요소들이 남아 있다. 특히 multi-hop 네트워크를 위해 필요한 **quantum memory, repeater, routing protocol**과 같은 핵심 기술들은 여전히 연구 단계에 머물러 있으며, 실제 상용화까지는 상당한 시간이 필요할 것으로 보인다.
  - 결국 이 논문은 완성된 양자 인터넷을 보여주는 것이 아니라, 그 구조를 이루는 중요한 퍼즐 중 하나를 제시한 것에 가깝다. 그리고 그 퍼즐은 IonQ와 같은 컴퓨팅 중심 기술과 만나게 될 때, 비로소 의미를 갖게 될 것이다.
