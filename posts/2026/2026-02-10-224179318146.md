**✅ 1. 양자 중계기 관련 성과**

**📌 양자 중계기 쪽 진전이 왜 중요하나?**

- - 광섬유에서는 광자가 멀리 갈수록 손실된다.
  - 하지만, 고전 네트워크와 달리 양자 상태는 복사 증폭이 안 되기 때문에 중간 증폭기가 통하지 않는다.
  - 그래서 필요한 게:

    - **구간을 나누고 → 각 구간에서 얽힘 생성 → 마지막에 이어 붙이기**
  - 문제는? **이어 붙이는 동안 얽힘이 죽어버림.**

****

**📌** **이번에 쓴 해결책**

- - **연구진은 세 가지를 동시에 개선했다.**

    - **장수명 이온트 메모리**

      - **칼슘 기반의 이온트랩을 사용**
      - **QFC를 이용하여 393nm의 파장을 1550nm인 C-Band로 변환하였음.**
    - **이온 ↔ 광자 변환 효율 향상**
    - **고정밀 entanglement 연결 프로토콜**
  - **이 조합으로**

    - 얽힘 수명 ≥ 네트워크 연결에 필요한 시간을 처음으로 만족시켰다는 주장이다.
    - **그래서 “확장 가능한 repeater building block”이라고 표현한다.**
  - **이건 앞으로:**

    - **도시 간**
    - **국가 간**
    - **위성 링크**
  - 모두로 확장 가능한 구조라는 뜻이라는 점에 의미가 큰 연구 실적이다.

**📌 IonQ(Lightsynq)의 기술과 무엇이 다른가?**

- - IonQ는 2025년에 양자 메모리·광자 상호연결 스타트업 Lightsynq Technologies를 인수했다.
  - 이 회사의 핵심은 양자 메모리 + 광자 인터커넥트 기술로, 양자 메모리 기능을 기존 IonQ의 트랩드 이온 시스템에 통합해 확장성과 내결함성을 확보하려는 목적이다.
  - IonQ는 이 인수 기술이 양자 시스템의 연결 속도 및 안정성을 크게 향상(“50배” 같은 표현) 시켰다고 발표했다

    - 이는 네트워크 상에서 메모리·재전송 기능이 강화됨을 의미한다.
  - 하지만 이 개선 수치는 업계 비교 지표라기보다 IonQ 내부 평가/마케팅 측면이 강하며, 각 기술의 측정 기준(속도, 응답, 유지시간, 오류율 등)이 뚜렷하게 공개된 학술적 수치는 아니다.
  - IonQ는 포토닉 양자 인터커텍트 플랫폼을 발표

    - 다수의 양자 메모리 와 광자 인터페이스 를 일관되게 결합한 확장성 있는 칩 기반 플랫폼을 개발
    - A scalable photonic quantum interconnect platform

      - 다수의 양자 메모리(실제로는 고체 상태 시뮬레이션을 위한 다중 컬러 결함) 와 포토닉 회로를 통합한 인터커넥트 플랫폼을 다룬다.
      - Diamond 기반 색심 시스템 에서 photons 와 quantum memories 간의 강한 coupling (Cooperativities ~100) 을 구현한다.
    - 이 논문의 목표는 “모듈식 · 대량 생산 가능한 포토닉 양자 메모리 연결” 이다.

**📌 Lightsynq와의 기술 비교**

|  |  |  |
| --- | --- | --- |
| **기술/논문** | **USTC 장거리 얽힘 논문** | **IonQ 라이트싱크/포토닉 칩셋** |
| 목표 | 장거리 얽힘 유지·분배 (양자 리피터 핵심 요건) | 양자 메모리 & 인터커넥트 통합 |
| 거리/스케일 | km급 실험 중심 | 칩·인터커넥트 중심 |
| 핵심 혁신 | 얽힘 유지 시간 > 생성 시간 → 리피터 요건 충족 가능성 | 포토닉-메모리 인터페이스 · 모듈식 생산성 |
| 플랫폼 | 구체 실험 성과 | 제작 수준 플랫폼 진전 (아직 프로토타입) |
| 영역 | 실험 물리 · 통신 | 시스템/집적 + 제품화 지향 |

> ***USTC의 논문*** *은 ‘장거리 얽힘 분배의 지속성·보존’이라는 물리적 현상 중심의 진전인데 반해,*
>
> ***IonQ의 LightSync + 포토닉 칩셋*** *은 공학적으로 통합된 포토닉-메모리 시스템 설계다.*
>
> *즉, 둘은* ***서로 다른 축에서의 발전****으로,*
>
> *USTC 쪽은* ***양자 네트워크 물리 레벨에서 기본 요건 달성에 가까운 성과***
>
> *IonQ 쪽은* ***양자 메모리·인터커넥트 기술을 실용 제품으로 연결하려는 공학적 접근으로 해석된다.***
>
> ***하지만, 개인적인 견해로는, 물리학적 성과보다 공학적 완성도를 높이는 것이 더 우선되어야 한다고 생각함***

[**Long-lived remote ion-ion entanglement for scalable quantum repeaters**](https://www.nature.com/articles/s41586-026-10177-4)

**✅ 연구 내용 분석**

**📌 내용 요약**

- - 서로 떨어진 **두 개의 이온 메모리 사이에서 안정적인 양자 얽힘(entanglement)** 을 생성하고 유지하는 데 성공했다.
  - 얽힘이 생성되는 속도보다 **얽힘이 유지되는 시간이 더 길어져**, 진정한 의미의 **양자 리피터(quantum repeater)** 접속이 가능한 수준을 달성했다.
  - **10 km의 광섬유를 이용하여 실험 검증**
  - **101km의 광섬유에서 positive key rate 획득**

    - **10km 실험에서 얻은 얽힘 fidelity, 검출 효율, 노이즈, 에러율을 기반으로 낙관적인 최대 거리 101km 도출**
    - **positive key rate란 보안이 충분히 가능하다는 것을 의미함.**

      - **참고로, negative면 도청 확율이 더 높음**
  - **이상의 거리**에서도 얽힘 유지가 가능하며, 장거리 양자 키 분배(DI-QKD) 증명도 함께 포함된다.
  - 이 연구는 **“양자 네트워크/양자 리피터” 구축이라는 큰 그림**에서 매우 중요한 성과를 보여준다.

**📌 이 실험에서 사용한 원자**

- - 사용한 큐비트는:

    - **Calcium 이온 (****40****Ca****+****)**
  - 이온 트랩 분야에서 가장 오래 쓰인 표준 중 하나.

**📌 왜 칼슘을 쓰냐?**

- - 레이저 접근성이 좋고, 에너지 준위 구조가 깔끔하고, 광자 방출을 다루기 좋기 때문.
  - 연구용으로 바륨이나 이테륨보다 적합하여, Oxford Ionics의 크리스 발란스 역시 초기 연구는 칼슘으로 진행하였다.

**📌 왜 이온트랩이야?**

- - 이온트랩은 느리긴 하지만 신뢰도가 높다.
  - 이번 연구에서는

    - Long Memory
    - Real fiber
    - 반복 동작
    - 키 생성
    - 등을 보여줘야 하므로 이온트랩을 사용한 것으로 생각됨.

**📌 그럼 IonQ도 이온트랩 분야의 선도 기업인데 왜 전혀 다른 NV 센터를 이용해?**

- - IonQ의 추구하는 방향은

    - 실제 도시망
    - 기존 광섬유 사용
    - 지속적으로 얽힘 공급
    - 모듈형 노드
    - 향후 여러 홉 연결
  - **즉, 실전 투입이 가능한지가 최우선이다. - 운영 가능성**

****

**📌 양자 메모리 비교**

|  |  |  |
| --- | --- | --- |
|  | **NV** | **이온** |
| coherence | ms ~ s | s 이상 |
| gate fidelity | 높음 | 매우 높음 |
| 안정성 | 환경 영향 받음 | 매우 깨끗 |
| 반복 운용 | 도전적 | 강함 |
| **한줄 요약** | **연결을 잘한다.** | **기억을 잘한다.** |

- - **이온은 기본적으로 다음의 이유로 통신 친화적이지 않다.**

    - 큰 진공 장치
    - 복잡한 레이저
    - 광자 수집 효율 낮음
    - 짧은 파장 (손실 큼)
  - **광자를 멀리 보내려면,**

    - 밝아야 하고
    - 방향성이 좋아야 하고
    - 광섬유에 잘 들어가야 하고
    - 안정적으로 반복되어야 한다.
    - **→** 이게 NV가 상대적으로 유리한 영역.
  - **NV가 네트워크에서 강한 이유**

    - NV는 고체라서

      - 칩 형태 가능
      - 포토닉 구조 집적 가능
      - cavity 붙이기 좋음
      - fiber coupling 쉬움
      - 소형화 가능

**✅ 양쪽의 철학 및 기술의 차이**

**📌 LightSynq**

- - 조금 덜 완벽하더라도 더 자주, 지속적으로 원격 얽힘을 공급함
  - 양자 네트워크의 상용화를 위해서

    - 높은 성공률
    - 빠른 반복
    - 자동화
    - 유지 가능성
  - 이 필요함
  - → 네트워크 운용에 초점. 더 나아가 ESP(Entanglement Service Provider)를 지향한다.

****

**📌 USTC**

- - 성공횟수가 많을 필요 없음
  - 대신 fidelity가 매우 높아야 함
  - → 물리적으로 가장 강한 보안 증명에 초점을 맞추고 "적게 성공해도 좋으니 한번을 완벽하게 성공하자"가 중심임

****

| --- | --- | --- |
|  | **USTC** | **LightSynq** |
| 목적 | 증명 | 운용 |
| 성공률 | 낮아도 됨 | 높아야 함 |
| 중요 | fidelity | rate |
| 전략 | 기다림 | 증폭 |
