**✅ RFI 요약**

**📌 목적 (What DARPA wants)**

- - DARPA는 **우주에서 높은 전력(power)을 제공할 수 있는 위성 플랫폼**에 대한 정보를 수집하고 있다.
  - 특히 관심 분야:

    - **LEO / MEO / GEO / Cislunar orbit**에서
    - 높은 전력(OAP, Orbital Average Power)을 탑재체(payload)에 공급할 수 있는 위성
  - 이 전력은 주로 다음 같은 용도를 염두에 두고 있다.

    - **Space Data Centers**
    - 고성능 컴퓨팅
    - 고전력 센서
    - 고성능 통신

> *우주에서 대형 컴퓨팅이나 데이터 인프라를 돌릴 수 있는 위성 플랫폼을 찾고 있는 것이다.*

**📌 DARPA가 기업들에게 묻는 핵심 질문**

- - **위성 생산 능력**

    - 기업이 **2025~2030 사이에 생산할 위성 수**
    - 각 궤도별로 질문:

|  |  |
| --- | --- |
| **Orbit** | **요구 전력** |
| LEO | >3kW / >10kW |
| MEO | >5kW / >20kW |
| GEO |
| Cislunar |

- - - 기업은 다음을 제출해야 한다.

      - 연도별 launch 계획
      - 분기별 생산 속도
      - 위성 bus 기술 성숙도
      - **TRL (Technology Readiness Level)**
      - **MRL (Manufacturing Readiness Level)**
      - 생산 관련 리스크
      - 비용
      - 기술
      - 일정
  - **열 관리 (Thermal Control)**

    - 고전력 위성에서 가장 큰 문제는 **열 관리**다.
    - DARPA는 다음을 묻는다.

      - payload cooling 방법
      - thermal control 시스템 설계 경험
      - TRL / MRL
    - 그리고 특히 **신기술**에 관심이 있다.
    - 예:

      - Variable emissivity surfaces
      - (thermochromic / electrochromic)
      - On-die cooling
      - Embedded cooling
      - Rollout / inflatable radiators
    - 즉 **고전력 위성에서 열을 어떻게 버릴 것인가**

****

**📌 중요한 의미**

- - 이 RFI가 시사하는 것:
  - **DARPA가 보는 미래**

    - DARPA는 다음을 준비 중이다.
    - **High-Power Space Infrastructure**
    - 특히:

      - Space Data Centers
      - Orbital compute
      - AI in space
      - ISR processing in orbit
    - 이를 위해 필요한 것이 바로
    - **High power satellites**

****

**📌 핵심 한줄 정리**

- - **DARPA는 우주에서 고전력 컴퓨팅·데이터 인프라를 운영할 수 있는 차세대 위성 플랫폼을 찾기 위해 산업계의 생산 능력과 기술 수준을 조사하는 RFI를 발표했다.**

---

**✅ DARPA가 우주 위성에서 “전력(Power)”을 중요하게 보는 이유**

**📌 우주 시스템에서 전력이 중요한 이유**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMTZfMTcg/MDAxNzczNjQyMDc0ODI1.3FzlW2uKuwHbGAA-tLE1pS6YfmF07U3IQhLzlvIK5_Ig.sW4udyJyt4v9Y_xlnbTzG-Us54Wsp51ek__PANsGHPcg.PNG/image.png?type=w800)](#)

- - 결론부터 말하면 **DARPA에서 전력은 핵심적인 요소 중 하나다.**
  - 이유는 단순하다.
  - **우주에서 대부분의 고성능 시스템은 결국 전력에 의해 제한되기 때문이다.**
  - 위성에서 구현할 수 있는 능력은 사실상 **전력 규모에 의해 결정된다.**

|  |  |  |
| --- | --- | --- |
| **시스템** | **필요한 것** | **전력 영향** |
| SAR 레이더 | 고출력 RF | 전력 ↑ → 해상도 ↑ |
| 레이저 통신 | Optical power | 전력 ↑ → 거리 ↑ |
| 전자전 / SIGINT | 고속 신호 처리 | 전력 ↑ → 처리량 ↑ |
| AI 분석 | GPU / FPGA | 전력 ↑ → 실시간 분석 |
| 데이터센터 | HPC | 전력 ↑ → 연산 가능 |

- - **전력 = 위성 capability**

****

**📌 DARPA RFI가 요구하는 전력 수준**

- - DARPA가 발표한 RFI에서는 단순한 위성이 아니라 **고전력 payload 위성**을 찾고 있다.
  - 특히 DARPA 문서에서 직접 언급된 예시가 있다.

    - **Space Data Centers**
  - 이것이 의미하는 것은 다음과 같다.

    - 궤도에서 AI 연산
    - ISR 데이터 실시간 분석
    - 위성 간 데이터 처리
    - 군사용 edge computing

**📌 현재 위성 전력 수준**

- - 현재 대부분의 위성 전력은 다음 수준이다.

|  |  |
| --- | --- |
| **위성** | **전력** |
| CubeSat | 10~100 W |
| 일반 LEO 위성 | 1~3 kW |
| Starlink | ~2~3 kW |
| GEO 통신 위성 | 10~20 kW |

- - DARPA가 묻는 수준은 **>20 kW payload power**
  - 이는 사실상 **우주 데이터센터급 전력**이다.

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMTZfMjMg/MDAxNzczNjQyMTMwMjQ1.Wc2HqdcIvNzSoxmG02-hYAe9aINNjpjpKHNBSZ7fD4Ag.7h2QyFbdd3rrEeHUHDZDZ0wHu8tQ5W6ZmBRhS7lUjAog.PNG/image.png?type=w800)](#)

**📌 기존 위성 전력 공급 방식**

- - 기존 위성은 대부분 **태양광 + 배터리 구조**를 사용한다.
  - 기본 구조는 다음과 같다.

|  |
| --- |
| 태양  ↓  Solar Panel  ↓  Power Control Unit  ↓  Satellite systems  ↓  Battery |

- - 즉

    - 태양이 있을 때 → 태양광 패널 발전
    - 지구 그림자 → 배터리 사용
  - **태양광 전력 밀도의 한계**

    - 우주에서 태양광 플럭스는 약 **1360 W/m****2**
    - 태양전지 효율 약 30%를 적용하면 **약 400 W/m****2**
    - 따라서
    - **20 kW 전력을 생산하려면** 약 **50 m****2** **이상의 태양광 패널**이 필요하다.
    - 이는 다음 문제를 만든다.

      - 구조 복잡
      - 질량 증가
      - 열 관리 문제

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjAzMTZfNDAg/MDAxNzczNjQyMjE4NDIy.O6J6BLQzVULxB6c_YcxMmGYy_LAnDc006DXAce17V5Ag.sX7YTZkkflLmEPEJjma_BicdCPIPql7crsthEanfhXYg.PNG/image.png?type=w800)](#)

**📌 우주에서 더 어려운 문제: 열 관리**

- - 우주에서 전력보다 더 어려운 문제는 열(thermal)이다.
  - 전력 사용 → 열 발생
  - 하지만 우주에서는

    - 공기 없음
    - 대류 없음
  - 따라서 열은 오직 **radiator (복사)** 로만 방출할 수 있다.
  - DARPA RFI에서 thermal control 관련 질문이 많은 이유가 바로 이것이다.
  - 예:

    - variable emissivity surfaces
    - rollout radiators
    - on-die cooling
    - embedded cooling

**📌 DARPA가 구상하는 미래 우주 구조**

- - DARPA가 바라보는 미래 구조는 다음과 같다.

|  |
| --- |
| Sensor satellites  ↓  Optical inter-satellite links  ↓  Orbital compute node (AI / HPC)  ↓  Processed intelligence  ↓  Ground networks |

- - 즉

    - **센서 → 우주 데이터센터 → 결과 전송** 구조다.

**📌 DARPA가 전력 기준을 두 단계로 나누는 이유**

- - DARPA는 전력 기준을 두 개로 나눠 질문한다.
  - 이것은 산업 capability를 구분하기 위한 것이다.
  - **현재 위성 (Current generation)**

    - **3~10 kW**
    - 예

      - EO 위성
      - 통신 위성
      - ISR 센서
  - **차세대 위성 (Next generation)**

    - **10~20 kW 이상**
    - 가능한 용도

      - Space data center
      - onboard AI computing
      - high power radar
      - electronic warfare
      - optical communication hubs
  - DARPA는 이를 통해 산업을 다음과 같이 분류하려 한다.

|  |  |
| --- | --- |
| **Capability** | **의미** |
| >3 kW | 대부분 기업 가능 |
| >10 kW | 일부 기업 |
| >20 kW | 극소수 |

- - 즉 **누가 진짜 high-power satellite bus를 만들 수 있는지 파악하려는 것**이다.

**📌 핵심 결론**

- - **DARPA에게 전력은 단순한 기술 요소가 아니라 “우주에서 어떤 군사 능력을 구현할 수 있는가”를 결정하는 핵심 병목이다.**
  - 특히 **AI / ISR / space computing** 시대가 오면서 그 중요성이 더욱 커지고 있다.

**✅ 투자 관점 핵심******

- - DARPA가 찾는 것은 **High-Power Space Infrastructure**

    - 즉 **우주 데이터센터 + 우주 컴퓨팅 + ISR processing** 이다.
  - 이 분야는 향후

    - 군사
    - AI
    - 우주 네트워크
  - 세 영역이 동시에 성장할 가능성이 높다.
