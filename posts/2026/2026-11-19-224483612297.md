# IonQ의 국제 양자보안망 전략

Published: 2026-11-19T18:54:37+11:00

Original Naver post: https://blog.naver.com/4-fire/224483612297?fromRss=true&trackingCode=rss

---

**✅ QKD–PQC 연결과 Q-KMS의 진짜 경쟁력**

- - **2026년 11월 19일, SK브로드밴드는 부산–싱가포르 SJC2 해저케이블을 활용한 국제 양자보안 시험망 구축 계획을 발표했다.** 국내와 싱가포르 현지에서는 QKD(양자키분배), 장거리 해저케이블에서는 PQC(양자내성암호)를 활용해 하나의 보안 네트워크로 연동하는 구상이다.
  - 아이온큐(IonQ)가 NIA 및 SK브로드밴드와 함께 싱가포르를 방문해 기술 협의에 참여했다는 점이 눈에 띈다. 다만 **SK브로드밴드의 사업 수행기관 선정과 아이온큐의 신규 장비 공급 계약 확정은 서로 다른 사실**이다.
  - 이번 사안을 기술적으로 이해하기 위한 핵심 질문은 두 가지다. **서로 다른 QKD·PQC 보안 구간을 어떻게 연결하는가?** 그리고 **그 연결을 담당하는 Q-KMS 시장에서 아이온큐 자회사 ID Quantique(IDQ)는 어떤 경쟁력을 갖고 있는가?**

**✅ 1. 한국–싱가포르 국제 시험망에서 확인된 내용**

- - 과학기술정보통신부와 한국지능정보사회진흥원(NIA)의 「개방형 양자 테스트베드 고도화·확산」 사업에서 SK브로드밴드가 해외 거점 수행기관으로 참여한다.
  - SK브로드밴드·NIA·아이온큐 관계자들이 싱가포르를 방문해 IMDA(싱가포르 정보통신미디어개발청), Singtel과 시험망 구성, 암호키 연동 방식, 역할 분담을 협의했다.
  - 공식 발표는 **2027년 시험망 개방을 위한 추진 일정**을 언급한다. 따라서 현재 성과는 완성된 상용 서비스가 아니라 구축을 위한 협의와 실증 계획이다.

**✅ 2. QKD → PQC → QKD, 실제로는 무엇을 넘겨주는가?**

**📌 QKD는 데이터를 보내는 기술이 아니라 암호키를 분배하는 기술**

- - QKD는 광자 등 양자적 특성을 활용해 양쪽 장비에 공유 비밀키를 생성·분배하는 방식이다. 실제 사용자 데이터는 AES 등의 대칭키 암호화와 기존 IP·광전송망을 이용할 수 있다.
  - PQC는 양자컴퓨터 공격에도 견디도록 설계된 수학적 암호 알고리즘을 의미한다. 예를 들어 PQC 기반 키 설정(KEM)을 통해 장거리 구간에서 사용할 공유 비밀을 수립할 수 있다.
  - **따라서 “한국 QKD 키가 싱가포르로 가는 도중 PQC 키로 물리적으로 변환된다”는 설명은 정확하지 않다.** Q-KMS가 각 구간에서 확보한 키 자료를 관리하거나 보호된 경로로 전달하도록 설계하는 것이다.

|  |  |  |  |
| --- | --- | --- | --- |
| **구간** | **키 수립·분배 방식** | **사용자 데이터 경로** | **중요 제약** |
| 한국 국내망 | QKD로 인접 노드 간 키 확보 | 기존 전송망에서 암호화 데이터 전달 | 광손실, 전용 링크, 중계 노드 신뢰 |
| 부산 ↔ 싱가포르 | PQC를 이용한 키 설정 또는 보호된 키 전달 | SJC2 해저케이블 상의 기존 통신 | PQC 가정, 게이트웨이 신뢰 |
| 싱가포르 현지망 | 현지 QKD 네트워크에서 키 확보 | 기존 전송망에서 암호화 데이터 전달 | KMS·암호화 장비 연동과 키 정책 |

**📌 구현 시나리오 A — 구간별 복호화·재암호화**

- - 한국의 보안 게이트웨이가 QKD로 확보한 키를 이용해 암호화한 데이터를 전달하고, 경계 지점에서 복호화한 뒤 PQC 기반으로 설정한 새로운 키로 다시 암호화할 수 있다.
  - 싱가포르 도착 후에는 현지 보안 게이트웨이가 해당 데이터를 다시 처리하고 현지 QKD 기반 키로 보호하는 구조가 가능하다.
  - **이 방식은 경계 게이트웨이가 평문을 다룰 수 있으므로 신뢰할 수 있는 장비와 운영 환경이 필수**다. 이는 가능한 설계 예시일 뿐, 이번 시험망의 최종 설계가 확정됐다는 뜻은 아니다.

**📌 구현 시나리오 B — 암호키를 안전하게 중계·결합**

- - 다른 방식은 사용자 데이터를 각 경계에서 반드시 복호화하는 대신, Q-KMS가 키 자료를 보호된 채널로 중계하거나 QKD와 PQC로 확보한 공유 비밀을 결합해 암호화 장비에 제공하는 것이다.
  - 이 경우 데이터와 키는 별도 경로·별도 수명주기로 관리될 수 있다. 애플리케이션의 종단 간 암호화를 유지하는 구성도 기술적으로 가능하다.
  - **QKD 구간과 PQC 구간을 이어 붙였다고 전체 국제 경로가 QKD 특유의 정보이론적 보안 보장을 갖는 것은 아니다.** 장거리 경로에서는 PQC, 키 관리 장치, 중계 노드의 신뢰성이 전체 보안 수준을 결정한다.
  - 공식 발표에서는 ETSI 표준 기반 키 연동을 논의했다고 밝혔지만, 시나리오 A·B 중 어느 방식을 채택했는지, 또는 두 방식을 병행하는지는 공개하지 않았다.

> *ID Quantique의* ***Clarion KX가 바로 QKD와 PQC를 통합 관리하도록 설계된 플랫폼****이다.*

**✅ 3. 네트워크 엔지니어 관점: Q-KMS가 실질적인 핵심이다**

- - 일반 네트워크에 비유하면, QKD 링크는 키를 확보하는 물리적 기반이고 **Q-KMS(Quantum Key Management System)는 그 키를 필요한 암호화 지점에 공급하는 제어·키 분배 계층**에 가깝다.
  - QKMS는 IonQ가 2026년 4월 World Quantum Day 전후에 QKD·PQC와 Cloud Virtual Quantum Key Management를 하나의 보안 전략으로 제시한 바 있다.

**📌 ETSI GS QKD 014와 020은 무슨 역할인가?**

- - **ETSI GS QKD 014**

    - 보안 애플리케이션·암호화 장비(SAE)가 키 관리 장치(KME)에 암호키를 요청해 제공받는 REST 기반 인터페이스를 정의한다.
  - **ETSI GS QKD 020**

    - 서로 다른 KMS/KME가 키를 교환·연동할 수 있도록 하는 상호운용 인터페이스를 정의한다. 2026년 6월판이 공개됐다.
  - 쉽게 말해 014는 **암호화 장비 ↔ KMS**, 020은 **KMS ↔ KMS**를 연결하는 표준에 해당한다. 다만 표준 지원만으로 실제 국가 간 연동 성능과 보안이 자동 보장되는 것은 아니다.

**✅ 4. 아이온큐 자회사 ID Quantique의 강점은 무엇인가?**

**📌 기존 고객망에서 검증된 Clarion KX**

- - 아이온큐는 2025년 ID Quantique의 지배지분 인수를 완료했다. 따라서 IDQ가 보유한 QKD 장비, 키 관리 플랫폼, 통신사업자 설치 기반을 아이온큐의 양자보안 사업에 연결할 수 있게 됐다.
  - **Clarion KX**는 QKD·PQC 기반 하이브리드 키 교환을 지원하며, 서로 다른 QKD 장비 및 암호화 인프라를 연동하는 키 관리 소프트웨어 플랫폼이다.
  - **Clavis XG**는 QKD 장비 제품군, **Solteris**는 별도 배치가 가능한 키 관리 어플라이언스이며, 실제 배치 방식에 따라 Clarion KX를 구성할 수 있다.

|  |  |  |
| --- | --- | --- |
| **IDQ 기술·제품** | **주요 기능** | **국제망에서의 가능 역할** |
| Clavis XG | 광섬유 기반 QKD 키 확보 | 한국·싱가포르 현지 QKD 구간 |
| Clarion KX | 키 동기화·키 버퍼·키 요청·QKD/PQC 통합·상호운용 | 이종 KMS와 암호화 장비 사이의 키 관리 계층 |
| Solteris | QRNG 및 하이브리드 키 관리용 독립형 Appliance | QKD가 없는 구간 또는 독립 KMS 배치 |
| QMS / SDN 연동 | 모니터링·정책·키 공급 경로 관리 | 사업자 NOC·서비스 운영 |

- - 여기서 가장 중요한 차이는 **“제품이 이런 기능을 제공한다”**와 **“이번 국제 시험망에 이 제품이 채택됐다”**를 구분해야 한다는 것이다. 후자는 아직 공식 자료로 확인되지 않았다.

**📌 한국에서 이미 구축한 800km 정부 QKD망의 의미**

- - IDQ 공식 구축 사례에 따르면 SK브로드밴드와 IDQ는 한국의 48개 정부기관을 연결하는 약 800km 규모의 QKD 기반 네트워크를 구축했다.
  - 공개된 구성에는 **27개 QKD 링크, 10개 Trusted Relay, 3개 분리된 Q-KMS 인스턴스**가 포함됐다. 16개 암호화 종단을 통해 127개 보안 연결이 가능한 구조도 제시했다.
  - 여러 고객·사업자가 공유 기반시설을 이용하면서 키 정책을 분리하고, 키를 버퍼링하거나 장애 시 재경로화하는 운영 경험이 축적됐다는 뜻이다.
  - 이는 단일 실험실 장비 성능보다 통신사업자 관점에서 중요한 설치 기반(Installed Base)·NOC 연동·운영 검증의 근거가 된다.

**📌 싱가포르와 제네바–서울에도 연결고리가 있다**

- - Singtel은 2023년 11월 IDQ와 협력해 싱가포르의 기업용 국가 양자안전망(NQSN+) 개발을 발표했다. 한국과 싱가포르 양쪽에 기존 협력 이력이 있다는 점은 이번 실증에서 유리한 출발점이 될 수 있다.
  - 아이온큐는 2026년 10월 제네바 지역의 QKD와 제네바–서울 PQC 기반 VPN을 결합해 자사 4개 사업장을 보호하는 하이브리드 보안망이 운영 중이라고 밝혔다.
  - 또한 SK텔레콤은 2024년 자체 PQC 기술을 IDQ의 Clavis XG·Solteris에 적용하는 하이브리드 제품 개발을 발표했다. 한국 사업 파트너와 기술을 조합한 이력이 존재하는 것이다.
  - **그러나 기존 협력 이력은 신규 국제 사업 수주에 대한 확정 증거가 아니다.**

**✅ 5. 경쟁사와 비교하면: IDQ가 독점하는 기술은 아니다**

**📌 Toshiba QSN/Q-KMS는 가장 직접적인 경쟁 제품**

- - Toshiba는 2026년 3월 **서로 떨어진 QKD망을 PQC 브리지로 연결**하는 기술을 발표했다. 10월에는 이를 포함한 QSN(Quantum-Safe Networking) 플랫폼과 x86 서버에서 구동하는 독립형 Q-KMS를 공개했다.
  - Toshiba도 QKD·PQC·하이브리드 키 제공, 키 라우팅, 다중 경로, 키 재고 관리 및 표준 연동을 제품 경쟁력으로 강조한다.
  - 따라서 “QKD → PQC → QKD를 구현할 수 있다”거나 “다중 벤더 QKD를 연동할 수 있다”는 사실만으로 IDQ가 기술적으로 유일하다고 주장할 수 없다.

**📌 무엇을 비교해야 실제 경쟁력이 드러나는가?**

- - 첫째, **키 공급 성능:** 초당 공급 가능한 키량, 키 생성·소비 속도 차이, 버퍼 고갈 시 복구 방식이다.
  - 둘째, **서비스 안정성:** QKD 광회선 장애 시 경로 전환 시간, KMS 이중화, 다중 사이트 동기화, 장애 도메인 분리다.
  - 셋째, **상호운용:** ETSI 014·020과 암호화 장비 API의 실제 호환성, 타사 QKD·KMS 연동 결과다.
  - 넷째, **보안·운영:** 키 폐기·회전, 감사 추적, 고객별 격리, HSM 활용, 규제 인증, NOC 운영 자동화와 SLA다.
  - 다섯째, **경제성:** 사이트당 장비 비용, 소프트웨어 구독료, 관리 인력과 전용 광섬유 비용, 기존 장비 교체 필요성이다.
  - 공개된 공식 자료만으로는 IDQ와 Toshiba 사이의 동일 조건 독립 벤치마크를 확인하기 어렵다. **정량적 우열을 단정하지 않는 것이 타당**하다.

**✅ 6. ETSI 표준화는 IDQ에 유리할까, 불리할까?**

- - **유리한 점:** 여러 공급사 QKD와 기존 IPsec·MACsec 장비를 연결할 수 있다면, IDQ의 Clarion KX를 통신사업자·국가기관의 통합 플랫폼으로 공급할 기회가 확대될 수 있다.
  - **불리한 점:** 인터페이스가 표준화될수록 고객은 한 제조사의 QKD 장비나 KMS에 영구적으로 종속되지 않을 수 있다. Toshiba 같은 경쟁사의 플랫폼으로 교체하거나 다중 공급사로 운영할 수 있기 때문이다.
  - 따라서 장기적인 진입장벽은 표준 지원 여부 자체보다 **검증된 운영 성능, 설치 기반, 사업자 고객 관계, 고객별 SLA, 전환 비용**에서 형성될 가능성이 높다.
  - 네트워크 업계로 비유하면 “BGP를 지원한다”는 사실보다, 실제 대규모 통신망에서 장애 없이 운영되는 라우터·운영 도구·지원 체계가 중요하다는 것과 비슷하다.

**✅ 7. 아이온큐의 보안 사업 전체와 연결하면?**

- - 아이온큐는 2026년 7월 SkyWater 인수를 완료했고, 11월에는 Elisity 인수를 완료했다. 이는 QKD·PQC 외에 반도체 제조 역량과 Zero Trust 네트워크 보안 소프트웨어를 확보했다는 뜻이다.
  - 잠재적인 통합 모델은 **Elisity의 장치·사용자·업무별 접근 정책 → IDQ의 QKD/PQC 키 공급 → IPsec·MACsec 등의 통신 암호화 → SkyWater를 활용한 보안 반도체**로 확장하는 것이다.
  - 이때 SkyWater가 암호 가속기나 HSM 관련 부품을 생산한다면 제조·공급망 통제에 장점이 생길 수 있다. 하지만 **직접 제조한 HSM이 있어야만 이러한 서비스가 가능하다는 뜻은 아니다.** 이미 외부 HSM 및 네트워크 암호화 장비와 연동하는 방식도 가능하다.
  - 이번 한국–싱가포르 시험망에 Elisity나 SkyWater가 참여한다는 공식 발표는 확인되지 않았다. 따라서 통합 보안 사업은 **가능한 장기 전략 시나리오**이지 이번 계약의 확정 범위가 아니다.

**✅ 결론: 양자보안의 승부처는 키를 만드는 장비를 넘어 KMS가 될 수 있다**

- - 한국–싱가포르 시험망의 중요한 기술적 의미는 수천 km 해저케이블에 QKD를 직접 설치한다는 것이 아니다. **국내 QKD망과 국제 PQC망, 싱가포르 QKD망을 하나의 키 관리 체계로 연결하려 한다는 것**이다.
  - Q-KMS는 암호키의 생성 원천·분배·저장·재경로화·장비 연동을 담당한다. 즉, 양자보안 서비스의 실제 운영 난도를 결정하는 중심 계층 중 하나다.
  - IDQ는 SK브로드밴드 국내 구축망, Singtel 협력, 자체 QKD·PQC 하이브리드 기술 등에서 유의미한 기반을 갖고 있다. 그러나 Toshiba도 QKD–PQC 브리지와 Q-KMS 제품을 이미 공개했으므로, **아이온큐가 기술적으로 독점적이라는 주장은 맞지 않는다.**
  - 따라서 이번 실증의 진정한 투자 포인트는 **“IonQ가 참여했는가?”를 넘어 “2027년 이후 누가 국제망의 Key Management Plane을 실제로 공급·운영하고 그 대가를 받는가?”**에 있다.
