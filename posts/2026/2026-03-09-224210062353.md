**✅ 유럽이 만들려는 “우주 광인터넷 백본”**

- - 최근 ESA(European Space Agency)가 추진하는 **HydRON (High-throughput Optical space Network)** 프로젝트가 우주 통신 산업에서 중요한 의미를 갖기 시작했다.
  - HydRON은 단순한 위성 통신 프로젝트가 아니다.
  - ESA가 공식적으로 설명하는 개념은 다음이다.

> ***“Fibre in the Sky”***

- - 즉 **지상 광인터넷 백본을 우주로 확장하는 프로젝트**다.
  - 지상 인터넷 구조와 비교하면 이해가 쉽다.

|  |  |
| --- | --- |
| **지상 인터넷** | **HydRON** |
| 광케이블 백본 | 위성 레이저 링크 |
| 인터넷 라우터 | 위성 네트워크 노드 |
| 데이터센터 연결 | 위성-위성 광 링크 |
| Tbps 광전송 | Tbps OISL |

> ***HydRON = Space Optical Internet Backbone***

---

**✅ HydRON이 등장한 이유**

- - HydRON의 배경은 **위성 데이터 폭증**이다.
  - 특히 다음과 같은 위성에서 생성되는 데이터가 급격히 증가하고 있다.

    - SAR 위성
    - hyperspectral 위성
    - climate monitoring 위성
    - EO (Earth Observation)
  - 예를 들어 SAR 위성은 하루 **수 TB 수준 데이터**를 생성한다.
  - 기존 위성 통신 구조는 다음과 같다.

    - Satellite → RF downlink → Ground station
  - 하지만 RF 다운링크는 대역폭이 제한적이다.
  - 그래서 ESA는 새로운 구조를 제안했다.
  - Satellite → Laser link → Satellite relay → Ground gateway
  - 즉

    - **위성 → 위성 → 지상**
    - 레이저 네트워크로 데이터를 전달하는 구조다.

---

**✅ HydRON의 기본 아키텍처**

- - HydRON의 목표는 단순한 레이저 통신이 아니다.
  - ESA가 목표로 하는 구조는 다음과 같다.

|  |
| --- |
| Ground optical network  │  Optical Ground Station  │  Laser link (OGSL)  │  LEO satellites  │  Optical mesh network  │  Relay satellites (MEO/GEO)  │  Gateway / Internet |

- - 핵심 특징은 다음이다.

    - multi-orbit networking
    - optical inter-satellite links (OISL)
    - space packet routing
    - 지상 광인터넷과 통합
  - 즉 **Space Optical Backbone**을 만드는 것이다.

**✅ HydRON의 핵심 기술**

- - HydRON이 기존 satcom과 다른 점은 다음 기술이다.
  - **Optical Inter-Satellite Links (OISL)**

    - 위성 간 레이저 통신
  - **On-Board Packet Router**

    - 위성 내부 라우터
  - **Optical mesh networking**

    - 위성 간 네트워크
  - **Coherent optical communication**

    - 지상 광통신 기술을 우주에 적용
  - **WDM optical transport**

    - 여러 파장을 동시에 사용하는 기술

---

**✅ WDM으로 Tbps를 만드는 방법**

- - HydRON의 핵심 목표는 **Tbps급 데이터 링크**다.
  - 이를 가능하게 하는 기술이 바로 **WDM (Wavelength Division Multiplexing)**이다.
  - WDM은 여러 파장의 레이저를 하나의 광 경로로 전송하는 기술이다.
  - 예를 들어

    - λ1 100 Gbps
    - λ2 100 Gbps
    - λ3 100 Gbps
    - λ4 100 Gbps
  - 이렇게 4개의 파장을 동시에 보내면 400 Gbps가 된다.
  - ESA ESTOL 스펙에서는 다음과 같은 변조 방식이 정의되어 있다.

|  |  |
| --- | --- |
| **변조 방식** | **속도** |
| DP-QPSK | 100-200 Gbps |
| DP-16QAM | 200-400 Gbps |

- - 예를 들어

    - 400 Gbps × 8 wavelengths이면 3.2 Tbps가 된다.
  - 즉 **Tbps 우주 네트워크는 WDM + coherent optical로 구현된다.**

---

**✅ OCT (Optical Communication Terminal)**

- - HydRON에서 가장 중요한 장비는 **OCT (Optical Communication Terminal)**이다.
  - 구성 요소

    - laser transmitter
    - telescope optics
    - beam steering
    - receiver
    - modem / DSP
  - 주요 업체

|  |  |
| --- | --- |
| **회사** | **국가** |
| TESAT | 독일 |
| Mynaric | 독일 |
| Skyloom | 미국 |

---

**✅ OCT 기술 경쟁**

- - 현재 우주 레이저 통신은 두 기술 방향으로 나뉜다.

**📌 Direct Detection**

- - 회사

    - Mynaric
    - TESAT
  - 특징

    - 구조 단순
    - 전력 효율 높음
    - 10–100 Gbps

**📌 Coherent Optical**

- - 회사

    - Skyloom
    - 일부 연구기관
  - 특징

    - DSP 기반
    - 고차 변조
    - WDM 가능
    - Tbps 확장
  - ESA ESTOL 표준은 **coherent optical**을 목표로 한다.

---

**✅ HydRON vs Starlink vs SDA**

- - 우주 네트워크는 크게 세 레이어로 나뉜다.

    - User Access
    - Satellite Network
    - Optical Backbone
  - 각 시스템의 역할은 다음과 같다.

|  |  |
| --- | --- |
| **시스템** | **역할** |
| Starlink | satellite ISP |
| SDA | military mesh network |
| HydRON | optical backbone |
| Skyloom | optical terminal |

> *HydRON은 우주 인터넷의 백본 네트워크이다.*

---

**✅ 우주 라우터 (On-Board Packet Router)**

- - HydRON 위성에는 **On-Board Packet Router (OBPR)**가 탑재된다.
  - Laser terminal → Packet router → Laser terminal
  - 즉 **우주에서 직접 IP 라우팅**이 가능해진다.
  - OBPR (On-Board Packet Router)는 개념적으로는 라우터이지만 **지상 데이터센터 라우터와는 설계 철학이 꽤 다르다.**
  - 핵심은 이것이다.

    - 지상 라우터 = 항상 연결된 네트워크
    - OBPR = 계속 끊어지는 네트워크
  - 그래서 구조가 다르다.

|  |  |  |
| --- | --- | --- |
| **항목** | **일반 라우터** | **OBPR** |
| 네트워크 | 항상 연결 | 링크 계속 생성/소멸 |
| 지연 | ms | 수십~수백 ms |
| 토폴로지 | 거의 고정 | 계속 변화 |
| 링크 수 | 많음 | 매우 제한 |
| 전력 | 충분 | 매우 제한 |

**📌 OBPR의 특징**

- - 라우팅 방식

    - contact plan routing
    - DTN (Delay Tolerant Networking) routing
    - central network controller
    - 같은 방식.
  - 포워딩 방식

    - store-and-forward
  - 하드웨어

    - radiation-hardened processor
    - FPGA
    - low power switching
  - 인터페이스

    - laser terminal (OCT)
    - RF payload
    - space link
  - 네트워크 구조

    - ground controller → satellite router → forwarding only
  - 추가 기능

    - contact schedule management
    - link availability prediction
    - DTN buffering
    - time synchronization
  - 특별 기능 (Hybrid Switching)

    - packet router와 circuit switch가 동시에 들어간다.

      - packet switching → 유연성

        - 작은 데이터 전달에 유리

          - network control
          - telemetry
          - command
          - internet traffic
      - circuit switching → 효율성

        - 큰 데이터 흐름에 매우 효율

          - earth observation satellite
          - SAR data
          - video
          - raw sensor data

**✅ ScyLight와 HydRON**

- - HydRON은 ESA 프로그램 **ScyLight** 아래에 있다.
  - 구조

    - ScyLight programme

      - optical terminal R&D
      - secure optical communication
      - quantum communication
      - HydRON
  - 즉

    - ScyLight = 기술 프로그램
    - HydRON = 네트워크 프로젝트

---

**✅ 투자 관점에서 중요한 포인트**

- - HydRON은 단순한 위성 통신 프로젝트가 아니다.
  - ESA 목표

    - “Extend terrestrial fibre networks into space”
  - 즉
  - **Space Optical Internet** 이다.
  - HydRON 생태계는 다음 네 레이어로 나뉜다.

|  |  |
| --- | --- |
| **Layer** | **Companies** |
| OCT | TESAT, Mynaric, Skyloom |
| Satellite prime | Airbus, Thales |
| Ground optical station | Officina Stellare |
| Network operator | Kepler |
| OBPR | Thales, Airbus, Cisco |
| Network orchestration | Cisco, Nokia, Ciena, Kepler, Amazon |

---

**✅ 결론**

- - HydRON은 단순 위성 통신 프로젝트가 아니다.
  - ESA가 만들려는 것은 **우주 광인터넷 백본**이다.
  - 전체 구조는 다음과 같다.

|  |
| --- |
| LEO constellation  ↓  Optical mesh network  ↓  Space optical backbone  ↓  Ground internet |

- - 이 구조가 완성되면

    - Tbps 위성 데이터 네트워크
    - 글로벌 위성 데이터센터
    - quantum communication
    - space internet
  - 같은 새로운 인프라가 가능해진다.
  - 그리고 이 변화는 우주 통신 산업이 RF 기반에서 광인터넷 기반으로 전환되는 과정의 시작일 가능성이 높다.
