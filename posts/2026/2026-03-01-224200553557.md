**✅ IonQ, 유럽 최대급 양자 키 분배 네트워크 중 하나를 루마니아에 구축**

**📌 주요 내용 요약**

- - IonQ가 루마니아에서 국가 규모 양자 키 분배(QKD) 네트워크(RoNaQCI)를 배치 완료했다.
  - 이 프로젝트는 약 **1,500km 이상****,** **6개 도시 연결**이라는 매우 광범위한 인프라로, 유럽 및 세계적으로도 중요한 운용 양자 통신망이다.
  - 공공·대학·리서치 네트워크 등 20여 기관이 참여했으며, EU 양자 보안 프레임워크 강화에 기여한다.

- - 이외에도 유럽에서 들리는 IonQ 관련 뉴스가 한두달 간격으로 계속 나오고 있다.

**✅ EuroQCI**

- - 유럽위원회 디지털 전략 페이지: **European Quantum Communication Infrastructure (EuroQCI)**

    - EuroQCI가 **지상(광섬유) + 우주(위성)** 두 세그먼트로 구성되고, EU 27개국 및 ESA와 함께 추진된다
  - “EuroQCI 배포(Deployment) 코디네이션 프로젝트”

    - **PETRUS (EuroQCI 배포 코디네이션)**:

**📌 기술 구조: Space + Terrestrial 이중 구조**

- - **SpaceQCI (위성 QKD)**

    - EU 소유
    - 장거리 연결
    - 날씨/야간 제약 있음
    - 버퍼링 필요
    - 온디맨드 불가능
  - **TerrQCI (광섬유 QKD)**

    - 각 회원국 소유
    - 요청 기반 공급 가능
    - 하지만 거리 한계 + trusted node 필요

**📌 구조적으로 유리한 기업 유형**

- - **QKD 장비 제조사**

    - ID Quantique
    - Toshiba
    - LuxQuanta
    - ThinkQuantum 등
    - → 단기 수혜
  - **위성 QKD / SpaceQCI 관련 기업**

    - ESA 연계 기업
    - 위성 payload 기업
    - 양자 광학 우주 기업
    - → 중장기 수혜
  - **네트워크 오케스트레이션 / SW 레이어 기업**

    - ConOps에서 명확히:
    - EU-QCI가 route 정의, orchestration 수행
    - 이건 소프트웨어 레이어다.
    - 이 부분이 커질수록:
    - 단순 QKD 박스 업체보다
    - “네트워크 제어 소프트웨어” 기업이 더 중요해질 가능성

**📌 가장 중요한 전략적 포인트**

- - EuroQCI는 단순 네트워크가 아니라 EU Secure Connectivity Programme (IRIS2와 연결)

    - IRIS2 = Infrastructure for Resilience, Interconnectivity and Security by Satellite
    - EU가 2023~2027년 기간 동안 추진하는 **차세대 유럽 위성 통신 보안 프로그램**

    - 위성 보안 통신
    - 디지털 주권

    - 방산 통합
  - 이건 “양자 기술 실험”이 아니라 👉 **유럽 안보 인프라 레벨 프로젝트**

**✅ [부록]** **DV-QKD 와 CV-QKD 차이**

**1️⃣ 기본 개념 차이**

|  |  |  |
| --- | --- | --- |
| **구분** | **DV-QKD** | **CV-QKD** |
| 변수 | Discrete Variable (이산 변수) | Continuous Variable (연속 변수) |
| 정보 표현 | 0 / 1 (광자 단위) | 진폭/위상 연속값 |
| 대표 프로토콜 | BB84, Decoy-state | Gaussian-modulated coherent state |
| 검출 방식 | 단일광자 검출기 (SNSPD, APD) | 호모다인/헤테로다인 검출 |
| 현재 EuroQCI | 대부분 DV | 일부 파일럿 |

****

**2️⃣ 물리적 차이 (핵심)**

- - **🔵 DV-QKD**

    - 단일 광자를 보냄
    - 편광 또는 위상 상태를 0/1로 인코딩
    - 수신자는 랜덤 기저로 측정
    - 잘못 측정된 비트는 폐기
    - 📌 쉽게 말하면:
    - “빛 한 개 한 개를 비트로 쓰는 방식”
  - **🟢 CV-QKD**

    - 매우 약한 레이저 펄스를 보냄
    - 광장의 **연속적인 진폭/위상 값**을 이용
    - 수신자는 표준 광통신 방식으로 측정
    - 📌 쉽게 말하면:
    - “빛의 세기와 위상 연속값을 이용하는 방식”

**3️⃣ 하드웨어 차이**

- - **🔵 DV**

    - 필수:

      - 단일광자 검출기 (비싸고 복잡)
      - 극저온 냉각 SNSPD가 자주 쓰임
    - 장점:

      - 이론적으로 보안 강함
      - 장거리 검증 완료
    - 단점:

      - 장비 가격 높음
      - 운영 복잡
  - **🟢 CV**

    - 필수:

      - 일반 통신용 광수신기
      - 로컬 오실레이터 기반 측정
    - 장점:

      - 기존 통신망과 통합 쉬움
      - 장비 단가 낮음 가능성
      - 냉각 필요 없음
    - 단점:

      - 손실에 민감
      - 장거리 제한
      - 아직 DV만큼 보편적 아님

**4️⃣ 거리 비교**

|  |  |  |
| --- | --- | --- |
| **항목** | **DV** | **CV** |
| 메트로 (≤100km) | 매우 안정 | 안정 |
| 200km 이상 | 가능 (중계 필요) | 급격히 어려움 |
| 위성 | DV가 유리 | CV는 불리 |

- - 👉 그래서 EuroQCI 1차는 DV가 주력.

**5️⃣ 보안 모델 차이**

- - DV:

    - 단일광자 기반
    - MDI-QKD 등 확장 가능
  - CV:

    - Gaussian 공격 모델
    - 보안 증명은 있지만 계산 복잡

**6️⃣ 왜 스페인은 CV를 밀까?**

- - LuxQuanta가 CV 기반이라서.
  - CV의 장점:

    - 통신 인프라와 자연스러운 통합
    - 광통신 DSP와 결합 가능
    - 비용 낮출 가능성
  - EU 전략자율성 측면에서 “유럽 자체 기술” 논리

**7️⃣ 투자 관점 비교**

|  |  |  |
| --- | --- | --- |
| **구분** | **DV-QKD** | **CV-QKD** |
| 현재 시장 | 주류 | 틈새 |
| EuroQCI 채택 | 대부분 | 일부 |
| 기술 성숙도 | 매우 높음 | 성장 중 |
| 장기 잠재력 | 안정적 | 비용 혁신 가능성 |
| 위성 적합성 | 높음 | 낮음 |

**8️⃣ 향후 판도**

- - 단기 (5년):

    - → DV 우세
  - 중기:

    - → MDI-DV 확장
  - 장기:

    - → CV가 비용 혁신으로 일부 영역 잠식 가능
