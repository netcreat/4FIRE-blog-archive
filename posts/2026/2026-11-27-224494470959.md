# AI가 암호를 먼저 해독한다면 양자컴퓨터의 가치는 사라질까?

Published: 2026-11-27T14:57:18+11:00

Original Naver post: https://blog.naver.com/4-fire/224494470959?fromRss=true&trackingCode=rss

---

**✅ P, NP, BPP, BQP와 양자 우위**

- - **양자컴퓨터의 대표적인 가치 중 하나는 고전컴퓨터에서 현실적으로 해결하기 어려운 문제를 효율적으로 풀 수 있다는 것이다. 소인수분해와 쇼어 알고리즘이 대표적이다.**
  - **최근 AI가 수학적 난제를 해결하고 새로운 고전 알고리즘을 발견하면서, 양자컴퓨터가 등장하기 전에 고전컴퓨터가 먼저 암호를 해독할 가능성도 논의되고 있다.**
  - **그러나 고전컴퓨터가 문제를 풀 수 있다는 사실과 양자컴퓨터보다 빠르고 저렴하게 풀 수 있다는 사실은 전혀 다르다.** **계산복잡도, 실제 성능, 상용화 시점을 구분해야 한다.**

---

**✅ 1. Scott Aaronson의 발언 — 무엇이 확인됐는가?**

- - **2026년 11월 24일 Scott Aaronson은 자신의 블로그에서 AI 연구소들의 VP ≠ VNP 증명 발표와 수학적 발전을 논했다.**
  - **11월 25일 후속 글에서는 여러 신뢰할 만한 출처를 통해 암호학에 충격을 줄 미공개 성과가 있다고 거의 확신하지만, 구체적인 성과의 내용은 확신하기 어렵다고 밝혔다. 소문이 전달 과정에서 왜곡될 가능성도 경고했다.**
  - **2026년 11월 27일 기준 이번에 확인한 공개 자료만으로는 OpenAI 또는 Anthropic이 RSA-2048을 실용적으로 해독할 수 있는 고전 알고리즘을 확보했다고 결론 내릴 수 없다.**

**📌 공개된 발표와 미확인 소문의 구분**

|  |  |  |
| --- | --- | --- |
| **주제** | **내용** | **해석** |
| GRH | 일반화 리만 가설 증명 발표가 블로그에 언급됨 | 정수론 관련 성과로, RSA 해독의 직접 증거는 아님 |
| ETH | 지수시간 가설 반증 발표가 블로그에 언급됨 | 일부 기존 복잡도 가정에 영향. P = NP를 뜻하지 않음 |
| VP ≠ VNP | 두 AI 연구소의 증명 발표가 언급됨 | P vs NP의 대수적 유사 문제. P ≠ NP의 직접 증명은 아님 |
| 행렬 곱셈 | 지수 ω = 9/4 주장 언급 | 선형대수 연산의 이론적 발전 |
| 소인수분해 | 고전 다항시간 알고리즘 가능성에 관한 소문 | 구체적 알고리즘 및 실용성 미확인 |
| P vs NP | 클레이 수학연구소의 미해결 난제 | 위 발표들만으로 해결되지 않음 |

- - **위 수학적 성과는 Aaronson이 소개한 발표를 요약한 것으로, 각 증명이나 Lean 검증 코드를 독립적으로 심사한 결과는 아니다.**

**✅ 2. 다항시간(Polynomial Time)이란 무엇인가?**

- - **계산복잡도는 입력의 크기 n이 커질 때 알고리즘이 요구하는 연산량이 얼마나 빠르게 증가하는지를 설명한다.**
  - **다항시간은 최악의 경우 실행 시간이 어떤 고정된 상수 k에 대해 O(n****k****)로 제한되는 경우를 뜻한다. 예를 들어 n, n****2****, n****3****, n****100****은 모두 다항시간 범주에 속한다.**
  - **반면 2****n****, 3****n****, n!은 다항식보다 빠르게 증가한다. 입력이 충분히 커지면 하드웨어 성능 향상만으로 감당하기 어렵다.**
  - **소인수분해에서 입력 크기 n은 정수의 값 자체가 아니라 이를 표현하는 비트 수다. RSA-2048의 n은 2,048이다.**

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **입력 n** | **n** | **n²** | **n³** | **2ⁿ** |
| 10 | 10 | 100 | 1,000 | 1,024 |
| 20 | 20 | 400 | 8,000 | 1,048,576 |
| 50 | 50 | 2,500 | 125,000 | 약 1.126 × 1015 |
| 100 | 100 | 10,000 | 1,000,000 | 약 1.268 × 1030 |
| 1000 | 1,000 | 1,000,000 | 1,000,000,000 | 약 1.072 × 10301 |

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMjdfMjU2/MDAxNzk1NzUwNzMwMjIz.-1jDjEdgNVEPr-Ca7SrO6c99dPh6Ho73PJJAWUd1uk0g.xqzJlE2pmMKrz617v1Fpte4jvVavPyGOGtMACBsLTkgg.PNG/image.png?type=w800)](#)

- - **그래프의 세로축은 로그 스케일이다. 이론적 증가율 비교이며 실제 실행 시간을 뜻하지 않는다.**
  - **다항시간은 이론적으로 효율적인 계산을 구분하는 기준이지, 반드시 실용적으로 빠르다는 의미는 아니다.** **n¹⁰⁰ 역시 다항시간이지만 실제 산업에서 쓰기 어려울 수 있다.**

**✅ 3. P와 NP — 문제 해결과 정답 검증의 차이**

|  |  |  |
| --- | --- | --- |
| **구분** | **P** | **NP** |
| 정식 명칭 | Polynomial Time | Nondeterministic Polynomial Time |
| 문제 해결 | 결정론적 고전컴퓨터로 다항시간 내 가능 | 모든 NP 문제를 고전컴퓨터로 다항시간 내 풀 수 있는지 미확인 |
| 정답 검증 | 다항시간 내 가능 | YES 답의 다항 크기 증거를 다항시간 내 검증 가능 |
| 계산 모델 | 결정론적 | 비결정론적(이론적 모델) |
| 예시 | 최단 경로 결정 문제 | SAT, 부분집합 합, 소인수분해 결정 문제 |

- - **NP는 Non-Polynomial의 약자가 아니다.** **N은 Nondeterministic, 즉 비결정론적이라는 뜻****이다.**
  - **엄밀히 P와 NP는 YES 또는 NO로 답하는 결정 문제의 집합이다.** **NP는 YES인 경우 다항 크기의 증거를 다항시간 내 검증할 수 있는 문제를 뜻한다.** **NO 답에도 항상 쉽게 검증할 수 있는 증거가 있다는 뜻은 아니다.**
  - **비결정론적 계산 모델은 가능한 계산 분기 중 적어도 하나가 정답을 찾아내는지 판정하는 수학적 모델이다. 실제 양자컴퓨터가 모든 답을 동시에 읽어낼 수 있다는 의미가 아니다.**

**📌 부분집합 합(Subset Sum) 예시**

- - **7, 13, 19, 24, 32, 41, 53, 68 중 일부를 한 번씩만 선택해 합이 100이 되는 조합이 존재하는가?**
  - **정답의 예: 32 + 68 = 100.** **각 숫자가 원래 목록에 있는지 확인하고 더하면 정답을 쉽게 검증할 수 있다.**
  - **숫자가 8개라면 가능한 부분집합은 256개다. 숫자가 1,000개라면 2****1000****개에 이른다. 이는 단순 전수 탐색의 후보 수이지 모든 알고리즘이 반드시 이만큼 연산해야 한다는 증명은 아니다.**
  - **부분집합 합에는 목표 합의 수치 크기에 의존하는 의사다항시간 알고리즘도 있다. 하지만 입력의 비트 길이에 대한 일반적인 다항시간 알고리즘은 알려져 있지 않다.**

**📌 P와 NP의 포함 관계**

- - **P ⊆ NP****는 이미 증명된 관계다. 직접 다항시간 내 풀 수 있다면 증거를 검증하는 일도 다항시간 내 할 수 있기 때문이다.**
  - **반대로 NP ⊆ P인지가 아직 해결되지 않았다. 이것이 P vs NP 문제이며 클레이 수학연구소의 100만 달러 밀레니엄 난제다.**

|  |  |
| --- | --- |
| **가설** | **의미** |
| P ≠ NP | 정답을 다항시간에 검증할 수 있지만 결정론적 고전컴퓨터로 다항시간 내 해결할 수 없는 NP 문제가 적어도 하나 존재 |
| P = NP | 모든 NP 결정 문제를 결정론적 고전컴퓨터로 다항시간 내 해결 가능 |

**✅ 4. NP-Complete와 NP-Hard**

|  |  |  |
| --- | --- | --- |
| **분류** | **의미** | **예시** |
| P | 다항시간 내 해결 가능한 결정 문제 | 최단 경로 결정 문제 |
| NP | YES 답의 증거를 다항시간 내 검증할 수 있는 결정 문제 | 소인수분해 결정 문제 |
| NP-Complete | NP에 속하고 모든 NP 문제를 다항시간 내 환원할 수 있는 문제 | 3-SAT, Subset Sum |
| NP-Hard | 모든 NP 문제만큼 어렵거나 그 이상인 문제. NP에 속할 필요는 없음 | 외판원 문제의 최적화 버전 |

- - **NP-Complete 문제 단 하나라도 결정론적 다항시간 알고리즘으로 해결하면 P = NP가 성립한다. 다른 모든 NP 문제를 그 문제로 다항시간에 변환할 수 있기 때문이다.**
  - **소인수분해는 NP-Complete 문제로 알려져 있지 않다. 따라서 고전 다항시간 소인수분해 알고리즘이 발견돼도 P = NP가 증명되는 것은 아니다.**

---

**✅ 5. BPP와 BQP는 무엇인가?**

|  |  |  |
| --- | --- | --- |
| **분류** | **영문 명칭** | **의미** |
| P | Polynomial Time | 결정론적 고전컴퓨터로 다항시간 내 해결 |
| BPP | Bounded-error Probabilistic Polynomial Time | 확률적 고전컴퓨터로 제한된 오류 확률 내에서 다항시간 내 해결 |
| BQP | Bounded-error Quantum Polynomial Time | 양자컴퓨터로 제한된 오류 확률 내에서 다항시간 내 해결 |
| NP | Nondeterministic Polynomial Time | YES 답의 증거를 고전컴퓨터로 다항시간 내 검증 |

- - **BPP와 BQP의 B는 Bounded-error를 뜻한다. 표준 정의에서는 모든 입력에 대해 정답을 얻을 확률이 최소 2/3인 다항시간 알고리즘을 기준으로 한다.**
  - **독립적인 반복 실행과 다수결을 통해 오류 확률을 더 낮출 수 있다. BPP는 고전 난수, BQP는 양자 중첩과 간섭 및 측정을 이용한다.**
  - **여기서 오류 확률은 이론적 알고리즘의 성공 확률이며, 실제 양자 하드웨어의 물리적 게이트 오류율과는 구분해야 한다.**

**📌 현재 증명된 포함 관계와 미해결 관계**

- - **P ⊆ BPP ⊆ BQP** **및** **P ⊆ NP****는 증명돼 있다.**
  - **BPP와 BQP가 엄격히 다른 집합인지는 아직 일반적인 계산 모델에서 증명되지 않았다. NP와 BQP 사이의 전체 포함 관계 역시 알려져 있지 않다.**
  - **소인수분해의 결정 문제는 NP와 BQP에 속한다. 고전 다항시간에 해결할 수 없다는 일반적 하한은 증명되지 않았다.**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMjdfMTIz/MDAxNzk1NzUxNDM1ODU4.Ackv40xgUfy5P2MwE3W6n8bspasqY9-EeqTYdqHtbE4g.S-LkzuBSc07A1JxFkkgh80cAYcq0ERoW-daRHUbYFMwg.PNG/image.png?type=w800)](#)

- - **도식은 포함 관계와 소인수분해의 일반적인 추정 위치를 설명한다. 각 집합이 서로 다르다는 사실이 증명됐다는 의미는 아니다. NP는 관계가 미확정이므로 도식에서 생략했다.**

**✅ 6. P = NP라면 세상은 어떻게 변할까?**

- - **P = NP가 성립하면 모든 NP 결정 문제를 다항시간 내 해결할 수 있다. 다항시간에 검증할 수 있는 다항 길이의 증거도 표준적인 탐색-결정 환원을 통해 찾을 수 있다.**
  - **다만 실제 알고리즘이 매우 높은 차수나 큰 상수를 갖는다면 당장 상용화되지 않을 수 있다****. 아래는 실용적으로 효율적인 알고리즘이 발견된다는 조건에서의 잠재적 영향이다.**

|  |  |
| --- | --- |
| **분야** | **잠재적 변화** |
| RSA | 소인수분해 기반 보안 위협 |
| ECC | 이산로그 기반 공개키 암호 위협 |
| PQC | 일반적인 계산적 일방향성에 기반한 공개키 보안 위협 |
| 물류 | 조합적 운송 경로 및 일정 최적화 |
| 반도체 | 일부 회로 배치와 설계 최적화 |
| 신약 개발 | 일부 구조 탐색 및 최적화 가속 |
| AI | 일부 모델 최적화 및 탐색 가속 |
| 수학 | 길이가 다항식으로 제한된 증명 탐색 가속 |
| 금융 | 일부 복잡한 포트폴리오 최적화 |

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMjdfMTg0/MDAxNzk1NzUxNDUyMDU2.Po283iyOoKgY_7KSAcvxMWntIHSpccq2NMpHd6-iaIYg.6tIF8Y0eqEhNcNVE8X0IiYKG2ArQ8Oj6rXHv-GkHQhwg.PNG/image.png?type=w800)](#)

- - **P = NP가 모든 수학적 난제의 해결이나 모든 양자물리 현상의 효율적 시뮬레이션을 보장하는 것은 아니다.**
  - **P = NP에서 BPP = P가 따라오지만, BQP = BPP까지 따라오는지는 알려져 있지 않다. 따라서** **P = NP만으로 양자컴퓨터의 모든 이론적 우위가 사라진다고 결론 내릴 수 없다.**

**✅ 7. RSA가 뚫리면 다른 암호도 뚫리는가?**

- - **RSA는 큰 정수의 소인수분해가 어렵다는 사실에 의존한다. 예를 들어 61 × 53 = 3,233을 계산하는 것은 쉽지만 큰 정수에서 원래 소수를 찾는 것은 훨씬 어려울 수 있다.**
  - **현재 일반 정수 소인수분해의 대표적 고전 알고리즘인 GNFS는 준지수적 실행 시간의 알고리즘이다. 쇼어 알고리즘은 양자 계산 모델에서 소인수분해 및 이산로그를 다항시간에 해결한다.**
  - **고전 소인수분해 알고리즘의 발견은 RSA에 직접적인 위협이지만, 수학적 기반이 다른 암호까지 자동으로 해독한다는 뜻은 아니다.**

|  |  |  |
| --- | --- | --- |
| **기술** | **기반** | **소인수분해 돌파의 영향** |
| RSA | 정수 소인수분해 | 직접적 위협 |
| DH | 유한체 이산로그 | 별도 알고리즘 필요 |
| ECC | 타원곡선 이산로그 | 별도 알고리즘 필요 |
| ML-KEM (Kyber) | 모듈 격자 | 직접적 영향 없음 |
| ML-DSA (Dilithium) | 모듈 격자 | 직접적 영향 없음 |
| SLH-DSA | 해시 함수 | 직접적 영향 없음 |
| AES-256 | 대칭키 암호 | 직접적 영향 없음 |
| QKD | 양자물리 기반 키 분배 | 직접적 영향 없음. 인증과 구현 보안은 필요 |

- - **양자내성암호(PQC)는 양자 및 고전 공격에 견디도록 설계됐지만 새로운 AI 기반 수학적 공격에 영구적으로 안전하다는 보장은 없다.**
  - **반대로 특정 RSA 공격이 발견됐다는 이유로 모든 PQC가 취약하다고 판단할 근거도 없다. 암호마다 기반 난제, 공격 복잡도, 파라미터를 별도로 검토해야 한다.**

---

**✅ 8. 같은 다항시간이라도 성능 차이는 크다**

- - **AI가 고전 소인수분해 알고리즘을 O(n****5****)로 만들고 양자 알고리즘이 O(n****3****)이라고 가정해 보자. 이는 설명을 위한 가상 복잡도이며 실제 새 알고리즘이나 쇼어 알고리즘의 구체적 구현 비용을 나타내지 않는다.**
  - **두 알고리즘 모두 다항시간이지만 같은 단위의 연산과 동일한 계수를 가정하면 연산량 차이는 n²배다.**

|  |  |  |  |
| --- | --- | --- | --- |
| **입력 비트 수** | **고전 n⁵** | **양자 n³** | **가상 연산량 비율** |
| 512 | 3.518e+13 | 1.342e+08 | 262,144배 |
| 1,024 | 1.126e+15 | 1.074e+09 | 1,048,576배 |
| 2,048 | 3.603e+16 | 8.590e+09 | 4,194,304배 |
| 4,096 | 1.153e+18 | 6.872e+10 | 16,777,216배 |
| 8,192 | 3.689e+19 | 5.498e+11 | 67,108,864배 |

- - **2,048비트에서 가상의 연산량 비율은 4,194,304배다. 하지만 이는 실제 실행 시간이나 가격의 차이가 아니다.**
  - **고전 CPU/GPU의 연산과 양자 논리 게이트의 비용 및 속도는 다르다. 양자 오류보정, 물리 큐비트 수, 게이트 깊이, 측정, 재실행, 데이터 입출력 등을 함께 비교해야 한다.**
  - **예를 들어 고전컴퓨터가 먼저 RSA-2048을 실용적으로 해독하고 양자컴퓨터가 나중에 더 적은 비용으로 큰 문제를 해결할 수도 있다. 반대의 경우도 가능하다.**

**📌 상용화 시점과 실제 경쟁력**

|  |  |
| --- | --- |
| **시나리오** | **양자컴퓨터에 미치는 영향** |
| 고전컴퓨터만 실용적 | 해당 암호 해독 분야의 우위 크게 약화 |
| 둘 다 가능하지만 양자가 빠름 | 실제 성능 우위 유지 가능 |
| 양자가 더 저렴함 | 경제적 우위 유지 가능 |
| 고전은 작은 규모만 효율적 | 큰 입력에서 양자 우위 유지 가능 |
| 고전이 범용 양자계산까지 저비용으로 수행 | 양자컴퓨팅의 근본적 경쟁력 위협 |

- - **고전컴퓨터는 이미 구축된 인프라를 이용할 수 있어 새로운 알고리즘을 빠르게 적용할 가능성이 있다.**
  - **양자컴퓨터는 오류보정과 논리 큐비트 확장이라는 하드웨어 과제가 남아 있다. 하지만 문제 규모가 커질수록 양자의 비용이나 시간 우위가 나타날 가능성은 별도로 평가해야 한다.**
  - **암호 해독 자체는 먼저 성공한 쪽의 국가안보상 가치가 특히 클 수 있다. 해당 암호가 이미 폐기된 뒤라면 후발 양자컴퓨터가 더 빨라도 시장 가치가 회복되지 않을 수 있다.**

**✅ 9. 양자컴퓨터의 독보적인 가치는 어디까지 훼손되는가?**

- - **쇼어 알고리즘은 고전적인 수학 문제를 양자컴퓨터가 효율적으로 풀 수 있음을 보여 준 상징적 사례다. 고전 알고리즘이 경쟁력 있게 소인수분해를 해결하면 이 사례의 독점적 가치가 약해진다.**
  - **그러나** **소인수분해가 P에 속한다고 해서 양자화학, 양자물질 시뮬레이션, 모든 양자회로의 고전 시뮬레이션도 효율적으로 가능해지는 것은 아니다.**

|  |  |
| --- | --- |
| **AI가 발견하는 고전 알고리즘** | **잠재적 양자컴퓨팅 영향** |
| 소인수분해 | RSA 해독 경쟁력 훼손 |
| 이산로그 | ECC 등 공개키 암호 해독 경쟁력 훼손 |
| 선형대수 | 일부 양자 머신러닝 경쟁력 감소 |
| 조합 최적화 | 일부 양자 최적화의 상업적 가치 감소 |
| 양자화학 시뮬레이션 | 신약 및 신소재 응용의 경쟁력 훼손 가능 |
| 범용 양자회로의 효율적 고전 시뮬레이션 | 양자컴퓨팅 산업의 근본적 위협 |

**📌 양자 시뮬레이션은 왜 별개의 문제인가?**

- - **분자, 전자, 초전도체 및 양자물질의 상호작용은 본질적으로 양자역학적이다. 파인만이 양자컴퓨터를 제안한 주요 동기 역시 이러한 물리계의 시뮬레이션이었다.**
  - **일반적인 순수 양자상태를 상태벡터로 직접 표현할 경우 n개의 큐비트에는 2****n****개의 복소수 진폭이 필요하다.**

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMjdfMTEy/MDAxNzk1NzUxNjA4NDc5.XU2_7q6P07No1aUu2OVvD8awHlPvJ5lS6wUmvvmlfCIg.hAoybYyTPLfP__lvc9uhwcuCLeyEzu_-rHhIkVUcXkgg.PNG/image.png?type=w800)](#)

|  |  |
| --- | --- |
| **큐비트 수** | **복소수 진폭 개수** |
| 10 | 1,024 |
| 20 | 1,048,576 |
| 30 | 1,073,741,824 |
| 50 | 약 1.126 × 1015 |
| 100 | 약 1.268 × 1030 |

- - **텐서 네트워크와 근사 알고리즘, AI 기반 시뮬레이션은 특정 구조를 갖는 양자상태를 효율적으로 표현할 수 있다. 위 상태벡터 크기만으로 모든 양자 시뮬레이션의 고전적 난이도나 양자 우위가 증명되는 것은 아니다.**

**📌 P = NP와 BPP = BQP는 서로 다른 주장이다**

|  |  |
| --- | --- |
| **조건** | **의미** |
| 소인수분해 ∈ P | 결정론적 고전 다항시간 소인수분해 가능 |
| P ≠ NP | 고전 다항시간에 풀 수 없는 NP 문제가 존재 |
| P = NP | 모든 NP 결정 문제를 고전 다항시간에 해결 |
| BPP = BQP | 양자 다항시간으로 해결할 수 있는 결정 문제를 확률적 고전 다항시간에 해결 |

[![](https://mblogthumb-phinf.pstatic.net/MjAyNjExMjdfMjU0/MDAxNzk1NzUxNzM2ODA5.ke2mkbhTPp0G21aZ2cSRO7u-uY7gfVgxlm_ywwtBoXUg.-VeT-Gx5rUyf2v6zlwjsm6NfuRan-6p5OIQZRte0G4Yg.PNG/image.png?type=w800)](#)

- - **BPP = BQP가 증명되더라도 양자컴퓨터의 모든 성능 우위가 사라진다는 의미는 아니다. 두 계산 모델의 다항식 차수, 상수, 시간과 비용은 다를 수 있다.**
  - **또한 BQP는 결정 문제의 분류이므로 BPP = BQP만으로 모든 양자 샘플링 작업이나 양자상태 생성 작업이 효율적으로 고전 시뮬레이션된다는 결론을 낼 수 없다.**
  - **CPU와 GPU는 원칙적으로 같은 고전 계산을 수행할 수 있지만 특정 연산에서 GPU가 훨씬 높은 처리량과 경제성을 제공한다. 계산 원리는 다르지만, 양자컴퓨터의 상업적 가치를 이해하는 비유로 활용할 수 있다.**

**✅ 10. IonQ에 미치는 영향 — AI는 조력자이자 경쟁자다**

- - **AI는 양자 오류보정, 양자회로 최적화, 신약 및 신소재 연구에서 양자컴퓨터의 발전을 도울 수 있다. 동시에 새로운 고전 알고리즘을 발견해 양자컴퓨터가 목표로 하는 시장을 선점할 수도 있다.**

|  |  |
| --- | --- |
| **사업 분야** | **고전 암호 해독 성공 시 잠재적 영향** |
| 범용 양자컴퓨팅 | 암호 관련 가치 제안 일부 약화 |
| 국가안보용 양자컴퓨팅 | 암호 해독의 전략적 희소성 감소 |
| 양자화학 및 신소재 | 직접 영향 제한적. 별도 고전 알고리즘 발전에 노출 |
| QKD | 수학적 난제 의존을 줄이는 키 분배 기술의 전략적 관심 증가 가능 |
| PQC | 전환 수요 가속 가능. 별도의 AI 공격에는 노출 |
| 양자 센싱 | 물리 기반 측정 기술로 직접 영향 제한적 |
| 양자 인터넷 | 물리적 양자 연결 기능은 별개 |
| Elisity | 마이크로세그멘테이션 및 제로트러스트 수요 증가 가능 |
| SkyWater | 새로운 암호 하드웨어 및 보안 반도체 수요 가능 |

- - **QKD는 인증과 구현 보안, 키 관리가 필요하며 암호화나 인증을 모두 대체하는 기술은 아니다. Elisity의 접근통제는 피해 확산을 줄이는 수단이지 취약한 암호를 복구하는 수단은 아니다.**
  - **위 사업별 영향은 투자 관점의 가설이며 확인된 신규 계약이나 매출 전망이 아니다. IonQ의 보안·센싱 사업 확대가 양자컴퓨팅 가치 하락을 반드시 상쇄하는 것도 아니다.**

**📌 기술적 위험도 비교**

|  |  |
| --- | --- |
| **AI의 돌파구** | **잠재적 위협** |
| 고전 소인수분해 알고리즘 | 암호 해독 분야의 직접적 위협 |
| 고전 이산로그 알고리즘 | 공개키 암호 해독 분야의 추가 위협 |
| P ≠ NP 증명 | 그 자체로 양자컴퓨팅 직접 위협 아님 |
| P = NP 증명 | 이론적 위협. 실제 알고리즘 성능 별도 |
| 실용적인 P = NP 알고리즘 | 암호·최적화 등 광범위한 산업적 위협 |
| BPP = BQP 증명 | 결정 문제의 초다항식 양자 우위에 근본적 위협 |
| 범용 양자계산의 저비용 고전 구현 | 양자컴퓨팅의 상업적 가치에 근본적 위협 |

**✅ 11. 결론 — 절대적 독점성과 상대적 경쟁우위는 다르다**

- - **양자컴퓨팅의 경쟁력을 평가할 때 다음 세 가지를 구분할 필요가 있다.**
  - **계산복잡도 우위(Computational Advantage)**

    - 입력 규모가 커질 때 고전 알고리즘 대비 연산량 증가율이 얼마나 유리한가.
  - **실제 성능 우위(Practical Advantage)**

    - 실제 하드웨어에서 동일한 정확도의 문제를 얼마나 빠르게 해결하는가.
  - **경제적 우위(Economic Advantage)**

    - 시간, 장비, 전력, 오류보정, 운용 비용을 모두 감안하면 어느 쪽이 더 효율적인가.
  - **AI가 소인수분해 같은 고전적 수학 문제를 효율적으로 해결해도 양자컴퓨터가 더 빠르거나 저렴할 가능성은 남아 있다. 양쪽의 상용화 시점과 목표 시장의 변화도 중요하다.**
  - **IonQ의 장기적인 경쟁력을 판단할 때 물리·논리 큐비트, 게이트 충실도, 오류보정, 인터커넥트뿐 아니라 AI가 개선하는 고전 알고리즘의 성능도 함께 추적해야 한다.**
  - **Q-Day에 더해 AI에 의해 기존 암호가 위협받는 시나리오도 고려할 필요가 있다. A-Day라는 표현을 사용한다면 이는 설명을 위한 가칭이며 확인된 사건이나 공인된 일정이 아니다.**
  - **결국 상업적으로 중요한 질문은 양자컴퓨터만 풀 수 있는 문제인가가 아니라, 언제부터 양자컴퓨터를 이용하는 것이 가장 효율적인가이다.**
