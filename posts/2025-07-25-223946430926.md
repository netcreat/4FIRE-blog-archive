호주 제조업 노조와 호주 간호·조산사 연맹이 생산성 향상을 근거로 근무 시간 단축과 연차 휴가 확대를 위한 새로운 움직임을 보이고 있는데요, 다시 화두에 오르고 있는 주 4일제 근무, 어떤 장단점이 있고 호주 정부는 어떤 결과를 내놓을지 친절한 경제에서 알아봅니다.

www.sbs.com.au](https://www.sbs.com.au/language/korean/ko/podcast-episode/working-a-four-day-week/qg3taluww)

다음은 SBS 뉴스 '친절한 경제'에서 다룬 **주 4일 근무제에 대한 방송 내용 요약**이다.

**🔎 개요**

- **호주 제조업 노조**와 **간호·조산사 연맹**이 **근무시간 단축 및 연차 확대**를 요구
- **알바니지 총리**, "폭넓은 지지" 있다면 **개혁 지지** 입장
- **주 4일제 도입 논의가 본격화**

****

**📊 주요 연구 결과**

- **네이처 휴먼 비헤이비어지** 발표 (2025)
- **6개국 141개 기관**, **2,896명 직원 참여**
- **주 4일 근무 후**:

  - **번아웃 감소**
  - **신체·정신 건강 향상**
  - **직무 만족도 증가**
  - **평균 근무시간 5시간 감소**

****

**⚖️ 장단점 및 과제**

|  |  |
| --- | --- |
| **장점** | **단점·한계** |
| ✅ 건강 및 웰빙 개선 | 🔸 참여 기업 자발성 (대표성 부족) |
| ✅ 생산성 증가 | 🔸 주로 영어권, 소규모 기업 중심 |
| ✅ 워라밸 향상 | 🔸 산업별 적용 어려움 가능성 |
| ✅ 회의 축소 등 업무 효율성 증가 | 🔸 공정성·지속 가능성 검토 필요 |

****

**🌏 해외 사례**

- **벨기에**: 법적 주 4일제 시행 (2022년)
- **영국**: 시범 운영 후 92% 기업이 지속 결정
- **아이슬란드**: 전체 노동자의 86%가 주 4일제 적용
- **뉴질랜드·브라질 등**도 시범 운영 및 유지 중
- **한국** : 주4.5일제 이재명 대통령 후보시절 핵심 공약

****

**🧠 전문가 의견**

- **단순한 '하루 줄이기'보다 스마트한 일하기가 핵심**
- **AI 등 기술혁신에 따른 노동 재편 필수**
- **전통적 근로자상 → 성과 중심으로 변화**
- **회의 축소 등 업무 방식 혁신 필요**

****

**🛠️ 시행 방식 예시**

- **100:80:100 모델**

  - ▶ 급여 100%, 근무시간 80%, 생산성 100% 유지
- **근무시간 단축 + 급여 감축**
- **주 40시간 → 4일로 압축**
- **격주 9일 근무, 주 35시간 등 다양한 형태**

****

**🏛️ 정부 대응 및 제언**

- **연방 경제개혁 원탁회의**(8월 예정)에서 논의 예정
- **시범사업부터 점진적 확대** 권고
- **공공부문부터 시작 → 민간 확대**
- **노조 외 사회 전반 합의 필요**
- **중소기업·자영업자 고려 필수**

****

> 주 4일 근무제는 단순한 ‘하루 덜 일하기’가 아니라 **미래 노동 패러다임 전환**을 의미
>
> 8월 원탁회의 결과가 향후 방향성에 중대한 영향 줄 전망

---

**🔍 근무제 단축의 역사적 변천 배경**

|  |  |  |
| --- | --- | --- |
| **시대** | **변화** | **핵심 이유** |
| 산업혁명 초기 | 주 6~7일, 하루 12~16시간 | 기계 중심 생산 → 노동력 최대 활용 필요 |
| 20세기 초 | **일요일 휴무 법제화** | 종교적 전통, 노동자 권익 요구 시작 |
| 1960~70년대 | **주 6일제 → 토요일 반일제** | 노동조합 운동 강화, **소득 증가**, **여가 수요** 등장 |
| 1980~90년대 | **주 5일제 정착** | 생산성 향상, 가족 중심 문화 확산, 복지정책 확대 |
| 2020년대~ | **4.5일제, 4일제 논의** | 기술 발전(AI, 자동화), 정신건강 문제 대두, 워라밸 중시 |

**🧠 왜 이런 변화가 일어날까? – 5가지 핵심 이유**

**1. 📈 생산성 향상**

- 예전에는 하루 10시간 일해도 겨우 결과물이 나왔지만, 지금은 자동화와 IT 기술로 4시간이면 가능.
- 예: Excel, 이메일, 챗GPT 도입 → 단순 반복 업무는 크게 줄어듦.

> “더 오래 일하는 것이 반드시 더 많은 성과를 내는 건 아니다”는 것이 입증됨.

**2. 💰 경제 구조 변화**

- **산업 중심 → 서비스 중심 → 디지털 중심**으로 변함에 따라

→ 노동 집약도 ↓, 뇌 기반 창의 노동 ↑

→ 장시간 집중보다 "효율적 몰입"이 더 중요

****

**3. 🤝 노동운동과 법·복지정책의 진화**

- 20세기 중반부터 노동조합이 주도한 "삶의 질 향상 요구"가 법제화에 반영
- 주 5일제 정착도 오랜 투쟁 끝에 이뤄진 제도적 성과

****

**4. 🧘 정신건강·번아웃 이슈 대두**

- 현대인은 정보 과부하, 멀티태스킹 등으로 **피로 누적**
- WHO가 "번아웃은 공식 질병"으로 지정

→ 장시간 노동이 생산성 저하로 연결된다는 연구 다수

****

**5. 🤖 AI·자동화로 인한 업무량 감소**

- 반복적/예측 가능한 업무는 **기계가 대체**

→ 인간은 **전략적 사고, 창의성, 공감 중심의 업무** 수행

→ 이런 업무는 ‘시간’보다 ‘집중도’가 핵심이므로 **근무시간 단축**이 타당

****

> 주 4일제와 같은 흐름은 **역사적으로도 일관된 진화의 연장선**이다.

- “**같은 시간 더 많이 일하라**” → “**더 오래 살기 위해 적절히 일하자**” → “**더 잘 살기 위해 효율적으로 일하자**”
- 즉, 노동은 **생존의 수단**에서 **삶의 일부**로 바뀌고 있고,
- 기술과 사회는 이를 뒷받침하고 있다.

**🔍 문제의 본질: 노동시간 단축 → 임금 or 기업이익 or 둘 다 감소?**

|  |  |  |
| --- | --- | --- |
| **측면** | **가능성** | **설명** |
| 노동자 | 💸 **임금 감소 우려** | 주 4일 근무 시 급여도 줄면 생활수준 위협 |
| 기업 | 📉 **비용 효율성 악화 우려** | 동일 임금 지급 → 근무일 단축 → 단기적 생산성 감소 가능 |
| 정부 | 🏛️ **세수 감소·복지 부담 증가 가능성** | 노동소득세 기반의 조세 시스템은 부담 가중 |

**🧠 이 문제를 해결하려는 3가지 글로벌 접근법**

**1. 📊 "100:80:100" 모델 (고정 수입 유지 전략)**

- **100% 급여**, **80% 근무시간**, **100% 생산성**
- 생산성 향상을 전제로 한 모델:

→ **"더 적게 일하지만 더 집중적으로 일해라"**

****

**2. ⚖️ 임금 조정형 모델 (선택형)**

- 일부 기업은 **근무시간 단축 시 급여도 일부 감액**

→ 직원 자율 선택: “시간과 돈 중 선택하세요”

→ 생활비 수준이 낮은 국가나 저축 중심 문화에서 선호

****

**3. 💡 기본소득 또는 사회보장 확장 모델**

- 노동 외 소득 보장을 위한 정책적 접근
- 예:

  - **기본소득제** (UBI: Universal Basic Income)
  - **부분고용지원금**
  - **사회임금 개념 강화** (주택·의료·교육 무상화로 실질 가처분소득 ↑)

**🏭 기업 입장: 손실인가? 기회인가?**

|  |  |
| --- | --- |
| **우려** | **대응 전략** |
| 💸 인건비 대비 생산성 하락 | → **업무 프로세스 개선**(회의 축소, 자동화 도입) |
| ❌ 고객 대응력 약화 (영업일 단축 시) | → **근무일 분산 배치**(로테이션 근무) |
| 📉 수익성 악화 | → **브랜드 가치 상승**, 이직률 감소 → 장기적 비용 절감 |

> 실제로 영국 4일제 시범기업 중 60%가 **수익이 증가**했다고 보고됨 (2023)

**🔮 장기적 접근: “노동 중심 경제 → 생태적·디지털 균형경제”로**

**✅ 전환 핵심 조건:**

- 노동 ↔ 생산 ↔ 분배 시스템 간 **균형 재설계**
- **AI·자동화가 대체하는 노동에 대해 사회적 배당**을 검토
- **성과 중심의 임금 체계**로 이동
- **사회적 협약(Social Compact)** 필요: 노동자, 기업, 정부가 함께 규칙 재정립

> “노동을 줄이면 소득이 줄고, 기업도 손해”라는 등식은 **과거 산업시대의 사고방식**이다.
>
> 핵심은 **“어떻게 하면 같은 가치(성과)를 더 적은 시간에 만들어낼 수 있는가”**
>
> 그리고 그 **성과의 분배를 어떻게 공정하게 재설계할 것인가**이다.

기술 발전으로 인한 생산성 향상은 과거와 비교할 수 없을 정도로 비약적이다. 디지털화와 AI 자동화 덕분에 업무량은 줄어들고, 육체적 노동은 감소했지만, 그만큼 정보 과부하와 멀티태스킹에 따른 **정신적 피로와 번아웃**은 새로운 사회적 문제로 부각되고 있다.

이제는 단순히 자리에 앉아 시간을 채우기보다, **스마트하게 일하고 효율적으로 성과를 내는 방식**이 더 합리적이다. 이는 기업 입장에서도 충분히 검토해볼 만한 변화이며, 노동자 입장에서는 **집중도 높은 일과 충분한 휴식을 병행함으로써 삶의 질을 높이고**, 나아가 **소비 여력과 여가 산업을 활성화하는 선순환 구조**를 기대할 수 있다.

혹자는 “이러다 주 3일, 주 2일제까지 요구하는 것 아니냐”고 우려할 수도 있다. 하지만 지금 논의되는 변화는 결코 극단적인 시도가 아니다. 시대 변화에 맞춰 **노동의 방식과 균형을 재설정하려는 자연스러운 흐름**이다.

물론, **개인적으로는 주 3일제도 환영할 준비가 되어 있긴 하다.**
