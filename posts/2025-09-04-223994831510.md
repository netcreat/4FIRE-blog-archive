**✅****2024년 7월 Microsoft Quantum Sydney** **University of Sydney내** **나노사이언스 허브에 위치한 연구시설 종료**

**💡****주요 연구성과 요약**

- - **양자 제어 칩 개발 (2021년)**

    - 2021년, David Reilly 교수를 이끄는 팀이 대규모 큐비트를 제어할 수 있는 칩을 개발했다. 이는 양자 컴퓨터의 **확장성(scalability)** 문제 해결에 매우 중요한 진전이었음.
  - **I/O 병목 문제 해결**

    - 이 팀은 양자 컴퓨터를 제어하는 과정에서 발생하는 전통적인 **입출력 병목(input/output bottleneck)** 문제에 대한 중대한 돌파구를 찾아냈다.
  - **토폴로지 기반 큐비트(read-out) 측정 기법 — Nature 논문**

    - 최근에 발표된 Nature 논문에서, 호주 연구진이 중심이 되어 큐비트의 **read‑out 및 제어 기술**(특히 측정 기반 토폴폴로지 큐비트 관련)이 검증되었고, 이 기술이 훌륭하게 구현되었다는 평가를 받았다.
  - **Majorana 1 칩에의 기여 (2025년 발표)**

    - Microsoft가 발표한 **Majorana 1 칩** 개발에도 시드니 연구진이 핵심 기여를 했다. 회로 설계, 상호 연결 구조, **cryogenic 환경에서의 냉각·열 관리 기술** 등 여러 분야에서 중요한 역할을 했죠.

> "A huge amount” of the University of Sydney researchers’ work contributed to the creation of Microsoft’s Majorana 1, Professor Reilly told *Information Age* on Thursday, "from the design, the manufacture of these circuit boards and interconnects, to the read-out technology".
>
> The team’s “major contribution” to the project also included aspects of the device’s cooling and thermal management, Reilly said.

- - **연구 기반 구축 및 인재 육성**

    - 약 7년간 이어진 이 파트너십은 호주와 시드니 대학의 **양자 과학 기초 역량 강화**, **첨단 장비 도입**, **연구 인력 확충**, **산업 연결 강화**에 크게 기여했다. 그리고, 그간의 기술력은 **Dr. David Reilly**와 **Dr. Thomas Ohki**를 매개로 하여 고스란히 **Emergence Quantum**에 남게 되었다.
  - 두 창업자의 기술적 강점 요약

|  |  |  |
| --- | --- | --- |
| **구분** | **Dr. David Reilly** | **Dr. Tom Ohki** |
| **전문성** | Cryo-CMOS / QPU 제어 ASIC / 시스템 아키텍처 | QPU 제어 / SNSPD / FPGA / 포토닉 체인 |

| **EQ에서 역할** | 시스템 통합 / Cryo-CMOS / ASIC 개발 총괄 | 제어기 / FPGA / 검출기 체인 / 인터페이스 설계 |

**💡****시드니 연구소 폐쇄는 무엇을 의미하는가?**

- - **Sydney Lab 폐쇄는 단순한 구조조정이 아님**

    - → **미국 안보 전략, DARPA 프로젝트, ITAR 규제**와 깊게 연결.
    - **ITAR 규제(2024년)**

      - 양자 기술을 군사 안보 핵심 자산으로 분류
    - **DARPA QBI (2024년 7월)**

      - 2033년까지 **유틸리티급(Utility-scale)** 양자컴퓨터 개발 목표.
      - 최종 단계에 **Microsoft**와 **PsiQuantum** 2곳만 선정.
      - **Microsoft 기술을 미국 내로 집중시키기 위한 전략적 압박** 해석 가능
  - Microsoft는 시드니 연구소에서 나온 **7년간의 특허와 IP**를 모두 보유

    - 하지만 기술력은 회수 못했음.

      - **Cryo-CMOS 제어 칩 개발**

        - 밀리켈빈(mK) 환경에서 동작 가능
        - 수천 개 큐비트를 **칩 내부에서 직접 제어**
        - 배선을 획기적으로 줄여 발열 문제 해결
        - **IBM, Google보다 수년 앞선 기술력**이라는 평가 → 상온 장비에서 생성한 제어 신호를 케이블로 QPU에 전달

          - 배선 병목(Wiring Bottleneck)

            - 수천 ~ 수만개의 동축 케이블 필요 → 부피와 비용 급증.
          - **열 부하(Heat Load)**

            - 케이블을 통해 실온에서 발생하는 열이 극저온 환경으로 유입 → 안정성 저하.
          - **스케일링 한계**

            - 현재 IBM·Google 시스템은 **100~433 큐비트 수준**에서 멈춰 있는 이유 중 하나가 바로 이 문제.
    - 법적 권리는 Microsoft이 소유, 실제 기술은 Emergence Quantum이 소유.

      - 한쪽은 결혼은 했으나 마음을 얻지 못했고, 다른 한쪽은 마음은 얻었지만 결혼을 못한 꼴.

**✅****Emergence Quantum의 핵심 역량**

|  |  |
| --- | --- |
| **항목** | **상세 설명** |
| **연구 중심** | 양자 컴퓨팅 제어 계층, cryogenic 하드웨어, 통합 시스템 설계 |
| **큐비트 플랫폼 독립적** | 다양한 물리적 qubit 기반 플랫폼을 모두 지원 |
| **기술 상업화** | 실용적 솔루션 개발 및 R&D 서비스 제공 |
| **전략적 파트너십** | IonQ, Diraq 등과 협업을 통한 기술 확대 및 응용 추진 |

**💡****양자 컴퓨팅 제어 계층**

- - 양자 프로세서(QPU)와 **클래식 컴퓨팅 계층(CPU/HPC/클라우드)** 사이에서 **큐비트를 구동·측정·보정하는 핵심 계층**이다.
  - 쉽게 말하면, "양자 하드웨어와 소프트웨어를 연결하는 중간층".
  - **역할**

    - 큐비트에 **게이트 신호**를 보내 연산을 수행
    - **레이저, 마이크로파, 전자기장** 등 구동 장치를 동기화
    - 다중 큐비트 시스템에서 **타이밍·동기화 제어**
    - **read-out 회로**를 통해 측정값 수집
    - 실시간 **에러 검출 및 보정(피드백 루프)** 수행

**💡****Emergence Quantum의 제어 계층 특징**

- - Emergence Quantum은 제어 계층에서 **큐비트-비종속(Qubit-agnostic)** 접근을 취한다.
  - 즉, 특정 물리적 플랫폼(초전도, 이온트랩, 광자, 스핀 등)에 종속되지 않고 하드웨어 추상화 계층(HAL, Hardware Abstraction Layer)을 구현하는 데 집중한다.

|  |  |  |
| --- | --- | --- |
| **기술 영역** | **상세 설명** | **비고** |
| **Cryo-CMOS 회로** | 밀리켈빈 온도에서도 안정 동작하는 저전력 CMOS 칩 설계 | Diraq와 공동 개발 |
| **고밀도 I/O 집적** | 수천 개 큐비트에서 발생하는 제어·측정 신호를 병목 없이 처리 | 기존 초전도 QPU의 가장 큰 한계 해결 |
| **멀티-플랫폼 제어** | 마이크로파·레이저·전기장 신호를 모두 하나의 제어 칩에서 지원 | trapped-ion + spin + photonic 호환 |
| **실시간 오류 보정 루프** | QEC 피드백을 cryo 레벨에서 직접 처리 | IonQ·Oxford보다 빠른 응답 가능 |
| **저온 패키징** | 극저온 환경에서 제어 신호 손실 최소화 | RF·광·마이크로파 혼합 |

**💡****Emgergence Quantum(Dr. David Reilly와 Dr. Thomas Ohki)의 기술력이 IonQ 와 Oxford Ionics에 미치는 영향**

- - 두 인물의 대표 실험은 **mK 초전도/스핀/마요라나**에 가깝지만, IonQ가 당면한 병목은 “물리 플랫폼”보다 “시스템 공학(전자·측정·다중화·운영 자동화)”에 더 많이 걸려 있다.

    - **Ohki = 저잡음 측정·증폭·피드포워드·검출기 체인·RB 표준**,
    - **Reilly = 크라이오-CMOS/주파수 다중화·대규모 제어 아키텍처·온칩 RF 소자**.
    - 이 둘을 IonQ의 **광학·마이크로파·포토닉 인터커넥트**에 이식하면, **QEC·원격얽힘·운영 자동화**가 빨라진다.

**✅****IonQ, Oxford Ionics, Emergemenc Quantum 기술 조합의 전략적 시너지**

**💡****IonQ + Oxford Ionics 공동 플랫폼**

- - IonQ: **포토닉 인터커넥트** + **고충실도 레이저 기반 게이트**
  - Oxford Ionics: **마이크로파 기반 QCCD 게이트**
  - Emergence Quantum: **저잡음 RF/마이크로파·제어 ASIC·실시간 오류정정 회로**

**💡****원격 얽힘 + 네트워크 QPU 단계에서의 기여**

- - IonQ의 최종 목표 중 하나가 **다중 QPU 네트워크화**인데,
  - Oxford Ionics와 결합하면 포토닉 인터커넥트 효율을 올리고 마이크로파 기반 **on-chip routing**을 활용할 수 있습니다.

    - Ohki → 단일광자 검출기(SNSPD, SPD)·광증폭기 체인 최적화
    - Reilly → 마이크로파 신호 라우팅·주파수 다중화·집적 인터커넥트
  - 포토닉 링크 효율 + 마이크로파 스케일링 + 전자 집적화가 결합되면 IonQ가 목표로 하는 **Milestone 3, 4** (이온-광자 ↔ 이온-이온 ↔ QPU↔QPU 얽힘)까지의 병목을 크게 해소할 수 있다.

**💡****오류정정(QEC) + 실시간 제어에서 강점**

- - Oxford Ionics의 QPU는 **마이크로파로 제어**하기 때문에 **미드서킷 측정 + μs급 피드포워드**가 핵심이다.

    - Ohki: FPGA+SFQ 회로로 **패리티 측정→결과 피드백 경로 μs 수준 최적화**
    - Reilly: Cryo-CMOS 제어 채널 + 읽기 회로 집적화 → **채널당 지연·전력 감소**
  - → **BB5/BB6/qLDPC** 같은 IonQ의 중장기 QEC 전략에도 그대로 직결.

**💡****Quantum Machines(QM)와의 차이점**

- - Quantum Machines(QM)는 OPX/OPX+ 플랫폼으로 유명한 회사지만, **플랫폼 독립 제어기**에만 집중한다.

|  |  |  |
| --- | --- | --- |
| **비교 항목** | **Emergence Quantum (EQ)** | **Quantum Machines (QM)** |
| **핵심 포지션** | **맞춤형 하드웨어 R&D 팀** | **범용 제어·오케스트레이션 플랫폼** |
| **제어기** | QPU별 커스텀 ASIC·FPGA 설계 | OPX+ 상용 FPGA 컨트롤러 공급 |
| **Cryo-CMOS** | ✅ 직접 설계·제작 가능 | ❌ 없음 |
| **SNSPD / SPD 체인** | ✅ 직접 개발 및 광자 인터페이스 설계 | ❌ 고객 장비 의존 |
| **FPGA 제어 회로** | μs급 피드포워드 루프 구현 | OPX 내장 FPGA 기반, 범용 지연 최적화 |
| **고객 지원 범위** | IonQ, Oxford Ionics, Diraq 등과 **공동 R&D** | 다수 QPU 업체에 범용 플랫폼 판매 |
| **SW 스택** | 필요시 ML 기반 자동화 지원, 고객 맞춤형 | QOP SDK로 표준 Pulse API 제공 |
| **플랫폼 커버리지** | 이온트랩, 마이크로파 타일, 스핀, 광자 등 **멀티** | 초전도·스핀·이온트랩 등 범용 지원 |

- - **Emergence Quantum(EQ)**

    - → **QPU 제어 + Cryo-CMOS + SNSPD + FPGA + 패키징까지 전방위 엔지니어링 조직**
    - → IonQ/Oxford Ionics와 **공동 개발** 가능
  - **Quantum Machines(QM)**

    - → **제어·오케스트레이션 플랫폼(OPX) 공급자**
    - → 범용성이 강점이지만, 하드웨어 커스터마이징은 한계적
  - 즉, **EQ는 QM보다 훨씬 깊은 하드웨어·시스템 스택을 커버하는 팀**이다.

**✅맺음말**

Microsoft가 마요라나 기반 토폴로지컬 큐비트 개발을 **계속할지, 아니면 포기할지는 단순한 선택의 문제**일 수 있다.

하지만 최근 행보를 종합해 보면, **개발 중단 선언이 나오더라도 크게 놀랍지 않은 상황**이다.

비슷한 시기에 이어진 **핵심 연구자들의 퇴사**, **시드니 랩 종료**, **두 개 이상의 다른 양자컴퓨터 업체와의 협력 확대**,

그리고 가장 최근에 발표한 **QEC 코드에서 특정 하드웨어가 아닌 다수 플랫폼을 지원**한다는 점은 Microsoft의 전략 축이 변화하고 있음을 보여준다.

이러한 흐름은 **Nvidia가 CUDA-Q 플랫폼을 통해 다양한 양자컴퓨터 생태계를 흡수하려는 전략**과 결이 비슷하다.

이 노선 변경의 **가장 큰 수혜자**는 아마 **IonQ**일 것이다.

IonQ는 그동안 **QPU 제어 기술을 통해 양자컴퓨터와 고전컴퓨터를 지연 없이 연결할 기술**이 필요했으며, **Cryo-CMOS 기술**과 **SNSPD 체인 기술** 역시 핵심 과제로 보고 있었다. 그런데 Microsoft가 이들 기술 역량을 갖춘 조직을 **어떤 이유에서인지 포기**하면서, IonQ에게는 오히려 **절호의 기회**가 주어진 셈이다. 물론 Emergence Quantum(EQ)은 초전도체 방식, 특히 **마요라나 기반**으로 기술력을 쌓아온 회사이긴 하지만, 최근 **추가 현금 조달에 성공한 IonQ** 입장에서 보면 EQ와의 관계를 단순 협력에 그칠지, 전략적 인수합병(M&A)까지 확대할지는 아직 **두 가지 가능성을 모두 열어둔 채 지켜볼 필요가 있다**.
